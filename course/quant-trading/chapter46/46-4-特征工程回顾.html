特征工程回顾

特征工程是机器学习中决定模型性能的关键环节。在量化交易中， 好的特征往往比复杂的模型更重要。本节将系统回顾特征工程的各个方面。

💡 特征工程全景

🔧

特征构造

从原始数据创造新特征

🎯

特征选择

选择最有价值的特征

🔄

特征变换

转换特征以提升效果

🔬 特征构造方法

1. 基础特征提取

从原始数据中提取基础统计特征。

  • 价格特征：开盘价、最高价、最低价、收盘价
  • 成交量特征：成交量、成交额
  • 时间特征：星期几、月份、季度、小时

2. 技术指标特征

基于技术指标构造特征。

  • 趋势指标：MA、EMA、MACD、ADX
  • 震荡指标：RSI、KDJ、CCI
  • 动量指标：ROC、MOM、威廉指标
  • 成交量指标：OBV、VR、EMV

3. 统计特征

计算统计量作为特征。

  • 收益率：日收益率、周收益率、月收益率
  • 波动率：历史波动率、GARCH波动率
  • 偏度和峰度：收益分布形状特征
  • 相关系数：与其他股票的相关性

4. 滚动特征

基于滚动窗口计算特征。

  • 滚动均值、滚动标准差
  • 滚动最大值、最小值
  • 滚动相关性
  • 滚动分位数

5. 差分特征

通过差分提取变化特征。

  • 价格差分：一阶、二阶差分
  • 对数收益率
  • 收益率变化

6. 比率特征

构造比率关系特征。

  • 价格比率：当前价格/移动平均
  • 成交量比率：当前成交量/平均成交量
  • 估值比率：PE、PB、PS

7. 交叉特征

组合多个特征构造新特征。

  • 特征乘积
  • 特征比值
  • 特征交互

🎯 特征选择方法

1. 过滤法 (Filter)

根据统计指标选择特征。

  • 方差阈值：删除方差小的特征
  • 相关系数：删除高相关特征
  • 卡方检验：适用于分类问题
  • 互信息：衡量特征与目标的依赖性

2. 包装法 (Wrapper)

使用模型评估选择特征。

  • 递归特征消除 (RFE)
  • 前向选择
  • 后向消除

3. 嵌入法 (Embedded)

模型训练过程中选择特征。

  • Lasso回归
  • 决策树特征重要性
  • 随机森林特征重要性

4. IC筛选法

量化交易专用方法。

  • 计算每个特征的IC值
  • 选择IC绝对值大的特征
  • 筛选IC稳定的特征

🔄 特征变换方法

1. 标准化

将特征缩放到标准正态分布。

z = (x - mean) / std

2. 归一化

将特征缩放到[0, 1]区间。

x_norm = (x - min) / (max - min)

3. 对数变换

处理偏态分布，使数据更接近正态分布。

x_log = log(x + 1)

4. Box-Cox变换

使数据更接近正态分布的幂变换。

5. 分箱

将连续特征离散化。

  • 等距分箱
  • 等频分箱
  • K-means分箱

6. One-Hot编码

将类别特征转换为二进制向量。

7. 目标编码

用目标变量的统计值替换类别特征。

💻 代码示例

import numpy as np
import pandas as pd
from sklearn.preprocessing import StandardScaler, MinMaxScaler, RobustScaler
from sklearn.preprocessing import LabelEncoder, OneHotEncoder
from sklearn.feature_selection import VarianceThreshold, SelectKBest, f_classif
from sklearn.feature_selection import RFE, SelectFromModel
from sklearn.ensemble import RandomForestClassifier
import talib

# 1. 基础特征构造
def create_basic_features(df):
    """构造基础特征"""
    df = df.copy()

    # 收益率
    df['returns'] = df['close'].pct_change()
    df['log_returns'] = np.log(df['close'] / df['close'].shift(1))

    # 差分
    df['price_diff'] = df['close'].diff()
    df['volume_diff'] = df['volume'].diff()

    # 比率
    df['volume_ratio'] = df['volume'] / df['volume'].rolling(20).mean()

    return df

# 2. 技术指标特征
def create_technical_features(df):
    """构造技术指标特征"""
    df = df.copy()

    # 移动平均
    df['ma5'] = talib.MA(df['close'], timeperiod=5)
    df['ma10'] = talib.MA(df['close'], timeperiod=10)
    df['ma20'] = talib.MA(df['close'], timeperiod=20)

    # 价格相对移动平均
    df['price_to_ma5'] = df['close'] / df['ma5']
    df['price_to_ma20'] = df['close'] / df['ma20']

    # RSI
    df['rsi'] = talib.RSI(df['close'], timeperiod=14)

    # MACD
    macd, macdsignal, macdhist = talib.MACD(df['close'])
    df['macd'] = macd
    df['macd_signal'] = macdsignal
    df['macd_hist'] = macdhist

    # 布林带
    upper, middle, lower = talib.BBANDS(df['close'])
    df['bb_upper'] = upper
    df['bb_middle'] = middle
    df['bb_lower'] = lower
    df['bb_width'] = (upper - lower) / middle
    df['bb_position'] = (df['close'] - lower) / (upper - lower)

    # ATR
    df['atr'] = talib.ATR(df['high'], df['low'], df['close'])

    return df

# 3. 统计特征
def create_statistical_features(df, windows=[5, 10, 20]):
    """构造统计特征"""
    df = df.copy()

    for window in windows:
        # 滚动统计
        df[f'returns_std_{window}'] = df['returns'].rolling(window).std()
        df[f'returns_skew_{window}'] = df['returns'].rolling(window).skew()
        df[f'returns_kurt_{window}'] = df['returns'].rolling(window).kurt()

        # 价格滚动统计
        df[f'close_max_{window}'] = df['close'].rolling(window).max()
        df[f'close_min_{window}'] = df['close'].rolling(window).min()
        df[f'close_range_{window}'] = (
            df[f'close_max_{window}'] - df[f'close_min_{window}']
        ) / df['close']

    return df

# 4. 交叉特征
def create_interaction_features(df):
    """构造交叉特征"""
    df = df.copy()

    # 价格与成交量交互
    df['price_volume'] = df['close'] * df['volume']

    # 收益率与波动率交互
    df['returns_volatility'] = df['returns'] * df['returns_std_20']

    # 趋势与动量交互
    df['trend_momentum'] = (df['close'] / df['ma20'] - 1) * df['rsi']

    return df

# 5. 特征选择 - IC法
def select_features_by_ic(df, target_col, ic_threshold=0.02):
    """基于IC选择特征"""
    feature_cols = [col for col in df.columns if col != target_col]

    ic_values = {}
    for col in feature_cols:
        ic = df[target_col].corr(df[col])
        ic_values[col] = ic

    # 选择IC绝对值大于阈值的特征
    selected_features = [
        col for col, ic in ic_values.items()
        if abs(ic) > ic_threshold
    ]

    return selected_features, ic_values

# 6. 特征标准化
def standardize_features(df, method='standard'):
    """特征标准化"""
    df = df.copy()

    if method == 'standard':
        scaler = StandardScaler()
    elif method == 'minmax':
        scaler = MinMaxScaler()
    elif method == 'robust':
        scaler = RobustScaler()

    numeric_cols = df.select_dtypes(include=[np.number]).columns
    df[numeric_cols] = scaler.fit_transform(df[numeric_cols])

    return df, scaler

# 7. 特征重要性分析
def analyze_feature_importance(X, y, n_features=20):
    """分析特征重要性"""
    rf = RandomForestClassifier(n_estimators=100, random_state=42)
    rf.fit(X, y)

    importance = pd.DataFrame({
        'feature': X.columns,
        'importance': rf.feature_importances_
    }).sort_values('importance', ascending=False)

    return importance.head(n_features)

# 8. 递归特征消除
def rfe_feature_selection(X, y, n_features_to_select=10):
    """使用RFE选择特征"""
    estimator = RandomForestClassifier(n_estimators=100, random_state=42)

    rfe = RFE(estimator=estimator,
              n_features_to_select=n_features_to_select)
    rfe.fit(X, y)

    selected_features = X.columns[rfe.support_]
    ranking = pd.DataFrame({
        'feature': X.columns,
        'ranking': rfe.ranking_
    }).sort_values('ranking')

    return selected_features, ranking

# 9. 特征相关性分析
def analyze_feature_correlation(df, threshold=0.9):
    """分析特征相关性"""
    corr_matrix = df.corr()

    # 找出高相关特征对
    high_corr = []
    for i in range(len(corr_matrix.columns)):
        for j in range(i+1, len(corr_matrix.columns)):
            if abs(corr_matrix.iloc[i, j]) > threshold:
                high_corr.append({
                    'feature1': corr_matrix.columns[i],
                    'feature2': corr_matrix.columns[j],
                    'correlation': corr_matrix.iloc[i, j]
                })

    return corr_matrix, high_corr

📚 量化交易特征工程要点

1. 避免前视偏差

  • 使用t时刻的信息预测t+1时刻
  • 不要使用未来数据构造特征

2. 特征稳定性

  • IC稳定性比IC大小更重要
  • 避免过度拟合历史模式

3. 特征多样性

  • 组合不同类型的特征
  • 避免特征间高度相关

4. 可解释性

  • 特征应有合理的金融逻辑
  • 避免无意义的数学组合
⚠️
注意事项

1. 特征工程比算法选择更重要
2. 避免数据泄漏，特别是时间序列数据
3. 注意特征的计算成本
4. 定期评估特征的衰减情况

✨
最佳实践

特征工程是一个迭代过程。建议从简单的特征开始，逐步增加复杂度。 使用可视化工具理解特征分布，使用统计方法评估特征质量。
