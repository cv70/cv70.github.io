云服务器概述

云服务器（Cloud Server）是一种简单高效、处理能力可弹性伸缩的计算服务。 相比传统物理服务器，云服务器具有即开即用、弹性扩展、按需付费等优势。

🔧 服务器基础配置

1. 连接服务器

# 使用 SSH 连接服务器 ssh root@your-server-ip # 或使用密钥文件 ssh -i ~/.ssh/your-key.pem root@your-server-ip

2. 创建普通用户

# 创建用户 adduser deployer # 添加 sudo 权限 usermod -aG sudo deployer # 配置 SSH 密钥 mkdir -p /home/deployer/.ssh cp ~/.ssh/authorized_keys /home/deployer/.ssh/ chown -R deployer:deployer /home/deployer/.ssh chmod 700 /home/deployer/.ssh chmod 600 /home/deployer/.ssh/authorized_keys

3. 系统更新与基础软件

# 更新系统 apt update && apt upgrade -y # 安装基础工具 apt install -y curl wget git vim htop net-tools # 安装 Node.js (使用 NodeSource) curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash - apt install -y nodejs # 安装 Docker curl -fsSL https://get.docker.com | sh usermod -aG docker deployer

🔐 安全配置

SSH 安全配置

# 编辑 SSH 配置 vim /etc/ssh/sshd_config # 推荐配置 Port 22 # 或改为非标准端口 PermitRootLogin no # 禁止 root 登录 PasswordAuthentication no # 禁用密码登录 PubkeyAuthentication yes # 启用密钥登录 # 重启 SSH 服务 systemctl restart sshd

防火墙配置 (UFW)

# 启用 UFW 防火墙 ufw default deny incoming ufw default allow outgoing # 开放必要端口 ufw allow 22/tcp # SSH ufw allow 80/tcp # HTTP ufw allow 443/tcp # HTTPS ufw allow 3000/tcp # Node.js 应用（如需要） # 启用防火墙 ufw enable ufw status

🚀 部署 Node.js 应用

# 创建应用目录 mkdir -p /var/www/myapp chown -R deployer:deployer /var/www/myapp # 切换用户 su - deployer # 克隆代码或上传文件 cd /var/www/myapp git clone https://github.com/your-repo/myapp.git . # 安装依赖 npm ci --production # 构建应用（TypeScript） npm run build # 使用 PM2 启动 npm install -g pm2 pm2 start dist/index.js --name myapp pm2 save pm2 startup
💡
云服务器安全检查清单
  • 禁用 root 登录和密码登录
  • 配置防火墙只开放必要端口
  • 定期更新系统和软件包
  • 配置安全组规则限制访问来源
  • 定期备份数据和配置
  • 启用系统日志监控
