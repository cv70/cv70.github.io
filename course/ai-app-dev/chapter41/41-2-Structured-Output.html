41.2 Structured Output

大模型的格式化输出控制

🎯 学习目标

  • 理解结构化输出的重要性和应用场景
  • 掌握JSON Schema约束输出的方法
  • 学会使用不同平台的结构化输出功能
  • 了解输出验证和错误处理策略

什么是Structured Output

Structured Output是指让大模型按照预定义的结构格式输出内容，通常为JSON格式。相比自由文本输出，结构化输出更易于程序处理和集成到应用系统中。

📊 结构化输出的价值

✅

可解析性

程序可直接解析，无需复杂正则

🔒

一致性

保证输出格式符合预期规范

🔗

可集成

便于与其他系统对接集成

⚖️ 实现方式对比

方式 优点 缺点 可靠性
Prompt引导 简单、通用 不可靠、需后处理 低
JSON Mode 保证有效JSON 不保证Schema符合 中
Function Calling 参数结构化 需要函数调用框架 高
Structured Output API 严格符合Schema 特定模型支持 最高

💻 OpenAI Structured Output

from openai import OpenAI from pydantic import BaseModel client = OpenAI() # 使用Pydantic定义输出结构 class PersonInfo(BaseModel): name: str age: int occupation: str skills: list[str] contact: dict # 使用response_format参数 response = client.beta.chat.completions.parse( model="gpt-4o-2024-08-06", messages=[ {"role": "system", "content": "提取人物信息并以JSON格式返回"}, {"role": "user", "content": "张三是一名30岁的软件工程师，擅长Python和Java"} ], response_format=PersonInfo ) # 直接获得解析后的对象 person = response.choices[0].message.parsed print(person.name) # 张三 print(person.age) # 30 print(person.skills) # ['Python', 'Java']
💡
Schema设计技巧

使用明确的字段名和详细的description，帮助模型理解每个字段的含义。对于枚举类型字段，使用enum限制可选值。

🔧 复杂Schema示例

嵌套结构定义

from pydantic import BaseModel from typing import Optional class Address(BaseModel): street: str city: str country: str postal_code: str class Company(BaseModel): name: str industry: str employee_count: int address: Address class Employee(BaseModel): name: str email: str department: str salary: Optional[int] = None company: Company skills: list[str]

JSON Schema定义

schema = { "type": "object", "properties": { "name": {"type": "string"}, "age": { "type": "integer", "minimum": 0, "maximum": 150 }, "status": { "type": "string", "enum": ["active", "inactive"] }, "tags": { "type": "array", "items": {"type": "string"} } }, "required": ["name", "age"] } # 使用schema response = client.chat.completions.create( model="gpt-4-turbo-preview", messages=messages, response_format={ "type": "json_schema", "json_schema": { "name": "user_info", "schema": schema, "strict": True } } )

🔄 输出验证与错误处理

import json from jsonschema import validate, ValidationError def get_structured_output(prompt, schema, max_retries=3): """带验证的结构化输出""" for attempt in range(max_retries): response = client.chat.completions.create( model="gpt-4-turbo-preview", messages=[ {"role": "user", "content": prompt} ], response_format={"type": "json_object"} ) try: # 解析JSON result = json.loads(response.choices[0].message.content) # 验证Schema validate(instance=result, schema=schema) return result except json.JSONDecodeError as e: print(f"JSON解析失败，重试 {attempt + 1}/{max_retries}") except ValidationError as e: print(f"Schema验证失败: {e.message}") raise Exception("无法生成符合要求的结构化输出")
