99.5 Node.js 应用容器化

完整实战：将 Node.js + TypeScript 项目容器化

🎯 学习目标

  • 掌握 Node.js 应用的完整容器化流程
  • 学会处理 TypeScript 项目的构建与运行
  • 了解生产环境最佳实践
  • 掌握容器调试技巧

项目结构

myapp/ ├── src/ │ ├── index.ts │ ├── app.ts │ └── modules/ ├── dist/ ├── package.json ├── tsconfig.json ├── Dockerfile ├── Dockerfile.dev ├── docker-compose.yml ├── docker-compose.override.yml └── .dockerignore

📦 生产环境 Dockerfile

# ==================== 构建阶段 ==================== FROM node:20-alpine AS builder # 安装构建工具（如果需要编译原生模块） RUN apk add --no-cache python3 make g++ WORKDIR /app # 复制依赖文件 COPY package.json package-lock.json ./ COPY tsconfig.json ./ # 安装所有依赖 RUN npm ci # 复制源代码 COPY src ./src # 构建 TypeScript RUN npm run build # 清理 devDependencies RUN npm prune --production # ==================== 生产阶段 ==================== FROM node:20-alpine # 安装 tini 作为 init 进程 RUN apk add --no-cache tini WORKDIR /app # 设置环境变量 ENV NODE_ENV=production \ PORT=3000 # 创建非 root 用户 RUN addgroup -g 1001 -S nodejs && \ adduser -S nodejs -u 1001 -G nodejs # 复制构建产物 COPY --from=builder --chown=nodejs:nodejs /app/dist ./dist COPY --from=builder --chown=nodejs:nodejs /app/node_modules ./node_modules COPY --from=builder --chown=nodejs:nodejs /app/package.json ./ # 切换到非 root 用户 USER nodejs # 暴露端口 EXPOSE 3000 # 健康检查 HEALTHCHECK --interval=30s --timeout=10s --start-period=30s --retries=3 \ CMD wget --no-verbose --tries=1 --spider http://localhost:3000/health || exit 1 # 使用 tini 启动应用 ENTRYPOINT ["/sbin/tini", "--"] CMD ["node", "dist/index.js"]

🔧 开发环境 Dockerfile

# Dockerfile.dev - 开发环境配置 FROM node:20-alpine WORKDIR /app # 安装 nodemon 全局 RUN npm install -g nodemon # 复制依赖文件 COPY package*.json ./ # 安装所有依赖（包括 devDependencies） RUN npm install # 复制源代码 COPY . . # 设置环境变量 ENV NODE_ENV=development \ PORT=3000 EXPOSE 3000 # 开发模式启动（热重载） CMD ["npm", "run", "dev"]

🛠️ 开发环境覆盖配置

# docker-compose.override.yml - 自动加载 version: '3.8' services: app: build: context: . dockerfile: Dockerfile.dev volumes: # 挂载源代码实现热重载 - ./src:/app/src:ro - ./package.json:/app/package.json:ro # 使用匿名卷保护 node_modules - /app/node_modules environment: - NODE_ENV=development - DEBUG=app:* ports: - "3000:3000" # 调试端口 - "9229:9229" command: npm run dev postgres: ports: - "5432:5432" redis: ports: - "6379:6379"
