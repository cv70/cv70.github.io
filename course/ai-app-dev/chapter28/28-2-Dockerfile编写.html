28.2 Dockerfile编写

构建高效、可维护的容器镜像

🎯 学习目标

  • 理解Dockerfile的基本结构和语法
  • 掌握常用指令的使用方法
  • 学会编写AI应用的Dockerfile
  • 了解镜像优化最佳实践

什么是Dockerfile？

Dockerfile是一个文本文件，包含了构建Docker镜像所需的所有命令。通过Dockerfile，我们可以自动化地创建自定义镜像，确保环境配置的可重复性和一致性。

📋 Dockerfile常用指令

指令 说明 示例
FROM 指定基础镜像 FROM python:3.10
WORKDIR 设置工作目录 WORKDIR /app
COPY 复制文件到镜像 COPY . /app
ADD 复制并解压文件 ADD app.tar.gz /app
RUN 执行命令 RUN pip install flask
CMD 容器启动命令 CMD ["python", "app.py"]
ENTRYPOINT 容器入口点 ENTRYPOINT ["python"]
ENV 设置环境变量 ENV MODEL_PATH=/models
EXPOSE 声明暴露端口 EXPOSE 8080
VOLUME 创建挂载点 VOLUME /data

🤖 AI应用Dockerfile示例

# 基础镜像：使用NVIDIA CUDA镜像
FROM nvidia/cuda:11.8-cudnn8-runtime-ubuntu22.04

# 设置环境变量
ENV DEBIAN_FRONTEND=noninteractive
ENV PYTHONUNBUFFERED=1
ENV MODEL_PATH=/app/models

# 设置工作目录
WORKDIR /app

# 安装系统依赖
RUN apt-get update && apt-get install -y \
    python3.10 \
    python3-pip \
    git \
    && rm -rf /var/lib/apt/lists/*

# 复制依赖文件
COPY requirements.txt .

# 安装Python依赖
RUN pip3 install --no-cache-dir -r requirements.txt

# 复制应用代码
COPY src/ ./src/
COPY config/ ./config/

# 创建模型目录
RUN mkdir -p /app/models

# 暴露端口
EXPOSE 8000

# 健康检查
HEALTHCHECK --interval=30s --timeout=10s --start-period=5s --retries=3 \
    CMD curl -f http://localhost:8000/health || exit 1

# 启动命令
CMD ["python3", "src/main.py"]
图：编写Dockerfile是容器化应用的第一步

⚡ 多阶段构建优化

# 第一阶段：构建阶段
FROM python:3.10 AS builder
WORKDIR /app
COPY requirements.txt .
RUN pip install --user -r requirements.txt

# 第二阶段：运行阶段
FROM python:3.10-slim
WORKDIR /app

# 只复制必要的文件
COPY --from=builder /root/.local /root/.local
COPY src/ ./src/

ENV PATH=/root/.local/bin:$PATH
CMD ["python", "src/main.py"]

📊 镜像大小对比

未优化镜像

  • 基础镜像: python:3.10 (约900MB)
  • 包含构建工具
  • 缓存未清理
  • 总大小: ~2GB

优化后镜像

  • 基础镜像: python:3.10-slim (约150MB)
  • 多阶段构建
  • 清理缓存
  • 总大小: ~400MB
⚠️
注意事项

避免在Dockerfile中硬编码敏感信息（如API密钥、密码）。应使用环境变量或Docker Secrets来管理敏感配置。
