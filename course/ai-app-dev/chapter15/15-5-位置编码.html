15.5 位置编码

为无序的注意力注入序列信息

🎯 学习目标

  • 理解位置编码的必要性与原理
  • 掌握正弦余弦位置编码公式
  • 了解可学习位置编码与相对位置编码
  • 能够在模型中正确应用位置编码

为什么需要位置编码

位置编码（Positional Encoding）是Transformer不可或缺的组成部分。 由于自注意力机制具有置换不变性（permutation invariant），打乱序列顺序不会改变输出， 因此必须显式地注入位置信息，让模型能够区分不同位置的token。

❓ 置换不变性问题

# 自注意力的置换不变性 # 输入序列 A B C 和 C B A 经过注意力后，每个位置的输出结构相同 # 示例： # "我 爱 你" 和 "你 爱 我" # 如果没有位置信息，"我"在两个句子中的表示完全相同 # 这显然是不合理的！ # 解决方案：为每个位置添加唯一的位置向量 embedding = token_embedding + positional_embedding

📐 正弦余弦位置编码

Transformer原文提出的经典位置编码方案：

# 正弦余弦位置编码公式 # 对于位置 pos 和维度 i： PE(pos, 2i) = sin(pos / 100002i/dmodel) PE(pos, 2i+1) = cos(pos / 100002i/dmodel) # 其中： # pos - token在序列中的位置（0, 1, 2, ...） # i - 嵌入向量的维度索引 # d_model - 嵌入维度 # 设计特点： # 1. 每个位置有唯一编码 # 2. 可以泛化到任意长度序列 # 3. 相对位置可以通过线性变换得到

💻 PyTorch实现位置编码

import torch import torch.nn as nn import math class PositionalEncoding(nn.Module): def __init__(self, d_model, max_len=5000, dropout=0.1): super().__init__() self.dropout = nn.Dropout(p=dropout) # 计算位置编码 pe = torch.zeros(max_len, d_model) position = torch.arange(0, max_len, dtype=torch.float).unsqueeze(1) # 计算分母项 div_term = torch.exp( torch.arange(0, d_model, 2).float() * (-math.log(10000.0) / d_model) ) # 偶数维度用sin，奇数维度用cos pe[:, 0::2] = torch.sin(position * div_term) pe[:, 1::2] = torch.cos(position * div_term) # 添加batch维度 [1, max_len, d_model] pe = pe.unsqueeze(0) # 注册为缓冲区（不是参数） self.register_buffer('pe', pe) def forward(self, x): # x: [batch_size, seq_len, d_model] x = x + self.pe[:, :x.size(1), :] return self.dropout(x) # 使用示例 pos_encoder = PositionalEncoding(d_model=512) embedded = embedding_layer(input_tokens) encoded = pos_encoder(embedded)

⚖️ 位置编码方案对比

方案 优点 缺点 应用
正弦余弦编码 可泛化到任意长度，相对位置可学习 固定模式，不够灵活 Transformer原版
可学习位置编码 灵活，可针对任务优化 最大长度固定，不可泛化 BERT、GPT
相对位置编码 直接建模相对距离 计算复杂度增加 T5、Transformer-XL
旋转位置编码(RoPE) 结合绝对与相对位置，效果好 实现复杂 LLaMA、GLM

🔬 可学习位置编码实现

class LearnedPositionalEncoding(nn.Module): def __init__(self, d_model, max_len=512): super().__init__() # 可学习的位置嵌入 self.pos_embedding = nn.Embedding(max_len, d_model) def forward(self, x): batch_size, seq_len, _ = x.size() positions = torch.arange(seq_len, device=x.device) return x + self.pos_embedding(positions) # BERT风格的位置编码 class BERTEmbedding(nn.Module): def __init__(self, vocab_size, d_model, max_len=512): super().__init__() self.token_embedding = nn.Embedding(vocab_size, d_model) self.position_embedding = nn.Embedding(max_len, d_model) self.token_type_embedding = nn.Embedding(2, d_model) # 句子区分 self.layer_norm = nn.LayerNorm(d_model) def forward(self, input_ids, token_type_ids=None): seq_len = input_ids.size(1) positions = torch.arange(seq_len, device=input_ids.device) if token_type_ids is None: token_type_ids = torch.zeros_like(input_ids) embedding = ( self.token_embedding(input_ids) + self.position_embedding(positions) + self.token_type_embedding(token_type_ids) ) return self.layer_norm(embedding)

🔄 旋转位置编码（RoPE）简介

核心思想

将位置信息编码为旋转矩阵，应用于Query和Key

# RoPE将位置m编码为旋转角度 # 对Query应用旋转： Q' = Q * eimθ # 这样Q'·K'包含了相对位置(m-n)

优势

  • 相对位置信息自然融入注意力计算
  • 支持任意长度序列扩展
  • 现代LLM广泛采用
💡
实践建议

对于新项目，建议从可学习位置编码开始（简单有效）。 如果需要处理超长序列或追求最佳性能，可以考虑RoPE或ALiBi等现代位置编码方案。
