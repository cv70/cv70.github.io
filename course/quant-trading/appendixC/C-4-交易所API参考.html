🔌 数据传输协议

协议 用途 特点
TCP/IP 行情传输 可靠传输，高延迟
UDP 行情传输 快速传输，可能丢包
FIX协议 交易协议 标准协议，全球通用
WebSocket 实时推送 双向通信，低延迟
REST API 查询接口 简单易用，延迟较高

📊 数据字段说明

字段 说明 数据类型
Open 开盘价 Float
High 最高价 Float
Low 最低价 Float
Close 收盘价 Float
Volume 成交量 Integer
Amount 成交额 Float
Turnover 换手率 Float
Precision 价格精度 Integer
⚠️
使用注意

交易所API通常需要通过券商或数据服务商接入。 Level-2数据需要付费订阅。注意数据延迟和更新频率， 高频交易需要低延迟的数据源。
