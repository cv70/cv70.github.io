12.4 package.json 详解

项目配置文件完全指南

🎯 学习目标

  • 理解 package.json 的作用
  • 掌握常用配置字段
  • 学会依赖版本管理
  • 了解脚本配置

📚 基本结构

{ "name": "my-project", // 项目名称（必填） "version": "1.0.0", // 版本号（必填） "description": "项目描述", // 描述信息 "main": "index.js", // 入口文件 "scripts": {}, // 脚本命令 "keywords": ["node", "js"], // 关键词 "author": "Your Name", // 作者 "license": "MIT", // 许可证 "repository": { // 仓库地址 "type": "git", "url": "https://github.com/user/repo.git" }, "bugs": { // 问题反馈 "url": "https://github.com/user/repo/issues" }, "homepage": "https://github.com/user/repo#readme" }

🔧 依赖管理

{ "dependencies": { // 生产环境依赖 "express": "^4.18.2", // 兼容版本 "lodash": "~4.17.21", // 补丁版本 "mongoose": "7.5.0", // 精确版本 "config": ">=1.0.0 <2.0.0" // 范围版本 }, "devDependencies": { // 开发环境依赖 "nodemon": "^3.0.1", "jest": "^29.7.0", "eslint": "^8.50.0", "typescript": "^5.2.2" }, "peerDependencies": { // 对等依赖（插件需要） "react": ">=16.8.0" }, "optionalDependencies": { // 可选依赖（安装失败不影响） "fsevents": "^2.3.2" }, "bundleDependencies": [ // 打包依赖 "my-private-module" ] }
💡
版本符号说明

^ 兼容次版本（^1.2.3 -> >=1.2.3 <2.0.0）

~ 兼容补丁版本（~1.2.3 -> >=1.2.3 <1.3.0）

⚙️ 脚本配置

{ "scripts": { "start": "node index.js", "dev": "nodemon index.js", "test": "jest", "test:watch": "jest --watch", "test:coverage": "jest --coverage", "build": "tsc", "build:prod": "NODE_ENV=production tsc", "lint": "eslint src/**/*.ts", "lint:fix": "eslint src/**/*.ts --fix", "format": "prettier --write .", "clean": "rm -rf dist", "prestart": "npm run build", // start 前自动执行 "postinstall": "node scripts/setup.js" // install 后自动执行 } } // 运行脚本 // npm run dev // npm start (特殊：可省略 run) // npm test (特殊：可省略 run)

📦 其他重要字段

{ // 模块类型 "type": "module", // 或 "commonjs" // 入口文件 "main": "dist/index.js", "module": "dist/index.esm.js", // ESM 入口 "browser": "dist/index.umd.js", // 浏览器入口 // TypeScript 类型定义 "types": "dist/index.d.ts", "typings": "dist/index.d.ts", // 导出配置（现代方式） "exports": { ".": { "import": "./dist/index.esm.js", "require": "./dist/index.js", "types": "./dist/index.d.ts" }, "./utils": "./dist/utils.js" }, // Node.js 版本要求 "engines": { "node": ">=18.0.0", "npm": ">=9.0.0" }, // 操作系统 "os": ["linux", "darwin"], "cpu": ["x64", "arm64"], // 二进制文件 "bin": { "my-cli": "./bin/cli.js" }, // 发布配置 "files": [ "dist", "README.md", "LICENSE" ], // 私有项目 "private": true }

📝 本节小结

✅
  • • name 和 version 是必填字段
  • • dependencies 是生产依赖，devDependencies 是开发依赖
  • • ^ 兼容次版本，~ 兼容补丁版本
  • • scripts 定义 npm run 可执行的命令
