81.5 组件通信

Vue 组件间的数据传递方式

📖 本节概述

在 Vue 应用中，组件之间的通信是一个核心话题。本节将介绍各种组件通信方式，包括父子组件通信、跨层级通信、以及使用状态管理工具。

🎯 学习目标

  • 掌握父子组件通信的基本方式
  • 学会使用 provide/inject 跨层级通信
  • 了解 ref 模板引用的使用
  • 掌握组件通信的最佳实践

📊 组件通信方式概览

通信方式 方向 适用场景
Props 父 -> 子 传递数据到子组件
Events (emit) 子 -> 父 子组件通知父组件
v-model 双向 表单双向绑定
provide/inject 跨层级 深层嵌套组件通信
ref 模板引用 父 -> 子 直接访问子组件
Event Bus 任意组件 非父子组件通信
状态管理 (Pinia) 全局 复杂应用状态共享

👨‍👦 父子组件通信

Props（父传子）

<!-- 父组件 --> <template> <ChildComponent :message="parentMessage" :count="10" /> </template> <script setup lang="ts"> import { ref } from 'vue'; import ChildComponent from './ChildComponent.vue'; const parentMessage = ref('Hello from parent'); </script> <!-- 子组件 --> <script setup lang="ts"> const props = defineProps<{ message: string; count: number; }>(); console.log(props.message); // 'Hello from parent' </script>

Events（子传父）

<!-- 子组件 --> <template> <button @click="handleClick">发送消息</button> </template> <script setup lang="ts"> const emit = defineEmits<{ (e: 'message', text: string): void; (e: 'update', data: { id: number; name: string }): void; }>(); function handleClick() { emit('message', 'Hello from child'); } </script> <!-- 父组件 --> <template> <ChildComponent @message="handleMessage" /> </template> <script setup lang="ts"> function handleMessage(text: string) { console.log(text); // 'Hello from child' } </script>

🔄 v-model 双向绑定

<!-- 自定义输入组件 --> <template> <input :value="modelValue" @input="$emit('update:modelValue', ($event.target as HTMLInputElement).value)" /> </template> <script setup lang="ts"> defineProps<{ modelValue: string }>(); defineEmits<{ (e: 'update:modelValue', value: string): void; }>(); </script> <!-- 父组件 --> <template> <CustomInput v-model="inputValue" /> </template> <!-- 多个 v-model --> <template> <UserForm v-model:username="username" v-model:email="email" /> </template> <!-- UserForm.vue --> <script setup lang="ts"> defineProps<{ username: string; email: string; }>(); defineEmits<{ (e: 'update:username', value: string): void; (e: 'update:email', value: string): void; }>(); </script>

📤 provide/inject 跨层级通信

基本用法

// 祖先组件 <script setup lang="ts"> import { provide, ref, readonly } from 'vue'; const theme = ref('dark'); const user = ref({ name: 'John' }); // 提供数据 provide('theme', readonly(theme)); provide('user', user); // 提供方法来修改数据 provide('updateTheme', (newTheme: string) => { theme.value = newTheme; }); </script> // 后代组件（任意层级） <script setup lang="ts"> import { inject } from 'vue'; // 注入数据 const theme = inject<string>('theme'); const user = inject<{ name: string }>('user'); const updateTheme = inject<(theme: string) => void>('updateTheme'); // 带默认值 const locale = inject('locale', 'zh-CN'); </script>

使用 Symbol 作为 key

// keys.ts - 导出 Symbol export const ThemeKey = Symbol('theme'); export const UserKey = Symbol('user'); // 祖先组件 import { ThemeKey, UserKey } from './keys'; provide(ThemeKey, theme); // 后代组件 const theme = inject(ThemeKey);

🔍 ref 模板引用

访问子组件

<!-- 父组件 --> <template> <ChildComponent ref="childRef" /> <button @click="callChildMethod">调用子组件方法</button> </template> <script setup lang="ts"> import { ref } from 'vue'; import ChildComponent from './ChildComponent.vue'; const childRef = ref<InstanceType<typeof ChildComponent> | null>(null); function callChildMethod() { childRef.value?.doSomething(); } </script> <!-- 子组件 --> <script setup lang="ts"> import { ref } from 'vue'; const count = ref(0); function doSomething() { count.value++; console.log('Method called'); } // 使用 defineExpose 暴露给父组件 defineExpose({ doSomething, count }); </script>

访问 DOM 元素

<template> <input ref="inputRef" /> <button @click="focusInput">Focus</button> </template> <script setup lang="ts"> import { ref } from 'vue'; const inputRef = ref<HTMLInputElement | null>(null); function focusInput() { inputRef.value?.focus(); } </script>

🚌 Event Bus

对于非父子关系的组件通信，可以使用事件总线模式。

// eventBus.ts import { ref } from 'vue'; type EventHandler = (...args: any[]) => void; class EventBus { private events = new Map<string, Set<EventHandler>>(); on(event: string, handler: EventHandler) { if (!this.events.has(event)) { this.events.set(event, new Set()); } this.events.get(event)!.add(handler); } off(event: string, handler: EventHandler) { this.events.get(event)?.delete(handler); } emit(event: string, ...args: any[]) { this.events.get(event)?.forEach(handler => handler(...args)); } } export const eventBus = new EventBus(); // 组件 A - 发送事件 import { eventBus } from './eventBus'; eventBus.emit('user-updated', { id: 1, name: 'John' }); // 组件 B - 监听事件 import { onUnmounted } from 'vue'; import { eventBus } from './eventBus'; const handleUserUpdate = (user: any) => { console.log('User updated:', user); }; eventBus.on('user-updated', handleUserUpdate); onUnmounted(() => { eventBus.off('user-updated', handleUserUpdate); });

📝 本节小结

  • Props 用于父传子，Events 用于子传父
  • v-model 实现双向绑定
  • provide/inject 用于跨层级通信
  • ref 模板引用可访问子组件实例和 DOM
  • 复杂应用推荐使用 Pinia 状态管理
