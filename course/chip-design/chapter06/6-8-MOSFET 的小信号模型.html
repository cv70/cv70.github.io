6.8 MOSFET 的小信号模型

小信号参数，等效电路

🎯 学习目标

  • 理解小信号模型的概念与适用条件
  • 掌握主要小信号参数的计算方法
  • 理解 MOSFET 小信号等效电路
  • 学会使用小信号模型分析放大器

什么是小信号模型

小信号模型是一种线性化的分析方法，用于分析电路对交流小信号的响应。在大信号直流工作点附近，将非线性器件用线性等效电路代替，从而应用线性电路理论进行分析。

小信号模型是模拟电路设计的基础工具，广泛用于放大器增益、输入/输出阻抗、频率响应等分析。

💡 小信号模型基础

适用条件

小信号条件：

  • 交流信号幅度足够小，使器件特性可近似为线性
  • 信号频率在器件工作频率范围内
  • 器件工作在稳定的直流工作点附近

通常要求：信号幅度 < VOV/10 或更小

直流工作点与交流分析

直流分析（大信号）
  • 确定静态工作点（Q点）
  • 计算 ID、VGS、VDS 等直流值
  • 确保器件工作在正确区域
交流分析（小信号）
  • 在工作点附近线性化
  • 用小信号模型替代器件
  • 计算增益、阻抗、频率响应

📐 主要小信号参数

1. 跨导 gm（Transconductance）

📐

定义：漏极电流对栅源电压的变化率

gm = ∂ID / ∂VGS | VDS = 常数

在饱和区的表达式：

gm = μnCox(W/L)(VGS - Vth) = √(2μnCox(W/L)ID)

设计启示：

  • 增大 W/L 可增加 gm
  • 增大偏置电流可增加 gm
  • gm 决定电压增益：Av = gm · Rout

2. 输出电阻 ro（Output Resistance）

📐

定义：漏源电压对漏极电流的变化率

ro = ∂VDS / ∂ID | VGS = 常数

表达式：

ro = VA / ID = 1 / (λID)

其中 VA 是厄利电压，λ 是沟道长度调制系数

典型值：ro ≈ 1-100 kΩ（取决于 L 和 ID）

3. 体效应跨导 gmb（Body Transconductance）

📐

定义：漏极电流对源-衬底电压的变化率

gmb = ∂ID / ∂VSB

与 gm 的关系：

gmb = η · gm

其中 η = gmb/gm，典型值 0.1-0.3

体效应在某些电路中不可忽略（如源极跟随器）

4. 栅源电容 Cgs

来源：

  • 栅极与沟道之间的氧化层电容
  • 栅极与源区重叠电容

饱和区近似：

Cgs ≈ (2/3)WLCoX + Cov

其中 Cov 是重叠电容

5. 栅漏电容 Cgd

来源：栅极与漏区重叠电容

Cgd ≈ Cov

在饱和区，Cgd 较小（沟道夹断）

但在高频分析中不可忽略（密勒效应）

📊 小信号等效电路

低频小信号模型

在低频时，忽略电容效应，MOSFET 可简化为：

  • • 输入端：栅极开路（输入阻抗无穷大）
  • • 输出端：受控电流源 gm·vgs 与输出电阻 ro 并联
  • • 体效应：可选的 gmb·vsb 受控源

高频小信号模型

在高频时，需要考虑各端之间的电容：

主要电容：

  • Cgs：栅-源电容（最大，影响输入阻抗）
  • Cgd：栅-漏电容（密勒效应倍增）
  • Cdb：漏-衬底结电容
  • Csb：源-衬底结电容

模型结构：

  • 在低频模型基础上添加各电容
  • Cgs 连接栅极与源极
  • Cgd 连接栅极与漏极
  • Cdb、Csb 连接相应端与衬底

完整小信号模型参数汇总

参数 符号 表达式 典型值
跨导 gm √(2μCox·W/L·ID) 0.1-10 mS
输出电阻 ro VA/ID 1-100 kΩ
体跨导 gmb η·gm 0.1-0.3 gm
栅源电容 Cgs (2/3)WLCox 10-100 fF
栅漏电容 Cgd W·Cov 1-10 fF
漏衬底电容 Cdb 结电容 1-20 fF

🔧 小信号模型的应用

共源极放大器分析

电压增益：

Av = -gm · (ro || RD || RL)

其中 RD 是漏极电阻，RL 是负载电阻

输入阻抗：Zin ≈ ∞（低频时）

输出阻抗：Zout = ro || RD

源极跟随器分析

电压增益：

Av = gmRS / (1 + (gm + gmb)RS)

增益接近 1（电压跟随）

输出阻抗：

Zout = 1 / (gm + gmb)

输出阻抗很低，适合驱动低阻抗负载

⚠️
小信号模型的局限性

线性假设：仅适用于小信号，大信号需用大信号模型。

频率限制：低频模型忽略电容，高频需用完整模型。

参数依赖：所有参数依赖于直流工作点，工作点变化时参数需重新计算。

高频效应：极高频率时需考虑更多寄生效应。

📝 本节小结

✅
  • • 小信号模型在工作点附近线性化，用于交流分析
  • • 跨导 gm = ∂ID/∂VGS，是增益的决定因素
  • • 输出电阻 ro = VA/ID，影响增益和阻抗
  • • 低频模型：电流源 + 电阻；高频模型需加电容
  • • 所有参数依赖于直流工作点，设计时需先确定偏置
