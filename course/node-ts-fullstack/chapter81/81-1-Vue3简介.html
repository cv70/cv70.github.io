81.1 Vue 3 简介

渐进式 JavaScript 框架的新时代

📖 本节概述

Vue 3 是 Vue.js 的最新主版本，它带来了全新的组合式 API、更好的 TypeScript 支持、更快的渲染性能和更小的打包体积。本节将介绍 Vue 3 的核心概念、特点以及与 Vue 2 的主要区别。

🎯 学习目标

  • 了解 Vue 3 的新特性和改进
  • 理解 Vue 3 与 Vue 2 的主要区别
  • 掌握 Vue 3 项目的创建方式
  • 熟悉 Vue 3 的核心概念

🚀 Vue 3 新特性

性能提升

// Vue 3 性能优化包括： // 1. 虚拟 DOM 重写 - 更高效的 diff 算法 // 2. 静态提升 - 静态节点只创建一次 // 3. 事件监听缓存 - 事件处理函数缓存 // 4. Tree-shaking 支持 - 更小的打包体积 // 静态提升示例 // Vue 2：每次渲染都会创建 VNode const vnode1 = createElement('div', { class: 'static' }, 'Hello'); // Vue 3：静态节点只创建一次 const hoisted = createElementVNode('div', { class: 'static' }, 'Hello'); // 渲染时直接使用 hoisted

组合式 API

Vue 3 引入了组合式 API，提供更灵活的代码组织方式。

// 选项式 API (Vue 2 风格) export default { data() { return { count: 0, name: '' }; }, computed: { doubleCount() { return this.count * 2; } }, methods: { increment() { this.count++; } } }; // 组合式 API (Vue 3) import { ref, computed } from 'vue'; export default { setup() { const count = ref(0); const name = ref(''); const doubleCount = computed(() => count.value * 2); function increment() { count.value++; } return { count, name, doubleCount, increment }; } };

📊 Vue 3 vs Vue 2

特性 Vue 2 Vue 3
API 风格 选项式 API 选项式 + 组合式 API
TypeScript 支持 有限支持 原生支持
响应式原理 Object.defineProperty Proxy
生命周期 beforeCreate, created... setup, onMounted...
Fragment 不支持 支持多根节点
Teleport 不支持 支持传送组件
Suspense 不支持 支持异步组件加载
打包体积 约 23KB 约 10KB (Tree-shakable)

📦 创建 Vue 3 项目

使用 Vite（推荐）

# 创建项目 npm create vue@latest my-app # 或使用 yarn yarn create vue my-app # 进入项目并安装依赖 cd my-app npm install # 启动开发服务器 npm run dev

使用 Vue CLI

# 安装 Vue CLI npm install -g @vue/cli # 创建项目 vue create my-app # 选择 Vue 3 预设或手动配置

项目结构

my-app/ ├── node_modules/ ├── public/ │ └── favicon.ico ├── src/ │ ├── assets/ │ ├── components/ │ ├── App.vue │ └── main.ts ├── index.html ├── package.json ├── tsconfig.json └── vite.config.ts

🔧 Vue 3 应用入口

// main.ts import { createApp } from 'vue'; import App from './App.vue'; import router from './router'; import { createPinia } from 'pinia'; // 创建应用实例 const app = createApp(App); // 使用插件 app.use(router); app.use(createPinia()); // 挂载应用 app.mount('#app'); // Vue 2 对比 // new Vue({ // router, // store, // render: h => h(App) // }).$mount('#app');

📝 单文件组件 (SFC)

<!-- App.vue --> <template> <div class="app"> <h1>{{ message }}</h1> <button @click="increment"> Count: {{ count }} </button> </div> </template> <script setup lang="ts"> import { ref } from 'vue'; // 响应式数据 const message = ref('Hello Vue 3!'); const count = ref(0); // 方法 function increment() { count.value++; } </script> <style scoped> .app { padding: 20px; } h1 { color: #42b883; } </style>
💡
script setup 语法糖

<script setup> 是 Vue 3 的编译时语法糖，它简化了组合式 API 的使用，自动暴露变量到模板，无需显式 return。

🌟 Vue 3 核心概念

响应式系统

import { ref, reactive, computed, watch } from 'vue'; // ref - 用于基本类型 const count = ref(0); console.log(count.value); // 需要用 .value 访问 // reactive - 用于对象 const state = reactive({ name: 'Vue', version: 3 }); console.log(state.name); // 直接访问 // computed - 计算属性 const double = computed(() => count.value * 2); // watch - 监听变化 watch(count, (newVal, oldVal) => { console.log(`count changed: ${oldVal} -> ${newVal}`); });

生命周期钩子

import { onBeforeMount, onMounted, onBeforeUpdate, onUpdated, onBeforeUnmount, onUnmounted } from 'vue'; export default { setup() { onMounted(() => { console.log('组件已挂载'); }); onUnmounted(() => { console.log('组件已卸载'); }); } }

  • Vue 3 带来性能提升、更小的打包体积
  • 组合式 API 提供更灵活的代码组织方式
