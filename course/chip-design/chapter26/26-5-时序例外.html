26.5 时序例外

高级时序例外约束技巧

🎯 学习目标

  • 掌握路径延迟约束的方法
  • 了解最大/最小延迟约束
  • 学会处理复杂的时序关系
  • 理解时序例外的组合使用

⏱️ 路径延迟约束

set_max_delay / set_min_delay

# 设置最大路径延迟 set_max_delay 5.0 -from [get_ports data_in] \ -to [get_ports data_out] # 设置最小路径延迟 set_min_delay 1.0 -from [get_ports data_in] \ -to [get_ports data_out] # 通过特定网络 set_max_delay 3.0 -through [get_nets critical_path*] # 针对特定单元 set_max_delay 2.5 -from [get_cells source_reg/Q] \ -to [get_cells dest_reg/D]

异步路径约束

# 异步复位路径 set_max_delay 10.0 -from [get_ports async_rst] \ -to [get_cells reset_reg*/R] # 中断信号路径 set_max_delay 5.0 -from [get_ports interrupt] \ -to [get_cells interrupt_handler/D]

⚡ 数据检查约束

set_data_check

# 数据到使能的检查 set_data_check -from [get_pins data_reg/Q] \ -to [get_pins enable_reg/D] \ -setup 1.0 -hold 0.2 # 地址到数据的检查 set_data_check -from [get_pins addr_reg/Q] \ -to [get_pins data_in_reg/D] \ -setup 2.0

🔄 组合时序例外

路径组合

# From-To组合 set_false_path \ -from [get_cells {reg1 reg2 reg3}] \ -to [get_cells {regA regB regC}] # Through组合 set_multicycle_path -setup 2 \ -through [get_cells stage1 stage2 stage3] # 组合多种条件 set_false_path \ -from [get_clocks CLK1] \ -to [get_clocks CLK2] \ -through [get_cells async_bridge*]

📊 复杂时序例外场景

# ============================================================================ # 复杂时序例外示例 # ============================================================================ # ========== 跨时钟域处理 ========== # 快到慢时钟域（2个同步器） set_multicycle_path -setup 2 \ -from [get_clocks FAST_CLK] \ -to [get_clocks SLOW_CLK] \ -through [get_cells sync_stage2] # 慢到快时钟域 set_false_path -from [get_clocks SLOW_CLK] \ -to [get_clocks FAST_CLK] # ========== 异步控制 ========== # 复位传播 set_max_delay 8.0 -from [get_ports reset_n] \ -to [all_registers] # 时钟使能 set_false_path -from [get_ports clock_en] \ -to [get_pins -filter "name =~ */E"] # ========== 特殊功能模块 ========== # 错误检测路径 set_max_delay 15.0 -from [get_ports error_in] \ -to [get_cells error_handler*/D] # 看门狗定时器 set_false_path -from [get_ports watchdog_feed] \ -to [get_cells watchdog_counter*/D] # 调试逻辑 set_false_path -from [get_ports debug_mode] \ -through [get_cells debug_logic*]

📝 时序例外管理

查询时序例外

# 报告所有虚假路径 report_exceptions -false_path # 报告所有多周期路径 report_exceptions -multicycle # 报告特定路径的例外 report_exceptions -from [get_cells reg1]

时序例外文档

  • 为每个时序例外添加注释说明
  • 在设计文档中记录例外原因
  • 定期审查和更新时序例外
  • 验证时序例外的正确性
⚠️
时序例外风险

不当使用时序例外可能导致：1）掩盖真实的时序问题；2）产生功能故障； 3）降低设计可靠性；4）增加调试难度。每个时序例外都需要充分的设计依据。
