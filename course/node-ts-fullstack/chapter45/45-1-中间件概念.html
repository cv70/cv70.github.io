45.1 中间件概念

理解 NestJS 中间件的执行机制

🎯 学习目标

  • 理解中间件的作用和执行时机
  • 掌握中间件的特点
  • 了解中间件与其他组件的区别
  • 理解中间件的应用场景

📚 什么是中间件？

中间件是在路由处理程序之前调用的函数，可以访问请求对象和响应对象，以及下一个中间件函数。

// 中间件执行流程 客户端请求 ↓ ┌─────────────────┐ │ 中间件 1 │ ← 可以修改请求/响应 └─────────────────┘ ↓ next() ┌─────────────────┐ │ 中间件 2 │ ← 可以终止请求 └─────────────────┘ ↓ next() ┌─────────────────┐ │ 路由处理器 │ ← 控制器方法 └─────────────────┘ ↓ 响应客户端
💡
中间件特点

中间件可以执行任何代码、修改请求响应对象、结束请求-响应周期、调用下一个中间件。如果不调用 next()，请求将被终止。

🔧 中间件接口

import { Injectable, NestMiddleware } from '@nestjs/common'; import { Request, Response, NextFunction } from 'express'; @Injectable() export class LoggerMiddleware implements NestMiddleware { use(req: Request, res: Response, next: NextFunction) { console.log(`[${new Date().toISOString()}] ${req.method} ${req.url}`); // 继续下一个中间件或路由处理器 next(); // next() 之后的代码在响应发送后执行 console.log(`Response sent: ${res.statusCode}`); } }

🔄 中间件 vs 其他组件

组件 执行时机 主要用途
中间件 路由处理前 日志、认证、请求预处理
守卫 中间件后 权限验证
拦截器 守卫后/响应前 响应转换、日志
管道 路由参数处理 数据验证、转换
过滤器 异常时 异常处理

✨ 应用场景

  • 请求日志记录
  • 请求体解析
  • CORS 处理
  • 请求限流
  • 请求计时
  • 请求 ID 生成
  • 认证前置处理
⚠️
中间件限制

中间件不能使用依赖注入来访问模块中的 Provider（除了在模块构造函数中注入）。如需访问数据库或其他服务，考虑使用守卫或拦截器。

📝 本节小结

✅
  • • 中间件在路由处理器前执行
  • • 可以访问和修改请求/响应对象
  • • next() 调用下一个中间件
  • • 常用于日志、认证预处理等
