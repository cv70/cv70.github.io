60.4 联合类型

GraphQL 联合类型详解

📖 联合类型概述

联合类型（Union Type）表示可以是多种类型之一的值。与接口不同，联合类型中的成员类型不需要共享字段。

💡
联合类型 vs 接口
  • 接口：成员类型必须共享字段
  • 联合：成员类型可以完全不同
  • 两者可以结合使用

📝 定义联合类型

// 定义对象类型 type User { id: ID! name: String! email: String! } type Post { id: ID! title: String! content: String author: User! } type Comment { id: ID! content: String! author: User! } type Tag { id: ID! name: String! slug: String! } // 定义联合类型 union SearchResult = User | Post | Comment union MediaContent = Image | Video | Audio union TimelineItem = Post | Photo | CheckIn | Event // 联合类型作为返回类型 type Query { search(query: String!): [SearchResult!]! getMedia(id: ID!): MediaContent timeline(userId: ID!): [TimelineItem!]! }

🔍 查询联合类型

由于联合类型的成员没有共同字段，必须使用内联片段来查询。

// 搜索查询 query Search($query: String!) { search(query: $query) { ... on User { id name email avatar } ... on Post { id title excerpt author { name } } ... on Comment { id content author { name } } } } // 响应示例 { "data": { "search": [ { "id": "user-1", "name": "张三", "email": "zhang@example.com", "avatar": "https://..." }, { "id": "post-1", "title": "GraphQL 入门", "excerpt": "...", "author": { "name": "李四" } }, { "id": "comment-1", "content": "很棒的文章！", "author": { "name": "王五" } } ] } }

🔄 解析联合类型

const resolvers = { // 联合类型解析器 SearchResult: { __resolveType(obj: any, context: any, info: any) { // 根据对象属性判断类型 if (obj.email) { return 'User'; } if (obj.title) { return 'Post'; } if (obj.content && !obj.title) { return 'Comment'; } return null; // 或抛出错误 }, }, MediaContent: { __resolveType(obj: any) { // 根据类型字段判断 switch (obj.type) { case 'image': return 'Image'; case 'video': return 'Video'; case 'audio': return 'Audio'; default: return null; } }, }, Query: { search: async (_: any, { query }: { query: string }, context) => { // 返回混合类型的数组 const results = await context.dataSources.searchApi.search(query); return results; }, }, };

🔀 联合类型与接口结合

// 定义接口 interface Node { id: ID! } interface Media { url: String! type: MediaType! } // 实现接口的对象类型 type Image implements Node & Media { id: ID! url: String! type: MediaType! width: Int! height: Int! } type Video implements Node & Media { id: ID! url: String! type: MediaType! duration: Int! thumbnail: String } type Audio implements Node & Media { id: ID! url: String! type: MediaType! duration: Int! artist: String } // 联合类型 union MediaContent = Image | Video | Audio // 查询时可以先查询接口字段 query GetMedia($id: ID!) { getMedia(id: $id) { // 接口共享字段可以直接查询 ... on Node { id } ... on Media { url type } // 具体类型字段 ... on Image { width height } ... on Video { duration thumbnail } ... on Audio { duration artist } } }

🎯 实战案例

搜索结果联合类型

union SearchResult = UserResult | PostResult | TagResult | Error type UserResult { user: User! score: Float! } type PostResult { post: Post! score: Float! highlights: [String!]! } type TagResult { tag: Tag! postCount: Int! } type Error { message: String! code: String! } type Query { search(query: String!, types: [SearchType!]): [SearchResult!]! } enum SearchType { USER POST TAG } // Resolver const resolvers = { SearchResult: { __resolveType(obj: any) { if (obj.user) return 'UserResult'; if (obj.post) return 'PostResult'; if (obj.tag) return 'TagResult'; if (obj.message) return 'Error'; return null; }, }, };

Mutation 结果联合类型

union CreateUserResult = UserCreated | ValidationError | PermissionDenied type UserCreated { user: User! token: String! } type ValidationError { field: String! message: String! } type PermissionDenied { reason: String! requiredRole: UserRole! } type Mutation { createUser(input: CreateUserInput!): CreateUserResult! } // 查询 mutation CreateUser($input: CreateUserInput!) { createUser(input: $input) { ... on UserCreated { user { id name email } token } ... on ValidationError { field message } ... on PermissionDenied { reason requiredRole } } }

📊 最佳实践

场景 推荐类型 原因
共享字段的多态 接口 有共同字段可复用
完全不同的类型 联合类型 无共同字段
搜索结果 联合类型 结果类型各异
Mutation 结果 联合类型 成功/失败返回不同结构

📝 小结

  • 联合类型表示可以是多种类型之一
  • 成员类型不需要共享字段
  • 查询时必须使用内联片段
  • 使用 __resolveType 解析具体类型
  • 可以与接口结合使用
  • 适用于搜索结果、Mutation 结果等场景
