无监督学习算法回顾

无监督学习不需要标签数据，能够从数据中发现隐藏的模式和结构。 在量化交易中，无监督学习可用于市场划分、因子发现、风险异常检测等多个领域。

🔬 核心算法详解

1. K-Means聚类

基于距离的聚类算法，通过迭代优化簇中心实现样本分组。

应用场景：

  • 股票风格划分
  • 市场状态识别
  • 因子相关性分组

2. 层次聚类

通过构建层次树状结构进行聚类，不需要预先指定聚类数量。

应用场景：

  • 行业分类
  • 资产配置分组
  • 风险因子识别

3. DBSCAN

基于密度的聚类算法，能发现任意形状的簇并识别噪声点。

应用场景：

  • 异常交易检测
  • 流动性异常识别
  • 市场异常分析

4. 主成分分析（PCA）

线性降维方法，通过正交变换提取数据的主要成分。

应用场景：

  • 因子降维
  • 风险因子提取
  • 数据压缩

5. t-SNE

非线性降维方法，适用于高维数据可视化。

应用场景：

  • 股票聚类可视化
  • 因子关系探索
  • 市场结构分析

6. UMAP

高效的非线性降维方法，保留了更多的局部和全局结构。

应用场景：

  • 大规模数据可视化
  • 特征工程
  • 模式发现

7. Isolation Forest

基于孤立树的异常检测算法，效率高适用于大数据。

应用场景：

  • 欺诈交易检测
  • 市场异常监控
  • 异常价格识别

8. 自编码器

神经网络实现的降维和异常检测方法，能学习复杂的数据表示。

应用场景：

  • 非线性特征提取
  • 数据生成
  • 异常检测

💻 代码示例

import numpy as np
import pandas as pd
from sklearn.cluster import KMeans, DBSCAN, AgglomerativeClustering
from sklearn.decomposition import PCA
from sklearn.manifold import TSNE
from sklearn.ensemble import IsolationForest
from sklearn.preprocessing import StandardScaler
import matplotlib.pyplot as plt

# 1. K-Means聚类 - 股票风格划分
def kmeans_clustering(data, n_clusters=5):
    """使用K-Means进行股票聚类"""
    scaler = StandardScaler()
    data_scaled = scaler.fit_transform(data)

    kmeans = KMeans(n_clusters=n_clusters, random_state=42)
    clusters = kmeans.fit_predict(data_scaled)

    results = pd.DataFrame({
        'cluster': clusters,
        'center_distance': kmeans.transform(data_scaled).min(axis=1)
    })
    return kmeans, results

# 2. DBSCAN - 异常检测
def dbscan_anomaly_detection(data, eps=0.5, min_samples=5):
    """使用DBSCAN检测异常点"""
    scaler = StandardScaler()
    data_scaled = scaler.fit_transform(data)

    dbscan = DBSCAN(eps=eps, min_samples=min_samples)
    clusters = dbscan.fit_predict(data_scaled)

    # -1表示异常点
    anomalies = data[clusters == -1]
    normal = data[clusters != -1]

    return dbscan, anomalies, normal

# 3. PCA - 因子降维
def pca_dimensionality_reduction(data, n_components=0.95):
    """使用PCA进行降维"""
    scaler = StandardScaler()
    data_scaled = scaler.fit_transform(data)

    pca = PCA(n_components=n_components)
    data_pca = pca.fit_transform(data_scaled)

    explained_variance = pca.explained_variance_ratio_
    cumulative_variance = np.cumsum(explained_variance)

    results = {
        'transformed_data': data_pca,
        'explained_variance': explained_variance,
        'cumulative_variance': cumulative_variance,
        'feature_importance': pca.components_
    }
    return pca, results

# 4. t-SNE - 可视化
def tsne_visualization(data, n_components=2, perplexity=30):
    """使用t-SNE进行降维可视化"""
    scaler = StandardScaler()
    data_scaled = scaler.fit_transform(data)

    tsne = TSNE(n_components=n_components,
                perplexity=perplexity,
                random_state=42)
    data_tsne = tsne.fit_transform(data_scaled)

    return tsne, data_tsne

# 5. Isolation Forest - 异常检测
def isolation_forest_detection(data, contamination=0.05):
    """使用孤立森林检测异常"""
    scaler = StandardScaler()
    data_scaled = scaler.fit_transform(data)

    iso_forest = IsolationForest(contamination=contamination,
                                   random_state=42)
    predictions = iso_forest.fit_predict(data_scaled)
    scores = iso_forest.score_samples(data_scaled)

    anomalies = data[predictions == -1]

    return iso_forest, anomalies, scores

# 6. 市场状态识别
def identify_market_state(data, n_clusters=4):
    """识别不同市场状态"""
    # 使用多个特征：波动率、成交量、收益率等
    features = ['volatility', 'volume', 'returns', 'trend']

    scaler = StandardScaler()
    data_scaled = scaler.fit_transform(data[features])

    kmeans = KMeans(n_clusters=n_clusters, random_state=42)
    states = kmeans.fit_predict(data_scaled)

    # 分析各状态特征
    data['market_state'] = states
    state_stats = data.groupby('market_state').mean()

    return kmeans, data, state_stats

# 7. 因子相关性分析
def factor_correlation_clustering(factors):
    """对因子进行相关性聚类"""
    # 计算因子相关性矩阵
    corr_matrix = factors.corr()

    # 将相关性转换为距离
    distance_matrix = 1 - np.abs(corr_matrix)

    # 使用层次聚类
    clustering = AgglomerativeClustering(
        n_clusters=None,
        affinity='precomputed',
        linkage='average',
        distance_threshold=0.5
    )

    cluster_labels = clustering.fit_predict(distance_matrix)

    return clustering, cluster_labels, distance_matrix

# 8. 主成分风险模型
def pca_risk_model(returns, n_components=10):
    """构建PCA风险模型"""
    scaler = StandardScaler()
    returns_scaled = scaler.fit_transform(returns.T)

    pca = PCA(n_components=n_components)
    pca.fit(returns_scaled)

    # 获取主成分
    components = pca.components_
    explained_var = pca.explained_variance_ratio_

    # 特定风险
    specific_risk = np.var(returns - pca.transform(returns_scaled) @ components.T, axis=1)

    return pca, components, explained_var, specific_risk

📚 量化交易应用案例

案例1：股票聚类分析

使用K-Means对股票进行风格聚类，识别具有相似特征的股票组合。

  • 特征：市值、估值、动量、波动率等
  • 应用：行业轮动、配对交易、投资组合构建

案例2：风险因子提取

使用PCA从股票收益率中提取主要风险因子。

  • 输入：多只股票的历史收益率
  • 输出：前几个主成分作为风险因子
  • 应用：风险归因、组合优化

案例3：异常交易检测

使用Isolation Forest检测异常交易行为。

  • 特征：交易量、价格变动、订单类型等
  • 应用：合规监控、风险预警

案例4：市场状态识别

结合聚类和降维方法识别不同的市场状态。

  • 特征：波动率、流动性、相关性等
  • 应用：策略切换、风险调整
⚠️
注意事项

1. 无监督学习结果需要领域知识解读
2. 金融数据的非平稳性影响聚类稳定性
3. 需要进行充分的数据预处理
4. 异常检测阈值需要仔细调优

✨
最佳实践

无监督学习特别适合探索性分析和特征工程。建议先使用无监督方法理解数据结构， 再结合监督学习构建预测模型。聚类结果可以用于构建新的分组特征。
