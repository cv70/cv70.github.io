generate 语句概述

generate 语句是 Verilog-2001 引入的强大特性，允许在编译时根据参数条件生成不同的硬件结构。与普通的过程语句不同，generate 语句在编译阶段执行，用于创建可参数化的硬件模块实例。

💡 generate-for 循环生成

generate-for 用于批量生成相同结构的模块或电路单元。

// 生成 N 位寄存器 module register_array #( parameter WIDTH = 8, parameter DEPTH = 4 )( input wire clk, input wire rst_n, input wire [WIDTH-1:0] din [0:DEPTH-1], output reg [WIDTH-1:0] dout [0:DEPTH-1] ); genvar i; generate for (i = 0; i < DEPTH; i = i + 1) begin : gen_reg always @(posedge clk or negedge rst_n) begin if (!rst_n) dout[i] <= 0; else dout[i] <= din[i]; end end endgenerate endmodule
💡
genvar 与 integer 的区别

genvar：编译时变量，只用于 generate-for 循环，在仿真中不存在。
integer：仿真时变量，用于过程块中的循环，占用仿真资源。

⚙️ generate-if 条件生成

generate-if 根据参数条件选择性地生成硬件结构。

module multiplier #( parameter WIDTH = 8, parameter IMPLEMENTATION = "CARRY" // "CARRY", "WALLACE", "DSP" )( input wire [WIDTH-1:0] a, input wire [WIDTH-1:0] b, output wire [2*WIDTH-1:0] product ); generate if (IMPLEMENTATION == "CARRY") begin : gen_carry // 使用进位传播乘法器 carry_mult #(.WIDTH(WIDTH)) u_mult (.a(a), .b(b), .product(product)); end else if (IMPLEMENTATION == "WALLACE") begin : gen_wallace // 使用 Wallace 树乘法器 wallace_mult #(.WIDTH(WIDTH)) u_mult (.a(a), .b(b), .product(product)); end else begin : gen_dsp // 使用 DSP 原语 dsp_mult #(.WIDTH(WIDTH)) u_mult (.a(a), .b(b), .product(product)); end endgenerate endmodule

📊 generate-case 选择生成

generate-case 类似于 case 语句，用于多分支条件生成。

module memory_wrapper #( parameter TYPE = "RAM" // "RAM", "ROM", "FIFO" )( input wire clk, input wire wr_en, input wire [7:0] addr, input wire [31:0] wdata, output wire [31:0] rdata ); generate case (TYPE) "RAM": begin : gen_ram ram_single_port u_mem (.clk(clk), .wr_en(wr_en), .addr(addr), .wdata(wdata), .rdata(rdata)); end "ROM": begin : gen_rom rom_async u_mem (.addr(addr), .rdata(rdata)); end "FIFO": begin : gen_fifo sync_fifo u_mem (.clk(clk), .wr_en(wr_en), .wdata(wdata), .rdata(rdata)); end default: begin : gen_default assign rdata = 32'h0; end endcase endgenerate endmodule

📝 生成块的命名

⚠️
重要提示

每个生成块都应该有唯一的名称（如 begin : block_name）。这不仅便于调试，也是某些工具正确处理生成层次结构所必需的。

📝 本节小结

✅
  • • generate-for 用于批量生成相同结构
  • • generate-if 用于条件选择生成
  • • generate-case 用于多分支条件生成
  • • 必须给生成块命名以便调试和层次化引用
