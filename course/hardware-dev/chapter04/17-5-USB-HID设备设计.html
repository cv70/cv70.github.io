USB HID概述

HID（Human Interface Device）即人机接口设备， 是USB标准中定义的一种设备类。HID设备包括键盘、鼠标、游戏杆等输入设备， 以及显示器、控制器等输出设备。HID设备无需驱动即可被操作系统识别。

报告类型 方向 说明
Input Report Device→Host 设备向Host发送数据
Output Report Host→Device Host向设备发送数据
Feature Report 双向 配置和状态信息
✨
最佳实践

HID设备设计要点：(1)使用标准HID类代码(0x03)；(2)编写正确的报告描述符； (3)自定义HID比键盘/鼠标更灵活；(4)端点0用于控制传输，端点1用于中断传输； (5)使用USB HID库简化开发。

⚠️
注意事项

HID报告描述符语法复杂，可用HID Descriptor Tool生成。 自定义HID需要在PC端编写驱动或使用库解析。 HID设备优先级较低，避免在HID端点传输大量数据。
