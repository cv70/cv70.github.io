什么是PyTorch FSDP？

FSDP（Fully Sharded Data Parallel）是PyTorch 2.0引入的全分片数据并行框架。 与DDP每个GPU存储完整模型不同，FSDP将模型参数、梯度和优化器状态全部切分到多个GPU上。 通过全分片，FSDP可以训练比DDP大得多的模型，是训练大模型的重要工具。

🏗️ FSDP核心原理

全分片机制

FSDP的三种分片： 1. 参数分片（Parameter Sharding） • 模型参数均匀分片到所有GPU • 每个GPU只存储部分参数 • 前向传播时动态收集所需的参数 2. 梯度分片（Gradient Sharding） • 反向传播时梯度也分片存储 • 每个GPU只计算和存储部分梯度 • 梯度同步后直接在各GPU上分片更新 3. 优化器状态分片（Optimizer State Sharding） • 优化器状态（如Adam的动量）也分片 • 这是显存占用的大头 • 大幅减少总显存占用 显存占用对比（假设1B参数模型）： DDP（不使用offload）： • 参数：2 GB（FP16） • 梯度：2 GB（FP16） • 优化器状态：12 GB（FP32参数+动量+方差） • 激活值：约4-8 GB • 总计：约20-24 GB FSDP（4卡）： • 每卡参数：0.5 GB（FP16/4） • 每卡梯度：0.5 GB（FP16/4） • 每卡优化器状态：3 GB（FP32/4） • 激活值：约4-8 GB（与DDP相同） • 每卡总计：约8-12 GB 节省：约50%显存！

⚙️ FSDP工作流程

前向和反向传播

前向传播（Forward Pass）： 对于每一层： 1. AllGather：收集该层的完整参数 ┌─────────────────────────────────┐ │ GPU0: [P₀] GPU1: [P₁] GPU2: [P₂] │ │ ↓ AllGather │ │ GPU0: [P₀P₁P₂] GPU1: [P₀P₁P₂] ... │ └─────────────────────────────────┘ 2. 计算该层输出（所有GPU都有完整参数） 3. Free：释放不需要的参数，保留激活值 反向传播（Backward Pass）： 对于每一层： 1. 计算梯度（基于激活值） 2. ReduceScatter：聚合梯度并分片 ┌─────────────────────────────────┐ │ GPU0: [G₀] GPU1: [G₁] GPU2: [G₂] │ │ ↓ ReduceScatter │ │ GPU0: [G₀] GPU1: [G₁] GPU2: [G₂] │ └─────────────────────────────────┘ 3. 更新参数：使用分片的梯度更新分片的参数 • 不需要AllReduce，更高效 • 每个GPU独立更新自己的参数分片 关键优化： • 自动激活值检查点 • 计算与通信重叠 • 通信原语优化（AllGather + ReduceScatter替代AllReduce）

💻 FSDP基本使用

FSDP代码示例

import torch import torch.distributed as dist import torch.multiprocessing as mp from torch.distributed.fsdp import FullyShardedDataParallel as FSDP from torch.distributed.fsdp import MixedPrecision, BackwardPrefetch from torch.distributed.fsdp.wrap import transformer_auto_wrap_policy def setup(rank, world_size): dist.init_process_group( backend='nccl', init_method='env://', world_size=world_size, rank=rank ) torch.cuda.set_device(rank) class TransformerLayer(torch.nn.Module): def __init__(self, hidden_size): super().__init__() self.attention = torch.nn.MultiheadAttention(hidden_size, num_heads=8) self.ffn = torch.nn.Sequential( torch.nn.Linear(hidden_size, hidden_size * 4), torch.nn.GELU(), torch.nn.Linear(hidden_size * 4, hidden_size) ) def forward(self, x): attn_out, _ = self.attention(x, x, x) x = x + attn_out ffn_out = self.ffn(x) return x + ffn_out class TransformerModel(torch.nn.Module): def __init__(self, hidden_size, num_layers): super().__init__() self.layers = torch.nn.ModuleList([ TransformerLayer(hidden_size) for _ in range(num_layers) ]) def forward(self, x): for layer in self.layers: x = layer(x) return x def train(rank, world_size): setup(rank, world_size) # 创建模型 model = TransformerModel(hidden_size=1024, num_layers=24) # 定义混合精度策略 mixed_precision = MixedPrecision( param_dtype=torch.float16, reduce_dtype=torch.float16, buffer_dtype=torch.float16, ) # 定义包装策略（按层包装） auto_wrap_policy = transformer_auto_wrap_policy # 用FSDP包装模型 fsdp_model = FSDP( model, sharding_strategy='FULL_SHARD', # 全分片 mixed_precision=mixed_precision, auto_wrap_policy=auto_wrap_policy, backward_prefetch=BackwardPrefetch.BACKWARD_PRE, // 预取优化 ) # 创建优化器（直接包装FSDP模型） optimizer = torch.optim.AdamW( fsdp_model.parameters(), lr=1e-4, weight_decay=0.01 ) # 训练循环 for epoch in range(100): for batch_idx, (inputs, targets) in enumerate(dataloader): inputs = inputs.cuda() targets = targets.cuda() # 前向传播 outputs = fsdp_model(inputs) loss = torch.nn.functional.cross_entropy(outputs, targets) # 反向传播 optimizer.zero_grad() loss.backward() # 更新参数 optimizer.step() if rank == 0 and batch_idx % 10 == 0: print(f'Epoch {epoch}, Loss: {loss.item()}') dist.destroy_process_group() if __name__ == '__main__': world_size = 8 mp.spawn(train, args=(world_size,), nprocs=world_size, join=True)

⚡ FSDP高级配置

分片策略

策略 说明 显存节省
FULL_SHARD 参数、梯度、优化器状态全分片 最大（约50%）
SHARD_GRAD_OP 梯度和优化器状态分片 中等（约33%）
NO_SHARD 不分片（等同于DDP） 无

🔧 FSDP优化技巧

包装策略优化

  • 按层包装，减少通信频率
  • 使用auto_wrap_policy自动决定包装粒度
  • 大层单独包装
  • 小层合并包装

通信优化

  • 使用BACKWARD_PRE预取
  • 增大通信桶大小
  • 使用混合精度减少数据量
  • 计算与通信重叠

显存优化

  • 使用CPU offload卸载优化器
  • 启用激活值检查点
  • 使用混合精度训练
  • 调整batch size

性能监控

  • 监控通信时间占比
  • 检查GPU利用率
  • 分析显存占用
  • 使用torch.profiler分析
⚠️
FSDP注意事项
  • 保存模型：需要先gather参数再保存，或使用state_dict_type='sharded'
  • 模型加载：需要使用sharded state_dict加载
  • 自定义层：需要正确注册可训练参数
  • 通信开销：小模型下FSDP可能比DDP慢
  • 调试困难：分布式系统调试复杂
💡
何时使用FSDP？
  • 显存不足：DDP无法加载模型时
  • 大模型训练：参数量>1B的模型
  • 长序列：需要激活值检查点的场景
  • PyTorch生态：希望使用PyTorch原生支持
  • 中等规模：8-64卡，FSDP比DeepSpeed更简单
