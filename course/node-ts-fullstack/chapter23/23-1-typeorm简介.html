23.1 TypeORM 简介

TypeScript 优先的 ORM 框架

🎯 学习目标

  • 理解 ORM 的概念和优势
  • 了解 TypeORM 的核心特性
  • 学会安装和配置 TypeORM
  • 掌握项目初始化方法

📚 什么是 ORM

ORM（Object-Relational Mapping）对象关系映射，是一种将数据库表映射到程序对象的技术。开发者可以使用面向对象的方式操作数据库，无需编写 SQL 语句。

ORM 的核心作用： ├── 对象 ↔ 表：类对应数据库表 ├── 属性 ↔ 列：类的属性对应表的列 ├── 实例 ↔ 行：对象实例对应表中的行 └── 方法 ↔ 操作：对象方法对应数据库操作 传统方式： const result = await db.query( 'SELECT * FROM users WHERE id = ?', [userId] ); ORM 方式： const user = await userRepository.findOne({ where: { id: userId } }); 优势： ├── 类型安全：TypeScript 类型推断 ├── 代码复用：封装通用操作 ├── 跨数据库：支持多种数据库 └── 易于维护：业务逻辑与数据访问分离
💡
ORM vs 原生 SQL

ORM 提供便利和类型安全，但复杂查询可能性能不如原生 SQL。实际项目中简单 CRUD 用 ORM，复杂查询可用 QueryBuilder 或原生 SQL。

🔧 TypeORM 特性

TypeORM 核心特性： 1. TypeScript 优先 ├── 完整的类型支持 ├── 装饰器定义实体 └── 类型推断和自动补全 2. 多数据库支持 ├── MySQL / MariaDB ├── PostgreSQL ├── SQLite ├── SQL Server ├── Oracle └── MongoDB 3. 两种开发模式 ├── Active Record：实体自带数据访问方法 └── Data Mapper：通过 Repository 操作 4. 功能丰富 ├── 关系映射（一对一、一对多、多对多） ├── 查询构建器（QueryBuilder） ├── 数据库迁移（Migrations） ├── 事务支持 └── 监听器和订阅者 5. 框架集成 ├── NestJS（推荐） ├── Express ├── Koa └── Fastify

📦 安装配置

# 安装依赖 npm install typeorm reflect-metadata mysql2 # 或使用 PostgreSQL npm install typeorm reflect-metadata pg # 安装 CLI（可选） npm install -g typeorm # 初始化项目 typeorm init --name my-app --database mysql 项目结构： my-app/ ├── src/ │ ├── entity/ # 实体定义 │ │ └── User.ts │ ├── migration/ # 数据库迁移 │ ├── data-source.ts # 数据源配置 │ └── index.ts # 入口文件 ├── ormconfig.json # 配置文件（旧版） ├── package.json └── tsconfig.json # tsconfig.json 需要启用装饰器 { "compilerOptions": { "emitDecoratorMetadata": true, "experimentalDecorators": true } }

⚙️ 数据源配置

// src/data-source.ts import { DataSource } from 'typeorm'; import { User } from './entity/User'; export const AppDataSource = new DataSource({ type: 'mysql', host: 'localhost', port: 3306, username: 'root', password: 'password', database: 'myapp', synchronize: process.env.NODE_ENV !== 'production', // 生产环境禁用 logging: true, entities: [User], migrations: ['src/migration/*.ts'], subscribers: [], }); // 初始化连接 AppDataSource.initialize() .then(() => { console.log('Database connected successfully'); }) .catch((error) => { console.error('Database connection error:', error); }); // 使用环境变量配置 export const AppDataSource = new DataSource({ type: (process.env.DB_TYPE as any) || 'mysql', host: process.env.DB_HOST || 'localhost', port: parseInt(process.env.DB_PORT) || 3306, username: process.env.DB_USERNAME, password: process.env.DB_PASSWORD, database: process.env.DB_DATABASE, entities: ['src/entity/*.ts'], synchronize: false, });

📝 本节小结

✅
  • • ORM 将数据库表映射为程序对象
  • • TypeORM 是 TypeScript 优先的 ORM 框架
  • • 支持多种数据库和两种开发模式
  • • 需要启用装饰器和元数据反射
