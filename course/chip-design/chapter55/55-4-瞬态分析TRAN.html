📊 瞬态分析原理

时域数值积分

瞬态分析求解电路的微分方程，计算电路随时间变化的响应。

  • 从t=0开始，逐步积分到结束时间
  • 每个时间点求解非线性方程组
  • 自动调整步长保证精度
  • 可以处理大信号非线性

🔧 .tran命令

语法和参数

* 基本语法 .tran tstep tstop [tstart] [tmax] * 示例1：基本瞬态分析 .tran 1n 100n * 步长1ns，总时间100ns * 示例2：指定保存起始时间 .tran 1n 100n 50n * 只保存50ns之后的数据 * 示例3：指定最大步长 .tran 1n 10u 0 100p * 最大步长限制为100ps

🌊 时域激励源

常用的时域源

* 脉冲源 V1 in 0 PULSE(0 3.3 10n 1n 1n 50n 100n) * 正弦波 V2 in 0 SIN(0 1 1Meg 0 0 0) * 分段线性源 V3 in 0 PWL(0 0 10n 0 10.1n 3.3 100n 3.3) * 指数源 V4 in 0 EXP(0 3.3 1n 1n 10n 10u)

⚠️ 收敛性问题

常见问题和解决方法

问题 解决方法
不收敛 减小步长、增加迭代次数
时间步长太小 检查模型、调整容差
振荡 增加节点寄生电容
