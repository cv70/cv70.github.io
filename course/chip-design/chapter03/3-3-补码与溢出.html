3.3 补码与溢出

计算机中有符号数的表示与运算

🎯 学习目标

  • 理解原码、反码、补码的概念与表示方法
  • 掌握补码的加减运算规则
  • 理解溢出的概念与检测方法
  • 认识补码在计算机系统中的重要性

为什么需要补码

在计算机中，我们需要表示正数和负数。如果直接用符号位加绝对值的方式（原码），在进行加减运算时会非常复杂。为了简化运算电路，计算机普遍采用补码（Two's Complement）来表示有符号整数。

使用补码的好处是：减法可以转化为加法运算，加法和减法可以使用同一套电路实现，大大简化了ALU（算术逻辑单元）的设计。

💡 三种编码方式

原码（Sign-Magnitude）

最高位为符号位（0正1负），其余位表示绝对值。

+5 的8位原码：00000101
-5 的8位原码：10000101

缺点：0有两种表示，运算复杂

反码（One's Complement）

正数同原码；负数的符号位不变，数值位按位取反。

+5 的8位反码：00000101
-5 的8位反码：11111010

缺点：0仍有两种表示

补码（Two's Complement）

正数同原码；负数为反码加1。

+5 的8位补码：00000101
-5 的8位补码：11111011

优点：0唯一，运算统一

💡
补码的快速求法

方法一：原码 → 符号位不变，数值位取反 → 加1
方法二：从最低位开始，找到第一个1，该位及以下保持不变，以上位取反（不包括符号位）

示例：求-20的8位补码
20的原码：00010100
找到第一个1（第3位），该位及以下保持：xxx100
以上位取反：11101100
结果：11101100

🔧 补码运算

补码加法

补码加法直接将两个补码相加，包括符号位在内，丢弃最高位的进位。

计算 5 + (-3) = 2：

  00000101 (+5)
+ 11111101 (-3)
-----------
  00000010 (+2) ✓

补码减法

补码减法通过"减去一个数等于加上这个数的补码"来实现。

计算 5 - 3 = 5 + (-3) = 2：

  00000101 (+5)
+ 11111101 (-3)
-----------
  00000010 (+2) ✓

⚠️ 溢出（Overflow）

什么是溢出

当运算结果超出了数据类型所能表示的范围时，就会发生溢出。在补码运算中，两个正数相加得到负数，或两个负数相加得到正数，就是溢出的典型情况。

正溢出

两个正数相加结果超出最大正值

4位补码：0101 (+5) + 0100 (+4)

  0101
+ 0100
------
  1001 (-7) ✗ 溢出！

正确结果+9超出了4位补码范围(-8~+7)

负溢出

两个负数相加结果超出最小负值

4位补码：1001 (-7) + 1000 (-8)

  1001
+ 1000
------
  0001 (+1) ✗ 溢出！

正确结果-15超出了4位补码范围

溢出检测方法

方法 判断规则
双高位法 最高位进位 Cin ≠ 符号位进位 Cout 时发生溢出
符号位判断 两正数相加得负数，或两负数相加得正数时溢出
双符号位法 使用两位符号位，两符号位不同时溢出
💡
补码的表示范围

n位补码的表示范围：-2ⁿ⁻¹ 到 +2ⁿ⁻¹-1

例如：8位补码范围是 -128 到 +127
16位补码范围是 -32768 到 +32767
32位补码范围是 -2147483648 到 +2147483647

注意：负数的表示范围比正数多1，这是因为0属于正数。

  • • 溢出检测是保证运算正确性的重要机制
  • • n位补码表示范围：-2ⁿ⁻¹ 到 +2ⁿ⁻¹-1
