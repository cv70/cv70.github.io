📚 数据压缩概述

# 为什么需要数据压缩 ## 减少传输数据量 - JSON 响应通常较大 - 文本数据压缩率高 - 节省带宽成本 ## 提高传输速度 - 更小的数据量 - 更快的下载速度 - 改善用户体验 # 常见压缩算法 ## Gzip - 最广泛支持 - 压缩率约 70-80% - 压缩速度快 ## Brotli - 新一代压缩算法 - 压缩率比 Gzip 高 15-20% - 压缩速度稍慢 ## Deflate - 较老的算法 - 压缩率一般 - 兼容性好 # 压缩效果示例 原始大小: 100KB JSON Gzip 压缩后: 15-20KB Brotli 压缩后: 12-17KB # 压缩适用场景 ✅ JSON API 响应 ✅ HTML 页面 ✅ CSS/JS 文件 ✅ 文本文件 ❌ 已压缩的图片（PNG/JPG） ❌ 视频文件 ❌ 二进制文件

🔧 Express 压缩配置

# 使用 compression 中间件 import express from 'express'; import compression from 'compression'; const app = express(); // 启用压缩 app.use(compression()); // 自定义配置 app.use(compression({ // 压缩阈值（字节） threshold: 1024, // 大于 1KB 才压缩 // 压缩级别 (0-9) level: 6, // 平衡压缩率和速度 // 过滤函数 filter: (req, res) => { // 检查客户端是否支持 if (req.headers['x-no-compression']) { return false; } // 使用默认过滤 return compression.filter(req, res); }, })); # 支持 Brotli import express from 'express'; import shrinkRay from 'shrink-ray-current'; const app = express(); // shrink-ray 支持 Brotli 和 Gzip app.use(shrinkRay()); # 手动压缩实现 import zlib from 'zlib'; import { promisify } from 'util'; const gzip = promisify(zlib.gzip); const brotli = promisify(zlib.brotliCompress); app.get('/api/data', async (req, res) => { const data = await getData(); const jsonStr = JSON.stringify(data); // 检查客户端支持的压缩方式 const acceptEncoding = req.headers['accept-encoding'] || ''; if (acceptEncoding.includes('br')) { // Brotli 压缩 const compressed = await brotli(jsonStr); res.set('Content-Encoding', 'br'); res.send(compressed); } else if (acceptEncoding.includes('gzip')) { // Gzip 压缩 const compressed = await gzip(jsonStr); res.set('Content-Encoding', 'gzip'); res.send(compressed); } else { // 不压缩 res.json(data); } });
💡
压缩级别

压缩级别 1-9，级别越高压缩率越好但速度越慢。推荐使用 4-6，平衡压缩率和性能。

⚙️ Nginx 压缩配置

# nginx.conf 压缩配置 http { # 启用 Gzip gzip on; gzip_vary on; gzip_proxied any; gzip_comp_level 6; gzip_min_length 1024; gzip_types application/json application/javascript text/plain text/css text/xml application/xml application/xml+rss; # 启用 Brotli（需要安装 ngx_brotli 模块） brotli on; brotli_comp_level 6; brotli_types application/json application/javascript text/plain text/css; # 禁用对已压缩文件的压缩 gzip_disable "msie6"; } # 反向代理配置 server { listen 80; server_name api.example.com; location / { proxy_pass http://localhost:3000; proxy_http_version 1.1; # 传递压缩相关头 proxy_set_header Accept-Encoding ""; # 或者让后端处理压缩 # proxy_set_header Accept-Encoding $http_accept_encoding; } }

🚀 压缩性能优化

# 预压缩静态文件 import fs from 'fs'; import zlib from 'zlib'; import { promisify } from 'util'; const gzip = promisify(zlib.gzip); const brotli = promisify(zlib.brotliCompress); // 构建时预压缩 async function precompress(filePath: string) { const content = fs.readFileSync(filePath); // 生成 Gzip 版本 const gzipped = await gzip(content); fs.writeFileSync(`${filePath}.gz`, gzipped); // 生成 Brotli 版本 const brotlied = await brotli(content); fs.writeFileSync(`${filePath}.br`, brotlied); console.log(`Compressed ${filePath}`); } # Express 静态文件预压缩 import express from 'express'; import expressStaticGzip from 'express-static-gzip'; const app = express(); // 自动提供预压缩文件 app.use(expressStaticGzip('public', { enableBrotli: true, orderPreference: ['br', 'gz'], })); # 压缩性能对比 import Benchmark from 'benchmark'; const suite = new Benchmark.Suite(); const testData = JSON.stringify({ /* large data */ }); suite .add('Gzip level 1', { defer: true, fn: async (deferred: any) => { await promisify(zlib.gzip)(testData, { level: 1 }); deferred.resolve(); }, }) .add('Gzip level 6', { defer: true, fn: async (deferred: any) => { await promisify(zlib.gzip)(testData, { level: 6 }); deferred.resolve(); }, }) .add('Brotli level 4', { defer: true, fn: async (deferred: any) => { await promisify(zlib.brotliCompress)(testData, { params: { [zlib.constants.BROTLI_PARAM_QUALITY]: 4 } }); deferred.resolve(); }, }) .on('complete', function() { console.log('Fastest:', this.filter('fastest').map('name')); }) .run();
