C-3 优矿API参考

数据API参考

🔑 认证与初始化

# 安装Uqer
pip install uqer

# 导入SDK
from uqer import DataAPI

# 初始化
client = DataAPI.Auth('username', 'password')

# 或者使用token
client = DataAPI.Auth(token='your_token')

🔧 通用参数

参数 说明 示例
secID 证券代码 '000001.XSHE'
ticker 交易代码 '000001'
beginDate 开始日期 '20240101'
endDate 结束日期 '20241231'
field 返回字段 ['open','high','low','close']
⚠️
使用限制

优矿API需要在优矿平台上运行。注意数据调用频率限制， 避免超过每日调用配额。部分接口需要付费权限才能访问。
