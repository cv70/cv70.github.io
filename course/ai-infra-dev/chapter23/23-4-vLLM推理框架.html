什么是vLLM

vLLM是一个高性能的大语言模型推理引擎，专为LLM推理优化设计。 它引入了PagedAttention技术，解决了KV Cache管理的内存碎片问题， 并实现了高效的连续批处理，在提升吞吐量的同时保持低延迟。

💡 核心创新

PagedAttention

  • 原理：将KV Cache分页存储
  • 优势：避免内存碎片
  • 效果：提高显存利用率
  • 类比：类似操作系统的虚拟内存

连续批处理

  • 原理：不等批次填满即处理
  • 优势：降低首token延迟
  • 效果：提升并发处理能力
  • 适用：高并发LLM服务

📊 PagedAttention原理

传统问题 vs PagedAttention

传统KV Cache
  • 连续内存分配
  • 固定最大序列长度
  • 大量内存浪费
  • 内存碎片严重
  • 难以动态调整
PagedAttention
  • 分页内存管理
  • 按需动态分配
  • 内存高效利用
  • 无内存碎片
  • 支持共享计算

🔥 连续批处理

Inflight Batching

vLLM实现了真正的连续批处理，可以在不等待整个批次完成的情况下，将新生成的请求加入正在处理的批次。

工作流程
请求A生成中
请求B生成中
请求C加入
请求D加入

💻 使用示例

from vllm import LLM, SamplingParams
from transformers import AutoTokenizer

# 基本使用
def basic_usage():
    """
    基本的vLLM推理
    """
    # 初始化LLM
    llm = LLM(
        model="meta-llama/Llama-2-7b-hf",
        tensor_parallel_size=1,  # 张量并行大小
        gpu_memory_utilization=0.9,  # GPU显存利用率
        max_model_len=4096,  # 最大序列长度
        trust_remote_code=True
    )

    # 采样参数
    sampling_params = SamplingParams(
        temperature=0.8,
        top_p=0.95,
        max_tokens=100
    )

    # 生成文本
    prompts = [
        "写一个Python函数计算斐波那契数列",
        "解释什么是机器学习",
        "用中文写一首诗"
    ]

    outputs = llm.generate(prompts, sampling_params)

    # 打印结果
    for output in outputs:
        prompt = output.prompt
        generated_text = output.outputs[0].text
        print(f"Prompt: {prompt}")
        print(f"Generated: {generated_text}\n")

# 批处理推理
def batch_inference():
    """
    批处理推理
    """
    llm = LLM(model="meta-llama/Llama-2-7b-hf")

    # 大批量请求
    prompts = [f"写一个关于{i}的故事" for i in range(100)]

    # 不同的采样参数
    sampling_params = [
        SamplingParams(temperature=0.1, max_tokens=50),
        SamplingParams(temperature=0.8, max_tokens=100),
        SamplingParams(temperature=1.0, max_tokens=150),
    ]

    # 生成
    outputs = llm.generate(
        prompts * 3,
        sampling_params
    )

    return outputs

# 流式生成
def stream_generation():
    """
    流式生成
    """
    from vllm import SamplingParams

    llm = LLM(model="meta-llama/Llama-2-7b-hf")

    sampling_params = SamplingParams(
        temperature=0.8,
        max_tokens=100,
        stream=True  # 启用流式输出
    )

    prompts = ["解释什么是深度学习"]

    # 流式生成
    for request_id, output in llm.generate(prompts, sampling_params):
        print(f"Request {request_id}:")
        for text in output:
            print(text, end="", flush=True)
        print("\n")

def quantized_inference():
    """
    使用量化模型
    """
    llm = LLM(
        model="TheBloke/Llama-2-7B-AWQ",
        quantization="awq",  # AWQ量化
