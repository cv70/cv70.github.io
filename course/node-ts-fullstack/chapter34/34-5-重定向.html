34.5 重定向

掌握 Express 重定向的各种用法

🎯 学习目标

  • 掌握 res.redirect() 的基本用法
  • 理解不同重定向状态码的区别
  • 学会相对路径和绝对路径重定向
  • 了解"返回上一页"的实现

🔄 res.redirect() 基本用法

// 默认 302 临时重定向 app.get('/old', (req, res) => { res.redirect('/new'); }); // 指定状态码 app.get('/permanent', (req, res) => { res.redirect(301, '/new-location'); // 永久重定向 }); // 重定向到外部网站 app.get('/google', (req, res) => { res.redirect('https://www.google.com'); }); // 返回上一页 app.get('/back', (req, res) => { res.redirect('back'); });

📊 重定向状态码

状态码 名称 说明
301 Moved Permanently 永久移动，SEO 权重转移
302 Found 临时移动（默认）
303 See Other POST 后重定向到 GET
307 Temporary Redirect 临时重定向，保留请求方法
308 Permanent Redirect 永久重定向，保留请求方法
// 301 永久重定向 app.get('/old-page', (req, res) => { res.redirect(301, '/new-page'); }); // 302 临时重定向（默认） app.get('/temp', (req, res) => { res.redirect('/maintenance'); }); // 303 POST 后重定向 app.post('/login', (req, res) => { // 登录成功后重定向到首页 res.redirect(303, '/dashboard'); }); // 307 保留 POST 方法 app.post('/submit', (req, res) => { res.redirect(307, '/process'); });

🛤️ 相对路径和绝对路径

// 相对于当前路径 app.get('/admin/settings', (req, res) => { res.redirect('./profile'); // /admin/profile }); app.get('/admin/settings', (req, res) => { res.redirect('../users'); // /admin/users }); // 绝对路径 app.get('/anywhere', (req, res) => { res.redirect('/api/users'); // /api/users }); // 完整 URL app.get('/external', (req, res) => { res.redirect('https://api.example.com/v2/users'); });

📋 实际应用示例

// 登录后重定向 app.post('/login', (req, res) => { const { username, password } = req.body; if (authenticate(username, password)) { // 登录成功，重定向到仪表板 res.redirect('/dashboard'); } else { // 登录失败，重定向回登录页 res.redirect('/login?error=1'); } }); // 认证中间件重定向 function requireAuth(req, res, next) { if (!req.user) { return res.redirect('/login?redirect=' + encodeURIComponent(req.originalUrl)); } next(); } app.get('/protected', requireAuth, (req, res) => { res.send('Protected content'); }); // HTTP 到 HTTPS 重定向 app.use((req, res, next) => { if (req.protocol === 'http' && process.env.NODE_ENV === 'production') { return res.redirect(301, 'https://' + req.headers.host + req.url); } next(); }); // www 到非 www 重定向 app.use((req, res, next) => { if (req.headers.host.startsWith('www.')) { const host = req.headers.host.slice(4); return res.redirect(301, req.protocol + '://' + host + req.url); } next(); }); // 模块化重定向 app.get('/blog/:slug', (req, res) => { const newSlug = getNewSlug(req.params.slug); if (newSlug) { res.redirect(301, `/posts/${newSlug}`); } else { res.status(404).send('Not found'); } });

✅ 小结

📌
本节要点
  • res.redirect() 默认 302 临时重定向
  • 301 永久重定向用于 SEO 权重转移
  • POST 后重定向用 303 避免重复提交
  • 支持相对路径、绝对路径和完整 URL
