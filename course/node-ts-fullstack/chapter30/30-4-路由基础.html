30.4 路由基础

理解 Express 路由的工作原理和基本用法

🎯 学习目标

  • 理解路由的概念和组成要素
  • 掌握基本路由的定义方法
  • 学会处理不同 HTTP 方法的请求
  • 理解路由匹配和执行顺序

📖 什么是路由

路由（Routing）是指确定应用程序如何响应客户端对特定端点的请求。每个路由可以有一个或多个处理函数，当匹配到对应的路由时执行。

路由的组成

一个路由由三个基本要素组成：

// 路由语法 app.METHOD(PATH, HANDLER) // METHOD: HTTP 请求方法（GET, POST, PUT, DELETE 等） // PATH: 请求路径（URL 路径） // HANDLER: 处理函数（可以是单个函数或函数数组）

METHOD

HTTP 请求方法，如 get、post、put、delete、patch 等

PATH

URL 路径，可以是字符串或正则表达式

HANDLER

处理函数，接收 req 和 res 对象

🛣️ 基本路由示例

GET 请求

// 处理 GET 请求 app.get('/', (req, res) => { res.send('Hello World!'); }); app.get('/about', (req, res) => { res.send('About Page'); }); app.get('/contact', (req, res) => { res.send('Contact Page'); });

POST 请求

// 处理 POST 请求 app.post('/users', (req, res) => { const user = req.body; res.status(201).json({ message: 'User created', data: user }); });

PUT 请求

// 处理 PUT 请求（完整更新） app.put('/users/:id', (req, res) => { const { id } = req.params; const updateData = req.body; res.json({ message: `User ${id} updated`, data: updateData }); });

DELETE 请求

// 处理 DELETE 请求 app.delete('/users/:id', (req, res) => { const { id } = req.params; res.json({ message: `User ${id} deleted` }); });

PATCH 请求

// 处理 PATCH 请求（部分更新） app.patch('/users/:id', (req, res) => { const { id } = req.params; const updateData = req.body; res.json({ message: `User ${id} partially updated`, data: updateData }); });

📦 HTTP 方法对照表

HTTP 方法 Express 方法 用途 典型场景
GET app.get() 获取资源 查询数据、获取页面
POST app.post() 创建资源 新增数据、表单提交
PUT app.put() 完整更新资源 替换整个资源
PATCH app.patch() 部分更新资源 修改部分字段
DELETE app.delete() 删除资源 删除数据
HEAD app.head() 获取响应头 检查资源是否存在
OPTIONS app.options() 获取支持的HTTP方法 CORS 预检请求

🔀 特殊路由方法

app.all() - 匹配所有 HTTP 方法

// 对 /secret 路径的所有请求方法都执行此处理 app.all('/secret', (req, res, next) => { console.log('Accessing the secret section...'); next(); // 传递给下一个处理程序 }); // 实际处理 app.get('/secret', (req, res) => { res.send('Secret content'); });

app.use() - 路由中间件

// 匹配以 /api 开头的所有路径 app.use('/api', (req, res, next) => { console.log('API request received'); next(); }); // 更具体的路由 app.get('/api/users', (req, res) => { res.json({ users: [] }); });
💡
app.use() vs app.METHOD()

app.use() 不关心 HTTP 方法，只匹配路径前缀；app.METHOD() 需要同时匹配方法和完整路径。

🎯 路由路径匹配

精确路径匹配

// 精确匹配根路径 app.get('/', (req, res) => res.send('Root')); // 精确匹配 /about app.get('/about', (req, res) => res.send('About'));

路径参数

// 动态路由参数 app.get('/users/:id', (req, res) => { res.send(`User ID: ${req.params.id}`); }); // 多个参数 app.get('/users/:userId/posts/:postId', (req, res) => { const { userId, postId } = req.params; res.send(`User ${userId}, Post ${postId}`); }); // 可选参数（使用正则） app.get('/users/:id?', (req, res) => { const id = req.params.id || 'default'; res.send(`User ID: ${id}`); });

正则表达式匹配

// 匹配任何以 .json 结尾的路径 app.get(/.*\.json$/, (req, res) => { res.send('JSON file requested'); }); // 匹配数字 ID app.get('/users/:id(\\d+)', (req, res) => { res.send(`Numeric User ID: ${req.params.id}`); });

路径匹配示例对照

路由路径 匹配 URL 不匹配 URL
/about /about /about/us, /about/
/about/ /about/, /about /about/us
/users/:id /users/123, /users/abc /users, /users/123/posts
/users/:id? /users, /users/123 /users/123/posts

🔄 多个处理函数

单个路由多个处理函数

// 方式一：使用 next() 传递 app.get('/example', (req, res, next) => { console.log('第一个处理函数'); next(); }, (req, res) => { console.log('第二个处理函数'); res.send('处理完成'); }); // 方式二：使用函数数组 const middleware1 = (req, res, next) => { console.log('中间件 1'); next(); }; const middleware2 = (req, res, next) => { console.log('中间件 2'); next(); }; const handler = (req, res) => { res.send('最终处理'); }; app.get('/example2', [middleware1, middleware2, handler]);
⚠️
重要提醒

必须调用 next() 才能将控制权传递给下一个处理函数，否则请求会被挂起。

📊 路由执行顺序

路由按照定义的顺序执行，第一个匹配的路由会先处理：

// 按顺序定义路由 app.get('/users/:id', (req, res) => { res.send(`User ${req.params.id}`); }); // 这条路由永远不会执行，因为上面的路由已经匹配 app.get('/users/admin', (req, res) => { res.send('Admin page'); }); // 正确顺序：更具体的路由放在前面 app.get('/users/admin', (req, res) => { res.send('Admin page'); }); app.get('/users/:id', (req, res) => { res.send(`User ${req.params.id}`); });
✅
最佳实践

将具体的路由放在参数化路由之前定义，避免参数化路由"吞掉"具体路由。

✅ 小结

📌
本节要点
  • 路由由 METHOD、PATH、HANDLER 三要素组成
  • Express 支持 GET、POST、PUT、DELETE、PATCH 等 HTTP 方法
  • 路径参数使用 :param 语法，通过 req.params 获取
  • app.all() 匹配所有方法，app.use() 用于中间件
  • 路由按定义顺序执行，具体路由应在参数化路由之前
