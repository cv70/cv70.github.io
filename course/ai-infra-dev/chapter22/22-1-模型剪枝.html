什么是模型剪枝

模型剪枝（Model Pruning）是指通过移除神经网络中不重要的参数或结构来减少模型大小和计算量的技术。 就像修剪树木的枝叶一样，剪枝可以让模型更紧凑、更高效。

🔍 剪枝的核心思想

为什么可以剪枝

  • 参数冗余：深度学习模型通常过度参数化
  • 权重分布：大量权重接近于零
  • 功能重叠：不同神经元可能学习相似特征
  • 容量富裕：模型容量往往超过任务需求

剪枝的好处

  • 减少计算量：降低推理延迟
  • 减少显存占用：支持更大batch
  • 提高缓存命中率：更好的内存访问
  • 降低能耗：适合边缘部署

🎭 剪枝类型

分类维度 类型 描述 特点
剪枝粒度 非结构化剪枝 逐个参数剪枝 精度高，需要稀疏库支持
结构化剪枝 按通道/层剪枝 易部署，精度略低
剪枝时机 训练后剪枝 先训练再剪枝 简单，但需要大量训练
训练中剪枝 训练时同时剪枝 效率高，训练稳定
剪枝顺序 一次性剪枝 达到目标即停止 快速，但精度损失大
迭代式剪枝 多次剪枝+微调 精度好，耗时较长

📊 重要性评估方法

权重幅度

  • 基于权重的绝对值
  • 小权重被认为不重要
  • 简单直观
  • 最常用的方法

梯度信息

  • 基于梯度的变化率
  • 反映参数对损失的影响
  • 需要额外计算
  • 更准确

一阶泰勒展开

  • 近似损失变化
  • 计算效率高
  • 平衡精度和效率
  • 实用性强

敏感度分析

  • 逐层评估影响
  • 确定每层的剪枝比例
  • 复杂度高
  • 效果好

💻 剪枝实现示例

import torch
import torch.nn as nn
import torch.nn.utils.prune as prune

def prune_model(model, pruning_rate=0.3):
    """
    对模型进行非结构化剪枝
    """
    # 对所有卷积层和全连接层进行剪枝
    for name, module in model.named_modules():
        if isinstance(module, (nn.Conv2d, nn.Linear)):
            # L1非结构化剪枝
            prune.l1_unstructured(
                module,
                name='weight',
                amount=pruning_rate  # 剪枝比例
            )

def structured_prune(model, pruning_rate=0.3):
    """
    对模型进行结构化剪枝（按通道）
    """
    for name, module in model.named_modules():
        if isinstance(module, nn.Conv2d):
            # Ln结构化剪枝
            prune.ln_structured(
                module,
                name='weight',
                amount=pruning_rate,
                n=2,  # L2范数
                dim=0  # 按通道剪枝
            )

def iterative_prune(model, target_sparsity=0.5, steps=10):
    """
    迭代式剪枝
    """
    current_sparsity = 0

💡
剪枝实践建议
  • 从小剪枝比例开始（10%-30%），逐步增加
  • 每次剪枝后进行充分的微调
  • 优先剪枝全连接层，其次是卷积层
  • 结构化剪枝更适合实际部署
