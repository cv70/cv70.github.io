6.3 MOSFET 的 I-V 特性曲线

输出特性曲线，转移特性曲线

🎯 学习目标

  • 理解 MOSFET 输出特性曲线的含义
  • 掌握转移特性曲线及其参数提取
  • 学会从特性曲线读取关键参数
  • 理解不同工作区域的 I-V 关系

为什么需要研究 I-V 特性

I-V 特性曲线是描述 MOSFET 电气特性的基本工具。通过特性曲线，我们可以了解器件的导通能力、开关特性、增益等关键参数，是进行电路设计和仿真的基础。

📊 输出特性曲线（Output Characteristics）

定义

输出特性曲线描述了在固定栅源电压 VGS 下，漏极电流 ID 随漏源电压 VDS 变化的关系。以 VGS 为参变量，可以得到一族曲线。

📐

ID = f(VDS) | VGS = 常数

曲线特征

截止区

VGS < Vth

ID ≈ 0

器件关断，无导电沟道

线性区

VDS < (VGS - Vth)

ID ∝ VDS

沟道未夹断，类似电阻

饱和区

VDS ≥ (VGS - Vth)

ID 基本恒定

沟道夹断，恒流特性

输出特性曲线的关键参数

参数 定义 意义
饱和电流 ID(sat) 给定 VGS 下的饱和区电流 反映器件的驱动能力
导通电阻 Ron 线性区曲线斜率的倒数 影响开关速度和功耗
厄利电压 VA 饱和区曲线延长线与横轴交点 反映沟道长度调制效应
跨导 gm ΔID / ΔVGS（固定 VDS） 反映电压-电流转换能力

📊 转移特性曲线（Transfer Characteristics）

定义

转移特性曲线描述了在固定漏源电压 VDS 下，漏极电流 ID 随栅源电压 VGS 变化的关系。通常在饱和区条件下测量。

📐

ID = f(VGS) | VDS = 常数

曲线特征

  • VGS < Vth 时，ID ≈ 0（截止区）
  • VGS = Vth 时，电流开始显著增加
  • VGS > Vth 时，ID 随 VGS 平方增加（饱和区）
  • 曲线在阈值附近变化急剧，可用于提取 Vth

从转移特性提取参数

阈值电压 Vth

方法一：线性外推法

将转移特性曲线线性区延长，与 VGS 轴的交点即为 Vth。

方法二：恒定电流法

规定 ID/W 达到某一值（如 1μA/μm）时的 VGS 为 Vth。

跨导 gm

转移特性曲线的斜率：

gm = ∂ID/∂VGS

在饱和区最大，反映器件的增益能力。

📐 各工作区域的电流方程

截止区（VGS < Vth）

ID ≈ 0

实际上存在极小的亚阈值电流（漏电流）

线性区/三极管区（VGS > Vth，VDS < VOV）

其中 VOV = VGS - Vth 称为过驱动电压。

📐

ID = μn Cox (W/L) [(VGS - Vth)VDS - VDS²/2]

当 VDS << VOV 时，简化为：

ID ≈ μn Cox (W/L) (VGS - Vth) VDS

此时 ID 与 VDS 成线性关系，MOSFET 等效为一个电阻：

Ron = 1 / [μn Cox (W/L) (VGS - Vth)]

饱和区（VGS > Vth，VDS ≥ VOV）

📐

ID = ½ μn Cox (W/L) (VGS - Vth)²

考虑沟道长度调制效应后：

ID = ½ μn Cox (W/L) (VGS - Vth)² (1 + λVDS)

其中 λ 是沟道长度调制系数

💡 关键参数定义

工艺跨导参数 KP

KP = μn × Cox

KP 是工艺相关的参数，单位为 A/V² 或 μA/V²

  • μn：电子迁移率（cm²/V·s）
  • Cox：单位面积栅氧化层电容（F/cm²）

典型值：NMOS KP ≈ 100-200 μA/V²，PMOS KP ≈ 40-80 μA/V²

跨导 gm（Transconductance）

跨导定义为漏极电流对栅源电压的变化率：

gm = ∂ID/∂VGS | VDS = 常数

在饱和区：

gm = μn Cox (W/L) (VGS - Vth) = √(2μn Cox (W/L) ID)

gm 越大，器件的增益能力越强，对模拟电路设计至关重要。

⚠️
特性曲线的温度依赖

MOSFET 的 I-V 特性受温度影响：

  • 迁移率：温度升高，迁移率下降，ID 减小
  • 阈值电压：温度升高，|Vth| 减小（约 -2mV/°C）
  • 综合效应：高温下饱和电流通常减小

温度特性对电路的稳定性和热设计非常重要。

📝 本节小结

✅
  • • 输出特性曲线描述 ID vs VDS 关系，分为截止、线性、饱和三个区域
  • • 转移特性曲线描述 ID vs VGS 关系，用于提取阈值电压和跨导
  • • 饱和区电流与 (VGS-Vth)² 成正比，呈平方律关系
  • • 跨导 gm 反映电压-电流转换能力，是模拟设计的关键参数
  • • I-V 特性受温度影响，需要考虑温度稳定性
