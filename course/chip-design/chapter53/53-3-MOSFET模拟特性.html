53.3 MOSFET模拟特性

深入理解MOSFET在模拟电路中的行为

🎯 学习目标

  • 掌握MOSFET的I-V特性方程
  • 理解小信号模型参数
  • 认识非理想效应的影响
  • 学会选择合适的工作区域

📊 MOSFET工作区域

NMOS工作条件

区域 条件 特性
截止区 Vgs < Vth Id = 0，相当于开路
线性区 Vgs > Vth, Vds < Vov 可变电阻，用于开关
饱和区 Vgs > Vth, Vds ≥ Vov 恒流源，用于放大
亚阈值区 Vgs < Vth（接近） 弱反型，指数关系

注：Vov = Vgs - Vth 为过驱动电压

📐 饱和区I-V方程

平方律模型（一阶近似）

Id = (1/2)·μ·Cox·(W/L)·(Vgs - Vth)²·(1 + λ·Vds)
  • μ：载流子迁移率
  • Cox：单位面积栅氧化层电容
  • W/L：宽长比
  • λ：沟道长度调制系数

🔬 小信号模型

低频小信号参数

跨导 gm

gm = ∂Id/∂Vgs = μ·Cox·(W/L)·(Vgs - Vth)
= 2·Id/(Vgs - Vth)

输出电阻 ro

ro = ∂Vds/∂Id = 1/(λ·Id)
= VA/Id
  • gm：栅极电压对漏极电流的控制能力
  • ro：漏极电压对漏极电流的影响
  • VA：厄利电压（Early Voltage）

📈 高频小信号模型

寄生电容

栅极电容

  • Cgs = (2/3)·W·L·Cox（饱和区）
  • Cgd ≈ 0（饱和区）

结电容

  • Csb：源-衬底结电容
  • Cdb：漏-衬底结电容
💡
本征增益

MOSFET作为放大器时，最大电压增益为 gm·ro，称为本征增益。现代工艺下通常在10-50之间。

A_v,max = gm·ro = (2·Id/(Vgs - Vth)) · (1/(λ·Id)) = 2/(λ·(Vgs - Vth))

⚠️ 短沟道效应

现代工艺中的非理想效应

效应 描述 影响
速度饱和 载流子速度不随电场线性增加 gm减小，Id与Vgs呈线性关系
DIBL 漏极电压影响阈值电压 Vth降低，ro减小
CLM 沟道长度调制增强 输出电阻减小
亚阈值斜率 亚阈值区电流变化率 决定最低工作电压

🔄 体效应（Body Effect）

源-衬底电压对Vth的影响

Vth = Vth0 + γ·(√(2φF + Vsb) - √(2φF))
  • γ：体效应系数
  • φF：费米势
  • Vsb：源-衬底电压
  • 当Vsb > 0时，Vth增大

🎯 模拟设计中的器件选择

长沟道器件

  • 本征增益高
  • 输出电阻大
  • 失配小
  • 寄生电容大
  • 用于：高增益放大级

短沟道器件

  • 速度快
  • gm大
  • 寄生电容小
  • 输出电阻小
  • 用于：高频、开关应用

📝 本节小结

✅
  • • MOSFET在模拟电路中主要工作在饱和区
  • • 小信号参数gm和ro是模拟设计的核心
  • • 本征增益gm·ro限制了单级放大器的最大增益
  • • 短沟道效应显著影响现代工艺中的器件行为
  • • 体效应需要考虑源-衬底电压的影响
  • • 根据应用选择合适的沟道长度是关键
