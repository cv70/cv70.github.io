34.6 模板渲染

掌握 Express 模板渲染的基本用法

🎯 学习目标

  • 学会配置 Express 模板引擎
  • 掌握 res.render() 的使用
  • 理解模板变量的传递
  • 了解不同模板引擎的基本语法

⚙️ 配置模板引擎

const express = require('express'); const app = express(); // 设置模板目录 app.set('views', './views'); // 设置模板引擎 app.set('view engine', 'ejs'); // 或使用其他引擎 // app.set('view engine', 'pug'); // app.set('view engine', 'hbs'); // 安装模板引擎 // npm install ejs // npm install pug // npm install hbs (Handlebars)

📄 res.render() 方法

// 基本渲染 app.get('/', (req, res) => { res.render('index'); // 渲染 views/index.ejs }); // 传递变量 app.get('/user/:id', (req, res) => { res.render('user', { title: 'User Profile', user: { id: req.params.id, name: 'Alice' } }); }); // 渲染并回调 app.get('/page', (req, res) => { res.render('page', { title: 'Page' }, (err, html) => { if (err) { return res.status(500).send('Render error'); } res.send(html); }); }); // 指定不同引擎 app.get('/custom', (req, res) => { res.render('template.pug', { title: 'Custom' }); });

📝 EJS 示例

Express 配置

app.set('view engine', 'ejs'); app.get('/users', async (req, res) => { const users = await User.findAll(); res.render('users/index', { title: 'Users List', users }); });

EJS 模板 (views/users/index.ejs)

<!DOCTYPE html> <html> <head> <title><%= title %></title> </head> <body> <h1><%= title %></h1> <ul> <% users.forEach(user => { %> <li> <a href="/users/<%= user.id %>"> <%= user.name %> </a> </li> <% }); %> </ul> <% if (users.length === 0) { %> <p>No users found</p> <% } %> </body> </html>

🔧 模板变量传递方式

// 1. 直接传递 res.render('page', { title: 'Page', data: {} }); // 2. 使用 app.locals 全局变量 app.locals.siteName = 'My Site'; // 所有模板都可访问 siteName // 3. 使用 res.locals 请求级变量 app.use((req, res, next) => { res.locals.user = req.user; res.locals.currentPath = req.path; next(); }); // 当前请求的模板可访问 user 和 currentPath // 4. 组合使用 app.get('/dashboard', (req, res) => { res.render('dashboard', { title: 'Dashboard', stats: getStats() }); // 模板可访问: siteName, user, currentPath, title, stats });

📁 模板布局

// 使用 express-ejs-layouts const expressLayouts = require('express-ejs-layouts'); app.use(expressLayouts); app.set('layout', 'layouts/main'); // views/layouts/main.ejs /* <%= title %>
<%- include('partials/header') %>
<%- body %>
<%- include('partials/footer') %>
*/ // 视图自动渲染在 body 位置 app.get('/', (req, res) => { res.render('home', { title: 'Home' }); });

✅ 小结

📌
本节要点
  • 使用 app.set() 配置模板目录和引擎
  • res.render() 渲染模板并传递变量
  • app.locals 设置全局变量，res.locals 设置请求级变量
  • EJS 使用 <%= %> 输出，<% %> 执行代码
