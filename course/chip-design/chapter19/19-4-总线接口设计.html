片上总线概述

片上总线是连接芯片内部各模块的通信通道，定义了数据传输的协议和接口标准。标准化的总线协议使得不同模块可以方便地集成，是SoC设计的基础。

📊 AMBA总线协议族

协议特点应用场景
APB简单、低功耗、无流水外设访问、低速设备
AHB高性能、流水线、突发传输高速总线、存储器接口
AXI高带宽、分离通道、乱序高性能系统、多核处理器
ACE缓存一致性扩展多核缓存一致性

💡 AXI协议核心信号

写通道

  • AW（Write Address）：写地址通道
  • W（Write Data）：写数据通道
  • B（Write Response）：写响应通道

读通道

  • AR（Read Address）：读地址通道
  • R（Read Data）：读数据通道

🔧 简单APB接口示例

// 简单APB从接口
module apb_slave (
    input  wire        pclk,
    input  wire        presetn,
    input  wire [31:0] paddr,
    input  wire        psel,
    input  wire        penable,
    input  wire        pwrite,
    input  wire [31:0] pwdata,
    output reg  [31:0] prdata,
    output reg         pready
);
    reg [31:0] mem [0:255];

    always @(posedge pclk or negedge presetn) begin
        if (!presetn) begin
            pready <= 1'b0;
        end else if (psel && penable) begin
            if (pwrite)
                mem[paddr[9:2]] <= pwdata;
            else
                prdata <= mem[paddr[9:2]];
            pready <= 1'b1;
        end else begin
            pready <= 1'b0;
        end
    end
endmodule
💡
总线设计要点

1. 严格遵循时序要求，保证setup/hold时间
2. 合理使用流水线提高吞吐率
3. 考虑总线仲裁和优先级
4. 支持错误处理和恢复机制
