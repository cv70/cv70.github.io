17.2 Few-shot Learning

通过示例教会模型新任务

什么是Few-shot Learning

Few-shot Learning（少样本学习）是指在Prompt中提供少量示例，引导模型理解任务模式并完成类似任务的技术。通过展示"输入-输出"对，模型能够快速学习任务要求，无需修改模型参数。

📊 三种学习模式对比

模式 示例数量 特点 适用场景
Zero-shot 0个 完全依赖模型先验知识 通用任务、快速验证
One-shot 1个 一个示例建立任务模式 简单格式转换
Few-shot 2-10个 多个示例提供丰富模式 复杂任务、风格定制
Many-shot 10+个 大量示例精细引导 高精度要求任务
图：通过示例教学，模型能够快速理解任务要求

📈 Few-shot效果提升技巧

示例选择原则

  • 代表性：示例应覆盖主要任务类型
  • 多样性：避免示例过于相似
  • 质量：确保示例输出正确无误
  • 简洁性：示例不宜过长

示例排序策略

  • 由简到繁：先简单后复杂
  • 相似优先：相似示例放最后
  • 随机排列：避免位置偏差
  • 近期效应：最后的示例影响最大

🔢 示例数量对效果的影响

示例数量 Token消耗 效果提升 推荐场景
1-2个 低 中等 简单格式任务
3-5个 中 显著 大多数任务
6-10个 高 边际递减 复杂分类任务
10+个 很高 可能下降 需要微调更好
💡
最佳实践

研究表明，3-5个示例通常能获得最佳性价比。示例过多会增加token消耗，且可能引入噪声。对于非常复杂的任务，考虑使用动态示例选择或微调代替。

⚙️ 动态Few-shot

根据输入动态选择最相关的示例，提升Few-shot效果。

import openai from sklearn.feature_extraction.text import TfidfVectorizer from sklearn.metrics.pairwise import cosine_similarity # 示例库 examples = [ ("产品质量很好", "正面"), ("服务态度差", "负面"), ("性价比高", "正面"), # ... 更多示例 ] def select_examples(query, examples, k=3): # 基于语义相似度选择最相关的示例 vectorizer = TfidfVectorizer() all_texts = [e[0] for e in examples] + [query] tfidf = vectorizer.fit_transform(all_texts) similarities = cosine_similarity(tfidf[-1], tfidf[:-1]) top_indices = similarities[0].argsort()[-k:][::-1] return [examples[i] for i in top_indices]
⚠️
注意事项

Few-shot的示例会被计入上下文token限制。对于长任务或需要大量示例的情况，要注意不要超出模型的上下文窗口。此外，示例中的格式一致性非常重要，不一致的格式会混淆模型。

📝 本节小结

✅

  • • 3-5个示例通常能获得最佳效果
  • • 示例应具有代表性、多样性和高质量
  • • 动态Few-shot可以根据输入选择最相关示例
  • • 注意示例的格式一致性和token消耗
