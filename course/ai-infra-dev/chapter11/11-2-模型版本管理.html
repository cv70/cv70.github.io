模型版本管理的重要性

模型版本管理是MLOps的核心组成部分，它确保模型的可追溯性、可复现性和可恢复性。 良好的版本管理能够帮助我们追踪模型的演进历史，快速定位问题，并在必要时回滚到稳定版本。

🏷️ 模型版本标识体系

语义化版本号

模型版本格式: MAJOR.MINOR.PATCH - MAJOR: 架构重大变更，不兼容 - MINOR: 功能新增，向后兼容 - PATCH: 问题修复，向后兼容 示例: - 1.0.0 (初始版本) - 1.1.0 (新增功能) - 1.1.1 (bug修复) - 2.0.0 (架构重构)

自定义版本管理

import os import json import shutil from datetime import datetime class ModelVersionManager: def __init__(self, base_dir="models"): self.base_dir = base_dir self.versions_dir = os.path.join(base_dir, "versions") def save_version(self, model, version, metadata): """保存模型版本""" version_dir = os.path.join(self.versions_dir, f"v{version}") os.makedirs(version_dir, exist_ok=True) # 保存模型文件 model_path = os.path.join(version_dir, "model.pt") torch.save(model.state_dict(), model_path) # 保存元数据 metadata_path = os.path.join(version_dir, "metadata.json") with open(metadata_path, 'w') as f: json.dump(metadata, f, indent=2) # 更新最新版本链接 self._update_latest(version) return version_dir def load_version(self, version=None): """加载指定版本""" if version is None: version = self._get_latest_version() version_dir = os.path.join(self.versions_dir, f"v{version}") model_path = os.path.join(version_dir, "model.pt") return torch.load(model_path) def list_versions(self): """列出所有版本""" versions = [d[1:] for d in os.listdir(self.versions_dir) if d.startswith('v') and os.path.isdir(os.path.join(self.versions_dir, d))] return sorted(versions, reverse=True) def _update_latest(self, version): """更新最新版本链接""" latest_link = os.path.join(self.versions_dir, "latest") if os.path.exists(latest_link) or os.path.islink(latest_link): os.remove(latest_link) os.symlink(f"v{version}", latest_link) def _get_latest_version(self): """获取最新版本""" latest_link = os.path.join(self.versions_dir, "latest") return os.path.basename(os.readlink(latest_link)).replace('v', '')

🔄 模型回滚策略

自动回滚触发条件

  • 性能下降：准确率下降超过阈值
  • 延迟增加：推理延迟超过SLA
  • 错误率升高：预测错误率超过基准
  • 异常检测：输出分布异常变化
  • 用户反馈：收到大量负面反馈

回滚流程

class ModelRollbackManager: def __init__(self, registry_client): self.registry = registry_client self.rollback_history = [] def monitor_production(self, metrics, thresholds): """监控生产模型性能""" for metric, value in metrics.items(): if value < thresholds[metric]: self.trigger_rollback(metric, value) def trigger_rollback(self, metric, current_value): """触发回滚""" print(f"Alert: {metric} = {current_value}, triggering rollback") # 获取上一个稳定版本 previous_version = self._get_previous_stable_version() # 执行回滚 self.rollback_to(previous_version) # 记录回滚事件 self.rollback_history.append({ 'timestamp': datetime.now().isoformat(), 'metric': metric, 'value': current_value, 'from_version': self._get_current_version(), 'to_version': previous_version }) def rollback_to(self, version): """回滚到指定版本""" # 1. 停止当前版本服务 # 2. 加载目标版本模型 # 3. 启动新服务 # 4. 验证服务正常 # 5. 更新路由配置 pass def _get_previous_stable_version(self): """获取上一个稳定版本""" # 从历史记录中查找 versions = self.registry.list_versions("MyModel") for v in versions: if v.status == "Production" and v.version != self._get_current_version(): return v.version return versions[-2].version # 返回次新版本

⚠️
回滚注意事项

在执行模型回滚前，确保：1）已备份当前版本数据；2）有完整的回滚计划；3）回滚过程经过测试；4）有监控告警机制；5）记录回滚原因用于后续分析。

归档标准

条件 操作 保留期限

归档自动化

class ModelArchiver: def __init__(self, registry): self.registry = registry def archive_old_models(self, max_age_days=365): """归档旧模型""" models = self.registry.list_models() for model in models: versions = self.registry.list_versions(model.name) for version in versions: age = self._calculate_age(version.created_at) if age > max_age_days and not version.is_used: self._archive_version(model.name, version.version) def _archive_version(self, model_name, version): """归档单个版本""" # 1. 移动到归档存储 archive_path = f"s3://archive-bucket/{model_name}/v{version}" self._move_to_archive(version.path, archive_path) # 2. 更新元数据 version.metadata["archived"] = True version.metadata["archive_path"] = archive_path version.metadata["archived_at"] = datetime.now().isoformat() # 3. 标记为已归档 self.registry.update_version(model_name, version.version, { "stage": "Archived", "metadata": version.metadata })
