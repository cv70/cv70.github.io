什么是图像分割

图像分割（Image Segmentation）是将图像划分为多个有意义的区域或对象的过程。与目标检测不同，分割在像素级别对图像进行分类，提供更精细的图像理解能力。图像分割广泛应用于医学影像分析、自动驾驶、遥感图像处理等领域。

💻 代码示例：使用Segment Anything进行分割

from segment_anything import sam_model_registry, SamPredictor
import numpy as np
import cv2

# 加载SAM模型
sam = sam_model_registry["vit_h"](checkpoint="sam_vit_h_4b8939.pth")
sam.to(device="cuda")
predictor = SamPredictor(sam)

# 设置图像
image = cv2.imread("dog.jpg")
predictor.set_image(image)

# 使用点提示进行分割
input_point = np.array([[500, 375]])  # 图像中的点坐标
input_label = np.array([1])  # 1表示前景点

masks, scores, logits = predictor.predict(
    point_coords=input_point,
    point_labels=input_label,
    multimask_output=True
)

# 选择最佳mask
best_mask = masks[np.argmax(scores)]
print(f"分割区域面积: {best_mask.sum()} 像素")

🔄 U-Net架构详解

编码器路径

  • 逐层下采样，提取高层特征
  • 卷积+池化操作
  • 感受野逐渐增大
  • 捕获全局上下文信息

解码器路径

  • 逐层上采样，恢复空间分辨率
  • 跳跃连接融合多尺度特征
  • 精确定位边界
  • 输出与输入同尺寸的分割图
💡
评估指标

IoU(Intersection over Union)和Dice系数是图像分割的核心评估指标。IoU计算预测区域与真实区域的交并比，Dice系数则更关注重叠程度。医学影像分割中Dice系数更为常用。
