9.2 Readonly 和 Partial

TypeScript 内置的映射类型

🎯 学习目标

  • 理解 Readonly 和 Partial 的实现原理
  • 掌握 Required 的用法
  • 学会组合使用这些工具类型
  • 了解实际应用场景

📚 Partial 实现

// Partial 将所有属性变为可选 // 内置实现： // type Partial = { // [P in keyof T]?: T[P]; // }; interface User { id: number; name: string; email: string; age: number; } // 创建部分用户（用于更新） type PartialUser = Partial; // { id?: number; name?: string; email?: string; age?: number; } // 实际应用：更新函数 function updateUser(id: number, updates: Partial): User { // 在实际应用中会从数据库获取用户 const existing: User = { id: 1, name: 'Alice', email: 'alice@example.com', age: 30 }; return { ...existing, ...updates }; } const updated = updateUser(1, { name: 'Bob' }); // { id: 1, name: 'Bob', email: 'alice@example.com', age: 30 }

🔒 Readonly 实现

// Readonly 将所有属性变为只读 // 内置实现： // type Readonly = { // readonly [P in keyof T]: T[P]; // }; interface Config { apiUrl: string; timeout: number; retries: number; } type ReadonlyConfig = Readonly; // { readonly apiUrl: string; readonly timeout: number; readonly retries: number; } const config: ReadonlyConfig = { apiUrl: 'https://api.example.com', timeout: 5000, retries: 3 }; // config.timeout = 10000; // Error: 只读属性不能修改 // 深层 Readonly type DeepReadonly = { readonly [P in keyof T]: T[P] extends object ? DeepReadonly : T[P]; }; interface NestedConfig { api: { url: string; headers: { auth: string; }; }; } const deepConfig: DeepReadonly = { api: { url: 'https://api.example.com', headers: { auth: 'Bearer token' } } }; // deepConfig.api.headers.auth = 'new'; // Error: 只读

✏️ Required 实现

// Required 将所有属性变为必需 // 内置实现： // type Required = { // [P in keyof T]-?: T[P]; // }; interface OptionalUser { id?: number; name?: string; email?: string; } type RequiredUser = Required; // { id: number; name: string; email: string; } // 必须提供所有属性 const user: RequiredUser = { id: 1, name: 'Alice', email: 'alice@example.com' }; // 实际应用：验证后的用户 interface FormUser { name?: string; email?: string; } function validateAndCreate(user: Required): void { // 此时可以确保所有属性都存在 console.log(`Creating user: ${user.name} (${user.email})`); }
💡
修饰符语法

+? 添加可选修饰符，-? 移除可选修饰符。同理，+readonly 添加只读，-readonly 移除只读。

🔀 组合使用

// 组合 Readonly 和 Partial type ReadonlyPartial = Readonly>; interface Settings { theme: string; lang: string; notifications: boolean; } type UpdateSettings = ReadonlyPartial; // { readonly theme?: string; readonly lang?: string; readonly notifications?: boolean; } // 创建不可变的更新对象 const updates: UpdateSettings = { theme: 'dark' }; // updates.theme = 'light'; // Error: 只读 // 实际应用：函数参数 function configure(options: Readonly>): void { // options 的属性都是可选且只读的 const theme = options.theme ?? 'light'; const lang = options.lang ?? 'en'; console.log(`Configured: ${theme}, ${lang}`); } configure({ theme: 'dark' });

📝 本节小结

✅
  • • Partial 使所有属性可选
  • • Readonly 使所有属性只读
  • • Required 使所有属性必需
  • • 可以组合使用实现复杂类型
