90.5 安全头配置

HTTP 安全响应头设置

🎯 学习目标

  • 理解 HTTP 安全响应头的作用
  • 掌握常用安全头配置
  • 学会使用 helmet 中间件
  • 了解内容安全策略配置

📚 安全响应头概述

HTTP 安全响应头可以增强 Web 应用的安全性，防止多种攻击类型。

# 常用安全响应头 ┌──────────────────────────┬────────────────────────────────┐ │ 响应头名称 │ 作用 │ ├──────────────────────────┼────────────────────────────────┤ │ Strict-Transport-Security│ 强制 HTTPS │ │ X-Content-Type-Options │ 防止 MIME 嗅探 │ │ X-Frame-Options │ 防止点击劫持 │ │ X-XSS-Protection │ XSS 过滤（已废弃） │ │ Content-Security-Policy │ 内容安全策略 │ │ X-Permitted-Cross-Domain │ Flash 跨域限制 │ │ Referrer-Policy │ Referer 控制策略 │ │ Permissions-Policy │ 浏览器功能权限 │ └──────────────────────────┴────────────────────────────────┘ # 检查安全头 curl -I https://example.com # 在线检测工具 https://securityheaders.com/ https://observatory.mozilla.org/

🔧 使用 Helmet 配置

import helmet from 'helmet'; import express from 'express'; const app = express(); // 使用默认配置 app.use(helmet()); // 等价于以下配置 app.use(helmet({ contentSecurityPolicy: true, crossOriginEmbedderPolicy: true, crossOriginOpenerPolicy: true, crossOriginResourcePolicy: true, dnsPrefetchControl: true, frameguard: true, hidePoweredBy: true, hsts: true, ieNoOpen: true, noSniff: true, originAgentCluster: true, permittedCrossDomainPolicies: true, referrerPolicy: true, xssFilter: true, })); // 自定义配置 app.use(helmet({ // HSTS 配置 hsts: { maxAge: 31536000, includeSubDomains: true, preload: true, }, // 防止点击劫持 frameguard: { action: 'deny', // 'deny' | 'sameorigin' | 'allow-from' }, // 防止 MIME 嗅探 noSniff: true, // 隐藏 X-Powered-By hidePoweredBy: true, // DNS 预取控制 dnsPrefetchControl: { allow: false, }, // Referrer 策略 referrerPolicy: { policy: 'strict-origin-when-cross-origin', }, }));
💡
Helmet 推荐配置

Helmet 是 Express 应用设置安全头的最佳方式，默认配置已经足够安全，可以根据需要自定义调整。

⚙️ 内容安全策略 (CSP)

# CSP 用于防止 XSS 和数据注入攻击 app.use(helmet.contentSecurityPolicy({ directives: { defaultSrc: ["'self'"], scriptSrc: [ "'self'", "'unsafe-inline'", // 不推荐，仅开发时使用 "https://cdn.jsdelivr.net", ], styleSrc: [ "'self'", "'unsafe-inline'", "https://fonts.googleapis.com", ], imgSrc: [ "'self'", "data:", "https://cdn.example.com", ], fontSrc: [ "'self'", "https://fonts.gstatic.com", ], connectSrc: [ "'self'", "https://api.example.com", ], frameSrc: ["'none'"], objectSrc: ["'none'"], baseUri: ["'self'"], formAction: ["'self'"], frameAncestors: ["'none'"], upgradeInsecureRequests: [], }, reportOnly: false, // true 时只报告不阻止 })); # CSP 指令说明 defaultSrc - 默认资源来源 scriptSrc - JavaScript 来源 styleSrc - CSS 来源 imgSrc - 图片来源 fontSrc - 字体来源 connectSrc - AJAX/WebSocket 来源 frameSrc - iframe 来源 objectSrc - object/embed 来源 frameAncestors - 允许嵌入的父页面 # 特殊值 'self' - 同源 'none' - 禁止 'unsafe-inline' - 允许内联（不安全） 'unsafe-eval' - 允许 eval（不安全） data: - 允许 data URI

🚀 权限策略

# Permissions-Policy 控制浏览器功能访问 app.use(helmet.permittedCrossDomainPolicies({ permittedPolicies: 'none', })); // 或手动设置 app.use((req, res, next) => { res.setHeader( 'Permissions-Policy', [ 'geolocation=()', 'microphone=()', 'camera=()', 'payment=()', 'usb=()', 'magnetometer=()', 'gyroscope=()', 'speaker=(self)', 'fullscreen=(self)', ].join(', ') ); next(); }); # 常见功能权限 geolocation - 地理位置 camera - 摄像头 microphone - 麦克风 payment - 支付请求 usb - USB 设备 fullscreen - 全屏 autoplay - 自动播放 # 禁用所有功能 res.setHeader('Permissions-Policy', 'default-src "none"'); # 允许特定源访问功能 res.setHeader( 'Permissions-Policy', 'camera=(self "https://trusted.com")' );
