希腊字母与风险管理

希腊字母（Greeks）是衡量期权价格对各种因素敏感度的指标，是期权风险管理的核心工具。通过理解和控制希腊字母，可以构建风险可控的期权策略组合。

📊 主要希腊字母

希腊字母 定义 含义 典型范围
Delta (Δ) ∂P/∂S 期权价格对标的资产价格的敏感度 0-1 (Call), -1-0 (Put)
Gamma (Γ) ∂²P/∂S² Delta对标的资产价格的敏感度 正值，ATM最大
Theta (Θ) ∂P/∂t 期权价格对时间的敏感度 负值（时间衰减）
Vega (ν) ∂P/∂σ 期权价格对波动率的敏感度 正值，ATM最大
Rho (ρ) ∂P/∂r 期权价格对利率的敏感度 Call正，Put负

⚖️ 风险管理策略

Delta中性策略

  • 构建Delta中性组合
  • 对冲标的资产价格风险
  • 关注Theta收益
  • 定期再平衡

Vega中性策略

  • 构建Vega中性组合
  • 对冲波动率风险
  • 利用波动率相对价值
  • 适合波动率交易

💻 Python实现示例

# 希腊字母与风险管理
import numpy as np
from scipy.stats import norm

class GreeksCalculator:
    """希腊字母计算器"""

    @staticmethod
    def delta(S, K, T, r, sigma, option_type='call'):
        """计算Delta"""
        d1 = (np.log(S/K) + (r + 0.5*sigma**2)*T) / (sigma*np.sqrt(T))
        if option_type == 'call':
            return norm.cdf(d1)
        else:
            return norm.cdf(d1) - 1

    @staticmethod
    def gamma(S, K, T, r, sigma):
        """计算Gamma"""
        d1 = (np.log(S/K) + (r + 0.5*sigma**2)*T) / (sigma*np.sqrt(T))
        return norm.pdf(d1) / (S * sigma * np.sqrt(T))

    @staticmethod
    def vega(S, K, T, r, sigma):
        """计算Vega"""
        d1 = (np.log(S/K) + (r + 0.5*sigma**2)*T) / (sigma*np.sqrt(T))
        return S * norm.pdf(d1) * np.sqrt(T)

class OptionsPortfolio:
    """期权组合风险管理"""

    def __init__(self):
        self.positions = []

    def add_position(self, position):
        """添加期权头寸"""
        self.positions.append(position)

    def calculate_portfolio_greeks(self, S, r, sigma):
        """计算组合希腊字母"""
        total_delta = 0
        total_gamma = 0
        total_vega = 0
        total_theta = 0

        for pos in self.positions:
            K = pos['strike']
            T = pos['time_to_expiry']
            quantity = pos['quantity']

            greeks = GreeksCalculator()
            delta = greeks.delta(S, K, T, r, sigma, pos['type'])
            gamma = greeks.gamma(S, K, T, r, sigma)
            vega = greeks.vega(S, K, T, r, sigma)

            total_delta += delta * quantity
            total_gamma += gamma * quantity
            total_vega += vega * quantity

        return {
            'delta': total_delta,
            'gamma': total_gamma,
            'vega': total_vega,
            'theta': total_theta
        }

    def check_risk_limits(self, greeks, limits):
        """检查风险限额"""
        warnings = []
        if abs(greeks['delta']) > limits['delta']:
            warnings.append(f"Delta超限: {greeks['delta']:.2f}")
        if abs(greeks['gamma']) > limits['gamma']:
            warnings.append(f"Gamma超限: {greeks['gamma']:.4f}")
        if abs(greeks['vega']) > limits['vega']:
            warnings.append(f"Vega超限: {greeks['vega']:.2f}")
        return warnings

# 使用示例
portfolio = OptionsPortfolio()

# 添加期权头寸
portfolio.add_position({
    'type': 'call',
    'strike': 100,
    'time_to_expiry': 0.5,
    'quantity': 10
})

portfolio.add_position({
    'type': 'put',
    'strike': 105,
    'time_to_expiry': 0.5,
    'quantity': -5
})

# 计算组合希腊字母
greeks = portfolio.calculate_portfolio_greeks(S=100, r=0.05, sigma=0.2)
print("Portfolio Greeks:", greeks)

# 检查风险限额
limits = {'delta': 50, 'gamma': 0.5, 'vega': 200}
warnings = portfolio.check_risk_limits(greeks, limits)
print("Risk Warnings:", warnings)
