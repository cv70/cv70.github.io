融资准备自查

融资准备是融资成功的关键前提。 充分的准备可以提高融资效率，避免浪费时间。 本节提供了融资准备的自查清单。

📋 融资材料

评估项 自查问题 是/否
商业计划书 是否准备了完整的商业计划书？ ____
融资材料包 是否准备了详细的融资材料？ ____
财务预测 是否有详细的财务预测模型？ ____
演示文稿 是否准备了路演PPT？ ____
公司资料 是否准备了公司基本资料？ ____

📊 数据准备

评估项 自查问题 是/否
用户数据 是否有清晰的用户数据？ ____
收入数据 是否有准确的收入数据？ ____
增长数据 是否有可验证的增长数据？ ____
竞品分析 是否有详细的竞品分析？ ____
市场数据 是否有权威的市场数据支撑？ ____

💼 公司治理

评估项 自查问题 是/否
公司结构 公司结构是否清晰？ ____
股权结构 股权结构是否合理？ ____
法律合规 是否完成了必要的法律合规？ ____
财务合规 财务是否规范？ ____
知识产权 是否完成了知识产权保护？ ____

🎯 融资策略

评估项 自查问题 是/否
融资金额 是否确定了合理的融资金额？ ____
融资阶段 是否明确了融资阶段？ ____
投资人目标 是否确定了目标投资人？ ____
估值预期 是否有合理的估值预期？ ____
退出路径 是否考虑了退出路径？ ____

🗣️ 路演准备

评估项 自查问题 是/否
核心故事 是否准备了核心故事？ ____
演练练习 是否进行了充分的演练？ ____
问答准备 是否准备了常见问题的答案？ ____
时间控制 能否在规定时间内完成路演？ ____
团队参与 团队是否熟悉路演内容？ ____
✨
最佳实践

融资准备是一个系统化的过程，建议提前3-6个月开始准备。 要根据不同投资机构的偏好调整材料和策略。 同时，要保持耐心，融资往往比预期时间要长。
