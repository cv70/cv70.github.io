4.3 N 型半导体与 P 型半导体

N型/P型掺杂与多数载流子

🎯 学习目标

  • 理解 N 型半导体的形成机理与特性
  • 理解 P 型半导体的形成机理与特性
  • 掌握多数载流子与少数载流子的概念
  • 了解施主杂质与受主杂质的区别

半导体掺杂类型

根据掺杂杂质类型的不同，掺杂半导体分为N型半导体和P型半导体两种。N型半导体以电子为主要载流子，P型半导体以空穴为主要载流子。这两种类型的半导体是构建所有半导体器件的基础。

💡 N 型半导体

形成原理

在硅晶体中掺入五价元素（如磷 P、砷 As、锑 Sb），这些杂质原子有5个价电子，其中4个与周围硅原子形成共价键，多出的第5个电子很容易挣脱束缚成为自由电子。

  • 杂质原子提供电子 → 施主
  • 电子浓度远大于空穴浓度
  • n ≈ Nᴅ >> p

特性总结

N型半导体中，电子是多数载流子（多子），空穴是少数载流子（少子）。

  • 多子：电子（负电荷）
  • 少子：空穴（正电荷）
  • 整体电中性：n = p + Nᴅ

🔮 P 型半导体

形成原理

在硅晶体中掺入三价元素（如硼 B、铝 Al、镓 Ga），这些杂质原子只有3个价电子，与周围硅原子形成共价键时缺少一个电子，形成一个空穴。邻近的电子可以填充这个空穴，形成空穴的移动。

  • 杂质原子接受电子 → 受主
  • 空穴浓度远大于电子浓度
  • p ≈ Nₐ >> n

特性总结

P型半导体中，空穴是多数载流子（多子），电子是少数载流子（少子）。

  • 多子：空穴（正电荷）
  • 少子：电子（负电荷）
  • 整体电中性：p = n + Nₐ

📊 施主杂质与受主杂质

特性 施主杂质（Donor） 受主杂质（Acceptor）
常用元素 P、As、Sb（五价） B、Al、Ga（三价）
价电子数 5个 3个
作用 提供自由电子 产生空穴
形成半导体类型 N型 P型
电离能 ~0.045 eV (Si中P) ~0.045 eV (Si中B)
能级位置 靠近导带底 靠近价带顶
💡
杂质电离

施主电离：施主杂质释放电子到导带，本身带正电
受主电离：受主杂质从价带接受电子，本身带负电

在室温下，杂质几乎完全电离。电离能很小（约 0.045 eV），远小于禁带宽度（Si: 1.12 eV），所以杂质原子很容易释放或接受电子。

📈 多数载流子与少数载流子

🔬
半导体类型 多数载流子 少数载流子 浓度关系
N型 电子 (nₙ) 空穴 (pₙ) nₙ·pₙ = nᵢ²
P型 空穴 (pₚ) 电子 (nₚ) nₚ·pₚ = nᵢ²

质量作用定律：在任何非简并半导体中，电子浓度与空穴浓度的乘积等于本征载流子浓度的平方：n·p = nᵢ²

⚠️
补偿掺杂

当半导体中同时含有施主和受主杂质时，会发生补偿效应：
• 如果 Nᴅ > Nₐ：表现为 N型，净施主浓度 = Nᴅ - Nₐ
• 如果 Nₐ > Nᴅ：表现为 P型，净受主浓度 = Nₐ - Nᴅ
补偿掺杂在器件制造中有重要应用，用于精确控制半导体类型和载流子浓度。

📝 本节小结

✅
  • • N型半导体：掺入五价元素，电子为多子，空穴为少子
  • • P型半导体：掺入三价元素，空穴为多子，电子为少子
  • • 施主杂质在禁带中形成靠近导带的施主能级
  • • 受主杂质在禁带中形成靠近价带的受主能级
  • • 质量作用定律：n·p = nᵢ²
