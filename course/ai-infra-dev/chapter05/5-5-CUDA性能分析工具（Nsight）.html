5.5 CUDA性能分析工具（Nsight）

使用Nsight工具分析GPU程序性能

🎯 学习目标

  • 了解Nsight工具套件

Nsight工具概述

Nsight是NVIDIA提供的GPU性能分析工具套件，包括Nsight Compute（Kernel级分析）和Nsight Systems（系统级分析）。这些工具帮助开发者深入了解GPU程序的执行细节，找出性能瓶颈并进行优化。

🔧 Nsight Compute

Kernel性能分析

Nsight Compute提供详细的Kernel执行分析，包括资源使用、内存访问、指令执行等：

命令行使用： # 基本分析 ncu ./my_app # 详细分析（所有指标） ncu --set full ./my_app # 分析特定Kernel ncu --kernel myKernel ./my_app # 输出报告 ncu --set full -o my_report ./my_app # 分析CUDA图 ncu --graph-level ./my_app # 查看特定Kernel的详细信息 ncu --kernel "void myKernel(float*, int)" ./my_app # 使用配置文件 ncu --config-file my_config.cfg ./my_app 常用参数： --set full # 收集所有指标 --kernel # 分析特定Kernel --metrics # 收集特定指标 --section # 分析特定部分 --range : # 分析指定范围 --page # 生成特定页面 --csv-export # 导出CSV格式
关键指标： 1. 占用率（Occupancy） - SM资源使用率 - 理想值：> 80% 2. 计算效率（Compute Efficiency） - 实际计算/理论峰值 - 理想值：> 70% 3. 内存带宽效率（Memory Bandwidth） - 实际带宽/理论带宽 - 理想值：> 70% 4. 访问效率（Memory Efficiency） - 合并访问比率 - 理想值：> 90% 5. IPC（Instructions Per Cycle） - 每周期指令数 - 理想值：接近理论最大值

📊 Nsight Systems

系统级分析

Nsight Systems提供系统级的性能分析，查看整个应用的执行流程：

命令行使用： # 基本分析 nsys profile ./my_app # 追踪CUDA和API调用 nsys profile --trace=cuda,nvtx,osrt ./my_app # 生成报告 nsys profile -o my_report ./my_app # 追踪CUDA流 nsys profile --trace=cuda ./my_app # 追踪内存分配 nsys profile --trace=cuda --cuda-memory-usage=true ./my_app # 生成详细报告 nsys profile --stats=true ./my_app # 分析Python应用 nsys profile python my_script.py 常用选项： --trace= # 追踪类型 --gpu-metrics= # GPU指标 --cuda-memory-usage=true # 追踪内存 --stats=true # 生成统计 --force-overwrite=true # 覆盖已有报告 --output= # 输出文件名
💡
使用建议

先用Nsight Systems找出整体瓶颈，再用Nsight Compute深入分析特定Kernel。

🎯 性能分析流程

分析方法

性能分析流程： 1. 初步分析 └─ 使用nsys profile获取整体视图 └─ 识别瓶颈阶段（CPU vs GPU） └─ 找出耗时最长的Kernel 2. Kernel级分析 └─ 使用ncu分析瓶颈Kernel └─ 检查占用率和效率指标 └─ 分析内存访问模式 3. 深入分析 └─ 检查资源使用情况 └─ 分析指令执行统计 └─ 查看内存访问细节 4. 优化实施 └─ 根据分析结果实施优化 └─ 重新编译和测试 └─ 验证性能提升 5. 迭代优化 └─ 重复上述过程 └─ 达到目标性能为止

🔍 常见性能问题

问题与解决方案

问题 症状 解决方案
低占用率 < 50% 减少寄存器使用，增加Block数
内存带宽瓶颈 低算术强度 合并访问，使用共享内存
分支发散 效率下降 减少分支，使用条件选择
寄存器溢出 性能下降 减少局部变量，降低占用率
同步开销 高延迟 减少__syncthreads调用
