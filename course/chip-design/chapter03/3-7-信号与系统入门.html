3.7 信号与系统入门

理解信号处理与系统分析的基础

🎯 学习目标

  • 理解信号与系统的基本概念与分类
  • 了解线性时不变（LTI）系统的特性
  • 掌握卷积运算的基本原理
  • 认识拉普拉斯变换与Z变换的基本概念

信号与系统的重要性

信号与系统是电子工程的核心课程，它提供了分析和设计各种电子系统的数学框架。在芯片设计中，无论是模拟电路的滤波器设计、数字信号处理单元的实现，还是高速信号的传输分析，都离不开信号与系统的理论知识。

理解信号与系统的基本概念，有助于从根本上把握电路行为的本质。

💡 信号的基本概念

什么是信号

信号是信息的载体，是随时间、空间或其他变量变化的物理量。在电子系统中，信号通常是随时间变化的电压或电流。

连续时间信号

在连续时间上定义的信号，用x(t)表示。

示例：

  • 模拟音频信号
  • 正弦波：x(t) = A·sin(ωt)
  • 阶跃信号：u(t)

离散时间信号

在离散时间点上定义的信号，用x[n]表示。

示例：

  • 采样后的音频数据
  • 数字序列
  • 单位脉冲：δ[n]

常用典型信号

信号名称 连续形式 离散形式 应用
单位脉冲 δ(t) δ[n] 系统冲激响应
单位阶跃 u(t) u[n] 开关信号、瞬态分析
指数信号 eat an 衰减、增长过程
正弦信号 A·sin(ωt) A·sin(ωn) 周期信号、频域分析

📊 系统的基本概念

什么是系统

系统是对信号进行变换或处理的装置。系统接收输入信号，产生输出信号。

y(t) = T[x(t)]

x(t)：输入信号
y(t)：输出信号
T：系统变换

系统的分类

分类 特点
线性系统 满足叠加原理
非线性系统 不满足叠加原理
时不变系统 系统特性不随时间改变
时变系统 系统特性随时间改变
分类 特点
因果系统 输出只与当前和过去输入有关
非因果系统 输出与未来输入有关
稳定系统 有界输入产生有界输出（BIBO）
不稳定系统 有界输入可能产生无界输出

🔧 线性时不变（LTI）系统

LTI系统的重要性质

线性时不变系统是最重要的一类系统，具有以下特性：

线性（叠加性）

T[ax₁(t) + bx₂(t)]
= aT[x₁(t)] + bT[x₂(t)]

多个信号的线性组合经过系统后，等于各信号分别经过系统后的线性组合。

时不变性

若 y(t) = T[x(t)]
则 y(t-t₀) = T[x(t-t₀)]

输入延迟多少时间，输出也延迟相同时间。

冲激响应与卷积

冲激响应h(t)是系统对单位脉冲输入δ(t)的响应。对于LTI系统，冲激响应完全描述了系统特性。

📐
卷积积分

y(t) = x(t) * h(t) = ∫x(τ)h(t-τ)dτ

连续系统的输出等于输入与冲激响应的卷积

y[n] = x[n] * h[n] = Σx[k]h[n-k]

离散系统的输出等于输入与冲激响应的卷积和

📈 变换域分析

拉普拉斯变换

用于连续时间信号和系统的分析：

X(s) = ∫x(t)e-stdt

s = σ + jω（复频率）

应用：

  • 微分方程求解
  • 系统稳定性分析（极点位置）
  • 传递函数分析

Z变换

用于离散时间信号和系统的分析：

X(z) = Σx[n]z-n

z = rejω（复变量）

应用：

  • 差分方程求解
  • 数字滤波器设计
  • 离散系统稳定性分析
⚠️
传递函数

在变换域中，卷积运算变为乘法运算：

Y(s) = X(s) × H(s)

Y(z) = X(z) × H(z)

其中H(s)或H(z)称为传递函数，是冲激响应的变换。

传递函数的极点分布决定了系统的稳定性：

  • 连续系统：极点全部在s平面左半平面则稳定
  • 离散系统：极点全部在z平面单位圆内则稳定

📝 本节小结

✅
  • • 信号是信息的载体，可分为连续和离散两大类
  • • 系统是对信号进行处理的装置
  • • LTI系统具有线性和时不变性，可用冲激响应完全描述
  • • 卷积是LTI系统输入输出关系的核心运算
  • • 拉普拉斯变换和Z变换是分析系统的重要工具
  • • 传递函数的极点分布决定系统的稳定性
