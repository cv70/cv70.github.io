📚 PWM概述

PWM（Pulse Width Modulation）脉冲宽度调制是一种通过改变脉冲宽度来控制平均功率的技术。它广泛应用于电机控制、LED调光、电源管理、音频合成等领域。

💡
PWM特点

• 数字控制：通过数字信号控制模拟量
• 高效率：功率器件工作在开关状态
• 精确控制：占空比可精确调节
• 易于实现：硬件结构简单

📊 PWM基本原理

PWM参数

周期（Period）：PWM信号的完整周期时间

频率（Frequency）：周期的倒数，f = 1/T

占空比（Duty Cycle）：高电平时间与周期的比值

分辨率（Resolution）：占空比可调节的精度

占空比计算

Duty Cycle (%) = (Ton / T) × 100%

其中：Ton = 高电平时间，T = 周期

🔧 PWM生成方法

计数比较法

使用计数器和比较器生成PWM：

1. 计数器从0到Period-1循环计数

2. 比较器将计数器值与Duty值比较

3. 计数器 < Duty时输出高电平

4. 计数器 ≥ Duty时输出低电平

相位累加法

使用相位累加器生成PWM：

1. 相位累加器持续累加频率字

2. 累加器高位作为比较基准

3. 与占空比寄存器比较

4. 生成精确的PWM输出

⚙️ PWM模块设计

// PWM模块设计
module pwm #(
    parameter COUNTER_WIDTH = 16,    // 计数器位宽
    parameter CHANNEL_NUM = 4,       // PWM通道数
    parameter DEFAULT_FREQ = 1000,   // 默认频率(Hz)
    parameter CLK_FREQ = 50_000_000  // 系统时钟频率
) (
    input  wire                          clk,
    input  wire                          rst_n,
    input  wire                          enable,         // PWM使能
    input  wire [CHANNEL_NUM-1:0]         polarity,       // 极性（0=正极性, 1=负极性）

    // 寄存器接口
    input  wire                          reg_wr,
    input  wire                          reg_rd,
    input  wire [4:0]                    reg_addr,
    input  wire [31:0]                   reg_wdata,
    output wire [31:0]                   reg_rdata,

    // PWM输出
    output wire [CHANNEL_NUM-1:0]         pwm_out,

    // 中断输出
    output wire                          pwm_irq
);

    // 频率计算：Fpwm = Fclk / (Prescaler * Period)
    // Period = Fclk / (Prescaler * Fpwm)

    // 寄存器定义
    reg [15:0] prescaler;        // 预分频器
    reg [COUNTER_WIDTH-1:0] period_reg;   // 周期寄存器
    reg [COUNTER_WIDTH-1:0] duty_reg [CHANNEL_NUM-1:0];  // 占空比寄存器
    reg [CHANNEL_NUM-1:0] enable_reg;     // 通道使能
    reg [CHANNEL_NUM-1:0] polarity_reg;   // 极性控制
    reg irq_enable;            // 中断使能

    // 状态寄存器
    reg update_flag;           // 更新标志
    reg period_match;          // 周期匹配标志

    // 初始化默认周期（1kHz）
    localparam DEFAULT_PERIOD = CLK_FREQ / DEFAULT_FREQ;

    // 计数器
    reg [COUNTER_WIDTH-1:0] counter;
    wire counter_zero = (counter == 0);

    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            counter <= 0;
            prescaler <= 0;
            period_reg <= DEFAULT_PERIOD[COUNTER_WIDTH-1:0];
            enable_reg <= {CHANNEL_NUM{1'b1}};
            polarity_reg <= {CHANNEL_NUM{1'b0}};
            irq_enable <= 0;
        end else if (enable) begin
            // 计数器逻辑
            if (counter >= period_reg) begin
                counter <= 0;
                period_match <= 1;
            end else begin
                counter <= counter + 1;
                period_match <= 0;
            end

            // 寄存器写操作
            if (reg_wr) begin
                case (reg_addr)
                    5'h0: prescaler <= reg_wdata[15:0];
                    5'h1: period_reg <= reg_wdata[COUNTER_WIDTH-1:0];
                    5'h2: begin
                        duty_reg[0] <= reg_wdata[COUNTER_WIDTH-1:0];
                        duty_reg[1] <= reg_wdata[COUNTER_WIDTH-1:0];
                        duty_reg[2] <= reg_wdata[COUNTER_WIDTH-1:0];
                        duty_reg[3] <= reg_wdata[COUNTER_WIDTH-1:0];
                    end
                    5'h8: enable_reg <= reg_wdata[CHANNEL_NUM-1:0];
                    5'h9: polarity_reg <= reg_wdata[CHANNEL_NUM-1:0];
                    5'hA: irq_enable <= reg_wdata[0];
                endcase
            end
        end
    end

    // 生成PWM输出
    genvar i;
    generate
        for (i = 0; i < CHANNEL_NUM; i = i + 1) begin : pwm_gen
            reg pwm_raw;

            always @(*) begin
                if (enable_reg[i]) begin
                    pwm_raw = (counter < duty_reg[i]);
                end else begin
                    pwm_raw = 0;
                end
            end

            // 极性控制
            assign pwm_out[i] = polarity_reg[i] ? ~pwm_raw : pwm_raw;
        end
    endgenerate

    // 寄存器读操作
    reg [31:0] rdata;
    always @(*) begin
        rdata = 32'h0;
        case (reg_addr)
            5'h0: rdata = {16'h0, prescaler};
            5'h1: rdata = {{32-COUNTER_WIDTH{1'b0}}, period_reg};
            5'h2: rdata = {{32-COUNTER_WIDTH{1'b0}}, duty_reg[0]};
            5'h3: rdata = {{32-COUNTER_WIDTH{1'b0}}, duty_reg[1]};
            5'h4: rdata = {{32-COUNTER_WIDTH{1'b0}}, duty_reg[2]};
            5'h5: rdata = {{32-COUNTER_WIDTH{1'b0}}, duty_reg[3]};
            5'h6: rdata = {{32-COUNTER_WIDTH{1'b0}}, counter};
            5'h8: rdata = {{32-CHANNEL_NUM{1'b0}}, enable_reg};
            5'h9: rdata = {{32-CHANNEL_NUM{1'b0}}, polarity_reg};
            5'hA: rdata = {31'h0, irq_enable};
            5'hB: rdata = {31'h0, period_match};
            default: rdata = 32'h0;
        endcase
    end

    assign reg_rdata = rdata;

    // 中断输出
    assign pwm_irq = irq_enable & period_match;

endmodule

🎛️ PWM高级功能

死区时间（Dead Time）

在互补PWM输出中插入死区时间，防止上下桥臂直通：

• 防止开关管同时导通
• 保护功率器件
• 可编程死区时间

互补输出

生成两路互补的PWM信号：

• 用于H桥驱动
• 自动插入死区
• 支持多种驱动模式

中心对齐PWM

对称的PWM波形：

• 减少谐波失真
• 提高控制精度
• 适合电机控制

PWM同步

多个PWM通道同步：

• 统一启动/停止
• 相位可调
• 适合多相控制

🔌 死区时间产生器

// 死区时间产生器
module pwm_dead_time #(
    parameter DEAD_TIME = 10  // 死区时间（时钟周期数）
) (
    input  wire clk,
    input  wire rst_n,
    input  wire pwm_in,        // 输入PWM
    output wire pwm_h,         // 高侧PWM
    output wire pwm_l          // 低侧PWM
);

    // 上升沿和下降沿延迟
    reg [3:0] rise_cnt, fall_cnt;
    reg rise_delay, fall_delay;
    wire pwm_rising = pwm_in & ~pwm_delayed;
    wire pwm_falling = ~pwm_in & pwm_delayed;
    reg pwm_delayed;

    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            rise_cnt <= 0;
            fall_cnt <= 0;
            rise_delay <= 0;
            fall_delay <= 0;
            pwm_delayed <= 0;
        end else begin
            pwm_delayed <= pwm_in;

            // 上升沿延迟
            if (pwm_rising) begin
                rise_cnt <= DEAD_TIME;
                rise_delay <= 0;
            end else if (rise_cnt > 0) begin
                rise_cnt <= rise_cnt - 1;
                if (rise_cnt == 1) rise_delay <= 1;
            end else begin
                rise_delay <= 1;
            end

            // 下降沿延迟
            if (pwm_falling) begin
                fall_cnt <= DEAD_TIME;
                fall_delay <= 1;
            end else if (fall_cnt > 0) begin
                fall_cnt <= fall_cnt - 1;
                if (fall_cnt == 1) fall_delay <= 0;
            end else begin
                fall_delay <= 0;
            end
        end
    end

    // 互补输出
    assign pwm_h = pwm_in & fall_delay;
    assign pwm_l = ~pwm_in | rise_delay;

endmodule

📊 PWM应用场景

应用频率范围特点注意事项
LED调光100Hz-1kHz频率低，人眼无闪烁避免可见频闪
电机控制10kHz-50kHz频率适中，效率高考虑电机电感
开关电源100kHz-1MHz频率高，体积小EMI干扰大
D类功放300kHz-1MHz高保真，效率高滤波器设计
伺服控制50Hz标准脉宽1-2ms时序精度要求高

🛠️ PWM配置寄存器

控制寄存器（PWM_CTRL）

| 位 | 名称 | 描述 |

| [31:16] | PRESCALER | 预分频值 |

| [15] | COUNTER_MODE | 0=递增, 1=递增递减 |

| [14] | SYNC_MODE | 同步模式 |

| [0] | ENABLE | PWM使能 |

通道控制寄存器（PWM_CH_CTRL）

| 位 | 名称 | 描述 |

| [31:16] | DEAD_TIME | 死区时间 |

| [3] | COMPLEMENT | 互补输出使能 |

| [2] | INVERT | 输出反相 |

| [0] | CH_EN | 通道使能 |

🐛 常见问题与调试

⚠️
常见问题

1. 频率不准确
症状：输出频率与设置不符
解决：检查时钟频率和预分频值

2. 占空比抖动
症状：占空比不稳定
解决：确保时钟稳定，检查计数器位宽

3. 死区时间不足
症状：功率管损坏
解决：增加死区时间，考虑开关速度

4. EMI干扰大
症状：电磁干扰严重
解决：优化边沿速率，增加滤波电路
