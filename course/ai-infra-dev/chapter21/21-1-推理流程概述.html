21.1 推理流程概述

理解模型推理的基本流程与原理

🎯 学习目标

  • 理解模型推理的基本概念
  • 掌握推理流程的核心步骤
  • 了解推理与训练的区别
  • 认识不同类型的推理场景

什么是模型推理

模型推理（Model Inference）是指使用训练好的模型对新数据进行预测或分类的过程。 与训练阶段不同，推理阶段不需要更新模型参数，只进行前向传播计算。

🔄 推理流程核心步骤

1

输入预处理

将原始数据转换为模型可接受的格式，包括归一化、编码、形状调整等

2

模型加载

将训练好的模型参数加载到内存，建立计算图

3

前向传播

输入数据通过神经网络各层，逐层计算得到输出

4

后处理

将模型输出转换为业务可理解的格式，如概率分布、标签等

5

结果返回

将处理后的结果返回给应用或用户

6

日志记录

记录推理请求、结果和性能指标用于监控和优化

📊 推理 vs 训练

特性 推理 训练
主要目标 预测新数据 优化模型参数
计算方式 仅前向传播 前向+反向传播
梯度计算 不需要 必须
内存需求 较小 较大（需存储梯度）
延迟要求 高（低延迟优先） 中（吞吐量优先）
数据量 单次小批量 大批量数据集

🎭 推理场景分类

在线推理

  • 实时响应用户请求
  • 低延迟要求（毫秒级）
  • 典型应用：推荐系统、对话AI
  • 部署方式：边缘设备、云端API

离线推理

  • 批量处理历史数据
  • 高吞吐量优先
  • 典型应用：数据标注、特征提取
  • 部署方式：批处理集群
图：推理服务器集群
⚠️
推理关键挑战
  • 延迟敏感性：用户期望快速响应
  • 并发处理：需要支持大量并发请求
  • 资源受限：边缘设备计算能力有限
  • 成本控制：推理成本可能超过训练成本

💻 简单推理示例

# PyTorch推理示例
import torch
from torchvision import transforms, models

# 1. 加载模型
model = models.resnet50(pretrained=True)
model.eval()  # 设置为评估模式

# 2. 定义预处理
preprocess = transforms.Compose([
    transforms.Resize(256),
    transforms.CenterCrop(224),
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406],
                        std=[0.229, 0.224, 0.225]),
])

# 3. 处理输入
input_tensor = preprocess(image)
input_batch = input_tensor.unsqueeze(0)  # 添加batch维度

# 4. 推理
with torch.no_grad():  # 不计算梯度
    output = model(input_batch)

# 5. 后处理
probabilities = torch.nn.functional.softmax(output[0], dim=0)

📝 本节小结

✅
  • • 推理是使用训练好的模型进行预测的过程
  • • 推理流程包括预处理、加载、前向传播、后处理等步骤
  • • 推理与训练在计算方式和需求上有本质区别
  • • 在线推理注重低延迟，离线推理注重高吞吐
