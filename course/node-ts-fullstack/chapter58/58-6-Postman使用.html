58.6 Postman 使用

API 开发与测试的利器

📖 Postman 简介

Postman 是一款流行的 API 开发和测试工具，提供了从 API 设计、开发、测试到文档的全流程支持。

🚀 基础使用

创建请求

请求配置

  • 选择 HTTP 方法（GET/POST/PUT/DELETE）
  • 输入请求 URL
  • 添加请求参数
  • 设置请求头
  • 编写请求体

认证配置

  • No Auth - 无认证
  • API Key - API 密钥
  • Bearer Token - JWT 认证
  • Basic Auth - 基础认证
  • OAuth 2.0 - OAuth 认证

请求示例

// GET 请求 - 获取用户列表 GET {{baseUrl}}/users?page=1&pageSize=10 // Headers Authorization: Bearer {{token}} Content-Type: application/json // POST 请求 - 创建用户 POST {{baseUrl}}/users // Request Body (JSON) { "name": "张三", "email": "zhangsan@example.com", "password": "Password123!" }

📁 集合管理

创建集合

集合（Collection）是一组相关 API 请求的容器，便于组织和管理 API。

// 集合结构示例 用户管理 API/ ├── 认证/ │ ├── 登录 │ ├── 注册 │ ├── 刷新 Token │ └── 登出 ├── 用户/ │ ├── 获取用户列表 │ ├── 获取用户详情 │ ├── 创建用户 │ ├── 更新用户 │ └── 删除用户 └── 文章/ ├── 获取文章列表 ├── 获取文章详情 └── ...

// 在集合中定义变量 baseUrl = http://localhost:3000/api/v1 token = userId = 123 // 在请求中使用变量 GET {{baseUrl}}/users/{{userId}} Authorization: Bearer {{token}}

📜 脚本编写

Pre-request Script（请求前脚本）

// 在请求发送前执行 // 设置时间戳 pm.environment.set('timestamp', Date.now()); // 生成签名 const crypto = require('crypto'); const secret = pm.environment.get('secret'); const timestamp = pm.environment.get('timestamp'); const signature = crypto .createHmac('sha256', secret) .update(timestamp.toString()) .digest('hex'); pm.environment.set('signature', signature); // 动态请求体 pm.request.body.update({ mode: 'raw', raw: JSON.stringify({ name: pm.variables.get('userName'), timestamp: timestamp, }), });

Tests Script（测试脚本）

// 在收到响应后执行 // 验证状态码 pm.test('状态码应为 200', function() { pm.response.to.have.status(200); }); // 验证响应时间 pm.test('响应时间应小于 200ms', function() { pm.expect(pm.response.responseTime).to.be.below(200); }); // 验证响应结构 pm.test('响应应包含 data 字段', function() { const json = pm.response.json(); pm.expect(json).to.have.property('data'); }); // 提取并保存 Token const json = pm.response.json(); if (json.token) { pm.environment.set('token', json.token); console.log('Token 已保存'); } // 链式断言 pm.test('用户数据验证', function() { const json = pm.response.json(); pm.expect(json.data).to.be.an('array'); pm.expect(json.data).to.have.length.greaterThan(0); pm.expect(json.data[0]).to.include.keys('id', 'name', 'email'); });

🧪 自动化测试

集合测试

// 集合级别测试脚本 // 登录并获取 Token const loginRequest = { url: pm.environment.get('baseUrl') + '/auth/login', method: 'POST', header: { 'Content-Type': 'application/json' }, body: { mode: 'raw', raw: JSON.stringify({ email: 'admin@example.com', password: 'password123', }), }, }; pm.sendRequest(loginRequest, function(err, res) { if (!err) { const json = res.json(); pm.environment.set('token', json.token); console.log('登录成功，Token 已设置'); } });
