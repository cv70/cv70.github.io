13.3 数据类型与变量声明

Verilog数据类型概述

Verilog是一种四值逻辑语言，每个信号可以取四种不同的值。Verilog的数据类型主要分为两大类：线网型（Net Type）和寄存器型（Variable Type）。

🔢 四值逻辑系统

值含义说明典型场景
0逻辑低电平接地、低电平GND、复位有效
1逻辑高电平接电源、高电平VDD、复位释放
x 或 X未知/不确定值不确定初始化前、冲突
z 或 Z高阻态断开连接三态门、未驱动
💡
值的扩展表示

强度级别：除了值，Verilog还支持信号强度描述：
• supply (电源级) > strong (强) > pull (拉) > weak (弱) > highz (高阻)
这主要用于精确的开关级建模，RTL设计中较少使用。

🔌 线网类型（wire）

wire特点

  • 表示物理连线
  • 必须被持续驱动
  • 不能在always中赋值
  • 用于组合逻辑输出

声明语法

wire        single_bit;     // 单比特
wire [7:0]  data_bus;       // 8位总线
wire [31:0] addr_bus;       // 32位地址

💾 寄存器类型（reg）

reg特点

  • 表示数据存储单元
  • 可在always中赋值
  • 可以保持上次的值
  • 用于时序逻辑和过程赋值

声明语法

reg         flag;           // 单比特标志
reg [7:0]   counter;        // 8位计数器
reg [15:0]  memory [0:255]; // 256x16存储器

🔄 wire vs reg 对比

特性wirereg
物理意义连线存储单元
赋值方式assign连续赋值always过程赋值
默认值z（高阻）x（未知）
综合结果组合逻辑连线组合逻辑或寄存器
input端口只能是wire不能是reg

📊 参数与常量

parameter定义

// 参数定义
parameter DATA_WIDTH = 8;
parameter ADDR_WIDTH = 16;
parameter IDLE = 2'b00, ACTIVE = 2'b01, DONE = 2'b10;

// localparam（局部参数，不能被覆盖）
localparam STATE_BITS = 4;

// 使用参数声明变量
wire [DATA_WIDTH-1:0] data_in;
reg  [ADDR_WIDTH-1:0] address;

🔢 数字常量表示

格式示例说明
二进制8'b1010_11008位二进制，下划线增加可读性
十进制16'd25516位十进制
十六进制32'hDEAD_BEEF32位十六进制
八进制12'o77712位八进制

📝 本节小结

✅
  • • Verilog采用四值逻辑：0、1、x、z
  • • wire用于连续赋值，表示连线
  • • reg用于过程赋值，表示存储
  • • parameter用于定义可配置参数
