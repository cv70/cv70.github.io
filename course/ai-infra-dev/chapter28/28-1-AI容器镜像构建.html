28.1 AI容器镜像构建

构建高效的AI应用容器镜像

🎯 学习目标

  • 理解AI容器镜像的特点与挑战
  • 掌握多阶段构建优化镜像大小
  • 学会使用CUDA基础镜像
  • 了解镜像构建的最佳实践

AI容器镜像概述

AI容器镜像是将AI应用及其依赖（CUDA、深度学习框架、模型等）打包成可移植的容器镜像。 良好的镜像构建策略可以显著提高部署效率、减少存储成本并优化运行时性能。

🏗️ 基础镜像选择

NVIDIA基础镜像

官方CUDA镜像，适合GPU应用。

# 开发版本（包含CUDA toolkit） FROM nvidia/cuda:11.8.0-devel-ubuntu22.04 # 运行时版本（体积更小） FROM nvidia/cuda:11.8.0-runtime-ubuntu22.04 # cuDNN版本 FROM nvidia/cuda:11.8.0-cudnn8-runtime-ubuntu22.04

框架镜像

预装深度学习框架。

# PyTorch FROM pytorch/pytorch:2.0.0-cuda11.7-cudnn8-runtime # TensorFlow FROM tensorflow/tensorflow:2.12.0-gpu # MXNet FROM mxnet/python:1.9.1_gpu_cu111_py38

优化镜像

精简版基础镜像。

# Alpine Linux（注意CUDA兼容性） FROM alpine:3.18 # Ubuntu精简版 FROM ubuntu:22.04 # Debian精简版 FROM debian:bookworm-slim
💡
选择建议
  • • 开发环境：使用devel版本，包含调试工具
  • • 生产环境：使用runtime版本，体积更小
  • • 推理服务：考虑使用Triton/TGI等优化镜像
  • • 安全考虑：定期更新基础镜像版本

🔧 多阶段构建

多阶段构建原理

多阶段构建通过使用多个FROM指令，在构建过程中创建多个临时镜像， 最终只保留需要的部分，大幅减少最终镜像大小。

PyTorch应用多阶段构建示例

# 阶段1：构建环境 FROM nvidia/cuda:11.8.0-devel-ubuntu22.04 AS builder # 安装构建工具 RUN apt-get update && apt-get install -y \ python3.10 \ python3-pip \ git \ && rm -rf /var/lib/apt/lists/* # 复制依赖文件 COPY requirements.txt /tmp/ # 安装Python依赖（编译扩展） RUN pip3 install --no-cache-dir \ --user \ -r /tmp/requirements.txt # 编译自定义CUDA kernel COPY src/ /tmp/src/ RUN cd /tmp/src && \ python setup.py build_ext --inplace --- # 阶段2：运行时环境 FROM nvidia/cuda:11.8.0-cudnn8-runtime-ubuntu22.04 # 安装运行时依赖 RUN apt-get update && apt-get install -y \ python3.10 \ python3-pip \ libgomp1 \ && rm -rf /var/lib/apt/lists/* # 复制构建阶段安装的包 COPY --from=builder /root/.local /root/.local # 复制应用代码 COPY src/ /app/src/ COPY models/ /app/models/ # 设置工作目录 WORKDIR /app # 暴露端口 EXPOSE 8080 # 启动命令 CMD ["python3", "-m", "src.server"]
✅
多阶段构建优势
  • • 镜像体积减少50-80%
  • • 避免构建工具进入生产环境
  • • 提高安全性（减少攻击面）
  • • 加快部署速度

📦 常见场景构建示例

训练作业镜像

FROM pytorch/pytorch:2.0.0-cuda11.7-cudnn8-devel # 安装额外依赖 RUN pip install --no-cache-dir \ wandb \ tensorboard \ transformers==4.27.4 \ datasets \ accelerate # 复制训练脚本 COPY train.py /app/ COPY config.yaml /app/ COPY data/ /app/data/ WORKDIR /app # 分布式训练入口 CMD ["python", "-m", "torch.distributed.launch", \ "--nproc_per_node=$(nvidia-smi -L | wc -l)", \ "train.py"]

推理服务镜像

FROM python:3.10-slim # 安装运行时依赖 RUN apt-get update && apt-get install -y \ libgomp1 \ && rm -rf /var/lib/apt/lists/* # 安装Python依赖 COPY requirements.txt /tmp/ RUN pip install --no-cache-dir --no-deps -r /tmp/requirements.txt # 复制模型 COPY models/ /app/models/ COPY server.py /app/ WORKDIR /app # 优化启动 ENV PYTHONUNBUFFERED=1 EXPOSE 8000 CMD ["gunicorn", "--bind", "0.0.0.0:8000", \ "--workers", "4", "--threads", "2", \ "--timeout", "120", "server:app"]

Jupyter Notebook镜像

FROM jupyter/datascience-notebook:latest USER root # 安装CUDA依赖（如有GPU） RUN conda install -c nvidia -c pytorch cudatoolkit=11.8 pytorch torchvision torchaudio # 安装常用包 RUN pip install --no-cache-dir \ transformers \ datasets \ accelerate \ wandb \ opencv-python-headless \ matplotlib # 设置工作目录 WORKDIR /workspace # 启动Jupyter CMD ["start-notebook.sh", \ "--NotebookApp.token=''", \ "--NotebookApp.password=''"]

⚙️ 构建优化技巧

层缓存优化

# ✅ 好的做法：利用层缓存 FROM python:3.10-slim # 先复制依赖文件 COPY requirements.txt /tmp/ RUN pip install -r /tmp/requirements.txt # 再复制代码（代码变化不会触发依赖重新安装） COPY . /app/ # ❌ 坏的做法：每次代码变化都会重新安装依赖 COPY . /app/ RUN pip install -r requirements.txt

减少镜像大小

# 清理APT缓存 RUN apt-get update && apt-get install -y package && \ rm -rf /var/lib/apt/lists/* # 清理Pip缓存 RUN pip install --no-cache-dir package # 合并RUN命令 RUN apt-get update && \ apt-get install -y package1 package2 package3 && \ rm -rf /var/lib/apt/lists/* # 使用.dockerignore # .dockerignore文件 .git/ .gitignore Dockerfile README.md __pycache__/ *.pyc .env test/

安全扫描

# 使用Trivy扫描镜像 docker build -t myapp:latest . trivy image myapp:latest # 使用Docker Scout docker scout cves myapp:latest # 构建时扫描（在CI/CD中） trivy image --exit-code 1 --severity HIGH,CRITICAL myapp:latest

🚀 高级构建技术

BuildKit加速构建

# 启用BuildKit export DOCKER_BUILDKIT=1 # 使用BuildKit特性 # syntax=docker/dockerfile:1 FROM python:3.10 # 并行构建 RUN --mount=type=cache,target=/root/.cache/pip \ pip install package1 # 远程缓存 docker build \ --cache-from type=registry,ref=myapp:cache \ --cache-to type=registry,ref=myapp:cache \ -t myapp:latest .

交叉编译

# 针对不同架构构建 docker buildx build --platform linux/amd64,linux/arm64 -t myapp:latest . # 指定目标架构 docker buildx build --platform linux/arm64 -t myapp:arm64 .

自定义Base镜像

# 创建自定义基础镜像 FROM nvidia/cuda:11.8.0-cudnn8-runtime-ubuntu22.04 AS base # 预装常用依赖 RUN apt-get update && apt-get install -y \ python3.10 \ python3-pip \ libgomp1 \ libsm6 \ libxext6 \ libxrender-dev \ && rm -rf /var/lib/apt/lists/* # 预装Python包 RUN pip3 install --no-cache-dir \ numpy==1.24.3 \ torch==2.0.0 # 设置环境变量 ENV PYTHONUNBUFFERED=1 \ CUDA_VISIBLE_DEVICES=0

📊 镜像管理

标签策略

# 语义化版本标签 docker build -t myapp:1.0.0 . docker tag myapp:1.0.0 myapp:latest # Git commit标签 docker build -t myapp:$(git rev-parse --short HEAD) . # 时间戳标签 docker build -t myapp:$(date +%Y%m%d) . # 多架构标签 docker buildx build --platform linux/amd64 -t myapp:amd64 . docker buildx build --platform linux/arm64 -t myapp:arm64 . docker manifest create myapp:latest myapp:amd64 myapp:arm64

镜像扫描与验证

# 完整扫描流程 echo "Building image..." docker build -t myapp:latest . echo "Scanning for vulnerabilities..." trivy image --severity HIGH,CRITICAL myapp:latest echo "Checking image size..." docker images myapp:latest echo "Testing image..." docker run --rm myapp:latest python -c "import torch; print(torch.__version__)"
✅
最佳实践总结

  • • 实施镜像安全扫描
  • • 使用标签进行版本管理
  • • 编写.dockerignore排除不必要文件
