⚡ 中断系统概述

💡
中断的定义

中断是一种机制，允许外部设备或内部模块在需要时暂停当前程序的执行，转而处理紧急事件。处理完成后，再返回原程序继续执行。

中断的优点：提高系统响应速度、实现多任务处理、降低CPU轮询开销。

中断与轮询的对比

特性 中断方式 轮询方式
响应速度 快（微秒级） 慢（取决于轮询周期）
CPU开销 事件触发时产生 持续占用CPU
实现复杂度 较复杂 简单
适用场景 异步事件、实时系统 同步事件、简单系统

中断控制器示例（简化版）

module interrupt_controller (
    input  clk,
    input  rst_n,
    input  [31:0] irq_in,      // 32个中断输入
    input  [31:0] irq_mask,    // 中断屏蔽
    input  [31:0] irq_priority, // 中断优先级
    input  irq_ack,            // 中断确认
    output reg   irq_out,      // 中断输出
    output reg [4:0] irq_vector // 中断向量
);

reg [31:0] irq_pending;

// 边沿检测
reg [31:0] irq_in_d1, irq_in_d2;
always @(posedge clk or negedge rst_n) begin
    if (!rst_n) begin
        irq_in_d1 <= 0;
        irq_in_d2 <= 0;
    end else begin
        irq_in_d1 <= irq_in;
        irq_in_d2 <= irq_in_d1;
    end
end

// 上升沿检测
wire [31:0] irq_edge = irq_in_d1 & ~irq_in_d2;

// 挂起中断更新
always @(posedge clk or negedge rst_n) begin
    if (!rst_n) begin
        irq_pending <= 0;
    end else begin
        irq_pending <= (irq_pending | irq_edge) & ~irq_mask;
    end
end

// 优先级编码（简化）
always @(*) begin
    irq_out = 0;
    irq_vector = 0;
    if (|irq_pending) begin
        // 查找最高优先级的挂起中断
        for (int i = 31; i >= 0; i--) begin
            if (irq_pending[i]) begin
                irq_out = 1;
                irq_vector = i;
                break;
            end
        end
    end
end

// 中断确认
always @(posedge clk or negedge rst_n) begin
    if (!rst_n) begin
        // no action
    end else if (irq_ack) begin
        irq_pending[irq_vector] <= 0;
    end
end

endmodule

🏆 ARM GIC中断控制器

GIC架构概述

ARM Generic Interrupt Controller（GIC）是ARM架构的标准中断控制器，支持多核处理器的中断分发和优先级管理。

GIC版本演进

版本 特点 支持的处理器
GICv1 基础功能，支持多核 Cortex-A7/A9
GICv2 增加虚拟化支持 Cortex-A15/A17
GICv3 支持Message Signaled Interrupts（MSI） Cortex-A53/A57/A72
GICv4 增强虚拟化，支持直接注入 Cortex-A76/A78

GIC中断类型

SGI（软件生成中断）

ID: 0-15

用于核间通信，由软件通过寄存器写入触发。

PPI（私有外设中断）

ID: 16-31

每个CPU私有的外设中断，如本地定时器。

SPI（共享外设中断）

ID: 32-1019

多个CPU共享的外设中断，可路由到任意CPU。

🔄 中断处理流程

外设产生中断信号
↓
中断控制器接收并同步
↓
中断挂起（Pending）
↓
优先级仲裁
↓
向CPU发送中断请求
↓
CPU响应中断
↓
执行中断服务程序（ISR）
↓
中断完成确认

🎚️ 中断优先级与嵌套

优先级设计原则

高优先级中断

  • 系统定时器
  • 看门狗中断
  • 电源管理中断
  • 安全相关中断

中优先级中断

  • 网络数据包
  • 存储操作完成
  • 音频数据
  • 关键传感器

低优先级中断

  • GPIO输入
  • 低速外设
  • 用户接口
  • 非关键任务

优先级分配原则

  • 实时性要求高的优先级高
  • 处理时间短的优先级高
  • 避免优先级反转
  • 合理设置优先级阈值

中断嵌套

中断嵌套允许高优先级中断打断低优先级中断的处理。需要保存上下文，正确管理堆栈。

// 中断嵌套示例
void __attribute__((interrupt("IRQ"))) IRQ_Handler(void) {
    uint32_t irq_id = GIC_GetIRQID();

    switch (irq_id) {
        case TIMER_IRQ:
            // 允许更高优先级中断
            __enable_irq();
            Timer_Handler();
            __disable_irq();
            break;

        case UART_IRQ:
            // 不允许中断嵌套
            UART_Handler();
            break;
    }

    GIC_EndInterrupt(irq_id);
}
