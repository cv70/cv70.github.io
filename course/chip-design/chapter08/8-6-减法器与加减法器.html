8.6 减法器与加减法器

减法器概述

在数字系统中，减法通常不直接实现，而是通过补码运算将减法转换为加法。这种方法简化了硬件设计，使得同一套加法器电路可以同时处理加法和减法运算。

💡 半减器与全减器

半减器（Half Subtractor）

实现两个1位二进制数的减法。

输入：A（被减数）, B（减数）

输出：D（差）, Bo（借位）

ABDBo
0000
0111
1010
1100

逻辑表达式：D = A ⊕ B, Bo = A'·B

全减器（Full Subtractor）

考虑低位借位的减法。

输入：A, B, Bin（低位借位）

输出：D, Bout

逻辑表达式：

  • D = A ⊕ B ⊕ Bin
  • Bout = A'·B + A'·Bin + B·Bin

🔧 补码减法器

补码减法原理

A - B = A + (-B) = A + B的补码

B的补码 = B的反码 + 1

💡
实现方法

n位补码减法器 = n位加法器 + n个反相器 + 进位输入设为1
步骤：
1. 对减数B取反（按位取反）
2. 加法器最低位进位输入设为1
3. 执行加法运算 A + B' + 1

示例：5 - 3（4位运算）

⚡ 加减法器（Adder-Subtractor）

可控加减法器

通过控制信号选择执行加法或减法运算，复用同一套硬件电路。

电路结构

  • 一个n位加法器
  • n个异或门（控制B是否取反）
  • 控制信号Sub

异或门作用：

  • Sub=0：B ⊕ 0 = B（加法）
  • Sub=1：B ⊕ 1 = B'（减法）

工作模式

Sub操作计算
0加法A + B + 0
1减法A + B' + 1

Sub信号同时连接到：

  • 每个异或门的一个输入
  • 加法器的进位输入C0

📊 溢出检测

溢出定义

运算结果超出了n位有符号数的表示范围，称为溢出。

n位有符号数范围：-2^(n-1) 到 2^(n-1)-1

⚠️
溢出检测方法

方法一：最高位进位输入 ≠ 最高位进位输出
Overflow = Cin(n-1) ⊕ Cout(n-1)

方法二：正数相加得负数，或负数相加得正数
Overflow = A(n-1)·B(n-1)·S'(n-1) + A'(n-1)·B'(n-1)·S(n-1)

示例：溢出情况（4位）

5 + 6 = 11，但4位有符号数最大值为7
