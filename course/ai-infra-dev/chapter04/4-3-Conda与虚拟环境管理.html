虚拟环境概述

Python虚拟环境允许在隔离的环境中安装不同版本的包和依赖，解决了版本冲突问题。Conda是流行的包和环境管理器，特别适合科学计算和AI开发。

🔧 Conda安装

安装步骤

安装Miniconda： # Linux/Mac wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh bash Miniconda3-latest-Linux-x86_64.sh # 安装过程 # - 按ENTER查看许可协议 # - 输入yes同意许可 # - 按ENTER使用默认安装路径 # - 输入yes将conda初始化到shell # 重新加载shell source ~/.bashrc # 验证安装 conda --version 配置Conda： # 添加频道（清华镜像，加速下载） conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/free/ conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/main/ conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/cloud/conda-forge/ conda config --set show_channel_urls yes # 更新conda conda update conda conda update --all

📦 Conda环境管理

常用命令

环境管理命令： # 创建环境 conda create -n ai-env python=3.10 conda create -n pytorch-env python=3.9 pytorch torchvision torchaudio cudatoolkit=11.8 # 列出环境 conda env list conda info --envs # 激活/停用环境 conda activate ai-env conda deactivate # 克隆环境 conda create --name new-env --clone old-env # 删除环境 conda remove -n ai-env --all # 导出/导入环境 conda env export > environment.yml conda env create -f environment.yml
包管理命令： # 安装包 conda install numpy pandas matplotlib conda install pytorch torchvision torchaudio -c pytorch # 安装特定版本 conda install numpy=1.24.0 conda install pytorch==2.0.0 torchvision==0.15.0 -c pytorch # 从conda-forge安装 conda install -c conda-forge jupyterlab # 使用pip安装 pip install transformers pip install -r requirements.txt # 列出已安装包 conda list pip list # 更新包 conda update numpy conda update --all # 删除包 conda remove numpy

📝 Environment文件

环境配置文件

environment.yml示例： name: ai-env channels: - pytorch - conda-forge - defaults dependencies: - python=3.10 - pytorch=2.0.0 - torchvision=0.15.0 - torchaudio=2.0.0 - cudatoolkit=11.8 - numpy - pandas - matplotlib - scikit-learn - jupyterlab - pip - pip: - transformers - datasets - accelerate - peft - bitsandbytes - wandb - tensorboard # 创建环境 conda env create -f environment.yml # 更新环境 conda env update -f environment.yml --prune

⚡ Mamba

更快的包管理器

Mamba是Conda的C++重写版本，显著提升了包解析和安装速度：

安装和使用Mamba： # 安装Mamba conda install -c conda-forge mamba # 使用Mamba替代conda命令 mamba create -n ai-env python=3.10 mamba install pytorch torchvision torchaudio -c pytorch mamba env update -f environment.yml # Micromamba（更轻量） # 下载并运行micromamba wget https://github.com/mamba-org/micromamba-releases/releases/download/1.4.0/micromamba-linux-64 chmod +x micromamba-linux-64 # 创建环境 ./micromamba-linux-64 create -n ai-env python=3.10
✅
优势

Mamba比conda快5-10倍，特别适合需要频繁创建和更新环境的场景。

🛠️ 环境优化

最佳实践

环境配置

  • 为每个项目创建独立环境
  • 使用明确的版本号
  • 定期更新依赖
  • 清理无用包

性能优化

  • 使用国内镜像
  • 预编译包优先
  • 并行下载
  • 缓存下载文件
清理命令： # 清理未使用的包 conda clean --all # 清理缓存 conda clean --tarballs # 查看环境大小 du -sh ~/miniconda3/envs/*

🔍 常见问题

⚠️
问题排查
  • 环境激活失败：检查shell配置
  • 包安装失败：切换频道或使用pip
  • 版本冲突：使用conda-forge频道
  • 性能问题：切换到mamba
