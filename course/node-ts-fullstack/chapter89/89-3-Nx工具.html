📚 Nx 简介

Nx 是一个智能构建系统，提供了强大的代码生成、依赖分析和增量构建能力。

# 创建 Nx 项目 npx create-nx-workspace@latest my-workspace # 选择预设 ? Which stack do you want to use? React Vue Angular Node ... # 目录结构 my-workspace/ ├── apps/ # 应用 │ ├── web/ │ └── api/ ├── libs/ # 库 │ ├── ui/ │ └── utils/ ├── nx.json # Nx 配置 ├── workspace.json # 工作区配置 ├── package.json └── tsconfig.base.json # 核心特性 1. 代码生成器 - 快速创建项目结构 2. 依赖图 - 可视化项目依赖关系 3. 增量构建 - 只构建受影响的项目 4. 分布式缓存 - 云端缓存构建结果 5. 代码约束 - 强制执行代码规范

🔧 代码生成器

# 安装插件 npm install -D @nx/react @nx/node @nx/express # 生成应用 npx nx g @nx/react:app web npx nx g @nx/node:app api # 生成库 npx nx g @nx/react:lib ui npx nx g @nx/node:lib utils # 生成组件 npx nx g @nx/react:component Button --project=ui # 生成服务 npx nx g @nx/node:service User --project=api # 查看可用生成器 npx nx list npx nx list @nx/react # 常用选项 npx nx g @nx/react:app web \ --directory=apps/web \ --style=scss \ --routing=true \ --unitTestRunner=jest \ --e2eTestRunner=cypress # 干运行（预览不执行） npx nx g @nx/react:component Card --dry-run
💡
代码生成优势

使用代码生成器可以保持项目结构一致性，减少重复工作，确保最佳实践。

⚙️ 构建和测试

# 运行应用 npx nx serve web npx nx serve api # 构建项目 npx nx build web npx nx build api # 运行测试 npx nx test web npx nx test utils # 运行 E2E 测试 npx nx e2e web-e2e # 代码检查 npx nx lint web # 运行所有受影响项目的任务 npx nx affected -t build npx nx affected -t test # 并行运行 npx nx run-many -t build --all --parallel=4 # 指定配置 npx nx build web --configuration=production # nx.json 配置 { "targetDefaults": { "build": { "dependsOn": ["^build"], "outputs": ["{projectRoot}/dist"], "cache": true }, "test": { "dependsOn": ["build"] } } }

🚀 依赖图和缓存

# 查看依赖图 npx nx graph # 浏览器打开交互式依赖图 # 可视化展示： # - 应用之间的依赖 # - 库之间的依赖 # - 项目结构 # 命令行查看依赖 npx nx dep-graph # 查看受影响的项目 npx nx affected:graph # Nx 缓存配置 # nx.json { "tasksRunnerOptions": { "default": { "runner": "nx/tasks-runners/default", "options": { "cacheableOperations": ["build", "test", "lint"], "parallel": 3 } } } } # 清除缓存 npx nx reset # 分布式缓存（Nx Cloud） # nx.json { "nxCloudAccessToken": "YOUR_ACCESS_TOKEN", "tasksRunnerOptions": { "default": { "runner": "nx-cloud", "options": { "cacheableOperations": ["build", "test", "lint"], "accessToken": "YOUR_ACCESS_TOKEN" } } } } # 启用 Nx Cloud npx nx connect-to-nx-cloud

📊 项目配置

// project.json { "name": "web", "$schema": "../node_modules/nx/schemas/project-schema.json", "sourceRoot": "apps/web/src", "projectType": "application", "targets": { "build": { "executor": "@nx/vite:build", "outputs": ["{workspaceRoot}/dist/apps/web"], "options": { "outputPath": "dist/apps/web" } }, "serve": { "executor": "@nx/vite:dev-server", "options": { "buildTarget": "web:build" } }, "test": { "executor": "@nx/jest:jest", "outputs": ["{workspaceRoot}/coverage/apps/web"], "options": { "jestConfig": "apps/web/jest.config.ts" } } }, "tags": ["type:app", "scope:frontend"] } # 使用标签组织项目 # libs/ui/project.json { "tags": ["type:lib", "scope:shared"] } # 依赖约束 // nx.json { "enforceModuleBoundary": true, "depConstraints": [ { "sourceTag": "scope:frontend", "onlyDependOnLibsWithTags": ["scope:shared"] } ] }
