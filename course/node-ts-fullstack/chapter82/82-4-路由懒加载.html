82.4 路由懒加载

优化应用加载性能

📖 本节概述

路由懒加载是一种将路由对应的组件分割成不同的代码块，然后在路由被访问时才加载对应组件的技术。这可以显著提高首屏加载速度，优化用户体验。

🎯 学习目标

  • 理解路由懒加载的原理和好处
  • 掌握动态导入的语法
  • 学会使用命名 chunk 和分组
  • 了解预加载和预取策略

📦 静态导入 vs 动态导入

静态导入（不推荐）

// 静态导入 - 所有组件打包在一起 import Home from '@/views/Home.vue'; import About from '@/views/About.vue'; import Users from '@/views/Users.vue'; const routes = [ { path: '/', component: Home }, { path: '/about', component: About }, { path: '/users', component: Users } ]; // 问题： // 1. 首次加载时下载所有组件代码 // 2. 首屏加载时间长 // 3. 用户可能不会访问所有页面

动态导入（推荐）

// 动态导入 - 按需加载 const routes = [ { path: '/', component: () => import('@/views/Home.vue') }, { path: '/about', component: () => import('@/views/About.vue') }, { path: '/users', component: () => import('@/views/Users.vue') } ]; // 优点： // 1. 每个路由生成独立的代码块 // 2. 首屏只加载需要的代码 // 3. 减少首屏加载时间

🏷️ 命名 Chunk

使用 webpack 的魔法注释可以为 chunk 命名。

const routes = [ { path: '/', component: () => import( /* webpackChunkName: "home" */ '@/views/Home.vue' ) }, { path: '/about', component: () => import( /* webpackChunkName: "about" */ '@/views/About.vue' ) }, { path: '/users', component: () => import( /* webpackChunkName: "users" */ '@/views/Users.vue' ) } ];

Vite 的命名方式

// Vite 使用不同的语法 const routes = [ { path: '/', component: () => import( /* @vite-ignore */ '/src/views/Home.vue' ) } ]; // 或者使用 vite-plugin-pages 插件自动生成路由

📂 分组打包

将相关的路由打包到同一个 chunk 中。

const routes = [ // 用户相关页面打包在一起 { path: '/users', component: () => import( /* webpackChunkName: "user" */ '@/views/Users.vue' ), children: [ { path: ':id', component: () => import( /* webpackChunkName: "user" */ '@/views/UserDetail.vue' ) }, { path: 'profile', component: () => import( /* webpackChunkName: "user" */ '@/views/UserProfile.vue' ) } ] }, // 管理后台页面打包在一起 { path: '/admin', component: () => import( /* webpackChunkName: "admin" */ '@/views/Admin.vue' ), children: [ { path: 'users', component: () => import( /* webpackChunkName: "admin" */ '@/views/AdminUsers.vue' ) }, { path: 'settings', component: () => import( /* webpackChunkName: "admin" */ '@/views/AdminSettings.vue' ) } ] } ];

⚡ 预加载策略

webpack 预取

// 预取（Prefetch）- 空闲时加载 const routes = [ { path: '/about', component: () => import( /* webpackPrefetch: true */ /* webpackChunkName: "about" */ '@/views/About.vue' ) } ]; // 预加载（Preload）- 立即加载 const routes = [ { path: '/', component: () => import( /* webpackPreload: true */ '@/views/Home.vue' ) } ];

Vue Router 的预加载

// 使用 onBeforeRouteLeave 预加载下一个可能访问的页面 import { onBeforeRouteLeave } from 'vue-router'; // 在 Home 组件中 onBeforeRouteLeave((to, from, next) => { if (to.name === 'About') { // 预加载 About 组件 import('@/views/About.vue'); } next(); });

🔄 加载状态处理

全局加载指示器

// router/index.ts import { createRouter } from 'vue-router'; import { useLoadingStore } from '@/stores/loading'; const router = createRouter({ /* ... */ }); router.beforeEach(() => { useLoadingStore().startLoading(); }); router.afterEach(() => { useLoadingStore().stopLoading(); });

Suspense 配合异步组件

// 定义异步组件 const AsyncHome = defineAsyncComponent({ loader: () => import('@/views/Home.vue'), loadingComponent: LoadingSpinner, errorComponent: ErrorComponent, delay: 200, timeout: 10000 }); // 在模板中使用 Suspense <template> <router-view v-slot="{ Component }"> <Suspense> <template #default> <component :is="Component" /> </template> <template #fallback> <LoadingSpinner /> </template> </Suspense> </router-view> </template>

💡 最佳实践

  • 首屏必需的组件使用静态导入
  • 其他页面使用动态导入按需加载
  • 相关页面分组打包减少请求数
  • 高频访问的页面使用预取策略
  • 配置加载状态提升用户体验
// 推荐的路由配置结构 const routes = [ // 首页 - 静态导入或预加载 { path: '/', name: 'Home', component: () => import( /* webpackChunkName: "home" */ /* webpackPreload: true */ '@/views/Home.vue' ) }, // 常规页面 - 动态导入 { path: '/about', name: 'About', component: () => import( /* webpackChunkName: "about" */ '@/views/About.vue' ) }, // 管理后台 - 分组打包 { path: '/admin', name: 'Admin', component: () => import( /* webpackChunkName: "admin-group" */ '@/views/admin/Admin.vue' ), children: [ { path: 'users', component: () => import( /* webpackChunkName: "admin-group" */ '@/views/admin/Users.vue' ) } ] }, // 404 页面 { path: '/:pathMatch(.*)*', name: 'NotFound', component: () => import( /* webpackChunkName: "error" */ '@/views/NotFound.vue' ) } ];

📝 本节小结

  • 路由懒加载使用动态 import() 语法
  • 命名 chunk 便于调试和分析
  • 分组打包减少请求数量
  • 预取策略优化用户体验
  • 配合 Suspense 处理加载状态
