📌 Python版本选择

💡
推荐版本

AI开发建议使用 Python 3.9 - 3.11，这些版本与主流AI库兼容性最好。Python 3.12+ 部分库可能尚未完全支持。

版本 状态 推荐度 说明
Python 3.8 维护中 可用 即将停止维护
Python 3.9 维护中 推荐 稳定，兼容性好
Python 3.10 维护中 推荐 新特性，稳定
Python 3.11 维护中 推荐 性能优化显著
Python 3.12+ 最新 谨慎 部分库兼容性问题

⬇️ Python安装方法

方法一：官网安装包

# Windows 1. 访问 python.org/downloads 2. 下载对应版本安装包 3. 勾选 "Add Python to PATH" 4. 点击 Install Now # macOS 1. 下载 .pkg 安装包 2. 双击运行安装程序 3. 按提示完成安装

适合 初学者，操作简单

方法二：Anaconda

# 下载地址 https://www.anaconda.com/download # 安装后创建环境 conda create -n ai python=3.10 conda activate ai # 安装常用库 conda install numpy pandas matplotlib

推荐 AI开发首选，预装科学计算库

🔧 环境变量配置

Windows系统

# 检查环境变量是否配置正确 python --version pip --version # 如果提示找不到命令，手动添加环境变量 # 1. 右键"此电脑" → 属性 → 高级系统设置 # 2. 环境变量 → 系统变量 → Path → 编辑 # 3. 添加以下路径（根据实际安装路径调整）： # C:\Users\YourName\AppData\Local\Programs\Python\Python310\ # C:\Users\YourName\AppData\Local\Programs\Python\Python310\Scripts\

macOS/Linux系统

# 编辑 shell 配置文件 nano ~/.bash_profile # 或 ~/.zshrc # 添加以下内容 export PATH="/usr/local/bin/python3:$PATH" export PATH="/usr/local/bin/pip3:$PATH" # 使配置生效 source ~/.bash_profile

✅ 验证安装

# 检查 Python 版本 $ python --version Python 3.10.12 # 检查 pip 版本 $ pip --version pip 23.2.1 from ... (python 3.10) # 进入 Python 交互模式 $ python >>> print("Hello, AI!") Hello, AI! >>> import sys >>> print(sys.version) 3.10.12 ... >>> exit() # 退出
⚠️
常见问题

python命令不存在：Windows上可能需要使用 python 或 py，macOS/Linux可能需要使用 python3。

pip命令不存在：使用 python -m pip 替代，或重新安装pip：python -m ensurepip

📦 pip包管理基础

# 安装包 pip install numpy # 安装指定版本 pip install numpy==1.24.0 # 升级包 pip install --upgrade numpy # 卸载包 pip uninstall numpy # 查看已安装的包 pip list # 导出依赖 pip freeze > requirements.txt # 安装依赖 pip install -r requirements.txt
