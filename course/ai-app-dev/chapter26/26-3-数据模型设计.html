📊 核心数据模型

# 用户模型 User: id, email, created_at # 对话模型 Conversation: id, user_id, title, created_at # 消息模型 Message: id, conversation_id, role, content, created_at # 文档模型 Document: id, title, content, embedding_id, metadata
