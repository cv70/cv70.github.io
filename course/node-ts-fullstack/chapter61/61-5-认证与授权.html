61.5 认证与授权

GraphQL 认证授权实现

📖 认证 vs 授权

认证（Authentication）

验证用户身份，确认"你是谁"

  • 用户名密码登录
  • Token 验证
  • OAuth 第三方登录

授权（Authorization）

验证用户权限，确认"你能做什么"

  • 角色权限控制
  • 资源访问控制
  • 操作权限检查

🔐 Context 认证

import { verify } from 'jsonwebtoken'; interface UserPayload { id: number; email: string; role: 'USER' | 'ADMIN'; } interface Context { user: UserPayload | null; prisma: PrismaClient; } // 解析 Token function parseToken(authHeader: string | undefined): UserPayload | null { if (!authHeader?.startsWith('Bearer ')) { return null; } const token = authHeader.slice(7); try { return verify(token, process.env.JWT_SECRET!) as UserPayload; } catch { return null; } } // Apollo Server 配置 const server = new ApolloServer({ typeDefs, resolvers }); await startStandaloneServer(server, { context: async ({ req }) => ({ user: parseToken(req.headers.authorization), prisma, }), });

🔒 Resolver 级别认证

const resolvers = { Query: { // 公开接口 publicPosts: async (_, __, context) => { return context.prisma.post.findMany({ where: { published: true }, }); }, // 需要登录 myPosts: async (_, __, context) => { if (!context.user) { throw new AuthenticationError('请先登录'); } return context.prisma.post.findMany({ where: { authorId: context.user.id }, }); }, // 需要管理员权限 allUsers: async (_, __, context) => { if (!context.user || context.user.role !== 'ADMIN') { throw new ForbiddenError('需要管理员权限'); } return context.prisma.user.findMany(); }, }, Mutation: { // 创建文章 - 需要登录 createPost: async (_, { title, content }, context) => { if (!context.user) { throw new AuthenticationError('请先登录'); } return context.prisma.post.create({ data: { title, content, authorId: context.user.id, }, }); }, // 删除用户 - 需要管理员权限 deleteUser: async (_, { id }, context) => { if (!context.user || context.user.role !== 'ADMIN') { throw new ForbiddenError('需要管理员权限'); } await context.prisma.user.delete({ where: { id: parseInt(id) } }); return true; }, }, };

🎯 自定义认证指令

// Schema directive @auth(requires: Role = USER) on FIELD_DEFINITION | OBJECT enum Role { USER ADMIN SUPER_ADMIN } type Query { publicData: String! userData: User! @auth adminData: AdminData! @auth(requires: ADMIN) } type Mutation { deleteUser(id: ID!): Boolean! @auth(requires: ADMIN) } // 指令实现 import { SchemaDirectiveVisitor, AuthenticationError, ForbiddenError } from 'apollo-server'; import { GraphQLField, defaultFieldResolver } from 'graphql'; class AuthDirective extends SchemaDirectiveVisitor { visitFieldDefinition(field: GraphQLField<any, any>) { const { resolve = defaultFieldResolver } = field; const { requires } = this.args; field.resolve = async function (root, args, context, info) { // 检查是否登录 if (!context.user) { throw new AuthenticationError('请先登录'); } // 检查权限 const roles = ['USER', 'ADMIN', 'SUPER_ADMIN']; const userLevel = roles.indexOf(context.user.role); const requiredLevel = roles.indexOf(requires); if (userLevel < requiredLevel) { throw new ForbiddenError(`需要 ${requires} 权限`); } return resolve.call(this, root, args, context, info); }; } visitObject(type: any) { const fields = type.getFields(); for (const field of Object.values(fields)) { this.visitFieldDefinition(field as GraphQLField<any, any>); } } } // Apollo Server 配置 const server = new ApolloServer({ typeDefs, resolvers, schemaDirectives: { auth: AuthDirective, }, });

📊 资源级权限控制

const resolvers = { Mutation: { // 更新文章 - 只能更新自己的文章 updatePost: async (_, { id, input }, context) => { if (!context.user) { throw new AuthenticationError('请先登录'); } const post = await context.prisma.post.findUnique({ where: { id: parseInt(id) }, }); if (!post) { throw new UserInputError('文章不存在'); } // 检查是否是作者或管理员 if (post.authorId !== context.user.id && context.user.role !== 'ADMIN') { throw new ForbiddenError('无权修改此文章'); } return context.prisma.post.update({ where: { id: parseInt(id) }, data: input, }); }, // 删除文章 - 作者或管理员可删除 deletePost: async (_, { id }, context) => { if (!context.user) { throw new AuthenticationError('请先登录'); } const post = await context.prisma.post.findUnique({ where: { id: parseInt(id) }, select: { authorId: true }, }); if (!post) { throw new UserInputError('文章不存在'); } if (post.authorId !== context.user.id && context.user.role !== 'ADMIN') { throw new ForbiddenError('无权删除此文章'); } await context.prisma.post.delete({ where: { id: parseInt(id) } }); return true; }, }, };

📝 小结

  • 认证验证用户身份，授权验证用户权限
  • 在 Context 中解析和存储用户信息
  • Resolver 级别进行权限检查
  • 自定义指令简化认证代码
  • 资源级权限控制确保数据安全
  • 区分公开接口和需要认证的接口
