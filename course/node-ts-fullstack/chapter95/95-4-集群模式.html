95.4 集群模式

利用多核 CPU 提升性能

📚 为什么需要集群

# Node.js 单线程限制 ## 问题 - 单线程只能利用一个 CPU 核心 - 现代 CPU 通常有 4-16+ 核心 - 单进程无法充分利用硬件资源 ## 解决方案 - 运行多个进程实例 - 负载均衡分发请求 - 每个进程独立事件循环 # 集群架构 负载均衡 │ ┌──────────────────┼──────────────────┐ │ │ │ ┌───┴───┐ ┌───┴───┐ ┌───┴───┐ │Worker1│ │Worker2│ │Worker3│ │Port │ │Port │ │Port │ │ 3000 │ │ 3000 │ │ 3000 │ └───────┘ └───────┘ └───────┘ # 集群优势 - 利用多核 CPU - 提高吞吐量 - 容错能力（进程崩溃不影响其他） - 零停机重启 # 集群注意事项 - 内存不共享，各自独立 - 需要处理进程间通信 - Session 需要外部存储 - 文件锁需要处理

🔧 Cluster 模块

# 使用 Node.js Cluster 模块 import cluster from 'cluster'; import os from 'os'; import http from 'http'; const numCPUs = os.cpus().length; if (cluster.isPrimary) { console.log(`Primary ${process.pid} is running`); // Fork workers for (let i = 0; i < numCPUs; i++) { cluster.fork(); } // Worker 退出时重启 cluster.on('exit', (worker, code, signal) => { console.log(`Worker ${worker.process.pid} died`); cluster.fork(); // 启动新 worker }); } else { // Worker 进程创建 HTTP 服务器 http.createServer((req, res) => { res.writeHead(200); res.end('Hello from worker ' + process.pid); }).listen(3000); console.log(`Worker ${process.pid} started`); } # 更完整的实现 import cluster from 'cluster'; import os from 'os'; interface WorkerEnv { PORT: string; NODE_ENV: string; } const setupWorkerProcesses = () => { const numCores = os.cpus().length; for (let i = 0; i < numCores; i++) { cluster.fork(); } cluster.on('online', (worker) => { console.log(`Worker ${worker.process.pid} is online`); }); cluster.on('exit', (worker, code, signal) => { console.log(`Worker ${worker.process.pid} died with code ${code}`); console.log('Starting new worker...'); cluster.fork(); }); }; if (cluster.isPrimary) { setupWorkerProcesses(); } else { require('./app'); // 启动应用 }
💡
负载均衡

Node.js 集群使用 round-robin 算法分发请求，确保每个 worker 均匀处理请求。

⚙️ PM2 集群模式

# 安装 PM2 npm install -g pm2 # 启动集群模式 pm2 start app.js -i max # 使用所有 CPU 核心 pm2 start app.js -i 4 # 启动 4 个实例 pm2 start app.js -i 0 # 自动检测 CPU 核心数 # PM2 配置文件 // ecosystem.config.js module.exports = { apps: [{ name: 'my-app', script: 'dist/index.js', instances: 'max', exec_mode: 'cluster', autorestart: true, watch: false, max_memory_restart: '1G', env: { NODE_ENV: 'production', PORT: 3000, }, env_development: { NODE_ENV: 'development', }, }], }; # PM2 常用命令 pm2 start # 启动应用 pm2 stop all # 停止所有 pm2 restart all # 重启所有 pm2 reload all # 无停机重启 pm2 delete all # 删除所有 pm2 list # 列出所有进程 pm2 monit # 监控面板 pm2 logs # 查看日志 pm2 show <app-name> # 查看详情 # 零停机重启 pm2 reload all # 监控 pm2 monit # 或使用 PM2 Plus # https://app.pm2.io
