18.5 代码风格与可读性

HDL 编码最佳实践

🎯 学习目标

  • 掌握命名规范
  • 理解代码缩进和格式
  • 学会添加有意义的注释
  • 能够编写清晰易读的代码

📝 命名规范

// ✅ 好的命名
module uart_controller(...);
reg [7:0] data_buffer;
wire tx_valid;
parameter CLK_FREQ = 50_000_000;

// ❌ 不好的命名
module uc(...);
reg [7:0] d;
wire v;
parameter F = 50_000_000;

📐 代码格式

// 一致的缩进和对齐
always @(posedge clk or negedge rst_n) begin
    if (!rst_n) begin
        data_out <= 8'd0;
        valid    <= 1'b0;
    end
    else begin
        data_out <= data_in;
        valid    <= 1'b1;
    end
end

📝 本节小结

✅
  • • 使用有意义的名称
  • • 保持一致的格式
  • • 添加必要的注释
  • • 提高代码可维护性
