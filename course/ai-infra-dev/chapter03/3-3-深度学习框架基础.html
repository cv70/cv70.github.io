深度学习框架概述

深度学习框架是构建和训练神经网络的工具，提供了高级API、自动微分、优化器等核心功能。PyTorch、TensorFlow和JAX是当前最主流的三个框架，各有特点和适用场景。

🔥 PyTorch

动态图与易用性

PyTorch以其动态计算图和Pythonic的API设计深受研究者和开发者喜爱：

核心特性

  • 动态计算图
  • 自动微分
  • 丰富的算子库
  • 活跃的社区

生态系统

  • PyTorch Lightning - 高级训练接口
  • Hugging Face Transformers - 预训练模型
  • TorchVision - 计算机视觉
  • PyTorch Geometric - 图神经网络
PyTorch基础示例： import torch import torch.nn as nn # 定义模型 class SimpleModel(nn.Module): def __init__(self): super().__init__() self.linear = nn.Linear(784, 10) def forward(self, x): return self.linear(x) model = SimpleModel().cuda() criterion = nn.CrossEntropyLoss() optimizer = torch.optim.Adam(model.parameters(), lr=0.001) # 训练循环 for epoch in range(10): for data, target in dataloader: data, target = data.cuda(), target.cuda() # 前向传播 output = model(data) loss = criterion(output, target) # 反向传播 optimizer.zero_grad() loss.backward() optimizer.step()

🌊 TensorFlow

生产级框架

TensorFlow是Google开发的深度学习框架，以其稳定性和生产部署能力著称：

核心特性

  • 静态图优化
  • XLA编译器
  • Keras高级API
  • TensorBoard可视化

生态系统

  • TensorFlow Serving - 推理服务
  • TensorFlow Lite - 移动端
  • TFX - MLOps平台
  • TPU支持
TensorFlow基础示例： import tensorflow as tf # 定义模型 model = tf.keras.Sequential([ tf.keras.layers.Dense(128, activation='relu'), tf.keras.layers.Dense(10) ]) # 编译模型 model.compile( optimizer='adam', loss=tf.keras.losses.SparseCategoricalCrossentropy(from_logits=True), metrics=['accuracy'] ) # 训练模型 model.fit( train_dataset, epochs=10, validation_data=val_dataset ) # 评估模型 test_loss, test_acc = model.evaluate(test_dataset)

⚡ JAX

函数式编程与自动微分

JAX是Google开发的数值计算库，以函数式编程和强大的自动微分能力著称：

核心特性

  • 纯函数式编程
  • grad/jit/vmap/pmap变换
  • Triton GPU编译器
  • 强大的JIT编译

适用场景

  • 科研计算
  • 强化学习
  • 数学优化
  • 大规模并行
JAX基础示例： import jax import jax.numpy as jnp from jax import grad, jit, vmap # 定义函数 def predict(params, x): w, b = params return jnp.dot(x, w) + b # 自动微分 def loss_fn(params, x, y): preds = predict(params, x) return jnp.mean((preds - y) ** 2) grad_fn = grad(loss_fn) # JIT编译 fast_predict = jit(predict) # 向量化 vmap_predict = vmap(predict, in_axes=(None, 0)) # 使用 key = jax.random.PRNGKey(0) x = jax.random.normal(key, (100, 10)) y = jax.random.normal(key, (100,)) params = (jax.random.normal(key, (10,)), 0.0) grads = grad_fn(params, x, y)

🔗 框架互操作性

模型转换与共享

不同框架之间可以通过标准格式进行模型转换：

模型格式转换： # PyTorch to ONNX import torch import onnx model = torch.load('model.pth') dummy_input = torch.randn(1, 3, 224, 224) torch.onnx.export( model, dummy_input, 'model.onnx', input_names=['input'], output_names=['output'] ) # ONNX to TensorFlow import onnx import tf2onnx model = onnx.load('model.onnx') tf_rep = tf2onnx.convert.from_onnx(model) tf_rep.save('model.pb') # Hugging Face Hub共享 from transformers import AutoModel # 自动从Hub加载模型 model = AutoModel.from_pretrained('bert-base-uncased')
