C-5 常用数据字段说明

数据API参考

📊 行情数据字段

字段 说明 类型 备注
trade_date 交易日期 String YYYYMMDD格式
ts_code 证券代码 String 000001.SZ格式
open 开盘价 Float 元
high 最高价 Float 元
low 最低价 Float 元
close 收盘价 Float 元
pre_close 昨收价 Float 元
vol 成交量(手) Float 手
amount 成交额(千元) Float 千元
pct_chg 涨跌幅 Float 百分比

📈 每日指标字段

字段 说明 类型 备注
pe 市盈率 Float 滚动市盈率
pe_ttm 滚动市盈率 Float TTM
pb 市净率 Float
ps 市销率 Float
ps_ttm 滚动市销率 Float TTM
dv_ratio 股息率 Float 百分比
dv_ttm 滚动股息率 Float 百分比
total_mv 总市值 Float 万元
circ_mv 流通市值 Float 万元

💹 财务数据字段

字段 说明 类型 备注
ann_date 公告日期 String YYYYMMDD格式
f_ann_date 报告期 String YYYYMMDD格式
end_date 报告期结束日 String YYYYMMDD格式
total_revenue 营业总收入 Float 元
revenue 营业收入 Float 元
operate_profit 营业利润 Float 元
total_profit 利润总额 Float 元
n_income 净利润 Float 元
total_assets 资产总计 Float 元
total_hldr_eqy_exc_min_int 股东权益合计 Float 元

📊 财务指标字段

字段 说明 类型 备注
roe 净资产收益率 Float 百分比
roe_dt 净资产收益率(扣非) Float 百分比
roe_wy 净资产收益率(摊薄) Float 百分比
roa 总资产收益率 Float 百分比
gross_profit_margin 销售毛利率 Float 百分比
current_ratio 流动比率 Float
quick_ratio 速动比率 Float
debt_to_assets 资产负债率 Float 百分比

🏢 股票基本信息字段

字段 说明 类型 备注
ts_code TS代码 String
symbol 股票代码 String
name 股票名称 String
area 地域 String
industry 所属行业 String
market 市场类型 String
list_date 上市日期 String YYYYMMDD格式
is_hs 是否沪深港通 String S/H/N

📊 资金流向字段

字段 说明 类型 备注
buy_lg_vol 超大单买入量 Float 手
buy_lg_amount 超大单买入金额 Float 元
sell_lg_vol 超大单卖出量 Float 手
sell_lg_amount 超大单卖出金额 Float 元
buy_md_vol 大单买入量 Float 手
buy_md_amount 大单买入金额 Float 元
net_mf_vol 净流入量 Float 手
net_mf_amount 净流入金额 Float 元

📈 涨跌停字段

字段 说明 类型 备注
trade_date 交易日期 String
ts_code 股票代码 String
close 收盘价 Float
high 涨停价 Float
low 跌停价 Float
up_limit 是否涨停 String Y/N
down_limit 是否跌停 String Y/N
limit_time 涨跌停时间 String HH:MM:SS
💡
使用建议

不同数据源字段命名可能略有差异，使用时请参考具体API文档。 注意数据的单位和格式，处理前进行必要的数据清洗和转换。
