📚 资源优化概述

# 前端资源类型 ## 静态资源 - 图片（PNG, JPG, SVG, WebP） - 字体（WOFF, WOFF2） - 样式（CSS） - 脚本（JavaScript） - 媒体（视频, 音频） ## 资源优化目标 - 减小文件体积 - 减少请求数量 - 加快加载速度 - 提升用户体验 # 优化策略 ┌─────────────────┬──────────────────────────────────┐ │ 策略 │ 方法 │ ├─────────────────┼──────────────────────────────────┤ │ 压缩 │ Gzip, Brotli, 图片压缩 │ │ 格式转换 │ WebP, AVIF, WOFF2 │ │ 合并 │ CSS/JS 合并, Sprite 图 │ │ 懒加载 │ 图片懒加载, 组件懒加载 │ │ 预加载 │ preload, prefetch, preconnect │ │ 缓存 │ 浏览器缓存, CDN 缓存 │ └─────────────────┴──────────────────────────────────┘ # 性能指标 ## Core Web Vitals - LCP (Largest Contentful Paint): 最大内容绘制 < 2.5s - FID (First Input Delay): 首次输入延迟 < 100ms - CLS (Cumulative Layout Shift): 累积布局偏移 < 0.1 ## 其他指标 - FCP (First Contentful Paint) - TTI (Time to Interactive) - TBT (Total Blocking Time)

🔧 图片优化

# 使用现代图片格式 <!-- 使用 picture 元素提供多种格式 --> <picture> <source srcset="image.avif" type="image/avif"> <source srcset="image.webp" type="image/webp"> <img src="image.jpg" alt="description"> </picture> # 响应式图片 <img srcset=" image-320w.jpg 320w, image-640w.jpg 640w, image-1280w.jpg 1280w " sizes="(max-width: 640px) 100vw, 50vw" src="image-640w.jpg" alt="description" > # 图片懒加载 <!-- 原生懒加载 --> <img src="image.jpg" loading="lazy" alt="description"> <!-- Intersection Observer API --> const observer = new IntersectionObserver((entries) => { entries.forEach(entry => { if (entry.isIntersecting) { const img = entry.target; img.src = img.dataset.src; observer.unobserve(img); } }); }); document.querySelectorAll('img[data-src]').forEach(img => { observer.observe(img); }); # 构建时图片优化 // vite.config.ts import viteImagemin from 'vite-plugin-imagemin'; export default defineConfig({ plugins: [ viteImagemin({ gifsicle: { optimizationLevel: 3 }, optipng: { optimizationLevel: 7 }, mozjpeg: { quality: 80 }, svgo: { plugins: [ { name: 'removeViewBox', active: false }, ], }, webp: { quality: 80 }, }), ], }); # 使用 sharp 处理图片 import sharp from 'sharp'; // 转换格式 await sharp('input.png') .webp({ quality: 80 }) .toFile('output.webp'); // 调整大小 await sharp('input.jpg') .resize(800, 600, { fit: 'inside' }) .toFile('output.jpg'); // 压缩 await sharp('input.jpg') .jpeg({ quality: 80, mozjpeg: true }) .toFile('output.jpg');
💡
图片格式选择

照片使用 WebP/AVIF，图标使用 SVG，需要透明使用 PNG 或 WebP。优先选择新一代格式。

⚙️ 字体优化

# 使用 WOFF2 格式 @font-face { font-family: 'MyFont'; src: url('font.woff2') format('woff2'), url('font.woff') format('woff'); font-weight: normal; font-style: normal; font-display: swap; /* 避免 FOIT */ } # 字体子集化 // 使用 fonttools 生成子集 pip install fonttools brotli pyftsubset font.ttf \ --output-file=font-subset.woff2 \ --subset-text="常用汉字" \ --flavor=woff2 # 字体预加载 <link rel="preload" href="font.woff2" as="font" type="font/woff2" crossorigin> # CSS 字体加载优化 /* 使用 font-display */ @font-face { font-family: 'MyFont'; src: url('font.woff2') format('woff2'); font-display: optional; /* 或 swap, fallback, block */ } /* font-display 策略 */ /* block: 隐藏文本直到字体加载（FOIT）*/ /* swap: 先显示后备字体，加载后替换（FOUT）*/ /* fallback: 短暂隐藏，超时使用后备字体 */ /* optional: 网络慢时使用后备字体 */ # JavaScript 字体加载 const font = new FontFace('MyFont', 'url(font.woff2)'); font.load().then((loadedFont) => { document.fonts.add(loadedFont); document.body.style.fontFamily = 'MyFont, sans-serif'; });

🚀 资源预加载

# preload - 预加载当前页面需要的资源 <!-- 预加载字体 --> <link rel="preload" href="font.woff2" as="font" type="font/woff2" crossorigin> <!-- 预加载关键 CSS --> <link rel="preload" href="critical.css" as="style"> <!-- 预加载图片 --> <link rel="preload" href="hero.jpg" as="image"> <!-- 预加载脚本 --> <link rel="preload" href="critical.js" as="script"> # prefetch - 预取下一页面可能需要的资源 <!-- 空闲时预取 --> <link rel="prefetch" href="next-page.js"> <link rel="prefetch" href="next-page.css"> # preconnect - 预连接 <!-- 预连接到 CDN --> <link rel="preconnect" href="https://cdn.example.com"> <link rel="dns-prefetch" href="https://cdn.example.com"> # modulepreload - ES 模块预加载 <link rel="modulepreload" href="module.js"> # 动态预加载 // 根据用户行为预加载 function prefetchOnHover(link) { link.addEventListener('mouseenter', () => { const prefetchLink = document.createElement('link'); prefetchLink.rel = 'prefetch'; prefetchLink.href = link.href; document.head.appendChild(prefetchLink); }, { once: true }); } // 使用 link rel="prerender" 完全预渲染 <link rel="prerender" href="https://example.com/next-page">
