10.2 Readonly 和 Mutable

控制属性的只读性

🎯 学习目标

  • 深入理解 Readonly 的实现原理
  • 学会创建 Mutable 工具类型
  • 掌握深层只读类型的实现
  • 了解实际项目中的应用

📚 Readonly 深入

// Readonly 将所有属性变为只读 // 内置实现： type MyReadonly = { readonly [P in keyof T]: T[P]; }; interface Config { apiUrl: string; timeout: number; retries: number; } // 使用 Readonly type ReadonlyConfig = Readonly; // { readonly apiUrl: string; readonly timeout: number; readonly retries: number; } const config: ReadonlyConfig = { apiUrl: 'https://api.example.com', timeout: 5000, retries: 3 }; // config.timeout = 10000; // Error: 只读属性不能修改 // 函数参数保护 function processConfig(config: Readonly): void { // config.timeout = 1000; // Error console.log(config.apiUrl); }

🔧 Mutable 工具类型

// TypeScript 没有内置 Mutable，需要自定义 type Mutable = { -readonly [P in keyof T]: T[P]; }; interface ReadonlyUser { readonly id: number; readonly name: string; readonly email: string; } // 移除只读修饰 type EditableUser = Mutable; // { id: number; name: string; email: string; } const user: EditableUser = { id: 1, name: 'Alice', email: 'alice@example.com' }; user.name = 'Bob'; // OK // 部分属性可变 type MutableKeys = Omit & { -readonly [P in K]: T[P]; }; interface StrictConfig { readonly apiUrl: string; readonly timeout: number; readonly debug: boolean; } type ConfigWithMutableDebug = MutableKeys; // { readonly apiUrl: string; readonly timeout: number; debug: boolean; }
💡
-readonly 语法

-readonly 用于移除只读修饰符，与 -? 移除可选修饰符类似。

🔀 深层只读

// 内置 Readonly 只处理第一层 // 自定义深层只读 type DeepReadonly = { readonly [P in keyof T]: T[P] extends object ? T[P] extends Function ? T[P] : DeepReadonly : T[P]; }; interface NestedConfig { api: { url: string; headers: { authorization: string; contentType: string; }; }; database: { host: string; port: number; }; } type DeepConfig = DeepReadonly; const deepConfig: DeepConfig = { api: { url: 'https://api.example.com', headers: { authorization: 'Bearer token', contentType: 'application/json' } }, database: { host: 'localhost', port: 5432 } }; // 所有层级都是只读 // deepConfig.api.url = ''; // Error // deepConfig.api.headers.authorization = ''; // Error // 深层可变 type DeepMutable = { -readonly [P in keyof T]: T[P] extends object ? T[P] extends Function ? T[P] : DeepMutable : T[P]; };

🎨 实际应用

// Redux 状态 interface AppState { user: { id: number; name: string; }; settings: { theme: string; lang: string; }; } // Redux 状态应该是只读的 type ReduxState = DeepReadonly; // 函数返回值保护 function getDefaultConfig(): Readonly { return { apiUrl: 'https://api.example.com', timeout: 3000, retries: 3 }; } const defaultConfig = getDefaultConfig(); // defaultConfig.timeout = 5000; // Error // 冻结对象运行时保护 function freezeConfig(config: T): Readonly { return Object.freeze(config); } const frozen = freezeConfig({ a: 1, b: 2 }); // frozen.a = 3; // Error (类型和运行时都报错)

📝 本节小结

✅
  • • Readonly 使所有属性变为只读
  • • Mutable 移除只读修饰符
  • • DeepReadonly 实现深层只读
  • • 常用于状态管理和配置保护
