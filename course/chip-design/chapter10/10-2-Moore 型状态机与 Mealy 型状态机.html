10.2 Moore 型状态机与 Mealy 型状态机

有限状态机（FSM）设计

🎯 学习目标

  • 理解Moore型和Mealy型状态机的区别
  • 掌握两种状态机的输出特性
  • 能够根据需求选择合适的状态机类型
  • 理解两种状态机的优缺点

状态机分类

根据输出与输入的关系，有限状态机分为两大类：Moore型状态机和Mealy型状态机。两者在输出产生方式上有本质区别，这直接影响状态机的设计和应用场景。

💡 Moore型状态机

定义

Moore型状态机的输出只与当前状态有关，与输入无关。输出在状态进入时确定，在状态保持期间不变。

特点

  • 输出 = f(当前状态)
  • 输出稳定，与输入时序无关
  • 状态数可能较多
  • 输出变化滞后于输入

结构示意

输入 → [次态逻辑] → 状态寄存器 → [输出逻辑] → 输出
              ↑_______________|

输出逻辑只连接状态寄存器输出

✅
Moore型优点

1. 输出稳定，无毛刺
2. 时序分析简单
3. 状态转换清晰
4. 易于设计和验证

🔧 Mealy型状态机

定义

Mealy型状态机的输出与当前状态和输入都有关。输出可以随输入变化立即改变。

特点

  • 输出 = f(当前状态, 输入)
  • 输出对输入响应快
  • 状态数可能较少
  • 输出可能有毛刺

结构示意

输入 → [次态逻辑] → 状态寄存器
  |         ↑
  |____[输出逻辑] → 输出

输出逻辑同时连接状态和输入

💡
Mealy型优点

1. 状态数通常更少
2. 响应速度更快
3. 电路规模可能更小
4. 适合快速响应场景

📊 两种状态机对比

特性Moore型Mealy型
输出依赖仅当前状态当前状态+输入
状态数量可能较多通常较少
输出稳定性稳定无毛刺可能有毛刺
响应速度慢一个周期即时响应
设计复杂度较简单较复杂
时序分析简单复杂

🔄 类型转换

Moore转Mealy

将Moore型的输出逻辑改为同时依赖输入，即可得到等效的Mealy型。状态数不变或减少。

Mealy转Moore

需要增加状态来区分不同的输出情况。每个Mealy状态可能对应多个Moore状态。

转换规则：如果Mealy状态在不同输入下有不同输出，则拆分为多个Moore状态。

⚠️
选择建议

1. 需要稳定输出时选Moore型
2. 需要快速响应时选Mealy型
3. 不确定时优先选择Moore型
4. 高速设计中Mealy型更常见

📝 本节小结

✅
  • • Moore型：输出只依赖状态，稳定但响应慢
  • • Mealy型：输出依赖状态和输入，响应快但可能有毛刺
  • • Moore型状态数可能更多
  • • 两者可以相互转换，功能等效
