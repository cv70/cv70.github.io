71.1 Supertest 简介

第十部分：测试篇 - Node.js HTTP 接口测试利器

1. Supertest 简介

Supertest 是一个用于测试 Node.js HTTP 服务器的库，基于 SuperAgent 构建，提供了流畅的 API 来测试 HTTP 请求。

💡
为什么选择 Supertest？
  • 不需要启动真实服务器
  • 支持 Express、Koa、NestJS 等框架
  • 流畅的链式 API
  • 完美集成 Jest/Mocha 等测试框架
  • 支持异步测试

3. 第一个测试

// Express 应用 // src/app.ts import express from 'express'; const app = express(); app.use(express.json()); app.get('/health', (req, res) => { res.json({ status: 'ok' }); }); app.get('/users/:id', (req, res) => { const { id } = req.params; res.json({ id, name: 'User ' + id }); }); export default app;
// 测试文件 // tests/app.test.ts import request from 'supertest'; import app from '../src/app'; describe('App Tests', () => { test('GET /health should return status ok', async () => { const response = await request(app) .get('/health'); expect(response.status).toBe(200); expect(response.body).toEqual({ status: 'ok' }); }); test('GET /users/:id should return user', async () => { const response = await request(app) .get('/users/123'); expect(response.status).toBe(200); expect(response.body).toEqual({ id: '123', name: 'User 123' }); }); });

Supertest 直接调用 Express 应用的请求处理函数，不需要通过真实的网络连接，这使得测试更快、更可靠。

// Supertest 内部工作方式简化示意 function request(app) { return { get(path) { return new Promise((resolve) => { // 创建模拟的请求和响应对象 const req = { method: 'GET', path }; const res = { status: (code) => { /* ... */ }, json: (data) => { resolve({ status: 200, body: data }); } }; // 直接调用应用 app(req, res); }); } }; }

5. 支持的 HTTP 方法

import request from 'supertest'; import app from './app'; // GET 请求 await request(app).get('/users'); // POST 请求 await request(app).post('/users').send({ name: 'John' }); // PUT 请求 await request(app).put('/users/1').send({ name: 'Jane' }); // PATCH 请求 await request(app).patch('/users/1').send({ age: 25 }); // DELETE 请求 await request(app).delete('/users/1'); // HEAD 请求 await request(app).head('/users'); // OPTIONS 请求 await request(app).options('/users');

6. 基本断言模式

describe('API Tests', () => { test('should return 200', async () => { const response = await request(app).get('/users'); // 状态码断言 expect(response.status).toBe(200); // 或使用 supertest 的断言 await request(app).get('/users').expect(200); }); test('should return JSON', async () => { const response = await request(app).get('/users'); // 响应头断言 expect(response.headers['content-type']).toMatch(/json/); // 或 await request(app).get('/users').expect('Content-Type', /json/); }); test('should return specific body', async () => { const response = await request(app).get('/users/1'); // 响应体断言 expect(response.body).toEqual({ id: 1, name: 'John' }); // 或使用 supertest 断言 await request(app) .get('/users/1') .expect(200, { id: 1, name: 'John' }); }); });
