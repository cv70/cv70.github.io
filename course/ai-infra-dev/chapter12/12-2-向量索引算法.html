索引算法的重要性

向量索引算法是向量数据库性能的核心。优秀的索引算法能够在保证召回率的前提下， 将搜索时间复杂度从O(n)降低到O(log n)甚至更低，使得在大规模向量数据上 实现实时相似度搜索成为可能。

📊 索引算法分类

算法家族

基于树的方法

  • KD-Tree: 适用于低维数据（<20维）
  • Ball Tree: 适用于中等维度的欧氏空间
  • Annoy: 随机投影树，支持大规模数据

优点: 精确度高；缺点: 高维数据性能急剧下降

基于图的方法

  • HNSW: 层次化小世界图，目前最流行
  • NSG: 导航的小世界图
  • SPTAG: 空间划分树+图

优点: 高性能、高召回率；缺点: 索引构建慢

基于量化的方法

  • IVF: 倒排文件，分区+量化
  • PQ: 乘积量化，压缩向量
  • OPQ: 优化的乘积量化

优点: 内存效率高；缺点: 召回率相对较低

基于哈希的方法

  • LSH: 局部敏感哈希
  • Multi-probe LSH: 多探针LSH

优点: 构建速度快；缺点: 参数调整复杂

🕸️ HNSW算法详解

算法原理

HNSW (Hierarchical Navigable Small World)是层次化的小世界图算法， 它借鉴了跳表（Skip List）的思想，通过多层图结构实现快速搜索。

HNSW实现

import numpy as np from sklearn.neighbors import NearestNeighbors from hnswlib import Index class HNSWIndex: def __init__(self, dim, max_elements=100000, ef_construction=200, M=16): """ 初始化HNSW索引 参数: dim: 向量维度 max_elements: 最大元素数量 ef_construction: 构建时的搜索宽度（越大索引质量越高） M: 每个节点的最大连接数（越大索引质量越高） """ self.dim = dim self.index = Index(space='cosine', dim=dim) self.index.init_index( max_elements=max_elements, ef_construction=ef_construction, M=M ) self.index.set_ef(50) # 查询时的搜索宽度 def add_items(self, vectors, ids=None): """添加向量到索引""" if ids is None: self.index.add_items(vectors) else: self.index.add_items(vectors, ids) def search(self, query_vectors, k=10): """搜索最近的k个向量""" labels, distances = self.index.knn_query(query_vectors, k=k) return labels, distances def save_index(self, filename): """保存索引""" self.index.save_index(filename) def load_index(self, filename, max_elements=None): """加载索引""" self.index.load_index(filename, max_elements=max_elements) # 使用示例 index = HNSWIndex(dim=384, max_elements=1000000) # 添加向量 vectors = np.random.random((10000, 384)).astype('float32') index.add_items(vectors) # 搜索 query = np.random.random((1, 384)).astype('float32') labels, distances = index.search(query, k=10) print(f"Top-10 indices: {labels}") print(f"Distances: {distances}")

📁 IVF算法详解

算法原理

IVF (Inverted File)算法通过聚类将向量空间划分为多个 Voronoi 单元， 每个单元有一个中心点。搜索时只搜索最相关的几个单元，而不是整个数据集。

IVF实现

import numpy as np import faiss class IVFIndex: def __init__(self, dim, nlist=100, nprobe=10, metric='L2'): """ 初始化IVF索引 参数: dim: 向量维度 nlist: 聚类中心数量 nprobe: 搜索时探查的聚类数量 metric: 距离度量 ('L2' 或 'IP') """ self.dim = dim self.nlist = nlist self.nprobe = nprobe # 选择度量方式 if metric == 'L2': quantizer = faiss.IndexFlatL2(dim) self.index = faiss.IndexIVFFlat(quantizer, dim, nlist) elif metric == 'IP': quantizer = faiss.IndexFlatIP(dim) self.index = faiss.IndexIVFFlat(quantizer, dim, nlist) self.index.nprobe = nprobe self.is_trained = False def train(self, vectors): """训练索引（聚类）""" self.index.train(vectors) self.is_trained = True def add(self, vectors, ids=None): """添加向量""" if not self.is_trained: raise ValueError("Index must be trained before adding vectors") if ids is not None: self.index.add_with_ids(vectors, ids) else: self.index.add(vectors) def search(self, query, k=10): """搜索最近的k个向量""" distances, indices = self.index.search(query, k) return indices, distances def set_nprobe(self, nprobe): """设置搜索时的探查数量""" self.nprobe = nprobe self.index.nprobe = nprobe # 使用示例 index = IVFIndex(dim=384, nlist=100, nprobe=10) # 训练索引 vectors = np.random.random((100000, 384)).astype('float32') index.train(vectors) # 添加向量 index.add(vectors) # 搜索 query = np.random.random((1, 384)).astype('float32') indices, distances = index.search(query, k=10) print(f"Top-10 indices: {indices}")

IVF-PQ组合

class IVFPQIndex: def __init__(self, dim, nlist=100, m=64, nbits=8, nprobe=10): """ IVF + PQ组合索引 参数: dim: 向量维度 nlist: 聚类中心数量 m: PQ子向量数量 nbits: 每个子向量的量化位数 nprobe: 搜索时探查的聚类数量 """ self.dim = dim quantizer = faiss.IndexFlatL2(dim) # IVF + PQ self.index = faiss.IndexIVFPQ( quantizer, dim, nlist, m, nbits ) self.index.nprobe = nprobe def train(self, vectors): """训练索引""" self.index.train(vectors) def add(self, vectors, ids=None): """添加向量""" if ids is not None: self.index.add_with_ids(vectors, ids) else: self.index.add(vectors) def search(self, query, k=10): """搜索""" distances, indices = self.index.search(query, k) return indices, distances # PQ压缩比计算 # 原始: dim * 32 bits # PQ: m * nbits # 压缩比 = (dim * 32) / (m * nbits) # # 示例: dim=768, m=64, nbits=8 # 原始: 768 * 32 = 24576 bits # PQ: 64 * 8 = 512 bits # 压缩比: 48x

⚖️ 算法对比与选择

性能对比

算法 构建速度 查询速度 召回率 内存占用 适用规模
暴力搜索 O(n) O(n) 100% 高 < 100万
KD-Tree O(n log n) O(log n) 100% 中 < 100万，低维
Annoy O(n log n) O(log n) 90-95% 中 100万-1亿
HNSW O(n log n) O(log n) 95-99% 高 100万-10亿
IVF O(n log n) O(n/nclusters) 90-98% 中 100万-10亿
IVF-PQ O(n log n) O(n/nclusters) 85-95% 低 1亿-100亿

选择建议

1亿向量: - 必须使用IVF-PQ或HNSW - 考虑分布式部署 特殊场景: - 实时插入更新: HNSW - 内存受限: IVF-PQ - 需要精确搜索: 暴力搜索或KD-Tree - 向量维度>1000: HNSW或IVF

🔧 FAISS实战

完整示例

import faiss import numpy as np import time class VectorSearchBenchmark: def __init__(self, dim=768): self.dim = dim def generate_data(self, n_vectors=1000000): """生成测试数据""" print(f"Generating {n_vectors} vectors...") return np.random.random((n_vectors, self.dim)).astype('float32') def benchmark_index(self, vectors, index_type='hnsw'): """测试不同索引的性能""" d = self.dim n = len(vectors) # 准备查询数据 nq = 100 query = np.random.random((nq, d)).astype('float32') if index_type == 'flat': print("\nTesting Flat index...") index = faiss.IndexFlatL2(d) index.add(vectors) elif index_type == 'hnsw': print("\nTesting HNSW index...") index = faiss.IndexHNSWFlat(d, M=32) index.hnsw.efConstruction = 200 index.add(vectors) elif index_type == 'ivf': print("\nTesting IVF index...") quantizer = faiss.IndexFlatL2(d) index = faiss.IndexIVFFlat(quantizer, d, 100) index.train(vectors) index.add(vectors) index.nprobe = 10 elif index_type == 'ivfpq': print("\nTesting IVF-PQ index...") quantizer = faiss.IndexFlatL2(d) index = faiss.IndexIVFPQ(quantizer, d, 100, 64, 8) index.train(vectors) index.add(vectors) index.nprobe = 10 # 测试查询性能 start = time.time() D, I = index.search(query, k=10) search_time = time.time() - start print(f"Search time: {search_time * 1000:.2f} ms") print(f"QPS: {nq / search_time:.2f}") return { 'index_type': index_type, 'search_time_ms': search_time * 1000, 'qps': nq / search_time } # 运行基准测试 benchmark = VectorSearchBenchmark(dim=768) vectors = benchmark.generate_data(n_vectors=1000000) results = [] for index_type in ['flat', 'hnsw', 'ivf', 'ivfpq']: result = benchmark.benchmark_index(vectors, index_type) results.append(result) # 比较结果 for r in results: print(f"{r['index_type']:10s}: {r['search_time_ms']:7.2f} ms, QPS: {r['qps']:7.0f}")
