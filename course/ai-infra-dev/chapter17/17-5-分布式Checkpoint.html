分布式Checkpoint概述

在分布式训练中，Checkpoint（检查点）用于保存训练状态， 包括模型参数、优化器状态、训练轮次等。分布式Checkpoint面临挑战： 如何高效保存分片参数、如何处理多进程一致性、如何减少I/O开销。 正确的Checkpoint策略对长时间训练的容错和恢复至关重要。

💾 DDP的Checkpoint

保存和加载DDP模型

DDP模型保存（只在rank 0上保存）： import torch import torch.distributed as dist from torch.nn.parallel import DistributedDataParallel as DDP def save_checkpoint(model, optimizer, epoch, filename): """保存checkpoint""" if dist.get_rank() == 0: # 只在主进程保存 # 获取原始模型（不是DDP包装器） model_state = model.module.state_dict() checkpoint = { 'epoch': epoch, 'model_state_dict': model_state, 'optimizer_state_dict': optimizer.state_dict(), # 可选：保存其他信息 'lr_scheduler_state': lr_scheduler.state_dict(), 'scaler': scaler.state_dict() # 如果使用混合精度 } torch.save(checkpoint, filename) print(f'Checkpoint saved to {filename}') # 使用示例 for epoch in range(num_epochs): # 训练... # 每N个epoch保存一次 if (epoch + 1) % save_interval == 0: save_checkpoint(ddp_model, optimizer, epoch, f'checkpoint_epoch_{epoch}.pt') 加载checkpoint（所有进程都需要加载）： def load_checkpoint(model, optimizer, filename): """加载checkpoint""" checkpoint = torch.load(filename, map_location='cpu') # 加载模型参数 model.module.load_state_dict(checkpoint['model_state_dict']) # 加载优化器状态 optimizer.load_state_dict(checkpoint['optimizer_state_dict']) # 加载其他状态 start_epoch = checkpoint['epoch'] + 1 return start_epoch # 使用示例 if os.path.exists('checkpoint_latest.pt'): start_epoch = load_checkpoint(ddp_model, optimizer, 'checkpoint_latest.pt') print(f'Resuming from epoch {start_epoch}') else: start_epoch = 0

💾 FSDP的Checkpoint

保存和加载FSDP模型

FSDP支持两种Checkpoint方式： 方式1：完整Checkpoint（所有rank协同保存） from torch.distributed.fsdp import FullStateDictConfig, StateDictType from torch.distributed.fsdp import FullyShardedDataParallel as FSDP def save_fsdp_checkpoint(model, optimizer, epoch, filename): """保存FSDP checkpoint（完整保存）""" rank = dist.get_rank() # 配置：所有rank协同保存完整模型 full_state_dict_config = FullStateDictConfig( offload_to_cpu=True, # 卸载到CPU，节省GPU显存 rank0_only=True # 只在rank 0上最终保存 ) with FSDP.state_dict_type( model, StateDictType.FULL_STATE_DICT, full_state_dict_config ): state_dict = model.state_dict() if rank == 0: checkpoint = { 'epoch': epoch, 'model_state_dict': state_dict, 'optimizer_state_dict': optimizer.state_dict(), } torch.save(checkpoint, filename) print(f'Checkpoint saved to {filename}') 方式2：分片Checkpoint（每个rank保存自己的分片） from torch.distributed.fsdp import ShardedStateDictConfig def save_sharded_checkpoint(model, optimizer, epoch, dir_path): """保存分片checkpoint""" rank = dist.get_rank() world_size = dist.get_world_size() # 配置：每个rank保存自己的分片 sharded_state_dict_config = ShardedStateDictConfig( offload_to_cpu=True ) with FSDP.state_dict_type( model, StateDictType.SHARDED_STATE_DICT, sharded_state_dict_config ): state_dict = model.state_dict() # 每个rank保存自己的分片 filename = os.path.join(dir_path, f'shard_{rank}.pt') torch.save(state_dict, filename) if rank == 0: # 保存元信息 meta = { 'epoch': epoch, 'world_size': world_size, } torch.save(meta, os.path.join(dir_path, 'meta.pt')) 加载分片Checkpoint： def load_sharded_checkpoint(model, dir_path): """加载分片checkpoint""" rank = dist.get_rank() world_size = dist.get_world_size() # 加载分片 filename = os.path.join(dir_path, f'shard_{rank}.pt') state_dict = torch.load(filename) # 使用FSDP加载 with FSDP.state_dict_type(model, StateDictType.SHARDED_STATE_DICT): model.load_state_dict(state_dict)

⚡ Checkpoint优化

I/O优化

  • 异步保存：使用独立线程/进程
  • 增量保存：只保存变化部分
  • 压缩：使用zip或gzip压缩
  • 分布式文件系统：使用Lustre/GPFS
异步保存示例： import threading import queue save_queue = queue.Queue() def save_worker(): while True: data = save_queue.get() torch.save(data['checkpoint'], data['filename']) save_queue.task_done() # 启动保存线程 save_thread = threading.Thread(target=save_worker, daemon=True) save_thread.start() # 异步保存 save_queue.put({'checkpoint': checkpoint, 'filename': 'ckpt.pt'})

显存优化

  • CPU卸载：offload_to_cpu=True
  • 分阶段保存：分层保存参数
  • 释放梯度：保存后释放梯度
  • 使用FP16：减少存储大小
FSDP优化保存： full_state_dict_config = FullStateDictConfig( offload_to_cpu=True, # 卸载到CPU rank0_only=True # 只rank 0保存 ) # 对于超大规模模型，可以考虑使用 # DeepSpeed的ZeRO-Offload进一步优化

🔄 恢复训练

从Checkpoint恢复训练

完整的恢复训练流程： def resume_training(checkpoint_path): """从checkpoint恢复训练""" # 1. 加载checkpoint checkpoint = torch.load(checkpoint_path, map_location='cpu') # 2. 重建模型 model = build_model() model = DDP(model.cuda()) # 3. 加载模型参数 model.module.load_state_dict(checkpoint['model_state_dict']) # 4. 重建优化器 optimizer = torch.optim.AdamW(model.parameters(), lr=1e-4) optimizer.load_state_dict(checkpoint['optimizer_state_dict']) # 5. 重建学习率调度器 lr_scheduler = get_lr_scheduler(optimizer) lr_scheduler.load_state_dict(checkpoint['lr_scheduler_state']) # 6. 恢复训练轮次 start_epoch = checkpoint['epoch'] + 1 # 7. 恢复混合精度scaler scaler = torch.cuda.amp.GradScaler() scaler.load_state_dict(checkpoint['scaler']) return model, optimizer, lr_scheduler, scaler, start_epoch # 使用示例 if os.path.exists('checkpoint_latest.pt'): model, optimizer, lr_scheduler, scaler, start_epoch = \ resume_training('checkpoint_latest.pt') print(f'Resuming training from epoch {start_epoch}') else: model, optimizer, lr_scheduler, scaler = \ build_training_components() start_epoch = 0 # 继续训练 for epoch in range(start_epoch, num_epochs): train_epoch(model, optimizer, lr_scheduler, scaler, epoch)

📊 Checkpoint管理策略

不同的保存策略

策略 说明 适用场景
定期保存 固定间隔保存 标准训练
最佳模型 保存验证集最佳模型 需要最优性能
最新N个 只保留最近的N个checkpoint 节省存储空间
分阶段保存 训练初期频繁，后期稀疏 长时间训练

⚠️ 常见问题

问题与解决方案

问题 原因 解决方案
模型参数不匹配 模型结构变化 确保模型结构一致，或使用参数映射
显存不足 checkpoint太大 使用CPU卸载或分片保存
加载慢 I/O瓶颈 使用更快的存储或分布式文件系统
优化器状态丢失 忘记保存优化器 确保保存完整的训练状态
多进程冲突 多个进程同时写入 只在rank 0上保存
💡
最佳实践
  • 定期保存：每1-5小时保存一次
  • 保留最新：只保留最近的3-5个checkpoint
  • 保存完整状态：包括模型、优化器、学习率等
  • 测试恢复：定期测试checkpoint能否正确恢复
  • 使用云存储：将重要checkpoint备份到云存储
