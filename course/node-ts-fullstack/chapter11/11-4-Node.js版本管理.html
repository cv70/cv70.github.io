11.4 Node.js 版本管理

掌握 Node.js 版本管理工具的使用

🎯 学习目标

  • 理解 Node.js 版本发布策略
  • 掌握 nvm 版本管理工具
  • 了解 LTS 与 Current 版本区别
  • 学会项目级版本锁定

📚 版本发布策略

// Node.js 版本命名规则 // 主版本.次版本.补丁版本 // 例如: 20.10.0 // LTS (Long Term Support) - 长期支持版 // - 偶数版本号: 18.x, 20.x, 22.x // - 30个月支持周期 // - 适合生产环境 // Current - 当前版本 // - 奇数版本号: 19.x, 21.x // - 最新特性 // - 适合开发测试 // 查看当前版本 // $ node -v // v20.10.0 // 查看详细版本信息 // $ node --version // $ npm -v
💡
版本选择建议

生产环境推荐使用 LTS 版本，开发学习可以使用 Current 版本体验最新特性。

🔧 NVM 版本管理

# NVM (Node Version Manager) 常用命令 # 安装最新 LTS 版本 nvm install --lts # 安装指定版本 nvm install 20.10.0 nvm install 18 # 查看已安装版本 nvm list # 或 nvm ls # 查看可安装的版本 nvm list-remote nvm list-remote --lts # 切换版本 nvm use 18 nvm use 20 # 设置默认版本 nvm alias default 20 # 查看当前使用的版本 nvm current # 卸载指定版本 nvm uninstall 18.0.0 # 运行特定版本的 Node nvm run 18 app.js # 在特定版本下执行命令 nvm exec 18 node -v

⚙️ 项目级版本控制

// package.json 中指定 Node 版本 { "name": "my-project", "version": "1.0.0", "engines": { "node": ">=18.0.0", "npm": ">=9.0.0" } } // 或更精确的版本 { "engines": { "node": "18.x || 20.x" } } // 使用 .nvmrc 文件锁定版本 // .nvmrc 内容: // 20.10.0 // 项目成员使用时 // $ nvm use // 自动读取 .nvmrc 文件 // 使用 .node-version 文件 // 支持多个版本管理工具 // 20.10.0

📦 其他版本管理工具

📋
  • • n：Node.js 版本管理，简单易用（Mac/Linux）
  • • fnm：Fast Node Manager，Rust 编写，速度快
  • • Volta：JavaScript 工具链管理器
  • • nvm-windows：Windows 版 nvm
# fnm (Fast Node Manager) fnm install 20 fnm use 20 fnm list # Volta volta install node@20 volta pin node@20.10.0 # n (Mac/Linux) n 20 n lts n latest

📝 本节小结

✅
  • • LTS 版本适合生产环境，偶数版本号
  • • nvm 是最常用的版本管理工具
  • • 使用 engines 字段指定项目 Node 版本
  • • .nvmrc 文件锁定项目版本
