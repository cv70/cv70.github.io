内存泄漏类型

内存泄漏是AI训练中常见的问题，会导致显存（GPU）或内存（CPU）持续增长。

🔍 常见内存泄漏场景

GPU显存泄漏

  • 张量未释放
  • 模型引用未清理
  • 缓存无限增长
  • 数据加载器泄漏
  • 分布式训练泄漏

CPU内存泄漏

  • 循环引用
  • 全局变量累积
  • 缓存未清理
  • 对象引用链
  • 第三方库泄漏

🔧 常见内存泄漏修复

💡
内存泄漏修复策略

针对不同类型的内存泄漏采用不同的修复方法：

# 1. 显存泄漏修复 ## 问题：张量累积 # 错误做法 def train_wrong(): outputs = [] for batch in dataloader: output = model(batch) outputs.append(output) # 累积张量 # 正确做法 def train_correct(): for batch in dataloader: output = model(batch) # 处理后释放 process(output) del output # 显式删除 torch.cuda.empty_cache() # 清空缓存 ## 问题：模型引用未清理 # 错误做法 def create_models(): models = [] for i in range(100): models.append(MyModel().cuda()) return models # 所有模型保留在内存 # 正确做法 def create_models(): for i in range(100): model = MyModel().cuda() # 使用后释放 process(model) del model torch.cuda.empty_cache() # 2. CPU内存泄漏修复 ## 问题：循环引用 class Node: def __init__(self): self.parent = None self.children = [] # 错误做法 def create_tree(): root = Node() child = Node() child.parent = root root.children.append(child) return root # 循环引用导致无法释放 # 正确做法 import weakref def create_tree(): root = Node() child = Node() child.parent = weakref.ref(root) # 使用弱引用 root.children.append(child) return root ## 问题：全局变量 # 错误做法 cache = {} def process_data(data): key = data.id cache[key] = data # 无限增长 # 正确做法 from collections import OrderedDict class LRUCache: def __init__(self, maxsize=1000): self.cache = OrderedDict() self.maxsize = maxsize def get(self, key): if key in self.cache: self.cache.move_to_end(key) return self.cache[key] return None def put(self, key, value): if key in self.cache: self.cache.move_to_end(key) self.cache[key] = value if len(self.cache) > self.maxsize: self.cache.popitem(last=False) cache = LRUCache(maxsize=1000) def process_data(data): cache.put(data.id, data)

🎯 预防内存泄漏

  • 及时释放 - 使用del显式删除对象
  • 避免循环 - 使用弱引用打破循环
  • 限制缓存 - 设置缓存上限和过期策略
  • 定期清理 - 定期清空缓存和临时对象
  • 使用上下文 - 利用with管理资源
  • 定期测试 - 长时间运行测试内存稳定性
