59.5 Mutation 变更

GraphQL 数据变更操作详解

📖 Mutation 基础

Mutation 是 GraphQL 中用于创建、更新、删除数据的操作类型。与 Query 不同，Mutation 用于修改服务器端的数据状态。

💡
Mutation vs Query
  • Query：只读操作，不修改数据
  • Mutation：写操作，修改数据状态
  • Mutation 保证串行执行，Query 可并行执行

基本语法

// 基本语法 mutation { mutationName(input: { ... }) { field1 field2 } } // 示例：创建用户 mutation { createUser(input: { name: "张三" email: "zhangsan@example.com" password: "Password123!" }) { id name email createdAt } } // 响应 { "data": { "createUser": { "id": "1", "name": "张三", "email": "zhangsan@example.com", "createdAt": "2024-01-15T10:30:00Z" } } }

➕ 创建操作

使用 Input 类型

// Schema 定义 input CreateUserInput { name: String! email: String! password: String! role: UserRole = USER } type Mutation { createUser(input: CreateUserInput!): User! } // Mutation 调用 mutation CreateUser($input: CreateUserInput!) { createUser(input: $input) { id name email role } } // 变量 { "input": { "name": "李四", "email": "lisi@example.com", "password": "Password123!" } }

批量创建

type Mutation { createUsers(inputs: [CreateUserInput!]!): [User!]! } // 批量创建用户 mutation CreateUsers { createUsers(inputs: [ { name: "用户1", email: "user1@example.com", password: "Pass123!" }, { name: "用户2", email: "user2@example.com", password: "Pass123!" } ]) { id name email } }

✏️ 更新操作

// Schema 定义 input UpdateUserInput { name: String email: String age: Int role: UserRole } type Mutation { updateUser(id: ID!, input: UpdateUserInput!): User } // 更新用户 mutation UpdateUser($id: ID!, $input: UpdateUserInput!) { updateUser(id: $id, input: $input) { id name email age updatedAt } } // 变量 { "id": "123", "input": { "name": "张三更新", "age": 25 } }

部分更新 vs 全量更新

// 部分更新（只更新提供的字段） input UpdateUserInput { name: String // 可选 email: String // 可选 } // 全量更新（需要提供所有字段） input ReplaceUserInput { name: String! // 必填 email: String! // 必填 } type Mutation { updateUser(id: ID!, input: UpdateUserInput!): User // 部分更新 replaceUser(id: ID!, input: ReplaceUserInput!): User // 全量更新 }

🗑️ 删除操作

// Schema 定义 type DeleteResult { success: Boolean! message: String deletedId: ID } type Mutation { deleteUser(id: ID!): DeleteResult! } // 删除用户 mutation DeleteUser($id: ID!) { deleteUser(id: $id) { success message deletedId } } // 变量 { "id": "123" } // 响应 { "data": { "deleteUser": { "success": true, "message": "用户已成功删除", "deletedId": "123" } } }

软删除 vs 硬删除

type Mutation { // 软删除（标记为已删除） archiveUser(id: ID!): User // 硬删除（永久删除） deleteUser(id: ID!): DeleteResult! // 恢复已删除 restoreUser(id: ID!): User }

🔐 认证相关 Mutation

// Schema input LoginInput { email: String! password: String! } input RegisterInput { name: String! email: String! password: String! } type AuthPayload { token: String! refreshToken: String! user: User! expiresIn: Int! } type Mutation { login(input: LoginInput!): AuthPayload! register(input: RegisterInput!): AuthPayload! logout: Boolean! refreshToken(token: String!): AuthPayload! changePassword(oldPassword: String!, newPassword: String!): Boolean! } // 登录 mutation Login($input: LoginInput!) { login(input: $input) { token refreshToken user { id name email } expiresIn } } // 注册 mutation Register($input: RegisterInput!) { register(input: $input) { token user { id name } } }

📦 文件上传 Mutation

// 使用 Upload 标量 scalar Upload input UploadFileInput { file: Upload! folder: String } type File { id: ID! url: String! filename: String! mimetype: String! size: Int! } type Mutation { uploadFile(input: UploadFileInput!): File! uploadFiles(files: [Upload!]!): [File!]! } // 客户端上传（需要 multipart 请求） mutation UploadFile($file: Upload!) { uploadFile(input: { file: $file }) { id url filename size } }

⚡ 多个 Mutation

// 在一个请求中执行多个 Mutation mutation CreateOrder($userInput: CreateUserInput!, $orderInput: CreateOrderInput!) { createUser(input: $userInput) { id name } createOrder(input: $orderInput) { id total status } } // 注意：Mutation 是串行执行的 // createUser 先执行，createOrder 后执行
⚠️
执行顺序

与 Query 不同，多个 Mutation 是串行执行的，保证操作的顺序性和数据一致性。

🔄 返回更新后的数据

// 最佳实践：返回更新后的完整对象 mutation UpdateUser($id: ID!, $input: UpdateUserInput!) { updateUser(id: $id, input: $input) { id name email age updatedAt posts { id title } followers { id name } } } // 返回类型选择 type Mutation { // 返回更新后的对象（推荐） updateUser(id: ID!, input: UpdateUserInput!): User // 返回操作结果 updateUserResult(id: ID!, input: UpdateUserInput!): UpdateResult! // 返回 ID（简单场景） updateUserSimple(id: ID!, input: UpdateUserInput!): ID }

📝 小结

  • Mutation 用于创建、更新、删除数据
  • 使用 Input 类型组织复杂参数
  • 返回更新后的数据便于客户端更新状态
  • 多个 Mutation 串行执行保证顺序性
  • 支持文件上传、认证等特殊操作
  • 结合客户端缓存实现数据同步
