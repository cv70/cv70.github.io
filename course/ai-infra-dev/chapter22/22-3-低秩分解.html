22.3 低秩分解

通过矩阵分解减少模型参数

🎯 学习目标

  • 理解低秩分解的数学原理

  • 学习分解在神经网络中的应用

什么是低秩分解

低秩分解（Low-Rank Decomposition）是将一个高秩矩阵分解为多个低秩矩阵乘积的技术。 在神经网络中，这可以将大权重矩阵分解为小矩阵，从而减少参数量和计算量。

📐 数学基础

矩阵秩的概念

矩阵的秩是指矩阵中线性无关的行或列的最大数量。

低秩假设

深度学习模型的权重矩阵通常是低秩的，意味着它们可以由少量基础向量的组合来表示。 这使得我们可以用两个小矩阵A和B的乘积来近似原大矩阵W。

🔢 常见分解方法

SVD分解

  • 全称：奇异值分解
  • 公式：W = U * Σ * V^T
  • 优点：理论最优
  • 缺点：计算复杂

CP分解

  • 全称：CANDECOMP/PARAFAC
  • 应用：张量分解
  • 优点：简单直观
  • 缺点：近似误差大

Tucker分解

  • 应用：高阶张量
  • 优点：灵活性高
  • 缺点：参数多

SVD近似

  • 方法：保留top-k奇异值
  • 优点：高效实用
  • 缺点：有误差

🧮 线性层分解

全连接层分解

将一个大的全连接层分解为两个小的全连接层。

输入 → W: d×k → 输出
输入 → A: d×r → B: r×k → 输出

其中 r < k, r < d，r称为秩(rank)。参数量从 d×k 减少到 d×r + r×k。

💻 低秩分解实现

import torch
import torch.nn as nn
import numpy as np

class SVDLinear(nn.Module):
    """
    使用SVD分解的线性层
    """
    def __init__(self, in_features, out_features, rank):
        super(SVDLinear, self).__init__()
        self.rank = rank
        self.in_features = in_features
        self.out_features = out_features

        # 创建两个小矩阵
        self.A = nn.Parameter(torch.randn(in_features, rank) / np.sqrt(rank))
        self.B = nn.Parameter(torch.randn(rank, out_features) / np.sqrt(rank))

    def forward(self, x):
        # x: (batch, in_features)
        # A: (in_features, rank)
        # B: (rank, out_features)
        return torch.matmul(torch.matmul(x, self.A), self.B)

def decompose_layer(layer, rank):
    """
    使用SVD分解线性层
    """
    # 获取原始权重
    W = layer.weight.data  # (out_features, in_features)

    # 转置以符合SVD惯例
    W = W.T  # (in_features, out_features)

    # SVD分解
    U, S, Vh = torch.linalg.svd(W, full_matrices=False)

    # 截断到指定秩
    U_r = U[:, :rank]  # (in_features, rank)
    S_r = S[:rank]     # (rank,)
    Vh_r = Vh[:rank, :]  # (rank, out_features)

    # 构造两个小矩阵
    A = U_r @ torch.diag(S_r)  # (in_features, rank)
    B = Vh_r                  # (rank, out_features)

    # 创建分解后的层
    decomposed_layer = SVDLinear(
        layer.in_features,
        layer.out_features,
        rank
    )

    # 初始化权重
    decomposed_layer.A.data = A
    decomposed_layer.B.data = B

    # 复制偏置（如果有）
    if layer.bias is not None:
        decomposed_layer.bias = nn.Parameter(layer.bias.data.clone())

    return decomposed_layer

# 使用示例
# 原始层
original_layer = nn.Linear(768, 768)

# 分解为rank=128的层
decomposed_layer = decompose_layer(original_layer, rank=128)

# 计算参数减少量
original_params = 768 * 768
decomposed_params = 768 * 128 + 128 * 768
compression_ratio = original_params / decomposed_params

print(f"原始参数: {original_params}")
print(f"分解后参数: {decomposed_params}")
print(f"压缩比: {compression_ratio:.2f}x")

📊 不同分解策略

策略 秩选择 压缩比 精度损失 适用场景
固定秩 预设固定值 高 高 极端压缩
能量比 保留95%能量 中 中 通用场景
自适应 根据层自动调整 可变 低 精度优先
分层 不同层不同秩 优化 低 精细调优
💡
低秩分解实践建议
  • 从中间层开始分解，最后分解输入输出层
  • 秩的选择需要平衡压缩比和精度
  • 分解后通常需要微调以恢复精度
  • 可与剪枝、量化结合使用效果更好

📝 本节小结

✅
  • • 低秩分解通过矩阵分解减少模型参数和计算量
  • • SVD是最常用的分解方法，保留top-k奇异值
  • • 线性层可以分解为两个小线性层的乘积
  • • 秩的选择是关键，需要平衡压缩和精度
