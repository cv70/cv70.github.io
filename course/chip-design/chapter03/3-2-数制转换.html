二进制、八进制、十六进制与十进制

什么是数制

数制（Number System）是用一组固定的数字符号和统一的规则来表示数值的方法。不同的数制使用不同的基数（Radix），在数字系统中，我们主要使用二进制（基数为2）、八进制（基数为8）、十进制（基数为10）和十六进制（基数为16）。

在芯片设计和计算机系统中，二进制是核心，因为电子元件的开关状态天然对应0和1。十六进制则常用于简化二进制表示，便于人类阅读和书写。

💡 四种常用进制

BIN

二进制

基数：2
数字：0, 1
后缀：B 或 b
例：1010B

OCT

八进制

基数：8
数字：0-7
后缀：O 或 o
例：12O

DEC

十进制

基数：10
数字：0-9
后缀：D 或无
例：10 或 10D

HEX

十六进制

基数：16
数字：0-9, A-F
后缀：H 或 0x
例：0xA 或 AH

🔄 进制转换方法

一、其他进制转十进制

方法：按权展开相加

📝

二进制转十进制：(1011.01)₂ = 1×2³ + 0×2² + 1×2¹ + 1×2⁰ + 0×2⁻¹ + 1×2⁻² = 8 + 0 + 2 + 1 + 0 + 0.25 = 11.25

八进制转十进制：(127)₈ = 1×8² + 2×8¹ + 7×8⁰ = 64 + 16 + 7 = 87

十六进制转十进制：(2A)₁₆ = 2×16¹ + 10×16⁰ = 32 + 10 = 42

二、十进制转其他进制

方法：整数部分除基取余（逆序），小数部分乘基取整（顺序）

📝

十进制转二进制：(25)₁₀ = (?)₂

25 ÷ 2 = 12 余 1
12 ÷ 2 = 6 余 0
6 ÷ 2 = 3 余 0
3 ÷ 2 = 1 余 1
1 ÷ 2 = 0 余 1
结果：(25)₁₀ = (11001)₂

三、二进制与八/十六进制互转

📝

二进制转八进制：3位一组，不足补零

(10110111)₂ = (010 110 111)₂ = (267)₈

二进制转十六进制：4位一组，不足补零

(10110111)₂ = (1011 0111)₂ = (B7)₁₆

逆向转换：每1位八/十六进制展开为3/4位二进制

⚠️
芯片设计中的常用表示

在Verilog HDL中：
• 4'b1010 - 4位二进制数
• 8'hA5 - 8位十六进制数
• 16'd255 - 16位十进制数
• 6'o77 - 6位八进制数

🔢 二进制的位运算

运算 符号 说明 示例
按位与 & 对应位都为1则为1 1010 & 1100 = 1000
按位或 | 对应位有1则为1 1010 | 1100 = 1110
按位异或 ^ 对应位不同则为1 1010 ^ 1100 = 0110
按位取反 ~ 0变1，1变0 ~1010 = 0101
左移 << 所有位左移n位，低位补0 1010 << 2 = 101000
右移 >> 所有位右移n位，高位补符号位或0 1010 >> 2 = 0010
