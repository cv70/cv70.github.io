Megatron-LM部署概述

Megatron-LM的部署包括环境准备、安装、数据准备、配置和启动训练等步骤。 正确的部署是成功训练的基础。本节将详细介绍从零开始部署Megatron-LM的完整流程。

🔧 环境准备

系统要求

硬件要求： 最低配置： • GPU: 8× V100 32GB • CPU: 32核 • 内存: 256 GB • 存储: 1 TB SSD 推荐配置： • GPU: 8× A100 80GB • CPU: 64核 • 内存: 512 GB • 存储: 2 TB NVMe 大规模训练： • GPU: 64+× A100 80GB • CPU: 128核/节点 • 内存: 1 TB/节点 • 网络: InfiniBand 200Gbps 软件要求： 操作系统： • Ubuntu 20.04+ 或 CentOS 7+ • 内核版本 >= 4.15 依赖软件： • CUDA: 11.8+ • cuDNN: 8.6+ • NCCL: 2.12+ • Python: 3.8-3.10 • PyTorch: 1.13+ • Apex: 0.1+

📦 安装流程

详细安装步骤

1. 创建虚拟环境 conda create -n megatron python=3.9 conda activate megatron 2. 安装依赖 # 安装PyTorch pip install torch==2.0.0+cu118 -f https://download.pytorch.org/whl/torch_stable.html # 安装Apex (可选，用于混合精度) git clone https://github.com/NVIDIA/apex.git cd apex pip install -v --disable-pip-version-check --no-build-isolation \ --config-settings "--global-option=--cpp_ext" \ --config-settings "--global-option=--cuda_ext" ./ cd .. 3. 安装Megatron-LM git clone https://github.com/NVIDIA/Megatron-LM.git cd Megatron-LM # 安装Python依赖 pip install -r requirements.txt # 安装Megatron-LM pip install -e . # 验证安装 python -c "import megatron; print(megatron.__version__)" 4. 配置NCCL（可选但推荐） export NCCL_DEBUG=INFO export NCCL_IB_DISABLE=0 export NCCL_NET_GDR_LEVEL=5 export NCCL_IB_GID_INDEX=3 5. 测试安装 # 运行简单的测试脚本 python examples/pretrain_gpt.py \ --tensor-model-parallel-size 1 \ --pipeline-model-parallel-size 1 \ --num-layers 2 \ --hidden-size 256 \ --num-attention-heads 4 \ --micro-batch-size 2 \ --global-batch-size 8 \ --seq-length 128 \ --max-position-embeddings 128 \ --train-iters 10 \ --lr 0.00015 \ --fp16

📊 数据准备

数据预处理

1. 准备原始数据 # 原始数据格式：纯文本文件 # corpus.txt 2. 数据预处理脚本 python tools/preprocess_data.py \ --input /path/to/corpus.txt \ --output-prefix /path/to/output/my_data \ --tokenizer-type GPT2BPETokenizer \ --vocab-file gpt2-vocab.json \ --merge-file gpt2-merges.txt \ --dataset-impl mmap \ --json-key text \ --split-sentences \ --workers 8 参数说明： • --input: 输入文本文件 • --output-prefix: 输出文件前缀 • --tokenizer-type: 分词器类型 - GPT2BPETokenizer: GPT-2 BPE - BertWordPieceTokenizer: BERT WordPiece - SentencePieceTokenizer: SentencePiece • --vocab-file: 词汇表文件 • --merge-file: BPE merge文件 • --dataset-impl: 数据集实现 - mmap: 内存映射（推荐） - lazy: 延迟加载 • --workers: 工作进程数 • --split-sentences: 按句子切分 3. 生成的文件 my_data_text_document.idx # 索引文件 my_data_text_document.bin # 数据文件 4. 验证数据 python tools/verify_dataset.py \ --dataset /path/to/output/my_data_text_document.bin

⚙️ 训练配置

关键配置参数

类别 参数 说明
模型配置 --num-layers Transformer层数
--hidden-size 隐藏层维度
--num-attention-heads 注意力头数
并行配置 --tensor-model-parallel-size 张量并行度
--pipeline-model-parallel-size 流水线并行度
批次配置 --micro-batch-size 微批次大小
--global-batch-size 全局批次大小
序列配置 --seq-length 序列长度
训练配置 --train-iters 训练迭代次数
--lr 学习率
精度配置 --fp16 使用FP16精度

🚀 启动训练

训练启动脚本

单机多卡训练： #!/bin/bash # launch_single_node.sh GPUS_PER_NODE=8 NNODES=1 NODE_RANK=0 MASTER_ADDR=localhost MASTER_PORT=6000 DISTRIBUTED_ARGS=" --nproc_per_node $GPUS_PER_NODE \ --nnodes $NNODES \ --node_rank $NODE_RANK \ --master_addr $MASTER_ADDR \ --master_port $MASTER_PORT " python -m torch.distributed.launch $DISTRIBUTED_ARGS \ pretrain_gpt.py \ --tensor-model-parallel-size 2 \ --pipeline-model-parallel-size 4 \ --num-layers 24 \ --hidden-size 1024 \ --num-attention-heads 16 \ --micro-batch-size 4 \ --global-batch-size 128 \ --seq-length 1024 \ --max-position-embeddings 1024 \ --train-iters 500000 \ --lr 0.00015 \ --min-lr 1.0e-5 \ --lr-decay-style cosine \ --weight-decay 0.1 \ --clip-grad 1.0 \ --fp16 \ --data-path /path/to/data \ --vocab-file gpt2-vocab.json \ --merge-file gpt2-merges.txt \ --save /path/to/checkpoints \ --save-interval 1000 \ --log-interval 10 多节点训练： #!/bin/bash # launch_multi_node.sh # 在主节点上运行 GPUS_PER_NODE=8 NNODES=4 NODE_RANK=0 MASTER_ADDR=192.168.1.1 # 主节点IP MASTER_PORT=6000 # (其他节点设置NODE_RANK=1, 2, 3) DISTRIBUTED_ARGS=" --nproc_per_node $GPUS_PER_NODE \ --nnodes $NNODES \ --node_rank $NODE_RANK \ --master_addr $MASTER_ADDR \ --master_port $MASTER_PORT " python -m torch.distributed.launch $DISTRIBUTED_ARGS \ pretrain_gpt.py \ [其他参数与单机相同]

📈 监控与调优

性能监控

  • GPU利用率：nvidia-smi持续监控
  • 训练日志：观察loss和学习率
  • TensorBoard：可视化训练曲线
  • 通信时间：检查网络瓶颈

常见问题

  • OOM：减小batch size或启用梯度累积
  • NaN loss：调整学习率或梯度裁剪
  • 通信超时：检查网络连接
  • 速度慢：优化数据加载和通信
⚠️
部署注意事项
  • 环境一致性：所有节点环境必须一致
  • 时间同步：所有节点时间必须同步（NTP）
  • 网络配置：确保InfiniBand正确配置
  • 存储挂载：确保所有节点访问相同的存储
  • 权限管理：确保文件系统权限正确
💡
最佳实践
  • 从小开始：先用小模型和小数据验证
  • 使用容器：Docker容器化环境，便于管理
  • 定期备份：定期保存checkpoint
  • 监控告警：设置训练失败告警
  • 文档记录：记录配置和训练结果
