60.3 枚举与接口

GraphQL 类型抽象能力

🔢 枚举类型

定义枚举

// 基本枚举定义 enum UserRole { USER ADMIN MODERATOR } enum PostStatus { DRAFT PUBLISHED ARCHIVED DELETED } enum SortOrder { ASC DESC } enum MediaType { IMAGE VIDEO AUDIO DOCUMENT }

使用枚举

// 在对象类型中使用 type User { id: ID! name: String! role: UserRole! // 必填枚举 status: UserStatus // 可选枚举 } type Post { id: ID! title: String! status: PostStatus! } // 在参数中使用 type Query { users(role: UserRole): [User!]! posts(status: PostStatus, sort: SortOrder = DESC): [Post!]! } // 在输入类型中使用 input CreateUserInput { name: String! email: String! role: UserRole = USER // 带默认值 } input PostFilterInput { status: PostStatus sort: SortOrder }

枚举查询示例

// 查询管理员用户 query GetAdmins { users(role: ADMIN) { id name role } } // 创建用户时指定角色 mutation CreateUser { createUser(input: { name: "管理员" email: "admin@example.com" role: ADMIN }) { id name role } } // 获取已发布的文章 query GetPublishedPosts { posts(status: PUBLISHED, sort: DESC) { title createdAt } }

TypeScript 枚举映射

// GraphQL Schema enum UserRole { USER ADMIN MODERATOR } // TypeScript 定义 enum UserRole { USER = 'USER', ADMIN = 'ADMIN', MODERATOR = 'MODERATOR', } // Resolver 使用 const resolvers = { Query: { users: async (_: any, { role }: { role?: UserRole }) => { if (role === UserRole.ADMIN) { return getAdminUsers(); } return getAllUsers(); }, }, };

🔗 接口类型

定义接口

// 基础接口 interface Node { id: ID! createdAt: DateTime! } interface Timestamped { createdAt: DateTime! updatedAt: DateTime! } interface Ownable { owner: User! } // 媒体接口 interface Media { id: ID! url: String! filename: String! mimeType: String! size: Int! }

实现接口

// 实现单个接口 type User implements Node { id: ID! createdAt: DateTime! name: String! email: String! } type Post implements Node { id: ID! createdAt: DateTime! title: String! content: String author: User! } // 实现多个接口 type Image implements Node & Media & Ownable { // Node 接口字段 id: ID! createdAt: DateTime! // Media 接口字段 url: String! filename: String! mimeType: String! size: Int! // Ownable 接口字段 owner: User! // Image 特有字段 width: Int! height: Int! alt: String } type Video implements Node & Media & Ownable { id: ID! createdAt: DateTime! url: String! filename: String! mimeType: String! size: Int! owner: User! // Video 特有字段 duration: Int! thumbnail: String resolution: String }

接口作为返回类型

type Query { // 返回接口类型 node(id: ID!): Node nodes(ids: [ID!]!): [Node]! // 返回媒体列表 media: [Media!]! // 用户的时间线（混合类型） timeline(userId: ID!): [Node!]! } // 查询时使用内联片段 query GetNode($id: ID!) { node(id: $id) { id createdAt ... on User { name email } ... on Post { title content } ... on Image { url width height } } }

接口 Resolver

const resolvers = { // 接口字段 resolver Node: { __resolveType(obj: any) { if (obj.name && obj.email) return 'User'; if (obj.title) return 'Post'; if (obj.mimeType) return 'Media'; return null; }, }, Media: { __resolveType(obj: any) { if (obj.mimeType.startsWith('image/')) return 'Image'; if (obj.mimeType.startsWith('video/')) return 'Video'; return null; }, }, // 接口共享字段的 resolver Ownable: { owner: async (obj, _, context) => { return context.dataSources.userApi.getById(obj.ownerId); }, }, };

📊 枚举 vs 接口 对比

特性 枚举 接口
用途 定义有限的选项值 定义共享字段
值类型 字符串 对象
扩展性 添加新值 添加新实现类型
使用场景 状态、角色、类型标识 多态、共享行为

🎯 实战示例

通知系统

enum NotificationType { LIKE COMMENT FOLLOW MENTION SYSTEM } interface Notification { id: ID! type: NotificationType! createdAt: DateTime! read: Boolean! } type LikeNotification implements Notification { id: ID! type: NotificationType! createdAt: DateTime! read: Boolean! like: Like! post: Post! } type CommentNotification implements Notification { id: ID! type: NotificationType! createdAt: DateTime! read: Boolean! comment: Comment! post: Post! } type FollowNotification implements Notification { id: ID! type: NotificationType! createdAt: DateTime! read: Boolean! follower: User! } type Query { notifications(type: NotificationType, unreadOnly: Boolean): [Notification!]! } // 查询 query GetNotifications { notifications(unreadOnly: true) { id type createdAt read ... on LikeNotification { post { title } } ... on CommentNotification { comment { content } post { title } } ... on FollowNotification { follower { name avatar } } } }

📝 小结

  • 枚举定义有限的选项值集合
  • 枚举可用于字段、参数、输入类型
  • 接口定义共享字段，支持多态
  • 一个类型可以实现多个接口
  • 使用 __resolveType 解析接口的实际类型
  • 内联片段查询接口的具体字段
