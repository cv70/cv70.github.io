6.4 阈值电压（Vth）

阈值电压定义，影响因素

🎯 学习目标

  • 理解阈值电压的物理定义与意义
  • 掌握影响阈值电压的主要因素
  • 理解阈值电压的调整方法
  • 认识阈值电压在工艺中的变化

什么是阈值电压

阈值电压（Threshold Voltage，Vth）是 MOSFET 的核心参数之一，定义为使器件从截止状态转变为导通状态所需的最小栅源电压。当 VGS 达到 Vth 时，半导体表面开始形成强反型层，导电沟道出现。

阈值电压是区分 MOSFET 开启与关断的临界点，直接决定了器件的开关特性和电路的噪声容限。

💡 阈值电压的物理定义

强反型条件

阈值电压对应半导体表面达到强反型（Strong Inversion）状态。强反型定义为：

📐

表面电势 φs = 2φF

其中 φF 是费米电势（Fermi Potential）：

φF = (kT/q) ln(NA/ni) （P型衬底）

φF = (kT/q) ln(ND/ni) （N型衬底）

阈值电压公式

📐

Vth = VFB + 2φF + (√(2εs q NA × 2φF)) / Cox

各项含义：

  • VFB：平带电压（Flat-band Voltage）
  • 2φF：表面电势变化（强反型所需）
  • 第三项：耗尽层电荷产生的电压降

📊 影响阈值电压的因素

1. 栅氧化层厚度（Tox）

栅氧化层越薄，Cox 越大：

Cox = εox / Tox

影响规律：

Tox 减小 → Cox 增大 → Vth 减小

同时栅极控制能力增强

2. 衬底掺杂浓度（NA 或 ND）

掺杂浓度越高：

  • 费米电势 |φF| 增大
  • 耗尽层电荷增加
  • 需要更大的栅压达到强反型
  • → Vth 增大

3. 栅极材料功函数（φm）

平带电压 VFB = φms = φm - φs

通过选择不同功函数的栅极材料可以调整 Vth：

栅极材料 功函数（eV） 应用
N+ 多晶硅 ~4.1 传统 NMOS 栅极
P+ 多晶硅 ~5.2 传统 PMOS 栅极
金属（TiN, TaN） 可调 先进工艺金属栅

4. 氧化层电荷（Qox）

氧化层中的固定电荷、界面态电荷会影响 Vth：

  • 固定氧化层电荷（Qf）：通常为正电荷，使 NMOS Vth 减小
  • 界面态电荷（Qit）：位于 Si-SiO2 界面
  • 可动离子电荷（Qm）：如 Na+ 等污染离子

这些电荷会导致 Vth 漂移，需要工艺控制。

5. 沟道长度（短沟道效应）

在短沟道器件中：

  • 源/漏区的耗尽层延伸到沟道区
  • 部分耗尽电荷由源/漏承担
  • 需要栅极控制的电荷减少
  • → Vth 随沟道长度减小而降低

🔧 阈值电压调整技术

离子注入调整

在沟道区进行离子注入是最常用的 Vth 调整方法：

  • 阈值调整注入：在沟道区注入杂质
  • NMOS：注入 P 型杂质（硼）提高 Vth
  • PMOS：注入 N 型杂质（磷、砷）降低 |Vth|
  • 注入剂量精确控制 Vth 值

金属栅功函数工程

先进工艺中采用金属栅：

  • 选择合适功函数的金属材料
  • 使用双金属栅工艺（NMOS/PMOS 不同金属）
  • 功函数可调的金属氮化物（TiN, TaN）
  • 消除多晶硅耗尽效应

💡
多阈值工艺

现代工艺通常提供多种阈值的器件：

  • LVT（Low Vth）：速度快，漏电大
  • SVT（Standard Vth）：平衡速度和漏电
  • HVT（High Vth）：速度慢，漏电小

设计者可根据性能和功耗需求选择不同阈值器件。

⚠️
阈值电压的变化与匹配

工艺波动：掺杂浓度、氧化层厚度等工艺参数的随机波动导致 Vth 变化。

失配（Mismatch）：相邻器件的 Vth 存在差异，影响模拟电路精度。

温度系数：Vth 随温度升高而减小（约 -2mV/°C）。

这些变化需要在电路设计中充分考虑。

📝 本节小结

✅
  • • 阈值电压是使 MOSFET 表面达到强反型所需的栅源电压
  • • Vth 受氧化层厚度、衬底掺杂、栅极功函数、氧化层电荷影响
  • • 短沟道效应导致 Vth 随沟道长度减小而降低
  • • 离子注入和金属栅功函数工程是调整 Vth 的主要方法
  • • 多阈值工艺提供性能与功耗的灵活选择
