61.2 数据关联查询

GraphQL 关联数据查询实现

📖 关联查询概述

GraphQL 的强大之处在于可以一次性获取多层关联数据。通过 Resolver 链，可以灵活地处理一对一、一对多、多对多等各种关联关系。

💡
关联类型
  • 一对一：用户-个人资料
  • 一对多：用户-文章
  • 多对多：文章-标签

👤 一对一关联

// Schema type User { id: ID! name: String! email: String! profile: Profile // 用户有一个个人资料 } type Profile { id: ID! bio: String avatar: String website: String user: User! // 个人资料属于一个用户 } // Resolvers const resolvers = { User: { profile: async (parent, _, context) => { return context.prisma.profile.findUnique({ where: { userId: parent.id }, }); }, }, Profile: { user: async (parent, _, context) => { return context.prisma.user.findUnique({ where: { id: parent.userId }, }); }, }, }; // 查询示例 query { user(id: "1") { name profile { bio avatar } } }

📄 一对多关联

// Schema type User { id: ID! name: String! posts: [Post!]! // 用户有多篇文章 postsCount: Int! } type Post { id: ID! title: String! content: String author: User! // 文章属于一个作者 comments: [Comment!]! // 文章有多条评论 } type Comment { id: ID! content: String! author: User! // 评论属于一个作者 post: Post! // 评论属于一篇文章 } // Resolvers const resolvers = { User: { posts: async (parent, { limit, offset }, context) => { return context.prisma.post.findMany({ where: { authorId: parent.id }, take: limit, skip: offset, }); }, postsCount: async (parent, _, context) => { return context.prisma.post.count({ where: { authorId: parent.id }, }); }, }, Post: { author: async (parent, _, context) => { return context.prisma.user.findUnique({ where: { id: parent.authorId }, }); }, comments: async (parent, _, context) => { return context.prisma.comment.findMany({ where: { postId: parent.id }, }); }, }, Comment: { author: async (parent, _, context) => { return context.prisma.user.findUnique({ where: { id: parent.authorId }, }); }, post: async (parent, _, context) => { return context.prisma.post.findUnique({ where: { id: parent.postId }, }); }, }, }; // 查询示例 query { user(id: "1") { name posts(limit: 5) { title comments { content author { name } } } postsCount } }

🏷️ 多对多关联

// Schema type Post { id: ID! title: String! content: String tags: [Tag!]! // 文章有多个标签 } type Tag { id: ID! name: String! slug: String! posts: [Post!]! // 标签下有多篇文章 } // 数据库中间表 _PostToTag // post_id | tag_id // Resolvers const resolvers = { Post: { tags: async (parent, _, context) => { // 通过中间表查询 return context.prisma.tag.findMany({ where: { posts: { some: { id: parent.id }, }, }, }); }, }, Tag: { posts: async (parent, _, context) => { return context.prisma.post.findMany({ where: { tags: { some: { id: parent.id }, }, }, }); }, }, }; // Prisma Schema 定义 model Post { id Int @id @default(autoincrement()) title String content String? tags Tag[] @relation("PostTags") } model Tag { id Int @id @default(autoincrement()) name String @unique slug String @unique posts Post[] @relation("PostTags") } // 查询示例 query { post(id: "1") { title tags { name posts { title } } } }

🔄 自引用关联

// Schema - 分类树结构 type Category { id: ID! name: String! parent: Category // 父分类 children: [Category!]! // 子分类 level: Int! } // Schema - 用户关注关系 type User { id: ID! name: String! followers: [User!]! // 关注者 following: [User!]! // 正在关注的人 } // Resolvers const resolvers = { Category: { parent: async (parent, _, context) => { if (!parent.parentId) return null; return context.prisma.category.findUnique({ where: { id: parent.parentId }, }); }, children: async (parent, _, context) => { return context.prisma.category.findMany({ where: { parentId: parent.id }, }); }, level: async (parent, _, context) => { let level = 0; let current = parent; while (current.parentId) { level++; current = await context.prisma.category.findUnique({ where: { id: current.parentId }, }); } return level; }, }, User: { followers: async (parent, _, context) => { return context.prisma.user.findMany({ where: { following: { some: { id: parent.id }, }, }, }); }, following: async (parent, _, context) => { return context.prisma.user.findMany({ where: { followers: { some: { id: parent.id }, }, }, }); }, }, }; // 查询分类树 query { category(id: "1") { name parent { name } children { name children { name } } } }

⚡ 使用 Include 优化

// 避免多次查询，使用 include 预加载 const resolvers = { Query: { user: async (_, { id }, context) => { // 一次查询获取用户和文章 return context.prisma.user.findUnique({ where: { id: parseInt(id) }, include: { posts: { include: { comments: { include: { author: true, }, }, }, }, }, }); }, }, }; // 使用 info 参数动态 include import { fieldSelection } from 'graphql-parse-fields'; const resolvers = { Query: { user: async (_, { id }, context, info) => { const selections = fieldSelection(info); const include = {}; if (selections.posts) { include.posts = true; } if (selections.profile) { include.profile = true; } return context.prisma.user.findUnique({ where: { id: parseInt(id) }, include: Object.keys(include).length > 0 ? include : undefined, }); }, }, };

📝 小结

  • 一对一关联使用 findUnique 查询
  • 一对多关联使用 findMany 查询
  • 多对多通过中间表关联
  • 自引用处理树形结构
  • 使用 include 预加载优化性能
  • 动态 include 减少不必要的查询
