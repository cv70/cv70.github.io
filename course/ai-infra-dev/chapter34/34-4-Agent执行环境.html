构建安全可控的Agent运行环境

执行环境概述

Agent执行环境提供Agent运行所需的计算资源、工具依赖、安全隔离和监控能力。一个良好的执行环境确保Agent稳定运行、安全可控、资源高效。

📦 Docker配置

Agent容器化

# Dockerfile
FROM python:3.11-slim

# 设置工作目录
WORKDIR /app

# 安装依赖
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# 复制代码
COPY . .

# 创建非root用户
RUN useradd -m -u 1000 agent
USER agent

# 暴露端口
EXPOSE 8000

# 启动命令
CMD ["python", "main.py"]

# requirements.txt
langchain==0.1.0
openai==1.0.0
requests==2.31.0
python-dotenv==1.0.0

# docker-compose.yml
version: '3.8'

services:
  agent:
    build: .
    ports:
      - "8000:8000"
    environment:
      - OPENAI_API_KEY=${OPENAI_API_KEY}
      - AGENT_NAME=${AGENT_NAME}
    volumes:
      - ./data:/app/data
      - ./logs:/app/logs
    restart: unless-stopped
    networks:
      - agent-network

networks:
  agent-network:
    driver: bridge

Docker容器化确保Agent在不同环境中一致运行，简化部署和管理。

🔒 沙箱隔离

隔离层级

  • 进程隔离：独立进程空间
  • 网络隔离：限制网络访问
  • 文件隔离：受限文件系统
  • 资源隔离：CPU/内存限制

安全措施

  • 最小权限原则
  • 只读文件系统
  • 网络白名单
  • 资源配额

🛡️ Kubernetes部署

K8s Agent部署

# agent-deployment.yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: agent-deployment
spec:
  replicas: 3
  selector:
    matchLabels:
      app: agent
  template:
    metadata:
      labels:
        app: agent
    spec:
      containers:
      - name: agent
        image: agent:latest
        ports:
        - containerPort: 8000
        resources:
          requests:
            cpu: "500m"
            memory: "1Gi"
          limits:
            cpu: "2000m"
            memory: "4Gi"
        env:
        - name: OPENAI_API_KEY
          valueFrom:
            secretKeyRef:
              name: api-secrets
              key: openai-key
        securityContext:
          runAsUser: 1000
          runAsGroup: 1000
          readOnlyRootFilesystem: true
          allowPrivilegeEscalation: false
        volumeMounts:
        - name: data
          mountPath: /app/data
          readOnly: true
      volumes:
      - name: data
        persistentVolumeClaim:
          claimName: data-pvc
---
apiVersion: v1
kind: Service
metadata:
  name: agent-service
spec:
  selector:
    app: agent
  ports:
  - port: 80
    targetPort: 8000
  type: LoadBalancer

Kubernetes提供可扩展、高可用的Agent部署，支持自动扩缩容和滚动更新。

import os
from dotenv import load_dotenv
import logging
from functools import wraps
import time

# 加载环境变量
load_dotenv()

# 配置日志
logging.basicConfig(
    level=logging.INFO,
    format='%(asctime)s - %(name)s - %(levelname)s - %(message)s',
    handlers=[
        logging.FileHandler('/app/logs/agent.log'),
        logging.StreamHandler()
    ]
)
logger = logging.getLogger(__name__)

# 资源监控装饰器
def monitor_resource(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        import psutil
        process = psutil.Process()

        # 记录初始资源
        start_memory = process.memory_info().rss / 1024 / 1024  # MB
        start_time = time.time()

        try:
            result = func(*args, **kwargs)
            return result
        finally:
            # 记录结束资源
            end_memory = process.memory_info().rss / 1024 / 1024  # MB
            end_time = time.time()

            logger.info(f"Function {func.__name__}: "
                       f"Memory: {start_memory:.2f}MB -> {end_memory:.2f}MB, "
                       f"Time: {end_time - start_time:.2f}s")

    return wrapper

# Agent运行时
class AgentRuntime:
    def __init__(self):
        self.agent_config = self._load_config()
        self._setup_environment()

    def _load_config(self):
        """加载配置"""
        return {
            "openai_api_key": os.getenv("OPENAI_API_KEY"),
            "max_tokens": int(os.getenv("MAX_TOKENS", 2000)),
            "timeout": int(os.getenv("TIMEOUT", 60)),
            "max_retries": int(os.getenv("MAX_RETRIES", 3))
        }

    def _setup_environment(self):
        """设置环境"""
        logger.info("Setting up Agent environment")

        # 检查资源

📊 监控与告警

监控指标

监控维度 关键指标 告警阈值
资源指标 CPU、内存、磁盘使用率 >90%
性能指标 响应时间、吞吐量 P99 > 5s
业务指标 任务成功率、错误率 成功率 < 95%
安全指标 异常访问、权限违规 任何异常
⚠️
安全注意事项

Agent执行环境要严格最小权限、网络隔离、定期审计。防止Agent被恶意利用或产生意外行为。
