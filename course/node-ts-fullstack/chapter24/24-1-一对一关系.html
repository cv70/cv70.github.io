24.1 一对一关系

定义实体间的一对一关联

🎯 学习目标

  • 理解一对一关系的概念
  • 掌握 @OneToOne 装饰器使用
  • 学会配置 @JoinColumn
  • 了解双向关系的定义

📚 一对一关系概述

一对一关系是指两个实体之间 A 包含一个 B，B 也只属于一个 A。例如：一个用户有一个用户详情，一个用户有一个头像。

数据库表结构： users 表 user_profiles 表 ┌─────┬──────────┬─────┐ ┌─────┬────────┬─────────┬─────────┐ │ id │ username │ age │ │ id │ bio │ avatar │ user_id │ ├─────┼──────────┼─────┤ ├─────┼────────┼─────────┼─────────┤ │ 1 │ alice │ 25 │ │ 1 │ Hello │ pic.jpg │ 1 │ │ 2 │ bob │ 30 │ │ 2 │ Hi │ pic.jpg │ 2 │ └─────┴──────────┴─────┘ └─────┴────────┴─────────┴─────────┘ ↑ 外键关联 users.id

🔧 单向一对一关系

import { Entity, PrimaryGeneratedColumn, Column, OneToOne, JoinColumn } from 'typeorm'; @Entity() export class User { @PrimaryGeneratedColumn() id: number; @Column() username: string; } @Entity() export class Profile { @PrimaryGeneratedColumn() id: number; @Column() bio: string; @Column() avatar: string; // 定义一对一关系 @OneToOne(() => User) @JoinColumn() // 指定外键列在此表中 user: User; } // 使用 const profile = await profileRepository.findOne({ where: { id: 1 }, relations: ['user'], }); console.log(profile.user.username); // 不使用 JoinColumn 时的默认外键列名 // 默认为：relationName + referencedColumnName = user_id
💡
@JoinColumn 说明

@JoinColumn 指定外键所在的表。在单向关系中，哪一方有 @JoinColumn，外键就在哪一方的表中。只能在一方添加 @JoinColumn。

📊 双向一对一关系

@Entity() export class User { @PrimaryGeneratedColumn() id: number; @Column() username: string; // 反向引用，没有 @JoinColumn @OneToOne(() => Profile, (profile) => profile.user) profile: Profile; } @Entity() export class Profile { @PrimaryGeneratedColumn() id: number; @Column() bio: string; @Column() avatar: string; // 拥有外键的一方 @OneToOne(() => User, (user) => user.profile) @JoinColumn() user: User; } // 使用 - 从用户查详情 const user = await userRepository.findOne({ where: { id: 1 }, relations: ['profile'], }); console.log(user.profile.bio); // 使用 - 从详情查用户 const profile = await profileRepository.findOne({ where: { id: 1 }, relations: ['user'], }); console.log(profile.user.username); // 类型安全的关联查询 const user = await userRepository.findOne({ where: { id: 1 }, relations: { profile: true, }, });

⚙️ 关系选项配置

@Entity() export class User { @PrimaryGeneratedColumn() id: number; @OneToOne(() => Profile, { // 级联操作 cascade: true, // 或 ['insert', 'update'] // 渴望加载（自动关联查询） eager: true, // 懒加载 lazy: true, // 删除行为 onDelete: 'CASCADE', // 删除用户时级联删除详情 onUpdate: 'CASCADE', // 是否可为空 nullable: true, // 主键引用 referencedColumnName: 'id', }) @JoinColumn() profile: Profile; } // 自定义外键列名 @OneToOne(() => User) @JoinColumn({ name: 'user_id', referencedColumnName: 'id' }) user: User; // 自定义外键约束名称 @OneToOne(() => User) @JoinColumn({ name: 'user_id', foreignKeyConstraintName: 'fk_profile_user' }) user: User; // 级联保存示例 const user = new User(); user.username = 'alice'; const profile = new Profile(); profile.bio = 'Hello World'; user.profile = profile; await userRepository.save(user); // 同时保存 user 和 profile

📝 本节小结

✅
  • • 一对一关系使用 @OneToOne 装饰器定义
  • • @JoinColumn 指定外键所在表
  • • 双向关系需要双方互相引用
  • • cascade 选项支持级联保存和删除
