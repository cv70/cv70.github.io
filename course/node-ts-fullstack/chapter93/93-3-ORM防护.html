使用 ORM 防止 SQL 注入

📚 ORM 安全优势

# ORM 自动防护 SQL 注入 ## 自动参数化 ORM 自动将用户输入作为参数处理 不直接拼接 SQL 字符串 ## 类型安全 数据类型自动验证和转换 不合法的类型被拒绝 ## 抽象层 开发者不需要手写 SQL 减少人为错误 # ORM 的安全性对比 ┌─────────────────┬──────────────────┬──────────────────┐ │ 方式 │ 安全性 │ 说明 │ ├─────────────────┼──────────────────┼──────────────────┤ │ 字符串拼接 │ 不安全 │ 容易注入 │ │ 参数化查询 │ 安全 │ 需要手动处理 │ │ ORM 查询 │ 安全 │ 自动参数化 │ │ ORM 原生查询 │ 取决于实现 │ 需要小心 │ └─────────────────┴──────────────────┴──────────────────┘ # 为什么 ORM 相对安全 - 使用预编译语句 - 参数自动绑定 - 类型自动转换 - 避免 SQL 字符串拼接

🔧 Prisma 安全用法

# Prisma 安全查询 import { PrismaClient } from '@prisma/client'; const prisma = new PrismaClient(); // 安全 - 自动参数化 const user = await prisma.user.findFirst({ where: { email: userInput, // 自动转义 }, }); // 安全 - 复杂查询 const users = await prisma.user.findMany({ where: { name: { contains: keyword, // 安全 }, role: roleInput, }, }); // 安全 - 关联查询 const posts = await prisma.post.findMany({ where: { author: { email: userEmail, }, }, }); # 原生查询 - 需要注意 // 安全 - 使用参数化 const result = await prisma.$queryRaw` SELECT * FROM users WHERE id = ${userId} `; // 不安全 - 模板字符串拼接 const result = await prisma.$queryRawUnsafe( `SELECT * FROM users WHERE id = ${userId}` // 危险！ ); // 安全 - 使用 Prisma.sql const result = await prisma.$queryRaw` SELECT * FROM users WHERE name LIKE ${'%' + keyword + '%'} `; // 批量查询 const result = await prisma.$queryRaw` SELECT * FROM users WHERE id IN (${Prisma.join(ids)}) `;
💡
Prisma 注意事项

使用 $queryRaw 时，确保使用模板字符串语法（反引号），它会自动参数化。避免使用 $queryRawUnsafe。

⚙️ TypeORM 安全用法

# TypeORM 安全查询 import { getRepository, Like } from 'typeorm'; import { User } from './entities/User'; const userRepo = getRepository(User); // 安全 - 使用 QueryBuilder const user = await userRepo .createQueryBuilder('user') .where('user.email = :email', { email: userEmail }) .getOne(); // 安全 - 使用 find 选项 const users = await userRepo.find({ where: { name: Like(`%${keyword}%`), // 安全 }, }); // 安全 - 动态条件 const users = await userRepo.find({ where: { ...(role && { role }), ...(status && { status }), }, }); # 原生查询 - 需要注意 // 安全 - 参数化 const result = await userRepo.query( 'SELECT * FROM users WHERE id = $1', [userId] ); // 不安全 - 字符串拼接 const result = await userRepo.query( `SELECT * FROM users WHERE id = ${userId}` // 危险！ ); // QueryBuilder 参数化 const users = await userRepo .createQueryBuilder('user') .where('user.id IN (:...ids)', { ids: [1, 2, 3] }) .getMany();

🚀 Sequelize 安全用法

# Sequelize 安全查询 import { User } from './models'; // 安全 - 使用模型方法 const user = await User.findOne({ where: { email: userEmail, // 自动转义 }, }); // 安全 - 使用 Op 操作符 import { Op } from 'sequelize'; const users = await User.findAll({ where: { name: { [Op.like]: `%${keyword}%`, }, }, }); // 安全 - 关联查询 const users = await User.findAll({ include: [{ model: Post, where: { status: 'published' }, }], }); # 原生查询 - 需要注意 // 安全 - 参数化 const result = await sequelize.query( 'SELECT * FROM users WHERE id = ?', { replacements: [userId], type: QueryTypes.SELECT, } ); // 安全 - 命名参数 const result = await sequelize.query( 'SELECT * FROM users WHERE email = :email AND status = :status', { replacements: { email, status }, type: QueryTypes.SELECT, } ); // 不安全 - 字符串拼接 const result = await sequelize.query( `SELECT * FROM users WHERE id = ${userId}`, // 危险！ { type: QueryTypes.SELECT } );
