40.5 模型监控

生产环境中模型性能的持续追踪

🎯 学习目标

  • 理解模型监控的重要性和核心指标
  • 掌握数据漂移和概念漂移的检测方法
  • 学会设计完整的监控告警体系
  • 了解模型监控工具和最佳实践

为什么需要模型监控

机器学习模型部署后并非一劳永逸。数据分布变化、用户行为改变等因素会导致模型性能退化。模型监控帮助我们及时发现问题，确保模型持续提供高质量的预测服务。

📊 监控指标体系

⚡

系统指标

延迟、吞吐量、错误率、资源使用

📈

模型指标

准确率、预测分布、置信度

📊

数据指标

数据漂移、特征分布、数据质量

⚖️ 数据漂移类型

漂移类型 定义 原因 检测方法
数据漂移 输入数据分布变化 用户群体变化、季节性 KS检验、PSI
概念漂移 输入输出关系变化 市场环境、趋势变化 准确率监控、ADWIN
标签漂移 输出标签分布变化 业务策略调整 标签分布监控
特征漂移 单个特征分布变化 数据源变更 特征级统计检验

💻 漂移检测实现

import numpy as np from scipy import stats def calculate_psi(expected, actual, buckets=10): """计算群体稳定性指标(PSI)""" def scale_range(input, min, max): input += -(np.min(input)) input /= np.max(input) / (max - min) input += min return input breakpoints = np.arange(0, buckets + 1) / buckets * 100 if len(np.unique(expected)) < buckets: breakpoints = np.percentile(expected, np.unique(breakpoints)) expected_percents = np.histogram(expected, breakpoints)[0] / len(expected) actual_percents = np.histogram(actual, breakpoints)[0] / len(actual) # 避免除零 expected_percents = np.where(expected_percents == 0, 0.0001, expected_percents) actual_percents = np.where(actual_percents == 0, 0.0001, actual_percents) psi_value = np.sum((actual_percents - expected_percents) * np.log(actual_percents / expected_percents)) return psi_value # PSI解读 # < 0.1: 无显著变化 # 0.1 - 0.25: 需要关注 # > 0.25: 显著变化，需要行动

监控最佳实践

监控应该从基线建立开始，记录模型部署初期的各项指标分布。设置合理的告警阈值，避免过于敏感导致告警疲劳，也不可过于宽松导致问题遗漏。
