25.2 综合流程详解

从设计输入到网表生成的完整过程

🎯 学习目标

  • 掌握逻辑综合的完整流程步骤
  • 理解每个步骤的作用和注意事项
  • 了解综合过程中的中间产物
  • 学会识别和解决综合过程中的问题

🔄 综合流程概览

1. 环境设置 → 2. 设计读入 → 3. 约束设定 → 4. 编译 → 5. 优化 → 6. 映射 → 7. 报告分析 → 8. 网表输出

📋 步骤详解

步骤1：环境设置

设置综合工具所需的各种参数和库文件：

# 设置目标库 set target_library [list saed90nm_typ.db] # 设置链接库 set link_library "* $target_library" # 设置符号库 set symbol_library saed90nm.sdb # 设置搜索路径 set search_path [list ./rtl ./lib ./scripts]

步骤2：设计读入

读取RTL设计文件并进行预处理：

# 读入RTL文件 read_verilog {top_module.v sub_module1.v sub_module2.v} # 分析设计层次 current_design top_module # 链接设计 link

步骤3：约束设定

设定时序、面积等设计约束：

# 时钟约束 create_clock -name CLK -period 10 [get_ports clk] # 输入延迟 set_input_delay 2 -clock CLK [all_inputs] # 输出延迟 set_output_delay 2 -clock CLK [all_outputs] # 面积约束 set_max_area 0

步骤4：编译

对设计进行初步编译和转换：

# 编译设计 compile # 或使用超编译（更激进优化） compile_ultra

步骤5：优化

根据约束进行多层次优化：

  • 架构级优化：选择最优的实现架构
  • 逻辑级优化：简化布尔表达式
  • 门级优化：选择最佳单元组合

步骤6：映射

将逻辑映射到工艺库的标准单元：

# 映射到目标库 map_effort high # 使用指定阈值电压 set_attribute -type boolean auto_ungroup none true

步骤7：报告分析

生成并分析综合报告：

# 时序报告 report_timing -max_paths 10 > timing.rpt # 面积报告 report_area > area.rpt # 功耗报告 report_power > power.rpt # 单元报告 report_cell > cell.rpt

步骤8：网表输出

输出综合后的网表和约束文件：

# 输出网表 write -format verilog -hierarchy -output top_synth.v # 输出约束文件 write_sdc -nosplit top_synth.sdc # 输出SDF文件 write_sdf -version 2.1 top_synth.sdf
💡
最佳实践

在综合过程中，建议使用增量综合策略。 对大型设计，可以先综合子模块，再综合顶层，这样可以减少综合时间并更容易定位问题。

⚠️ 常见问题处理

问题 可能原因 解决方法
链接失败 缺少库文件或路径错误 检查search_path和library设置
时序违例 约束过紧或逻辑复杂 调整约束或优化设计架构
面积超标 未设置面积约束 添加set_max_area约束

📝 本节小结

✅

  • • 每个步骤都有特定的目的和操作
  • • 约束设定是综合成功的关键
  • • 报告分析用于验证综合结果
