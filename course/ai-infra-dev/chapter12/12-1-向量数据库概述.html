什么是向量数据库

向量数据库是专门用于存储、索引和查询高维向量数据的数据库系统。 它与传统数据库的核心区别在于：传统数据库基于精确匹配和结构化查询， 而向量数据库基于相似度计算和高维空间搜索，是AI应用的核心基础设施。

🧮 向量表示与相似度

什么是向量

向量是具有大小和方向的数学对象，在AI领域通常指高维数组。 文本、图像、音频等数据都可以通过深度学习模型转换为向量表示。

# 示例：将文本转换为向量 from sentence_transformers import SentenceTransformer # 加载预训练模型 model = SentenceTransformer('all-MiniLM-L6-v2') # 文本转向量 text = "人工智能正在改变世界" vector = model.encode(text) print(f"向量维度: {len(vector)}") print(f"向量示例: {vector[:10]}") # 输出: # 向量维度: 384 # 向量示例: [0.1234, -0.5678, 0.9012, ...]

相似度计算方法

方法 公式 范围 特点 适用场景
余弦相似度 cos(θ) = (A·B) / (|A||B|) [-1, 1] 关注方向，忽略大小 文本相似度
欧氏距离 ||A - B|| [0, ∞) 几何距离 图像相似度
点积 A·B = ΣAi·Bi [-∞, ∞) 方向和大小的综合 已归一化向量
曼哈顿距离 ||A - B||₁ = Σ|Ai - Bi| [0, ∞) 网格距离 稀疏数据
汉明距离 不同位数 [0, n] 二进制向量 哈希索引

🔍 相似度搜索原理

暴力搜索（Brute Force）

import numpy as np def brute_force_search(query_vector, database_vectors, k=10): """ 暴力搜索最近的k个向量 """ # 计算所有向量的相似度 similarities = np.dot(database_vectors, query_vector) # 找到最相似的k个索引 top_k_indices = np.argsort(similarities)[-k:][::-1] # 返回结果 results = [ { 'index': idx, 'similarity': float(similarities[idx]), 'vector': database_vectors[idx] } for idx in top_k_indices ] return results # 性能分析 # 时间复杂度: O(n*d)，其中n是向量数量，d是向量维度 # 空间复杂度: O(n*d) # 适用于: 小规模数据集（<10万向量）

近似最近邻搜索（ANN）

ANN算法分类

树形方法
  • KD-Tree
  • Ball Tree
  • Annoy

通过空间划分快速缩小搜索范围

图方法
  • HNSW
  • NSG
  • SPTAG

构建近邻图进行快速遍历

量化方法
  • IVF
  • PQ
  • OPQ

通过量化减少计算量

哈希方法
  • LSH
  • Multi-probe LSH

使用局部敏感哈希快速定位

📊 向量数据库选型考虑

选型维度

性能指标

  • 查询延迟（P95/P99）
  • 吞吐量（QPS）
  • 索引构建时间
  • 存储效率

功能特性

  • 支持的向量维度
  • 相似度度量方式
  • 元数据过滤能力
  • 实时索引更新

扩展性

  • 水平扩展能力
  • 数据分片策略
  • 副本机制
  • 负载均衡

运维友好

  • 部署复杂度
  • 监控告警
  • 备份恢复
  • 社区支持
💡
选型建议

小规模（<100万向量）可以使用轻量级方案如FAISS；中等规模（100万-1亿）推荐使用Milvus或Qdrant；大规模（>1亿）考虑云托管服务如Pinecone或自建Milvus集群。
