9.4 键重映射

使用 as 子句重命名键

🎯 学习目标

  • 理解 as 子句的作用
  • 掌握键名转换技巧
  • 学会过滤特定键
  • 了解实际应用场景

📚 as 子句基础

// 键重映射使用 as 子句改变键名 // 语法：[K in keyof T as NewKey]: T[K] interface User { id: number; name: string; email: string; } // 添加前缀 type Prefixed = { [K in keyof T as `${P}${Capitalize}`]: T[K]; }; type PrefixedUser = Prefixed; // { userId: number; userName: string; userEmail: string; } // 添加后缀 type Suffixed = { [K in keyof T as `${string & K}${S}`]: T[K]; }; type SuffixedUser = Suffixed; // { idField: number; nameField: string; emailField: string; }
💡
as 子句

as 子句允许在映射类型中重新定义键名。结合模板字面量类型可以实现强大的键名转换。

🔧 过滤键

// 当 as 子句返回 never 时，该键会被过滤掉 type OnlyStrings = { [K in keyof T as T[K] extends string ? K : never]: T[K]; }; interface Mixed { id: number; name: string; email: string; active: boolean; } type StringProps = OnlyStrings; // { name: string; email: string; } // 排除特定键 type OmitByType = { [K in keyof T as T[K] extends U ? never : K]: T[K]; }; type WithoutNumbers = OmitByType; // { name: string; email: string; active: boolean; } // 只保留特定键 type PickByType = { [K in keyof T as T[K] extends U ? K : never]: T[K]; }; type OnlyNumbers = PickByType; // { id: number; }

🔀 Getter/Setter 生成

// 生成 getter 方法 type Getters = { [K in keyof T as `get${Capitalize}`]: () => T[K]; }; // 生成 setter 方法 type Setters = { [K in keyof T as `set${Capitalize}`]: (value: T[K]) => void; }; interface State { count: number; name: string; loading: boolean; } type StateGetters = Getters; // { getCount: () => number; getName: () => string; getLoading: () => boolean; } type StateSetters = Setters; // { setCount: (value: number) => void; setName: (value: string) => void; ... } // 组合 getter 和 setter type WithAccessors = T & Getters & Setters; type FullState = WithAccessors; // 包含所有属性和 getter/setter 方法

🎨 实用示例

// 将下划线命名转为驼峰 type CamelCase = S extends `${infer P}_${infer Q}` ? `${P}${Capitalize>}` : S; type CamelCaseKeys = { [K in keyof T as CamelCase]: T[K]; }; interface SnakeCase { user_id: number; user_name: string; created_at: Date; } type CamelCaseUser = CamelCaseKeys; // { userId: number; userName: string; createdAt: Date; } // 提取事件处理器类型 type EventHandler = { [K in keyof T as `on${Capitalize}`]: (event: T[K]) => void; }; interface Events { click: { x: number; y: number }; focus: { target: HTMLElement }; blur: { target: HTMLElement }; } type EventHandlers = EventHandler; // { onClick: (event: { x: number; y: number }) => void; ... }
⚠️
注意事项

键重映射是 TypeScript 4.1+ 的特性。确保使用支持此特性的 TypeScript 版本。
