13.1 global 对象

Node.js 全局作用域

🎯 学习目标

  • 理解 global 对象的作用
  • 掌握全局变量定义方式
  • 了解 global 与 globalThis 的区别
  • 学会正确使用全局变量

📚 global 对象简介

// global 是 Node.js 的全局对象 // 类似浏览器中的 window 对象 // 在全局作用域定义的变量不会成为 global 的属性 var myVar = 'Hello'; // 模块作用域，不是全局 console.log(global.myVar); // undefined // 显式添加到 global global.myGlobal = 'World'; console.log(global.myGlobal); // 'World' // globalThis 是现代标准（Node.js 12+ 支持） console.log(globalThis === global); // true // global 对象上的内置属性 console.log(global.process); // process 对象 console.log(global.console); // console 对象 console.log(global.Buffer); // Buffer 类 console.log(global.setTimeout); // setTimeout 函数
💡
注意

Node.js 中每个文件都是一个模块，顶层变量不会自动成为全局变量。

🔧 全局对象属性

// 查看所有全局属性 console.log(Object.keys(global)); // 主要内置属性： // - process: 进程对象 // - console: 控制台输出 // - Buffer: 二进制数据处理 // - setTimeout/setInterval: 定时器 // - setImmediate: 立即执行 // - __dirname: 当前目录 // - __filename: 当前文件路径 // - module: 模块对象 // - exports: 导出对象 // - require: 加载函数 // 注意：__dirname, __filename, module, exports, require // 实际上是模块包装函数的参数，不是 global 的属性 console.log(global.__dirname); // undefined console.log(__dirname); // '/path/to/current/dir'

📦 定义全局变量

// ========== config.js ========== // 方式一：使用 global global.config = { port: 3000, dbUrl: 'mongodb://localhost:27017/myapp', secret: 'my-secret-key' }; // 方式二：使用 globalThis（推荐） globalThis.config = { port: 3000, dbUrl: 'mongodb://localhost:27017/myapp' }; // ========== app.js ========== require('./config'); console.log(config.port); // 3000 // 但不推荐使用全局变量！ // 推荐方式：模块导出 // ========== config.js（推荐） ========== module.exports = { port: 3000, dbUrl: 'mongodb://localhost:27017/myapp', secret: 'my-secret-key' }; // ========== app.js ========== const config = require('./config'); console.log(config.port);

⚠️ 最佳实践

⚠️
  • • 避免使用全局变量，使用模块导出
  • • 全局变量可能导致命名冲突
  • • 全局变量难以测试和维护
  • • 优先使用依赖注入而非全局状态

📝 本节小结

✅
  • • global 是 Node.js 全局对象
  • • globalThis 是现代标准写法
  • • 模块顶层变量不是全局变量
  • • 避免使用全局变量，推荐模块导出
