46.5 数据转换

使用 class-transformer 转换数据

🎯 学习目标

  • 理解数据转换的作用
  • 掌握 class-transformer 装饰器
  • 学会响应序列化
  • 掌握隐式类型转换

📚 为什么需要数据转换？

HTTP 请求的数据都是字符串格式，需要转换为 TypeScript 的类型。响应时可能需要排除某些字段（如密码）。class-transformer 帮助完成这些转换。

// 问题示例 @Post() create(@Body() createUserDto: CreateUserDto) { // createUserDto 中的 age 是 string 类型，不是 number // 需要手动转换或使用自动转换 } // 解决方案：ValidationPipe 配置 transform: true app.useGlobalPipes( new ValidationPipe({ transform: true, // 启用自动转换 }), );

🔧 class-transformer 装饰器

import { Exclude, Expose, Transform, Type, plainToClass, } from 'class-transformer'; export class UserDto { @Expose() id: number; @Expose() name: string; @Expose() email: string; @Exclude() // 响应时排除此字段 password: string; @Expose() @Type(() => Date) // 转换为 Date 类型 createdAt: Date; @Expose({ name: 'user_name' }) // 重命名 userName: string; @Transform(({ value }) => value?.toUpperCase()) // 自定义转换 @Expose() country: string; @Expose() @Type(() => RoleDto) // 嵌套对象 role: RoleDto; }

🌐 响应序列化

// user.entity.ts import { Exclude, Expose, Type } from 'class-transformer'; export class User { @Expose() id: number; @Expose() name: string; @Exclude() password: string; @Exclude() salt: string; @Expose() @Type(() => Profile) profile: Profile; } // 控制器中使用 ClassSerializerInterceptor import { ClassSerializerInterceptor, UseInterceptors } from '@nestjs/common'; @Controller('users') @UseInterceptors(ClassSerializerInterceptor) // 启用序列化 export class UsersController { @Get(':id') async findOne(@Param('id') id: string): Promise { const user = await this.usersService.findOne(+id); return new User(user); // 返回实例，自动应用序列化 } @Get() async findAll(): Promise { const users = await this.usersService.findAll(); return users.map(user => new User(user)); } } // 全局启用 async function bootstrap() { const app = await NestFactory.create(AppModule); app.useGlobalInterceptors(new ClassSerializerInterceptor(app.get(Reflector))); await app.listen(3000); }
💡
序列化注意

ClassSerializerInterceptor 需要返回类的实例才能生效。直接返回普通对象不会应用 @Exclude/@Expose 装饰器。

📦 隐式类型转换

// dto/query.dto.ts import { IsInt, IsOptional } from 'class-validator'; import { Type } from 'class-transformer'; export class QueryDto { @IsOptional() @Type(() => Number) // 显式类型转换 @IsInt() page?: number; @IsOptional() @Type(() => Number) @IsInt() limit?: number; } // 或使用 ValidationPipe 的隐式转换 app.useGlobalPipes( new ValidationPipe({ transform: true, transformOptions: { enableImplicitConversion: true, // 根据类型自动转换 }, }), ); // DTO 定义类型后自动转换 export class QueryDto { @IsOptional() @IsInt() page?: number; // 会自动转换为 number @IsOptional() @IsInt() limit?: number; }

✨ 自定义转换示例

import { Transform, Type } from 'class-transformer'; export class CreateProductDto { // 字符串数组转换 @Transform(({ value }) => value?.split(',').map(Number)) tags: number[]; // 日期转换 @Type(() => Date) @Transform(({ value }) => new Date(value)) publishDate: Date; // 布尔值转换 @Transform(({ value }) => value === 'true' || value === true) isActive: boolean; // JSON 字符串转换 @Transform(({ value }) => { if (typeof value === 'string') { return JSON.parse(value); } return value; }) metadata: Record; // 大小写转换 @Transform(({ value }) => value?.toLowerCase()) email: string; // 去除空格 @Transform(({ value }) => value?.trim()) name: string; }
⚠️
转换顺序

ValidationPipe 先执行验证，再执行转换。确保 @Transform 不会破坏验证结果。复杂转换建议在 Service 层处理。

📝 本节小结

✅
  • • transform: true 启用自动类型转换
  • • @Exclude/@Expose 控制响应字段
  • • ClassSerializerInterceptor 实现响应序列化
  • • @Transform 自定义转换逻辑
