55.6 蒙特卡洛分析

统计特性与良率分析

🎯 学习目标

  • 理解蒙特卡洛分析的原理
  • 掌握随机变量设置
  • 学会评估设计良率

🎲 蒙特卡洛分析原理

统计仿真

蒙特卡洛分析通过随机采样器件参数，进行多次仿真来评估电路的统计特性。

  • 器件参数服从统计分布（通常为高斯分布）
  • 每次仿真使用不同的随机参数组合
  • 收集多次仿真的结果进行统计分析
  • 可以评估良率、失效模式等

🔧 设置随机变量

定义器件的统计分布

* 方法1：使用.param和分布函数 .param W_nom = 10u .param W_var = agauss(W_nom, 0.1u, 1) * 0.1u是标准差，1是sigma倍数 M1 out in 0 0 NMOS W=W_var L=0.18u * 方法2：在模型中定义 .model NMOS nmos level=49 + W=AGAUSS(10u,0.1u,1) + L=AGAUSS(0.18u,0.01u,1)

📊 运行蒙特卡洛分析

.mc命令

* 基本语法 .mc [runs] [analysis] [output] * 示例：运行100次直流扫描 .mc 100 dc v(out) max * 示例：运行200次交流分析 .mc 200 ac vdb(out) min * 示例：只运行瞬态分析 .mc 50 tran

📈 结果分析

统计特性

  • 均值：性能的平均值
  • 标准差：性能的分散程度
  • 良率：满足规格的比例
  • 直方图：性能分布
  • 灵敏度：各参数对性能的影响

🎯 设计优化

基于蒙特卡洛的优化

  • 中心值优化：使均值接近目标值
  • 方差减小：降低对工艺的敏感度
  • 最坏情况设计：确保在所有corner都工作
  • 设计裕度评估：确定安全裕度
