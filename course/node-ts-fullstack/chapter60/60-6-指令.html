60.6 指令

GraphQL 指令系统详解

📖 指令概述

指令（Directive）是 GraphQL 中用于影响查询执行行为的特殊语法。指令可以附加在字段、片段或操作上，实现条件包含、格式化等功能。

💡
指令的作用
  • 条件性地包含或排除字段
  • 修改字段行为
  • 添加元数据
  • 实现自定义功能

🔧 内置指令

@include(if: Boolean!)

条件为 true 时包含字段。

// 语法 field @include(if: $condition) // 示例 query GetUser($id: ID!, $withPosts: Boolean!) { user(id: $id) { id name email posts @include(if: $withPosts) { id title } } } // 变量 { "id": "123", "withPosts": true // posts 字段会被包含 } // 当 withPosts 为 false 时 { "data": { "user": { "id": "123", "name": "张三", "email": "zhang@example.com" // posts 字段不存在 } } }

@skip(if: Boolean!)

条件为 true 时跳过字段。

// 语法 field @skip(if: $condition) // 示例 query GetUsers($hideInactive: Boolean!) { users { id name email isActive lastLogin @skip(if: $hideInactive) } } // 变量 { "hideInactive": true // lastLogin 字段会被跳过 } // @include 和 @skip 可以组合使用 query GetUser($showPosts: Boolean!, $hideComments: Boolean!) { user(id: "123") { name posts @include(if: $showPosts) { title comments @skip(if: $hideComments) { content } } } }

@deprecated(reason: String)

标记字段已废弃。

type User { id: ID! name: String! // 废弃字段 fullName: String @deprecated(reason: "使用 name 字段替代") // 新字段 firstName: String lastName: String } // 查询时仍可使用，但会显示警告 query { user(id: "123") { name fullName // 会收到废弃警告 } }

⚙️ 自定义指令

定义指令

// Schema 中定义指令 directive @auth(requires: Role = USER) on FIELD_DEFINITION directive @upper on FIELD_DEFINITION directive @date(format: String = "yyyy-MM-dd") on FIELD_DEFINITION directive @cache(ttl: Int!) on QUERY // 指令位置 directive @example on | QUERY // 查询操作 | MUTATION // 变更操作 | SUBSCRIPTION // 订阅操作 | FIELD // 字段 | FRAGMENT_DEFINITION // 片段定义 | FRAGMENT_SPREAD // 片段引用 | INLINE_FRAGMENT // 内联片段 | VARIABLE_DEFINITION // 变量定义 | SCHEMA // Schema | SCALAR // 标量 | OBJECT // 对象类型 | FIELD_DEFINITION // 字段定义 | ARGUMENT_DEFINITION // 参数定义 | INTERFACE // 接口 | UNION // 联合类型 | ENUM // 枚举 | ENUM_VALUE // 枚举值 | INPUT_OBJECT // 输入类型 | INPUT_FIELD_DEFINITION // 输入字段定义

实现自定义指令

import { SchemaDirectiveVisitor } from 'graphql-tools'; import { GraphQLField, GraphQLString, defaultFieldResolver } from 'graphql'; // 大写指令 class UpperDirective extends SchemaDirectiveVisitor { visitFieldDefinition(field: GraphQLField<any, any>) { const { resolve = defaultFieldResolver } = field; field.resolve = async function (...args) { const result = await resolve.apply(this, args); if (typeof result === 'string') { return result.toUpperCase(); } return result; }; } } // 日期格式化指令 class DateDirective extends SchemaDirectiveVisitor { visitFieldDefinition(field: GraphQLField<any, any>) { const { resolve = defaultFieldResolver } = field; const { format } = this.args; field.resolve = async function (...args) { const result = await resolve.apply(this, args); if (result instanceof Date) { return formatDate(result, format); } return result; }; } } // 认证指令 class AuthDirective extends SchemaDirectiveVisitor { visitFieldDefinition(field: GraphQLField<any, any>) { const { resolve = defaultFieldResolver } = field; const { requires } = this.args; field.resolve = async function (root, args, context, info) { if (!context.user || !hasRole(context.user, requires)) { throw new Error('未授权访问'); } return resolve.call(this, root, args, context, info); }; } } // Schema 中使用 type User { id: ID! name: String! @upper createdAt: DateTime! @date(format: "yyyy年MM月dd日") } type Query { adminData: AdminData! @auth(requires: ADMIN) }

🔐 认证指令示例

// Schema directive @auth(requires: Role = USER) on FIELD_DEFINITION | OBJECT enum Role { USER ADMIN SUPER_ADMIN } type Query { // 公开接口 publicData: String! // 需要登录 userData: User! @auth // 需要管理员权限 adminData: AdminData! @auth(requires: ADMIN) } type Mutation { // 需要超级管理员 deleteUser(id: ID!): Boolean! @auth(requires: SUPER_ADMIN) } // 整个类型需要认证 type AdminPanel @auth(requires: ADMIN) { users: [User!]! statistics: Statistics! } // Apollo Server 实现 const server = new ApolloServer({ typeDefs, resolvers, schemaDirectives: { auth: AuthDirective, }, });

📦 缓存指令

// Schema directive @cache(ttl: Int!) on QUERY | FIELD type Query { // 缓存 60 秒 popularPosts: [Post!]! @cache(ttl: 60) // 缓存 5 分钟 categories: [Category!]! @cache(ttl: 300) } // 客户端使用 query GetPopularPosts @cache(ttl: 120) { popularPosts { title author { name } } }

🔄 常用指令库

指令 功能 来源
@auth 认证授权 graphql-auth-directives
@cache 缓存控制 apollo-cache-control
@rest REST 数据源 graphql-rest-binding
@validate 输入验证 graphql-constraints
@rateLimit 速率限制 graphql-rate-limit

📝 小结

  • @include 和 @skip 是最常用的内置指令
  • @deprecated 用于标记废弃字段
  • 自定义指令可以扩展 GraphQL 功能
  • 指令可用于认证、缓存、格式化等
  • 指令可以应用在多种位置
  • 合理使用指令提高代码复用性
