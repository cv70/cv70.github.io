35.5 模板继承与布局

学习模板的复用和组织方式

🎯 学习目标

  • 掌握模板继承机制
  • 学会使用布局模板
  • 理解模板包含的使用
  • 学会组织模板文件结构

📁 模板文件组织

views/ ├── layouts/ │ ├── main.ejs # 主布局 │ ├── admin.ejs # 管理后台布局 │ └── auth.ejs # 认证页面布局 ├── partials/ │ ├── header.ejs # 头部 │ ├── footer.ejs # 底部 │ ├── sidebar.ejs # 侧边栏 │ └── pagination.ejs # 分页组件 ├── pages/ │ ├── home.ejs # 首页 │ ├── about.ejs # 关于页 │ └── contact.ejs # 联系页 ├── users/ │ ├── index.ejs # 用户列表 │ ├── show.ejs # 用户详情 │ └── edit.ejs # 用户编辑 └── errors/ ├── 404.ejs # 404 页面 └── 500.ejs # 500 页面

🔧 EJS 布局（使用 express-ejs-layouts）

// 安装 npm install express-ejs-layouts // 配置 const expressLayouts = require('express-ejs-layouts'); app.use(expressLayouts); app.set('layout', 'layouts/main'); // views/layouts/main.ejs <!DOCTYPE html> <html> <head> <title><%= title %></title> <link rel="stylesheet" href="/css/style.css"> <%- contentFor('head') %> </head> <body> <%- include('../partials/header') %> <main> <%- body %> </main> <%- include('../partials/footer') %> <script src="/js/main.js"></script> </body> </html> // views/pages/home.ejs <%- contentFor('head', '<style>.hero { height: 500px; }</style>') %> <div class="hero"> <h1>Welcome</h1> </div>

📐 Pug 模板继承

//- views/layouts/main.pug doctype html html head block head title= title link(rel='stylesheet', href='/css/style.css') body include ../partials/header main block content include ../partials/footer script(src='/js/main.js') //- views/home.pug extends layouts/main block head title Home - My Site link(rel='stylesheet', href='/css/home.css') block content h1 Welcome to My Site p This is the home page //- 多级继承 //- views/layouts/admin.pug extends ./main block content .admin-wrapper include ../partials/admin/sidebar .admin-content block admin-content //- views/admin/dashboard.pug extends layouts/admin block admin-content h1 Admin Dashboard

📦 模板包含（Include）

<!-- EJS 包含 --> <!DOCTYPE html> <html> <body> <%- include('partials/header', { title: 'Page Title' }) %> <main> <!-- 页面内容 --> </main> <%- include('partials/footer') %> </body> </html> <!-- views/partials/pagination.ejs --> <div class="pagination"> <% if (currentPage > 1) { %> <a href="?page=<%= currentPage - 1 %>">Previous</a> <% } %> <% for (let i = 1; i <= totalPages; i++) { %> <a href="?page=<%= i %>" class="<%= i === currentPage ? 'active' : '' %>"> <%= i %> </a> <% } %> <% if (currentPage < totalPages) { %> <a href="?page=<%= currentPage + 1 %>">Next</a> <% } %> </div> <!-- 使用分页组件 --> <%- include('partials/pagination', { currentPage: page, totalPages: Math.ceil(total / limit) }) %>

🔄 动态布局

// 根据路由切换布局 app.get('/admin/*', (req, res, next) => { req.app.locals.layout = 'layouts/admin'; next(); }); app.get('/', (req, res) => { res.render('home', { layout: 'layouts/main' }); }); // API 文档使用不同布局 app.get('/docs', (req, res) => { res.render('docs/index', { layout: 'layouts/docs' }); }); // 无布局（返回片段） app.get('/partials/:name', (req, res) => { res.render(`partials/${req.params.name}`, { layout: false }); });

✅ 小结

📌
本节要点
  • 使用 layouts 目录存放布局模板
  • 使用 partials 目录存放可复用片段
  • express-ejs-layouts 为 EJS 提供布局支持
  • Pug 使用 extends 和 block 实现继承
