交割机制

期货交割是期货合约到期时的最终结算方式，分为实物交割和现金交割两种。理解交割机制对于期货交易者至关重要，特别是在临近交割期时，合约价格会向现货价格收敛，流动性也会发生变化。

📦 交割方式

实物交割

  • 买方交付资金，接收商品
  • 卖方交付商品，接收资金
  • 适用于商品期货
  • 需要处理仓储、运输等问题
  • 中国商品期货主要采用

现金交割

  • 按最后结算价现金结算
  • 无需实物交割
  • 适用于金融期货
  • 结算效率高
  • 股指期货主要采用

📋 交割流程

阶段 时间 关键事项
交割月前 交割月前1-2个月 持仓限制收紧，逐步移仓
最后交易日 交割月的特定日期 新开仓截止，可平仓
最后交割日 最后交易日后的几日内 实物交割完成

⚠️ 交割风险

📋
主要交割风险
  • 被动交割: 未及时平仓被强制交割，可能造成损失
  • 流动性风险: 临近交割流动性下降，滑点增大
  • 交割成本: 仓储费、运输费等额外成本
  • 质量差异: 交割品与预期不符
  • 交割失败: 无法完成交割导致违约

💻 Python实现示例

# 交割风险管理
import pandas as pd
from datetime import datetime, timedelta

class DeliveryRiskManager:
    """交割风险管理器"""

    def __init__(self):
        self.contracts = {}
        self.delivery_calendar = {}

    def check_delivery_risk(self, symbol, contract_month, current_date):
        """检查交割风险"""
        delivery_date = self.delivery_calendar.get(f"{symbol}_{contract_month}")

        if not delivery_date:
            return {'risk': 'unknown', 'days_to_delivery': None}

        days_to_delivery = (delivery_date - current_date).days

        if days_to_delivery <= 0:
            risk_level = "critical"
            action = "立即平仓，避免被动交割"
        elif days_to_delivery <= 5:
            risk_level = "high"
            action = "建议尽快移仓或平仓"
        elif days_to_delivery <= 20:
            risk_level = "medium"
            action = "关注移仓机会"
        else:
            risk_level = "low"
            action = "风险可控"

        return {
            'risk_level': risk_level,
            'days_to_delivery': days_to_delivery,
            'delivery_date': delivery_date,
            'action': action
        }

    def calculate_rolling_cost(self, near_price, far_price, contract_size):
        """计算移仓成本"""
        price_diff = far_price - near_price
        rolling_cost_pct = price_diff / near_price
        rolling_cost_abs = price_diff * contract_size

        return {
            'rolling_cost_pct': rolling_cost_pct,
            'rolling_cost_abs': rolling_cost_abs,
            'favorable': rolling_cost_pct < 0  # 负成本表示展期收益
        }

    def generate_rolling_signal(self, current_contract, next_contract):
        """生成移仓信号"""
        # 检查当前合约交割风险
        risk = self.check_delivery_risk(
            current_contract['symbol'],
            current_contract['month'],
            datetime.now()
        )

        if risk['risk_level'] in ['critical', 'high']:
            # 计算移仓成本
            cost = self.calculate_rolling_cost(
                current_contract['price'],
                next_contract['price'],
                current_contract['size']
            )

            if cost['rolling_cost_pct'] < 0.02:  # 移仓成本小于2%
                return {
                    'signal': 'roll',
                    'from': current_contract['contract'],
                    'to': next_contract['contract'],
                    'cost': cost['rolling_cost_pct'],
                    'action': '建议移仓至远月合约'
                }
            else:
                return {
                    'signal': 'close',
                    'action': '移仓成本过高，建议平仓'
                }

        return {
            'signal': 'hold',
            'action': '保持当前持仓'
        }

# 使用示例
manager = DeliveryRiskManager()

# 设置交割日历
manager.delivery_calendar['RB_2405'] = datetime(2024, 5, 15)
manager.delivery_calendar['RB_2406'] = datetime(2024, 6, 15)

# 检查交割风险
risk = manager.check_delivery_risk('RB', '2405', datetime(2024, 4, 20))
print("Delivery Risk:", risk)

# 计算移仓成本
cost = manager.calculate_rolling_cost(3800, 3850, 10)
print("Rolling Cost:", cost)
