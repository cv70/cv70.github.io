11.5 开发环境搭建

搭建完整的 Node.js 开发环境

🎯 学习目标

  • 掌握 Node.js 安装方法
  • 配置 npm 镜像源
  • 了解常用开发工具
  • 创建第一个 Node.js 项目

📚 安装 Node.js

# 方式一：官网下载安装包 # https://nodejs.org/ # 下载 LTS 版本安装包，双击安装 # 方式二：使用 nvm 安装（推荐） # Windows 安装 nvm-windows # 下载地址: https://github.com/coreybutler/nvm-windows/releases # Mac/Linux 安装 nvm curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash # 安装 Node.js nvm install 20 nvm use 20 # 验证安装 node -v # v20.10.0 npm -v # 10.2.3 # 查看安装路径 which node # Linux/Mac where node # Windows

🔧 配置 npm

# 查看当前镜像源 npm config get registry # 默认: https://registry.npmjs.org/ # 切换到淘宝镜像（国内推荐） npm config set registry https://registry.npmmirror.com # 或使用 nrm 管理镜像源 npm install -g nrm nrm ls # npm ---------- https://registry.npmjs.org/ # yarn --------- https://registry.yarnpkg.com/ # taobao ------- https://registry.npmmirror.com nrm use taobao # 切换到淘宝镜像 nrm use npm # 切换回官方源 # 设置 npm 缓存目录 npm config set cache "C:\nodejs\npm-cache" # 设置全局安装目录 npm config set prefix "C:\nodejs\npm-global" # 查看 npm 配置 npm config list

📦 常用开发工具

💡
  • • VS Code：最流行的 Node.js 开发 IDE
  • • WebStorm：JetBrains 出品，功能强大
  • • nodemon：自动重启开发服务器
  • • PM2：进程管理工具
# 全局安装常用工具 npm install -g nodemon # 自动重启 npm install -g pm2 # 进程管理 npm install -g yarn # Yarn 包管理器 npm install -g pnpm # pnpm 包管理器 npm install -g ts-node # 直接运行 TypeScript npm install -g typescript # TypeScript 编译器 # nodemon 使用 nodemon app.js # 文件变化自动重启 # PM2 使用 pm2 start app.js --name "my-app" pm2 list pm2 logs pm2 stop my-app pm2 restart my-app

# 创建项目目录 mkdir my-first-node-app cd my-first-node-app # 初始化项目 npm init -y # 或交互式初始化 npm init # 创建入口文件 # app.js const http = require('http'); const server = http.createServer((req, res) => { res.writeHead(200, { 'Content-Type': 'text/html; charset=utf-8' }); res.end('

Hello Node.js!

'); }); server.listen(3000, () => { console.log('Server running at http://localhost:3000'); }); # 运行项目 node app.js # 使用 nodemon 运行 nodemon app.js
