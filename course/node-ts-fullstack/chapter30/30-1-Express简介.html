📖 什么是 Express

Express 是一个基于 Node.js 平台的极简、灵活的 Web 应用开发框架。它提供了一系列强大的功能来帮助你创建各种 Web 和移动应用。Express 是 Node.js 最流行的 Web 框架之一，被广泛用于构建 RESTful API、单页应用后端、实时应用等服务。

// Express 基本使用示例 const express = require('express'); const app = express(); const port = 3000; // 定义路由 app.get('/', (req, res) => { res.send('Hello World!'); }); // 启动服务器 app.listen(port, () => { console.log(`服务器运行在 http://localhost:${port}`); });
💡
Express 的定位

Express 不是一个"大而全"的框架，而是提供了 Web 开发的基础功能，其他功能通过中间件扩展实现。这种设计让 Express 保持轻量且高度可定制。

📜 Express 的发展历史

2010年
Express 诞生

TJ Holowaychuk 创建了 Express，灵感来自 Ruby 的 Sinatra 框架。

2014年
StrongLoop 接管

Express 项目移交给 StrongLoop 公司维护。

2015年
Node 基金会

IBM 收购 StrongLoop，Express 成为 Node.js 基金会项目。

至今
持续发展

Express 保持稳定更新，成为 Node.js 生态中最成熟的 Web 框架。

⭐ Express 的核心特点

🎯 极简设计

Express 核心功能精简，不内置模板引擎、ORM 等，开发者可自由选择组件。

🔌 中间件架构

强大的中间件机制，请求处理流程清晰可控，功能扩展简单。

🛣️ 强大路由

灵活的路由系统，支持动态路由、路由参数、模块化路由等。

📦 丰富生态

NPM 上有大量 Express 中间件和插件，几乎可以满足所有需求。

📊 框架对比

特性 Express Koa NestJS
设计理念 极简、灵活 轻量、现代化 企业级、结构化
学习曲线 低 中等 较高
TypeScript 支持 需手动配置 需手动配置 原生支持
内置功能 路由、中间件 基本无 全面（DI、模块化等）
适用场景 小型项目、API 需要定制的项目 大型企业项目

⚠️
框架选择建议

Express 适合快速开发和小型项目；Koa 适合需要高度定制的场景；NestJS 适合大型企业级项目和团队协作。根据项目需求选择合适的框架。

模板引擎

Express 支持多种模板引擎，常用的有：

  • EJS - 嵌入式 JavaScript 模板
  • Pug - 简洁的模板语法（原 Jade）
  • Nunjucks - 功能丰富的模板引擎
  • Handlebars - 逻辑少的模板引擎

💡 Express 的设计理念

约定优于配置？不

Express 不强制任何项目结构或约定，完全由开发者决定如何组织代码。这带来了最大的灵活性，但也要求开发者有良好的架构能力。

中间件链式处理

请求通过一系列中间件处理，每个中间件可以：执行代码、修改请求/响应对象、结束响应、调用下一个中间件。

// 中间件链示意 app.use((req, res, next) => { console.log('第一个中间件'); next(); // 传递给下一个中间件 }); app.use((req, res, next) => { console.log('第二个中间件'); next(); }); app.get('/', (req, res) => { res.send('最终处理'); });
