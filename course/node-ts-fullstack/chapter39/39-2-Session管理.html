39.2 Session 管理

使用 Session 实现用户状态管理

🎯 学习目标

  • 理解 Session 的工作原理
  • 学会使用 koa-session
  • 掌握 Session 存储配置
  • 了解 Session 与 Cookie 的关系

📚 Session 原理

Session 是服务端存储用户状态的机制，通过 Cookie 中的 Session ID 关联服务端数据。

┌──────────┐ ┌──────────┐ │ 客户端 │ │ 服务端 │ └────┬─────┘ └────┬─────┘ │ │ │ 1. 首次请求 │ │ ─────────────────────────────>│ │ │ 创建 Session │ │ 生成 Session ID │ 2. 返回 Set-Cookie: sid=xxx │ │ <─────────────────────────────│ │ │ │ 3. 携带 Cookie: sid=xxx │ │ ─────────────────────────────>│ │ │ 查找 Session │ 4. 返回用户数据 │ │ <─────────────────────────────│
💡
Session vs Cookie

Session 存储在服务端，Cookie 存储在客户端。Session 更安全，适合存储敏感信息。

📦 安装 koa-session

# 安装 koa-session npm install koa-session
const Koa = require('koa'); const session = require('koa-session'); const app = new Koa(); // 设置密钥（用于签名） app.keys = ['secret-key-1', 'secret-key-2']; // Session 配置 const CONFIG = { key: 'koa:sess', // Cookie 名称 maxAge: 86400000, // 过期时间（毫秒） autoCommit: true, // 自动提交 overwrite: true, // 允许覆盖 httpOnly: true, // 仅 HTTP 访问 signed: true, // 签名 rolling: false, // 每次请求更新过期时间 renew: false, // 快过期时自动续期 }; app.use(session(CONFIG, app));

💻 基本使用

// 设置 Session router.get('/login', async ctx => { ctx.session.user = { id: 1, username: 'admin', role: 'admin' }; ctx.body = { message: 'Logged in' }; }); // 获取 Session router.get('/profile', async ctx => { const user = ctx.session.user; if (!user) { ctx.status = 401; ctx.body = { error: 'Not logged in' }; return; } ctx.body = { user }; }); // 销毁 Session router.get('/logout', async ctx => { ctx.session = null; // 方式1：设为 null // 或方式2 // ctx.session = {}; ctx.body = { message: 'Logged out' }; });

🔐 登录认证示例

const Router = require('koa-router'); const bcrypt = require('bcryptjs'); const router = new Router(); // 登录 router.post('/auth/login', async ctx => { const { username, password } = ctx.request.body; // 验证用户（示例） const user = await User.findOne({ where: { username } }); if (!user || !(await bcrypt.compare(password, user.password))) { ctx.status = 401; ctx.body = { error: 'Invalid credentials' }; return; } // 设置 Session ctx.session.user = { id: user.id, username: user.username, role: user.role }; ctx.body = { message: 'Login successful', user: ctx.session.user }; }); // 登出 router.post('/auth/logout', async ctx => { ctx.session = null; ctx.body = { message: 'Logged out' }; }); // 获取当前用户 router.get('/auth/me', async ctx => { if (!ctx.session.user) { ctx.status = 401; ctx.body = { error: 'Not authenticated' }; return; } ctx.body = { user: ctx.session.user }; }); // 认证中间件 function requireAuth(ctx, next) { if (!ctx.session.user) { ctx.status = 401; ctx.body = { error: 'Please login first' }; return; } return next(); } // 受保护的路由 router.get('/protected', requireAuth, async ctx => { ctx.body = { message: 'Protected content', user: ctx.session.user }); });

💾 Session 存储

默认 Session 存储在内存中，重启服务器会丢失。生产环境建议使用外部存储。

内存存储（默认）

  • 简单易用
  • 重启丢失
  • 不适合生产环境

Redis 存储

  • 持久化存储
  • 支持分布式
  • 高性能

🔄 Redis 存储配置

# 安装依赖 npm install koa-session koa-generic-session koa-redis
const session = require('koa-generic-session'); const RedisStore = require('koa-redis'); app.keys = ['secret-key']; app.use(session({ store: RedisStore({ host: 'localhost', port: 6379, password: '', db: 0 }), prefix: 'sess:', // Redis key 前缀 cookie: { maxAge: 86400000, httpOnly: true, signed: true } })); // 使用方式相同 router.get('/login', async ctx => { ctx.session.user = { id: 1, name: 'John' }; ctx.body = { message: 'OK' }; });

⚙️ Session 配置详解

const CONFIG = { // Cookie 键名 key: 'koa:sess', // 过期时间（毫秒） maxAge: 86400000, // 1 天 // 自动设置 Set-Cookie 头 autoCommit: true, // 是否覆盖同名 Cookie overwrite: true, // 是否禁止 JS 访问（安全） httpOnly: true, // 是否签名 Cookie signed: true, // 每次请求都重新设置过期时间 rolling: false, // Session 快过期时自动续期 renew: true, // 安全 Cookie（仅 HTTPS） secure: process.env.NODE_ENV === 'production', // 同站策略 sameSite: 'strict' }; app.use(session(CONFIG, app));
⚠️
生产环境注意

生产环境必须设置 secure: true 和 signed: true，确保 Cookie 安全。

📊 Session 管理工具

// 查看所有 Session（需 Redis） router.get('/admin/sessions', async ctx => { const client = require('redis').createClient(); const keys = await client.keys('sess:*'); const sessions = []; for (const key of keys) { const data = await client.get(key); sessions.push({ id: key, data: JSON.parse(data) }); } ctx.body = { count: sessions.length, sessions }; }); // 强制登出用户 router.delete('/admin/sessions/:sessionId', async ctx => { const client = require('redis').createClient(); await client.del(ctx.params.sessionId); ctx.body = { message: 'Session deleted' }; });
