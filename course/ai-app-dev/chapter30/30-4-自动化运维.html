30.4 自动化运维

AI应用的自动化部署与运维实践

🎯 学习目标

  • 理解自动化运维的重要性和核心理念
  • 掌握CI/CD流水线设计
  • 学会使用IaC管理基础设施
  • 了解AI应用的MLOps实践

什么是自动化运维？

自动化运维是通过工具和平台实现运维任务的自动化执行，包括自动部署、自动扩缩容、自动故障恢复等。自动化运维可以减少人为错误、提高效率、保障系统稳定性。

🔄 CI/CD流水线

阶段 任务 工具
代码提交 触发构建、代码检查 Git、GitHub/GitLab
持续集成 单元测试、集成测试 Jenkins、GitHub Actions
构建镜像 打包Docker镜像 Docker、Kaniko
持续部署 更新K8s部署 ArgoCD、Flux
验证发布 健康检查、冒烟测试 自定义脚本

🤖 GitHub Actions CI/CD示例

# .github/workflows/ai-deploy.yml
name: AI Model Deployment

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3

      - name: Set up Python
        uses: actions/setup-python@v4
        with:
          python-version: '3.10'

      - name: Install dependencies
        run: |
          pip install -r requirements.txt
          pip install pytest pytest-cov

      - name: Run tests
        run: |
          pytest tests/ --cov=src --cov-report=xml

      - name: Upload coverage
        uses: codecov/codecov-action@v3

  build-and-push:
    needs: test
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3

      - name: Login to ECR
        uses: aws-actions/amazon-ecr-login@v1

      - name: Build and push
        uses: docker/build-push-action@v4
        with:
          context: .
          push: true
          tags: |
            ${{ env.REGISTRY }}/ai-inference:${{ github.sha }}
            ${{ env.REGISTRY }}/ai-inference:latest

  deploy:
    needs: build-and-push
    runs-on: ubuntu-latest
    steps:
      - name: Deploy to Kubernetes
        run: |
          kubectl set image deployment/ai-inference \
            inference=${{ env.REGISTRY }}/ai-inference:${{ github.sha }}
          kubectl rollout status deployment/ai-inference

Terraform示例

# 定义GPU实例
resource "aws_instance" "gpu" {

  instance_type = "g4dn.xlarge"

  tags = {
    Name = "ai-inference-gpu"
  }

# 定义EKS集群
resource "aws_eks_cluster" "ai" {
  name     = "ai-cluster"
  role_arn = aws_iam_role.cluster.arn

  vpc_config {
    subnet_ids = aws_subnet.main[*].id
  }
}

🔄 GitOps实践

# ArgoCD Application配置
apiVersion: argoproj.io/v1alpha1
kind: Application
metadata:
  name: ai-inference
  namespace: argocd
spec:
  project: default
  source:
    repoURL: https://github.com/org/ai-infra
    targetRevision: main
    path: k8s/overlays/production
  destination:
    server: https://kubernetes.default.svc
    namespace: ai-system
  syncPolicy:
    automated:
      prune: true
      selfHeal: true
    syncOptions:
      - CreateNamespace=true

💡
自动化运维最佳实践

1. 小步快跑：频繁发布小版本，降低风险
2. 可回滚：每次部署都能快速回滚
3. 金丝雀发布：先部署小流量验证，再全量发布
4. 可观测性：部署后自动验证系统健康
