68.4 Jest 配置

第十部分：测试篇 - 深入了解 Jest 的配置选项

1. 配置文件方式

Jest 支持多种配置方式，可以根据项目需求选择最适合的方式。

配置文件选项

文件名 格式 说明
jest.config.js JavaScript 推荐方式，支持动态配置
jest.config.ts TypeScript TypeScript 项目推荐
jest.config.json JSON 简单静态配置
package.json JSON 内嵌在 package.json 中
// jest.config.js - 推荐的配置方式 /** @type {import('jest').Config} */ const config = { // 配置项 }; module.exports = config;
// jest.config.ts - TypeScript 配置 import type { Config } from 'jest'; const config: Config = { // 配置项 }; export default config;
// package.json 内嵌配置 { "jest": { "testEnvironment": "node", "testMatch": ["**/*.test.ts"] } }

2. 核心配置项

基础配置

module.exports = { // 测试环境：node 或 jsdom testEnvironment: 'node', // 根目录，默认为 package.json 所在目录 rootDir: './', // 搜索测试文件的目录 roots: ['<rootDir>/src', '<rootDir>/tests'], // 测试文件匹配模式 testMatch: [ '**/__tests__/**/*.[jt]s?(x)', '**/?(*.)+(spec|test).[jt]s?(x)' ], // 忽略的测试文件 testPathIgnorePatterns: [ '/node_modules/', '/dist/' ], // 是否递归搜索子目录 testRegex: '.*\\.test\\.(ts|js)$' };

TypeScript 配置

module.exports = { // 使用 ts-jest 预设 preset: 'ts-jest', // 或者手动配置 transform transform: { '^.+\\.tsx?$': [ 'ts-jest', { tsconfig: 'tsconfig.json', // 隔离模块，提升性能 isolatedModules: true, // 启用 ESM 支持 useESM: true } ] }, // 处理 ESM 模块 extensionsToTreatAsEsm: ['.ts'], // 模块文件扩展名 moduleFileExtensions: ['ts', 'tsx', 'js', 'jsx', 'json', 'node'] };

3. 模块解析配置

module.exports = { // 模块路径别名 moduleNameMapper: { // 路径别名 '^@/(.*)$': '<rootDir>/src/$1', '^@tests/(.*)$': '<rootDir>/tests/$1', '^@models/(.*)$': '<rootDir>/src/models/$1', '^@services/(.*)$': '<rootDir>/src/services/$1', // CSS 模块 Mock '\\.css$': 'identity-obj-proxy', // 静态资源 Mock '\\.(jpg|jpeg|png|gif|eot|otf|webp|svg|ttf|woff|woff2)$': '<rootDir>/__mocks__/fileMock.js' }, // 模块目录 modulePaths: ['<rootDir>/src'], // 忽略的模块 modulePathIgnorePatterns: ['<rootDir>/dist/'] };
💡
路径别名

moduleNameMapper 的别名应该与 tsconfig.json 中的 paths 配置保持一致，确保 TypeScript 和 Jest 都能正确解析模块路径。

4. 覆盖率配置

module.exports = { // 收集覆盖率的文件 collectCoverageFrom: [ 'src/**/*.{ts,tsx}', // 排除文件 '!src/**/*.d.ts', '!src/**/index.ts', '!src/main.ts', '!src/**/types.ts' ], // 覆盖率输出目录 coverageDirectory: 'coverage', // 覆盖率报告格式 coverageReporters: ['text', 'lcov', 'html', 'json-summary'], // 覆盖率提供者 coverageProvider: 'v8', // 或 'babel' // 覆盖率阈值（低于此值测试失败） coverageThreshold: { global: { branches: 80, functions: 80, lines: 80, statements: 80 }, // 指定文件的阈值 './src/services/': { branches: 90, functions: 90 } } };

覆盖率类型说明

类型 说明
branches 分支覆盖率（if/else、switch 等分支）
functions 函数覆盖率（函数是否被调用）
lines 行覆盖率（代码行是否执行）
statements 语句覆盖率（语句是否执行）

5. 性能优化配置

module.exports = { // 最大工作进程数 maxWorkers: '50%', // 测试超时时间（毫秒） testTimeout: 5000, // 慢测试阈值 slowTestThreshold: 300, // 缓存配置 cache: true, cacheDirectory: '<rootDir>/.jest-cache', // 并行执行 maxConcurrency: 5, // 启用 Watch 插件 watchPlugins: [ 'jest-watch-typeahead/filename', 'jest-watch-typeahead/testname' ] };

maxWorkers 配置

  • '50%' - 使用一半 CPU 核心
  • '2' - 使用 2 个工作进程
  • 默认根据 CPU 核心数自动分配

性能优化建议

  • 使用 isolatedModules: true
  • 合理设置测试超时
  • 开启缓存提升速度

6. 测试环境配置

module.exports = { // 测试环境 testEnvironment: 'node', // 或 'jsdom' // 环境配置 testEnvironmentOptions: { // jsdom 特定配置 html: '<html></html>', url: 'http://localhost', userAgent: 'agent' }, // 全局设置文件 globalSetup: '<rootDir>/tests/setup/global-setup.ts', // 全局清理文件 globalTeardown: '<rootDir>/tests/setup/global-teardown.ts', // 每个测试文件的设置 setupFiles: ['<rootDir>/tests/setup/env.ts'], // 测试框架设置 setupFilesAfterEnv: [ '<rootDir>/tests/setup/jest-setup.ts', 'jest-extended/all' ] };

环境选择

环境 适用场景
node Node.js 后端项目、API 测试
jsdom 前端项目、需要 DOM API 的测试
自定义环境 特殊需求，如数据库集成测试

7. 完整配置示例

// jest.config.ts import type { Config } from 'jest'; const config: Config = { // 预设 preset: 'ts-jest', // 测试环境 testEnvironment: 'node', // 根目录 rootDir: './', // 测试文件位置 roots: ['<rootDir>/src', '<rootDir>/tests'], // 测试匹配 testMatch: ['**/*.test.ts', '**/*.spec.ts'], // 忽略 testPathIgnorePatterns: ['/node_modules/', '/dist/'], // 模块解析 moduleNameMapper: { '^@/(.*)$': '<rootDir>/src/$1', '^@tests/(.*)$': '<rootDir>/tests/$1' }, // 转换 transform: { '^.+\\.tsx?$': ['ts-jest', { tsconfig: 'tsconfig.json', isolatedModules: true }] }, // 文件扩展名 moduleFileExtensions: ['ts', 'tsx', 'js', 'jsx', 'json'], // 覆盖率 collectCoverageFrom: [ 'src/**/*.ts', '!src/**/*.d.ts', '!src/main.ts' ], coverageDirectory: 'coverage', coverageReporters: ['text', 'lcov', 'html'], coverageThreshold: { global: { branches: 70, functions: 70, lines: 70, statements: 70 } }, // 性能 maxWorkers: '50%', testTimeout: 10000, // 设置文件 setupFilesAfterEnv: ['<rootDir>/tests/setup/jest-setup.ts'], // 详细输出 verbose: true, // 强制退出 forceExit: true, // 检测未关闭的资源 detectOpenHandles: true }; export default config;

8. 本节小结

📚
关键要点
  • 推荐使用 jest.config.ts 或 jest.config.js 作为配置文件
  • preset: 'ts-jest' 是 TypeScript 项目的快速配置方式
  • moduleNameMapper 用于路径别名映射
  • coverageThreshold 可以强制覆盖率要求
  • 合理的性能配置可以显著提升测试速度
