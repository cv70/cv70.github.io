60.5 输入类型

GraphQL 输入类型详解

📖 输入类型概述

输入类型（Input Type）专门用于定义传递给 Mutation 或 Query 的复杂参数结构。它与对象类型类似，但只能用于输入。

💡
Input Type vs Object Type
  • Input Type：用于参数输入，只能是标量、枚举或其他 Input Type
  • Object Type：用于输出，可以包含任意类型
  • Input Type 不能包含字段参数

📝 定义输入类型

// 基本输入类型 input CreateUserInput { name: String! email: String! password: String! age: Int } input UpdateUserInput { name: String email: String age: Int } // 嵌套输入类型 input CreatePostInput { title: String! content: String tags: [String!] settings: PostSettingsInput } input PostSettingsInput { isPublished: Boolean = false allowComments: Boolean = true visibility: Visibility = PUBLIC } enum Visibility { PUBLIC PRIVATE UNLISTED } // 带默认值的输入类型 input PaginationInput { page: Int = 1 pageSize: Int = 10 } input FilterInput { search: String = "" status: Status = ACTIVE tags: [String!] = [] }

🔧 使用输入类型

在 Mutation 中使用

type Mutation { createUser(input: CreateUserInput!): User! updateUser(id: ID!, input: UpdateUserInput!): User createPost(input: CreatePostInput!): Post! deleteUsers(ids: [ID!]!): DeleteResult! } // 调用 Mutation mutation CreateUser { createUser(input: { name: "张三" email: "zhangsan@example.com" password: "Password123!" age: 25 }) { id name email } } // 嵌套输入 mutation CreatePost { createPost(input: { title: "GraphQL 入门" content: "这是一篇教程..." tags: ["GraphQL", "教程"] settings: { isPublished: true allowComments: true visibility: PUBLIC } }) { id title } }

在 Query 中使用

input UserFilterInput { name: String email: String role: UserRole isActive: Boolean createdAfter: DateTime } input UserSortInput { field: UserSortField! order: SortOrder = ASC } type Query { users( filter: UserFilterInput sort: UserSortInput pagination: PaginationInput ): UserConnection! } // 调用 Query query GetUsers { users( filter: { role: ADMIN isActive: true createdAfter: "2024-01-01T00:00:00Z" } sort: { field: CREATED_AT, order: DESC } pagination: { page: 1, pageSize: 20 } ) { data { id name email } total } }

📦 变量与输入类型

// 定义带变量的查询 mutation CreateUser($input: CreateUserInput!) { createUser(input: $input) { id name email } } // 变量值 { "input": { "name": "张三", "email": "zhangsan@example.com", "password": "Password123!", "age": 25 } } // 复杂嵌套变量 mutation CreatePost($input: CreatePostInput!) { createPost(input: $input) { id title } } { "input": { "title": "文章标题", "content": "文章内容", "tags": ["技术", "教程"], "settings": { "isPublished": true, "visibility": "PUBLIC" } } }

🔄 类型复用模式

Create/Update 模式

// 创建输入（必填字段） input CreateUserInput { name: String! email: String! password: String! } // 更新输入（可选字段） input UpdateUserInput { name: String email: String password: String } type Mutation { createUser(input: CreateUserInput!): User! updateUser(id: ID!, input: UpdateUserInput!): User } // TypeScript 映射 interface CreateUserInput { name: string; email: string; password: string; } interface UpdateUserInput { name?: string; email?: string; password?: string; }

基础字段复用

// 用户基础字段 input UserBaseInput { name: String! email: String! bio: String } // 创建时扩展 input CreateUserInput { user: UserBaseInput! password: String! role: UserRole = USER } // 更新时扩展 input UpdateUserInput { user: UserBaseInput role: UserRole } // 调用示例 mutation { createUser(input: { user: { name: "张三" email: "zhangsan@example.com" bio: "前端开发" } password: "Password123!" }) { id name } }

🔍 过滤与搜索输入

// 通用过滤器 input StringFilter { eq: String ne: String in: [String!] nin: [String!] contains: String startsWith: String endsWith: String } input IntFilter { eq: Int ne: Int gt: Int gte: Int lt: Int lte: Int in: [Int!] } input DateTimeFilter { eq: DateTime gt: DateTime gte: DateTime lt: DateTime lte: DateTime } // 组合过滤器 input UserFilterInput { AND: [UserFilterInput!] OR: [UserFilterInput!] NOT: UserFilterInput name: StringFilter email: StringFilter age: IntFilter role: UserRoleFilter createdAt: DateTimeFilter isActive: Boolean } input UserRoleFilter { eq: UserRole in: [UserRole!] } // 查询示例 query GetUsers { users(filter: { OR: [ { name: { contains: "张" } } { name: { contains: "李" } } ] age: { gte: 18, lte: 60 } isActive: true }) { id name age } }

💻 TypeScript 类型生成

// 使用 GraphQL Code Generator 生成类型 // GraphQL Schema input CreateUserInput { name: String! email: String! password: String! age: Int role: UserRole = USER } // 生成的 TypeScript 类型 export type UserRole = 'USER' | 'ADMIN' | 'MODERATOR'; export interface CreateUserInput { name: string; email: string; password: string; age?: number | null; role?: UserRole; } // 在代码中使用 async function createUser(input: CreateUserInput): Promise { const response = await fetch('/graphql', { method: 'POST', body: JSON.stringify({ query: ` mutation CreateUser($input: CreateUserInput!) { createUser(input: $input) { id name email } } `, variables: { input }, }), }); return response.json(); } // 类型安全调用 const user = await createUser({ name: '张三', email: 'zhangsan@example.com', password: 'Password123!', // age 可选 // role 有默认值 });

📝 小结

  • 输入类型专门用于参数传递
  • 只能包含标量、枚举和其他输入类型
  • 支持嵌套和默认值
  • 可以定义复杂的过滤和搜索结构
  • 使用变量传递输入类型值
  • 可自动生成 TypeScript 类型
