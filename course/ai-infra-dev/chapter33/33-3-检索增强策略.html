检索增强概述

检索增强技术通过查询处理、检索优化、结果重排等手段，显著提升RAG系统的检索质量和用户体验。从基础的向量检索到高级RAG，需要综合运用多种策略。

✍️ 查询重写

LLM查询重写

LLM查询重写策略：

1. 问题分解
   原查询："如何用Python实现机器学习模型训练和评估？"

   分解后：
   - "如何用Python实现机器学习模型训练？"
   - "如何用Python实现机器学习模型评估？"

2. 语义重写
   原查询："怎么弄个网站？"

   重写后：
   - "如何创建一个网站？"
   - "网站开发的基本步骤是什么？"

3. 上下文增强
   用户："它支持什么语言？"
   上下文："关于PyTorch的讨论"

   重写后：
   - "PyTorch支持什么编程语言？"

4. 多版本生成
   生成3-5个版本的查询
   增加召回的多样性

实现示例：
def rewrite_query(query, history=None):
    prompt = f"""
    重写以下查询，使其更清晰、更具体：

    原查询：{query}

    对话历史：
    {history if history else "无"}

    请生成3个不同版本的重写查询，每行一个：
    """

    rewritten = llm.generate(prompt)
    return rewritten.split('\n')[:3]
💡
查询重写提示

查询重写要平衡精确性和召回率。过度重写可能偏离原意，不够重写又无法提升效果。建议使用多版本策略，增加检索多样性。

🔀 多路检索

多路检索融合

多路检索架构：

1. 并行检索路
   ├── 向量检索路：语义相似
   ├── 关键词检索路：精确匹配
   ├── 混合检索路：融合优势
   └── 多模型路：不同嵌入

2. 检索配置
   向量检索：
   ├── Top-K: 50
   ├── 索引类型: HNSW
   └── ef_search: 50

   关键词检索：
   ├── Top-K: 30
   ├── 索引类型: BM25
   └── 字段: title, content

   多模型检索：
   ├── 模型1: bge-large
   ├── 模型2: e5-large
   └── 模型3: m3e-large

3. 结果融合
   ├── 去重合并
   ├── 分数归一化
   ├── 加权融合
   └── 重新排序

融合策略：
• 向量权重: 0.6
• 关键词权重: 0.3
• 多模型平均: 0.1

📊 重排序技术

检索结果重排序

重排序架构：

1. 候选集生成
   ├── 初步检索: Top-100
   ├── 去重处理
   └── 质量过滤

2. 特征提取
   ├── 查询-文档相似度
   ├── 查询-文档相关性
   ├── 文档质量分数
   ├── 文档新鲜度
   └── 用户历史偏好

3. 重排序模型
   ├── 交叉编码器(Cross-Encoder)
   ├── LLM重排序
   ├── 学习排序(Learning to Rank)
   └── 规则排序

4. 最终选择
   ├── Top-K: 10-20
   ├── 多样性控制
   └── 平衡策略

重排序模型示例：
from sentence_transformers import CrossEncoder

# 加载重排序模型
reranker = CrossEncoder('BAAI/bge-reranker-large')

# 重排序
candidates = retrieve(query, top_k=100)
pairs = [[query, doc] for doc in candidates]
scores = reranker.predict(pairs)

# 选择Top-K
top_k = 10
sorted_docs = [x for _, x in sorted(zip(scores, candidates),
                                   reverse=True)][:top_k]

重排序使用更精确但更慢的模型（如Cross-Encoder）对初步检索结果进行精细排序，显著提升检索质量。

🔗 多跳检索

迭代式多跳检索

多跳检索流程：

第一跳：
查询: "什么是深度学习？"
检索: 返回相关文档

第二跳：
基于第一跳结果:
- 提取关键概念: "神经网络", "反向传播"
- 生成新查询: "神经网络是什么？", "反向传播如何工作？"
- 再次检索

第三跳：
基于前两跳结果:
- 发现关联主题: "卷积神经网络"
- 生成查询: "卷积神经网络的应用？"
- 继续检索

多跳终止条件：
1. 达到最大跳数(3-5跳)
2. 收敛(新结果与之前重叠)
3. 用户满意
4. 超时限制

优势：
• 深度探索主题
• 发现隐式关联
• 全面覆盖主题
• 提高召回率

劣势：
• 增加延迟
• 可能偏离主题
• 计算成本高
⚠️
多跳检索注意事项

多跳检索可能偏离原始意图，需要设置终止条件和质量监控。建议在专业领域或复杂查询时使用，简单查询可采用单跳检索。

🎯 高级RAG策略

Advanced RAG技术

  • 自适应检索：根据查询复杂度动态调整检索策略

  • 递归检索：基于检索结果生成新查询，递归检索
  • 元数据过滤：结合元数据进行精确过滤
  • 时序检索：考虑文档时间维度
  • 知识图谱检索：结合结构化知识

    CohereRerank

    retriever=base_retriever,
    llm=llm

# 2. 上下文压缩检索
compressor = LLMChainExtractor.from_llm(llm)
compression_retriever = ContextualCompressionRetriever(
    base_compressor=compressor,
    base_retriever=base_retriever
)

# 3. 重排序检索
compressor = CohereRerank(top_n_results=5)
rerank_retriever = ContextualCompressionRetriever(
    base_compressor=compressor,
    base_retriever=base_retriever
)

# 4. 父文档检索
parent_retriever = ParentDocumentRetriever(
    vectorstore=vectorstore,

    parent_splitter=parent_splitter,
    child_splitter=child_splitter

# 组合使用
