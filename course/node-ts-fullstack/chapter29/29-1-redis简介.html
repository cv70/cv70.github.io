📚 Redis 特点

Redis（Remote Dictionary Server）是一个开源的内存数据结构存储系统，可用作数据库、缓存和消息代理。

Redis 核心特点： 1. 高性能 ├── 基于内存操作 ├── 单线程处理请求 ├── QPS 可达 10 万+ └── 平均响应时间 < 1ms 2. 丰富的数据类型 ├── String - 字符串 ├── Hash - 哈希表 ├── List - 列表 ├── Set - 集合 ├── ZSet - 有序集合 ├── Bitmap - 位图 ├── HyperLogLog - 基数统计 └── Stream - 流 3. 持久化支持 ├── RDB - 快照 └── AOF - 追加日志 4. 高可用特性 ├── 主从复制 ├── 哨兵模式 └── 集群模式 Redis vs Memcached： ┌─────────────┬──────────────┬───────────────┐ │ 特性 │ Redis │ Memcached │ ├─────────────┼──────────────┼───────────────┤ │ 数据类型 │ 多种 │ 仅字符串 │ │ 持久化 │ 支持 │ 不支持 │ │ 集群 │ 支持 │ 不支持 │ │ 事务 │ 支持 │ 不支持 │ │ 性能 │ 高 │ 高 │ │ 内存管理 │ 更高效 │ 预分配 │ └─────────────┴──────────────┴───────────────┘

生产环境配置

生产环境建议设置密码、限制最大内存、启用持久化。使用 Redis Sentinel 或 Cluster 实现高可用。

📊 Node.js 连接

# 安装依赖 npm install ioredis # 或 npm install redis // 使用 ioredis（推荐） import Redis from 'ioredis'; // 基本连接 const redis = new Redis({ host: 'localhost', port: 6379, password: 'your_password', db: 0, // 数据库编号 0-15 }); // 连接 URL const redis = new Redis('redis://:password@localhost:6379/0'); // 基本操作 await redis.set('name', 'Alice'); const name = await redis.get('name'); console.log(name); // 'Alice' await redis.del('name'); // 设置过期时间 await redis.set('key', 'value', 'EX', 60); // 60 秒后过期 // 批量操作 await redis.mset('key1', 'value1', 'key2', 'value2'); const values = await redis.mget('key1', 'key2'); // 检查 key 是否存在 const exists = await redis.exists('key'); // 设置过期时间 await redis.expire('key', 3600); // 1 小时后过期 // 获取剩余过期时间 const ttl = await redis.ttl('key'); // 事件监听 redis.on('connect', () => { console.log('Redis connected'); }); redis.on('error', (error) => { console.error('Redis error:', error); }); // 使用官方 redis 包 import { createClient } from 'redis'; const client = createClient({ url: 'redis://localhost:6379', }); await client.connect(); await client.set('key', 'value'); const value = await client.get('key'); await client.disconnect();

⚙️ 典型应用场景

1. 缓存 ├── 热点数据缓存 ├── 会话存储 ├── 页面缓存 └── 查询结果缓存 2. 计数器 ├── 文章阅读量 ├── 用户积分 ├── 点赞数 └── 在线人数 3. 排行榜 ├── 游戏排行榜 ├── 热门内容 └── 积分排名 4. 消息队列 ├── 简单队列 ├── 延迟队列 └── 发布订阅 5. 分布式锁 ├── 防止重复操作 ├── 库存扣减 └── 定时任务互斥 6. 社交功能 ├── 好友关系 ├── 时间线 └── 点赞/关注 7. 地理位置 ├── 附近的人 ├── 商家搜索 └── 轨迹追踪 选择 Redis 的依据： ├── 需要极快的读写速度 ├── 数据可以容忍部分丢失 ├── 需要丰富的数据结构 ├── 需要原子操作 └── 需要过期自动清理
