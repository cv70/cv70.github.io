训练稳定性概述

大模型训练往往面临数值不稳定、收敛困难、梯度爆炸/消失等问题。 这些问题会导致训练中断、性能下降甚至完全失败。通过系统化的稳定性优化， 可以确保训练稳定进行并获得良好的模型性能。

⚠️ 训练不稳定的现象

常见不稳定问题

问题 表现 原因
梯度爆炸 Loss变为NaN或Inf 学习率过大、梯度累积
梯度消失 Loss不下降或极小 学习率过小、深层网络
Loss波动 Loss剧烈震荡 batch size小、学习率不稳定
数值溢出 FP16溢出 FP16范围有限
精度损失 模型性能下降 混合精度训练
训练停滞 Loss长时间不变 陷入局部最优

🔢 数值稳定性优化

混合精度和Loss Scaling

FP16 Loss Scaling： 问题： • FP16范围有限: ±65504 • 梯度容易溢出 • 训练不稳定 解决方案：动态Loss Scaling 原理： • 在反向传播前放大loss • 梯度相应放大 • 更新时缩小梯度 • 动态调整scale factor 实现： from torch.cuda.amp import autocast, GradScaler scaler = GradScaler( init_scale=2.**16, # 初始scale = 65536 growth_factor=2.0, # 成功时倍增 backoff_factor=0.5, # 失败时减半 growth_interval=2000, # 连续成功2000步后增长 ) for inputs, labels in dataloader: optimizer.zero_grad() with autocast(): outputs = model(inputs) loss = loss_fn(outputs, labels) # 反向传播（自动loss scaling） scaler.scale(loss).backward() # 梯度裁剪 scaler.unscale_(optimizer) torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0) # 更新参数 scaler.step(optimizer) scaler.update() BF16训练（推荐Ampere+）： 优势： • 范围更大: ±3.3×10³⁸ • 不需要loss scaling • 更好的数值稳定性 • 与FP32相同的指数位 实现： from torch.cuda.amp import autocast model = model.bfloat16() # 转换为BF16 for inputs, labels in dataloader: optimizer.zero_grad() with autocast(dtype=torch.bfloat16): outputs = model(inputs) loss = loss_fn(outputs, labels) loss.backward() torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0) optimizer.step()

📈 学习率优化

学习率调度策略

Warmup: 问题： • 训练初期梯度不稳定 • 大学习率导致震荡 解决方案：Warmup 原理： • 初始学习率很小 • 逐步增加到目标学习率 • 避免早期不稳定 实现： import math def get_warmup_lr(current_step, total_warmup_steps, base_lr): """线性warmup""" if current_step < total_warmup_steps: return base_lr * current_step / total_warmup_steps return base_lr # 使用 for step in range(total_steps): lr = get_warmup_lr(step, warmup_steps, base_lr) optimizer.param_groups[0]['lr'] = lr # ... Cosine Decay: 原理： • 训练后期逐步降低学习率 • 使用cosine函数平滑衰减 • 改善最终收敛 实现： def get_cosine_lr(current_step, total_steps, base_lr, min_lr): """Cosine decay""" if current_step < total_steps: alpha = current_step / total_steps lr = min_lr + 0.5 * (base_lr - min_lr) * (1 + math.cos(math.pi * alpha)) else: lr = min_lr return lr Warmup + Cosine Decay组合： def get_lr_with_warmup_cosine(current_step, warmup_steps, total_steps, base_lr, min_lr): """Warmup + Cosine decay""" if current_step < warmup_steps: # Warmup阶段 return base_lr * current_step / warmup_steps elif current_step < total_steps: # Cosine decay阶段 alpha = (current_step - warmup_steps) / (total_steps - warmup_steps) lr = min_lr + 0.5 * (base_lr - min_lr) * (1 + math.cos(math.pi * alpha)) return lr else: return min_lr

✂️ 梯度裁剪

防止梯度爆炸

梯度裁剪原理： 问题： • 梯度可能变得非常大 • 导致参数更新过大 • 模型崩溃 解决方案：限制梯度范数 实现方式： 1. 按范数裁剪（Clipping by Norm） def clip_grad_norm(parameters, max_norm): """按范数裁剪梯度""" parameters = list(filter(lambda p: p.grad is not None, parameters)) total_norm = 0 for p in parameters: param_norm = p.grad.data.norm(2) total_norm += param_norm.item() ** 2 total_norm = total_norm ** 0.5 if total_norm > max_norm: clip_coef = max_norm / total_norm for p in parameters: p.grad.data.mul_(clip_coef) return total_norm # 使用 for batch in dataloader: loss.backward() torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0) optimizer.step() 2. 按值裁剪（Clipping by Value） def clip_grad_value(parameters, clip_value): """按值裁剪梯度""" for p in parameters: if p.grad is not None: p.grad.data.clamp_(-clip_value, clip_value) # 使用 for batch in dataloader: loss.backward() clip_grad_value(model.parameters(), clip_value=1.0) optimizer.step() 最佳实践： • max_norm通常设为1.0或0.5 • 在混合精度训练中使用 • 与loss scaling配合使用 • 监控梯度范数
图：持续监控训练是保持稳定性的关键

📊 训练监控

关键监控指标

监控指标： 1. Loss曲线 • 正常: 平滑下降 • 异常: 震荡、不下降、突然上升 2. 学习率 • 确认warmup和decay正常 • 监控是否过大或过小 3. 梯度范数 • 监控梯度大小 • 检测梯度爆炸/消失 4. 参数更新 • 监控参数变化幅度 • 确保合理更新 5. GPU利用率 • 确保GPU正常工作 • 检测GPU空闲 6. 内存使用 • 显存占用 • 系统内存 实现监控： import torch import numpy as np from torch.utils.tensorboard import SummaryWriter writer = SummaryWriter() gradient_norms = [] losses = [] for step, (inputs, labels) in enumerate(dataloader): # 前向传播 outputs = model(inputs) loss = loss_fn(outputs, labels) # 反向传播 optimizer.zero_grad() loss.backward() # 记录loss losses.append(loss.item()) if step % 100 == 0: avg_loss = np.mean(losses[-100:]) writer.add_scalar('Loss/train', avg_loss, step) # 计算梯度范数 total_norm = 0 for p in model.parameters(): if p.grad is not None: param_norm = p.grad.data.norm(2) total_norm += param_norm.item() ** 2 total_norm = total_norm ** 0.5 gradient_norms.append(total_norm) if step % 100 == 0: avg_grad_norm = np.mean(gradient_norms[-100:]) writer.add_scalar('Gradients/norm', avg_grad_norm, step) # 更新参数 optimizer.step()

🔧 其他优化技巧

权重初始化

  • Xavier初始化：适合sigmoid/tanh
  • He初始化：适合ReLU
  • 预训练模型：微调时使用
torch.nn.init.xavier_uniform_(layer.weight) torch.nn.init.kaiming_normal_(layer.weight, mode='fan_out')

正则化

  • Dropout：防止过拟合
  • 权重衰减：L2正则化
  • LayerNorm：稳定训练
torch.nn.Dropout(p=0.1) torch.nn.LayerNorm(hidden_size)

💡 调试技巧

常见问题诊断

问题 诊断方法 解决方案
Loss为NaN 检查梯度、学习率 降低学习率、启用loss scaling
Loss不下降 检查梯度大小 增加学习率、检查数据
Loss震荡 观察loss曲线 减小学习率、增大batch size
精度低 对比FP32训练 使用BF16、调整loss scaling
⚠️
稳定性注意事项
  • 从小规模开始：先用小模型验证训练流程
  • 逐步增大batch：逐步增加batch size
  • 监控关键指标：持续监控loss、梯度等
  • 定期保存checkpoint：防止训练失败丢失进度
  • 及时调整：发现异常及时调整参数
