API安全概述

API安全是指保护应用程序编程接口（API）免受攻击和滥用的措施。 在AI基础设施中，API是模型服务、训练任务、数据访问等核心功能的入口，API安全至关重要。

⚠️ 常见API安全威胁

注入攻击

  • SQL注入
  • NoSQL注入
  • 命令注入
  • 代码注入

认证绕过

  • 弱认证机制
  • 会话劫持
  • 令牌重放
  • 权限提升

数据泄露

  • 敏感信息暴露
  • 过度数据返回
  • 错误信息泄露
  • 日志信息泄露

资源滥用

  • DDoS攻击
  • 限流绕过
  • 资源耗尽
  • 恶意爬取

🔐 API认证机制

认证方式 优点 缺点 适用场景
API Key 简单易实现 安全性较低，难以撤销 简单服务、内部调用
Bearer Token 标准协议，易于集成 需要令牌管理 RESTful API

mTLS 双向认证，安全性高 证书管理复杂 高安全要求的服务

📝 API限流策略

令牌桶算法

# 令牌桶限流实现
from time import time
import threading

class TokenBucket:
    def __init__(self, rate, capacity):
        self.rate = rate  # 令牌生成速率（令牌/秒）
        self.capacity = capacity  # 桶容量
        self.tokens = capacity
        self.last_time = time()
        self.lock = threading.Lock()

    def consume(self, tokens=1):
        with self.lock:
            now = time()
            # 添加新令牌
            elapsed = now - self.last_time
            self.tokens = min(
                self.capacity,
                self.tokens + elapsed * self.rate
            )
            self.last_time = now

            # 消费令牌
            if self.tokens >= tokens:
                self.tokens -= tokens
                return True
            return False

# 使用示例
bucket = TokenBucket(rate=10, capacity=20)

if bucket.consume():
    print("请求通过")
else:
    print("请求被限流")

🔍 API安全检查清单

  • 认证: 实施强认证机制，支持多因素认证
  • 授权: 实施细粒度权限控制，遵循最小权限原则
  • 输入验证: 验证所有输入，防止注入攻击
  • 输出编码: 对输出进行编码，防止XSS攻击
  • 限流: 实施速率限制，防止API滥用
  • 日志: 记录所有API调用，便于审计和追踪
  • 监控: 监控异常行为，及时发现攻击
  • HTTPS: 强制使用HTTPS，保护传输安全
💡
API网关的作用

API网关是保护API安全的重要组件，它提供统一的安全入口： 认证、授权、限流、日志、监控等功能都可以在网关层实现。

🌐 AI模型API安全实践

模型推理API

  • 实施API Key认证
  • 限制调用频率
  • 监控输入输出大小
  • 过滤恶意输入

训练任务API

  • 严格的RBAC控制
  • 资源配额限制
  • 审计任务操作
  • 保护训练数据
⚠️
模型API特殊风险
  • 提示注入: 通过精心设计的输入操纵模型输出
  • 模型窃取: 通过API查询窃取模型参数
  • 对抗攻击: 生成对抗样本欺骗模型
  • 数据泄露: 通过模型输出反向推断训练数据
