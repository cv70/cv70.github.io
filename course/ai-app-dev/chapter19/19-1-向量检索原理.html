什么是向量检索

向量检索（Vector Search）是一种基于语义相似度的检索技术。它将文本、图像等数据转换为高维向量， 然后通过计算向量之间的距离来找出最相似的内容。相比传统的关键词匹配，向量检索能够理解语义，实现"意思相近"的匹配。

特性 关键词检索 向量检索

📐 相似度计算方法

余弦相似度

cos(a,b) = a·b / |a||b|

最常用，关注方向而非大小

欧氏距离

d = ||a - b||

绝对距离，考虑大小差异

点积

dot = a · b

计算简单，适合归一化向量

💻 Python实现相似度计算

import numpy as np # 定义两个向量 vec_a = np.array([0.1, 0.3, 0.5, 0.2]) vec_b = np.array([0.2, 0.4, 0.4, 0.1]) # 余弦相似度 def cosine_sim(a, b): return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b)) # 欧氏距离 def euclidean_dist(a, b): return np.linalg.norm(a - b) # 点积 dot_product = np.dot(vec_a, vec_b) print(f"余弦相似度: {cosine_sim(vec_a, vec_b):.4f}") print(f"欧氏距离: {euclidean_dist(vec_a, vec_b):.4f}") print(f"点积: {dot_product:.4f}")

关键理解

向量检索的核心是将"语义相似性"问题转化为"向量距离"问题。 通过Embedding模型将文本映射到向量空间，语义相似的文本在向量空间中距离更近。 ANN算法在精度与速度之间权衡，精确搜索慢但准确，近似搜索快但可能漏掉部分结果。

📝 本节小结

✅
  • • 向量检索基于语义相似度，比关键词匹配更智能
  • • 常用余弦相似度、欧氏距离、点积计算相似度
  • • 大规模数据使用ANN算法（HNSW、IVF等）加速
  • • 向量检索是RAG、推荐系统、语义搜索的基础
