52.1 UART接口设计

常用外设接口设计

  • 了解UART的配置与调试技巧

📚 UART概述

UART（Universal Asynchronous Receiver/Transmitter）通用异步收发传输器是一种串行通信接口，广泛用于微控制器与外设之间的通信。它采用异步传输方式，只需两根信号线（TX和RX）即可实现全双工通信。

💡
UART特点

• 异步通信：无需时钟信号同步
• 全双工：可同时收发数据
• 简单易用：只需TX、RX两根线
• 灵活配置：支持多种波特率和数据格式

🔌 UART信号接口

信号方向描述电平
TX输出发送数据3.3V/5V TTL
RX输入接收数据3.3V/5V TTL
RTS输出请求发送（流控）可选
CTS输入清除发送（流控）可选
GND-信号地0V
⚠️
电平转换注意

UART通常使用TTL电平（0-3.3V或0-5V），如需与RS-232设备通信，需要使用电平转换芯片（如MAX232）。

📦 UART数据帧格式

标准UART数据帧

| 起始位 | 数据位 | 奇偶校验位 | 停止位 |

| 1 bit | 5-9 bits | 0-1 bit | 1-2 bits |

起始位（Start Bit）

固定为0，表示数据帧开始，触发接收器同步。

数据位（Data Bits）

通常为8位，可配置为5、6、7或9位，先传LSB。

奇偶校验位（Parity Bit）

可选，用于错误检测。可配置为奇校验、偶校验或无校验。

停止位（Stop Bits）

固定为1，可配置为1、1.5或2位，表示数据帧结束。

⚙️ UART模块硬件设计

UART发送模块（UART TX）

// UART发送模块结构
module uart_tx #(
    parameter CLK_FREQ = 50_000_000,  // 系统时钟频率
    parameter BAUD_RATE = 115200      // 波特率
) (
    input  wire       clk,
    input  wire       rst_n,
    input  wire       tx_start,       // 发送启动信号
    input  wire [7:0] tx_data,        // 发送数据
    output reg        tx,             // UART TX信号
    output reg        tx_busy         // 发送忙标志
);

    // 波特率生成器
    localparam BAUD_DIV = CLK_FREQ / BAUD_RATE;
    reg [15:0] baud_counter;

    // 发送状态机
    localparam IDLE = 0, START = 1, DATA = 2, PARITY = 3, STOP = 4;
    reg [2:0] state;
    reg [3:0] bit_cnt;
    reg [7:0] tx_shift;

    // 状态机实现
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            state <= IDLE;
            tx <= 1;
            tx_busy <= 0;
            bit_cnt <= 0;
            baud_counter <= 0;
        end else begin
            case (state)
                IDLE: begin
                    tx <= 1;
                    tx_busy <= 0;
                    if (tx_start) begin
                        state <= START;
                        tx_shift <= tx_data;
                        tx_busy <= 1;
                        baud_counter <= 0;
                    end
                end
                START: begin
                    tx <= 0;
                    if (baud_counter >= BAUD_DIV-1) begin
                        state <= DATA;
                        baud_counter <= 0;
                        bit_cnt <= 0;
                    end else begin
                        baud_counter <= baud_counter + 1;
                    end
                end
                DATA: begin
                    tx <= tx_shift[0];
                    if (baud_counter >= BAUD_DIV-1) begin
                        tx_shift <= tx_shift >> 1;
                        if (bit_cnt >= 7) begin
                            state <= STOP;
                        end else begin
                            bit_cnt <= bit_cnt + 1;
                        end
                        baud_counter <= 0;
                    end else begin
                        baud_counter <= baud_counter + 1;
                    end
                end
                STOP: begin
                    tx <= 1;
                    if (baud_counter >= BAUD_DIV-1) begin
                        state <= IDLE;
                        tx_busy <= 0;
                    end else begin
                        baud_counter <= baud_counter + 1;
                    end
                end
            endcase
        end
    end

endmodule

UART接收模块（UART RX）

// UART接收模块结构
module uart_rx #(
    parameter CLK_FREQ = 50_000_000,
    parameter BAUD_RATE = 115200
) (
    input  wire       clk,
    input  wire       rst_n,
    input  wire       rx,             // UART RX信号
    output reg [7:0]  rx_data,        // 接收数据
    output reg        rx_valid,       // 数据有效标志
    output reg        rx_error        // 帧错误标志
);

    localparam BAUD_DIV = CLK_FREQ / BAUD_RATE;
    reg [15:0] baud_counter;
    reg [3:0] bit_cnt;
    reg [7:0] rx_shift;
    reg rx_sync1, rx_sync2;  // 同步寄存器

    // 边沿检测
    wire rx_falling = rx_sync2 & ~rx_sync1;

    // 状态机
    localparam IDLE = 0, START = 1, DATA = 2, STOP = 3;
    reg [1:0] state;

    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            state <= IDLE;
            rx_valid <= 0;
            rx_error <= 0;
            rx_sync1 <= 1;
            rx_sync2 <= 1;
            baud_counter <= 0;
        end else begin
            // 同步异步输入
            rx_sync1 <= rx;
            rx_sync2 <= rx_sync1;

            rx_valid <= 0;
            rx_error <= 0;

            case (state)
                IDLE: begin
                    if (rx_falling) begin
                        state <= START;
                        baud_counter <= BAUD_DIV/2;  // 中心采样
                    end
                end
                START: begin
                    if (baud_counter >= BAUD_DIV-1) begin
                        if (rx_sync2) begin
                            rx_error <= 1;
                            state <= IDLE;
                        end else begin
                            state <= DATA;
                            bit_cnt <= 0;
                        end
                        baud_counter <= 0;
                    end else begin
                        baud_counter <= baud_counter + 1;
                    end
                end
                DATA: begin
                    if (baud_counter >= BAUD_DIV-1) begin
                        rx_shift[bit_cnt] <= rx_sync2;
                        if (bit_cnt >= 7) begin
                            state <= STOP;
                            rx_data <= rx_shift;
                        end else begin
                            bit_cnt <= bit_cnt + 1;
                        end
                        baud_counter <= 0;
                    end else begin
                        baud_counter <= baud_counter + 1;
                    end
                end
                STOP: begin
                    if (baud_counter >= BAUD_DIV-1) begin
                        if (!rx_sync2) begin
                            rx_error <= 1;
                        end else begin
                            rx_valid <= 1;
                        end
                        state <= IDLE;
                    end else begin
                        baud_counter <= baud_counter + 1;
                    end
                end
            endcase
        end
    end

endmodule

📊 常用波特率

波特率应用场景典型用途
9600低速设备传感器、旧式设备
19200中低速PLC、工业控制
38400中速GPS模块
57600中高速蓝牙模块
115200高速（最常用）调试输出、下载器
230400超高速高速数据传输
921600极高速高带宽数据

🔧 UART配置寄存器

控制寄存器（UART_CTRL）

| 位 | 名称 | 描述 |

| [31:16] | BAUD_DIV | 波特率分频值 |

| [3:2] | STOP_BITS | 停止位：00=1, 01=1.5, 10=2 |

| [1:0] | PARITY | 奇偶校验：00=无, 01=奇, 10=偶 |

状态寄存器（UART_STATUS）

| 位 | 名称 | 描述 |

| [7] | RX_OVF | 接收溢出 |

| [6] | RX_ERR | 接收错误 |

| [5] | TX_BUSY | 发送忙 |

| [4] | RX_AVAIL | 接收数据可用 |

🐛 常见问题与调试

⚠️
常见问题

1. 波特率不匹配
症状：接收数据乱码
解决：检查波特率设置，确保收发一致

2. 数据帧格式不一致
症状：接收错误或丢包
解决：确认数据位、校验位、停止位配置相同

3. 电平不兼容
症状：无法通信
解决：添加电平转换电路

4. 时钟漂移
症状：长时间通信后出错
解决：使用高精度晶振，优化波特率分频

📝 本节小结

✅
  • • UART是异步串行通信接口，使用TX/RX两根线实现全双工通信
  • • UART数据帧由起始位、数据位、校验位、停止位组成
  • • UART模块包括波特率生成器、发送状态机、接收状态机
  • • 常用波特率从9600到921600，115200最常用
  • • 波特率匹配、帧格式一致、电平兼容是正常通信的关键
