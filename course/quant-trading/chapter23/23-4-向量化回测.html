向量化回测

向量化回测利用NumPy和Pandas的向量化运算能力，一次性处理整个时间序列数据，大幅提升回测效率。适合简单策略和大规模参数优化场景。

⚡ 向量化核心概念

🔢

数组运算

使用NumPy数组进行批量计算

📊

数据框操作

使用Pandas DataFrame处理时间序列

🚀

批量处理

避免循环，提升计算效率

💻 向量化回测示例

双均线策略向量化实现

import numpy as np
import pandas as pd

# 计算均线
data['ma_short'] = data['close'].rolling(5).mean()
data['ma_long'] = data['close'].rolling(20).mean()

# 向量化生成信号
data['signal'] = np.where(data['ma_short'] > data['ma_long'], 1, -1)

# 计算收益
data['returns'] = data['close'].pct_change()
data['strategy_returns'] = data['signal'].shift(1) * data['returns']

# 计算累计收益
cumulative_returns = (1 + data['strategy_returns']).cumprod()

🔧 常用向量化操作

操作类型 函数示例 应用场景
滚动计算 rolling().mean/sum/std 计算移动平均、移动波动率
扩展计算 expanding().mean/sum 计算累计收益、累计最大值
条件判断 np.where/np.select 生成交易信号、过滤条件
位移操作 shift(1)/shift(-1) 避免未来函数、计算滞后指标

📊 优缺点对比

优点

  • 计算速度快，适合大规模回测
  • 代码简洁，易于理解和维护
  • 内存效率高
  • 适合参数优化和敏感性分析

缺点

  • 难以模拟复杂交易逻辑
  • 对订单管理和成交模拟有限
  • 容易忽略交易时序细节
  • 不适合高频交易策略
⚠️
注意事项

向量化回测容易出现"前视偏差"，使用shift()函数确保不使用未来数据。同时，向量化方法难以精确模拟滑点、部分成交等实盘细节，需要合理估算交易成本。
