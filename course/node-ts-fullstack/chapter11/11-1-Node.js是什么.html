📚 Node.js 简介

Node.js 是一个基于 Chrome V8 引擎的 JavaScript 运行时环境。它让 JavaScript 可以脱离浏览器运行在服务器端，实现全栈 JavaScript 开发。

// Node.js 官方定义 // Node.js® is a JavaScript runtime built on Chrome's V8 JavaScript engine. // 简单的 Node.js 程序 console.log('Hello, Node.js!'); // 查看 Node.js 版本 // 命令行运行: node -v // 输出示例: v20.10.0 // 查看 V8 引擎版本 process.versions.v8; // '8.4.371.19-node.19'
💡
核心特点

Node.js 不是框架，也不是编程语言，而是一个运行时环境，让 JavaScript 可以在服务器端运行。

🔧 Node.js 与浏览器区别

// ========== 浏览器环境 ========== // 有 window 对象 window.alert('Hello'); // 有 document 对象 document.getElementById('app'); // 有 DOM API const div = document.createElement('div'); // ========== Node.js 环境 ========== // 没有 window，有 global 对象（新版本用 globalThis） global.console.log('Hello'); // 没有 document，没有 DOM // document // ReferenceError: document is not defined // 有 process 对象 process.version; // Node.js 版本 process.platform; // 操作系统平台 process.cwd(); // 当前工作目录 // 有 require 函数（CommonJS） const fs = require('fs'); const path = require('path');

📖 Node.js 历史

📋
  • • 2009年：Ryan Dahl 创建 Node.js
  • • 2010年：npm 包管理器发布
  • • 2014年：io.js 分支出现
  • • 2015年：Node.js 基金会成立，Node.js 与 io.js 合并
  • • 2018年：Node.js 10 LTS 发布，增加更多 ES Module 支持
  • • 2020年：Node.js 14 LTS 发布，可选链和空值合并运算符
  • • 2023年：Node.js 20 LTS 发布，性能大幅提升

📝 本节小结

✅
  • • Node.js 是 JavaScript 运行时环境，基于 V8 引擎
  • • 让 JavaScript 可以脱离浏览器运行
  • • 没有 DOM，但有 process、Buffer 等服务端 API
  • • 使用 CommonJS 模块系统（也支持 ES Modules）
