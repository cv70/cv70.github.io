PWM脉冲宽度调制

PWM（Pulse Width Modulation，脉冲宽度调制）是一种通过改变脉冲宽度来控制模拟信号的技术。 PWM在电机控制、调光、电源管理等领域有广泛应用。本节将深入讲解PWM的工作原理与关键参数。

⚙️ PWM工作原理

基本原理

脉冲周期（Period）

PWM信号的重复周期，T = 1/frequency。周期固定时，改变占空比即可改变平均电压。

脉冲宽度（Pulse Width）

高电平持续的时间。通过调整脉冲宽度，可以改变输出的平均电压值。

占空比（Duty Cycle）

高电平时间占周期的百分比，Duty = (Ton/T) × 100%。决定输出平均电压。

📊 PWM关键参数

参数 定义 计算公式 典型范围
频率（Frequency） 每秒脉冲重复次数 f = 1/T 1Hz - 数百kHz
周期（Period） 一个完整脉冲的时间 T = 1/f 数μs - 数秒
占空比（Duty Cycle） 高电平时间占比 D = (Ton/T) × 100% 0% - 100%
分辨率（Resolution） 占空比可调的最小步长 Step = 100%/2^n 8-16位
上升时间（Rise Time） 从低电平到高电平的时间 tr = 10%-90%时间 数ns - 数μs
下降时间（Fall Time） 从高电平到低电平的时间 tf = 90%-10%时间 数ns - 数μs

🔧 PWM配置计算

参数计算示例

已知条件：

系统时钟 = 72MHz，定时器预分频 = 72，所需PWM频率 = 1kHz

计算步骤：

1. 定时器时钟 = 72MHz / 72 = 1MHz

2. 自动重装载值ARR = 1MHz / 1kHz - 1 = 999

3. 比较值CCR决定占空比，CCR = (Duty% × ARR)

4. 50%占空比：CCR = 0.5 × 999 = 499或500

分辨率：

分辨率 = log2(ARR+1) = log2(1000) ≈ 10位

📐 PWM输出特性

平均电压输出

通过低通滤波后，PWM的平均输出电压为：Vavg = Vcc × Duty Cycle。这是PWM实现模拟控制的基础原理。

功率效率

PWM开关工作在饱和区，开关损耗小，效率高。相比线性控制，PWM能显著降低功耗。

控制精度

PWM的精度由分辨率决定，分辨率越高，占空比调节越精细，控制精度越高。

动态响应

PWM频率越高，动态响应越好，但会增加开关损耗和EMI。需根据应用平衡选择。

✨
最佳实践

PWM设计建议：1）根据应用选择合适的PWM频率，电机控制通常10-20kHz，LED调光100Hz-1kHz；2）占空比分辨率应满足控制精度要求；3）注意PWM上升/下降时间，高速PWM需快速开关；4）驱动感性负载时需考虑续流二极管；5）多通道PWM需注意相位同步；6）通过滤波器可获得平滑的模拟输出。
