101.2 PM2 进程管理

使用 PM2 管理和监控 Node.js 应用

🎯 学习目标

  • 理解 PM2 的核心功能与优势
  • 掌握 PM2 常用命令与配置
  • 学会配置集群模式和负载均衡
  • 掌握日志管理和监控配置

PM2 简介

PM2 是一个带有负载均衡功能的 Node.js 应用进程管理器。 它可以保持应用永远在线、自动重启崩溃的应用、无缝重载、零停机部署等功能。

📦 安装与基础命令

# 全局安装 PM2 npm install -g pm2 # 启动应用 pm2 start app.js pm2 start dist/index.js --name myapp # 查看应用列表 pm2 list pm2 status # 查看应用详情 pm2 show myapp pm2 describe myapp # 停止应用 pm2 stop myapp pm2 stop all # 重启应用 pm2 restart myapp pm2 restart all # 删除应用 pm2 delete myapp pm2 delete all # 查看日志 pm2 logs pm2 logs myapp pm2 logs --lines 100 # 清空日志 pm2 flush

📁 PM2 配置文件

# ecosystem.config.js module.exports = { apps: [ { name: 'myapp-api', script: './dist/index.js', cwd: '/var/www/myapp', instances: 'max', // 使用所有 CPU 核心 exec_mode: 'cluster', // 集群模式 watch: false, // 生产环境不建议开启 max_memory_restart: '1G', // 内存超限自动重启 env: { NODE_ENV: 'development', PORT: 3000 }, env_production: { NODE_ENV: 'production', PORT: 3000 }, // 日志配置 log_date_format: 'YYYY-MM-DD HH:mm:ss', error_file: '/var/log/pm2/myapp-error.log', out_file: '/var/log/pm2/myapp-out.log', merge_logs: true, // 重启策略 exp_backoff_restart_delay: 100, max_restarts: 10, min_uptime: '10s', // 优雅关闭 kill_timeout: 5000, wait_ready: true, listen_timeout: 10000 } ] };

🔄 集群模式

集群模式优势

  • 充分利用多核 CPU
  • 内置负载均衡
  • 提高应用可用性
  • 支持零停机重载

启动集群

# 启动 4 个实例 pm2 start app.js -i 4 # 使用所有 CPU 核心 pm2 start app.js -i max # 零停机重载 pm2 reload all # 优雅关闭 pm2 gracefulReload all

📊 监控与管理

实时监控

# 终端监控面板 pm2 monit # 查看实时指标 pm2 show myapp

PM2 Plus (可选)

# 链接到 PM2 Plus 云服务 pm2 link # 或使用自定义监控 pm2 install pm2-logrotate

⚙️ 开机自启动

# 生成启动脚本 pm2 startup # 保存当前进程列表 pm2 save # 恢复进程列表 pm2 resurrect # 取消开机启动 pm2 unstartup

📝 日志管理

pm2-logrotate 配置

# 安装日志轮转模块 pm2 install pm2-logrotate # 配置日志轮转 pm2 set pm2-logrotate:max_size 10M pm2 set pm2-logrotate:retain 7 pm2 set pm2-logrotate:compress true

🚀 部署脚本示例

# ecosystem.config.js with deploy module.exports = { apps: [{ name: 'myapp', script: './dist/index.js', instances: 'max', exec_mode: 'cluster' }], deploy: { production: { user: 'deployer', host: ['server1.example.com', 'server2.example.com'], ref: 'origin/main', repo: 'git@github.com:user/myapp.git', path: '/var/www/myapp', 'post-deploy': 'npm ci && npm run build && pm2 reload ecosystem.config.js --env production', 'pre-setup': 'apt install git -y' }, staging: { user: 'deployer', host: 'staging.example.com', ref: 'origin/develop', repo: 'git@github.com:user/myapp.git', path: '/var/www/myapp-staging', 'post-deploy': 'npm ci && npm run build && pm2 reload ecosystem.config.js --env staging' } } }; # 部署命令 # 首次部署 pm2 deploy production setup # 更新部署 pm2 deploy production update # 回滚 pm2 deploy production revert 1

PM2 最佳实践
  • 生产环境使用集群模式充分利用多核
  • 配置内存限制自动重启防止内存泄漏
  • 使用 ecosystem.config.js 统一管理配置
  • 配置日志轮转避免日志文件过大
  • 使用 pm2 reload 实现零停机部署
