49.2 内置异常

使用 NestJS 提供的内置 HTTP 异常

🎯 学习目标

  • 掌握常用 HTTP 异常类
  • 学会抛出带自定义消息的异常
  • 了解异常的响应格式
  • 掌握异常的最佳实践

📚 常用 HTTP 异常

异常类 状态码 使用场景
BadRequestException 400 请求参数错误
UnauthorizedException 401 未认证
ForbiddenException 403 无权限
NotFoundException 404 资源不存在
ConflictException 409 资源冲突
UnprocessableEntityException 422 验证失败
InternalServerErrorException 500 服务器错误
BadGatewayException 502 网关错误
ServiceUnavailableException 503 服务不可用

🔧 使用内置异常

import { BadRequestException, UnauthorizedException, ForbiddenException, NotFoundException, ConflictException, HttpException, HttpStatus, } from '@nestjs/common'; @Controller('users') export class UsersController { constructor(private usersService: UsersService) {} @Get(':id') async findOne(@Param('id') id: string) { const user = await this.usersService.findOne(+id); if (!user) { throw new NotFoundException(`User with id ${id} not found`); } return user; } @Post() async create(@Body() createUserDto: CreateUserDto) { const exists = await this.usersService.findByEmail(createUserDto.email); if (exists) { throw new ConflictException('Email already exists'); } return this.usersService.create(createUserDto); } @Delete(':id') async remove(@Param('id') id: string, @Req() req: Request) { const user = await this.usersService.findOne(+id); if (user.id !== req.user.id && !req.user.roles.includes('admin')) { throw new ForbiddenException('You can only delete your own account'); } return this.usersService.remove(+id); } }
💡
异常消息

所有 HTTP 异常都接受一个可选的消息参数。如果不提供，将使用默认的错误消息。

🌐 自定义异常响应

// 传递对象作为消息 throw new BadRequestException({ code: 'VALIDATION_ERROR', message: 'Validation failed', errors: [ { field: 'email', message: 'Invalid email format' }, { field: 'password', message: 'Password too short' }, ], }); // 响应格式 // { // statusCode: 400, // message: { // code: 'VALIDATION_ERROR', // message: 'Validation failed', // errors: [...] // }, // error: 'Bad Request' // } // 使用 HttpException 自定义 throw new HttpException( { code: 'CUSTOM_ERROR', message: 'Something went wrong', details: 'More info here', }, HttpStatus.BAD_REQUEST, );

📦 异常基类

import { HttpException, HttpStatus } from '@nestjs/common'; // 所有 HTTP 异常都继承自 HttpException class CustomException extends HttpException { constructor(message: string, public readonly code: string) { super( { code, message, timestamp: new Date().toISOString(), }, HttpStatus.BAD_REQUEST, ); } } // 使用 throw new CustomException('User not active', 'USER_INACTIVE'); // 响应 // { // statusCode: 400, // message: { // code: 'USER_INACTIVE', // message: 'User not active', // timestamp: '...' // } // }
⚠️
异常最佳实践

使用语义明确的异常类。NotFoundException 表示资源不存在，ForbiddenException 表示权限不足。不要滥用 InternalServerErrorException，它应该只用于真正的服务器错误。
