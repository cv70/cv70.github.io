📦 什么是模型序列化

模型序列化是指将训练好的神经网络模型从内存中的对象状态转换为可持久存储的字节序列的过程。这个过程包括：

  • 权重参数：模型的所有可训练参数
  • 模型结构：网络的层结构和连接关系
  • 超参数：优化器状态、学习率等信息
  • 元数据：模型版本、创建时间等

模型序列化的意义

模型序列化使得我们能够保存训练成果、在不同环境间迁移模型、 进行模型部署和推理。一个优秀的序列化方案应该具备高效、兼容、可扩展的特性。

🔧 主流模型格式

PyTorch格式

torch.save(model.state_dict(), 'model.pt') # 仅保存权重 torch.save(model, 'model_full.pt') # 保存完整模型
💡
最佳实践

推荐使用state_dict()方式保存，这样可以避免代码变更导致的问题，并允许在不同框架间迁移。

TensorFlow格式

# SavedModel格式 tf.saved_model.save(model, 'saved_model/') # Keras H5格式 model.save('model.h5') # 检查点格式 model.save_weights('weights.h5')

ONNX格式

import torch import torch.onnx # 导出为ONNX torch.onnx.export( model, dummy_input, "model.onnx", opset_version=14, input_names=['input'], output_names=['output'] )

📊 模型格式对比

格式 框架 优点 缺点 适用场景
.pt/.pth PyTorch 原生支持、灵活、保留训练状态 跨框架兼容性差 PyTorch训练和开发
.h5 Keras 单文件、易于共享 大型模型性能较差 Keras模型部署
SavedModel TensorFlow 结构清晰、支持版本管理 文件结构复杂 TensorFlow Serving
.onnx 跨框架 框架无关、支持多种推理引擎 不支持动态图特性 跨框架部署
.safetensors 安全格式 防止代码注入、快速加载 生态较新 HuggingFace模型

⚙️ 模型序列化细节

权重存储格式

FP32 vs FP16 vs BF16

精度 位数 存储空间 精度损失 适用场景
FP32 32位 基准 无 训练、高精度推理
FP16 16位 减半 较小 推理、快速训练
BF16 16位 减半 极小 大模型训练

压缩存储

import torch # 使用torch.save的压缩选项 torch.save({ 'model_state_dict': model.state_dict(), 'optimizer_state_dict': optimizer.state_dict(), 'epoch': epoch }, 'checkpoint.pt', _use_new_zipfile_serialization=True) # 手动压缩存储 import gzip import pickle with gzip.open('model_compressed.pt.gz', 'wb') as f: pickle.dump(model.state_dict(), f, protocol=pickle.HIGHEST_PROTOCOL)

🔄 模型格式转换

PyTorch ↔ ONNX

import torch import onnxruntime as ort # PyTorch转ONNX model = MyModel() dummy_input = torch.randn(1, 3, 224, 224) torch.onnx.export(model, dummy_input, "model.onnx") # ONNX加载推理 ort_session = ort.InferenceSession("model.onnx") outputs = ort_session.run(None, {'input': dummy_input.numpy()})

TensorFlow ↔ TFLite

import tensorflow as tf # 转换为TFLite converter = tf.lite.TFLiteConverter.from_keras_model(model) converter.optimizations = [tf.lite.Optimize.DEFAULT] tflite_model = converter.convert() # 保存模型 with open('model.tflite', 'wb') as f: f.write(tflite_model)

HuggingFace格式转换

from transformers import AutoModel # 加载模型 model = AutoModel.from_pretrained("bert-base-uncased") # 保存为Safetensors model.save_pretrained("./my_model", safe_serialization=True) # 保存为PyTorch格式 model.save_pretrained("./my_model_pt", safe_serialization=False)

🔐 Safetensors - 安全的模型格式

Safetensors是一种新的模型存储格式，旨在解决传统格式中的安全问题：

⚠️
传统格式的风险

使用pickle的格式存在代码注入风险，因为加载模型时会执行任意代码。

from safetensors.torch import save_file, load_file # 保存模型 tensors = { "layer1.weight": model.layer1.weight, "layer1.bias": model.layer1.bias } save_file(tensors, "model.safetensors") # 加载模型 tensors = load_file("model.safetensors") model.load_state_dict(tensors)

优点

  • 零信任安全（不执行代码）
  • 延迟加载（支持大模型）
  • 无需反序列化（内存映射）
  • 跨框架支持

特性

  • 基于零拷贝内存映射
  • 支持所有张量类型
  • 内置校验和验证
  • 简单的JSON元数据
