103.5 告警系统

构建高效可靠的告警体系

🎯 学习目标

  • 理解告警系统设计原则
  • 学会配置 Alertmanager
  • 掌握多渠道告警通知
  • 了解告警分级与处理流程

告警系统概述

告警系统是运维的眼睛，好的告警系统能在问题发生时及时通知相关人员， 同时避免过多的噪音造成"告警疲劳"。设计合理的告警体系是保障服务稳定的关键。

📊 告警分级

级别 说明 响应时间 通知方式
P0 - Critical 服务不可用 立即响应 电话 + 短信 + 即时通讯
P1 - High 核心功能受损 15 分钟内 短信 + 即时通讯
P2 - Medium 性能下降/非核心问题 1 小时内 即时通讯 + 邮件
P3 - Low 需要关注的问题 工作时间处理 邮件

📱 多渠道通知实现

// src/services/alertService.ts import axios from 'axios'; import nodemailer from 'nodemailer'; interface Alert { name: string; severity: 'critical' | 'high' | 'medium' | 'low'; message: string; labels: Record; annotations: Record; } class AlertService { private emailTransporter; constructor() { this.emailTransporter = nodemailer.createTransporter({ host: process.env.SMTP_HOST, port: 587, auth: { user: process.env.SMTP_USER, pass: process.env.SMTP_PASS } }); } # 发送钉钉通知 async sendDingTalk(alert: Alert) { const webhook = process.env.DINGTALK_WEBHOOK; const text = this.formatAlertText(alert); await axios.post(webhook, { msgtype: 'markdown', markdown: { title: `【${alert.severity.toUpperCase()}】${alert.name}`, text: text } }); } # 发送企业微信通知 async sendWeChat(alert: Alert) { const webhook = process.env.WECHAT_WEBHOOK; const text = this.formatAlertText(alert); await axios.post(webhook, { msgtype: 'markdown', markdown: { content: text } }); } # 发送邮件通知 async sendEmail(alert: Alert, recipients: string[]) { await this.emailTransporter.sendMail({ from: process.env.SMTP_FROM, to: recipients.join(','), subject: `【${alert.severity.toUpperCase()}】${alert.name}`, html: this.formatAlertHtml(alert) }); } # 发送 Slack 通知 async sendSlack(alert: Alert) { const webhook = process.env.SLACK_WEBHOOK; await axios.post(webhook, { text: `【${alert.severity.toUpperCase()}】${alert.name}`, attachments: [{ color: this.getSeverityColor(alert.severity), fields: [ { title: 'Alert', value: alert.name, short: true }, { title: 'Severity', value: alert.severity, short: true }, { title: 'Message', value: alert.message, short: false } ] }] }); } private formatAlertText(alert: Alert): string { return ` ### ${alert.name} - **级别**: ${alert.severity} - **消息**: ${alert.message} - **时间**: ${new Date().toISOString()} - **标签**: ${JSON.stringify(alert.labels)} `.trim(); } private getSeverityColor(severity: string): string { const colors = { critical: 'danger', high: 'warning', medium: '#ff9900', low: 'good' }; return colors[severity] || 'good'; } } export default new AlertService();

📋 告警最佳实践

告警原则

  • 可操作性：每个告警都要能处理
  • 明确性：告警信息清晰准确
  • 及时性：问题发生后快速通知
  • 去重：避免重复告警骚扰

避免的问题

  • 告警风暴：短时间内大量告警
  • 误报频繁：降低信任度
  • 无主告警：没人负责处理
  • 疲劳轰炸：过多低级别告警
💡
告警系统设计建议
  • 使用分组和聚合减少告警数量
  • 设置合理的持续时间和重复间隔
  • 不同级别使用不同通知渠道
  • 建立清晰的值班和升级机制
  • 定期复盘告警有效性并优化
  • 维护期间使用静默功能

📝 本节小结

✅
  • • 告警分为 P0-P3 四个级别，响应方式不同
  • • Alertmanager 是 Prometheus 的告警组件
  • • 支持多渠道通知：邮件、Slack、钉钉、企业微信等
  • • 遵循可操作性、明确性原则，避免告警疲劳
