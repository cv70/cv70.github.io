41.5 启动与调试

掌握 NestJS 应用的启动和调试技巧

🎯 学习目标

  • 掌握不同的启动模式
  • 了解环境变量配置
  • 学会使用 VSCode 调试
  • 掌握日志配置

🚀 启动命令

# package.json 中的脚本命令 { "scripts": { "start": "nest start", # 普通启动 "start:dev": "nest start --watch", # 开发模式(热重载) "start:debug": "nest start --debug --watch", # 调试模式 "start:prod": "node dist/main" # 生产模式 } } # 使用命令 npm run start # 普通启动 npm run start:dev # 开发模式(推荐) npm run start:debug # 调试模式 npm run start:prod # 生产模式
⚠️
启动模式区别

start:dev 启用 watch 模式，代码修改后自动重新编译。start:prod 需要先执行 npm run build 构建生产代码。

⚙️ 环境变量配置

# .env 文件 PORT=3000 NODE_ENV=development DB_HOST=localhost DB_PORT=5432 DB_USERNAME=postgres DB_PASSWORD=password DB_DATABASE=mydb # .env.development (开发环境) # .env.production (生产环境) # .env.test (测试环境)

安装配置包：

npm install @nestjs/config // app.module.ts import { ConfigModule } from '@nestjs/config'; @Module({ imports: [ ConfigModule.forRoot({ isGlobal: true, // 全局可用 envFilePath: `.env.${process.env.NODE_ENV || 'development'}`, }), ], }) export class AppModule {}

🐛 VSCode 调试配置

// .vscode/launch.json { "version": "0.2.0", "configurations": [ { "type": "node", "request": "launch", "name": "Debug NestJS", "runtimeExecutable": "npm", "runtimeArgs": [ "run", "start:debug" ], "console": "integratedTerminal", "restart": true, "protocol": "inspector" } ] }

📋 日志配置

// main.ts import { Logger } from '@nestjs/common'; async function bootstrap() { const app = await NestFactory.create(AppModule, { logger: ['log', 'error', 'warn', 'debug', 'verbose'], }); const logger = new Logger('Bootstrap'); app.setGlobalPrefix('api'); await app.listen(3000); logger.log(`Application is running on: ${await app.getUrl()}`); logger.debug('Debug mode enabled'); logger.verbose('Verbose logging enabled'); } bootstrap(); // 在服务中使用 Logger @Injectable() export class UsersService { private readonly logger = new Logger(UsersService.name); findAll() { this.logger.log('Finding all users'); // ... } }

📝 本节小结

✅
  • • start:dev 用于开发，支持热重载
  • • @nestjs/config 管理环境变量
  • • VSCode 可通过 launch.json 配置调试
  • • Logger 类提供日志功能
