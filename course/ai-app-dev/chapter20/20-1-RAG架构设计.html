💡 什么是RAG

Retrieval-Augmented Generation

RAG是一种结合检索和生成的AI架构，通过检索外部知识库来增强LLM的生成能力。

解决的问题

  • 知识时效性不足
  • 专业领域知识缺乏
  • 幻觉问题
  • 私有数据整合

核心优势

  • 知识可更新
  • 答案可追溯
  • 无需微调
  • 数据安全可控

🔄 RAG工作流程

1
用户提问
2
向量检索
3
构建Prompt
4
LLM生成
# RAG核心代码示例 def rag_query(question, vector_store, llm): # 1. 问题向量化 query_embedding = embed(question) # 2. 检索相关文档 docs = vector_store.similarity_search( query_embedding, k=3 ) # 3. 构建Prompt context = "\n".join([d.content for d in docs]) prompt = f""" 基于以下参考资料回答问题： 参考资料： {context} 问题：{question} 请基于参考资料回答，如果参考资料中没有相关信息，请说明。 """ # 4. LLM生成答案 answer = llm.generate(prompt) return answer, docs

🏗️ RAG系统架构

索引阶段（离线）

  • 文档加载
  • 文本分割
  • 向量化嵌入
  • 存储到向量数据库

查询阶段（在线）

  • 问题向量化
  • 相似度检索
  • 重排序（可选）
  • LLM生成答案
💡
RAG vs 微调

RAG适合需要实时知识、数据频繁更新、成本敏感的场景。微调适合需要改变模型行为、特定任务优化的场景。两者可以结合使用。
