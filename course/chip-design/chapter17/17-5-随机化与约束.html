17.5 随机化与约束

SystemVerilog 语言精讲

🎯 学习目标

  • 掌握随机变量的定义
  • 理解约束块的使用
  • 学会约束的组合与覆盖
  • 能够生成受约束的随机数据

🎲 随机化

// 随机化类
class Packet;
    rand bit [7:0]  addr;
    rand bit [31:0] data;
    rand bit        valid;

    // 约束块
    constraint addr_range {
        addr inside {[8'h00:8'hFF]};
    }

    constraint data_valid {
        valid == 1;
    }

    constraint data_alignment {
        data[1:0] == 2'b00;  // 4字节对齐
    }
endclass

📝 本节小结

✅
  • • rand声明随机变量
  • • constraint定义约束
  • • 支持复杂约束表达式
  • • 随机化提高验证效率
