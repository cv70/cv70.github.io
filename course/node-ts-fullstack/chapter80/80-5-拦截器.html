80.5 拦截器

请求和响应的中间件处理

📖 本节概述

Axios 拦截器允许你在请求发送之前或响应到达 then/catch 之前对它们进行处理。这是实现全局请求处理、错误处理、日志记录、认证注入等功能的强大工具。

🎯 学习目标

  • 理解拦截器的工作原理和执行顺序
  • 掌握请求拦截器和响应拦截器的使用
  • 学会实现常见的拦截器应用场景
  • 了解拦截器的管理和移除

🔧 拦截器基础

请求拦截器

请求拦截器在请求发送之前执行，可以修改请求配置或添加通用处理。

import axios from 'axios'; const api = axios.create(); // 添加请求拦截器 api.interceptors.request.use( config => { // 在发送请求之前做些什么 console.log('Request:', config.url); // 添加 Token const token = localStorage.getItem('token'); if (token) { config.headers.Authorization = `Bearer ${token}`; } return config; }, error => { // 对请求错误做些什么 return Promise.reject(error); } );

响应拦截器

响应拦截器在响应到达 then/catch 之前执行，可以统一处理响应数据或错误。

// 添加响应拦截器 api.interceptors.response.use( response => { // 对响应数据做点什么 console.log('Response:', response.status); // 提取数据 return response.data; }, error => { // 对响应错误做点什么 if (error.response?.status === 401) { // Token 过期，跳转登录 window.location.href = '/login'; } return Promise.reject(error); } );

📋 拦截器执行顺序

多个拦截器按照添加顺序执行，但请求拦截器和响应拦截器的执行顺序相反：

// 请求拦截器：先添加的先执行 api.interceptors.request.use(config => { console.log('请求拦截器 1'); return config; }); api.interceptors.request.use(config => { console.log('请求拦截器 2'); return config; }); // 响应拦截器：先添加的后执行 api.interceptors.response.use(response => { console.log('响应拦截器 1'); return response; }); api.interceptors.response.use(response => { console.log('响应拦截器 2'); return response; }); // 执行顺序： // 请求拦截器 1 -> 请求拦截器 2 -> 发送请求 -> 响应拦截器 2 -> 响应拦截器 1

🔐 Token 认证拦截器

import axios from 'axios'; const api = axios.create({ baseURL: '/api' }); // 请求拦截器：自动添加 Token api.interceptors.request.use( config => { const token = localStorage.getItem('access_token'); if (token) { config.headers.Authorization = `Bearer ${token}`; } return config; }, error => Promise.reject(error) ); // 响应拦截器：处理 Token 过期 api.interceptors.response.use( response => response, async error => { const originalRequest = error.config; // Token 过期，尝试刷新 if (error.response?.status === 401 && !originalRequest._retry) { originalRequest._retry = true; try { const refreshToken = localStorage.getItem('refresh_token'); const response = await axios.post('/auth/refresh', { refreshToken }); const { accessToken } = response.data; localStorage.setItem('access_token', accessToken); // 重试原请求 originalRequest.headers.Authorization = `Bearer ${accessToken}`; return api(originalRequest); } catch (refreshError) { // 刷新失败，跳转登录 localStorage.removeItem('access_token'); localStorage.removeItem('refresh_token'); window.location.href = '/login'; return Promise.reject(refreshError); } } return Promise.reject(error); } );

📊 日志和性能监控

const api = axios.create(); // 请求日志拦截器 api.interceptors.request.use( config => { // 记录请求开始时间 config.metadata = { startTime: Date.now() }; console.log('[Request]', { method: config.method?.toUpperCase(), url: config.url, params: config.params, data: config.data }); return config; }, error => { console.error('[Request Error]', error); return Promise.reject(error); } ); // 响应日志拦截器 api.interceptors.response.use( response => { const duration = Date.now() - response.config.metadata.startTime; console.log('[Response]', { url: response.config.url, status: response.status, duration: `${duration}ms`, data: response.data }); // 性能监控：慢请求告警 if (duration > 3000) { console.warn(`[Slow Request] ${response.config.url} took ${duration}ms`); } return response; }, error => { const duration = Date.now() - error.config?.metadata?.startTime; console.error('[Response Error]', { url: error.config?.url, status: error.response?.status, duration: `${duration}ms`, message: error.message }); return Promise.reject(error); } ); // 扩展 AxiosRequestConfig 类型 declare module 'axios' { interface AxiosRequestConfig { metadata?: { startTime: number }; } }

⏱️ 加载状态管理

import axios from 'axios'; // 简单的加载计数器 let loadingCount = 0; let loadingCallback: (loading: boolean) => void; export function setLoadingCallback(callback: (loading: boolean) => void) { loadingCallback = callback; } const api = axios.create(); api.interceptors.request.use( config => { loadingCount++; loadingCallback?.(true); return config; }, error => { loadingCount--; if (loadingCount === 0) { loadingCallback?.(false); } return Promise.reject(error); } ); api.interceptors.response.use( response => { loadingCount--; if (loadingCount === 0) { loadingCallback?.(false); } return response; }, error => { loadingCount--; if (loadingCount === 0) { loadingCallback?.(false); } return Promise.reject(error); } );

🚫 错误处理拦截器

import { ElMessage } from 'element-plus'; // 或其他 UI 库 const api = axios.create(); // 统一错误处理 api.interceptors.response.use( response => response, error => { let message = '请求失败'; if (error.response) { // 服务器返回错误 const { status, data } = error.response; switch (status) { case 400: message = data.message || '请求参数错误'; break; case 401: message = '登录已过期，请重新登录'; break; case 403: message = '没有权限访问'; break; case 404: message = '请求的资源不存在'; break; case 500: message = '服务器错误，请稍后重试'; break; default: message = `请求失败 (${status})`; } } else if (error.request) { // 请求发出但无响应 message = '网络连接失败，请检查网络'; } else { // 请求配置错误 message = error.message; } // 显示错误提示 ElMessage.error(message); return Promise.reject(error); } );

🗑️ 移除拦截器

// 添加拦截器时保存引用 const requestInterceptor = api.interceptors.request.use( config => config ); const responseInterceptor = api.interceptors.response.use( response => response ); // 移除拦截器 api.interceptors.request.eject(requestInterceptor); api.interceptors.response.eject(responseInterceptor); // 清除所有拦截器 api.interceptors.request.clear(); api.interceptors.response.clear();

📝 本节小结

  • 拦截器是 Axios 的核心功能之一
  • 请求拦截器可添加通用配置如 Token、日志
  • 响应拦截器可统一处理响应数据和错误
  • 多个拦截器按顺序执行，响应拦截器顺序相反
  • 使用 eject 方法可以移除已添加的拦截器
