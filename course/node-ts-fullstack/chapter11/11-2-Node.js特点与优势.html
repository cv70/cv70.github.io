11.2 Node.js 特点与优势

深入理解 Node.js 的核心特性

🎯 学习目标

  • 理解事件驱动的编程模型
  • 掌握非阻塞 I/O 的工作原理
  • 了解单线程与事件循环
  • 认识 Node.js 的优势场景

📚 核心特点

// 1. 单线程 // Node.js 主线程只有一个，不会创建新线程 // 2. 非阻塞 I/O // I/O 操作不会阻塞主线程 // 3. 事件驱动 // 通过事件和回调处理异步操作 // 示例：非阻塞文件读取 const fs = require('fs'); // 异步读取 - 不阻塞 fs.readFile('data.txt', 'utf8', (err, data) => { console.log('文件读取完成'); }); console.log('这行先执行'); // 先于文件读取完成输出 // 同步读取 - 会阻塞 const data = fs.readFileSync('data.txt', 'utf8'); console.log('同步读取完成');

🔧 事件驱动模型

// 事件驱动示例 const EventEmitter = require('events'); // 创建事件发射器 const emitter = new EventEmitter(); // 注册事件监听器 emitter.on('message', (data) => { console.log('收到消息:', data); }); // 触发事件 emitter.emit('message', 'Hello Node.js!'); emitter.emit('message', { name: 'Alice', age: 25 }); // HTTP 服务器就是事件驱动的 const http = require('http'); const server = http.createServer(); server.on('request', (req, res) => { res.end('Hello World!'); }); server.listen(3000);
💡
事件循环

Node.js 通过事件循环机制处理异步操作，主线程不会被 I/O 操作阻塞，可以处理更多请求。

⚡ Node.js 优势

✅
  • • 高并发处理：单线程事件驱动，适合 I/O 密集型应用
  • • 全栈 JavaScript：前后端使用同一语言，降低学习成本
  • • 丰富的生态系统：npm 拥有超过百万的开源包
  • • 高性能：V8 引擎编译 JavaScript 为机器码
  • • 跨平台：支持 Windows、Mac、Linux

⚠️ 不适用场景

// CPU 密集型任务不适合 Node.js // 因为单线程会被长时间占用 // ❌ 不好的做法 function fibonacci(n) { if (n <= 1) return n; return fibonacci(n - 1) + fibonacci(n - 2); } // 这会阻塞事件循环 const result = fibonacci(45); // 耗时很长 console.log('计算完成'); // ✅ 正确做法：使用 Worker Threads const { Worker, isMainThread, parentPort } = require('worker_threads'); if (isMainThread) { const worker = new Worker(__filename); worker.on('message', (result) => { console.log('结果:', result); }); } else { const result = fibonacci(45); parentPort.postMessage(result); }

📝 本节小结

✅
  • • Node.js 特点：单线程、非阻塞 I/O、事件驱动
  • • 适合 I/O 密集型应用，不适合 CPU 密集型
  • • 优势：高并发、全栈 JS、生态丰富
  • • CPU 密集任务可用 Worker Threads
