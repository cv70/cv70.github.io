PrimeTime简介

PrimeTime（PT）是Synopsys公司开发的业界标准静态时序分析工具。 它提供了全面的时序分析能力，支持从综合到签收的完整时序验证流程， 是数字芯片设计流程中最常用的STA工具。

🚀 PT启动方式

# 命令行模式 pt_shell # 图形界面模式 pt_shell -gui # 执行脚本文件 pt_shell -f sta_analysis.tcl # 指定内存和CPU pt_shell -64bit -threads 8 -max_memory 32G

📜 PT分析流程

#!/bin/tcl # ============================================================================ # PrimeTime 时序分析脚本 # ============================================================================ # 1. 环境设置 # ============================================ set LIB_PATH "/foundry/libraries/saed90nm" set TECH_LIB "${LIB_PATH}/stdcell_rvt/db/saed90nm" # 设置目标库 set target_library [list ${TECH_LIB}_ss.db ${TECH_LIB}_ff.db] # 设置链接库 set link_library "* $target_library" # 设置搜索路径 set search_path [list ./netlist ./lib ./sdc ${LIB_PATH}] # 2. 读入设计 # ============================================ # 读入网表 read_verilog ./netlist/top_synth.v # 设置当前设计 current_design top # 链接设计 link # 更新时序 update_timing # 3. 读入约束 # ============================================ read_sdc ./sdc/top_synth.sdc # 4. 时序分析 # ============================================ # 执行时序分析 update_timing # 检查时序 check_timing # 5. 生成报告 # ============================================ file mkdir reports # Setup时序报告 report_timing -max_paths 20 -delay_type max \ -input_pins -nets -transition_time -capacitance \ > reports/setup.rpt # Hold时序报告 report_timing -max_paths 20 -delay_type min \ -input_pins -nets -transition_time -capacitance \ > reports/hold.rpt # 时序违例报告 report_constraint -all_violators \ > reports/violations.rpt # 时钟报告 report_clock -attributes > reports/clocks.rpt # 时序路径组报告 report_path_group > reports/path_groups.rpt # 6. 退出 # ============================================ # 保存会话 save_session output/session # 退出 exit

⚡ PT常用命令

命令类别 命令 功能说明
设计管理 read_verilog, read_lib 读入网表和库
current_design, link 设置和链接设计
约束管理 read_sdc, write_sdc 读入和写入SDC
时序分析 update_timing 更新时序
check_timing 检查时序
报告生成 report_timing 时序报告
report_constraint 约束报告
report_clock 时钟报告

🌡️ 多角分析

# 定义工艺角 set_corner ss_corner set_corner ff_corner # 为每个角设置库 read_lib -corner ss_corner ${TECH_LIB}_ss.db read_lib -corner ff_corner ${TECH_LIB}_ff.db # 设置操作条件 set_operating_conditions -corner ss_corner ss_0.9V_125C set_operating_conditions -corner ff_corner ff_1.1V_-40C # 为每个角生成报告 foreach corner {ss_corner ff_corner} { set_analysis_view -setup $corner $corner report_timing -corner $corner -max_paths 10 \ > reports/timing_${corner}.rpt }

PT使用技巧

1）使用脚本化方式进行时序分析；2）合理设置多角分析； 3）定期保存会话以便调试；4）使用增量分析提高效率； 5）生成详细的报告用于问题诊断。
