Kernel优化概述

Kernel优化是提升GPU程序性能的核心。通过合理的线程配置、内存访问模式和计算优化，可以将性能提升数倍甚至数十倍。

📊 性能指标

关键指标

指标 定义 目标
占用率 SM资源使用率 > 80%
效率 实际利用率/理论峰值 > 70%
算术强度 计算量/内存访问量 最大化
内存带宽 实际带宽/理论带宽 > 70%
性能计算： // 理论峰值计算（H100） float peak_flops = 89.0e12; // 89 TFLOPS (FP32) // 实际计算量 float actual_flops = n_ops / time; // 计算效率 float efficiency = actual_flops / peak_flops; // 理论内存带宽（H100） float peak_bandwidth = 3.35e12; // 3.35 TB/s // 实际内存访问量 float data_size = n_reads + n_writes; // 实际带宽 float actual_bandwidth = data_size / time; // 内存效率 float memory_efficiency = actual_bandwidth / peak_bandwidth;

⚡ 计算优化

算术优化

计算优化技巧： // 1. 使用内建函数（快速数学） __global__ void optimized_sqrt(float *data, int n) { int tid = blockIdx.x * blockDim.x + threadIdx.x; if (tid < n) { // 使用__sqrtf替代sqrt（更快但精度略低） data[tid] = __sqrtf(data[tid]); } } // 2. 避免除法 __global__ void avoid_division(float *data, int n) { int tid = blockIdx.x * blockDim.x + threadIdx.x; if (tid < n) { // 不：data[tid] = data[tid] / 2.0f; // 好：乘法代替除法 data[tid] = data[tid] * 0.5f; } } // 3. 预计算循环不变量 __global__ void loop_optimization(float *a, float *b, float *c, int n) { int tid = threadIdx.x; int gid = blockIdx.x * blockDim.x + tid; float scale = 1.0f / n; // 预计算 for (int i = 0; i < n; i++) { c[gid] += a[gid] * b[i] * scale; } } // 4. 循环展开 __global__ void loop_unroll(float *data, int n) { int tid = blockIdx.x * blockDim.x + threadIdx.x; int stride = blockDim.x * gridDim.x; #pragma unroll 4 for (int i = tid; i < n; i += stride * 4) { data[i] *= 2.0f; data[i + stride] *= 2.0f; data[i + 2*stride] *= 2.0f; data[i + 3*stride] *= 2.0f; } }

💾 内存优化

访问模式优化

内存优化技巧： // 1. 共享内存平铺（Tiling） __global__ void matrix_mul_tiled(float *A, float *B, float *C, int N) { // 声明平铺大小为32x32的共享内存 __shared__ float tile_A[32][32]; __shared__ float tile_B[32][32]; int bx = blockIdx.x, by = blockIdx.y; int tx = threadIdx.x, ty = threadIdx.y; // 计算全局索引 int row = by * 32 + ty; int col = bx * 32 + tx; float sum = 0.0f; // 循环处理所有平铺 for (int t = 0; t < N / 32; t++) { // 加载到共享内存 tile_A[ty][tx] = A[row * N + t * 32 + tx]; tile_B[ty][tx] = B[(t * 32 + ty) * N + col]; __syncthreads(); // 计算部分积 for (int i = 0; i < 32; i++) { sum += tile_A[ty][i] * tile_B[i][tx]; } __syncthreads(); } C[row * N + col] = sum; } // 2. 使用向量化加载 __global__ void vectorized_load(float *data, int n) { int tid = blockIdx.x * blockDim.x + threadIdx.x; int stride = blockDim.x * gridDim.x; // 每次4个float（16字节） float4 *ptr = (float4*)data; for (int i = tid; i < n/4; i += stride) { float4 val = ptr[i]; // 处理val.x, val.y, val.z, val.w } } // 3. 只读缓存 __constant__ float const_data[256]; // 常量内存 __global__ void use_constant_memory(float *output) { int tid = threadIdx.x; output[tid] = const_data[tid]; // 快速访问 }

🔧 编译器优化

优化标志

NVCC编译选项： # 基本优化 nvcc -O3 kernel.cu -o kernel # 针对特定GPU架构优化 nvcc -O3 -arch=sm_80 kernel.cu -o kernel # A100 nvcc -O3 -arch=sm_86 kernel.cu -o kernel # RTX 3090 # 使用fast-math（更快但精度略低） nvcc -O3 -use_fast_math kernel.cu -o kernel # 控制最大寄存器使用 nvcc -O3 -maxrregcount=64 kernel.cu -o kernel # 生成PTX代码查看优化结果 nvcc -O3 -ptx kernel.cu -o kernel.ptx # 生成SASS代码（实际GPU指令） nvcc -O3 -cubin kernel.cu -o kernel.cubin cuobjdump -sass kernel.cubin
