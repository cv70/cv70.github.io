15.1 同步与异步操作

理解 Node.js 的异步编程模型

🎯 学习目标

  • 理解同步与异步的区别
  • 掌握回调函数的使用
  • 了解阻塞与非阻塞
  • 学会选择合适的操作方式

📚 同步 vs 异步

const fs = require('fs'); // 同步操作 - 阻塞代码执行 console.log('开始'); const data = fs.readFileSync('file.txt', 'utf8'); // 阻塞等待 console.log('读取完成:', data); console.log('结束'); // 执行顺序： // 开始 -> 读取文件（阻塞） -> 读取完成 -> 结束 // 异步操作 - 不阻塞代码执行 console.log('开始'); fs.readFile('file.txt', 'utf8', (err, data) => { console.log('读取完成:', data); }); console.log('结束'); // 执行顺序： // 开始 -> 发起读取请求 -> 结束 -> 读取完成（回调执行）
💡
关键区别

同步操作会阻塞后续代码执行，异步操作立即返回，结果通过回调函数获取。

🔧 回调函数

const fs = require('fs'); // 异步操作的回调模式 // 回调函数参数：(error, result) fs.readFile('file.txt', 'utf8', (err, data) => { if (err) { console.error('读取失败:', err); return; } console.log('读取成功:', data); }); // 自定义异步函数 function readFileAsync(filepath, callback) { fs.readFile(filepath, 'utf8', (err, data) => { if (err) { callback(err, null); return; } callback(null, data); }); } // 使用 readFileAsync('file.txt', (err, data) => { if (err) { console.error(err); return; } console.log(data); }); // 回调地狱问题 fs.readFile('file1.txt', 'utf8', (err, data1) => { if (err) throw err; fs.readFile('file2.txt', 'utf8', (err, data2) => { if (err) throw err; fs.readFile('file3.txt', 'utf8', (err, data3) => { if (err) throw err; // 嵌套越来越深... console.log(data1, data2, data3); }); }); });

📦 Promise 与 async/await

const fs = require('fs').promises; // 使用 Promise 版本 // Promise 方式 fs.readFile('file.txt', 'utf8') .then(data => { console.log('读取成功:', data); return fs.readFile('file2.txt', 'utf8'); }) .then(data2 => { console.log('第二个文件:', data2); }) .catch(err => { console.error('出错了:', err); }); // async/await 方式（推荐） async function readFiles() { try { const data1 = await fs.readFile('file1.txt', 'utf8'); const data2 = await fs.readFile('file2.txt', 'utf8'); const data3 = await fs.readFile('file3.txt', 'utf8'); console.log(data1, data2, data3); } catch (err) { console.error('读取失败:', err); } } readFiles(); // 并行读取 async function readFilesParallel() { const [data1, data2, data3] = await Promise.all([ fs.readFile('file1.txt', 'utf8'), fs.readFile('file2.txt', 'utf8'), fs.readFile('file3.txt', 'utf8') ]); return { data1, data2, data3 }; }

⚙️ 选择同步还是异步

// 使用同步的场景： // 1. 应用启动时加载配置 // 2. 命令行工具 // 3. 简单脚本 // 同步加载配置 const config = JSON.parse(fs.readFileSync('config.json', 'utf8')); console.log('配置加载完成:', config); // 使用异步的场景： // 1. Web 服务器处理请求 // 2. 高并发应用 // 3. 需要高性能的场景 // HTTP 服务器必须使用异步 const http = require('http'); http.createServer((req, res) => { // 异步读取文件 fs.readFile('public' + req.url, (err, data) => { if (err) { res.writeHead(404); res.end('Not Found'); return; } res.end(data); }); }).listen(3000);
⚠️
注意

生产环境的服务器代码必须使用异步操作。同步操作会阻塞事件循环，影响并发性能。

📝 本节小结

✅
  • • 同步操作阻塞代码执行，异步操作不阻塞
  • • 异步操作通过回调函数返回结果
  • • 推荐使用 async/await 处理异步操作
  • • 服务器应用必须使用异步操作
