44.4 自定义 Provider

灵活配置 Provider 的注册方式

🎯 学习目标

  • 理解 Provider 注册语法
  • 掌握 useClass、useValue、useFactory
  • 学会使用自定义 Token
  • 了解现有 Provider 的覆盖

📚 Provider 注册语法

// 简写形式 providers: [UsersService] // 完整形式 providers: [ { provide: UsersService, useClass: UsersService, } ] // 两者等价，provide 是 Token，useClass 是具体实现

🔧 useClass - 类提供者

// 接口定义 export interface LoggerService { log(message: string): void; } // 实现类 @Injectable() class ConsoleLogger implements LoggerService { log(message: string) { console.log(message); } } @Injectable() class FileLogger implements LoggerService { log(message: string) { // 写入文件 } } // 注册时选择实现 @Module({ providers: [ { provide: LoggerService, useClass: process.env.NODE_ENV === 'production' ? FileLogger : ConsoleLogger, }, ], }) export class AppModule {} // 注入时使用接口类型 @Injectable() export class UsersService { constructor(private readonly logger: LoggerService) {} }

📦 useValue - 值提供者

// 注入常量值 @Module({ providers: [ { provide: 'DATABASE_URL', useValue: 'postgresql://localhost:5432/mydb', }, { provide: 'CONFIG', useValue: { apiUrl: 'https://api.example.com', timeout: 5000, }, }, ], }) export class AppModule {} // 注入使用 @Injectable() export class UsersService { constructor( @Inject('DATABASE_URL') private readonly dbUrl: string, @Inject('CONFIG') private readonly config: any, ) { console.log(dbUrl); // postgresql://localhost:5432/mydb console.log(config.timeout); // 5000 } } // Mock 服务（测试用） providers: [ { provide: UsersService, useValue: { findAll: jest.fn().mockReturnValue([{ id: 1, name: 'Mock' }]), }, }, ]
💡
字符串 Token

使用字符串作为 Token 时，需要用 @Inject() 装饰器显式注入。建议使用 Symbol 或强类型常量避免冲突。

🏭 useFactory - 工厂提供者

// 动态创建 Provider @Module({ providers: [ { provide: 'DATABASE_CONNECTION', useFactory: async (configService: ConfigService) => { const connection = await createConnection({ host: configService.get('DB_HOST'), port: configService.get('DB_PORT'), }); return connection; }, inject: [ConfigService], // 注入依赖 }, ], }) export class AppModule {} // 复杂工厂示例 providers: [ { provide: 'API_SERVICE', useFactory: ( configService: ConfigService, logger: LoggerService, cacheService: CacheService, ) => { const apiKey = configService.get('API_KEY'); logger.log(`Creating API service with key: ${apiKey}`); return new ApiService(apiKey, cacheService); }, inject: [ConfigService, LoggerService, CacheService], }, ] // 异步工厂 providers: [ { provide: 'ASYNC_DATA', useFactory: async () => { const data = await fetchDataFromRemote(); return data; }, }, ]

🔄 useExisting - 别名提供者

@Module({ providers: [ ConsoleLogger, { provide: LoggerService, // 别名 useExisting: ConsoleLogger, }, { provide: 'Logger', // 字符串别名 useExisting: ConsoleLogger, }, ], }) export class AppModule {} // 注入使用 @Injectable() export class UsersService { constructor( private readonly logger: ConsoleLogger, // 原类型 private readonly loggerService: LoggerService, // 别名 @Inject('Logger') private readonly aliasLogger: LoggerService, // 都是同一个实例 ) {} }

✅

  • • useValue 注册常量值
  • • useFactory 动态创建 Provider
  • • useExisting 创建别名
