41.3 创建第一个项目

使用 Nest CLI 快速搭建项目

🎯 学习目标

  • 安装 NestJS CLI 工具
  • 创建 NestJS 项目
  • 了解项目启动命令
  • 创建第一个 Hello World 应用

📚 安装 NestJS CLI

# 全局安装 NestJS CLI npm install -g @nestjs/cli # 验证安装 nest --version # 输出: 10.x.x # 查看帮助 nest --help
💡
CLI 的作用

Nest CLI 是一个强大的命令行工具，可以帮助你快速创建项目、生成模块/控制器/服务、构建和启动应用。

🔧 创建新项目

# 创建新项目 nest new my-nest-project # 选择包管理器 ? Which package manager would you ❤️ to use? ❯ npm yarn pnpm # 进入项目目录 cd my-nest-project # 启动开发服务器 npm run start:dev
⚠️
开发模式

使用 start:dev 启动开发服务器，支持热重载，代码修改后自动重新编译和重启服务。

🚀 Hello World 示例

项目创建后，会自动生成一个基础的 Hello World 应用：

// src/app.controller.ts import { Controller, Get } from '@nestjs/common'; import { AppService } from './app.service'; @Controller() export class AppController { constructor(private readonly appService: AppService) {} @Get() getHello(): string { return this.appService.getHello(); } } // src/app.service.ts import { Injectable } from '@nestjs/common'; @Injectable() export class AppService { getHello(): string { return 'Hello World!'; } }

访问 http://localhost:3000 可以看到 "Hello World!" 响应。

⚡ 常用 CLI 命令

命令 说明 简写
nest new 创建新项目 -
nest generate module 生成模块 nest g mo
nest generate controller 生成控制器 nest g co
nest generate service 生成服务 nest g s
nest start 启动应用 -
nest build 构建应用 -
