📚 Vite 概述

Vite 是由 Vue.js 作者尤雨溪创建的下一代前端构建工具，利用浏览器原生 ES 模块支持实现极速开发体验。

# Vite 名称由来 Vite (法语意为 "快") /vit/ # 为什么 Vite 快？ 1. 开发模式：利用浏览器原生 ES 模块，无需打包 2. 生产模式：使用 Rollup 进行高效打包 3. 热更新：只更新变化的模块，速度极快 # 核心优势 - 开发服务器启动快（秒级） - 热模块替换快（毫秒级） - 按需编译，只编译当前页面需要的代码 - 配置简单，开箱即用 # 创建项目 npm create vite@latest my-app # 或 yarn create vite my-app # 或 pnpm create vite my-app # 选择框架 ? 💡
入口文件

Vite 的入口是 index.html，在 HTML 中使用 <script type="module"> 引入 JavaScript，Vite 会自动处理模块依赖。

⚙️ 工作原理

# 开发模式 ## 传统打包工具 源代码 → 打包 → 开发服务器 → 浏览器 （启动慢，更新需要重新打包） ## Vite 源代码 → 开发服务器 → 浏览器（原生 ES 模块） （启动快，按需编译，更新即时） # 工作流程 ## 1. 启动阶段 - 解析 index.html - 启动开发服务器 - 不进行预打包 ## 2. 请求处理 浏览器请求 → Vite 拦截 → 编译转换 → 返回 ## 3. 模块解析 import App from './App.vue' ↓ Vite 拦截 .vue 文件 ↓ 编译成 JavaScript ↓ 返回给浏览器 ## 4. 依赖预构建 - 使用 esbuild 预打包依赖 - CommonJS/UMD → ESM - 减少请求数量 # 依赖预构建触发条件 - package.json 的 dependencies 变化 - package-lock.json 变化 - vite.config.js 相关配置变化

🚀 热模块替换

# Vite HMR 原理 1. 服务器监听文件变化 2. 通过 WebSocket 通知客户端 3. 客户端请求更新的模块 4. 只替换变化的模块，保留状态 # Vue 组件 HMR 示例 <script setup lang="ts"> import { ref } from 'vue' // 修改这里会触发热更新，count 状态保留 const count = ref(0) </script> <template> <button @click="count++">{{ count }}</button> </template> # 手动处理 HMR if (import.meta.hot) { import.meta.hot.accept((newModule) => { // 处理模块更新 }) import.meta.hot.dispose(() => { // 清理副作用 }) } # HMR API import.meta.hot.accept() // 接受更新 import.meta.hot.decline() // 拒绝更新 import.meta.hot.invalidate() // 强制刷新 import.meta.hot.dispose() // 清理回调
