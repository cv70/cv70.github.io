47.5 全局守卫

配置全局生效的守卫

🎯 学习目标

  • 掌握全局守卫的配置方式
  • 了解全局守卫的依赖注入
  • 学会排除特定路由
  • 理解全局守卫的最佳实践

📚 全局守卫配置方式

// 方式1：main.ts 中注册（不支持依赖注入） async function bootstrap() { const app = await NestFactory.create(AppModule); app.useGlobalGuards(new AuthGuard()); await app.listen(3000); } // 方式2：模块中注册（支持依赖注入） import { APP_GUARD } from '@nestjs/core'; @Module({ providers: [ { provide: APP_GUARD, useClass: AuthGuard, // 支持依赖注入 }, ], }) export class AppModule {} // 方式3：使用现有实例 @Module({ providers: [ AuthGuard, { provide: APP_GUARD, useExisting: AuthGuard, }, ], }) export class AppModule {}
💡
推荐使用模块注册

使用 APP_GUARD 在模块中注册全局守卫，可以正确进行依赖注入。main.ts 中的方式需要手动处理依赖。

🔧 完整的全局认证配置

// auth.module.ts import { Module } from '@nestjs/common'; import { APP_GUARD } from '@nestjs/core'; import { JwtService } from '@nestjs/jwt'; import { AuthGuard } from './auth.guard'; @Module({ providers: [ JwtService, { provide: APP_GUARD, useClass: AuthGuard, }, ], exports: [JwtService], }) export class AuthModule {} // auth.guard.ts import { Injectable, CanActivate, ExecutionContext, UnauthorizedException } from '@nestjs/common'; import { JwtService } from '@nestjs/jwt'; import { Reflector } from '@nestjs/core'; import { IS_PUBLIC_KEY } from './public.decorator'; @Injectable() export class AuthGuard implements CanActivate { constructor( private jwtService: JwtService, private reflector: Reflector, ) {} async canActivate(context: ExecutionContext): Promise { // 检查是否公开路由 const isPublic = this.reflector.getAllAndOverride( IS_PUBLIC_KEY, [context.getHandler(), context.getClass()], ); if (isPublic) { return true; } const request = context.switchToHttp().getRequest(); const token = this.extractTokenFromHeader(request); if (!token) { throw new UnauthorizedException(); } try { const payload = await this.jwtService.verifyAsync(token); request['user'] = payload; } catch { throw new UnauthorizedException(); } return true; } private extractTokenFromHeader(request: Request): string | undefined { const [type, token] = request.headers.authorization?.split(' ') ?? []; return type === 'Bearer' ? token : undefined; } }

🚫 排除公开路由

// public.decorator.ts import { SetMetadata } from '@nestjs/common'; export const IS_PUBLIC_KEY = 'isPublic'; export const Public = () => SetMetadata(IS_PUBLIC_KEY, true); // auth.controller.ts @Controller('auth') export class AuthController { @Public() // 不需要认证 @Post('login') login(@Body() loginDto: LoginDto) { return this.authService.login(loginDto); } @Public() @Post('register') register(@Body() registerDto: RegisterDto) { return this.authService.register(registerDto); } @Post('logout') // 需要认证 logout() { return { message: 'Logged out' }; } } // health.controller.ts @Controller('health') @Public() // 整个控制器公开 export class HealthController { @Get() check() { return { status: 'ok' }; } }

🔄 多个全局守卫

@Module({ providers: [ { provide: APP_GUARD, useClass: AuthGuard, // 第一个执行 }, { provide: APP_GUARD, useClass: RolesGuard, // 第二个执行 }, { provide: APP_GUARD, useClass: PermissionsGuard, // 第三个执行 }, ], }) export class AppModule {} // 执行顺序：AuthGuard -> RolesGuard -> PermissionsGuard // 任何一个守卫拒绝，后续守卫不会执行
⚠️
守卫顺序依赖

RolesGuard 和 PermissionsGuard 依赖 AuthGuard 先执行并附加用户信息。确保使用 useFactory 或正确配置依赖注入顺序。

📝 本节小结

✅
