输入捕获应用

输入捕获是定时器的重要功能，用于捕获外部信号的跳变时刻。 通过测量信号跳变时的计数值，可以计算脉宽、频率、周期等参数。本节将深入讲解输入捕获的应用。

⚙️ 输入捕获工作原理

捕获机制

边沿检测

检测输入信号的上升沿或下降沿。可配置为上升沿、下降沿或双边沿触发。

计数器锁存

捕获事件发生时，将当前计数值锁存到CCR寄存器，同时产生中断或DMA请求。

滤波功能

输入滤波器消除噪声干扰，防止误触发。可配置滤波时间。

📊 脉宽测量

步骤 操作 计算
1 配置捕获上升沿，捕获CCR1 记录上升沿时刻t1
2 配置捕获下降沿，捕获CCR2 记录下降沿时刻t2
3 计算脉宽 Pulse_Width = (CCR2 - CCR1) / Tclk

🔧 频率测量方法

两种测量方法

周期计数法（测频）

  • 在固定时间窗口内计数脉冲个数
  • 频率 = 脉冲数 / 时间窗口
  • 适合高频信号
  • 低频时精度差

周期测量法（测周）

  • 测量一个或多个周期的时间
  • 频率 = 1 / 周期
  • 适合低频信号
  • 高频时分辨率不够

📐 PWM输入捕获

PWM信号测量

配置方法

  • 使用两个捕获通道
  • 通道1捕获上升沿（周期）
  • 通道2捕获下降沿（脉宽）
  • 从控模式自动切换边沿

计算公式

  • 周期 = CCR1 / Tclk
  • 脉宽 = CCR2 / Tclk
  • 频率 = Tclk / CCR1
  • 占空比 = CCR2 / CCR1 × 100%
✨
最佳实践

输入捕获应用建议：1）根据信号频率选择合适的测量方法；2）配置合适的输入滤波，消除噪声干扰；3）注意计数器溢出处理，特别是低频信号；4）使用中断或DMA处理捕获事件，提高效率；5）高精度测量可使用外部时钟源提高分辨率；6）多通道捕获可同时测量多个信号。
