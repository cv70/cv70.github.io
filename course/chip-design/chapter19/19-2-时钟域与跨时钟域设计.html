19.2 时钟域与跨时钟域设计

处理多时钟系统的设计挑战

🎯 学习目标

  • 理解时钟域的概念
  • 掌握跨时钟域问题
  • 学习常用的CDC处理方法
  • 了解亚稳态及其影响

时钟域的概念

时钟域（Clock Domain）是指由同一时钟驱动的所有触发器和逻辑单元组成的集合。当信号从一个时钟域传递到另一个时钟域时，就产生了跨时钟域（CDC）问题。

⚡ 亚稳态问题

亚稳态产生条件

  • 异步信号在时钟沿附近变化
  • 建立/保持时间违规
  • 多时钟系统中的信号传递
  • 复位信号的释放

亚稳态影响

  • 输出不确定
  • 传播错误信号
  • 导致系统功能异常
  • 降低系统可靠性
⚠️
关键概念

MTBF（平均无故障时间）：亚稳态发生到恢复稳定状态的平均时间。通过使用同步器可以显著提高MTBF。

🛠️ 常用CDC处理方法

方法 适用场景 特点
双触发器同步器 单bit控制信号 简单有效，延迟2个时钟周期
握手协议 数据包传输 可靠但速度慢
FIFO 突发数据传输 高效，需要异步FIFO
格雷码 计数器/指针 只有1bit变化，减少冒险

💻 双触发器同步器代码

// 双触发器同步器
module sync_2ff (
    input wire clk_dst,
    input wire rst_n,
    input wire async_sig,
    output reg sync_sig
);

reg sync_sig_reg;

always @(posedge clk_dst or negedge rst_n) begin
    if (!rst_n) begin
        sync_sig_reg <= 1'b0;
        sync_sig     <= 1'b0;
    end else begin
        sync_sig_reg <= async_sig;
        sync_sig     <= sync_sig_reg;
    end
end

endmodule

📊 CDC设计检查清单

  • 所有跨时钟域信号是否已正确处理？
  • 是否使用了适当的同步器？
  • 多bit信号是否使用了安全的方法？
  • 是否进行了CDC检查和分析？
  • 复位释放是否同步？

📝 本节小结

✅
  • • 时钟域是由同一时钟驱动的逻辑集合
  • • CDC问题会导致亚稳态，影响系统可靠性
  • • 单bit信号使用双触发器同步器
  • • 多bit信号使用握手、FIFO或格雷码等方法
