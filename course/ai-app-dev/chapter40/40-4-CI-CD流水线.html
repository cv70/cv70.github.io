机器学习的持续集成与持续部署

ML中的CI/CD

ML CI/CD在传统CI/CD基础上增加了机器学习特有的环节：数据验证、模型训练、模型评估和模型部署。它实现了从代码提交到模型上线的全自动化流程。

🔄 ML CI/CD流水线架构

📥

持续集成(CI)

代码测试、数据验证、模型训练

📤

持续部署(CD)

模型打包、服务部署、流量切换

🔄

持续训练(CT)

自动触发训练、模型更新

⚖️ CI/CD流水线对比

阶段 传统软件 机器学习
代码验证 单元测试、集成测试 + 模型性能测试、数据质量检查
构建产物 可执行文件、Docker镜像 模型文件、推理服务镜像
部署策略 蓝绿部署、金丝雀发布 + 模型A/B测试、影子模式
触发条件 代码提交、定时任务 + 数据更新、性能退化

💻 GitHub Actions配置示例

# .github/workflows/ml-pipeline.yml name: ML Pipeline on: push: branches: [main] schedule: - cron: '0 2 * * *' # 每天凌晨2点 jobs: train: runs-on: ubuntu-latest steps: - uses: actions/checkout@v3 - name: Set up Python uses: actions/setup-python@v4 with: python-version: '3.10' - name: Install dependencies run: | pip install -r requirements.txt - name: Validate data run: python scripts/validate_data.py - name: Train model run: | python scripts/train.py \ --data-path ${{ secrets.DATA_PATH }} \ --experiment-name ${{ github.sha }} - name: Evaluate model run: python scripts/evaluate.py - name: Register model if: success() run: python scripts/register_model.py deploy: needs: train runs-on: ubuntu-latest steps: - name: Deploy to production run: python scripts/deploy.py --stage production

流水线触发策略

ML流水线可以由多种条件触发：代码提交（模型架构变更）、定时任务（周期性重训）、数据更新（新数据到达）、性能告警（模型退化）。

🔧 部署策略详解

蓝绿部署

# 流量切换脚本 def blue_green_deploy(new_model_version): # 1. 部署新版本到Green环境 deploy_model(new_model_version, env="green") # 2. 健康检查 if not health_check(env="green"): rollback(env="green") return False # 3. 切换流量 update_load_balancer(target="green") # 4. 保留Blue环境用于回滚 keep_old_version(env="blue", ttl="24h") return True
  • 快速回滚能力
  • 零停机部署
  • 需要双倍资源

金丝雀发布

# 渐进式流量切换 def canary_deploy(new_model_version): # 逐步增加流量 for percentage in [5, 10, 25, 50, 100]: set_traffic_split({ "current": 100 - percentage, "canary": percentage }) # 监控指标 if not monitor_metrics(duration="1h"): rollback_canary() return False # 完全切换 set_traffic_split({"current": 0, "canary": 100})
  • 渐进式验证
  • 风险可控
  • 适合大规模系统

🔄 持续训练(CT)流水线

# 持续训练触发器配置 ct_triggers = { # 数据触发：新数据达到阈值 "data_trigger": { "type": "data_volume", "threshold": 10000, # 新增1万条样本 "action": "retrain" }, # 性能触发：模型准确率下降 "performance_trigger": { "type": "metric_threshold", "metric": "accuracy", "threshold": 0.90, "condition": "below", "action": "retrain_and_alert" }, # 时间触发：定期重训 "schedule_trigger": { "type": "cron", "schedule": "0 2 * * 0", # 每周日凌晨2点 "action": "retrain" } }
