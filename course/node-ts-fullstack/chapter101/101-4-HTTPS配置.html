101.4 HTTPS 配置

使用 Let's Encrypt 配置免费 SSL 证书

为什么需要 HTTPS

HTTPS（HTTP Secure）通过 SSL/TLS 协议加密 HTTP 通信， 保护数据传输安全，防止数据被窃取或篡改。现代浏览器将 HTTP 网站标记为"不安全"， 搜索引擎也对 HTTPS 网站给予更高权重。

🔒

数据加密

保护敏感信息不被窃取

✅

身份验证

确认服务器真实身份

📊

SEO 优化

搜索引擎优先收录

🎯

用户信任

浏览器显示安全标识

🛠️ 安装 Certbot

# Ubuntu/Debian sudo apt update sudo apt install certbot python3-certbot-nginx -y # CentOS/RHEL sudo yum install certbot python3-certbot-nginx -y # 验证安装 certbot --version

📜 获取 SSL 证书

方法1: 使用 Certbot 自动配置

# 自动获取证书并配置 Nginx sudo certbot --nginx -d example.com -d www.example.com # 按提示输入邮箱并同意条款 # Certbot 会自动修改 Nginx 配置

方法2: 手动获取证书

# 仅获取证书，不修改配置 sudo certbot certonly --nginx -d example.com -d www.example.com # 证书位置 # /etc/letsencrypt/live/example.com/fullchain.pem # /etc/letsencrypt/live/example.com/privkey.pem # 使用 DNS 验证（适用于内网或负载均衡） sudo certbot certonly --manual --preferred-challenges dns -d example.com

📁 Nginx HTTPS 配置

# /etc/nginx/sites-available/myapp server { listen 80; server_name example.com www.example.com; # 强制跳转 HTTPS return 301 https://$server_name$request_uri; } server { listen 443 ssl http2; server_name example.com www.example.com; # SSL 证书配置 ssl_certificate /etc/letsencrypt/live/example.com/fullchain.pem; ssl_certificate_key /etc/letsencrypt/live/example.com/privkey.pem; # SSL 安全配置 ssl_protocols TLSv1.2 TLSv1.3; ssl_ciphers ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-RSA-AES128-GCM-SHA256: ECDHE-ECDSA-AES256-GCM-SHA384:ECDHE-RSA-AES256-GCM-SHA384: ECDHE-ECDSA-CHACHA20-POLY1305:ECDHE-RSA-CHACHA20-POLY1305: DHE-RSA-AES128-GCM-SHA256:DHE-RSA-AES256-GCM-SHA384; ssl_prefer_server_ciphers off; # SSL 会话配置 ssl_session_timeout 1d; ssl_session_cache shared:SSL:10m; ssl_session_tickets off; # HSTS (可选，增强安全性) add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always; # OCSP Stapling ssl_stapling on; ssl_stapling_verify on; resolver 8.8.8.8 8.8.4.4 valid=300s; resolver_timeout 5s; # 反向代理 location / { proxy_pass http://localhost:3000; proxy_http_version 1.1; proxy_set_header Host $host; proxy_set_header X-Real-IP $remote_addr; proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for; proxy_set_header X-Forwarded-Proto $scheme; } }

🔄 证书自动续期

# 测试续期 sudo certbot renew --dry-run # Certbot 会自动添加定时任务 # 查看定时任务 sudo systemctl list-timers | grep certbot # 手动续期 sudo certbot renew # 续期后重载 Nginx sudo systemctl reload nginx

自定义续期钩子

# /etc/letsencrypt/renewal/example.com.conf # 添加以下内容 renew_hook = systemctl reload nginx

🧪 SSL 测试与验证

# 在线测试: https://www.ssllabs.com/ssltest/ # 命令行测试 openssl s_client -connect example.com:443 -servername example.com # 查看证书信息 openssl x509 -in /etc/letsencrypt/live/example.com/cert.pem -text -noout # 检查证书过期时间 echo | openssl s_client -connect example.com:443 2>/dev/null | \ openssl x509 -noout -dates
⚠️
注意事项
  • Let's Encrypt 证书有效期为 90 天，需要定期续期
  • 确保证书续期时 Nginx 能够正常重载
  • 配置防火墙开放 443 端口
  • 测试环境中先使用 --dry-run 避免触发限制
  • 每个域名每周最多申请 5 次
