运算符分类

Verilog提供了丰富的运算符，可分为算术运算符、逻辑运算符、位运算符、关系运算符、等式运算符、移位运算符和拼接运算符等。

➕ 算术运算符

运算符说明示例结果
+加法4 + 26
-减法4 - 22
*乘法4 * 28
/除法4 / 22
%取模7 % 31
**幂运算2 ** 38
⚠️
注意事项

• 除法和取模运算综合成本较高，需谨慎使用
• 负数运算结果可能不符合预期，建议使用无符号数

💡 逻辑运算符

运算符说明示例说明
!逻辑非!(a)a为0则结果为1
&&逻辑与a && b都为真则为真
||逻辑或a || b有真则为真
💡
位运算 vs 逻辑运算

位运算：对每一位单独运算，结果为多位
• 4'b1010 & 4'b1100 = 4'b1000
逻辑运算：整体判断真假，结果为1位（0或1）
• 4'b1010 && 4'b1100 = 1'b1（都非零）

⚖️ 关系与等式运算符

运算符说明结果类型
<, >小于、大于返回0或1
<=, >=小于等于、大于等于返回0或1
==, !=相等、不等（可能含x/z）可能返回x
===, !==全等、不全等（精确比较）返回0或1

运算符说明示例结果

>>逻辑右移4'b0101 >> 24'b0001
<<<算术左移4'b0101 <<< 24'b0100
>>>算术右移4'sb1010 >>> 24'sb1110

🔗 拼接运算符

拼接与复制

// 拼接：将多个信号合并
wire [7:0] result = {a, b, c[1:0]};  // a(4位) + b(2位) + c[1:0](2位) = 8位

// 复制：重复信号
wire [7:0] all_ones = {8{1'b1}};     // 8个1
wire [15:0] repeat = {2{8'hAA}};     // 16'hAAAA

📝 本节小结

✅
