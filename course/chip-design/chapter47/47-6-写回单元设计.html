47.6 写回单元设计

RISC-V 处理器设计实战

🎯 学习目标

  • 理解写回单元的功能和设计要点
  • 掌握寄存器堆的写回机制
  • 了解写回数据的选择逻辑
  • 熟悉异常时的写回处理

写回单元概述

写回单元（Write Back Unit, WBU）是流水线的最后一级，负责将指令执行 结果写回寄存器堆。WBU需要从多个数据源中选择正确的写回数据，并处理异常情况下的写回取消。

🧩 WBU基本架构

主要组件

数据选择

  • 多路选择器 - 选择写回数据
  • 数据源 - ALU结果/内存数据/PC+4

控制逻辑

  • 写使能 - 控制寄存器写
  • 异常处理 - 取消写回

📊 写回数据源

数据源 描述 控制信号
ALU结果 算术逻辑运算结果 mem_to_reg=0
内存数据 Load指令从内存读取的数据 mem_to_reg=1
PC+4 跳转/链接指令的返回地址 jump=1
立即数 LUI/AUIPC的结果 特殊处理

💻 WBU实现

写回逻辑

// 写回数据选择 wire [31:0] wb_data; assign wb_data = (mem_to_reg) ? mem_read_data : (jump) ? pc_plus_4 : alu_result; // 寄存器写使能 wire reg_write_en = reg_write && !exception && !flush; // 写回目的寄存器 wire [4:0] rd_wb = (reg_write_en) ? rd : 5'b0; // 写入寄存器堆 register_file reg_file ( .clk (clk), .rd_a1 (rs1), .rd_a2 (rs2), .rd_d1 (reg_data1), .rd_d2 (reg_data2), .wr_en (reg_write_en), .wr_addr (rd_wb), .wr_data (wb_data) );

⚠️ 异常处理

异常时的写回控制

  • 异常检测 - 在WB阶段检测异常
  • 写回取消 - 异常时禁止写回
  • 流水线刷新 - 清除后续指令
  • PC保存 - 保存异常返回地址
💡
精确异常

处理器需要支持精确异常，即异常发生时，所有在异常指令之前的指令都已完成， 所有在异常指令之后的指令都未修改架构状态。这需要在流水线中正确处理异常和写回。

🔄 前递支持

WBU前递数据

WBU阶段的写回数据需要前递到ID/EX阶段，用于解决数据冒险。

// 前递信号 wire [4:0] wb_rd = rd_wb; wire [31:0] wb_data_out = wb_data; wire wb_reg_write = reg_write_en; // 这些信号连接到前递单元

📝 本节小结

✅
  • • WBU负责将结果写回寄存器堆
  • • 需要从多个数据源选择写回数据
  • • 异常时需要取消写回
  • • WBU数据需要前递到早期阶段
