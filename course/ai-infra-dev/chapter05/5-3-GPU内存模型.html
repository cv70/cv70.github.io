GPU内存模型概述

GPU内存模型复杂而强大，包含从最快的寄存器到最慢的全局内存多层结构。理解这些内存类型及其访问模式对于编写高性能GPU程序至关重要。

🏗️ 内存层次结构

存储层次

GPU内存层次： ↑ 速度 ↑ ↓ 容量 ↓ ┌─────────────────────────────────────┐ │ 寄存器（Register） │ 最快，线程私有 │ • 数量有限（每个线程） │ │ • 编译器自动分配 │ │ • 无需手动管理 │ ├─────────────────────────────────────┤ │ 共享内存（Shared Memory） │ 快，Block内共享 │ • 手动管理 │ │ • 需要__syncthreads()同步 │ │ • 可编程缓存 │ ├─────────────────────────────────────┤ │ L1/L2 Cache │ 硬件缓存 │ • 透明加速 │ │ • 自动管理 │ ├─────────────────────────────────────┤ │ 常量内存（Constant Memory） │ 只读，全局共享 │ • 编译时常量 │ │ • 缓存优化 │ ├─────────────────────────────────────┤ │ 纹理内存（Texture Memory） │ 只读，特殊访问 │ • 空间局部性优化 │ │ • 纹理采样 │ ├─────────────────────────────────────┤ │ 全局内存（Global Memory） │ 慢，全局共享 │ • 容量大（GB级） │ │ • 主要存储空间 │ │ • 需要优化访问模式 │ └─────────────────────────────────────┘

💾 共享内存

可编程缓存

共享内存是GPU上最快的可编程内存，可用于优化全局内存访问：

共享内存使用示例： __global__ void shared_memory_example(float *input, float *output, int n) { // 声明共享内存 extern __shared__ float s_data[]; int tid = threadIdx.x; int gid = blockIdx.x * blockDim.x + tid; // 加载数据到共享内存 if (gid < n) { s_data[tid] = input[gid]; } __syncthreads(); // 同步等待所有加载完成 // 处理共享内存数据（比全局内存快） if (gid < n) { s_data[tid] = s_data[tid] * 2; } __syncthreads(); // 写回结果 if (gid < n) { output[gid] = s_data[tid]; } } // 调用时需要指定共享内存大小 int blockSize = 256; int sharedMemSize = blockSize * sizeof(float); shared_memory_example<<>>(d_input, d_output, n);
💡
使用建议

共享内存适合存储频繁访问的数据，可以显著减少对慢速全局内存的访问。

🔀 内存合并

Coalesced Access

内存合并是GPU性能优化的关键，确保Warp中的线程访问连续内存：

内存合并示例： // 不好：非合并访问 __global__ void uncoalesced_access(float *data) { int tid = threadIdx.x; int stride = 1024; // 大步长 data[tid * stride] = tid; // 非连续访问 // Warp内线程访问相距1024的内存 } // 好：合并访问 __global__ void coalesced_access(float *data) { int tid = threadIdx.x; data[tid] = tid; // 连续访问 // Warp内线程访问连续的32个浮点数 } // 2D访问优化 __global__ void row_major_optimized(float *matrix, int width, int height) { int x = blockIdx.x * blockDim.x + threadIdx.x; int y = blockIdx.y * blockDim.y + threadIdx.y; if (x < width && y < height) { int idx = y * width + x; // 行主序 matrix[idx] = idx; // 合并访问 } } // 列主序访问 __global__ void column_major_optimized(float *matrix, int width, int height) { int x = blockIdx.x * blockDim.x + threadIdx.x; int y = blockIdx.y * blockDim.y + threadIdx.y; if (x < width && y < height) { int idx = x * height + y; // 列主序 matrix[idx] = idx; // 合并访问 } }

🔄 统一内存

Unified Memory

统一内存简化了GPU编程，让开发者无需手动管理数据传输：

统一内存使用： #include // 分配统一内存 float *data; cudaMallocManaged(&data, n * sizeof(float)); // 主机可以直接访问 for (int i = 0; i < n; i++) { data[i] = i; } // GPU可以直接访问 kernel<<>>(data, n); // 自动数据传输 // CUDA Runtime自动处理主机与GPU间的数据移动 // 显式预取（优化性能） cudaMemPrefetchAsync(data, n * sizeof(float), 0); // 预取到GPU kernel<<>>(data, n); cudaMemPrefetchAsync(data, n * sizeof(float), cudaCpuDeviceId); // 预取到CPU // 释放内存 cudaFree(data);

优点

  • 简化编程
  • 自动数据迁移
  • 减少错误
  • 代码简洁

缺点

  • 性能开销
  • 页面错误
  • 不可预测
  • 依赖HBM支持
