63.4 Socket.IO 简介

功能强大的实时通信框架

🎯 学习目标

  • 了解 Socket.IO 的定位和优势
  • 理解 Socket.IO 与原生 WebSocket 的区别
  • 掌握 Socket.IO 的核心特性
  • 学会安装和基本配置

什么是 Socket.IO

Socket.IO 是一个基于事件驱动的 JavaScript 实时通信库，它使得客户端和服务器之间的双向实时通信变得非常简单。Socket.IO 由两部分组成：

  • 服务端：运行在 Node.js 服务器上
  • 客户端：可在浏览器或 Node.js 中运行
💡
重要说明

Socket.IO 不是 WebSocket 的实现，而是一个独立的实时通信框架。虽然它默认使用 WebSocket 作为传输方式，但它在 WebSocket 之上封装了更多功能，并在 WebSocket 不可用时自动降级到其他传输方式。

⚡ Socket.IO 核心特性

🔄 自动降级传输

当 WebSocket 不可用时，自动降级到 HTTP 长轮询等方式，确保通信可靠。

降级顺序： WebSocket → HTTP 长轮询 → JSONP 轮询

🔁 自动重连

连接断开时自动尝试重连，支持配置重连策略。

// 默认重连配置 reconnection: true reconnectionAttempts: Infinity reconnectionDelay: 1000

📦 命名空间

通过命名空间分隔不同的通信频道，避免消息混淆。

// 不同命名空间独立通信 io.of('/chat') io.of('/notifications')

🏠 房间系统

支持将连接分组到房间，方便实现群组广播。

// 加入房间 socket.join('room1') // 向房间广播 io.to('room1').emit('msg')

📨 消息确认

支持消息确认机制，确保消息被正确处理。

// 客户端发送并等待确认 socket.emit('event', data, (ack) => { console.log('服务端已确认'); });

💾 心跳机制

内置心跳检测，自动管理连接状态。

// 心跳配置 pingInterval: 25000 pingTimeout: 60000

⚖️ Socket.IO vs 原生 WebSocket

特性 原生 WebSocket Socket.IO
传输方式 仅 WebSocket WebSocket + 降级方案
自动重连 需手动实现 内置支持
房间/命名空间 需手动实现 内置支持
消息确认 不支持 支持回调确认
广播 需手动实现 内置 API
二进制支持 原生支持 支持
兼容性 现代浏览器 更广泛（含旧浏览器）
体积 浏览器原生 客户端约 30KB

📥 安装 Socket.IO

服务端安装

# 使用 npm npm install socket.io # 使用 yarn yarn add socket.io # 使用 pnpm pnpm add socket.io

客户端安装

# npm 包（用于 Node.js 客户端或打包工具） npm install socket.io-client # CDN 引入 <script src="/socket.io/socket.io.js"></script> # 或者使用 CDN <script src="https://cdn.socket.io/4.7.2/socket.io.min.js"></script>

🚀 快速开始

服务端（与 HTTP 服务器集成）

import { createServer } from 'http'; import { Server } from 'socket.io'; // 创建 HTTP 服务器 const httpServer = createServer(); // 创建 Socket.IO 服务器 const io = new Server(httpServer, { // 配置选项 cors: { origin: "http://localhost:3000", methods: ["GET", "POST"] } }); // 监听连接事件 io.on('connection', (socket) => { console.log('客户端已连接:', socket.id); // 接收消息 socket.on('chat message', (msg) => { console.log('收到消息:', msg); // 广播给所有客户端 io.emit('chat message', msg); }); // 监听断开连接 socket.on('disconnect', () => { console.log('客户端已断开:', socket.id); }); }); // 启动服务器 httpServer.listen(3000, () => { console.log('服务器运行在 http://localhost:3000'); });

客户端

import { io } from 'socket.io-client'; // 连接到服务器 const socket = io('http://localhost:3000'); // 连接成功 socket.on('connect', () => { console.log('已连接到服务器'); // 发送消息 socket.emit('chat message', 'Hello World!'); }); // 接收消息 socket.on('chat message', (msg) => { console.log('收到消息:', msg); }); // 连接错误 socket.on('connect_error', (error) => { console.error('连接错误:', error); });

⚙️ 常用配置选项

const io = new Server(httpServer, { // CORS 配置 cors: { origin: ['http://localhost:3000', 'http://example.com'], methods: ['GET', 'POST'], credentials: true }, // 心跳配置 pingInterval: 25000, // 心跳间隔（毫秒） pingTimeout: 60000, // 心跳超时（毫秒） // 传输方式 transports: ['websocket', 'polling'], // 默认两种都启用 // 连接配置 connectTimeout: 45000, // 连接超时 // 路径配置 path: '/socket.io/', // 默认路径 });

📝 本节小结

✅
  • • Socket.IO 是一个完整的实时通信框架，不是 WebSocket 实现
  • • 提供自动降级、重连、房间、命名空间等丰富功能
  • • 相比原生 WebSocket，开发效率更高，功能更完善
  • • 客户端和服务端都需要使用 Socket.IO 库
  • • 支持灵活的配置选项，可适应各种场景
