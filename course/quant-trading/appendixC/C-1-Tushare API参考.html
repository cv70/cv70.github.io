C-1 Tushare API参考

数据API参考

🔑 认证与初始化

# 安装Tushare
pip install tushare

# 导入并初始化
import tushare as ts

# 设置token (在官网注册获取)
ts.set_token('your_token_here')

# 创建API对象
pro = ts.pro_api()

# 或者直接传递token
pro = ts.pro_api('your_token_here')

📊 行情数据

接口 说明 示例
daily() 日线行情 pro.daily(ts_code='000001.SZ')
daily_basic() 每日指标 pro.daily_basic(ts_code='000001.SZ')
weekly() 周线行情 pro.weekly(ts_code='000001.SZ')
monthly() 月线行情 pro.monthly(ts_code='000001.SZ')
trade_cal() 交易日历 pro.trade_cal(exchange='SSE')

接口 说明 示例

🔧 通用参数

参数 说明 示例
ts_code 股票代码 '000001.SZ'
trade_date 交易日期 '20240101'
start_date 开始日期 '20240101'
end_date 结束日期 '20241231'
limit 返回条数 100
offset 偏移量 0
⚠️
使用限制

Tushare API有调用频率限制，免费用户每分钟最多请求200次。 建议合理规划数据获取时间，避免频繁调用。注意积分权限， 部分接口需要付费才能访问。
