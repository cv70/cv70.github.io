什么是PagedAttention

PagedAttention是vLLM框架引入的革命性技术，用于解决KV Cache的内存碎片问题。 它借鉴操作系统的虚拟内存管理思想，将KV Cache划分为固定大小的块（block）， 实现了动态内存分配和高效复用。

🔍 传统KV Cache的问题

连续内存分配的困境

内存碎片
  • 固定最大序列长度分配
  • 短序列浪费大量内存
  • 无法动态调整大小
并发受限
  • 显存预分配限制并发
  • 无法及时释放内存
  • 批处理效率低
资源浪费
  • 内存利用率低（<20%）
  • 无法有效复用
  • 成本高昂

虚拟内存类比

📊 核心优势

内存效率

  • 无碎片：避免内存碎片化
  • 按需分配：不预分配全部
  • 动态扩展：随序列增长
  • 高利用率：可达80%+

计算效率

  • 内核优化：融合内核加速
  • 批量处理：多个请求批处理
  • 缓存共享：相同前缀共享
  • 并行计算：充分利用GPU

🔗 共享计算

前缀共享机制

PagedAttention支持多个请求共享相同的前缀KV，大幅减少计算和内存开销。

共享场景
  • 系统提示词：多个请求共享相同的系统prompt
  • 文档对话：基于同一文档的多轮对话
  • 少样本：相同的few-shot示例
  • 对话历史：共享相同的对话上下文

# PagedAttention的核心概念（简化版）

class Block:
    """
    物理内存块
    """
    def __init__(self, block_size, device='cuda'):
        # KV Cache块
        self.block_size = block_size
        # 每个块存储block_size个token的KV
        self.k_cache = torch.empty(
            num_heads, block_size, head_dim,
            dtype=torch.float16, device=device
        )
        self.v_cache = torch.empty(
            num_heads, block_size, head_dim,
            dtype=torch.float16, device=device
        )
        self.ref_count = 0  # 引用计数

class BlockManager:
    """
    块管理器
    """
    def __init__(self, num_blocks, block_size):
        self.block_size = block_size
        self.num_blocks = num_blocks

        # 物理块池
        self.physical_blocks = [Block(block_size) for _ in range(num_blocks)]

        # 空闲块列表
        self.free_blocks = list(range(num_blocks))

        # 请求的页表
        self.page_tables = {}  # {request_id: [block_idx, ...]}

    def allocate(self, request_id, num_blocks):
        """
        为请求分配块
        """
        if len(self.free_blocks) < num_blocks:
            raise RuntimeError("Not enough free blocks")

        # 分配块
        allocated_blocks = []
        for _ in range(num_blocks):
            block_idx = self.free_blocks.pop()
            self.physical_blocks[block_idx].ref_count += 1
            allocated_blocks.append(block_idx)

        # 更新页表
        self.page_tables[request_id] = allocated_blocks

        return allocated_blocks

    def deallocate(self, request_id):
        """
        释放请求的块
        """
        if request_id not in self.page_tables:
            return

        # 释放块
        for block_idx in self.page_tables[request_id]:
            self.physical_blocks[block_idx].ref_count -= 1
            if self.physical_blocks[block_idx].ref_count == 0:
                self.free_blocks.append(block_idx)

        # 删除页表
        del self.page_tables[request_id]

    def get_blocks(self, request_id):
        """
        获取请求的块列表
        """
        return self.page_tables.get(request_id, [])

class PagedAttention:
    """
    PagedAttention实现
    """
    def __init__(self, block_size=16, num_blocks=1000):
        self.block_size = block_size
        self.block_manager = BlockManager(num_blocks, block_size)

    def compute_attention(self, q, k_blocks, v_blocks, page_table):
        """
        计算PagedAttention
        Args:
            q: Query (batch, num_heads, 1, head_dim)
            k_blocks: Key块列表
            v_blocks: Value块列表
            page_table: 页表，映射逻辑块到物理块
        """
        # 收集所有需要的块
        all_k = []
        all_v = []

        for block_idx in page_table:
            all_k.append(k_blocks[block_idx])
            all_v.append(v_blocks[block_idx])

        # 拼接所有KV
        k_concat = torch.cat(all_k, dim=2)  # (num_heads, seq_len, head_dim)
        v_concat = torch.cat(all_v, dim=2)

        # 计算注意力
        attn_output = self._scaled_dot_product_attention(q, k_concat, v_concat)

        return attn_output

    def _scaled_dot_product_attention(self, q, k, v):
        """
        缩放点积注意力
        """
        # q: (batch, num_heads, 1, head_dim)
        # k: (batch, num_heads, seq_len, head_dim)
        # v: (batch, num_heads, seq_len, head_dim)

        # 计算注意力分数
        scores = torch.matmul(q, k.transpose(-2, -1)) / (k.size(-1) ** 0.5)

        # Softmax
        attn_weights = torch.softmax(scores, dim=-1)

        # 加权求和
        output = torch.matmul(attn_weights, v)

        return output

# 使用示例
def example_usage():
    # 初始化
    block_size = 16  # 每个块16个token
    num_blocks = 1000
    paged_attn = PagedAttention(block_size, num_blocks)

    # 新请求
    request_id = "req_1"

    # 分配块（假设需要10个块）
    blocks = paged_attn.block_manager.allocate(request_id, num_blocks=10)

    # 计算注意力
    q = torch.randn(1, 32, 1, 128, device='cuda')
    attn_output = paged_attn.compute_attention(
        q,
        paged_attn.block_manager.physical_blocks,
        paged_attn.block_manager.physical_blocks,
        blocks
    )

    # 释放
    paged_attn.block_manager.deallocate(request_id)
