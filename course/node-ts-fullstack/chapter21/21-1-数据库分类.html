21.1 数据库分类

了解数据库的分类体系和特点

🎯 学习目标

  • 理解数据库的基本概念
  • 掌握数据库的主要分类方式
  • 了解不同类型数据库的特点
  • 学会根据场景选择数据库类型

📚 数据库概述

数据库（Database）是按照数据结构来组织、存储和管理数据的仓库。它是一个长期存储在计算机内的、有组织的、可共享的、统一管理的大量数据的集合。

数据库的主要特征： ├── 数据结构化 ├── 数据共享性 ├── 数据独立性 ├── 数据完整性 └── 数据安全性
💡
数据库管理系统（DBMS）

数据库管理系统是用于创建、管理和查询数据库的软件系统。常见的 DBMS 包括 MySQL、PostgreSQL、MongoDB、Redis 等。

🔧 数据库分类方式

数据库分类 ├── 按数据模型分类 │ ├── 关系型数据库（RDBMS） │ │ ├── MySQL │ │ ├── PostgreSQL │ │ ├── Oracle │ │ └── SQL Server │ └── 非关系型数据库（NoSQL） │ ├── 文档型：MongoDB │ ├── 键值型：Redis │ ├── 列族型：Cassandra │ └── 图型：Neo4j │ ├── 按存储方式分类 │ ├── 行存储：MySQL、PostgreSQL │ └── 列存储：ClickHouse、HBase │ └── 按部署方式分类 ├── 单机数据库 ├── 分布式数据库 └── 云数据库

📊 关系型 vs 非关系型对比

特性 关系型数据库 非关系型数据库
数据结构 表格（行、列） 文档、键值对、图等
查询语言 SQL 各产品特有API
事务支持 ACID完整支持 通常支持BASE
扩展性 垂直扩展为主 水平扩展为主
适用场景 结构化数据、复杂查询 非结构化数据、高并发

📝 本节小结

✅
  • • 数据库按数据模型分为关系型和非关系型
  • • 关系型数据库使用表格存储结构化数据
  • • 非关系型数据库适合非结构化和半结构化数据
  • • 选择数据库需考虑数据特点、查询需求和扩展性
