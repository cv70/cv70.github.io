AI应用安全的重要性

AI应用安全涉及模型安全、数据安全、API安全等多个层面。随着AI应用的普及，模型可能被攻击（对抗样本）、数据可能泄露、API可能被滥用。完善的安全审计机制是保障AI应用可信、可靠的关键。

🛡️ AI安全威胁类型

威胁类型 说明 防护措施
对抗攻击 精心构造输入欺骗模型 对抗训练、输入验证
模型窃取 通过API查询窃取模型 查询限制、差分隐私
数据投毒 污染训练数据 数据验证、异常检测
成员推断 推断数据是否在训练集 差分隐私、正则化
API滥用 恶意调用消耗资源 限流、认证授权

# API认证中间件示例
from fastapi import FastAPI, Depends, HTTPException
from fastapi.security import APIKeyHeader
import jwt

app = FastAPI()
api_key_header = APIKeyHeader(name="X-API-Key")

# API Key认证
async def verify_api_key(api_key: str = Depends(api_key_header)):
    if not is_valid_api_key(api_key):
        raise HTTPException(status_code=401, detail="Invalid API Key")
    return api_key

# JWT认证
async def verify_jwt_token(token: str):
    try:
        payload = jwt.decode(token, SECRET_KEY, algorithms=["HS256"])
        return payload
    except jwt.ExpiredSignatureError:
        raise HTTPException(status_code=401, detail="Token expired")

# RBAC权限控制
def check_permission(resource: str, action: str):
    def decorator(func):
        async def wrapper(*args, user=Depends(get_current_user), **kwargs):
            if not has_permission(user.role, resource, action):
                raise HTTPException(status_code=403, detail="Permission denied")
            return await func(*args, **kwargs)
        return wrapper
    return decorator

@app.post("/predict")
@check_permission("model", "inference")

📝 审计日志设计

# 审计日志记录
import logging
from datetime import datetime
from dataclasses import dataclass
from typing import Optional

@dataclass
class AuditLog:
    timestamp: str
    user_id: str
    action: str
    resource: str
    resource_id: Optional[str]
    ip_address: str
    user_agent: str
    status: str
    details: dict

class AuditLogger:
    def __init__(self):
        self.logger = logging.getLogger("audit")
        self.logger.setLevel(logging.INFO)

    def log_model_access(self, user_id, model_name, action, status, details=None):
        """记录模型访问审计"""
        audit_entry = AuditLog(
            timestamp=datetime.utcnow().isoformat(),
            user_id=user_id,
            action=action,
            resource=f"model/{model_name}",
            resource_id=None,
            ip_address=get_request_ip(),
            user_agent=get_user_agent(),
            status=status,
            details=details or {}
        )
        self.logger.info(audit_entry.__dict__)

    def log_data_access(self, user_id, dataset_name, action, records_accessed):
        """记录数据访问审计"""
        self.logger.info({
            "event": "data_access",
            "user_id": user_id,
            "dataset": dataset_name,
            "action": action,
            "records": records_accessed,
            "timestamp": datetime.utcnow().isoformat()
        })

# 使用示例
audit = AuditLogger()
audit.log_model_access(
    user_id="user-123",
    model_name="gpt-model",
    action="inference",
    status="success",
    details={"tokens_used": 500}
)

合规标准 适用场景 关键要求

⚠️
AI安全特别提示

AI应用需要注意：模型文件可能包含训练数据痕迹，发布前需检查是否泄露敏感信息；API响应可能暴露模型细节，需过滤敏感字段；日志不应记录原始输入，避免数据泄露风险。
