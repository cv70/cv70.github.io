9.1 映射类型基础

基于旧类型创建新类型

🎯 学习目标

  • 理解映射类型的概念和作用
  • 掌握 in 和 keyof 的使用
  • 学会遍历类型的键
  • 了解映射类型的基本应用

📚 什么是映射类型？

// 映射类型基于旧类型创建新类型 // 类似于数组的 map 方法，但是用于类型 // 基本语法 type Mapped = { [K in keyof T]: T[K]; }; // 简单示例 interface Person { name: string; age: number; } // 创建一个与 Person 完全相同的类型 type Copy = Mapped; // { name: string; age: number; } // 将所有属性变为可选 type Optional = { [K in keyof T]?: T[K]; }; type OptionalPerson = Optional; // { name?: string; age?: number; } // 将所有属性变为只读 type Readonly = { readonly [K in keyof T]: T[K]; }; type ReadonlyPerson = Readonly; // { readonly name: string; readonly age: number; }
💡
映射类型核心

映射类型使用 [K in keyof T] 语法遍历类型的所有键，可以修改属性的类型、可选性或只读性。

🔧 属性类型转换

// 将所有属性变为字符串 type Stringify = { [K in keyof T]: string; }; interface Product { id: number; name: string; price: number; inStock: boolean; } type StringProduct = Stringify; // { id: string; name: string; price: string; inStock: string; } // 将所有属性包装为 Promise type Promisify = { [K in keyof T]: Promise; }; type AsyncProduct = Promisify; // { id: Promise; name: Promise; ... } // 将所有属性变为数组 type Arrayify = { [K in keyof T]: T[K][]; }; type ArrayProduct = Arrayify; // { id: number[]; name: string[]; ... }

🔀 获取键和值类型

interface User { id: number; name: string; email: string; role: 'admin' | 'user'; } // 获取所有键的类型 type UserKeys = keyof User; // 'id' | 'name' | 'email' | 'role' // 获取所有值的类型的联合 type UserValues = User[keyof User]; // number | string | 'admin' | 'user' // 创建键值对类型 type KeyValuePairs = { [K in keyof T]: { key: K; value: T[K] }; }; type UserPairs = KeyValuePairs; // { // id: { key: 'id'; value: number }; // name: { key: 'name'; value: string }; // ... // } // 创建 getter 函数类型 type Getters = { [K in keyof T as `get${Capitalize}`]: () => T[K]; }; type UserGetters = Getters; // { getId: () => number; getName: () => string; ... }

📝 本节小结

✅
  • • 映射类型使用 [K in keyof T] 遍历键
  • • 可以修改属性的修饰符和类型
  • • keyof 获取类型所有键的联合
  • • T[K] 获取键对应的值类型
