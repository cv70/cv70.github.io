35.4 模板变量传递

学习向模板传递数据的各种方式

🎯 学习目标

  • 掌握 res.render() 传递变量
  • 理解 app.locals 和 res.locals
  • 学会传递复杂数据结构
  • 理解变量作用域和优先级

📤 res.render() 直接传递

// 基本传递 app.get('/', (req, res) => { res.render('index', { title: 'Home Page', message: 'Welcome!' }); }); // 传递复杂数据 app.get('/user/:id', async (req, res) => { const user = await User.findById(req.params.id); const posts = await Post.findByUserId(req.params.id); res.render('user/profile', { title: `${user.name}'s Profile`, user, posts, isOwner: req.user?.id === user.id }); }); // 嵌套数据 app.get('/dashboard', async (req, res) => { res.render('dashboard', { user: { name: 'Alice', email: 'alice@example.com', stats: { posts: 10, followers: 100 } } }); });

🌐 app.locals 全局变量

// 设置全局变量（应用级别） app.locals.siteName = 'My Website'; app.locals.version = '1.0.0'; app.locals.env = process.env.NODE_ENV; // 辅助函数 app.locals.formatDate = (date) => { return new Date(date).toLocaleDateString('zh-CN'); }; app.locals.truncate = (str, length) => { return str.length > length ? str.slice(0, length) + '...' : str; }; // 所有模板都可以访问 // <%= siteName %> // <%= formatDate(post.createdAt) %>
💡
适用场景

app.locals 适合设置全站共享的数据，如网站名称、版本号、辅助函数等。

📦 res.locals 请求级变量

// 中间件设置请求级变量 app.use((req, res, next) => { // 当前用户 res.locals.user = req.user; // 当前路径 res.locals.currentPath = req.path; // 当前时间 res.locals.now = new Date(); // Flash 消息 res.locals.message = req.flash('message'); next(); }); // 认证中间件 app.use((req, res, next) => { res.locals.isAuthenticated = !!req.user; res.locals.isAdmin = req.user?.role === 'admin'; next(); }); // 使用 app.get('/profile', (req, res) => { res.render('profile', { title: 'My Profile' // 模板可访问: user, currentPath, isAuthenticated, isAdmin }); });

📊 变量优先级

当同名变量存在于多个地方时，优先级如下：

优先级 来源 说明
1（最高） res.render() 传入 渲染时传递的变量
2 res.locals 请求级变量
3（最低） app.locals 应用级变量
// 优先级示例 app.locals.title = 'Site Name'; // 全局 title app.use((req, res, next) => { res.locals.title = 'Page Name'; // 请求级 title next(); }); app.get('/special', (req, res) => { res.render('page', { title: 'Special Page' // 渲染时传递 - 最高优先级 }); // 模板中 title = 'Special Page' });

// 注册模板辅助函数 app.locals.helpers = { // 日期格式化 formatDate: (date, format = 'YYYY-MM-DD') => { // 格式化逻辑 return formatted; }, // 字符串截断 truncate: (str, length = 100) => { if (!str) return ''; return str.length > length ? str.slice(0, length) + '...' : str; }, // 条件类名 classIf: (condition, className) => { return condition ? className : ''; }, // 安全 HTML safe: (html) => { // 返回原始 HTML（不转义） return html; }, // 调试 debug: (obj) => { return JSON.stringify(obj, null, 2); } }; // 模板中使用 /* <%= helpers.formatDate(post.createdAt) %> <%= helpers.truncate(post.content, 200) %>

✅ 小结

📌
本节要点
  • res.render() 直接传递变量，优先级最高
  • app.locals 设置全局变量
  • res.locals 设置请求级变量
  • 可以传递对象、数组、函数等复杂数据
