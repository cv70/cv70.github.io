32.4 OCR文字识别

从图像中提取文字信息

🎯 学习目标

  • 理解OCR技术的基本原理与发展历程
  • 掌握文字检测与识别的核心方法
  • 了解场景文本识别的难点与解决方案
  • 学会使用开源OCR工具进行开发

什么是OCR

OCR（Optical Character Recognition，光学字符识别）是指将图像中的文字转换为可编辑文本的技术。OCR技术广泛应用于文档数字化、票据处理、车牌识别、身份证读取等场景，是连接图像世界与文本世界的桥梁。

🔄 OCR技术流程

文字检测

输入图像 ↓ 特征提取 ↓ 文字区域定位 ↓ 文字实例分割 检测框 + 掩码

文字识别

裁剪文字区域 ↓ 特征编码 ↓ 序列解码 ↓ 后处理校正 识别文本

⚖️ OCR模型架构对比

模块 方法 特点 适用场景
文字检测 CTPN 检测水平文本 文档扫描
文字检测 EAST 多方向文本检测 场景文本
文字检测 DBNet 可微分二值化，速度快 实时检测
文字识别 CRNN CNN+RNN+CTC 通用识别
文字识别 SAR 基于注意力的解码 不规则文本
端到端 PaddleOCR 检测+识别一体化 工业部署

💻 代码示例：使用PaddleOCR进行文字识别

from paddleocr import PaddleOCR
import cv2

# 初始化OCR引擎（支持中英文）
ocr = PaddleOCR(use_angle_cls=True, lang='ch')

# 识别图像中的文字
img_path = 'document.jpg'
result = ocr.ocr(img_path, cls=True)

# 解析识别结果
for idx in range(len(result)):
    res = result[idx]
    for line in res:
        # 文字位置坐标
        box = line[0]
        # 识别文本和置信度
        text = line[1][0]
        confidence = line[1][1]

        print(f"文本: {text}")
        print(f"置信度: {confidence:.4f}")
        print(f"位置: {box}")
        print("---")

# 可视化结果
from paddleocr import draw_ocr
result = result[0]
image = cv2.imread(img_path)
boxes = [line[0] for line in result]
texts = [line[1][0] for line in result]
scores = [line[1][1] for line in result]
im_show = draw_ocr(image, boxes, texts, scores)

💡
中文OCR挑战

中文OCR相比英文更具挑战性：字符数量大（常用字3000+，总数超10万）、字形复杂（形近字多）、多字体变体、排版多样（竖排、横排混排）。解决方案包括数据增强、合成数据训练、字典约束等。
