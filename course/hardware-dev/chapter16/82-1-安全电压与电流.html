安全电压与电流

安全电压与电流是"电气安全基础"这一章中的第1节内容。 在电子产品设计中，安全是首要考虑因素。本节将系统介绍安全电压与电流的标准规范， 帮助你理解电击防护的基本原理。

💡 安全电压与电流全景解析

🎓

Why - 为什么重要

确保产品使用安全，防止电击事故，符合安规认证要求

🚀

What - 核心内容

掌握安全电压分类、安全限值、人体阻抗等关键概念

🏗️

How - 如何落地

在设计阶段进行安全评估，确保符合相关标准要求

⚡ 安全电压分类

根据IEC 60950和GB/T 3805标准，安全电压分为以下几类：

电压等级 电压范围 适用环境 特点
特低电压(ELV) ≤ 42V AC / ≤ 60V DC 一般室内环境 无需特殊防护
安全特低电压(SELV) ≤ 50V AC / ≤ 120V DC 所有环境 双重隔离或加强绝缘
保护特低电压(PELV) ≤ 50V AC / ≤ 120V DC 需要接地保护 与地相连
功能特低电压(FELV) ≤ 50V AC / ≤ 120V DC 功能用途 不完全满足安全要求

常用安全电压值

  • 42V AC：工频特低电压限值
  • 24V DC：常用直流安全电压
  • 12V DC：低功耗设备安全电压
  • 5V DC：USB等低压接口

🔋 安全电流限值

人体对不同频率和类型电流的反应不同，以下是安全电流参考值：

电流类型 电流范围 人体反应 危险性
直流电(DC) ≤ 2mA 几乎无感觉 安全
直流电(DC) 2-50mA 轻微电击感 轻微危险
交流电(AC 50Hz) ≤ 0.5mA 几乎无感觉 安全
交流电(AC 50Hz) 0.5-10mA 轻度电击，可自行摆脱 轻微危险
交流电(AC 50Hz) 10-30mA 肌肉痉挛，难以摆脱 中等危险
交流电(AC 50Hz) > 30mA 呼吸麻痹，危及生命 高度危险
⚠️
重要提示

30mA是人体安全电流的关键阈值，超过此值可能导致心室颤动。 在设计中应确保漏电流不超过0.75mA（手持设备）或3.5mA（其他设备）。

👤 人体阻抗特性

人体阻抗受多种因素影响，是评估电击危险的重要参数：

  • 皮肤阻抗：与接触面积、湿度、压力相关，通常10kΩ-1MΩ
  • 体内阻抗：相对稳定，约500Ω-800Ω
  • 接触电压：电压越高，皮肤阻抗越低
  • 频率影响：高频下皮肤阻抗显著降低

典型接触阻抗

接触条件 人体阻抗 备注
干燥皮肤 100kΩ - 1MΩ 接触干燥、完整皮肤
潮湿皮肤 1kΩ - 10kΩ 汗湿或水浸环境
破损皮肤 100Ω - 1kΩ 皮肤破损或伤口
大面积接触 500Ω - 5kΩ 大面积金属接触

⚙️ 不同环境的安全要求

不同使用环境对安全电压的要求不同：

环境类型 安全电压限值 特殊要求
一般干燥环境 ≤ 42V AC / ≤ 60V DC 基本绝缘即可
潮湿环境 ≤ 24V AC / ≤ 36V DC 需要加强防护
金属容器内 ≤ 12V AC / ≤ 24V DC 双重绝缘或隔离供电
人体频繁接触 ≤ 24V AC / ≤ 36V DC 防触电保护
医疗设备 ≤ 12V DC (部分) 严格隔离限制

🔌 接地与保护措施

保护接地

  • I类设备：金属外壳必须接地，漏电时跳闸保护
  • II类设备：双重绝缘，无需接地
  • III类设备：采用安全特低电压供电

漏电保护

  • 家用设备：30mA漏电保护器
  • 医疗设备：10mA或更低
  • 特殊场合：6mA高灵敏度保护
✨
最佳实践

在进行产品安全设计时： 1）优先采用低电压设计，减少安全风险； 2）对高电压部分进行可靠隔离和防护； 3）确保金属外壳的有效接地； 4）在关键位置设置漏电保护装置； 5）严格测试漏电流是否符合标准要求。
