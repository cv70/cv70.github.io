模块的概念

模块（Module）是Verilog的基本设计单元，类似于C语言中的函数。一个模块可以是一个简单的逻辑门，也可以是一个复杂的处理器。模块支持层次化设计，大模块可以包含多个小模块。

📋 模块基本结构

模块定义语法

module 模块名 (
    input  [位宽-1:0] 输入端口名,
    output [位宽-1:0] 输出端口名,
    inout  [位宽-1:0] 双向端口名
);
    // 内部信号声明
    wire [7:0] data_bus;
    reg  [7:0] counter;

    // 模块功能实现
    // ...

endmodule

🔌 端口类型

端口类型关键字说明典型应用
输入端口input数据流入模块时钟、复位、数据输入
输出端口output数据流出模块结果输出、状态信号
双向端口inout双向数据传输总线接口、IO引脚
⚠️
端口声明注意事项

• input端口默认为wire类型，不能声明为reg
• output端口可以是wire或reg类型
• inout端口通常为wire类型，需要三态控制

🔧 模块实例化

实例化方式

// 方式1：按名称连接（推荐）
and_gate u_and (
    .a(in1),      // 端口名(连接信号)
    .b(in2),
    .y(out1)
);

// 方式2：按位置连接
and_gate u_and2 (in1, in2, out1); // 不推荐
💡
实例化最佳实践

推荐使用按名称连接的方式，优点：
• 代码可读性更好
• 端口顺序不影响连接
• 易于维护和修改
• 未连接端口容易发现

📊 简单模块示例

D触发器模块

module d_flip_flop (
    input  wire clk,
    input  wire rst_n,
    input  wire d,
    output reg  q
);

always @(posedge clk or negedge rst_n) begin
    if (!rst_n)
        q <= 1'b0;
    else
        q <= d;
end

endmodule
