UART协议概述

UART（Universal Asynchronous Receiver/Transmitter）即通用异步收发传输器，是嵌入式系统中最基础、最常用的串行通信接口之一。 UART采用异步通信方式，不需要时钟线同步，仅需TX（发送）和RX（接收）两根信号线即可实现全双工通信。

⚙️ UART帧结构

位 名称 电平 说明
起始位 Start Bit 低电平(0) 标志一帧数据的开始，唤醒接收方
数据位 Data Bits 高/低 通常5~9位，最常用8位，低位先发
校验位 Parity Bit 高/低 奇校验/偶校验/无校验，用于错误检测
停止位 Stop Bit 高电平(1) 标志一帧结束，可配置1位、1.5位、2位

📊 常用波特率配置

波特率 位时间 应用场景 误差要求
9600 104.17μs 低速设备、传统设备 ±2%
115200 8.68μs 调试输出、高速通信 ±2%
921600 1.09μs 高速数据传输 ±1%
1000000 1μs 固件下载、高速调试 ±1%
✨
最佳实践

波特率误差计算公式：误差 = |(实际波特率 - 目标波特率) / 目标波特率| × 100%。 当系统时钟无法整除产生精确波特率时，需选择误差最小的配置，一般要求误差小于2%。

⚠️
注意事项

UART空闲状态时TX和RX都保持高电平。若看到低电平，说明可能有数据正在传输或线路故障。 设计时应加上拉电阻确保空闲状态稳定。

📝 本节小结

✅
  • • UART是异步串行通信，仅需TX/RX两根线即可实现全双工通信
  • • 帧结构包含：起始位(1位) + 数据位(通常8位) + 校验位(可选) + 停止位(1~2位)
  • • 波特率决定了数据传输速率，双方必须配置一致
  • • 空闲状态为高电平，起始位为低电平触发接收
