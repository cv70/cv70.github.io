做市策略基础

做市策略（Market Making）是指交易者同时提供买入和卖出报价，通过买卖价差（Bid-Ask Spread）获利的策略。做市商为市场提供流动性，同时承担存货风险。

💡 做市商的角色与职能

💧

平滑价格波动，维护市场稳定

📊 做市策略盈利原理

买卖价差收益

# 做市策略基本逻辑
def market_making_strategy(market_data, spread=0.01):
    """
    做市策略
    - 买价 = 中间价 - spread/2
    - 卖价 = 中间价 + spread/2
    - 利润 = 买价和卖价之间的价差
    """
    mid_price = (market_data['bid'] + market_data['ask']) / 2

    bid_price = mid_price - spread / 2
    ask_price = mid_price + spread / 2

    # 挂买单和卖单
    place_limit_order(side='buy', price=bid_price)
    place_limit_order(side='sell', price=ask_price)

    return {
        'bid': bid_price,
        'ask': ask_price,
        'spread': spread
    }

# 收益来源：
# 1. 买卖价差（主要）
# 2. 交易所返佣
# 3. 逆势交易机会（次要）

做市策略的风险

做市商主要面临存货风险：当市场单边走势时，做市商会积累单边仓位，面临价格不利变动的风险。需要通过风险对冲和动态调整来管理这些风险。

🔧 做市策略关键要素

要素 作用 优化方向
报价价差 决定每笔交易利润 根据波动率动态调整
挂单深度 决定成交概率 平衡成交与风险
仓位管理 控制存货风险 动态调整净头寸
风险对冲 降低价格风险 使用衍生品对冲
风险限额 控制最大亏损 设置止损和限额

📈 经典做市策略

1. 固定价差做市

最简单的做市策略，使用固定的买卖价差。实现简单但风险较高，无法适应市场变化。

2. 动态价差做市

根据市场波动率动态调整价差。高波动时扩大价差，低波动时收窄价差，平衡风险和收益。

3. 库存风险管理

# 库存风险管理的做市报价
def inventory_aware_making(mid_price, inventory, risk_aversion=0.1):
    """
    基于库存管理的做市报价
    - 持有过多多头：提高卖价，降低买价
    - 持有过多空头：降低卖价，提高买价
    """
    # 根据库存调整报价
    price_adjustment = -risk_aversion * inventory

    adjusted_bid = mid_price + price_adjustment - spread/2
    adjusted_ask = mid_price + price_adjustment + spread/2

    return adjusted_bid, adjusted_ask
⚠️
做市策略的风险与挑战

1. 存货风险：单边市场导致亏损
2. 信息不对称：知情交易者选择性交易
3. 技术要求高：需要低延迟系统
4. 资金需求大：需要充足保证金
5. 监管要求：需获得做市商资格
