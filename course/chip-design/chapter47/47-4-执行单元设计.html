执行单元概述

执行单元（Execution Unit, EXU）是处理器的核心计算单元，负责执行算术、 逻辑运算和分支条件判断。EXU包含ALU、移位器、比较器等关键组件，是决定处理器性能的关键部分。

🧩 EXU基本架构

主要组件

运算组件

  • ALU - 算术逻辑单元
  • 移位器 - 左/右移位
  • 乘法器 - 整数乘法
  • 除法器 - 整数除法

控制组件

  • 比较器 - 分支条件判断
  • 前递单元 - 数据前递
  • 旁路网络 - 解决数据冒险

📊 ALU设计

ALU操作类型

操作 描述 funct3
ADD/SUB 加法/减法 000
AND 按位与 111
OR 按位或 110
XOR 按位异或 100
SLL 逻辑左移 001
SRL/SRA 逻辑/算术右移 101
SLT/SLTU 小于比较（有/无符号） 010/011

💻 ALU实现

ALU模块代码

module alu ( input wire [3:0] alu_op, input wire [31:0] src1, input wire [31:0] src2, output reg [31:0] result ); always @(*) begin case (alu_op) `ALU_ADD: result = src1 + src2; `ALU_SUB: result = src1 - src2; `ALU_AND: result = src1 & src2; `ALU_OR: result = src1 | src2; `ALU_XOR: result = src1 ^ src2; `ALU_SLL: result = src1 << src2[4:0]; `ALU_SRL: result = src1 >> src2[4:0]; `ALU_SRA: result = $signed(src1) >>> src2[4:0]; `ALU_SLT: result = ($signed(src1) < $signed(src2)) ? 1 : 0; `ALU_SLTU: result = (src1 < src2) ? 1 : 0; default: result = 32'b0; endcase end endmodule

🔀 分支条件计算

分支判断逻辑

// 分支条件信号 wire take_branch; // 根据funct3判断分支类型 always @(*) begin case (funct3) 3'b000: take_branch = (src1 == src2); // BEQ 3'b001: take_branch = (src1 != src2); // BNE 3'b100: take_branch = ($signed(src1) < $signed(src2)); // BLT 3'b101: take_branch = ($signed(src1) >= $signed(src2)); // BGE 3'b110: take_branch = (src1 < src2); // BLTU 3'b111: take_branch = (src1 >= src2); // BGEU default: take_branch = 1'b0; endcase end // 分支目标地址计算 wire [31:0] branch_target = pc + imm_b;

⚠️ 数据前递

解决数据冒险

  • EX前递 - 从EX阶段结果前递
  • MEM前递 - 从MEM阶段结果前递
  • WB前递 - 从WB阶段结果前递
  • 检测逻辑 - 比较目的寄存器和源寄存器
💡
前递检测示例

EX冒险检测： if (EX_MEM_reg_write && EX_MEM_rd != 0 && EX_MEM_rd == ID_EX_rs1)
MEM冒险检测： if (MEM_WB_reg_write && MEM_WB_rd != 0 && MEM_WB_rd == ID_EX_rs1)

⏱️ 多周期操作

乘除法处理

  • 乘法通常需要3-5个周期
  • 除法需要更多周期（取决于实现）
  • 需要流水线停顿或独立单元
  • 可以考虑使用乘法器阵列加速

📈 性能优化

EXU优化策略

  • 并行计算 - 同时计算多个条件
  • 快速加法器 - 使用Carry Lookahead
  • 桶形移位器 - 快速移位操作
  • 前递优化 - 减少停顿周期
