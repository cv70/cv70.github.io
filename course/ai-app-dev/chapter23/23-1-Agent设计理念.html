💡 什么是AI Agent

定义

AI Agent是一个能够感知环境、做出决策并采取行动以实现目标的自主系统。在LLM语境下，Agent使用LLM作为"大脑"来推理和决策。

🧠

感知

理解输入和上下文

🤔

推理

规划和决策

🎬

行动

调用工具执行

🔄 Agent工作循环

1
接收任务
2
分析规划
3
选择工具
4
执行操作
5
评估结果
# Agent伪代码 def agent_loop(user_input): while not task_complete: # 1. 思考：分析当前状态 thought = llm.think(user_input, history) # 2. 决策：选择行动 action = llm.decide(thought, available_tools) # 3. 执行：调用工具 if action.type == "tool_call": result = execute_tool(action.tool, action.args) # 4. 观察：获取结果 observation = observe(result) # 5. 更新历史 history.append(thought, action, observation) return final_answer

🔧 核心组件

组件 作用 示例
LLM 推理和决策引擎 GPT-4, Claude
Tools 扩展Agent能力 搜索、计算、API调用
Memory 存储对话和状态 对话历史、知识库
Planner 任务分解和规划 ReAct, Plan-and-Solve
⚠️
Agent设计注意事项
  • Agent可能陷入死循环，需要设置最大迭代次数
  • 工具调用需要错误处理和重试机制
  • 复杂任务可能需要多Agent协作
  • Agent行为需要可观测和可控制
