46.2 RISC-V基础指令集RV32I

RV32I概述

RV32I是RISC-V的基础整数指令集，包含47条指令。它是最小的、完整的RISC-V实现， 所有RISC-V处理器都必须支持RV32I。RV32I支持32位地址和数据宽度。

RV32I的设计目标是最小化硬件实现复杂度，同时提供足够的编程能力。

📊 通用寄存器组

💡
32个通用寄存器（x0-x31）

RISC-V有32个通用寄存器，每个32位宽。其中x0是硬编码为0的特殊寄存器，其他31个寄存器可自由使用。

寄存器 ABI名称 描述 保存者
x0 zero 硬编码为0 -
x1 ra 返回地址 调用者
x2 sp 栈指针 被调用者
x3 gp 全局指针 -
x4 tp 线程指针 -
x5-x7 t0-t2 临时寄存器 调用者
x8 s0/fp 保存寄存器/帧指针 被调用者
x9 s1 保存寄存器 被调用者
x10-x11 a0-a1 函数参数/返回值 调用者
x12-x17 a2-a7 函数参数 调用者
x18-x27 s2-s11 保存寄存器 被调用者
x28-x31 t3-t6 临时寄存器 调用者

🧩 指令格式

R型（寄存器型）

[31:25] func7 [24:20] rs2 [19:15] rs1 [14:12] funct3 [11:7] rd [6:0] opcode

用于寄存器-寄存器操作，如ADD、SUB、AND、OR

I型（立即数型）

[31:20] imm[11:0] [19:15] rs1 [14:12] funct3 [11:7] rd [6:0] opcode

用于立即数操作和加载指令，如ADDI、LW

S型（存储型）

[31:25] imm[11:5] [24:20] rs2 [19:15] rs1 [14:12] funct3 [11:7] imm[4:0] [6:0] opcode

用于存储指令，如SW、SH、SB

B型（分支型）

[31] imm[12] [30:25] imm[10:5] [24:20] rs2 [19:15] rs1 [14:12] funct3 [11:8] imm[4:1] [7] imm[11] [6:0] opcode

用于条件分支指令，如BEQ、BNE、BLT

U型（上位立即数型）

[31:12] imm[31:12] [11:7] rd [6:0] opcode

用于生成大立即数，如LUI、AUIPC

J型（跳转型）

[31] imm[20] [30:21] imm[10:1] [20:19] imm[11] [19:12] imm[19:12] [11:7] rd [6:0] opcode

用于无条件跳转，如JAL、JALR

📚 核心指令类型

算术运算

  • ADD, SUB
  • AND, OR, XOR
  • SLL, SRL, SRA
  • SLT, SLTU

访存指令

  • LB, LH, LW, LBU, LHU
  • SB, SH, SW
  • 支持字节、半字、字访问

控制流

  • BEQ, BNE, BLT, BGE, BLTU, BGEU
  • JAL, JALR
  • AUIPC, LUI
✅
RV32I的设计优势
  • • 指令长度固定为32位，简化译码
  • • 只有6种指令格式，易于硬件实现
  • • 基于寄存器，减少访存开销
  • • 延迟槽设计，简化流水线

💻 指令示例

示例：计算数组元素和

# 计算 a0 = a0 + a1 + ... + a7 # a0-a7: 输入数组 # t0: 循环计数器 # t1: 累加和 li t0, 8 # 循环次数 = 8 li t1, 0 # 初始化和为0 li a0, array # 加载数组基址 loop: lw t2, 0(a0) # 加载array[i] add t1, t1, t2 # 累加 addi a0, a0, 4 # 指针+4 addi t0, t0, -1 # 计数器-1 bnez t0, loop # 继续循环 mv a0, t1 # 返回结果
