99.2 Docker 安装

在不同操作系统上安装和配置 Docker 环境

🎯 学习目标

  • 掌握 Docker 在各平台的安装方法
  • 了解 Docker 的核心组件
  • 学会配置 Docker 镜像加速
  • 掌握 Docker 基本命令验证安装

Docker 简介

Docker 是一个开源的应用容器引擎，让开发者可以打包应用及其依赖包到一个可移植的容器中，然后发布到任何流行的 Linux 或 Windows 操作系统上。

🪟 Windows 安装 Docker

系统要求

  • Windows 10/11 64位（专业版、企业版或教育版）
  • 启用 WSL 2（Windows Subsystem for Linux）
  • 启用 Hyper-V 和容器功能
  • BIOS 中启用虚拟化

安装步骤

# 1. 启用 WSL2 wsl --install wsl --set-default-version 2 # 2. 下载 Docker Desktop for Windows # 访问 https://www.docker.com/products/docker-desktop # 3. 运行安装程序，按提示完成安装 # 4. 重启电脑后启动 Docker Desktop

🍎 macOS 安装 Docker

系统要求

  • macOS 11 (Big Sur) 或更高版本
  • Intel 芯片或 Apple Silicon (M1/M2/M3)
  • 至少 4GB RAM

安装步骤

# 方法1: 官网下载 Docker Desktop # https://www.docker.com/products/docker-desktop # 方法2: 使用 Homebrew 安装 brew install --cask docker # 安装完成后启动 Docker 应用

🐧 Linux 安装 Docker

Ubuntu/Debian 安装

# 1. 更新软件包索引 sudo apt-get update # 2. 安装依赖 sudo apt-get install \ apt-transport-https \ ca-certificates \ curl \ gnupg \ lsb-release # 3. 添加 Docker 官方 GPG 密钥 curl -fsSL https://download.docker.com/linux/ubuntu/gpg | \ sudo gpg --dearmor -o /usr/share/keyrings/docker-archive-keyring.gpg # 4. 设置稳定版仓库 echo \ "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/docker-archive-keyring.gpg] \ https://download.docker.com/linux/ubuntu \ $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null # 5. 安装 Docker Engine sudo apt-get update sudo apt-get install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin # 6. 验证安装 sudo docker run hello-world

CentOS/RHEL 安装

# 1. 安装必要工具 sudo yum install -y yum-utils # 2. 添加 Docker 仓库 sudo yum-config-manager --add-repo \ https://download.docker.com/linux/centos/docker-ce.repo # 3. 安装 Docker sudo yum install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin # 4. 启动 Docker 服务 sudo systemctl start docker sudo systemctl enable docker

⚡ 配置镜像加速

国内用户建议配置镜像加速器，提高镜像下载速度。

# Linux: 编辑 /etc/docker/daemon.json # Windows/macOS: Docker Desktop 设置中配置 { "registry-mirrors": [ "https://mirror.ccs.tencentyun.com", "https://docker.mirrors.ustc.edu.cn", "https://hub-mirror.c.163.com" ] } # 重启 Docker 服务 (Linux) sudo systemctl daemon-reload sudo systemctl restart docker

🔧 Docker 核心组件

Docker Engine

Docker 的核心运行时引擎，负责构建、运行和分发容器。

  • dockerd - 守护进程
  • docker CLI - 命令行工具
  • containerd - 容器运行时

Docker Desktop

面向开发者的桌面应用，集成 Docker Engine、CLI 等工具。

  • 图形化管理界面
  • 内置 Kubernetes
  • 资源监控工具

✅ 验证安装

# 查看 Docker 版本 docker --version docker version # 查看 Docker 系统信息 docker info # 运行测试容器 docker run hello-world # 查看 Docker Compose 版本 docker compose version
💡
将用户添加到 docker 组（Linux）

避免每次使用 docker 命令都需要 sudo：

sudo usermod -aG docker $USER
newgrp docker
