6.5 线性区、饱和区与截止区

三个工作区域特性

🎯 学习目标

  • 掌握 MOSFET 三个工作区域的划分条件
  • 理解各工作区域的电流-电压关系
  • 认识不同工作区域的应用场景
  • 理解工作区域转换的物理机制

工作区域概述

MOSFET 根据栅源电压 VGS 和漏源电压 VDS 的不同，工作在三个不同的区域：截止区、线性区（三极管区）和饱和区。每个区域具有独特的电流-电压特性和应用场景。

🔴 截止区（Cutoff Region）

工作条件

VGS < Vth

栅源电压低于阈值电压，无法形成导电沟道

物理状态

  • 栅极下方无导电沟道形成
  • 源-漏之间被衬底隔离
  • 源-衬底和漏-衬底 PN 结反偏
  • 器件处于"关断"状态

电流特性

ID ≈ 0

理想情况下漏极电流为零。实际存在以下漏电流：

  • 亚阈值漏电：弱反型下的扩散电流
  • PN 结漏电：源/漏-衬底结的反向漏电
  • 栅漏电：通过薄栅氧化层的隧穿电流

应用场景

截止区对应数字电路的逻辑"关"状态。在 CMOS 逻辑门中，截止的 MOSFET 提供高阻抗，阻断电流通路。

🟡 线性区（Linear/Triode Region）

工作条件

VGS > Vth 且 VDS < (VGS - Vth)

其中 VOV = VGS - Vth 称为过驱动电压（Overdrive Voltage）

物理状态

  • 栅极下方形成均匀的导电沟道
  • 沟道未被夹断，从源到漏连续
  • 沟道类似一个可变电阻
  • 器件处于"导通"低阻状态

电流方程

📐

ID = μnCox(W/L)[(VGS-Vth)VDS - VDS²/2]

当 VDS << VOV 时，可简化为：

ID ≈ μnCox(W/L)(VGS-Vth)·VDS

此时 ID 与 VDS 成线性关系

导通电阻（Ron）

在线性区，MOSFET 可视为一个电阻：

Ron = VDS/ID = 1/[μnCox(W/L)(VGS-Vth)]

影响 Ron 的因素：

  • W/L 越大，Ron 越小
  • VGS 越大，Ron 越小
  • Ron 决定开关速度和导通损耗

应用场景

线性区主要应用于：

  • 开关应用：作为传输门、开关管
  • 电阻替代：工作在线性区的 MOSFET 可作为可调电阻
  • 数字逻辑导通态：CMOS 门电路导通时工作在此区

🟢 饱和区（Saturation Region）

工作条件

VGS > Vth 且 VDS ≥ (VGS - Vth)

漏源电压足够大，使沟道在漏端夹断

物理状态 - 沟道夹断

当 VDS 增加到 VOV 时，漏端的有效栅压降为零：

VGS - Vth - VDS = 0 时，漏端沟道夹断

继续增加 VDS：

  • 夹断点向源端移动
  • 电子在夹断区被强电场扫向漏极
  • 电流基本恒定，与 VDS 无关
  • 器件表现为恒流源特性

电流方程

📐

理想饱和电流（不考虑沟道长度调制）：

ID = ½·μnCox(W/L)(VGS-Vth)²

考虑沟道长度调制：

ID = ½·μnCox(W/L)(VGS-Vth)²(1+λVDS)

其中 λ 是沟道长度调制系数

输出电阻（ro）

饱和区的输出电阻：

ro = ∂VDS/∂ID = 1/(λID) ≈ VA/ID

其中 VA = 1/λ 是厄利电压（Early Voltage）

  • ro 越大，恒流特性越好
  • 长沟道器件的 ro 更大
  • 对模拟电路增益有重要影响

应用场景

饱和区是模拟电路的核心工作区：

  • 放大器：利用 gm 实现电压增益
  • 电流源/电流镜：利用恒流特性
  • 模拟开关：需要高输出阻抗的场合

📊 三个工作区域对比

特性 截止区 线性区 饱和区
VGS 条件 VGS < Vth VGS > Vth VGS > Vth
VDS 条件 任意 VDS < VOV VDS ≥ VOV
沟道状态 无沟道 均匀沟道 漏端夹断
电流特性 ID ≈ 0 ID ∝ VDS ID ≈ 恒定
等效特性 开路 电阻 电流源
主要应用 数字逻辑"关" 开关、传输门 放大、电流源
⚠️
工作区域的边界

VDS = VGS - Vth 是线性区与饱和区的边界，称为夹断电压或饱和电压（VDsat）。

在实际电路中，器件可能在不同工作区域之间切换：

  • 数字电路：截止区 ↔ 线性区（开关工作）
  • 模拟电路：工作点设在线性区或饱和区
  • 开关电路：可能经过所有三个区域

📝 本节小结

✅
  • • 截止区：VGS < Vth，无导电沟道，ID ≈ 0
  • • 线性区：VDS < VOV，沟道均匀，ID ∝ VDS，等效电阻
  • • 饱和区：VDS ≥ VOV，沟道夹断，ID 恒定，等效电流源
  • • 导通电阻 Ron 和输出电阻 ro 是关键参数
  • • 不同工作区域适用于不同应用场景
