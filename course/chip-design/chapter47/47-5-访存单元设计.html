访存单元概述

访存单元（Load Store Unit, LSU）负责处理所有内存访问指令， 包括加载（Load）和存储（Store）操作。LSU需要处理数据Cache、地址对齐、 内存屏障等复杂情况，是处理器与内存系统交互的关键接口。

📊 Load/Store指令

指令 操作 数据宽度 对齐要求
LB/LH/LW 加载（有符号） 8/16/32位 字节/半字/字对齐
LBU/LHU 加载（无符号） 8/16位 字节/半字对齐
SB/SH/SW 存储 8/16/32位 字节/半字/字对齐

💾 数据Cache设计

Cache参数配置

  • 容量 - 32KB/64KB/128KB
  • 块大小 - 64B/128B
  • 关联度 - 4路/8路组相联
  • 写策略 - 写通/写回
  • 分配策略 - 读分配/写分配

🔧 地址对齐处理

对齐检查与处理

// 对齐检查 wire load_misaligned = (funct3 == 3'b000 && addr[0]) || // LB (funct3 == 3'b001 && addr[0]) || // LH (funct3 == 3'b010 && addr[1:0]); // LW wire store_misaligned = (funct3 == 3'b000 && addr[0]) || // SB (funct3 == 3'b001 && addr[0]) || // SH (funct3 == 3'b010 && addr[1:0]); // SW // 对齐异常 wire misaligned_exception = (mem_read && load_misaligned) || (mem_write && store_misaligned);
💡
数据字节选择

对于未对齐访问或小宽度访问，需要从Cache行中选择正确的字节：
• 字节访问：根据addr[1:0]选择字节
• 半字访问：根据addr[1]选择半字
• 符号扩展：有符号加载需要符号扩展

⚡ Load-Store队列

LSQ功能

  • Load队列 - 缓存待执行的Load操作
  • Store队列 - 缓存待执行的Store操作
  • 内存一致性 - 维护内存访问顺序
  • Load-Store冲突检测 - 检测RAW/WAR/WAW冒险

🛡️ 访问权限检查

权限验证

  • 读权限 - PTE.R=1
  • 写权限 - PTE.W=1
  • 用户态访问 - PTE.U=1
  • 异常处理 - 访问违规触发异常
