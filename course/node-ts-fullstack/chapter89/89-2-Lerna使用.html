89.2 Lerna 使用

JavaScript Monorepo 管理工具

🎯 学习目标

  • 理解 Lerna 的核心功能
  • 掌握 Lerna 项目初始化
  • 学会包管理和发布流程
  • 了解 Lerna 与其他工具集成

📚 Lerna 简介

Lerna 是一个用于管理包含多个 npm 包的 JavaScript 项目的工具，特别适合发布到 npm 的包开发。

# 安装 Lerna npm install -g lerna # 或在项目中安装 npm install -D lerna # 初始化项目 mkdir my-lerna-repo cd my-lerna-repo lerna init # 生成的目录结构 my-lerna-repo/ ├── packages/ ├── lerna.json ├── package.json └── .gitignore # lerna.json 配置 { "packages": ["packages/*"], "version": "1.0.0", "npmClient": "npm", "command": { "publish": { "ignoreChanges": ["*.md"], "message": "chore(release): publish" }, "bootstrap": { "npmClientArgs": ["--no-package-lock"] } } }

🔧 包管理命令

# 创建新包 lerna create @myorg/utils # 生成的包结构 packages/utils/ ├── __tests__/ │ └── utils.test.ts ├── src/ │ └── index.ts ├── package.json ├── README.md └── tsconfig.json # 安装依赖 # 安装到所有包 lerna add lodash # 安装到指定包 lerna add axios --scope=@myorg/api # 安装开发依赖 lerna add typescript --dev --scope=@myorg/utils # 安装本地包依赖 lerna add @myorg/utils --scope=@myorg/api # 清理所有 node_modules lerna clean # 引导项目（链接本地包） lerna bootstrap # 执行命令 # 在所有包中执行 lerna run build lerna run test # 在指定包中执行 lerna run build --scope=@myorg/utils # 并行执行 lerna run build --parallel # 查看包信息 lerna list lerna list --long lerna list --json # 查看包之间的依赖关系 lerna graph
💡
包命名规范

建议使用 @scope/package-name 格式命名包，便于区分和组织。scope 通常是组织名或项目名。

⚙️ 版本和发布

# 版本模式 ## 固定模式 (Fixed) 所有包使用同一版本号 lerna.json: "version": "1.0.0" ## 独立模式 (Independent) 每个包独立版本号 lerna.json: "version": "independent" # 版本更新 lerna version # 交互式选择版本 ? Select a new version (currently 1.0.0) (Use arrow keys) Patch (1.0.1) Minor (1.1.0) Major (2.0.0) Prepatch (1.0.1-alpha.0) Preminor (1.1.0-alpha.0) Premajor (2.0.0-alpha.0) Custom Prerelease Custom Version # 常用选项 lerna version patch # 自动升级补丁版本 lerna version minor # 自动升级次版本 lerna version major # 自动升级主版本 lerna version --conventional-commits # 根据提交自动确定版本 # 发布到 npm lerna publish # 发布选项 lerna publish from-git # 从 git tag 发布 lerna publish from-package # 从 package.json 发布 lerna publish --dist-tag next # 发布到 next 标签 # 跳过某个包的发布 # package.json 中添加 { "private": true }

🚀 Lerna + pnpm 集成

# 安装 pnpm npm install -g pnpm # 配置 lerna 使用 pnpm # lerna.json { "packages": ["packages/*"], "version": "1.0.0", "npmClient": "pnpm", "useWorkspaces": true } # pnpm-workspace.yaml packages: - 'packages/*' # 初始化 pnpm install # 添加依赖 pnpm add lodash --filter @myorg/utils pnpm add @myorg/utils --filter @myorg/api # 开发依赖 pnpm add -D typescript --filter @myorg/utils # 根目录开发依赖 pnpm add -Dw typescript # 执行命令 pnpm -r run build pnpm --filter @myorg/utils run build # Lerna 命令仍可用 lerna version lerna publish

  • • lerna version 自动管理版本号
  • • 推荐与 pnpm workspace 配合使用
