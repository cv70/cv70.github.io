14.3 GRU架构

门控循环单元的简化设计

🎯 学习目标

  • 理解GRU的设计思想与简化策略
  • 掌握GRU两个门控的工作机制
  • 能够比较GRU与LSTM的异同
  • 学会在PyTorch中使用GRU

GRU简介

门控循环单元（Gated Recurrent Unit，GRU）由Cho等人在2014年提出， 是LSTM的一种简化变体。GRU将LSTM的三个门控简化为两个（更新门和重置门）， 在保持相近性能的同时减少了参数量，训练效率更高，成为序列建模的常用选择。

🚪 GRU的两个门控

🔄

更新门（Update Gate）

决定当前状态保留多少历史信息，合并了LSTM的遗忘门和输入门功能

🗑️

重置门（Reset Gate）

控制如何将新输入与历史信息结合，决定"遗忘"历史信息的程度

📐 GRU的数学公式

# GRU核心公式（更简洁！） # 1. 重置门：控制历史信息的重要性 r = σ(Wr * [h, x] + br) # 2. 更新门：控制新旧信息的混合比例 z = σ(Wz * [h, x] + bz) # 3. 候选隐藏状态 h̃ = tanh(W * [r * h, x] + b) # 4. 最终隐藏状态 h = (1 - z) * h + z * h̃ # 注意：z接近1时更依赖新信息 # z接近0时更依赖历史信息

💻 PyTorch实现GRU

import torch import torch.nn as nn class GRUModel(nn.Module): def __init__(self, vocab_size, embed_dim, hidden_dim, output_dim): super().__init__() self.embedding = nn.Embedding(vocab_size, embed_dim) self.gru = nn.GRU(embed_dim, hidden_dim, num_layers=2, batch_first=True, dropout=0.3, bidirectional=True) self.fc = nn.Linear(hidden_dim * 2, output_dim) def forward(self, text): # 词嵌入 embedded = self.embedding(text) # GRU前向传播 output, hidden = self.gru(embedded) # 拼接双向最后隐藏状态 hidden = torch.cat((hidden[-2, :, :], hidden[-1, :, :]), dim=1) return self.fc(hidden) # 使用示例 model = GRUModel(vocab_size=10000, embed_dim=128, hidden_dim=256, output_dim=2)

⚖️ GRU vs LSTM 详细对比

特性 LSTM GRU
门控数量 3个（遗忘、输入、输出） 2个（更新、重置）
状态数量 2个（细胞状态、隐藏状态） 1个（隐藏状态）
参数量 4 * hidden_dim * (hidden_dim + input_dim + 1) 3 * hidden_dim * (hidden_dim + input_dim + 1)
计算复杂度 较高 较低
训练速度 较慢 较快
长序列表现 略优 相当
小数据集 可能过拟合 更合适

🔬 选择建议

推荐使用LSTM

  • 超长序列数据
  • 需要精确控制信息流
  • 计算资源充足
  • 任务对精度要求极高

推荐使用GRU

  • 中小规模数据集
  • 需要快速训练迭代
  • 计算资源有限
  • 实时性要求高
💡
实践经验

在很多实际任务中，GRU和LSTM的性能差异很小。建议先用GRU进行快速实验，如果效果不理想再尝试LSTM。双向结构通常能带来显著提升。

📝 本节小结

✅
  • • GRU是LSTM的简化版本，只有两个门控
  • • 更新门控制新旧信息混合比例
  • • 重置门控制历史信息的保留程度
  • • GRU参数少、训练快，适合大多数场景
