12.2 ES Modules

JavaScript 标准模块系统

🎯 学习目标

  • 理解 ES Modules 规范
  • 掌握 export 和 import 语法
  • 学会在 Node.js 中启用 ESM
  • 了解 ESM 与 CommonJS 的区别

📚 启用 ES Modules

// 方式一：在 package.json 中设置 { "type": "module" } // 方式二：使用 .mjs 文件扩展名 // math.mjs // app.mjs // 方式三：命令行参数 // node --experimental-modules app.mjs // 注意：ESM 模块需要使用完整路径（包括扩展名） import { add } from './math.js'; // ✅ 正确 import { add } from './math'; // ❌ 错误（与 CommonJS 不同）

🔧 导出语法

// ========== math.js ========== // 命名导出 export const PI = 3.14159; export function add(a, b) { return a + b; } export function subtract(a, b) { return a - b; } export class Calculator { constructor(initial = 0) { this.value = initial; } } // 导出列表 const multiply = (a, b) => a * b; const divide = (a, b) => a / b; export { multiply, divide }; // 重命名导出 export { multiply as mul, divide as div }; // 默认导出（每个模块只能有一个） export default function log(message) { console.log(`[LOG] ${message}`); } // 或 export default class Logger { log(msg) { console.log(msg); } } // 组合导出 export { PI, add, subtract }; export default Calculator;

📦 导入语法

// ========== app.js ========== // 命名导入 import { add, subtract, PI } from './math.js'; console.log(add(1, 2)); // 3 console.log(PI); // 3.14159 // 重命名导入 import { multiply as mul } from './math.js'; mul(2, 3); // 6 // 导入所有（命名空间导入） import * as math from './math.js'; math.add(1, 2); // 3 math.subtract(5, 3); // 2 math.PI; // 3.14159 // 默认导入 import log from './math.js'; log('Hello'); // 混合导入 import Calculator, { add, subtract } from './math.js'; const calc = new Calculator(100); add(10, 20); // 仅执行模块（不导入值） import './setup.js'; // 动态导入 const moduleName = './math.js'; const math = await import(moduleName); math.add(1, 2);

⚡ ESM vs CommonJS

// CommonJS const math = require('./math'); module.exports = { add, subtract }; // ES Modules import math from './math.js'; export { add, subtract }; // 主要区别： // 1. 语法不同 // 2. ESM 是静态的，import 必须在顶层 // 3. ESM 是异步加载 // 4. ESM this 是 undefined，CommonJS this 指向当前模块 // ESM 中模拟 require import { createRequire } from 'module'; const require = createRequire(import.meta.url); const fs = require('fs'); // CommonJS 中导入 ESM // 必须使用动态 import() const math = await import('./math.mjs');
⚠️
注意

Node.js 中 ESM 是相对较新的功能，部分第三方包可能仍使用 CommonJS。

📝 本节小结

✅
  • • ES Modules 是 JavaScript 标准模块系统
  • • 在 package.json 设置 "type": "module" 启用
  • • export / import 用于导出导入
  • • ESM 需要使用完整文件路径
