什么是TEE

可信执行环境（Trusted Execution Environment，TEE）是处理器中与普通执行环境（如Android、Linux）隔离的安全执行环境。TEE为敏感应用提供了独立、安全的运行空间，确保代码和数据在执行过程中不被篡改和窃取。

TEE是移动支付、数字版权、生物识别等安全应用的基础设施。

🏗️ TEE架构

📊
双系统架构
  • Rich Execution Environment (REE) - 普通执行环境，运行Android、Linux等
  • Trusted Execution Environment (TEE) - 可信执行环境，运行安全应用
  • 硬件隔离 - 通过硬件机制实现隔离
  • 安全通信 - REE和TEE之间的安全通信通道

🔒 TEE安全特性

特性 描述 实现方式
隔离性 TEE与REE完全隔离 内存保护、特权级隔离
完整性 保证代码和数据不被篡改 安全启动、完整性验证
机密性 保护数据不被窃取 内存加密、安全存储
可信根 从硬件建立信任链 硬件可信根、安全启动

📱 主流TEE实现

ARM TrustZone

ARM架构的TEE实现标准：

  • Secure World和Normal World
  • AXI总线地址空间隔离
  • 中断路由控制
  • 广泛用于移动设备

Intel SGX

Intel的软件防护扩展：

  • Enclave飞地
  • 内存加密引擎（MEE）
  • 远程认证
  • 用于PC和服务器

RISC-V PMP

RISC-V的物理内存保护：

  • 可配置的内存访问权限
  • M模式（机器模式）隔离
  • 开源实现
  • 新兴架构

国密TEE

中国的TEE标准实现：

  • 符合国内安全要求
  • 支持国密算法
  • 自主可控
  • 用于国产设备

⚠️
TEE面临的挑战
  • 侧信道攻击 - 功耗、电磁等侧信道泄露
  • 故障注入 - 电压、时钟故障注入
  • 软件漏洞 - TEE OS和应用的安全漏洞
  • 兼容性 - 不同TEE实现的兼容性问题

🚀 TEE发展趋势

💡
  • 更多硬件支持 - 更多的加密引擎、随机数生成器
  • 更好的隔离 - 更细粒度的内存和资源隔离
  • 标准化 - GlobalPlatform等标准推动互操作性
  • 云TEE - 将TEE扩展到云计算环境

📝 本节小结

✅
  • • TEE提供与普通环境隔离的安全执行环境
  • • 核心特性是隔离性、完整性、机密性
  • • 主流实现包括ARM TrustZone、Intel SGX
  • • 应用于移动支付、生物识别、数字版权
  • • 需要应对侧信道和故障注入等威胁
