📚 插件机制

Vite 插件基于 Rollup 插件接口扩展，同时增加了 Vite 特有的钩子。

// Vite 插件结构 interface VitePlugin { // 插件名称 name: string // 应用条件 apply?: 'build' | 'serve' | ((config, env) => boolean) // Rollup 钩子 options?: (options) => void buildStart?: (options) => void resolveId?: (source, importer) => string | null load?: (id) => string | null transform?: (code, id) => { code, map } | null // Vite 特有钩子 config?: (config, env) => void configResolved?: (config) => void configureServer?: (server) => void transformIndexHtml?: (html) => string handleHotUpdate?: (ctx) => void } // 插件执行顺序 1. Alias 路径解析 2. 用户插件（带 enforce: 'pre'） 3. Vite 核心插件 4. 用户插件（无 enforce） 5. Vite 构建插件 6. 用户插件（带 enforce: 'post'）

🔧 常用官方插件

// vite.config.ts import { defineConfig } from 'vite' import vue from '@vitejs/plugin-vue' import vueJsx from '@vitejs/plugin-vue-jsx' import react from '@vitejs/plugin-react' import legacy from '@vitejs/plugin-legacy' export default defineConfig({ plugins: [ // Vue 3 单文件组件支持 vue({ include: [/\.vue$/, /\.md$/], }), // Vue JSX 支持 vueJsx(), // React 支持 react({ babel: { presets: ['@babel/preset-react'], }, }), // 旧版浏览器支持 legacy({ targets: ['defaults', 'not IE 11'], additionalLegacyPolyfills: ['regenerator-runtime/runtime'], }), ], }) // 安装插件 npm install -D @vitejs/plugin-vue npm install -D @vitejs/plugin-vue-jsx npm install -D @vitejs/plugin-react npm install -D @vitejs/plugin-legacy

⚙️ 社区常用插件

import { defineConfig } from 'vite' import vue from '@vitejs/plugin-vue' import Components from 'unplugin-vue-components/vite' import AutoImport from 'unplugin-auto-import/vite' import { VitePWA } from 'vite-plugin-pwa' import viteCompression from 'vite-plugin-compression' import { visualizer } from 'rollup-plugin-visualizer' export default defineConfig({ plugins: [ vue(), // 自动导入组件 Components({ dirs: ['src/components'], extensions: ['vue'], dts: 'src/components.d.ts', }), // 自动导入 API AutoImport({ imports: ['vue', 'vue-router', 'pinia'], dts: 'src/auto-imports.d.ts', }), // PWA 支持 VitePWA({ registerType: 'autoUpdate', workbox: { globPatterns: ['**/*.{js,css,html,ico,png,svg}'], }, }), // Gzip 压缩 viteCompression({ algorithm: 'gzip', ext: '.gz', }), // 构建分析 visualizer({ open: true, gzipSize: true, }), ], }) // 其他常用插件 // vite-plugin-svg-icons - SVG 图标 // vite-plugin-imagemin - 图片压缩 // vite-plugin-mock - Mock 数据 // vite-plugin-pages - 文件路由
💡
插件推荐

unplugin-vue-components 和 unplugin-auto-import 可以自动导入组件和 API，减少手写 import 语句。

🚀 自定义插件开发

// 自定义插件示例 function myVitePlugin(): Plugin { return { name: 'my-vite-plugin', // 仅在构建时应用 apply: 'build', // 执行顺序 enforce: 'pre', // 修改配置 config(config, env) { return { define: { __DEV__: env.mode === 'development', }, } }, // 配置解析完成 configResolved(resolvedConfig) { console.log('Config resolved:', resolvedConfig.mode) }, // 开发服务器配置 configureServer(server) { server.middlewares.use((req, res, next) => { if (req.url === '/api/hello') { res.end(JSON.stringify({ message: 'Hello from plugin!' })) return } next() }) }, // 转换 HTML transformIndexHtml(html) { return html.replace( /<title>/, `<title>My App - ` ) }, // 转换代码 transform(code, id) { if (id.endsWith('.custom')) { return { code: compileCustom(code), map: null, } } }, // 热更新处理 handleHotUpdate({ file, server }) { if (file.endsWith('.custom')) { server.ws.send({ type: 'custom', event: 'custom-update', data: { file }, }) } }, } } // 使用 export default defineConfig({ plugins: [myVitePlugin()], })
