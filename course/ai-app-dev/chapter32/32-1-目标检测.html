什么是目标检测

目标检测（Object Detection）是计算机视觉的核心任务，目标是识别图像中所有感兴趣的目标，并确定它们的类别和位置（边界框）。目标检测是自动驾驶、安防监控、工业检测等应用的基础技术。

📋 目标检测输出

📦

边界框

定位目标位置
(x, y, w, h)

🏷️

类别标签

识别目标类型
人、车、动物等

📊

置信度

检测确定性
0.0 - 1.0

⚖️ 检测器类型对比

类型 代表模型 速度 精度 特点
两阶段 R-CNN, Faster R-CNN 较慢 高 先生成候选区域再分类
单阶段 YOLO, SSD, RetinaNet 快 中高 端到端直接预测
锚点自由 FCOS, CenterNet 中等 高 无需预设锚点框
Transformer DETR, DINO 中等 高 基于注意力机制

💻 代码示例：使用YOLOv8进行目标检测

from ultralytics import YOLO
import cv2

# 加载预训练YOLOv8模型
model = YOLO('yolov8n.pt')  # nano版本，速度快

# 对图像进行目标检测
results = model('street.jpg')

# 解析检测结果
for result in results:
    boxes = result.boxes
    for box in boxes:
        # 获取边界框坐标
        x1, y1, x2, y2 = box.xyxy[0]
        # 获取类别和置信度
        cls = box.cls[0]
        conf = box.conf[0]
        print(f"检测到: {model.names[int(cls)]}")
        print(f"位置: ({x1:.0f}, {y1:.0f}, {x2:.0f}, {y2:.0f})")
        print(f"置信度: {conf:.2f}")

# 可视化结果
result[0].show()

🔄 YOLO算法流程

输入处理

原图像 ↓ 缩放到固定尺寸 ↓ 归一化处理 ↓ 划分网格(如13x13) 特征图

预测输出

每个网格预测: → 边界框坐标(x,y,w,h) → 置信度分数 → 类别概率 ↓ NMS后处理 最终检测结果
💡
评估指标

mAP(mean Average Precision)是目标检测最常用的评估指标。mAP@0.5表示IoU阈值为0.5时的平均精度，mAP@0.5:0.95则计算多个IoU阈值下的平均mAP值，更能反映检测器的整体性能。
