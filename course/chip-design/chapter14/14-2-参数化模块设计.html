14.2 参数化模块设计

Verilog HDL 进阶

  • 掌握 parameter 和 localparam 的使用方法

什么是参数化模块

参数化模块设计是指在模块中使用参数（parameter）来定义可配置的特性，如数据位宽、深度、延迟等。这样同一个模块可以根据不同的参数值生成不同规格的电路，大大提高了代码的复用性和灵活性。

💡 parameter 基本语法

module param_adder #( parameter DATA_WIDTH = 8, // 数据位宽 parameter PIPELINE = 0 // 是否使用流水线 )( input wire [DATA_WIDTH-1:0] a, input wire [DATA_WIDTH-1:0] b, output wire [DATA_WIDTH:0] sum ); if (PIPELINE) begin : gen_pipeline reg [DATA_WIDTH:0] sum_reg; always @(posedge clk) sum_reg <= a + b; assign sum = sum_reg; end else begin : gen_comb assign sum = a + b; end endmodule

📊 参数传递方式

方式 语法示例 说明
位置传递 module_name #(8, 1) inst(...) 按顺序传递参数，不推荐
命名传递 module_name #(.DATA_WIDTH(16)) inst(...) 推荐方式，清晰明确
defparam defparam inst.DATA_WIDTH = 16; 旧语法，不推荐使用
💡
参数传递示例
// 实例化参数化模块 param_adder #( .DATA_WIDTH(16), // 16位加法器 .PIPELINE(1) // 启用流水线 ) u_adder_16bit ( .a(data_a), .b(data_b), .sum(result) ); // 另一个不同配置的实例 param_adder #( .DATA_WIDTH(32) // 32位加法器，无流水线 ) u_adder_32bit ( .a(addr_a), .b(addr_b), .sum(addr_sum) );

⚙️ parameter 与 localparam

parameter

可在模块实例化时被覆盖，用于外部可配置的参数。

parameter WIDTH = 8;

localparam

不能被外部覆盖，用于模块内部的常量定义。

localparam FULL = WIDTH + 1;
✨
参数化 FIFO 示例
module sync_fifo #( parameter DATA_WIDTH = 8, parameter DEPTH = 16, parameter ADDR_WIDTH = $clog2(DEPTH) )( input wire clk, input wire rst_n, input wire wr_en, input wire [DATA_WIDTH-1:0] wr_data, input wire rd_en, output reg [DATA_WIDTH-1:0] rd_data, output wire full, output wire empty ); // 存储数组 reg [DATA_WIDTH-1:0] mem [0:DEPTH-1]; // 读写指针 reg [ADDR_WIDTH:0] wr_ptr, rd_ptr; // 状态信号 assign full = (wr_ptr[ADDR_WIDTH] != rd_ptr[ADDR_WIDTH]) && (wr_ptr[ADDR_WIDTH-1:0] == rd_ptr[ADDR_WIDTH-1:0]); assign empty = (wr_ptr == rd_ptr); // 写逻辑 always @(posedge clk or negedge rst_n) begin if (!rst_n) wr_ptr <= 0; else if (wr_en && !full) begin mem[wr_ptr[ADDR_WIDTH-1:0]] <= wr_data; wr_ptr <= wr_ptr + 1; end end // 读逻辑 always @(posedge clk or negedge rst_n) begin if (!rst_n) begin rd_ptr <= 0; rd_data <= 0; end else if (rd_en && !empty) begin rd_data <= mem[rd_ptr[ADDR_WIDTH-1:0]]; rd_ptr <= rd_ptr + 1; end end endmodule
