供应链数据

供应链数据反映企业从原材料采购到产品交付的全过程。通过分析供应链各环节的数据，投资者可以提前预测企业营收、产能利用、库存水平等关键经营指标。供应链数据具有明显的领先性，是营收预测的重要前瞻指标。

🔗 供应链数据类型

采购数据

  • 原材料采购量
  • 采购价格变化
  • 供应商订单趋势
  • 应用: 营收预测、成本分析

物流数据

  • 货运量/船运量
  • 运输路线与时效
  • 仓储利用率
  • 应用: 需求预测、产能评估

生产数据

  • 工厂开工率
  • 产量统计
  • 设备运行时间
  • 应用: 产能分析、生产预测

库存数据

  • 原材料库存
  • 在制品库存
  • 产成品库存
  • 应用: 库存周转、需求判断

🏭 主要应用场景

应用领域 数据源 预测指标 交易机会
营收预测 货运量、出货数据 季度营收、同比增长 财报前交易

# 供应链数据分析示例
import pandas as pd
import numpy as np
from sklearn.ensemble import RandomForestRegressor
from sklearn.preprocessing import StandardScaler
from scipy import stats

# 货运量分析预测营收
def analyze_freight_revenue(freight_data, revenue_history):
    """基于货运量预测营收"""
    df = pd.merge(freight_data, revenue_history,
                  on=['company', 'quarter'], how='inner')

    # 特征工程
    df['freight_yoy'] = df.groupby('company')['freight_volume'].pct_change(4)
    df['freight_qoq'] = df.groupby('company')['freight_volume'].pct_change(1)

    # 滚动特征
    df['freight_ma4'] = df.groupby('company')['freight_volume'].transform(
        lambda x: x.rolling(4).mean()
    )

    # 准备训练数据
    features = ['freight_volume', 'freight_yoy', 'freight_qoq', 'freight_ma4']
    X = df[features].dropna()
    y = df['revenue'].loc[X.index]

    # 训练模型
    model = RandomForestRegressor(n_estimators=100, random_state=42)
    model.fit(X, y)

    # 特征重要性
    feature_importance = dict(zip(features, model.feature_importances_))

    return model, feature_importance

# 工厂开工率分析
def analyze_capacity_utilization(factory_data):
    """分析工厂产能利用率"""
    df = pd.DataFrame(factory_data)

    # 计算开工率
    df['utilization_rate'] = df['actual_output'] / df['max_capacity']

    # 趋势分析
    df['utilization_trend'] = df.groupby('factory_id')['utilization_rate'].transform(
        lambda x: x.rolling(4).mean()
    )

    # 识别高负荷工厂（开工率>90%）
    high_utilization = df[df['utilization_rate'] > 0.9]

    # 识别低开工率工厂（开工率<50%）
    low_utilization = df[df['utilization_rate'] < 0.5]

    results = {
        'average_utilization': df['utilization_rate'].mean(),
        'high_utilization_count': high_utilization['factory_id'].nunique(),
        'low_utilization_count': low_utilization['factory_id'].nunique(),
        'utilization_trend': df['utilization_trend'].iloc[-1]
    }

    return results

# 库存周转分析
def analyze_inventory_turnover(inventory_data, cogs_data):
    """分析库存周转情况"""
    # 合并库存和销售数据
    df = pd.merge(inventory_data, cogs_data, on=['company', 'quarter'])

    # 计算库存周转率
    df['inventory_turnover'] = df['cogs'] / df['avg_inventory']

    # 计算库存周转天数
    df['inventory_days'] = 90 / df['inventory_turnover']  # 假设季度数据

    # 趋势分析
    df['turnover_trend'] = df.groupby('company')['inventory_turnover'].transform(
        lambda x: x.pct_change(1)
    )

    # 异常检测：库存周转率显著下降
    df['turnover_anomaly'] = df['turnover_trend'] < -0.2  # 下降超过20%

    return df

# 供应链风险评分
def assess_supply_chain_risk(supply_chain_metrics):
    """评估供应链风险"""
    df = pd.DataFrame(supply_chain_metrics)

    # 风险因子标准化
    scaler = StandardScaler()

    risk_factors = ['supplier_concentration', 'lead_time_days',
                   'inventory_volatility', 'freight_cost_volatility']

    df_normalized = df[risk_factors].copy()
    df_normalized[risk_factors] = scaler.fit_transform(df_normalized[risk_factors])

    # 计算综合风险得分
    df['risk_score'] = df_normalized[risk_factors].mean(axis=1)

    # 风险等级分类
    def risk_category(score):
        if score < -1:
            return '低风险'
        elif score < 1:
            return '中风险'
        else:
            return '高风险'

    df['risk_level'] = df['risk_score'].apply(risk_category)

    return df

# 新产品需求预测
def forecast_new_product_demand(supply_chain_signals):
    """基于供应链信号预测新产品需求"""
    df = pd.DataFrame(supply_chain_signals)

    # 关键信号
    signals = {
        'component_orders': 'increase',
        'production_ramp_up': 'early_stage',
        'freight_bookings': 'above_normal',
        'channel_inventory': 'building'
    }

    # 计算需求强度评分
    demand_score = 0

    if signals['component_orders'] == 'increase':
        demand_score += 0.3

    if signals['production_ramp_up'] in ['early_stage', 'mid_stage']:
        demand_score += 0.3

    if signals['freight_bookings'] == 'above_normal':
        demand_score += 0.2

    if signals['channel_inventory'] == 'building':
        demand_score += 0.2

    return {
        'demand_intensity': '高' if demand_score > 0.6 else '中' if demand_score > 0.3 else '低',
        'demand_score': demand_score
    }

# 供应商分析
def analyze_supplier_stability(purchase_orders):
    """分析供应商稳定性"""
    df = pd.DataFrame(purchase_orders)

    # 按供应商聚合
    supplier_stats = df.groupby('supplier_id').agg({
        'order_id': 'count',  # 订单数量
        'quantity': 'mean',   # 平均订单量
        'delivery_days': ['mean', 'std'],  # 交货时间
        'quality_score': 'mean'  # 质量评分
    }).reset_index()

    supplier_stats.columns = ['supplier_id', 'order_count', 'avg_quantity',
                              'avg_delivery_days', 'delivery_std',
                              'quality_score']

    # 稳定性评分
    supplier_stats['stability_score'] = (
        1.0 / (1 + supplier_stats['delivery_std']) *
        supplier_stats['quality_score']
    )

    return supplier_stats.sort_values('stability_score', ascending=False)

📊 供应链领先指标体系

营收领先指标

  • 货运量/出货量
  • 订单 backlog
  • 渠道库存补货
  • 领先期: 1-2季度

利润领先指标

  • 原材料采购价格
  • 生产效率指标
  • 供应商议价能力
  • 领先期: 1季度
⚠️
注意事项

供应链数据应用需注意：1）数据通常为间接数据，非公司官方数据；2）不同公司的供应链透明度差异大；3）需要理解行业特性才能正确解读数据；4）数据可能存在噪音和异常值；5）供应链变化与最终销售可能存在时间差。建议结合行业知识和多种数据源进行验证。

✨
最佳实践

供应链数据成功应用的关键：1）建立完整的公司-供应商-产品映射；2）深入理解行业供应链结构；3）关注供应链异常而非正常波动；4）建立多维度验证体系；5）跟踪长期趋势而非短期噪音。建议聚焦重点行业和公司，建立行业专属的供应链分析模型。
