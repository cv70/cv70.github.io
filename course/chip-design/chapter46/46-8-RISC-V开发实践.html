💻 汇编编程实例

示例：字符串复制

# char *strcpy(char *dest, const char *src) # a0: dest, a1: src # 返回: a0 (dest) strcpy: mv t0, a0 # 保存dest指针 loop: lbu t1, 0(a1) # 加载src字符（无符号） sb t1, 0(a0) # 存储到dest addi a0, a0, 1 # dest++ addi a1, a1, 1 # src++ bnez t1, loop # 如果不是'\0'则继续 mv a0, t0 # 返回原始dest指针 ret

🔄 函数调用约定

RISC-V ABI调用规范

寄存器 用途 保存者
ra (x1) 返回地址 调用者保存
sp (x2) 栈指针 被调用者保存
a0-a7 参数/返回值 调用者保存
t0-t6 临时寄存器 调用者保存
s0-s11 保存寄存器 被调用者保存

📋 函数调用示例

递归函数：斐波那契数列

# int fib(int n) # a0: n # 返回: a0 (fib(n)) fib: addi sp, sp, -16 # 分配栈空间 sw ra, 0(sp) # 保存返回地址 sw s0, 4(sp) # 保存s0 mv s0, a0 # s0 = n li t0, 1 ble s0, t0, base_case # if (n <= 1) return n # fib(n-1) addi a0, s0, -1 # a0 = n-1 call fib mv s1, a0 # s1 = fib(n-1) # fib(n-2) addi a0, s0, -2 # a0 = n-2 call fib add a0, a0, s1 # a0 = fib(n-1) + fib(n-2) j epilogue base_case: mv a0, s0 # return n epilogue: lw ra, 0(sp) # 恢复返回地址 lw s0, 4(sp) # 恢复s0 addi sp, sp, 16 # 释放栈空间 ret

⚡ 性能优化技巧

优化策略

  • 减少分支 - 使用条件移动代替条件分支
  • 指令调度 - 重排指令减少数据依赖
  • 循环展开 - 减少循环开销
  • 内存访问优化 - 利用Cache局部性
  • 使用压缩指令 - 减少代码大小
  • 利用SIMD - 使用向量扩展加速

🎯 实战项目：数组求和优化

基本实现 vs 优化实现

# 基本实现 sum_basic: mv t0, a0 # 数组指针 li t1, 0 # 和 = 0 mv t2, a1 # 计数器 loop_basic: beqz t2, end_basic lw t3, 0(t0) add t1, t1, t3 addi t0, t0, 4 addi t2, t2, -1 j loop_basic end_basic: mv a0, t1 ret # 优化实现（循环展开4x） sum_optimized: mv t0, a0 # 数组指针 li t1, 0 # 和 = 0 mv t2, a1 # 计数器 # 处理不能被4整除的部分 andi t3, t2, 3 beqz t3, loop_opt remainder_loop: beqz t3, loop_opt lw t4, 0(t0) add t1, t1, t4 addi t0, t0, 4 addi t3, t3, -1 j remainder_loop loop_opt: blt t2, 4, end_opt lw t4, 0(t0) # 展开4次 lw t5, 4(t0) lw t6, 8(t0) lw t7, 12(t0) add t1, t1, t4 add t1, t1, t5 add t1, t1, t6 add t1, t1, t7 addi t0, t0, 16 addi t2, t2, -4 j loop_opt end_opt: mv a0, t1 ret

🛡️ 常见错误与调试

典型问题

  • 栈不平衡 - 忘记恢复栈指针
  • 寄存器覆盖 - 未正确保存/恢复寄存器
  • 对齐错误 - 访问未对齐的内存
  • 延迟槽误解 - RISC-V没有延迟槽
  • 立即数范围 - 立即数超出12位范围
⚠️
开发最佳实践

• 使用注释说明代码意图
• 遵循调用约定规范
• 编写测试用例验证正确性
• 使用版本控制管理代码
• 关注性能与可读性的平衡
