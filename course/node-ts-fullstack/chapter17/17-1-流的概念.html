17.1 流的概念

理解流式数据处理

🎯 学习目标

  • 理解流的基本概念
  • 了解流的四种类型
  • 掌握流的优势
  • 了解流的应用场景

📚 什么是流

// 流（Stream）是 Node.js 处理流式数据的抽象接口 // 传统方式：一次性读取全部数据 const fs = require('fs'); const data = fs.readFileSync('large-video.mp4'); // 占用大量内存 // 流方式：分块读取处理 const readStream = fs.createReadStream('large-video.mp4'); readStream.on('data', (chunk) => { // 每次只处理一小块数据（默认 64KB） console.log('读取块大小:', chunk.length); }); // 流的比喻： // 传统方式：用水桶一次性装满水 // 流方式：用管道持续流动水 // 流的基本概念： // 1. 数据分成小块（chunk）依次处理 // 2. 不需要等待全部数据加载完成 // 3. 内存占用固定且小 // 4. 可以边读边处理边写
💡
流的核心优势

流式处理将大数据分成小块，降低内存使用，实现高效的数据处理。

🔧 流的四种类型

const stream = require('stream'); // 1. 可读流（Readable） // 用于读取数据，如文件读取、HTTP 请求 const { Readable } = stream; // 2. 可写流（Writable） // 用于写入数据，如文件写入、HTTP 响应 const { Writable } = stream; // 3. 双工流（Duplex） // 既可读又可写，如 TCP socket const { Duplex } = stream; // 4. 转换流（Transform） // 在读写过程中转换数据，如压缩、加密 const { Transform } = stream; // 内置的流示例 const fs = require('fs'); const http = require('http'); const net = require('net'); const zlib = require('zlib'); // 可读流 const readStream = fs.createReadStream('file.txt'); // 可写流 const writeStream = fs.createWriteStream('output.txt'); // 双工流 const socket = new net.Socket(); // 转换流 const gzip = zlib.createGzip();

📦 流的优势

// 1. 内存效率 // 传统方式：内存占用 = 文件大小 // 1GB 文件需要 1GB+ 内存 const bigData = fs.readFileSync('1GB-file.bin'); // 流方式：内存占用 = highWaterMark（默认 64KB） // 1GB 文件只需要 64KB 内存 fs.createReadStream('1GB-file.bin') .pipe(fs.createWriteStream('copy.bin')); // 2. 时间效率 // 传统方式：等待全部读取完成才能开始处理 // 流方式：读取第一个块后立即开始处理 // 3. 可组合性 // 流可以像管道一样连接 fs.createReadStream('file.txt') .pipe(zlib.createGzip()) // 压缩 .pipe(crypto.createCipher()) // 加密 .pipe(fs.createWriteStream('encrypted.gz')); // 4. 实时处理 // HTTP 请求体、标准输入等都是流 // 可以实时处理数据流 // 示例：实时处理日志 process.stdin.on('data', (chunk) => { const lines = chunk.toString().split('\n'); lines.forEach(line => { if (line.includes('ERROR')) { console.error(line); } }); });

⚙️ 流的模式

// 可读流有两种模式： // 1. flowing 模式：自动读取数据并通过事件发送 // 2. paused 模式：需要显式调用 read() 读取 const fs = require('fs'); const readable = fs.createReadStream('file.txt'); // flowing 模式 - 自动推送数据 readable.on('data', (chunk) => { console.log('收到数据:', chunk.length); }); // 暂停流 readable.pause(); // 恢复流 readable.resume(); // paused 模式 - 手动读取 readable.on('readable', () => { let chunk; while (null !== (chunk = readable.read())) { console.log('手动读取:', chunk.length); } }); // 切换模式的操作 // 进入 flowing 模式： // - 添加 'data' 监听器 // - 调用 resume() // - 调用 pipe() // 进入 paused 模式： // - 调用 pause() // - 移除所有 'data' 监听器 // - 调用 unpipe()

📝 本节小结

✅
  • • 流分块处理数据，降低内存占用
  • • 四种类型：Readable、Writable、Duplex、Transform
  • • 可读流有 flowing 和 paused 两种模式
  • • 流可以像管道一样连接组合
