AI公平性与偏见概述

AI偏见是指AI系统对某些群体产生系统性不公平的结果。 偏见可能来源于训练数据、算法设计、社会背景等多个方面。 构建公平的AI系统不仅是道德要求，更是法律合规和社会责任。

⚠️ 偏见的来源

数据偏见

  • 采样偏见
  • 标注偏见
  • 历史偏见
  • 代表性不足

算法偏见

  • 目标函数偏差
  • 特征选择偏差
  • 模型架构偏差
  • 优化偏差

交互偏见

  • 反馈循环
  • 用户偏见
  • 部署环境偏差
  • 使用场景偏差

⚖️ 公平性定义

公平性类型 定义 数学表达
群体公平 不同群体获得相似结果 P(Y|A=0) = P(Y|A=1)
机会均等 不同群体的合格者有相同机会 P(Y|A=0, R) = P(Y|A=1, R)
预测公平 不同群体的预测准确率相似 P(R|A=0) = P(R|A=1)
个体公平 相似个体应被相似对待 d(x,x')小则f(x)≈f(x')

🔍 偏见检测方法

# 公平性指标计算示例
from fairlearn.metrics import MetricFrame
from sklearn.metrics import accuracy_score

# 计算不同群体的准确率
metrics = MetricFrame(
    metrics=accuracy_score,
    y_true=y_true,
    y_pred=y_pred,
    sensitive_features=sensitive_attr
)

print("整体准确率:", metrics.overall)
print("各群体准确率:", metrics.by_group)

# 差异比率
disparity = metrics.difference()
print("准确率差异:", disparity)

🎯 训练中约束方法

# 使用公平约束训练
from fairlearn.reductions import ExponentiatedGradient
from fairlearn.reductions import DemographicParity

# 定义公平性约束
constraint = DemographicParity()

# 创建公平分类器
fair_classifier = ExponentiatedGradient(
    estimator=classifier,
    constraints=constraint
)

# 训练模型
fair_classifier.fit(X_train, y_train, sensitive_features=gender_train)

# 预测
y_pred = fair_classifier.predict(X_test)

📝 后处理方法

# 调整不同群体的阈值
from fairlearn.postprocessing import ThresholdOptimizer

# 创建后处理器
postprocess = ThresholdOptimizer(
    estimator=classifier,
    constraints='equalized_odds',
    prefit=True
)

# 在验证数据上拟合后处理器
postprocess.fit(
    X_valid,
    y_valid,
    sensitive_features=gender_valid
)

# 应用后处理
y_pred_fair = postprocess.predict(X_test, sensitive_features=gender_test)

📋 公平性评估指标

指标类别 具体指标 说明
差异性指标 差异比率、差异度量 不同群体结果差异
独立性指标 统计差异、相关系数 预测与敏感属性独立
分离性指标 机会均等、预测均等 不同群体准确率相似
充分性指标 校准、预测可靠性 预测概率反映真实风险
⚠️
公平性挑战
  • 定义困难: 公平性定义多样且可能冲突
  • 数据局限: 历史数据包含社会偏见
  • 上下文依赖: 公平性依赖于具体场景
  • 权衡复杂: 准确性、隐私、公平性权衡

📊 公平性实施流程

1. 识别敏感属性
   ├─ 确定受保护群体
   ├─ 收集相关数据
   └─ 定义公平性目标

2. 评估当前系统
   ├─ 计算公平性指标
   ├─ 识别偏见来源
   └─ 确定影响范围

3. 实施缓解措施
   ├─ 选择缓解方法
   ├─ 应用数据/模型调整
   └─ 验证效果

4. 持续监控
   ├─ 部署后监控
   ├─ 定期重新评估
   └─ 及时响应问题
