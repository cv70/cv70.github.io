84.2 组件类型

Vue 组件的 TypeScript 类型定义

📖 本节概述

本节将介绍如何在 Vue 3 组件中使用 TypeScript，包括组件的类型定义、props 和 emits 的类型标注、以及泛型组件的使用。

🎯 学习目标

  • 掌握 script setup 中的 TypeScript 用法
  • 学会定义组件 Props 类型
  • 掌握 Emits 的类型定义
  • 了解泛型组件的使用

🔧 基本组件类型

script setup 类型

<script setup lang="ts"> import { ref, computed } from 'vue'; // 响应式数据自动推断类型 const count = ref(0); // Ref<number> const message = ref('hello'); // Ref<string> // 显式类型标注 const user = ref<User | null>(null); // 计算属性 const doubleCount = computed(() => count.value * 2); // 函数 function increment(): void { count.value++; } </script>

📥 Props 类型定义

使用 TypeScript 接口

<script setup lang="ts"> // 定义 Props 接口 interface Props { title: string; count?: number; items: string[]; user: { id: number; name: string; }; status: 'active' | 'inactive'; } // 使用 defineProps const props = defineProps<Props>(); // 带默认值 const props = withDefaults(defineProps<Props>(), { count: 0, status: 'active' }); </script>

复杂类型

<script setup lang="ts"> interface User { id: number; name: string; email: string; } interface Props { users: User[]; selectedIds: number[]; onSelect: (user: User) => void; config: { pageSize: number; showAvatar: boolean; }; } const props = defineProps<Props>(); </script>

📤 Emits 类型定义

使用类型化 Emits

<script setup lang="ts"> // 定义 Emits 类型 const emit = defineEmits<{ (e: 'update', value: string): void; (e: 'delete', id: number): void; (e: 'change', oldValue: string, newValue: string): void; }>(); // 使用 emit('update', 'new value'); emit('delete', 1); emit('change', 'old', 'new'); </script>

v-model 的类型定义

<script setup lang="ts"> // 单个 v-model const props = defineProps<{ modelValue: string; }>(); const emit = defineEmits<{ (e: 'update:modelValue', value: string): void; }>(); // 多个 v-model const props = defineProps<{ modelValue: string; title: string; }>(); const emit = defineEmits<{ (e: 'update:modelValue', value: string): void; (e: 'update:title', value: string): void; }>(); </script>

🔁 泛型组件

基本泛型组件

<script setup lang="ts" generic="T"> import { ref } from 'vue'; const props = defineProps<{ items: T[]; selected: T | null; }>(); const emit = defineEmits<{ (e: 'select', item: T): void; }>(); function select(item: T) { emit('select', item); } </script> <template> <ul> <li v-for="item in items" :key="item" @click="select(item)" > {{ item }} </li> </ul> </template>

带约束的泛型

<script setup lang="ts" generic="T extends { id: number }"> const props = defineProps<{ items: T[]; }>(); const emit = defineEmits<{ (e: 'select', item: T): void; }>(); // 可以访问 item.id function getKey(item: T) { return item.id; } </script>

多个泛型参数

<script setup lang="ts" generic="T, K extends keyof T"> const props = defineProps<{ items: T[]; valueKey: K; }>(); // 获取值 function getValue(item: T) { return item[props.valueKey]; } </script>

🔧 defineExpose 类型

<script setup lang="ts"> import { ref } from 'vue'; const count = ref(0); function increment() { count.value++; } function reset() { count.value = 0; } // 暴露给父组件 defineExpose({ count, increment, reset }); </script> <!-- 父组件 --> <script setup lang="ts"> import { ref } from 'vue'; import ChildComponent from './ChildComponent.vue'; const childRef = ref<InstanceType<typeof ChildComponent> | null>(null); function callChildMethod() { childRef.value?.increment(); childRef.value?.reset(); console.log(childRef.value?.count); } </script>

📝 本节小结

  • 使用 interface 定义 Props 和 Emits 类型
  • withDefaults 可以设置 Props 默认值
  • Emits 使用函数签名定义类型
  • 泛型组件支持类型参数化
  • defineExpose 暴露组件内部方法
