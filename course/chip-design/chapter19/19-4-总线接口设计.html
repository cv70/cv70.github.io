19.4 总线接口设计

芯片间通信的桥梁

🎯 学习目标

  • 理解总线接口的基本概念
  • 掌握常用总线协议
  • 学会设计AXI接口
  • 了解总线接口的时序约束

总线接口概述

总线接口是芯片与外部设备或其他芯片进行数据通信的通道。良好的总线接口设计需要考虑协议兼容性、时序匹配、带宽需求等多个方面。

🔌 常用总线协议对比

总线类型 特点 应用场景 带宽
APB 简单、低功耗 低速外设配置 低
AHB 流水线、高带宽 高性能系统 中
AXI 多通道、突发传输 SoC内部互联 高
PCIe 串行、高速 扩展卡、高速IO 极高

🚀 AXI总线特点

通道结构

  • 读地址通道
  • 读数据通道
  • 写地址通道
  • 写数据通道
  • 写响应通道

核心特性

  • 分离的地址/数据通道
  • 支持未对齐传输
  • 突发传输支持
  • 乱序完成支持

💻 简单APB从机接口代码

// APB Slave接口
module apb_slave (
    // APB信号
    input  wire        pclk,
    input  wire        presetn,
    input  wire        psel,
    input  wire        penable,
    input  wire        pwrite,
    input  wire [31:0] paddr,
    input  wire [31:0] pwdata,
    output reg  [31:0] prdata,
    output reg         pready,

    // 内部寄存器接口
    output reg  [31:0] reg0,
    output reg  [31:0] reg1
);

always @(posedge pclk or negedge presetn) begin
    if (!presetn) begin
        reg0   <= 32'h0;
        reg1   <= 32'h0;
        prdata <= 32'h0;
        pready <= 1'b0;
    end else begin
        pready <= 1'b1;

        if (psel && penable) begin
            if (pwrite) begin
                case (paddr[7:0])
                    8'h00: reg0 <= pwdata;
                    8'h04: reg1 <= pwdata;
                endcase
            end else begin
                case (paddr[7:0])
                    8'h00: prdata <= reg0;
                    8'h04: prdata <= reg1;
                    default: prdata <= 32'h0;
                endcase
            end
        end
    end
end

endmodule

⚡ 接口时序设计要点

  • 建立时间和保持时间满足要求
  • 时钟偏移（skew）控制在范围内
  • 输出延迟符合接口规范
  • 输入采样窗口充足
  • 考虑PCB走线延迟
⚠️
设计注意事项

总线接口设计时必须严格遵循协议规范，在仿真中验证所有时序参数，并在实际硬件上进行充分的时序分析。
