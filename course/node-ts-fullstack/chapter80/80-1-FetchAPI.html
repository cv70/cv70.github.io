80.1 Fetch API

现代浏览器内置的 HTTP 请求方法

📖 本节概述

Fetch API 是现代浏览器提供的用于发起网络请求的接口，它基于 Promise 设计，提供了更强大、更灵活的方式来处理 HTTP 请求，是 XMLHttpRequest 的现代替代方案。

🎯 学习目标

  • 理解 Fetch API 的基本概念和工作原理
  • 掌握 GET 和 POST 请求的发送方式
  • 学会处理响应数据和错误
  • 了解 Fetch 的配置选项

💡 Fetch API 基础

基本语法

Fetch API 的基本语法非常简洁，接收一个 URL 参数，返回一个 Promise。

// 基本的 GET 请求 fetch('https://api.example.com/data') .then(response => response.json()) .then(data => console.log(data)) .catch(error => console.error('Error:', error)); // 使用 async/await async function fetchData() { try { const response = await fetch('https://api.example.com/data'); const data = await response.json(); console.log(data); } catch (error) { console.error('Error:', error); } }

Response 对象

Fetch 返回的 Response 对象包含了响应的各种信息：

const response = await fetch('https://api.example.com/data'); // Response 对象属性 console.log(response.status); // 状态码，如 200 console.log(response.statusText); // 状态文本，如 'OK' console.log(response.ok); // 是否成功 (status 200-299) console.log(response.headers); // 响应头 console.log(response.url); // 请求的 URL // 响应体解析方法 const jsonData = await response.json(); // 解析 JSON const textData = await response.text(); // 解析文本 const blobData = await response.blob(); // 解析 Blob const arrayBuffer = await response.arrayBuffer(); // 解析 ArrayBuffer

🔧 GET 请求

GET 请求用于从服务器获取数据。

// 简单的 GET 请求 async function getUsers() { const response = await fetch('https://jsonplaceholder.typicode.com/users'); const users = await response.json(); return users; } // 带查询参数的 GET 请求 async function searchUsers(name: string) { const params = new URLSearchParams({ name }); const response = await fetch( `https://api.example.com/users?${params}` ); return response.json(); } // 带请求头的 GET 请求 async function getProtectedData(token: string) { const response = await fetch('https://api.example.com/protected', { headers: { 'Authorization': `Bearer ${token}`, 'Content-Type': 'application/json' } }); return response.json(); }

🔧 POST 请求

POST 请求用于向服务器发送数据。

// 发送 JSON 数据 async function createUser(userData: { name: string; email: string }) { const response = await fetch('https://api.example.com/users', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify(userData) }); return response.json(); } // 发送表单数据 async function uploadForm(formData: FormData) { const response = await fetch('https://api.example.com/upload', { method: 'POST', body: formData // 不需要设置 Content-Type，浏览器会自动设置 }); return response.json(); } // 文件上传 async function uploadFile(file: File) { const formData = new FormData(); formData.append('file', file); const response = await fetch('https://api.example.com/upload', { method: 'POST', body: formData }); return response.json(); }

⚙️ 请求配置选项

Fetch 支持多种配置选项来自定义请求行为。

const response = await fetch('https://api.example.com/data', { method: 'GET', // 请求方法：GET, POST, PUT, DELETE, PATCH headers: { // 请求头 'Content-Type': 'application/json', 'Authorization': 'Bearer token' }, body: JSON.stringify(data), // 请求体 mode: 'cors', // 跨域模式：cors, no-cors, same-origin credentials: 'include', // 发送 Cookie：include, same-origin, omit cache: 'default', // 缓存策略 redirect: 'follow', // 重定向处理：follow, error, manual referrer: 'no-referrer', // 引用页 signal: controller.signal // 用于取消请求 });

请求方法

方法 描述 使用场景
GET 获取资源 查询数据、获取列表
POST 创建资源 提交表单、上传文件
PUT 更新资源（完整） 整体更新数据
PATCH 更新资源（部分） 部分更新数据
DELETE 删除资源 删除数据

⚠️ 错误处理

Fetch 的错误处理与传统的 AJAX 有所不同，需要注意 HTTP 错误状态码的处理。

// 完整的错误处理 async function fetchWithErrorHandling(url: string) { try { const response = await fetch(url); // 检查 HTTP 状态码 if (!response.ok) { throw new Error(`HTTP error! status: ${response.status}`); } const data = await response.json(); return { success: true, data }; } catch (error) { if (error instanceof TypeError) { // 网络错误或请求被阻止 console.error('Network error:', error.message); } else { // 其他错误 console.error('Fetch error:', error); } return { success: false, error }; } }
⚠️
注意

Fetch 只有在网络错误或请求被阻止时才会 reject，HTTP 404 或 500 等错误状态码不会触发 catch，需要通过 response.ok 或 response.status 来判断。

🚀 高级用法

请求超时

function fetchWithTimeout(url: string, timeout: number = 5000) { const controller = new AbortController(); const signal = controller.signal; const timeoutId = setTimeout(() => { controller.abort(); }, timeout); return fetch(url, { signal }) .finally(() => clearTimeout(timeoutId)); } // 使用 try { const response = await fetchWithTimeout('https://api.example.com/data', 3000); const data = await response.json(); } catch (error) { if (error.name === 'AbortError') { console.error('Request timeout'); } }

请求重试

async function fetchWithRetry( url: string, options: RequestInit = {}, retries: number = 3 ): Promise { try { const response = await fetch(url, options); if (!response.ok) throw new Error(`HTTP ${response.status}`); return response; } catch (error) { if (retries > 0) { console.log(`Retrying... ${retries} attempts left`); await new Promise(r => setTimeout(r, 1000)); // 等待1秒 return fetchWithRetry(url, options, retries - 1); } throw error; } }

📝 本节小结

  • Fetch API 基于 Promise，提供简洁的请求方式
  • Response 对象提供多种解析响应体的方法
  • 需要手动检查 response.ok 来判断请求是否成功
  • 支持丰富的配置选项来自定义请求行为
  • 可以配合 AbortController 实现请求取消和超时
