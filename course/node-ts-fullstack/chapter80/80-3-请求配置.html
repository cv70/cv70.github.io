80.3 请求配置

自定义 Axios 请求行为

📖 本节概述

Axios 提供了丰富的配置选项，允许开发者自定义请求的各种行为，包括请求头、超时时间、响应类型、认证信息等。合理使用这些配置可以更好地满足业务需求。

🎯 学习目标

  • 掌握 Axios 的核心配置选项
  • 学会创建 Axios 实例和自定义默认配置
  • 理解配置的优先级顺序
  • 了解常用配置的最佳实践

⚙️ 核心配置选项

interface AxiosRequestConfig { // 请求 URL url?: string; // 请求方法 method?: string; // 'GET' | 'POST' | 'PUT' | 'DELETE' | 'PATCH' 等 // 基础 URL baseURL?: string; // 请求头 headers?: any; // URL 查询参数 params?: any; // 参数序列化函数 paramsSerializer?: (params: any) => string; // 请求体数据 data?: any; // 请求超时时间（毫秒） timeout?: number; // 跨域请求时是否携带凭证 withCredentials?: boolean; // 响应数据类型 responseType?: string; // 'json' | 'blob' | 'text' | 'arraybuffer' 等 // 响应编码 responseEncoding?: string; // 身份验证 auth?: { username: string; password: string; }; // 请求取消令牌 signal?: AbortSignal; // 数据转换函数 transformRequest?: (any | (any))[]; transformResponse?: (any | (any))[]; // 代理配置 proxy?: { host: string; port: number; auth?: { username: string; password: string }; }; }

🔧 创建 Axios 实例

使用 axios.create() 可以创建一个自定义配置的 Axios 实例，便于在项目中统一管理请求配置。

import axios from 'axios'; // 创建实例 const apiClient = axios.create({ baseURL: 'https://api.example.com', timeout: 10000, headers: { 'Content-Type': 'application/json' } }); // 使用实例发送请求 apiClient.get('/users') .then(response => console.log(response.data)); // 可以覆盖实例的默认配置 apiClient.get('/users', { timeout: 5000, // 这个请求使用 5 秒超时 headers: { 'X-Custom-Header': 'value' } });

📋 配置优先级

配置会按优先级进行合并，顺序如下：

  1. 请求时的 config 参数（优先级最高）
  2. 实例的 defaults 配置
  3. 库的默认配置（优先级最低）
import axios from 'axios'; // 库默认配置 // timeout: 0 (无超时) // 全局默认配置 axios.defaults.baseURL = 'https://api.example.com'; axios.defaults.timeout = 10000; axios.defaults.headers.common['Authorization'] = 'Bearer token'; // 创建实例时设置默认配置 const api = axios.create({ baseURL: 'https://api.example.com/v1', timeout: 5000 }); // 请求时覆盖配置（最高优先级） api.get('/users', { timeout: 3000 // 最终使用 3000ms });

🌐 请求头配置

const api = axios.create({ baseURL: 'https://api.example.com', headers: { // 通用请求头 'Content-Type': 'application/json', 'Accept': 'application/json', // 自定义请求头 'X-API-Key': 'your-api-key', 'X-Client-Version': '1.0.0' } }); // 动态设置请求头 api.defaults.headers.common['Authorization'] = `Bearer ${token}`; // 单次请求设置请求头 api.get('/protected', { headers: { 'Authorization': `Bearer ${specificToken}` } });

⏱️ 超时与重试配置

const api = axios.create({ baseURL: 'https://api.example.com', timeout: 10000, // 10秒超时 }); // 重试逻辑封装 async function requestWithRetry( config: AxiosRequestConfig, retries: number = 3, delay: number = 1000 ): Promise<AxiosResponse> { try { return await api.request(config); } catch (error) { if (retries <= 0) throw error; await new Promise(resolve => setTimeout(resolve, delay)); return requestWithRetry(config, retries - 1, delay * 2); } } // 使用 const response = await requestWithRetry({ method: 'GET', url: '/users' }, 3, 1000);

🔄 数据转换配置

const api = axios.create({ // 请求数据转换 transformRequest: [ (data, headers) => { // 在发送前对数据进行处理 if (data && typeof data === 'object') { // 添加时间戳 data.timestamp = Date.now(); } return JSON.stringify(data); }, ...axios.defaults.transformRequest // 保留默认转换 ], // 响应数据转换 transformResponse: [ ...axios.defaults.transformResponse, // 保留默认转换 (data) => { // 对响应数据进行处理 if (data && data.code === 200) { return data.data; // 提取实际数据 } return data; } ] });

📁 响应类型配置

// JSON 响应（默认） const json = await axios.get('/api/data'); // 文本响应 const text = await axios.get('/api/data', { responseType: 'text' }); // Blob 响应（用于文件下载） const blob = await axios.get('/api/file', { responseType: 'blob' }); // ArrayBuffer 响应 const buffer = await axios.get('/api/binary', { responseType: 'arraybuffer' }); // 流响应（Node.js 环境） const stream = await axios.get('/api/stream', { responseType: 'stream' });

🔐 认证配置

// Bearer Token 认证 const api = axios.create({ baseURL: 'https://api.example.com', headers: { 'Authorization': `Bearer ${token}` } }); // Basic 认证 axios.get('/protected', { auth: { username: 'user', password: 'pass' } }); // 动态添加 Token function setAuthToken(token: string | null) { if (token) { api.defaults.headers.common['Authorization'] = `Bearer ${token}`; } else { delete api.defaults.headers.common['Authorization']; } }

📝 本节小结

  • Axios 提供丰富的配置选项自定义请求行为
  • 使用 axios.create() 创建实例，统一管理配置
  • 配置优先级：请求配置 > 实例默认 > 库默认
  • 支持自定义请求/响应数据转换
  • 支持多种响应类型和认证方式
