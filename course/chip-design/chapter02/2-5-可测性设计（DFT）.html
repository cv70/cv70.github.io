2.5 可测性设计（DFT）

芯片测试的基石

为什么需要 DFT

DFT（Design For Testability，可测性设计）是在芯片设计阶段就考虑测试需求，通过添加专门的测试结构，使得芯片在制造后能够被有效、高效地测试。随着芯片规模和复杂度的增加，测试已成为芯片开发中不可或缺的环节。

没有 DFT 的芯片几乎无法进行有效的生产测试，缺陷芯片难以被筛选，将严重影响产品质量和可靠性。测试成本可能占到芯片总成本的 30-40%。

📊 DFT 的核心目标

🔍

高故障覆盖率

能检测到尽可能多的制造缺陷

⏱️

短测试时间

减少测试向量，缩短测试周期

📈

低成本测试

降低对测试设备的要求

🔧

可诊断性

帮助定位缺陷位置

🔗 扫描链设计（Scan Chain）

扫描链是 DFT 的核心技术，通过将设计中的触发器替换为扫描触发器，并串联成链，实现对内部状态的控制和观察。

扫描链工作原理

💡
  • 正常模式：扫描触发器作为普通触发器工作
  • 扫描模式：触发器串联，数据通过扫描链移入/移出
  • 测试过程：扫描输入测试数据 → 捕获响应 → 扫描输出结果

扫描链设计要素

要素 说明 设计考虑
扫描触发器 带扫描使能和扫描输入的触发器 面积开销、时序影响
扫描链数量 并行扫描链的数量 测试时间 vs IO 引脚
扫描链长度 每条扫描链的触发器数量 测试时间 vs 功耗
扫描链排序 触发器在链中的顺序 布线长度、功耗优化
时钟域处理 跨时钟域触发器的处理 避免跨域移位

🔄 内建自测试（BIST）

BIST（Built-In Self Test）是在芯片内部集成测试电路，使芯片能够自行产生测试激励并分析响应。

Logic BIST

  • 内部产生伪随机测试向量
  • 使用 MISR 压缩响应
  • 适合组合逻辑测试
  • 减少外部测试向量存储

Memory BIST

  • 自动产生存储器测试算法
  • 检测各种存储器故障
  • 支持多种存储器类型
  • 嵌入式存储器测试必备
⚠️
BIST 的权衡

BIST 的优点是减少测试时间和外部测试数据，提高测试速度。缺点是增加芯片面积和功耗，BIST 电路本身也需要测试。需要根据芯片特点和测试需求选择合适的 BIST 方案。

🔌 JTAG 边界扫描

JTAG（Joint Test Action Group）是 IEEE 1149.1 标准定义的边界扫描架构，用于测试芯片间互连和板级连接。

JTAG 架构组成

组件 功能
TAP 控制器 状态机，控制测试操作流程
指令寄存器 存储当前测试指令
数据寄存器 边界扫描寄存器、旁路寄存器等
边界扫描单元 包围 I/O，实现信号控制和观察

JTAG 接口信号

📋
  • TCK（Test Clock）：测试时钟
  • TMS（Test Mode Select）：测试模式选择
  • TDI（Test Data In）：测试数据输入
  • TDO（Test Data Out）：测试数据输出
  • TRST（Test Reset）：测试复位（可选）

🧪 ATPG 与故障模型

ATPG（Automatic Test Pattern Generation）是自动生成测试向量的技术，基于故障模型产生能够检测特定故障的测试模式。

常见故障模型

故障模型 描述 覆盖目标
Stuck-at 信号固定为 0 或 1 连接开路/短路、栅氧化缺陷
Transition 信号无法在规定时间内翻转 延迟缺陷、电阻性缺陷
Path Delay 特定路径延迟超过规格 时序相关缺陷
Bridging 相邻信号线短路 金属桥接缺陷
IDDQ 静态电流异常 桥接、栅氧化缺陷
💡
故障覆盖率目标

工业界通常要求 Stuck-at 覆盖率 ≥98%，Transition 覆盖率 ≥90%。更高的覆盖率意味着更高的产品质量，但也需要更多的测试向量和测试时间。
