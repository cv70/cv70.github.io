8.5 加法器：半加器、全加器、超前进位加法器

组合逻辑电路设计

🎯 学习目标

  • 掌握半加器和全加器的原理与设计
  • 理解行波进位加法器的工作原理和局限性
  • 掌握超前进位加法器的设计方法
  • 了解不同加法器的性能与面积权衡

加法器的重要性

加法器是算术运算电路的基础，CPU中的ALU、DSP处理单元等都离不开加法器。加法器的设计直接影响处理器的性能，是数字系统设计的核心内容。

💡 半加器（Half Adder）

定义

半加器实现两个1位二进制数的加法，不考虑低位进位。

输入：A, B（两个加数）

输出：S（和）, C（进位）

真值表

ABSC
0000
0110
1010
1101

逻辑表达式

和：S = A ⊕ B

进位：C = A · B

实现：1个异或门 + 1个与门

🔧 全加器（Full Adder）

定义

全加器实现两个1位二进制数及低位进位的加法。

输入：A, B, Cin（低位进位）

输出：S（和）, Cout（进位）

真值表

ABCinSCout
00000
00110
01010
01101
10010
10101
11001
11111

逻辑表达式

和：S = A ⊕ B ⊕ Cin

进位：Cout = AB + BCin + ACin

或：Cout = AB + Cin(A⊕B)

💡
用半加器构建全加器

全加器可以用两个半加器和一个或门实现：
1. 第一个半加器：S1 = A ⊕ B, C1 = AB
2. 第二个半加器：S = S1 ⊕ Cin, C2 = S1·Cin
3. 最终进位：Cout = C1 + C2

📈 行波进位加法器（Ripple Carry Adder）

结构

将n个全加器级联，低位的进位输出连接到高位的进位输入。

n位加法器：需要n个全加器，进位依次传递。

⚠️
延迟问题

行波进位加法器的延迟为O(n)，因为进位必须依次经过所有全加器。
例如：32位加法器，如果每个全加器进位延迟为2ns，总延迟约64ns。
这严重限制了高速处理器的设计。

⚡ 超前进位加法器（Carry Look-Ahead Adder）

核心思想

并行计算所有位的进位，而不是串行传递。利用进位生成和进位传播信号。

进位生成与传播

进位生成：Gi = Ai · Bi

（两位都为1时必然产生进位）

进位传播：Pi = Ai ⊕ Bi 或 Pi = Ai + Bi

（有一位为1时，有进位输入就会传播）

进位公式

Ci+1 = Gi + Pi · Ci

  • C1 = G0 + P0·C0
  • C2 = G1 + P1·G0 + P1·P0·C0
  • C3 = G2 + P2·G1 + P2·P1·G0 + P2·P1·P0·C0
✅
CLA优势

超前进位加法器延迟为O(log n)，远优于行波进位加法器的O(n)。
4位CLA延迟约为2-3级门延迟，而4位行波进位需要8级门延迟。
代价是需要更多的硬件资源（与或门）。

📊 加法器性能对比

类型延迟面积应用场景
行波进位O(n)小低速、面积敏感
超前进位O(log n)中等高速处理器
进位选择O(√n)大高性能ALU
进位跳转O(√n)中等折中方案

📝 本节小结

✅
  • • 半加器：2输入1位加法，S=A⊕B, C=AB
  • • 全加器：3输入1位加法，包含进位输入
  • • 行波进位：简单但慢，延迟O(n)
  • • 超前进位：快但复杂，延迟O(log n)
  • • 选择加法器类型需权衡延迟、面积、功耗
