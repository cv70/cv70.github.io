14.4 Verilog 中的时序控制：延迟与事件

时序控制概述

Verilog 提供了多种时序控制机制，用于描述时间行为和事件响应。这些控制主要用于仿真，在可综合代码中需谨慎使用。

💡 延迟控制

延迟控制使用 # 符号指定仿真时间延迟。

// 简单延迟 #10 a = b; // 等待10个时间单位后赋值 // 惯性延迟（用于信号跳变过滤） assign #5 out = in; // 输出延迟5个时间单位 // 传输延迟 out <= #3 in; // 非阻塞赋值带延迟

📊 事件控制类型

类型 语法 说明
边沿敏感 @(posedge clk) 等待时钟上升沿
边沿敏感 @(negedge clk) 等待时钟下降沿
信号敏感 @(a or b) 等待a或b变化
事件变量 @(event_var) 等待事件触发
永远等待 @(*) 等待任意信号变化
💡
事件控制示例
// 测试时钟生成 initial begin clk = 0; forever #5 clk = ~clk; // 周期为10的时钟 end // 同步时序逻辑 always @(posedge clk or negedge rst_n) begin if (!rst_n) q <= 0; else q <= d; end // 组合逻辑敏感列表 always @(a or b or c) begin out = a & b | c; end // 使用 @(*) 自动推断敏感列表 always @(*) begin out = a & b | c; // 编译器自动添加敏感信号 end

⚙️ wait 语句

wait 语句用于电平敏感的条件等待，当条件为真时继续执行。

// 等待条件成立 initial begin wait(enable); // 等待enable为高 wait(counter == 10); // 等待counter等于10 $display("Counter reached 10"); end // 与事件控制对比 initial begin @(posedge enable); // 等待enable上升沿 wait(enable); // 等待enable为高电平 end
⚠️
可综合性注意

延迟控制 # 通常不可综合，仅用于仿真。事件控制 @(posedge clk) 是可综合的标准形式，用于描述同步时序逻辑。

📝 本节小结

✅
  • • 延迟控制用于仿真时序建模
  • • 事件控制用于响应信号变化
  • • wait 用于电平敏感的条件等待
  • • 可综合代码中主要使用 @(posedge clk)
