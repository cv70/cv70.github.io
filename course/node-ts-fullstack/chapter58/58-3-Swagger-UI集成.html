58.3 Swagger UI 集成

在 NestJS 中集成交互式 API 文档

📖 Swagger UI 简介

Swagger UI 是一个开源工具，可以将 OpenAPI 规范文档渲染成可视化的、可交互的 API 文档页面。开发者可以直接在浏览器中查看和测试 API。

💡
Swagger UI 特点
  • 可视化展示 API 文档
  • 支持在线测试 API
  • 自动生成请求代码示例
  • 支持多种认证方式
  • 响应式设计，支持移动端

⚙️ NestJS 集成 Swagger

1. 安装依赖

# 安装 @nestjs/swagger npm install @nestjs/swagger swagger-ui-express

2. 基本配置

// main.ts import { NestFactory } from '@nestjs/core'; import { SwaggerModule, DocumentBuilder } from '@nestjs/swagger'; import { AppModule } from './app.module'; async function bootstrap() { const app = await NestFactory.create(AppModule); // Swagger 配置 const config = new DocumentBuilder() .setTitle('用户管理 API') .setDescription('用户注册、登录、信息管理接口文档') .setVersion('1.0') .addTag('用户', '用户相关接口') .addTag('认证', '认证授权接口') .addBearerAuth() // 添加 Bearer 认证 .build(); const document = SwaggerModule.createDocument(app, config); // 挂载到 /api 路径 SwaggerModule.setup('api', app, document); await app.listen(3000); console.log('Swagger UI: http://localhost:3000/api'); } bootstrap();

3. DocumentBuilder 配置选项

const config = new DocumentBuilder() // 基本信息 .setTitle('API 标题') .setDescription('API 描述') .setVersion('1.0.0') .setTermsOfService('https://example.com/terms') // 联系方式 .setContact('技术支持', 'https://example.com', 'support@example.com') // 许可证 .setLicense('MIT', 'https://opensource.org/licenses/MIT') // 服务器 .addServer('https://api.example.com', '生产环境') .addServer('http://localhost:3000', '开发环境') // 认证方式 .addBearerAuth( { type: 'http', scheme: 'bearer', bearerFormat: 'JWT', description: '请输入 JWT Token', }, 'JWT-auth', // 认证名称 ) .addBasicAuth() // Basic 认证 .addApiKey() // API Key 认证 .addOAuth2() // OAuth2 认证 // 标签 .addTag('用户', '用户管理') .addTag('文章', '文章管理') .build();

🎨 Swagger UI 界面定制

自定义样式和标题

// main.ts SwaggerModule.setup('api', app, document, { // 自定义选项 customCss: ` .topbar { display: none; } .swagger-ui { font-family: 'Microsoft YaHei', sans-serif; } `, customCssUrl: '/swagger-custom.css', // 外部样式文件 customJs: '/swagger-custom.js', // 自定义脚本 customfavIcon: '/favicon.ico', // 网站图标 customSiteTitle: 'API 文档 - 我的项目', // 页面标题 swaggerOptions: { persistAuthorization: true, // 保持认证状态 docExpansion: 'list', // 展开/折叠 filter: true, // 启用搜索过滤 showExtensions: true, // 显示扩展信息 showCommonExtensions: true, }, });

多文档配置

// 创建多个文档 const userConfig = new DocumentBuilder() .setTitle('用户 API') .build(); const userDocument = SwaggerModule.createDocument(app, userConfig, { include: [UserModule], // 只包含特定模块 }); const orderConfig = new DocumentBuilder() .setTitle('订单 API') .build(); const orderDocument = SwaggerModule.createDocument(app, orderConfig, { include: [OrderModule], }); // 挂载不同路径 SwaggerModule.setup('api/users', app, userDocument); SwaggerModule.setup('api/orders', app, orderDocument);

📱 访问 Swagger UI

启动应用后，访问以下地址：

地址 说明
http://localhost:3000/api Swagger UI 界面
http://localhost:3000/api-json JSON 格式的 OpenAPI 文档
http://localhost:3000/api-yaml YAML 格式的 OpenAPI 文档

🔧 环境区分配置

// main.ts import { ConfigService } from '@nestjs/config'; async function bootstrap() { const app = await NestFactory.create(AppModule); const configService = app.get(ConfigService); const nodeEnv = configService.get('NODE_ENV'); // 仅在开发环境启用 Swagger if (nodeEnv !== 'production') { const config = new DocumentBuilder() .setTitle('API 文档') .setVersion('1.0') .build(); const document = SwaggerModule.createDocument(app, config); SwaggerModule.setup('api', app, document); } await app.listen(3000); }
⚠️
生产环境注意

生产环境建议关闭 Swagger UI，避免暴露 API 结构。如需开放，确保配置适当的访问控制。

🔒 Swagger UI 安全配置

// 添加 HTTP Basic 认证保护 Swagger import * as expressBasicAuth from 'express-basic-auth'; async function bootstrap() { const app = await NestFactory.create(AppModule); // Swagger 访问认证 app.use( ['/api', '/api-json'], expressBasicAuth({ challenge: true, users: { admin: 'password123', // 生产环境应使用环境变量 }, }), ); // ... Swagger 配置 }

📊 Swagger UI 功能介绍

文档浏览

  • 按标签分组展示接口
  • 展开/折叠接口详情
  • 查看参数和响应结构
  • 查看数据模型定义

在线测试

  • 填写参数并发送请求
  • 查看响应结果
  • 测试不同认证方式
  • 查看请求/响应头

代码生成

  • curl 命令
  • JavaScript/Node.js
  • Python
  • Java、C#、Go 等

文档导出

  • 导出 OpenAPI JSON
  • 导出 OpenAPI YAML
  • 生成客户端 SDK
  • 导入 Postman

📝 小结

  • @nestjs/swagger 提供了优雅的集成方式
  • DocumentBuilder 用于配置文档基本信息
  • 支持多种认证方式的配置
  • 可自定义 Swagger UI 的样式和行为
  • 支持多文档配置
  • 生产环境注意安全配置
