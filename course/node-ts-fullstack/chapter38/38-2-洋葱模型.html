38.2 洋葱模型

深入理解 Koa 的中间件执行模型

🎯 学习目标

  • 理解洋葱模型的概念和原理
  • 掌握中间件的执行顺序
  • 学会利用洋葱模型解决问题
  • 理解与 Express 线性模型的区别

📚 洋葱模型图解

┌─────────────────────────────────────┐ │ 请求进入 Request │ └─────────────────────────────────────┘ │ ▼ ┌───────────────────────────────────────────────┐ │ 中间件 1 (前置处理) │ │ console.log('1-start') │ └───────────────────────────────────────────────┘ │ ▼ ┌───────────────────────────────────────────────┐ │ 中间件 2 (前置处理) │ │ console.log('2-start') │ └───────────────────────────────────────────────┘ │ ▼ ┌───────────────────────────────────────────────┐ │ 中间件 3 (核心处理) │ │ console.log('3-core') │ │ ctx.body = 'Hello' │ └───────────────────────────────────────────────┘ │ ▼ ┌───────────────────────────────────────────────┐ │ 中间件 2 (后置处理) │ │ console.log('2-end') │ └───────────────────────────────────────────────┘ │ ▼ ┌───────────────────────────────────────────────┐ │ 中间件 1 (后置处理) │ │ console.log('1-end') │ └───────────────────────────────────────────────┘ │ ▼ ┌─────────────────────────────────────┐ │ 响应返回 Response │ └─────────────────────────────────────┘
💡
核心特点

请求从外向内穿过所有中间件，响应从内向外返回，形成一个完整的"洋葱"结构。

💻 代码演示

const Koa = require('koa'); const app = new Koa(); // 中间件 1 app.use(async (ctx, next) => { console.log('1. 中间件1 - 进入'); await next(); console.log('6. 中间件1 - 退出'); }); // 中间件 2 app.use(async (ctx, next) => { console.log('2. 中间件2 - 进入'); await next(); console.log('5. 中间件2 - 退出'); }); // 中间件 3 app.use(async (ctx, next) => { console.log('3. 中间件3 - 进入'); await next(); console.log('4. 中间件3 - 退出'); }); // 核心处理 app.use(async ctx => { console.log('--- 核心处理 ---'); ctx.body = 'Hello Koa'; }); app.listen(3000); // 控制台输出: // 1. 中间件1 - 进入 // 2. 中间件2 - 进入 // 3. 中间件3 - 进入 // --- 核心处理 --- // 4. 中间件3 - 退出 // 5. 中间件2 - 退出 // 6. 中间件1 - 退出

📊 Koa vs Express 模型对比

Koa 洋葱模型

app.use(async (ctx, next) => { // 前置处理 const start = Date.now(); await next(); // 后置处理 console.log(Date.now() - start); });
  • 可以轻松获取响应时间
  • 前后逻辑在同一函数内
  • 代码更加内聚

Express 线性模型

app.use((req, res, next) => { // 前置处理 const start = Date.now(); res.on('finish', () => { // 需要监听事件 console.log(Date.now() - start); }); next(); });
  • 需要监听事件获取响应时间
  • 前后逻辑分离
  • 代码相对分散

💡 洋葱模型的应用场景

请求耗时统计

app.use(async (ctx, next) => { const start = Date.now(); await next(); const ms = Date.now() - start; ctx.set('X-Response-Time', `${ms}ms`); });

请求日志记录

app.use(async (ctx, next) => { console.log(`--> ${ctx.method} ${ctx.url}`); await next(); console.log(`<-- ${ctx.status}`); });

🔐 认证与权限控制

// 认证中间件 app.use(async (ctx, next) => { const token = ctx.headers.authorization; if (!token) { ctx.status = 401; return; // 阻止继续执行 } try { ctx.state.user = await verifyToken(token); } catch (err) { ctx.status = 401; ctx.body = { error: 'Invalid token' }; return; } await next(); }); // 权限中间件 app.use(async (ctx, next) => { const { user } = ctx.state; if (!user.isAdmin) { ctx.status = 403; ctx.body = { error: 'Forbidden' }; return; } await next(); });

🔄 数据库事务管理

// 事务中间件 app.use(async (ctx, next) => { const transaction = await sequelize.transaction(); try { ctx.state.transaction = transaction; await next(); await transaction.commit(); console.log('Transaction committed'); } catch (err) { await transaction.rollback(); console.log('Transaction rolled back'); throw err; } }); // 业务处理 app.use(async ctx => { const { transaction } = ctx.state; await User.create({ name: 'John' }, { transaction }); await Order.create({ userId: 1 }, { transaction }); ctx.body = { success: true }; });
✅
事务处理优势

洋葱模型天然适合事务管理，前置开启事务，后置根据结果提交或回滚。

⚠️ 常见问题

// 错误示例：忘记 await next() app.use(async (ctx, next) => { console.log('1'); next(); // 缺少 await console.log('2'); // 会立即执行 }); // 正确示例 app.use(async (ctx, next) => { console.log('1'); await next(); // 等待下游完成 console.log('2'); // 下游完成后执行 }); // 错误示例：多次调用 next() app.use(async (ctx, next) => { await next(); await next(); // 错误：不能多次调用 });

📝 本节小结

✅
  • • 洋葱模型：请求从外向内，响应从内向外
  • • await next() 之前的代码在请求阶段执行
  • • await next() 之后的代码在响应阶段执行
  • • 适合处理日志、计时、事务等场景
