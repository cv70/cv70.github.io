14.1 path 基础方法

路径处理工具函数

🎯 学习目标

  • 掌握 path 模块的基本用法
  • 学会获取路径各部分
  • 理解路径分隔符
  • 掌握路径格式化方法

📚 获取路径信息

const path = require('path'); const filePath = '/user/docs/node/app.js'; // 获取目录名 console.log(path.dirname(filePath)); // '/user/docs/node' // 获取文件名 console.log(path.basename(filePath)); // 'app.js' // 获取文件名（不含扩展名） console.log(path.basename(filePath, '.js')); // 'app' // 获取扩展名 console.log(path.extname(filePath)); // '.js' // 获取扩展名（多级） console.log(path.extname('app.tar.gz')); // '.gz' // 解析路径（返回对象） console.log(path.parse(filePath)); // { // root: '/', // dir: '/user/docs/node', // base: 'app.js', // ext: '.js', // name: 'app' // }

🔧 路径分隔符

const path = require('path'); // 平台特定的分隔符 console.log(path.sep); // Windows: '\\' Linux/Mac: '/' // 路径分隔符（用于 PATH 环境变量） console.log(path.delimiter); // Windows: ';' Linux/Mac: ':' // 使用分隔符拆分路径 const filePath = '/user/docs/node/app.js'; console.log(filePath.split(path.sep)); // Linux: ['', 'user', 'docs', 'node', 'app.js'] // PATH 环境变量解析 const envPath = process.env.PATH; console.log(envPath.split(path.delimiter)); // 获取当前文件路径 console.log(__filename); // 当前文件的绝对路径 console.log(__dirname); // 当前文件所在目录 // 获取路径的相对路径 console.log(path.relative('/data/orandea/test/aaa', '/data/orandea/impl/bbb')); // '../../impl/bbb'
💡
跨平台注意

Windows 使用反斜杠 \ 作为分隔符，Linux/Mac 使用斜杠 /。使用 path.sep 可保证跨平台兼容。

📦 路径格式化

const path = require('path'); // path.format - 从对象生成路径 const pathObj = { root: '/', dir: '/user/docs/node', base: 'app.js', ext: '.js', name: 'app' }; console.log(path.format(pathObj)); // '/user/docs/node/app.js' // 优先级：dir + base > root + name + ext console.log(path.format({ dir: '/user/docs', base: 'file.txt' })); // '/user/docs/file.txt' console.log(path.format({ root: '/user/', name: 'file', ext: '.txt' })); // '/user/file.txt' // path.normalize - 规范化路径 console.log(path.normalize('/user//docs/../node/./app.js')); // '/user/node/app.js' console.log(path.normalize('C:\\\\Users\\\\..\\\\Documents')); // Windows: 'C:\\Documents'

⚙️ 路径判断

const path = require('path'); // 判断是否是绝对路径 console.log(path.isAbsolute('/user/docs')); // true console.log(path.isAbsolute('./docs')); // false console.log(path.isAbsolute('C:\\Users')); // Windows: true // 获取绝对路径 console.log(path.resolve('app.js')); // '/current/working/directory/app.js' console.log(path.resolve('/user', 'docs', 'app.js')); // '/user/docs/app.js' console.log(path.resolve('www', 'static', '../public')); // '/current/www/public' // 获取相对路径 console.log(path.relative('/data/test', '/data/impl')); // '../impl' console.log(path.relative('/data/test/aaa', '/data/test/bbb')); // '../bbb'

📝 本节小结

✅
  • • dirname/basename/extname 获取路径各部分
  • • path.sep 和 path.delimiter 是平台相关的分隔符
  • • path.parse 解析路径为对象
  • • path.format 从对象生成路径
  • • path.normalize 规范化路径
