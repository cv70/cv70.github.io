什么是KV Cache

KV Cache（Key-Value Cache）是大语言模型推理中的关键技术。 它缓存了自注意力机制中所有历史token的Key和Value矩阵， 避免了每次生成新token时重新计算之前的注意力，大幅提升了推理速度。

🧠 自注意力机制回顾

注意力计算公式

Attention(Q, K, V) = softmax(QK^T / √d) · V

在自注意力中：

  • Q：当前token的Query
  • K：所有历史token的Keys（需要缓存）
  • V：所有历史token的Values（需要缓存）

💾 KV Cache的作用

无KV Cache

  • 每步重新计算所有token
  • 复杂度：O(n²)
  • 显存占用：小
  • 推理速度：慢

有KV Cache

  • 只计算新token
  • 复杂度：O(n)
  • 显存占用：大
  • 推理速度：快

⚠️ KV Cache的挑战

内存需求问题

线性增长

显存瓶颈

💻 KV Cache实现示例

import torch
import torch.nn as nn

class KVCache:
    """
    KV Cache实现
    """
    def __init__(self, batch_size, num_heads, head_dim, max_seq_len, dtype=torch.float16):
        self.batch_size = batch_size
        self.num_heads = num_heads
        self.head_dim = head_dim
        self.max_seq_len = max_seq_len
        self.dtype = dtype

        # 初始化KV缓存
        self.k_cache = torch.zeros(
            batch_size, num_heads, max_seq_len, head_dim,
            dtype=dtype, device='cuda'
        )
        self.v_cache = torch.zeros(
            batch_size, num_heads, max_seq_len, head_dim,
            dtype=dtype, device='cuda'
        )

        self.current_seq_len = 0

    def update(self, new_k, new_v):
        """
        更新KV缓存
        Args:
            new_k: 新的Key (batch, num_heads, 1, head_dim)
            new_v: 新的Value (batch, num_heads, 1, head_dim)
        """
        seq_len = new_k.shape[2]

        # 将新的KV写入缓存
        self.k_cache[:, :, self.current_seq_len:self.current_seq_len+seq_len, :] = new_k
        self.v_cache[:, :, self.current_seq_len:self.current_seq_len+seq_len, :] = new_v

        self.current_seq_len += seq_len

    def get(self):
        """
        获取所有KV缓存
        """
        return self.k_cache[:, :, :self.current_seq_len, :], \
               self.v_cache[:, :, :self.current_seq_len, :]

    def get_slice(self, start, end):
        """
        获取指定范围的KV
        """
        return self.k_cache[:, :, start:end, :], \
               self.v_cache[:, :, start:end, :]

    def reset(self):
        """
        重置缓存
        """
        self.k_cache.zero_()
        self.v_cache.zero_()
        self.current_seq_len = 0

# 量化的KV Cache
class QuantizedKVCache:
    """
    量化KV Cache（INT8）
    """
    def __init__(self, batch_size, num_heads, head_dim, max_seq_len):
        self.batch_size = batch_size
        self.num_heads = num_heads
        self.head_dim = head_dim
        self.max_seq_len = max_seq_len

        # INT8缓存
        self.k_cache_int8 = torch.zeros(
            batch_size, num_heads, max_seq_len, head_dim,
            dtype=torch.int8, device='cuda'
        )
        self.v_cache_int8 = torch.zeros(
            batch_size, num_heads, max_seq_len, head_dim,
            dtype=torch.int8, device='cuda'
        )

        # 缩放因子
        self.k_scale = torch.ones(
            batch_size, num_heads, 1, 1,
            dtype=torch.float16, device='cuda'
        )
        self.v_scale = torch.ones(
            batch_size, num_heads, 1, 1,
            dtype=torch.float16, device='cuda'
        )

        self.current_seq_len = 0

    def quantize(self, x):
        """
        量化到INT8
        """
        # 计算缩放因子
        scale = x.abs().max() / 127.0

        # 量化
        x_quant = (x / scale).round().clamp(-128, 127).to(torch.int8)

        return x_quant, scale

    def update(self, new_k, new_v):
        """
        更新量化缓存
        """
        seq_len = new_k.shape[2]

        # 量化
        k_quant, k_scale = self.quantize(new_k)
        v_quant, v_scale = self.quantize(new_v)

        # 写入缓存
        self.k_cache_int8[:, :, self.current_seq_len:self.current_seq_len+seq_len, :] = k_quant
        self.v_cache_int8[:, :, self.current_seq_len:self.current_seq_len+seq_len, :] = v_quant

        # 更新缩放因子
        self.k_scale = torch.maximum(self.k_scale, k_scale)
        self.v_scale = torch.maximum(self.v_scale, v_scale)

        self.current_seq_len += seq_len

    def dequantize(self, cache_int8, scale):
        """
        反量化
        """
        return cache_int8.float() * scale

    def get(self):
        """
        获取反量化后的KV
        """
        k = self.dequantize(
            self.k_cache_int8[:, :, :self.current_seq_len, :],
            self.k_scale
        )
        v = self.dequantize(
            self.v_cache_int8[:, :, :self.current_seq_len, :],
            self.v_scale
        )
        return k, v

# 使用示例
def example_usage():
    """
    使用KV Cache的示例
    """
    # 参数
    batch_size = 4
    num_heads = 32
    head_dim = 128
    max_seq_len = 4096

    # 创建KV Cache
    kv_cache = KVCache(batch_size, num_heads, head_dim, max_seq_len)

    # 模拟推理过程
    for i in range(100):
        # 模拟新的K和V
        new_k = torch.randn(batch_size, num_heads, 1, head_dim, device='cuda')
        new_v = torch.randn(batch_size, num_heads, 1, head_dim, device='cuda')

        # 更新KV Cache
        kv_cache.update(new_k, new_v)

        # 获取所有KV用于注意力计算
        k, v = kv_cache.get()

        # 进行注意力计算（省略）
        pass

    # 量化版本
    kv_cache_quant = QuantizedKVCache(batch_size, num_heads, head_dim, max_seq_len)

    for i in range(100):
        new_k = torch.randn(batch_size, num_heads, 1, head_dim, device='cuda')
        new_v = torch.randn(batch_size, num_heads, 1, head_dim, device='cuda')

        kv_cache_quant.update(new_k, new_v)

        k, v = kv_cache_quant.get()

📊 优化效果对比

优化方法 显存减少 精度损失 性能影响
FP16量化 50% 几乎无 提升
INT8量化 75% 小 提升
PagedAttention 30-50% 无 显著提升
KV压缩 60-80% 中 可能降低
💡
KV Cache优化建议
  • FP16量化是性价比最高的选择
  • PagedAttention可以大幅提升显存利用率
  • INT8量化需要校准，精度损失可接受
  • 长序列场景推荐组合使用多种优化
