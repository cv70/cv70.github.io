82.2 动态路由

路由参数与动态匹配

📖 本节概述

动态路由允许我们在路由路径中使用参数，实现路由的动态匹配。本节将介绍路由参数、查询参数、多个参数的处理，以及动态添加路由。

🎯 学习目标

  • 掌握路由参数的定义和使用
  • 学会获取路由参数和查询参数
  • 理解路由匹配规则和优先级
  • 掌握动态添加路由的方法

🔢 路由参数

基本参数

// 定义带参数的路由 const routes: RouteRecordRaw[] = [ { path: '/users/:id', name: 'UserDetail', component: () => import('@/views/UserDetail.vue') } ];

获取参数

<!-- UserDetail.vue --> <script setup lang="ts"> import { useRoute } from 'vue-router'; import { ref, watch } from 'vue'; const route = useRoute(); // 获取参数 const userId = route.params.id; // string 或 string[] console.log('User ID:', userId); // 监听参数变化 watch( () => route.params.id, (newId) => { console.log('ID changed:', newId); // 重新加载数据 } ); </script> <template> <div>用户 ID: {{ $route.params.id }}</div> </template>

多个参数

// 多个参数 const routes = [ { path: '/users/:userId/posts/:postId', name: 'PostDetail', component: () => import('@/views/PostDetail.vue') } ]; // 在组件中获取 const route = useRoute(); const userId = route.params.userId; const postId = route.params.postId;

可选参数

// 可选参数（使用 ?） const routes = [ { path: '/users/:id/:tab?', // tab 是可选的 component: UserView } ]; // 匹配： // /users/123 -> id: '123', tab: undefined // /users/123/posts -> id: '123', tab: 'posts'

可重复参数

// 可重复参数（使用 + 或 *） const routes = [ { path: '/files/:path+', // 至少一个 component: FileView }, { path: '/search/:keywords*', // 零个或多个 component: SearchView } ]; // 匹配： // /files/docs/work/report.pdf -> path: ['docs', 'work', 'report.pdf'] // /search/vue/router -> keywords: ['vue', 'router'] // /search -> keywords: []

❓ 查询参数

// 导航时传递查询参数 router.push({ path: '/search', query: { q: 'vue', page: '1', sort: 'date' } }); // URL: /search?q=vue&page=1&sort=date // 在组件中获取 const route = useRoute(); console.log(route.query.q); // 'vue' console.log(route.query.page); // '1' console.log(route.query.sort); // 'date' <!-- 模板中使用 --> <template> <div> 搜索关键词: {{ $route.query.q }} 当前页: {{ $route.query.page }} </div> </template>

🎯 路由匹配优先级

// 路由按定义顺序匹配 const routes = [ // 更具体的路由放在前面 { path: '/users/create', name: 'UserCreate', component: UserCreate }, // 动态参数路由放在后面 { path: '/users/:id', name: 'UserDetail', component: UserDetail }, // 捕获所有路由 { path: '/:pathMatch(.*)*', name: 'NotFound', component: NotFound } ];

正则匹配

// 使用正则限制参数格式 const routes = [ { // 只匹配数字 path: '/users/:id(\\d+)', component: UserDetail }, { // 只匹配特定格式 path: '/posts/:slug([a-z-]+)', component: PostDetail } ];

➕ 动态添加路由

添加单个路由

import { useRouter } from 'vue-router'; const router = useRouter(); // 添加路由 router.addRoute({ path: '/admin', name: 'Admin', component: () => import('@/views/Admin.vue') }); // 添加嵌套路由 router.addRoute('Admin', { path: 'dashboard', name: 'AdminDashboard', component: () => import('@/views/AdminDashboard.vue') });

动态路由权限控制

// 根据用户权限动态添加路由 const adminRoutes = [ { path: '/admin', name: 'Admin', component: () => import('@/views/Admin.vue'), children: [ { path: 'users', name: 'AdminUsers', component: () => import('@/views/AdminUsers.vue') }, { path: 'settings', name: 'AdminSettings', component: () => import('@/views/AdminSettings.vue') } ] } ]; function setupDynamicRoutes(roles: string[]) { if (roles.includes('admin')) { adminRoutes.forEach(route => { router.addRoute(route); }); } } // 移除路由 router.removeRoute('Admin'); // 检查路由是否存在 router.hasRoute('Admin'); // true/false // 获取所有路由 router.getRoutes(); // RouteRecordRaw[]

🔗 路由元信息

// 定义路由元信息 const routes: RouteRecordRaw[] = [ { path: '/admin', name: 'Admin', component: Admin, meta: { requiresAuth: true, title: '管理后台', roles: ['admin'] } } ]; // 类型扩展 import 'vue-router'; declare module 'vue-router' { interface RouteMeta { requiresAuth?: boolean; title?: string; roles?: string[]; } } // 使用元信息 const route = useRoute(); console.log(route.meta.title); // '管理后台' console.log(route.meta.requiresAuth); // true

📝 本节小结

  • 使用 :param 定义动态路由参数
  • 通过 route.params 获取路由参数
  • 通过 route.query 获取查询参数
  • 路由按定义顺序匹配，更具体的路由放前面
  • 使用 addRoute/removeRoute 动态管理路由
