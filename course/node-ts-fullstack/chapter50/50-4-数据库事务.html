50.4 数据库事务

保证数据操作的原子性和一致性

🎯 学习目标

  • 理解事务的概念和作用
  • 掌握 TypeORM 事务处理
  • 掌握 Prisma 事务处理
  • 了解事务隔离级别

📚 什么是事务？

事务是一组数据库操作的逻辑单元，要么全部成功，要么全部失败。事务保证数据的 ACID 特性：原子性、一致性、隔离性、持久性。

事务示例：转账操作 1. 从账户A扣款 100 元 2. 向账户B加款 100 元 如果没有事务，步骤1成功后系统崩溃， 账户A扣款了但账户B没有收到， 导致数据不一致。 使用事务，如果步骤2失败， 步骤1会自动回滚， 保证数据一致性。

🔧 TypeORM 事务

// 方式1：使用 @Transaction() 装饰器（已弃用） // 方式2：使用 DataSource.transaction() import { Injectable } from '@nestjs/common'; import { InjectDataSource } from '@nestjs/typeorm'; import { DataSource } from 'typeorm'; import { User } from './user.entity'; import { Order } from './order.entity'; @Injectable() export class OrderService { constructor( @InjectDataSource() private dataSource: DataSource, ) {} async createOrder(userId: number, items: OrderItem[]) { // 使用事务 return this.dataSource.transaction(async (manager) => { // 创建订单 const order = manager.create(Order, { userId, total: items.reduce((sum, item) => sum + item.price * item.quantity, 0), status: 'pending', }); await manager.save(order); // 扣减库存 for (const item of items) { const product = await manager.findOne(Product, { where: { id: item.productId }, lock: { mode: 'pessimistic_write' }, // 悲观锁 }); if (product.stock < item.quantity) { throw new Error('Insufficient stock'); } product.stock -= item.quantity; await manager.save(product); } // 扣减用户余额 const user = await manager.findOne(User, { where: { id: userId } }); if (user.balance < order.total) { throw new Error('Insufficient balance'); } user.balance -= order.total; await manager.save(user); return order; }); } } // 方式3：使用 QueryRunner async createOrderWithQueryRunner() { const queryRunner = this.dataSource.createQueryRunner(); await queryRunner.connect(); await queryRunner.startTransaction(); try { // 执行操作 await queryRunner.manager.save(Order, orderData); await queryRunner.manager.update(User, userId, { balance: newBalance }); await queryRunner.commitTransaction(); } catch (err) { await queryRunner.rollbackTransaction(); throw err; } finally { await queryRunner.release(); } }

事务管理器

transaction() 方法自动管理事务的开始、提交和回滚。如果回调函数抛出异常，事务会自动回滚。

📦 Prisma 事务

// 方式1：交互式事务 @Injectable() export class OrderService { constructor(private prisma: PrismaService) {} async createOrder(userId: number, items: OrderItem[]) { return this.prisma.$transaction(async (tx) => { // 创建订单 const order = await tx.order.create({ data: { userId, total: items.reduce((sum, item) => sum + item.price * item.quantity, 0), status: 'pending', items: { create: items.map(item => ({ productId: item.productId, quantity: item.quantity, price: item.price, })), }, }, }); // 扣减库存 for (const item of items) { const product = await tx.product.findUnique({ where: { id: item.productId }, }); if (product.stock < item.quantity) { throw new Error('Insufficient stock'); } await tx.product.update({ where: { id: item.productId }, data: { stock: { decrement: item.quantity } }, }); } // 扣减用户余额 const user = await tx.user.findUnique({ where: { id: userId } }); if (user.balance < order.total) { throw new Error('Insufficient balance'); } await tx.user.update({ where: { id: userId }, data: { balance: { decrement: order.total } }, }); return order; }); } } // 方式2：批量事务 const result = await prisma.$transaction([ prisma.user.update({ where: { id: 1 }, data: { balance: { decrement: 100 } }, }), prisma.user.update({ where: { id: 2 }, data: { balance: { increment: 100 } }, }), ]); // 设置事务超时 await prisma.$transaction( async (tx) => { // 事务操作 }, { maxWait: 5000, // 最大等待时间 timeout: 10000, // 事务超时时间 }, );

🔒 事务隔离级别

隔离级别 脏读 不可重复读 幻读
Read Uncommitted 可能 可能 可能
Read Committed 不会 可能 可能
Repeatable Read 不会 不会 可能
Serializable 不会 不会 不会
⚠️
事务最佳实践

事务应尽量简短，避免长时间占用数据库连接。对于复杂的业务逻辑，考虑使用分布式事务或最终一致性方案。
