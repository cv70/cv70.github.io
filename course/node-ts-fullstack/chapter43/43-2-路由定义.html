43.2 路由定义

掌握 NestJS 路由配置技巧

🎯 学习目标

  • 理解路由的组成方式
  • 掌握路由参数的定义
  • 学会定义子路由
  • 了解路由重定向

📚 路由组成

NestJS 路由由控制器装饰器和方法装饰器组合而成：

// 完整路由 = 控制器前缀 + 方法路径 @Controller('users') // 前缀: /users export class UsersController { @Get() // GET /users findAll() {} @Get('active') // GET /users/active findActive() {} @Get(':id') // GET /users/:id findOne(@Param('id') id: string) {} @Post() // POST /users create() {} @Put(':id') // PUT /users/:id update(@Param('id') id: string) {} @Delete(':id') // DELETE /users/:id remove(@Param('id') id: string) {} } // 嵌套路由示例 @Controller('users/:userId/posts') export class PostsController { @Get() // GET /users/:userId/posts findAll(@Param('userId') userId: string) {} @Get(':postId') // GET /users/:userId/posts/:postId findOne( @Param('userId') userId: string, @Param('postId') postId: string ) {} }

🔧 路由参数

import { Controller, Get, Post, Param, Body, Query } from '@nestjs/common'; @Controller('products') export class ProductsController { // 路径参数 @Get(':id') findOne(@Param('id') id: string) { return `Product ${id}`; } // 多个路径参数 @Get('category/:categoryId/product/:productId') findByCategory( @Param('categoryId') categoryId: string, @Param('productId') productId: string, ) { return `Category: ${categoryId}, Product: ${productId}`; } // 查询参数 @Get() findAll( @Query('page') page: number = 1, @Query('limit') limit: number = 10, @Query('sort') sort: string = 'createdAt', ) { return { page, limit, sort }; } // 获取所有参数 @Get('search') search(@Query() query: any) { return query; // { keyword: 'xxx', category: 'yyy', ... } } }
💡
参数顺序

当定义多个路由时，更具体的路由应该放在前面。例如 @Get('active') 应该放在 @Get(':id') 之前，否则 'active' 会被当作 id 参数匹配。

🔄 路由重定向

import { Controller, Get, Redirect } from '@nestjs/common'; @Controller() export class AppController { @Get() @Redirect('https://docs.nestjs.com', 302) root() {} @Get('docs') @Redirect('https://docs.nestjs.com', 301) getDocs() {} // 动态重定向 @Get('blog/:id') @Redirect('https://blog.example.com') getBlog(@Param('id') id: string) { return { url: `https://blog.example.com/posts/${id}` }; } }

🌐 通配符路由

@Controller('files') export class FilesController { // 匹配 /files/abc, /files/abc/def, /files/abc/def/ghi ... @Get('*') getFile(@Req() req: Request) { const path = req.path.replace('/files/', ''); return { path }; } // 匹配特定模式 @Get('image/*') getImage(@Req() req: Request) { // 匹配 /files/image/xxx.jpg } }
⚠️
通配符注意

通配符路由使用 glob 模式匹配。注意不要与具体路由冲突，通配符路由通常放在最后。

📝 本节小结

✅
  • • 路由 = 控制器前缀 + 方法路径
  • • @Param() 获取路径参数
  • • @Query() 获取查询参数
  • • 具体路由应在参数路由之前
