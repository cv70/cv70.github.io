92.2 CSRF Token

CSRF Token 防护机制

🎯 学习目标

  • 理解 CSRF Token 的工作原理
  • 掌握 Token 的生成和验证
  • 学会在 Express 中实现 CSRF 防护
  • 了解前后端配合方式

📚 CSRF Token 原理

# CSRF Token 工作原理 1. 用户访问网站，服务器生成 Token 2. Token 存储在 Session 或 Cookie 中 3. Token 发送给前端，嵌入表单或请求头 4. 用户提交请求时携带 Token 5. 服务器验证 Token 是否匹配 6. 匹配则请求合法，否则拒绝 # 为什么 CSRF Token 有效 ## 攻击者无法获取 Token - Token 存储在目标网站 - 同源策略阻止跨域读取 - 攻击者无法在请求中携带正确的 Token ## Token 必须匹配 - 服务器存储的 Token 与请求中的必须一致 - 攻击者不知道正确的 Token 值 # Token 的特点 - 随机生成，不可预测 - 每个用户独立的 Token - 可以定期更换 - 与 Session 关联

🔧 Express 实现

# 安装 csrf 中间件 npm install csurf # 基本配置 import express from 'express'; import cookieParser from 'cookie-parser'; import csrf from 'csurf'; const app = express(); app.use(cookieParser()); // CSRF 保护 const csrfProtection = csrf({ cookie: true }); // 获取 CSRF Token app.get('/api/csrf-token', csrfProtection, (req, res) => { res.json({ csrfToken: req.csrfToken() }); }); // 受保护的路由 app.post('/api/transfer', csrfProtection, (req, res) => { // 如果 CSRF Token 无效，会自动拒绝 const { to, amount } = req.body; // 执行转账操作 res.json({ success: true }); }); # 使用 Session 存储 Token import session from 'express-session'; app.use(session({ secret: 'your-secret', resave: false, saveUninitialized: false, })); const csrfProtection = csrf({ session: true }); # 错误处理 app.use((err, req, res, next) => { if (err.code === 'EBADCSRFTOKEN') { return res.status(403).json({ error: 'Invalid CSRF token', }); } next(err); });
💡
Token 位置

Token 可以存储在 Session 或 Cookie 中。Cookie 方式不需要 Session 支持，但需要确保 Cookie 安全。

⚙️ 前端集成

# 方式一：表单隐藏字段 // 服务端渲染表单 app.get('/form', csrfProtection, (req, res) => { res.send(` <form action="/transfer" method="POST"> <input type="hidden" name="_csrf" value="${req.csrfToken()}"> <input name="to" placeholder="收款人"> <input name="amount" placeholder="金额"> <button>转账</button> </form> `); }); # 方式二：请求头 // 前端获取 Token async function getCsrfToken() { const response = await fetch('/api/csrf-token'); const data = await response.json(); return data.csrfToken; } // 发送请求时携带 Token async function transfer(to, amount) { const csrfToken = await getCsrfToken(); const response = await fetch('/api/transfer', { method: 'POST', headers: { 'Content-Type': 'application/json', 'X-CSRF-Token': csrfToken, // 自定义请求头 }, body: JSON.stringify({ to, amount }), }); return response.json(); } # 方式三：axios 拦截器 import axios from 'axios'; // 创建 axios 实例 const api = axios.create({ baseURL: '/api', }); // 获取并存储 CSRF Token let csrfToken = ''; async function initCsrfToken() { const response = await api.get('/csrf-token'); csrfToken = response.data.csrfToken; } // 请求拦截器 api.interceptors.request.use((config) => { if (['post', 'put', 'delete', 'patch'].includes(config.method || '')) { config.headers['X-CSRF-Token'] = csrfToken; } return config; }); // 初始化 initCsrfToken();

🚀 自定义 Token 验证

# 手动实现 CSRF Token 验证 import crypto from 'crypto'; // 生成 Token function generateCsrfToken(): string { return crypto.randomBytes(32).toString('hex'); } // 中间件：设置 CSRF Token app.use((req, res, next) => { if (!req.session.csrfToken) { req.session.csrfToken = generateCsrfToken(); } res.locals.csrfToken = req.session.csrfToken; next(); }); // 中间件：验证 CSRF Token function validateCsrfToken(req, res, next) { const token = req.body._csrf || req.headers['x-csrf-token'] || req.query._csrf; if (!token || token !== req.session.csrfToken) { return res.status(403).json({ error: 'Invalid CSRF token' }); } next(); } // 暴露 Token 接口 app.get('/api/csrf-token', (req, res) => { res.json({ csrfToken: req.session.csrfToken }); }); // 保护路由 app.post('/api/transfer', validateCsrfToken, (req, res) => { // 执行操作 }); # Token 轮换（增强安全性） app.post('/api/transfer', validateCsrfToken, (req, res) => { // 操作完成后轮换 Token req.session.csrfToken = generateCsrfToken(); // 执行操作 });

📝 本节小结

✅
  • • CSRF Token 是最有效的 CSRF 防护方式
  • • Token 存储在服务端，随请求发送
  • • 攻击者无法获取正确的 Token
  • • 可以通过表单字段或请求头传递
