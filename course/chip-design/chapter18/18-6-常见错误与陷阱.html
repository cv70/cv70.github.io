18.6 常见错误与陷阱

HDL 编码最佳实践

🎯 学习目标

  • 识别常见的编码错误
  • 理解阻塞与非阻塞的区别
  • 学会避免锁存器推断
  • 能够调试常见问题

⚠️ 常见错误

// ❌ 错误1：在组合逻辑中使用非阻塞赋值
always @(*) begin
    a <= b;  // 错误！应该用 =
end

// ❌ 错误2：不完整的case导致锁存器
always @(*) begin
    case (sel)
        2'b00: y = a;
        2'b01: y = b;
        // 缺少default和其他分支
    endcase
end

// ✅ 正确：完整的case
always @(*) begin
    case (sel)
        2'b00: y = a;
        2'b01: y = b;
        2'b10: y = c;
        2'b11: y = d;
        default: y = 0;
    endcase
end

🔍 时序逻辑错误

// ❌ 错误：在时序逻辑中使用阻塞赋值
always @(posedge clk) begin
    q0 = d;    // 错误！应该用 <=
    q1 = q0;   // q1得到d的值，不是q0的旧值
end

// ✅ 正确：使用非阻塞赋值
always @(posedge clk) begin
    q0 <= d;   // 正确
    q1 <= q0;  // q1得到q0的旧值
end

📝 本节小结

✅
  • • 组合逻辑用阻塞赋值
  • • 时序逻辑用非阻塞赋值
  • • 确保case/if语句完整
  • • 注意信号位宽匹配
