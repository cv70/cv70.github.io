🏢 Triton Inference Server

NVIDIA Triton简介

Triton是NVIDIA开发的高性能推理服务框架，支持多种后端和框架。

核心特性

  • 多后端支持：TensorRT、ONNX、PyTorch、TensorFlow
  • 动态批处理：自动批处理优化
  • 模型仓库：统一模型管理
  • 版本管理：支持多版本模型
  • 自定义后端：C++/Python自定义算子
  • 性能分析：内置profiling工具

适用场景

  • 企业级推理服务
  • 多模型统一管理
  • 高并发在线推理
  • GPU集群部署
  • 需要版本管理
  • 复杂推理流水线

🤖 TGI（Text Generation Inference）

Hugging Face TGI简介

TGI是Hugging Face推出的LLM推理服务框架，专为文本生成优化。

核心特性

  • Flash Attention：加速注意力计算
  • Paged Attention：优化KV Cache
  • 量化支持：INT8/INT4量化
  • 流式输出：实时生成token
  • OpenAI兼容：标准API接口
  • 动态批处理：连续批处理

适用场景

  • 大语言模型推理
  • 对话系统
  • 文本生成服务
  • 聊天机器人
  • OpenAI API迁移
  • 流式生成需求

⚡ vLLM

vLLM推理服务

vLLM不仅是一个推理引擎，也提供了完整的推理服务功能。

核心特性

  • PagedAttention：核心创新技术
  • Inflight Batching：连续批处理
  • 高吞吐：24倍性能提升
  • 低延迟：优化的TTFT
  • OpenAI API：兼容接口
  • 多GPU支持：张量并行

适用场景

  • LLM推理服务
  • 高并发场景
  • 长序列生成
  • 多GPU部署
  • 需要极致性能
  • 成本敏感场景

# Triton服务部署示例
"""

  │   └── 1/
  │       └── model.plan  # TensorRT引擎
  └── model-bert/
      ├── config.pbtxt
      └── 1/
          └── model.onnx   # ONNX模型
"""

# config.pbtxt示例
triton_config = """
name: "model-resnet50"
platform: "tensorrt_plan"
max_batch_size: 8
input [
  {
    name: "input"
    data_type: TYPE_FP32
    dims: [ 3, 224, 224 ]
  }
]
output [
  {
    name: "output"
    data_type: TYPE_FP32
    dims: [ 1000 ]
  }

instance_group [
  {
    kind: KIND_GPU
    count: 1
    gpus: [ 0 ]
  }

dynamic_batching {
  max_queue_delay_microseconds: 1000

# TGI部署示例
def deploy_tgi():
    """
    使用TGI部署LLM服务
    """
    import subprocess

    # 启动TGI服务
    cmd = [
        "text-generation-launcher",
        "--model-name", "meta-llama/Llama-2-7b-hf",
        "--num-shard", "4",  # 4个GPU
        "--max-total-tokens", "4096",
        "--max-batch-total-tokens", "8192",
        "--quantize", "awq",  # 量化
        "--port", "8080",
    ]

    subprocess.run(cmd)

# 使用TGI API
def use_tgi_api():
    """
    调用TGI API
    """
    import requests

    # 生成文本
    response = requests.post(
        "http://localhost:8080/generate",
        json={
            "inputs": "写一个Python函数",
            "parameters": {
                "max_new_tokens": 100,
                "temperature": 0.8,
            }
        }
    )

    print(response.json())

# vLLM服务部署示例
def deploy_vllm():
    """
    使用vLLM部署LLM服务
    """
    from vllm.entrypoints.api_server import serve

    # 启动vLLM服务
    serve(
        model="meta-llama/Llama-2-7b-hf",
        tensor_parallel_size=4,
        gpu_memory_utilization=0.9,
        max_model_len=4096,
        host="0.0.0.0",
        port=8000,
    )

# 使用vLLM API
def use_vllm_api():
    """
    调用vLLM API（OpenAI兼容）
    """
    from openai import OpenAI

    client = OpenAI(
        base_url="http://localhost:8000/v1",
        api_key="not-needed"
    )

    # 生成文本
    completion = client.chat.completions.create(
        model="meta-llama/Llama-2-7b-hf",
        messages=[
            {"role": "user", "content": "写一个Python函数"}
        ],
        temperature=0.8,
        max_tokens=100,
    )

    print(completion.choices[0].message.content)

# 流式生成示例
def stream_generation():
    """
    流式生成
    """
    from openai import OpenAI

    client = OpenAI(
        base_url="http://localhost:8000/v1",
        api_key="not-needed"
    )

    # 流式生成
    stream = client.chat.completions.create(
        model="meta-llama/Llama-2-7b-hf",
        messages=[{"role": "user", "content": "解释什么是深度学习"}],
        stream=True,
    )

    for chunk in stream:
        if chunk.choices[0].delta.content:
            print(chunk.choices[0].delta.content, end="", flush=True)

    print()

# 健康检查和监控
def health_check():
    """
    健康检查
    """
    import requests

    # TGI健康检查
    response = requests.get("http://localhost:8080/health")

    response = requests.get("http://localhost:8000/health")
    print(f"vLLM Health: {response.status_code}")

    # 获取模型信息
    response = requests.get("http://localhost:8000/v1/models")
    print(f"Models: {response.json()}")

推理服务框架选择建议
  • 企业级、多模型统一管理选Triton
  • LLM专用服务选TGI或vLLM
  • 需要极致性能选vLLM
  • 需要OpenAI兼容API选TGI或vLLM
  • 微服务架构选Ray Serve
