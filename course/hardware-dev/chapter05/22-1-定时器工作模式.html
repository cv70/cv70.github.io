定时器工作模式

定时器是MCU中非常重要的外设，用于实现精确的时间控制和事件计数。 定时器广泛应用于PWM生成、输入捕获、输出比较、编码器接口等功能。本节将深入讲解定时器的工作模式。

⚙️ 定时器基本原理

定时器组成

计数器（Counter）

核心计数单元，向上或向下计数。位数决定计数范围，如16位定时器可计数0-65535。

预分频器（Prescaler）

对时钟进行分频，调节计数速度。分频比可配置，如1、2、4、8...65536。

自动重装载（ARR）

设定计数周期，计数到ARR后自动复位。ARR决定定时周期。

📊 定时器工作模式

模式 计数方式 特点 应用场景
向上计数 0 → ARR 计数到ARR溢出产生更新事件 定时中断、PWM输出
向下计数 ARR → 0 计数到0下溢产生更新事件 倒计时、精确延迟
中心对齐 0 → ARR → 0 对称计数，产生上下溢事件 互补PWM、电机控制

🔧 定时时间计算

定时周期计算公式

定时周期计算：

T = (ARR + 1) × (Prescaler + 1) / Tclk

其中：T为定时周期，Tclk为定时器时钟频率

定时频率计算：

f = Tclk / [(ARR + 1) × (Prescaler + 1)]

配置示例：

系统时钟72MHz，Prescaler=71，ARR=999

定时器时钟 = 72MHz / 72 = 1MHz

定时周期 = (999+1) × 1μs = 1000μs = 1ms

📐 定时器功能模块

比较输出通道

每个定时器有多个比较通道（CCR），当计数值等于CCR时触发事件。可用于PWM输出、单次脉冲输出等。

输入捕获通道

捕获外部信号跳变时的计数值。可用于测量脉宽、频率、周期等参数。

编码器接口

正交编码器输入模式，自动识别A/B相信号和方向。用于电机位置和速度测量。

触发与从控

定时器可以相互触发，实现多路PWM同步、级联计数等功能。支持内部触发和外部触发。

✨
最佳实践

定时器配置建议：1）根据需要选择合适的定时器类型（通用、高级、基本）；2）预分频和重装载值的配置要满足精度要求；3）注意定时器时钟源和分频配置；4）使用中断或DMA处理定时器事件；5）多路PWM输出注意相位同步；6）编码器接口模式适合电机控制应用。
