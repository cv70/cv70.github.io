61.1 Resolver 编写

GraphQL Resolver 详解

📖 Resolver 概述

Resolver 是 GraphQL 中处理每个字段请求的函数，负责从数据源获取数据并返回给客户端。每个字段都可以有一个对应的 Resolver。

💡
Resolver 的作用
  • 处理字段请求
  • 从数据库或 API 获取数据
  • 处理业务逻辑
  • 实现数据关联

📝 Resolver 函数签名

// Resolver 函数签名 fieldName(parent, args, context, info) => result // 参数说明 const resolvers = { Query: { user: ( parent: any, // 父级字段的返回值 args: { // 查询参数 id: string; }, context: { // 共享上下文 dataSources: any; user: User; }, info: GraphQLResolveInfo // 查询信息 ) => { return { id: '1', name: '张三' }; }, }, };

参数详解

参数 类型 说明
parent any 父级字段的返回值，Query 类型为 undefined
args object 查询中传递的参数对象
context object 所有 Resolver 共享的上下文对象
info GraphQLResolveInfo 包含查询 AST、字段信息等

🔧 基础 Resolver

// Schema type Query { user(id: ID!): User users: [User!]! } type Mutation { createUser(name: String!, email: String!): User! } type User { id: ID! name: String! email: String! } // Resolvers const resolvers = { Query: { // 获取单个用户 user: async (_parent, { id }, context) => { return context.prisma.user.findUnique({ where: { id: parseInt(id) }, }); }, // 获取所有用户 users: async (_parent, _args, context) => { return context.prisma.user.findMany(); }, }, Mutation: { // 创建用户 createUser: async (_parent, { name, email }, context) => { return context.prisma.user.create({ data: { name, email }, }); }, }, };

📦 字段 Resolver

// Schema type User { id: ID! name: String! email: String! posts: [Post!]! // 关联字段 postCount: Int! // 计算字段 } type Post { id: ID! title: String! author: User! // 关联字段 } // Resolvers const resolvers = { User: { // 关联查询：用户的文章 posts: async (parent, _args, context) => { // parent 是 User 对象 return context.prisma.post.findMany({ where: { authorId: parent.id }, }); }, // 计算字段：文章数量 postCount: async (parent, _args, context) => { return context.prisma.post.count({ where: { authorId: parent.id }, }); }, }, Post: { // 关联查询：文章作者 author: async (parent, _args, context) => { return context.prisma.user.findUnique({ where: { id: parent.authorId }, }); }, }, };

⚙️ Context 配置

import { PrismaClient } from '@prisma/client'; const prisma = new PrismaClient(); // 定义 Context 类型 interface Context { prisma: PrismaClient; user?: { id: number; role: string }; dataSources: { userApi: UserAPI; postApi: PostAPI; }; } // 配置 Context const server = new ApolloServer({ typeDefs, resolvers, }); const { url } = await startStandaloneServer(server, { context: async ({ req, res }) => ({ prisma, user: await getUserFromToken(req.headers.authorization), dataSources: { userApi: new UserAPI(), postApi: new PostAPI(), }, }), });

🔄 默认 Resolver

// 如果没有定义 Resolver，GraphQL 使用默认行为 // 默认返回 parent[fieldName] type User { id: ID! // 自动返回 parent.id name: String! // 自动返回 parent.name email: String! // 自动返回 parent.email } // 只有复杂字段需要显式定义 Resolver const resolvers = { User: { // 只定义需要特殊处理的字段 posts: async (parent, _args, context) => { return context.prisma.post.findMany({ where: { authorId: parent.id }, }); }, }, };

📊 Resolver 链

GraphQL 按照查询结构依次执行 Resolver，形成 Resolver 链。

// 查询 query { user(id: "1") { // 1. 执行 Query.user name posts { // 2. 执行 User.posts title comments { // 3. 执行 Post.comments content author { // 4. 执行 Comment.author name } } } } } // 执行顺序 // 1. Query.user(parent=undefined, args={id:"1"}, ...) // 返回: { id: "1", name: "张三", ... } // 2. User.posts(parent={id:"1", name:"张三",...}, ...) // 返回: [{ id: "p1", title: "文章1", ... }] // 3. Post.comments(parent={id:"p1",...}, ...) // 返回: [{ id: "c1", content: "评论1", ... }] // 4. Comment.author(parent={id:"c1",...}, ...) // 返回: { id: "2", name: "李四" }

💻 完整示例

import { ApolloServer } from '@apollo/server'; import { startStandaloneServer } from '@apollo/server/standalone'; import { PrismaClient } from '@prisma/client'; const prisma = new PrismaClient(); const typeDefs = `#graphql type User { id: ID! name: String! email: String! posts: [Post!]! postCount: Int! } type Post { id: ID! title: String! content: String author: User! comments: [Comment!]! } type Comment { id: ID! content: String! author: User! } type Query { user(id: ID!): User users: [User!]! post(id: ID!): Post posts(limit: Int = 10): [Post!]! } type Mutation { createUser(name: String!, email: String!): User! createPost(title: String!, content: String, authorId: ID!): Post! } `; const resolvers = { Query: { user: async (_, { id }, context) => { return context.prisma.user.findUnique({ where: { id: parseInt(id) }, }); }, users: async (_, __, context) => { return context.prisma.user.findMany(); }, post: async (_, { id }, context) => { return context.prisma.post.findUnique({ where: { id: parseInt(id) }, }); }, posts: async (_, { limit }, context) => { return context.prisma.post.findMany({ take: limit }); }, }, Mutation: { createUser: async (_, { name, email }, context) => { return context.prisma.user.create({ data: { name, email }, }); }, createPost: async (_, { title, content, authorId }, context) => { return context.prisma.post.create({ data: { title, content, authorId: parseInt(authorId) }, }); }, }, User: { posts: async (parent, _, context) => { return context.prisma.post.findMany({ where: { authorId: parent.id }, }); }, postCount: async (parent, _, context) => { return context.prisma.post.count({ where: { authorId: parent.id }, }); }, }, Post: { author: async (parent, _, context) => { return context.prisma.user.findUnique({ where: { id: parent.authorId }, }); }, comments: async (parent, _, context) => { return context.prisma.comment.findMany({ where: { postId: parent.id }, }); }, }, }; const server = new ApolloServer({ typeDefs, resolvers }); await startStandaloneServer(server, { context: async () => ({ prisma }), });

📝 小结

  • Resolver 是处理字段请求的函数
  • 四个参数：parent、args、context、info
  • Context 用于共享数据
  • 字段 Resolver 处理关联和计算字段
  • 默认 Resolver 返回 parent[fieldName]
  • Resolver 链按查询结构顺序执行
