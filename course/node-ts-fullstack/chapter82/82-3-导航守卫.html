82.3 导航守卫

路由导航的控制与拦截

📖 本节概述

导航守卫是 Vue Router 提供的路由拦截机制，用于在路由跳转前后执行特定逻辑，如权限验证、登录检查、页面标题设置等。

🎯 学习目标

  • 理解导航守卫的执行流程
  • 掌握全局前置/后置守卫的使用
  • 学会路由独享守卫和组件内守卫
  • 掌握权限控制的实现方式

📋 守卫类型

守卫类型 位置 用途
全局前置守卫 router.beforeEach 权限验证、登录检查
全局解析守卫 router.beforeResolve 确保所有守卫完成
全局后置钩子 router.afterEach 分析、更新标题
路由独享守卫 路由配置 beforeEnter 特定路由的守卫
组件内守卫 组件内 beforeRouteEnter 等 组件级别的路由控制

🌐 全局前置守卫

import { createRouter } from 'vue-router'; import type { NavigationGuardNext, RouteLocationNormalized } from 'vue-router'; const router = createRouter({ /* ... */ }); router.beforeEach(( to: RouteLocationNormalized, from: RouteLocationNormalized, next: NavigationGuardNext ) => { // to: 即将进入的目标路由 // from: 当前导航正要离开的路由 // next: 必须调用该方法来 resolve 这个钩子 const isAuthenticated = localStorage.getItem('token'); // 需要认证的页面 if (to.meta.requiresAuth && !isAuthenticated) { // 重定向到登录页 next({ path: '/login', query: { redirect: to.fullPath } }); } else { // 放行 next(); } });

返回值方式

router.beforeEach(async (to, from) => { // 返回 false 取消导航 if (to.path === '/blocked') { return false; } // 返回路由地址重定向 if (!isAuthenticated && to.meta.requiresAuth) { return { path: '/login', query: { redirect: to.fullPath } }; } // 返回 undefined 或 true 继续导航 return true; });

🔐 权限控制实现

import { useUserStore } from '@/stores/user'; // 白名单路由 const whiteList = ['/login', '/register', '/forgot-password']; router.beforeEach(async (to, from) => { // 设置页面标题 document.title = (to.meta.title as string) || 'My App'; const userStore = useUserStore(); const token = localStorage.getItem('token'); // 有 token if (token) { if (to.path === '/login') { // 已登录，跳转到首页 return { path: '/' }; } // 检查用户信息是否已加载 if (!userStore.userInfo) { try { // 获取用户信息 await userStore.fetchUserInfo(); // 检查权限 const roles = userStore.roles; const requiredRoles = to.meta.roles as string[] | undefined; if (requiredRoles && !requiredRoles.some(role => roles.includes(role))) { // 无权限 return { path: '/403' }; } } catch (error) { // Token 无效 userStore.logout(); return { path: '/login', query: { redirect: to.fullPath } }; } } return true; } else { // 无 token if (whiteList.includes(to.path)) { return true; } return { path: '/login', query: { redirect: to.fullPath } }; } });

✅ 全局后置钩子

router.afterEach((to, from) => { // to: 即将进入的路由 // from: 离开的路由 // 设置页面标题 document.title = (to.meta.title as string) || 'My App'; // 滚动到顶部 window.scrollTo(0, 0); // 发送页面访问统计 analytics.trackPageView(to.fullPath); }); // 带错误处理的后置钩子 router.afterEach((to, from, failure) => { if (failure) { console.log('导航失败:', failure); } });

const routes = [ { path: '/admin', name: 'Admin', component: Admin, beforeEnter: (to, from) => { const isAdmin = localStorage.getItem('role') === 'admin'; if (!isAdmin) { return { path: '/403' }; } } }, { path: '/user/:id', name: 'UserDetail', component: UserDetail, beforeEnter: [ // 可以使用数组 checkAuth, checkUserExists ] } ]; // 复用守卫函数 function checkAuth(to, from) { const token = localStorage.getItem('token'); if (!token) { return { path: '/login' }; } } async function checkUserExists(to) { const exists = await checkUser(to.params.id); if (!exists) { return { path: '/404' }; } }

🧩 组件内守卫

import { defineComponent } from 'vue'; export default defineComponent({ // 在渲染该组件的对应路由被验证前调用 // 不能获取组件实例 this，因为当守卫执行时，组件实例还没被创建 beforeRouteEnter(to, from, next) { // 通过回调访问组件实例 next(vm => { vm.loadData(); }); }, // 在当前路由改变，但是该组件被复用时调用 // 比如从 /users/1 导航到 /users/2 beforeRouteUpdate(to, from, next) { this.loadData(); next(); }, // 在导航离开该组件的对应路由时调用 beforeRouteLeave(to, from, next) { const answer = window.confirm('确定要离开吗？未保存的数据将丢失。'); if (answer) { next(); } else { next(false); } } });

Composition API 中使用

<script setup lang="ts"> import { onBeforeRouteLeave, onBeforeRouteUpdate } from 'vue-router'; // 离开守卫 onBeforeRouteLeave((to, from, next) => { if (hasUnsavedChanges.value) { const confirmed = confirm('有未保存的更改，确定要离开吗？'); if (!confirmed) return false; } next(); }); // 更新守卫 onBeforeRouteUpdate((to, from, next) => { if (to.params.id !== from.params.id) { loadUserData(to.params.id as string); } next(); }); </script>

📊 守卫执行流程

  1. 触发导航
  2. 调用失活组件的 beforeRouteLeave
  3. 调用全局 beforeEach
  4. 重用组件调用 beforeRouteUpdate
  5. 路由配置中的 beforeEnter
  6. 解析异步路由组件
  7. 激活组件的 beforeRouteEnter
  8. 调用全局 beforeResolve
  9. 导航确认
  10. 调用全局 afterEach
  11. DOM 更新后调用 beforeRouteEnter 的 next 回调

📝 本节小结

  • 导航守卫用于控制路由跳转的流程
  • 全局前置守卫常用于权限验证
  • 全局后置钩子用于页面标题、分析等
  • 路由独享守卫用于特定路由的控制
  • 组件内守卫用于组件级别的路由控制
