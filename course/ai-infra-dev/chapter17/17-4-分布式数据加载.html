分布式数据加载概述

在分布式训练中，数据需要被正确地分配到不同的GPU上。 使用DistributedSampler可以确保每个GPU处理不同的数据子集， 同时保持数据的随机性和均衡性。高效的数据加载对训练性能至关重要。

📊 DistributedSampler原理

数据采样机制

DistributedSampler工作原理： 1. 数据划分 • 将整个数据集分成num_replicas个子集 • 每个rank处理一个子集 • 子集大小 = ceil(total_size / num_replicas) 2. 索引分配 总数据集：[0, 1, 2, ..., 9999] (10000个样本) world_size = 4 Rank 0: [0, 4, 8, ..., 9996] (2500个样本) Rank 1: [1, 5, 9, ..., 9997] (2500个样本) Rank 2: [2, 6, 10, ..., 9998] (2500个样本) Rank 3: [3, 7, 11, ..., 9999] (2500个样本) 3. 随机打乱 • 每个epoch打乱数据顺序 • 使用set_epoch()确保每个epoch打乱不同 • 保持数据的随机性 4. 数据完整性 • 所有rank处理的数据并集 = 完整数据集 • 没有重复，也没有遗漏 • 确保训练数据的一致性 关键特性： • 自动处理数据划分 • 支持drop_last（丢弃不完整batch） • 支持shuffle（随机打乱） • 与DataLoader无缝集成

💻 基本使用

DistributedSampler示例

import torch from torch.utils.data import Dataset, DataLoader from torch.utils.data.distributed import DistributedSampler import torch.distributed as dist class SimpleDataset(Dataset): def __init__(self, size=10000): self.size = size self.data = list(range(size)) def __len__(self): return self.size def __getitem__(self, idx): return self.data[idx] def create_dataloader(batch_size=32, shuffle=True): # 创建数据集 dataset = SimpleDataset(size=10000) # 创建分布式采样器 sampler = DistributedSampler( dataset, num_replicas=dist.get_world_size(), # 总进程数 rank=dist.get_rank(), # 当前进程rank shuffle=shuffle, # 是否随机打乱 drop_last=False # 是否丢弃最后一个不完整batch ) # 创建数据加载器 dataloader = DataLoader( dataset, batch_size=batch_size, sampler=sampler, # 使用分布式采样器 num_workers=4, # 数据加载worker数 pin_memory=True # 锁页内存，加速数据传输 ) return dataloader, sampler def train(rank, world_size): # 初始化分布式环境 dist.init_process_group(backend='nccl') torch.cuda.set_device(rank) # 创建数据加载器 dataloader, sampler = create_dataloader(batch_size=32, shuffle=True) # 训练循环 for epoch in range(10): # 重要：每个epoch都要设置epoch，确保数据打乱不同 sampler.set_epoch(epoch) for batch_idx, data in enumerate(dataloader): # 处理数据 data = data.cuda() # ... if rank == 0 and batch_idx % 100 == 0: print(f'Epoch {epoch}, Batch {batch_idx}') # 清理 dist.destroy_process_group()

⚡ 性能优化

DataLoader优化

  • num_workers：设置为CPU核心数，通常4-8
  • pin_memory：True加速数据传输到GPU
  • prefetch_factor：预取因子，默认2
  • persistent_workers：保持worker活跃
优化配置示例： dataloader = DataLoader( dataset, batch_size=batch_size, sampler=sampler, num_workers=8, # 根据CPU核心数设置 pin_memory=True, # 加速GPU传输 prefetch_factor=2, # 预取2个batch persistent_workers=True # 保持worker )

数据预处理优化

  • 在线预处理：使用DataLoader的transform
  • 离线预处理：提前处理并保存
  • 缓存数据：缓存常用数据到内存
  • 批量处理：使用Vectorized操作
预处理优化示例： from torchvision import transforms transform = transforms.Compose([ transforms.Resize(256), transforms.CenterCrop(224), transforms.ToTensor(), transforms.Normalize( mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225] ) ]) dataset = ImageFolder( 'path/to/data', transform=transform # 在DataLoader中应用 )

⚠️ 常见问题

问题与解决方案

问题 原因 解决方案
数据重复 忘记设置sampler 必须指定sampler参数
数据不随机 忘记调用set_epoch() 每个epoch调用set_epoch()
数据量不同 drop_last=False且数据集大小不能整除 使用drop_last=True
加载慢 num_workers太少 增加num_workers到4-8
显存不足 数据预处理在GPU上 将预处理移到CPU
