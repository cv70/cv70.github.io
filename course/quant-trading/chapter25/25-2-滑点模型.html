滑点模型

滑点模型是量化交易开发中的重要内容。本节将深入探讨滑点模型的相关知识和实践方法。

💻 滑点模型实现

Backtrader滑点设置

import backtrader as bt

# 固定滑点
class FixedSlipper(bt.Slipper):
    params = (('slip', 0.001),)
    
    def _getslip(self, order, price, dt):
        return price * self.p.slip

# 比例滑点
# 使用cerebro.broker.set_slippage_perc(perc=0.001)

🏗️ 核心内容

📉

固定滑点

每笔交易固定滑点金额或比例

📊

比例滑点

按成交额一定比例的滑点

📈

动态滑点

根据市场条件变化的滑点

🔧 滑点模型对比

滑点类型 优点 缺点
固定滑点简单易用不够精确高频策略研究
比例滑点更贴近实际仍可能偏差中低频策略
真实滑点最准确计算复杂实盘回放
⚠️
注意事项

滑点是回测中最容易被低估的成本。建议在回测中使用保守的滑点假设，特别是对于高频策略。实盘前务必进行小资金验证，了解真实滑点水平。
