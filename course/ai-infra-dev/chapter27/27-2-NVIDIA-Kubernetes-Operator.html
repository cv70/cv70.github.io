GPU Operator概述

NVIDIA GPU Operator是Kubernetes上完整的GPU管理解决方案，自动安装和管理NVIDIA驱动、 容器运行时、设备插件、监控组件等。通过声明式API简化GPU集群的部署和运维。

📦 安装GPU Operator

前提条件

# 系统要求 - Kubernetes 1.23+ - Ubuntu 20.04+ / RHEL 8+ - NVIDIA GPU硬件 - 节点内核头文件 - 容器运行时（containerd推荐）
⚠️
重要提示

确保节点已卸载预装的NVIDIA驱动，GPU Operator会自动管理驱动版本。

Helm安装

# 添加NVIDIA Helm仓库 helm repo add nvidia https://nvidia.github.io/gpu-operator helm repo update # 创建命名空间 kubectl create namespace gpu-operator # 安装GPU Operator helm install --wait --generate-name \ nvidia/gpu-operator \ --namespace gpu-operator \ --set driver.enabled=true \ --set toolkit.enabled=true # 查看安装状态 kubectl get pods -n gpu-operator kubectl get crd | grep nvidia

自定义配置

# 使用values文件定制安装 cat > gpu-operator-values.yaml << 'EOF' driver: enabled: true repoConfig: destinations: - type: "base" destination: "/etc/apt/sources.list.d/nvidia.list" overwrite: true - type: "cuda" destination: "/etc/apt/sources.list.d/cuda.list" overwrite: true version: "535.129.03" toolkit: enabled: true version: "1.14.3" devicePlugin: enabled: true version: "v0.14.0" dcgmExporter: enabled: true migManager: enabled: true migStrategy: single gfd: enabled: true node-feature-discovery: enabled: true EOF helm install gpu-operator nvidia/gpu-operator \ --namespace gpu-operator \ --values gpu-operator-values.yaml

🔧 驱动管理

多驱动支持

# 支持多版本驱动共存 apiVersion: nvidia.com/v1 kind: ClusterPolicy metadata: name: gpu-cluster-policy spec: driver: enabled: true # 使用Repository配置驱动源 repositoryConfig: name: "nvidia-drivers" # 多驱动版本 version: "535.129.03" # 自动升级策略 upgradePolicy: autoUpgrade: true drain: enabled: true timeoutSeconds: 300

节点标签管理

# 查看自动生成的节点标签 kubectl get nodes --show-labels | grep nvidia # 标签示例： # nvidia.com/gpu.count=8 # nvidia.com/gpu.product=A100-SXM4-80GB # nvidia.com/gpu.memory=80 # nvidia.com/gpu.computeCapability=8.0 # 使用标签选择GPU节点 kubectl label nodes gpu-type=high-performance

📊 DCGM监控

DCGM简介

DCGM（Data Center GPU Manager）是NVIDIA提供的企业级GPU监控和管理套件， 提供GPU性能指标收集、健康检查、配置管理等功能。

启用DCGM Exporter

# GPU Operator默认启用DCGM Exporter # 查看DCGM Exporter Pod kubectl get pods -n gpu-operator -l app=nvidia-dcgm-exporter # 端口转发查看指标 kubectl port-forward -n gpu-operator 9400:9400 # 访问指标 curl http://localhost:9400/metrics

关键指标

# GPU利用率 DCGM_FI_DEV_GPU_UTIL # 显存使用 DCGM_FI_DEV_FB_USED DCGM_FI_DEV_FB_TOTAL # 温度 DCGM_FI_DEV_GPU_TEMP # 功耗 DCGM_FI_DEV_POWER_USAGE # PCIe带宽 DCGM_FI_DEV_PCIE_RX_BYTES DCGM_FI_DEV_PCIE_TX_BYTES # ECC错误 DCGM_FI_DEV_ECC_SBE_VOL_TOTAL DCGM_FI_DEV_ECC_DBE_VOL_TOTAL

Prometheus集成

apiVersion: v1 kind: Service metadata: name: nvidia-dcgm-exporter namespace: gpu-operator labels: app: nvidia-dcgm-exporter spec: ports: - name: metrics port: 9400 protocol: TCP targetPort: 9400 selector: app: nvidia-dcgm-exporter type: ClusterIP --- apiVersion: monitoring.coreos.com/v1 kind: ServiceMonitor metadata: name: nvidia-dcgm-exporter namespace: gpu-operator labels: app: nvidia-dcgm-exporter spec: selector: matchLabels: app: nvidia-dcgm-exporter endpoints: - port: metrics interval: 15s

🎛️ MIG管理

MIG（Multi-Instance GPU）

MIG将单个GPU分割成多个隔离的实例，每个实例拥有独立的GPU资源。 适用于多个小规模工作负载共享GPU的场景。

MIG配置

# 配置MIG策略 apiVersion: nvidia.com/v1 kind: ClusterPolicy metadata: name: gpu-cluster-policy spec: migManager: enabled: true # single: 所有GPU使用相同MIG配置 # mixed: 部分GPU使用MIG，部分完整 # none: 禁用MIG migStrategy: single

MIG设备配置

# 创建MIG配置 apiVersion: nvidia.com/v1 kind: MigDevice metadata: name: a100-1g-5gb spec: migProfile: "1g.5gb" # 1个实例，5GB显存 parentGPU: "0"
✅
MIG优势
  • • 提高GPU资源利用率
  • • 硬件级隔离，安全可靠
  • • 支持多个工作负载并行
  • • 降低推理成本

🔄 升级与维护

驱动升级

# 升级GPU Operator helm upgrade gpu-operator nvidia/gpu-operator \ --namespace gpu-operator \ --values gpu-operator-values.yaml \ --reuse-values # 滚动升级（需要驱逐节点） kubectl annotate node \ nvidia.com/driver.upgrade=auto

故障恢复

# 重启GPU组件 kubectl delete pod -n gpu-operator -l app=nvidia-driver-daemonset kubectl delete pod -n gpu-operator -l app=nvidia-device-plugin-ds # 查看组件日志 kubectl logs -n gpu-operator -l app=nvidia-driver-daemonset --tail=100 kubectl logs -n gpu-operator -l app=nvidia-device-plugin-ds --tail=100
