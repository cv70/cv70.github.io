14.3 SPI时钟极性与相位

第14章 SPI总线

🎯 学习目标

  • 理解SPI的四种工作模式
  • 掌握时钟极性(CPOL)和时钟相位(CPHA)的定义
  • 能够根据芯片数据手册正确配置SPI模式
  • 了解不同模式的时序特点与应用场景

SPI时钟模式概述

SPI共有四种工作模式，由时钟极性(CPOL)和时钟相位(CPHA)两个参数决定。 CPOL决定时钟空闲时的电平状态，CPHA决定数据在时钟的哪个边沿采样。 主从设备必须配置相同的模式才能正确通信，配置错误会导致数据错乱。

💡 时钟模式解析

🎓

Why - 为什么重要

模式不匹配会导致通信失败，必须正确配置

🚀

What - 核心参数

CPOL(时钟极性)、CPHA(时钟相位)

🏗️

How - 如何配置

查阅芯片手册，配置MCU的SPI寄存器

⚙️ SPI四种工作模式

模式 CPOL CPHA 时钟空闲电平 数据采样边沿 数据变化边沿
Mode 0 0 0 低电平 第一个上升沿 第一个下降沿
Mode 1 0 1 低电平 第二个下降沿 第二个上升沿
Mode 2 1 0 高电平 第一个下降沿 第一个上升沿
Mode 3 1 1 高电平 第二个上升沿 第二个下降沿

📊 模式选择指南

模式 时序特点 典型设备 注意事项
Mode 0 上升沿采样 大多数SPI Flash 最常用的模式
Mode 1 下降沿采样 部分传感器 较少使用
Mode 2 下降沿采样 部分SD卡 空闲电平为高
Mode 3 上升沿采样 部分DAC 空闲电平为高
✨
最佳实践

配置步骤：(1)查阅芯片数据手册，确定设备支持的SPI模式；(2)配置MCU的CPOL和CPHA参数； (3)用逻辑分析仪抓取波形验证时序；(4)若通信失败，尝试切换到其他模式测试。

⚠️
注意事项

CPOL=0表示时钟空闲时为低电平，CPOL=1表示时钟空闲时为高电平。 CPHA=0表示在时钟的第一个边沿采样，CPHA=1表示在时钟的第二个边沿采样。 主从设备必须配置完全一致才能正常通信。

📝 本节小结

✅
  • • SPI有4种工作模式，由CPOL(时钟极性)和CPHA(时钟相位)决定
  • • CPOL决定时钟空闲时的电平(0=低电平，1=高电平)
  • • CPHA决定数据采样边沿(0=第一边沿，1=第二边沿)
  • • 主从设备必须配置相同的SPI模式才能正确通信
