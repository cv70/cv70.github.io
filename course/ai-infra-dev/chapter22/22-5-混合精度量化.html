什么是混合精度量化

混合精度量化是指在同一模型中使用不同精度的参数。 通过对不同层、不同权重和激活使用不同的量化精度，可以在保持精度的同时最大化压缩效果。

🎭 混合精度类型

权重混合精度

  • 方法：不同层使用不同比特数
  • 策略：敏感层高精度，非敏感层低精度
  • 优势：平衡精度和压缩
  • 挑战：需要确定敏感度

激活混合精度

  • 方法：不同激活使用不同精度
  • 策略：根据激活范围动态选择
  • 优势：减少内存带宽
  • 挑战：需要动态处理

逐通道混合

  • 方法：同层不同通道不同精度
  • 策略：重要通道高精度
  • 优势：更细粒度控制
  • 挑战：实现复杂

逐层混合

  • 方法：不同层整体不同精度
  • 策略：首尾层高精度，中间层低精度
  • 优势：实现相对简单
  • 挑战：粒度较粗

💻 混合精度量化实现

import torch
import torch.nn as nn
from transformers import AutoModelForCausalLM, BitsAndBytesConfig

# 使用BitsAndBytes进行混合精度量化
def quantize_llm(model_name, load_in_4bit=True, load_in_8bit=False):
    """
    量化LLM模型
    """
    # 配置量化
    bnb_config = BitsAndBytesConfig(
        load_in_4bit=load_in_4bit,
        load_in_8bit=load_in_8bit,
        bnb_4bit_compute_dtype=torch.float16,  # 计算用FP16
        bnb_4bit_use_double_quant=True,      # 双重量化
        bnb_4bit_quant_type="nf4"             # NF4量化类型
    )

    # 加载量化模型
    model = AutoModelForCausalLM.from_pretrained(
        model_name,
        quantization_config=bnb_config,
        device_map="auto"
    )

    return model

# 分层量化示例
from torch.ao.quantization import (
    get_default_qconfig,
    prepare,
    convert
)

def layerwise_quantize(model):
    """
    逐层不同精度量化
    """
    # 第一层：高精度
    model.layer1.qconfig = get_default_qconfig('fbgemm')
    model.layer1.qconfig.weight.qscheme = torch.per_channel_symmetric

    # 中间层：标准精度
    for i in range(2, len(model.layers) - 1):
        model.layers[i].qconfig = get_default_qconfig('fbgemm')

    # 最后一层：高精度
    model.layer_last.qconfig = get_default_qconfig('fbgemm')

    # 准备和转换
    model = prepare(model)
    # 使用校准数据进行校准
    # calibrate_model(model, calibration_data)
    model = convert(model)

    return model

# 动态量化
from torch.ao.quantization import quantize_dynamic

def dynamic_quantize(model):
    """
    动态量化（权重静态量化，激活动态量化）
    """
    quantized_model = quantize_dynamic(
        model,
        {nn.Linear, nn.LSTM},  # 要量化的层
        dtype=torch.qint8
    )
    return quantized_model

# 使用示例
# 量化LLM
model = quantize_llm("meta-llama/Llama-2-7b-hf",
                    load_in_4bit=True)

# 计算模型大小
def count_parameters(model):
    return sum(p.numel() for p in model.parameters())

print(f"量化后参数量: {count_parameters(model) / 1e9:.2f}B")

📈 量化精度权衡

配置 模型大小 精度损失 推理速度 适用场景
FP32 100% 0% 1x 基准
FP16 50% <1% 1.5x 训练/推理
INT8 25% 1-2% 2-4x 通用推理
INT4 (混合) 15% 2-3% 4-8x LLM推理
INT4 (纯) 12.5% 5-10% 6-10x 边缘推理
💡
混合精度量化建议
  • 对LLM使用专门的量化方法（GPTQ/AWQ）
  • 第一层和最后一层保持较高精度
  • INT4量化建议结合校准和微调
  • 实际部署前务必测试精度和性能
