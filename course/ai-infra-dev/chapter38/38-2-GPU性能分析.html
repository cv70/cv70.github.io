NVIDIA Nsight工具

Nsight工具集是NVIDIA提供的GPU性能分析工具，包括Nsight Systems和Nsight Compute。

🛠️ Nsight工具对比

工具 用途 分析粒度 开销
Nsight Systems 系统级分析 函数/API级别 低
Nsight Compute Kernel级分析 指令级别 高
Nsight Graphics 图形应用分析 Draw call级别 中等

📊 Nsight Systems使用

# Nsight Systems安装 # 下载地址: https://developer.nvidia.com/nsight-systems # 基本使用命令 nsys profile --output=profile.nsys-rep python train.py # 常用选项 nsys profile \ --output=profile.nsys-rep \ # 输出文件 --trace=cuda,nvtx \ # 追踪CUDA和NVTX --force-overwrite=true \ # 覆盖已存在文件 --cuda-memory-usage=true \ # 追踪CUDA内存使用 --sample=cpu \ # CPU采样 --python-backtrace=none \ # Python backtrace --cudabacktrace=true \ # CUDA backtrace python train.py # 指定GPU nsys profile --output=profile.nsys-rep \ --gpu=0,1 \ python train.py # 设置采样间隔 nsys profile --output=profile.nsys-rep \ --sample=cpu:1000000 \ # CPU采样1ms --sampling-frequency=1000000 \ # 1kHz python train.py # 长时间训练分析 nsys profile --output=profile.nsys-rep \ --duration=10 \ # 采集10秒 --capture-range=nvtx \ # 按NVTX标记采集 python train.py

🔍 Nsight Compute使用

# Nsight Compute安装 # 下载地址: https://developer.nvidia.com/nsight-compute # 基本使用命令 ncu --set=full python train.py # 常用选项 ncu \ --export=report.ncu-rep \ # 导出报告 --set=detailed \ # 详细模式 --metrics all \ # 收集所有指标 --demangles \ # 符号解码 --launch-count=10 \ # 启动10次kernel --pagebuffer=1 \ # 页面缓冲 python train.py # 指定kernel分析 ncu --kernel-name "attention_forward" python train.py # 指定GPU ncu --gpu=0,1 python train.py # 只分析指定kernel ncu --kernel-id=1 python train.py # 生成HTML报告 ncu --export=report.ncu-rep \ --target-processes all \ python train.py

📈 GPU性能指标解读

计算性能指标

  • SM占用率 - Streaming Multiprocessor利用率
  • FP32吞吐 - 单精度浮点性能
  • FP16吞吐 - 半精度浮点性能
  • INT8吞吐 - 整数运算性能
  • Tensor Core利用率 - 矩阵运算效率

内存性能指标

  • 显存带宽 - Memory bandwidth usage
  • L1缓存命中 - L1 cache hit rate
  • L2缓存命中 - L2 cache hit rate
  • 共享内存使用 - Shared memory usage
  • 寄存器使用 - Register usage

🎯 GPU瓶颈识别

💡
常见GPU瓶颈

通过Nsight工具可以识别以下类型的GPU瓶颈：

# GPU瓶颈识别指南 ## 1. 内存受限（Memory Bound） 特征: - Memory bandwidth > 80% - Compute throughput < 50% - High L1/L2 cache miss rate 解决方案: - 优化内存访问模式 - 增加缓存利用率 - 使用共享内存 - 合并内存访问 ## 2. 计算受限（Compute Bound） 特征: - Memory bandwidth < 50% - Compute throughput > 80% - High instruction issue rate 解决方案: - 优化指令选择 - 使用Tensor Core - 增加计算强度 - 利用向量化指令 ## 3. 延迟受限（Latency Bound） 特征: - Low occupancy - High synchronization - Frequent memory access 解决方案: - 增加block数量 - 优化线程块配置 - 减少同步 - 使用异步操作 ## 4. 通信受限（Communication Bound） 特征: - High PCIe/NVLink usage - Frequent host-device transfer - Long kernel launch time 解决方案: - 减少数据传输 - 使用CUDA streams - Pinned memory - Batch transfers

🔧 GPU性能优化技巧

# GPU性能优化示例 ## 1. 优化内存访问 # 不好的做法：非合并访问 for i in range(n): data[i] = array[i * stride] # 好的做法：合并访问 for i in range(n): data[i] = array[i] ## 2. 使用共享内存 # CUDA kernel优化 __global__ void optimized_kernel(float* input, float* output) { __shared__ float s_data[BLOCK_SIZE]; int tid = threadIdx.x; int bid = blockIdx.x; // 加载到共享内存 s_data[tid] = input[bid * BLOCK_SIZE + tid]; __syncthreads(); // 使用共享内存计算 output[bid * BLOCK_SIZE + tid] = process(s_data[tid]); } ## 3. 使用Tensor Core # PyTorch中启用自动混合精度 from torch.cuda.amp import autocast, GradScaler model = MyModel().cuda() optimizer = torch.optim.Adam(model.parameters()) scaler = GradScaler() for batch in dataloader: optimizer.zero_grad() with autocast(): output = model(batch) loss = criterion(output, target) scaler.scale(loss).backward() scaler.step(optimizer) scaler.update() ## 4. 优化批处理 # 动态批大小 dynamic_batch_size = min(max_batch_size, available_memory // memory_per_sample)

📊 PyTorch集成性能分析

import torch import torch.profiler as profiler # 使用PyTorch Profiler model = MyModel().cuda() optimizer = torch.optim.Adam(model.parameters()) with profiler.profile( activities=[ profiler.ProfilerActivity.CPU, profiler.ProfilerActivity.CUDA, ], schedule=profiler.profiler_schedule( wait=1, warmup=1, active=3, repeat=2 ), on_trace_ready=profiler.tensorboard_trace_handler('./log'), record_shapes=True, profile_memory=True, with_stack=True ) as prof: for step, batch in enumerate(dataloader): if step >= (1 + 1 + 3) * 2: break loss = model(batch) loss.backward() optimizer.step() # 查看关键kernel print(prof.key_averages().table(sort_by="cuda_time_total")) # 查看内存使用 print(prof.key_averages().table(sort_by="self_cuda_memory_usage")) # 导出Chrome Trace prof.export_chrome_trace("trace.json")

🎯 性能分析工作流
