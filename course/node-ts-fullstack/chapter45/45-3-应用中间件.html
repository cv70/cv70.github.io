45.3 应用中间件

配置中间件的作用范围

🎯 学习目标

  • 掌握中间件的路由配置
  • 学会排除特定路由
  • 了解路由对象配置
  • 掌握模块级中间件配置

📚 基本配置

import { Module, NestModule, MiddlewareConsumer } from '@nestjs/common'; import { LoggerMiddleware } from './common/middleware/logger.middleware'; @Module({}) export class AppModule implements NestModule { configure(consumer: MiddlewareConsumer) { consumer .apply(LoggerMiddleware) .forRoutes('users'); // 应用到 /users 路由 } }

🔧 路由配置方式

import { RequestMethod } from '@nestjs/common'; @Module({}) export class AppModule implements NestModule { configure(consumer: MiddlewareConsumer) { // 1. 字符串路径 consumer.apply(LoggerMiddleware) .forRoutes('users'); // 2. 多个路径 consumer.apply(LoggerMiddleware) .forRoutes('users', 'products', 'orders'); // 3. 所有路由 consumer.apply(LoggerMiddleware) .forRoutes('*'); // 4. 指定 HTTP 方法 consumer.apply(LoggerMiddleware) .forRoutes({ path: 'users', method: RequestMethod.GET, }); // 5. 多个路由配置 consumer.apply(LoggerMiddleware) .forRoutes( { path: 'users', method: RequestMethod.GET }, { path: 'users/:id', method: RequestMethod.GET }, { path: 'products', method: RequestMethod.ALL }, ); } }
💡
路由配置说明

forRoutes 支持字符串路径、路由对象、通配符 '*'。RequestMethod 包括 GET, POST, PUT, DELETE, PATCH, ALL 等。

🚫 排除路由

@Module({}) export class AppModule implements NestModule { configure(consumer: MiddlewareConsumer) { consumer .apply(AuthMiddleware) .exclude( 'auth/login', 'auth/register', 'auth/refresh', { path: 'health', method: RequestMethod.GET }, ) .forRoutes('*'); } } // 排除的路由不会经过中间件 // /auth/login - 不应用中间件 // /users - 应用中间件

📦 模块级中间件

// users.module.ts @Module({ controllers: [UsersController], providers: [UsersService], }) export class UsersModule implements NestModule { configure(consumer: MiddlewareConsumer) { // 只在 UsersModule 的路由上应用 consumer .apply(UsersLoggerMiddleware) .forRoutes(UsersController); // 使用控制器类 // 或者指定路由 consumer .apply(UsersAuthMiddleware) .forRoutes('users'); } } // 使用控制器类作为参数，会自动应用到该控制器的所有路由

🔄 链式配置

@Module({}) export class AppModule implements NestModule { configure(consumer: MiddlewareConsumer) { // 为不同路由配置不同中间件 consumer .apply(LoggerMiddleware) .forRoutes('*') .apply(AuthMiddleware) .exclude('auth/*') .forRoutes('*') .apply(AdminMiddleware) .forRoutes('admin/*'); } }
⚠️
配置注意

中间件配置是顺序执行的，后面的配置会在前面配置的基础上叠加。确保配置逻辑清晰，避免重复应用。

📝 本节小结

✅
  • • forRoutes() 指定中间件作用的路由
  • • exclude() 排除特定路由
  • • 可以使用控制器类作为路由参数
  • • 支持链式配置多个中间件
