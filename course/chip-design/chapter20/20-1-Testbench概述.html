什么是Testbench

Testbench（测试平台）是用于验证设计正确性的Verilog代码模块。它产生激励信号驱动待测设计（DUT），并检查DUT的输出是否符合预期。

🔄 Testbench工作流程

📥

激励生成

产生输入信号

⚙️

DUT执行

待测设计处理

📤

响应捕获

收集输出信号

✓

结果检查

验证正确性

💻 简单Testbench示例

// DUT：二选一多路选择器
module mux2to1 (
    input  wire a,
    input  wire b,
    input  wire sel,
    output wire y
);

assign y = sel ? b : a;

endmodule

// Testbench
module tb_mux2to1;

// 信号声明
reg  a, b, sel;
wire y;

// 实例化DUT
mux2to1 u_dut (
    .a(a),
    .b(b),
    .sel(sel),
    .y(y)
);

// 产生激励
initial begin
    // 初始化
    a = 0; b = 0; sel = 0;

    // 测试用例1
    #10 a = 1; b = 0; sel = 0;
    if (y !== 1) $display("Error: Case 1 failed");

    // 测试用例2
    #10 a = 0; b = 1; sel = 1;
    if (y !== 1) $display("Error: Case 2 failed");

    $display("Test completed");
    $finish;
end

endmodule

📋 Testbench组成要素

要素 描述 示例
信号声明 定义输入输出信号 reg, wire
DUT实例化 连接待测设计 module_name u_dut (...)
激励生成 产生输入信号 initial块
响应检查 验证输出正确性 if, assert
时钟生成 产生时钟信号 always块
💡
设计建议

良好的Testbench应该具有自检能力，能够自动判断测试通过或失败，而不是依赖人工查看波形。使用$display和$monitor输出关键信息有助于调试。

📝 本节小结

✅
  • • Testbench是验证设计正确性的测试平台
  • • Testbench包括激励生成、DUT连接和响应检查
  • • 使用initial块产生时序激励
  • • 好的Testbench应该具有自动检查能力
