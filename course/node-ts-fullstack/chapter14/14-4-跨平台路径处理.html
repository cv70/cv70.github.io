14.4 跨平台路径处理

编写兼容 Windows 和 Unix 的代码

🎯 学习目标

  • 理解 Windows 和 Unix 路径差异
  • 掌握 path.win32 和 path.posix
  • 学会编写跨平台代码
  • 了解常见跨平台问题

📚 平台差异

// Windows 和 Unix 路径的主要差异 // 1. 分隔符 // Windows: \ (反斜杠) // Unix: / (斜杠) // Windows 路径示例 'C:\\Users\\Admin\\Documents\\file.txt' // Unix 路径示例 '/home/user/docs/file.txt' // 2. 根目录 // Windows: C:\, D:\ 等盘符 // Unix: / (单一根目录) // 3. PATH 分隔符 // Windows: ; // Unix: : // 4. 大小写敏感 // Windows: 不敏感 (File.txt = file.txt) // Unix: 敏感 (File.txt != file.txt) // 查看当前平台的值 const path = require('path'); console.log('分隔符:', path.sep); console.log('PATH 分隔符:', path.delimiter); console.log('当前平台:', process.platform);

🔧 path.win32 和 path.posix

const path = require('path'); // path 默认使用当前平台的方法 // path.win32 强制使用 Windows 方法 // path.posix 强制使用 Unix 方法 // 在任何平台上使用 Windows 路径 const winPath = path.win32.join('C:\\Users', 'Admin', 'Documents'); console.log(winPath); // 'C:\\Users\\Admin\\Documents' console.log(path.win32.sep); // '\\' console.log(path.win32.delimiter); // ';' console.log(path.win32.parse('C:\\Users\\file.txt')); // { root: 'C:\\', dir: 'C:\\Users', base: 'file.txt', ... } // 在任何平台上使用 Unix 路径 const posixPath = path.posix.join('/home', 'user', 'docs'); console.log(posixPath); // '/home/user/docs' console.log(path.posix.sep); // '/' console.log(path.posix.delimiter); // ':' console.log(path.posix.parse('/home/user/file.txt')); // { root: '/', dir: '/home/user', base: 'file.txt', ... } // 强制解析 URL 路径（总是用 POSIX） const urlPath = path.posix.join('assets', 'images', 'logo.png'); console.log(urlPath); // 'assets/images/logo.png'

📦 跨平台最佳实践

const path = require('path'); const fs = require('fs'); // ❌ 错误：硬编码路径分隔符 const wrongPath = 'src' + '/' + 'components' + '/' + 'Button.js'; // ✅ 正确：使用 path.join const rightPath = path.join('src', 'components', 'Button.js'); // ❌ 错误：硬编码 PATH 分隔符 const wrongPaths = '/usr/bin:/usr/local/bin'; // ✅ 正确：使用 path.delimiter const rightPaths = `/usr/bin${path.delimiter}/usr/local/bin`; // ❌ 错误：假设盘符 const wrongConfig = 'C:\\config\\app.json'; // ✅ 正确：使用相对路径或 __dirname const rightConfig = path.join(__dirname, 'config', 'app.json'); // ❌ 错误：拆分路径使用固定分隔符 const wrongParts = filePath.split('/'); // ✅ 正确：使用 path.sep 或 path 方法 const rightParts = filePath.split(path.sep); // ✅ 正确：使用 path.parse 解析 const { dir, base } = path.parse(filePath);

⚙️ 实用工具函数

const path = require('path'); // 1. 安全路径拼接 function safePath(...segments) { return path.join(...segments); } // 2. 获取项目根目录 function getProjectRoot() { return path.resolve(__dirname, '..'); } // 3. 跨平台路径转 URL 路径 function pathToUrl(filePath) { return filePath.split(path.sep).join('/'); } console.log(pathToUrl(path.join('assets', 'images', 'logo.png'))); // 'assets/images/logo.png' // 4. URL 路径转系统路径 function urlToPath(urlPath) { return urlPath.split('/').join(path.sep); } // 5. 规范化用户输入路径 function normalizeUserPath(userPath) { // 处理 ~（仅 Unix） if (userPath.startsWith('~')) { const os = require('os'); userPath = path.join(os.homedir(), userPath.slice(1)); } // 转换为绝对路径 return path.resolve(userPath); } // 6. 路径比较（跨平台） function areSamePath(path1, path2) { return path.resolve(path1) === path.resolve(path2); } // Windows 还需要考虑大小写 function areSamePathCrossPlatform(path1, path2) { const p1 = path.resolve(path1); const p2 = path.resolve(path2); if (process.platform === 'win32') { return p1.toLowerCase() === p2.toLowerCase(); } return p1 === p2; }

⚠️ 常见陷阱

⚠️
  • • 不要假设路径分隔符是 / 或 \
  • • 不要假设绝对路径以 / 开头（Windows 有盘符）
  • • 注意文件名大小写敏感性差异
  • • URL 路径总是用 /，使用 path.posix 处理
  • • 避免在路径中存储用户敏感信息

📝 本节小结

✅
  • • Windows 使用 \ 分隔符，Unix 使用 /
  • • path.win32 和 path.posix 强制使用特定平台方法
  • • 始终使用 path.join 等方法拼接路径
  • • URL 路径使用 path.posix 或手动处理
