15.4 Transformer完整架构

深度理解Transformer的设计精髓

🎯 学习目标

  • 理解Transformer的整体架构设计
  • 掌握编码器和解码器的结构
  • 理解残差连接和层归一化的作用
  • 能够实现完整的Transformer模型

Transformer概述

Transformer是Google在2017年论文"Attention is All You Need"中提出的革命性架构。 它完全抛弃了循环和卷积结构，仅依靠注意力机制实现序列建模，在机器翻译任务上取得了SOTA效果， 并成为BERT、GPT等现代大语言模型的基础架构。

🏗️ Transformer架构组成

编码器（Encoder）

  • 6个相同的编码器层堆叠
  • 每层包含：多头自注意力 + 前馈网络
  • 残差连接 + 层归一化
  • 输入：词嵌入 + 位置编码

解码器（Decoder）

  • 6个相同的解码器层堆叠
  • 每层包含：掩码自注意力 + 交叉注意力 + 前馈网络
  • 掩码确保只看到之前的位置
  • 交叉注意力连接编码器输出

📐 编码器层实现

class EncoderLayer(nn.Module): def __init__(self, d_model, num_heads, d_ff, dropout=0.1): super().__init__() # 多头自注意力 self.self_attn = MultiHeadAttention(d_model, num_heads) # 前馈网络 self.ffn = nn.Sequential( nn.Linear(d_model, d_ff), nn.ReLU(), nn.Linear(d_ff, d_model) ) # 层归一化 self.norm1 = nn.LayerNorm(d_model) self.norm2 = nn.LayerNorm(d_model) # Dropout self.dropout = nn.Dropout(dropout) def forward(self, x, mask=None): # 多头注意力 + 残差 + LayerNorm attn_out, _ = self.self_attn(x, mask) x = self.norm1(x + self.dropout(attn_out)) # 前馈网络 + 残差 + LayerNorm ffn_out = self.ffn(x) x = self.norm2(x + self.dropout(ffn_out)) return x

📐 解码器层实现

class DecoderLayer(nn.Module): def __init__(self, d_model, num_heads, d_ff, dropout=0.1): super().__init__() # 掩码自注意力 self.self_attn = MultiHeadAttention(d_model, num_heads) # 交叉注意力 self.cross_attn = MultiHeadAttention(d_model, num_heads) # 前馈网络 self.ffn = nn.Sequential( nn.Linear(d_model, d_ff), nn.ReLU(), nn.Linear(d_ff, d_model) ) # 层归一化 self.norm1 = nn.LayerNorm(d_model) self.norm2 = nn.LayerNorm(d_model) self.norm3 = nn.LayerNorm(d_model) self.dropout = nn.Dropout(dropout) def forward(self, x, enc_output, tgt_mask, src_mask): # 掩码自注意力 attn_out, _ = self.self_attn(x, tgt_mask) x = self.norm1(x + self.dropout(attn_out)) # 交叉注意力（Query来自解码器，K/V来自编码器） cross_out, _ = self.cross_attn(x, enc_output, enc_output, src_mask) x = self.norm2(x + self.dropout(cross_out)) # 前馈网络 ffn_out = self.ffn(x) x = self.norm3(x + self.dropout(ffn_out)) return x

⚖️ Transformer vs RNN架构对比

特性 RNN/LSTM Transformer
并行化 难以并行（顺序计算） 完全并行
长距离依赖 需要多步传递 一步直达（O(1)）
计算复杂度 O(n·d²) O(n²·d)
路径长度 O(n) O(1)
训练速度 较慢 显著更快
可扩展性 有限 优秀（支持超大模型）

🔧 关键设计：残差与归一化

残差连接（Residual）

解决深层网络退化问题

# 残差连接公式 output = LayerNorm(x + Sublayer(x)) # 优势： # 1. 梯度直通，缓解梯度消失 # 2. 允许跳过某些层 # 3. 便于训练深层网络

层归一化（LayerNorm）

稳定训练过程

# LayerNorm vs BatchNorm # BatchNorm：在batch维度归一化 # LayerNorm：在特征维度归一化 # Transformer使用LayerNorm # 因为序列长度可变，batch内不一致

📊 Transformer超参数配置

# 标准Transformer配置（base） d_model = 512 # 模型维度 d_ff = 2048 # 前馈网络维度 num_heads = 8 # 注意力头数 num_layers = 6 # 编码器/解码器层数 dropout = 0.1 # Dropout率 # Transformer Big配置 d_model = 1024 d_ff = 4096 num_heads = 16 num_layers = 6
💡
架构变体

Transformer有三种常见使用方式：Encoder-only（BERT，用于理解任务）、 Decoder-only（GPT，用于生成任务）、Encoder-Decoder（T5，用于序列到序列任务）。

📝 本节小结

✅
  • • Transformer由编码器和解码器组成
  • • 每层包含注意力、前馈网络、残差和归一化
  • • 残差连接解决梯度消失，LayerNorm稳定训练
  • • 完全并行化是其相比RNN的核心优势
