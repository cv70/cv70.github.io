75.6 条件渲染

根据条件显示不同内容

🎯 学习目标

  • 掌握 if 条件渲染
  • 学会使用 && 运算符
  • 理解三元运算符的应用
  • 了解列表渲染与 key

📚 if 条件渲染

// 方式1：使用 if 语句 function UserStatus({ isLoggedIn }) { if (isLoggedIn) { return <h1>Welcome back!</h1>; } return <h1>Please sign in.</h1>; } // 方式2：使用变量存储元素 function UserStatus({ isLoggedIn }) { let content; if (isLoggedIn) { content = <h1>Welcome back!</h1>; } else { content = <h1>Please sign in.</h1>; } return <div>{content}</div>; } // 方式3：提前返回 function UserList({ users }) { if (!users || users.length === 0) { return <p>No users found.</p>; } return ( <ul> {users.map(user => ( <li key={user.id}>{user.name}</li> ))} </ul> ); }

🔧 && 和 三元运算符

// && 运算符：条件为真时渲染 function Mailbox({ unreadMessages }) { return ( <div> <h1>Hello!</h1> {/* 仅当有未读消息时显示 */} {unreadMessages.length > 0 && ( <h2>You have {unreadMessages.length} unread messages.</h2> )} </div> ); } // 注意：0 会被渲染 // 错误示例 function List({ items }) { return ( <ul> {/* 如果 items 为空数组，会显示 0 */} {items.length && items.map(item => <li>{item}</li>)} </ul> ); } // 正确写法 function List({ items }) { return ( <ul> {items.length > 0 && items.map(item => <li>{item}</li>)} </ul> ); } // 三元运算符：二选一 function LoginButton({ isLoggedIn }) { return ( <button> {isLoggedIn ? 'Logout' : 'Login'} </button> ); } // 嵌套三元运算符（不推荐过多嵌套） function Status({ status }) { return ( <div> {status === 'loading' ? ( <p>Loading...</p> ) : status === 'error' ? ( <p>Error occurred!</p> ) : ( <p>Data loaded!</p> )} </div> ); }

📊 列表渲染

// 使用 map 渲染列表 function NumberList({ numbers }) { return ( <ul> {numbers.map((number) => ( <li key={number.toString()}>{number}</li> ))} </ul> ); } // key 的作用：帮助 React 识别元素变化 function TodoList({ todos }) { return ( <ul> {todos.map(todo => ( <li key={todo.id}> <input type="checkbox" checked={todo.completed} onChange={() => toggle(todo.id)} /> {todo.text} </li> ))} </ul> ); } // key 选择原则 // 1. 优先使用数据中的唯一标识（如 id） // 2. 避免使用索引作为 key（除非列表是静态的） // 3. key 只需要在兄弟节点中唯一 // 错误示例：使用索引作为 key function List({ items }) { return ( <ul> {/* 不推荐：如果列表会重新排序，会导致问题 */} {items.map((item, index) => ( <li key={index}>{item}</li> ))} </ul> ); } // 正确示例：使用唯一 id function List({ items }) { return ( <ul> {items.map(item => ( <li key={item.id}>{item.name}</li> ))} </ul> ); }

📝 本节小结

✅
  • • if 语句适合复杂条件逻辑
  • • && 运算符适合条件渲染单个元素
  • • 三元运算符适合二选一场景
  • • 列表渲染必须设置唯一的 key
