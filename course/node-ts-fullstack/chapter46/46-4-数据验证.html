46.4 数据验证

使用 class-validator 进行 DTO 验证

🎯 学习目标

  • 安装和配置 class-validator
  • 掌握常用验证装饰器
  • 学会自定义验证规则
  • 掌握 ValidationPipe 配置

📚 安装依赖

# 安装 class-validator 和 class-transformer npm install class-validator class-transformer

🔧 定义验证 DTO

// create-user.dto.ts import { IsString, IsEmail, IsInt, Min, Max, IsOptional, IsEnum, MinLength, MaxLength, Matches, IsDateString, IsBoolean, ValidateNested, } from 'class-validator'; import { Type } from 'class-transformer'; export class CreateAddressDto { @IsString() @MaxLength(100) city: string; @IsString() @MaxLength(200) street: string; @IsString() @Matches(/^[0-9]{6}$/) zipCode: string; } export class CreateUserDto { @IsString() @MinLength(2, { message: 'Name is too short' }) @MaxLength(50) name: string; @IsEmail({}, { message: 'Invalid email format' }) email: string; @IsString() @MinLength(8) @Matches(/((?=.*\d)|(?=.*\W+))(?![.\n])(?=.*[A-Z])(?=.*[a-z]).*$/, { message: 'Password too weak', }) password: string; @IsInt() @Min(0) @Max(150) age: number; @IsEnum(['admin', 'user', 'guest']) role: string; @IsOptional() @IsDateString() birthday?: string; @IsBoolean() isActive: boolean; @ValidateNested() @Type(() => CreateAddressDto) address: CreateAddressDto; }
💡
验证装饰器

class-validator 提供了丰富的验证装饰器，可以组合使用。message 选项可以自定义错误消息。

🌐 常用验证装饰器

装饰器 说明
@IsString() 验证字符串
@IsNumber() 验证数字
@IsInt() 验证整数
@IsEmail() 验证邮箱格式
@Min() / @Max() 最小/最大值
@MinLength() / @MaxLength() 最小/最大长度
@IsEnum() 验证枚举值
@Matches() 正则表达式验证
@IsOptional() 可选字段
@IsDateString() 验证日期字符串
@IsArray() 验证数组

⚙️ 配置 ValidationPipe

// main.ts import { ValidationPipe } from '@nestjs/common'; async function bootstrap() { const app = await NestFactory.create(AppModule); app.useGlobalPipes( new ValidationPipe({ whitelist: true, // 过滤非 DTO 定义的属性 forbidNonWhitelisted: true, // 有非定义属性时报错 transform: true, // 自动转换为 DTO 类型 transformOptions: { enableImplicitConversion: true, // 启用隐式类型转换 }, disableErrorMessages: false, // 生产环境可设为 true validationError: { target: false, // 不返回目标对象 value: false, // 不返回错误值 }, }), ); await app.listen(3000); } bootstrap();

✨ 自定义验证器

import { registerDecorator, ValidationOptions, ValidationArguments, } from 'class-validator'; // 自定义装饰器：验证密码确认 export function IsMatch(property: string, validationOptions?: ValidationOptions) { return function (object: Object, propertyName: string) { registerDecorator({ name: 'isMatch', target: object.constructor, propertyName: propertyName, constraints: [property], options: validationOptions, validator: { validate(value: any, args: ValidationArguments) { const [relatedPropertyName] = args.constraints; const relatedValue = (args.object as any)[relatedPropertyName]; return value === relatedValue; }, defaultMessage(args: ValidationArguments) { const [relatedPropertyName] = args.constraints; return `${propertyName} must match ${relatedPropertyName}`; }, }, }); }; } // 使用自定义验证器 export class RegisterDto { @IsString() password: string; @IsString() @IsMatch('password', { message: 'Passwords do not match' }) confirmPassword: string; }
⚠️
验证组

可以使用 groups 选项为不同场景定义不同的验证规则，例如创建和更新时使用不同的验证。
