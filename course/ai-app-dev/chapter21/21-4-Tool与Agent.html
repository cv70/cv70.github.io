Tool扩展LLM能力

Tool让LLM能够执行外部操作，如搜索网络、查询数据库、调用API等。 Agent根据用户输入自主决定调用哪些工具。

💻 创建自定义Tool

from langchain.tools import Tool from langchain.agents import initialize_agent # 定义工具函数 def search_web(query: str) -> str: return f"搜索结果: {query}" # 创建Tool tools = [ Tool( name="Search", func=search_web, description="搜索网络获取信息" ) ] # 创建Agent agent = initialize_agent(tools, llm, agent="zero-shot-react-description") result = agent.run("搜索最新的AI新闻")
💡
工具描述很重要

Agent根据工具描述决定何时调用哪个工具，描述需要清晰准确。
