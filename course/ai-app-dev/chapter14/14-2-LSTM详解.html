LSTM简介

长短期记忆网络（Long Short-Term Memory，LSTM）由Hochreiter和Schmidhuber于1997年提出， 是一种特殊的RNN架构，专门设计用于解决标准RNN的梯度消失问题。LSTM通过精巧的门控机制， 能够学习长期依赖关系，是自然语言处理领域最重要的突破之一。

🚪 LSTM的三个门控结构

🚫

遗忘门

决定从细胞状态中丢弃哪些信息

➕

输入门

决定哪些新信息将被存储

📤

输出门

决定输出什么信息

📐 LSTM的数学公式

# LSTM核心公式 # 1. 遗忘门：决定丢弃哪些信息 f = σ(Wf * [h, x] + bf) # 2. 输入门：决定存储哪些新信息 i = σ(Wi * [h, x] + bi) # 候选细胞状态 C̃ = tanh(WC * [h, x] + bC) # 3. 更新细胞状态 C = f * C + i * C̃ # 4. 输出门：决定输出值 o = σ(Wo * [h, x] + bo) h = o * tanh(C) # σ = sigmoid激活函数

💻 PyTorch实现LSTM

import torch import torch.nn as nn class LSTMModel(nn.Module): def __init__(self, vocab_size, embed_dim, hidden_dim, output_dim): super().__init__() self.embedding = nn.Embedding(vocab_size, embed_dim) self.lstm = nn.LSTM(embed_dim, hidden_dim, num_layers=2, batch_first=True, dropout=0.3, bidirectional=True) self.fc = nn.Linear(hidden_dim * 2, output_dim) self.dropout = nn.Dropout(0.5) def forward(self, text): # 词嵌入 embedded = self.dropout(self.embedding(text)) # LSTM处理 output, (hidden, cell) = self.lstm(embedded) # 拼接最后隐藏状态 hidden = torch.cat((hidden[-2, :, :], hidden[-1, :, :]), dim=1) return self.fc(self.dropout(hidden)) # 使用示例 model = LSTMModel(vocab_size=10000, embed_dim=128, hidden_dim=256, output_dim=2)

⚖️ LSTM vs 标准RNN对比

特性 标准RNN LSTM
记忆机制 单一隐藏状态 细胞状态 + 隐藏状态
门控结构 无 遗忘门、输入门、输出门
长距离依赖 效果差 效果好
梯度流动 容易消失 通过细胞状态保持
参数量 较少 约为RNN的4倍
训练速度 较快 相对较慢

🔧 LSTM的变体

Peephole LSTM

门控层可以"窥视"细胞状态

# 增加细胞状态到门控输入 f = σ(Wf * [C, h, x] + bf)

双向LSTM

同时考虑前向和后向信息

# PyTorch双向LSTM lstm = nn.LSTM(hidden_dim, hidden_dim, bidirectional=True)
💡
实践建议

在实际应用中，推荐使用双向LSTM处理文本任务，因为它能同时捕捉前后文信息。对于长文档，可以考虑使用多层LSTM增加模型表达能力。
