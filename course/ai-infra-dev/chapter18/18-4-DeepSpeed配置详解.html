DeepSpeed配置概述

DeepSpeed通过JSON配置文件控制训练行为。配置文件包含多个部分： 训练批次、优化器、ZeRO设置、混合精度、梯度累积、流水线并行等。 正确的配置是高效训练的关键，需要根据模型规模、硬件配置等仔细调优。

📋 配置文件结构

完整配置模板

{ // ========== 基本训练配置 ========== "train_batch_size": 32, "train_micro_batch_size_per_gpu": 1, "gradient_accumulation_steps": 1, // ========== 优化器配置 ========== "optimizer": { "type": "AdamW", "params": { "lr": 1e-4, "betas": [0.9, 0.999], "eps": 1e-8, "weight_decay": 0.01 } }, // ========== 学习率调度器 ========== "scheduler": { "type": "WarmupDecayLR", "params": { "total_num_steps": 100000, "warmup_min_lr": 0, "warmup_max_lr": 1e-4, "warmup_num_steps": 10000 } }, // ========== 混合精度 ========== "fp16": { "enabled": true, "loss_scale": 0, "initial_scale_power": 16, "loss_scale_window": 1000, "hysteresis": 2, "min_loss_scale": 1 }, // ========== BF16精度 ========== "bf16": { "enabled": false }, // ========== 梯度裁剪 ========== "gradient_clipping": 1.0, // ========== ZeRO优化 ========== "zero_optimization": { "stage": 2, "offload_optimizer": { "device": "none" }, "offload_param": { "device": "none" }, "overlap_comm": true, "contiguous_gradients": true, "sub_group_size": 1e9, "reduce_bucket_size": "auto", "stage3_prefetch_bucket_size": "auto", "stage3_param_persistence_threshold": "auto" }, // ========== 流水线并行 ========== "pipeline": { "enabled": false, "parallel_size": 1, "schedule": "1f1b", "activation_checkpointing": false }, // ========== 激活值检查点 ========== "activation_checkpointing": { "partition_activations": false, "cpu_checkpointing": false, "contiguous_memory_optimization": false, "number_checkpoints": null }, // ========== 分布式训练 ========== "communication_data_type": "fp16", "prescale_gradients": false, "postscale_gradients": false, // ========== 训练监控 ========== "steps_per_print": 10, "gradient_accumulation_steps": 1, "wall_clock_breakdown": false, // ========== 数据加载 ========== "data_efficiency": { "enabled": false, "data_sampling": null } }

🎯 批次配置

批次大小相关配置

参数 说明 计算公式
train_batch_size 全局批次大小 micro_batch_size × gradient_accumulation × num_gpus
train_micro_batch_size_per_gpu 每个GPU的微批次大小 通常1-16
gradient_accumulation_steps 梯度累积步数 train_batch_size / (micro_batch_size × num_gpus)
示例计算： 硬件：8 GPU 目标全局批次：512 每GPU微批次：4 gradient_accumulation_steps = 512 / (4 × 8) = 16 配置： { "train_batch_size": 512, "train_micro_batch_size_per_gpu": 4, "gradient_accumulation_steps": 16 } 效果： • 每个GPU处理4个样本 • 累积16步后更新参数 • 等效于每个GPU处理64个样本

⚡ 优化器配置

优化器类型与参数

优化器 类型 适用场景
AdamW AdamW Transformer模型
Adam Adam 通用场景
Lamb LAMB 大batch训练
SGD SGD CNN模型
AdamW配置示例： { "optimizer": { "type": "AdamW", "params": { "lr": 1e-4, // 学习率 "betas": [0.9, 0.999], // Adam beta参数 "eps": 1e-8, // 数值稳定性 "weight_decay": 0.01, // 权重衰减 "correct_bias": true // 偏差修正 } } } LAMB配置示例（大batch训练）： { "optimizer": { "type": "Lamb", "params": { "lr": 0.01, // LAMB需要较大的lr "betas": [0.9, 0.999], "eps": 1e-6, "weight_decay": 0.01 } } }

🎛️ ZeRO配置详解

ZeRO各阶段完整配置

ZeRO-1 配置： { "zero_optimization": { "stage": 1, "overlap_comm": true, "contiguous_gradients": true, "reduce_bucket_size": "auto", "allgather_bucket_size": "auto" } } ZeRO-2 配置： { "zero_optimization": { "stage": 2, "overlap_comm": true, "contiguous_gradients": true, "sub_group_size": 1e9, "reduce_bucket_size": "auto", "allgather_bucket_size": "auto", "offload_optimizer": { "device": "none" // 或 "cpu" 开启offload } } } ZeRO-3 配置： { "zero_optimization": { "stage": 3, "overlap_comm": true, "contiguous_gradients": true, "sub_group_size": 1e9, "reduce_bucket_size": "auto", "stage3_prefetch_bucket_size": "auto", "stage3_param_persistence_threshold": "auto", "stage3_max_live_parameters": 1e9, "stage3_max_reuse_distance": 1e9, "offload_optimizer": { "device": "cpu", "pin_memory": true }, "offload_param": { "device": "none" // 或 "cpu" 开启ZeRO-Infinity } } } 参数说明： • stage：ZeRO阶段（1/2/3） • overlap_comm：通信与计算重叠 • contiguous_gradients：使用连续梯度内存 • sub_group_size：子通信组大小（减少通信量） • reduce_bucket_size：梯度聚合桶大小 • stage3_prefetch_bucket_size：预取桶大小 • stage3_param_persistence_threshold： 参数持久化阈值（小参数常驻GPU） • stage3_max_live_parameters：最大活动参数数 • stage3_max_reuse_distance：最大重用距离
图：正确的DeepSpeed配置对训练性能至关重要

🔢 混合精度配置

FP16和BF16配置

精度 范围 优点 缺点
FP16 ±65504 速度快，广泛支持 容易溢出
BF16 ±3.3×10³⁸ 范围大，不易溢出 需要Ampere+ GPU
FP16配置： { "fp16": { "enabled": true, "loss_scale": 0, // 0表示动态loss scale "initial_scale_power": 16, // 初始scale = 2^16 = 65536 "loss_scale_window": 1000, // 成功步数窗口 "hysteresis": 2, // 下溢/上溢阈值 "min_loss_scale": 1 // 最小scale } } BF16配置（推荐Ampere+）： { "bf16": { "enabled": true } } 注意：BF16不需要loss scaling

🚀 场景化配置

不同场景的推荐配置

场景1：小模型，单卡训练 { "train_batch_size": 32, "train_micro_batch_size_per_gpu": 32, "gradient_accumulation_steps": 1, "fp16": {"enabled": true}, "zero_optimization": {"stage": 1} } 场景2：中等模型，多卡训练 { "train_batch_size": 256, "train_micro_batch_size_per_gpu": 8, "gradient_accumulation_steps": 4, "fp16": {"enabled": true}, "zero_optimization": {"stage": 2}, "gradient_clipping": 1.0 } 场景3：大模型，少GPU { "train_batch_size": 32, "train_micro_batch_size_per_gpu": 1, "gradient_accumulation_steps": 4, "bf16": {"enabled": true}, "zero_optimization": { "stage": 2, "offload_optimizer": {"device": "cpu"} } } 场景4：超大模型，多GPU { "train_batch_size": 512, "train_micro_batch_size_per_gpu": 1, "gradient_accumulation_steps": 16, "bf16": {"enabled": true}, "zero_optimization": { "stage": 3, "offload_param": {"device": "cpu"} }, "activation_checkpointing": { "partition_activations": true } } 场景5：超大模型，单GPU { "train_batch_size": 1, "train_micro_batch_size_per_gpu": 1, "gradient_accumulation_steps": 1, "bf16": {"enabled": true}, "zero_optimization": { "stage": 3, "offload_optimizer": {"device": "cpu"}, "offload_param": {"device": "nvme"} }, "activation_checkpointing": { "partition_activations": true, "cpu_checkpointing": true } }

🔧 高级配置

其他重要配置

流水线并行配置： { "pipeline": { "enabled": true, "parallel_size": 4, // 流水线阶段数 "schedule": "1f1b", // 调度策略 "activation_checkpointing": { "partition_activations": true } } } 激活值检查点： { "activation_checkpointing": { "partition_activations": false, "cpu_checkpointing": false, "contiguous_memory_optimization": false, "number_checkpoints": null } } 通信配置： { "communication_data_type": "fp16", // 或 "fp32" "prescale_gradients": false, "postscale_gradients": false } 训练监控： { "steps_per_print": 10, "wall_clock_breakdown": false, "dump_state": false }
💡
配置调优建议
  • batch size：从大开始，逐步减小到显存允许的最大值
  • learning rate：根据batch size线性缩放
  • ZeRO阶段：从stage 1开始，逐步升级
  • 混合精度：Ampere+优先使用BF16
  • 梯度累积：使用梯度累积模拟大batch

📝 本节小结

✅
  • • DeepSpeed配置文件包含训练、优化器、ZeRO等部分
  • • 批次配置需要考虑micro_batch和梯度累积
  • • ZeRO有3个阶段，显存节省逐步增加
  • • BF16优于FP16（如果硬件支持）
  • • 需要根据场景调优配置参数
