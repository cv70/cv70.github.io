📚 什么是 NestJS？

NestJS 是一个用于构建高效、可扩展的 Node.js 服务器端应用程序的框架。它使用渐进式 JavaScript，内置并完全支持 TypeScript，并结合了 OOP（面向对象编程）、FP（函数式编程）和 FRP（函数响应式编程）的元素。

# NestJS 核心特点 1. 完全支持 TypeScript 2. 模块化架构设计 3. 依赖注入系统 4. 内置 HTTP 服务器支持（Express/Fastify） 5. 强大的 CLI 工具 6. 丰富的生态系统
💡
框架起源

NestJS 由 Kamil Myśliwiec 创建，灵感来自 Angular 框架，借鉴了其模块化、依赖注入等核心概念，使后端开发更加规范和高效。

🔄 NestJS vs 其他框架

🔧 NestJS 应用场景

企业级应用

适合构建大型、复杂的企业级后端服务，模块化设计便于团队协作和代码维护。

RESTful API

快速构建规范的 REST API，支持控制器、路由、管道等完整功能。

GraphQL 服务

内置 GraphQL 支持，可以轻松构建 GraphQL API 服务。

微服务架构

支持多种微服务传输层，便于构建分布式系统。
