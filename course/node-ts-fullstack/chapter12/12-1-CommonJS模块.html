12.1 CommonJS 模块

Node.js 默认的模块系统

🎯 学习目标

  • 理解 CommonJS 模块规范
  • 掌握 module.exports 和 exports
  • 学会使用 require 导入模块
  • 了解模块加载顺序

📚 模块导出

// ========== math.js ========== // 方式一：导出单个值 module.exports = function add(a, b) { return a + b; }; // 方式二：导出对象 module.exports = { add: (a, b) => a + b, subtract: (a, b) => a - b, multiply: (a, b) => a * b, divide: (a, b) => a / b }; // 方式三：逐个添加属性 exports.add = (a, b) => a + b; exports.subtract = (a, b) => a - b; exports.PI = 3.14159; // 注意：exports 是 module.exports 的引用 // 不能直接给 exports 赋值！ // ❌ 错误：exports = { add: ... } // ✅ 正确：exports.add = ... 或 module.exports = { add: ... } // 方式四：导出类 class Calculator { constructor(initial = 0) { this.value = initial; } add(n) { this.value += n; return this; } subtract(n) { this.value -= n; return this; } getValue() { return this.value; } } module.exports = Calculator;

🔧 模块导入

// ========== app.js ========== // 导入自定义模块 const math = require('./math'); console.log(math.add(1, 2)); // 3 console.log(math.subtract(5, 3)); // 2 // 解构导入 const { add, multiply, PI } = require('./math'); console.log(add(10, 20)); // 30 console.log(PI); // 3.14159 // 导入类 const Calculator = require('./math'); const calc = new Calculator(100); calc.add(50).subtract(30); console.log(calc.getValue()); // 120 // 导入 Node.js 内置模块 const fs = require('fs'); const path = require('path'); const http = require('http'); // 导入 node_modules 中的模块 const express = require('express'); const lodash = require('lodash');
💡
路径规则

以 ./ 或 ../ 开头表示相对路径，不以 ./ 开头表示 node_modules 或内置模块。

⚙️ 模块缓存

// 模块第一次加载后会被缓存 // 后续 require 返回的是缓存对象 // ========== counter.js ========== let count = 0; module.exports = { increment: () => ++count, getCount: () => count }; // ========== app.js ========== const counter1 = require('./counter'); const counter2 = require('./counter'); // 返回缓存 counter1.increment(); // 1 counter1.increment(); // 2 counter2.increment(); // 3 (同一个对象) console.log(counter1.getCount()); // 3 console.log(counter2.getCount()); // 3 // 查看缓存 console.log(require.cache); // 清除缓存 delete require.cache[require.resolve('./counter')]; // 重新加载模块 const counter3 = require('./counter'); console.log(counter3.getCount()); // 0

📝 本节小结

✅
  • • CommonJS 使用 require 导入，module.exports 导出
  • • exports 是 module.exports 的引用
  • • 模块会被缓存，多次 require 返回同一对象
  • • ./ 表示相对路径，不带路径表示内置或 npm 包
