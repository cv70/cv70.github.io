22.1 MySQL 安装配置

搭建 MySQL 开发环境

🎯 学习目标

  • 掌握 MySQL 的安装方法
  • 学会基本配置和安全设置
  • 了解常用管理工具
  • 熟悉 Docker 方式部署

📚 Windows 安装

1. 下载 MySQL Installer 访问：https://dev.mysql.com/downloads/installer/ 选择：mysql-installer-community-x.x.x.msi 2. 安装步骤 ├── 选择安装类型：Developer Default ├── 检查依赖：Execute 安装缺失组件 ├── 配置类型：Development Computer ├── 设置 root 密码 └── 完成安装 3. 环境变量配置 将 MySQL bin 目录添加到 PATH： C:\Program Files\MySQL\MySQL Server 8.0\bin 4. 验证安装 mysql --version mysql -u root -p

🔧 Docker 部署（推荐）

# 拉取 MySQL 镜像 docker pull mysql:8.0 # 启动 MySQL 容器 docker run -d \ --name mysql-server \ -p 3306:3306 \ -e MYSQL_ROOT_PASSWORD=your_password \ -e MYSQL_DATABASE=myapp \ -v mysql_data:/var/lib/mysql \ mysql:8.0 # 连接到 MySQL 容器 docker exec -it mysql-server mysql -u root -p # 使用 Docker Compose # docker-compose.yml version: '3.8' services: mysql: image: mysql:8.0 container_name: mysql-server restart: always environment: MYSQL_ROOT_PASSWORD: root123 MYSQL_DATABASE: myapp MYSQL_USER: appuser MYSQL_PASSWORD: app123 ports: - "3306:3306" volumes: - mysql_data:/var/lib/mysql - ./init.sql:/docker-entrypoint-initdb.d/init.sql volumes: mysql_data:
💡
Docker 方式优势

使用 Docker 部署 MySQL 可以快速创建干净的开发环境，便于版本切换和多实例管理，推荐在开发环境使用。

⚙️ 基本配置

# my.cnf (Linux) 或 my.ini (Windows) [mysqld] # 服务器端口 port = 3306 # 字符集设置 character-set-server = utf8mb4 collation-server = utf8mb4_unicode_ci # 存储引擎 default-storage-engine = InnoDB # 最大连接数 max_connections = 200 # 缓冲池大小（建议物理内存的 70-80%） innodb_buffer_pool_size = 1G # 日志配置 slow_query_log = 1 slow_query_log_file = /var/log/mysql/slow.log long_query_time = 2 [client] default-character-set = utf8mb4 # 重启服务使配置生效 # Linux: systemctl restart mysql # Windows: net stop mysql && net start mysql

🖥️ 常用管理工具

命令行工具： ├── mysql # MySQL 客户端 ├── mysqldump # 数据库备份 ├── mysqladmin # 管理工具 └── mysqlcheck # 检查和修复表 图形化工具： ├── MySQL Workbench # 官方工具，功能全面 ├── DBeaver # 免费，支持多种数据库 ├── Navicat # 商业软件，功能强大 └── phpMyAdmin # Web 界面管理 VSCode 插件： ├── MySQL # jun han 开发 ├── SQLTools # 通用 SQL 工具 └── Database Client # 支持 MySQL 和 PostgreSQL
