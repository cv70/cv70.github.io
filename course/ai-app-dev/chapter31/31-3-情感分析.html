31.3 情感分析

理解文本背后的情感态度

🎯 学习目标

  • 理解情感分析的定义与应用价值
  • 掌握情感分析的不同层次与方法
  • 了解基于词典与基于机器学习的方法
  • 学会处理细粒度情感分析任务

什么是情感分析

情感分析（Sentiment Analysis）又称意见挖掘，是指利用自然语言处理技术对文本中的主观信息进行分析、提取和处理的过程。其核心目标是判断文本表达的情感倾向（正面、负面或中性）。

📊 情感分析应用场景

🛒

电商评论分析

分析用户对产品的评价与反馈

📱

舆情监控

实时监测社交媒体上的舆论动向

🎬

影视评论

预测电影口碑与票房表现

⚙️ 情感分析方法对比

方法 原理 优点 缺点
情感词典法 基于情感词库匹配 无需训练数据，可解释性强 难以处理上下文和新词
传统机器学习 SVM、朴素贝叶斯等 训练快速，资源需求低 需要特征工程
深度学习 LSTM、CNN、BERT等 自动特征学习，效果优 需要大量标注数据
大语言模型 GPT、Claude等 少样本学习能力强 推理成本高

💻 代码示例：情感分析实现

from transformers import pipeline

# 加载中文情感分析模型
sentiment_analyzer = pipeline(
    "sentiment-analysis",
    model="uer/roberta-base-finetuned-chinanews-chinese"
)

# 分析文本情感
texts = [
    "这款手机非常好用，电池续航时间长！",
    "服务态度太差了，不会再来了。",
    "今天天气一般，没什么特别的。"
]

for text in texts:
    result = sentiment_analyzer(text)[0]
    print(f"文本: {text}")
    print(f"情感: {result['label']}")
    print(f"置信度: {result['score']:.4f}")
    print("---")

🔬 情感分析层次

文档级情感分析

判断整篇文档的整体情感倾向

示例：影评整体评价 "这部电影太棒了！" → 正面情感

句子级情感分析

判断每个句子的情感倾向

示例：评论句子分析 "外观漂亮，但续航一般。" → 前半句正面 + 后半句负面

🎯 方面级情感分析(ABSA)

💡
细粒度分析

方面级情感分析（Aspect-Based Sentiment Analysis）是识别文本中针对特定方面的情感表达。例如："这家餐厅的菜品很好吃，但服务有待改进"，需要分别识别"菜品"正面、"服务"负面。
