83.5 持久化存储

状态持久化解决方案

📖 本节概述

默认情况下，Pinia 的状态存储在内存中，页面刷新后会丢失。本节将介绍如何使用插件实现状态持久化，将数据保存到 localStorage 或其他存储中。

🎯 学习目标

  • 理解状态持久化的必要性
  • 掌握使用 pinia-plugin-persistedstate 插件
  • 学会自定义持久化配置
  • 了解其他持久化方案

📦 安装插件

# 安装 pinia-plugin-persistedstate npm install pinia-plugin-persistedstate # 使用 yarn yarn add pinia-plugin-persistedstate # 使用 pnpm pnpm add pinia-plugin-persistedstate

注册插件

// main.ts import { createApp } from 'vue'; import { createPinia } from 'pinia'; import piniaPluginPersistedstate from 'pinia-plugin-persistedstate'; import App from './App.vue'; const app = createApp(App); const pinia = createPinia(); // 添加持久化插件 pinia.use(piniaPluginPersistedstate); app.use(pinia); app.mount('#app');

🔧 基本使用

启用持久化

import { defineStore } from 'pinia'; export const useUserStore = defineStore('user', { state: () => ({ token: null as string | null, user: null as User | null }), // 启用持久化 persist: true }); // Setup Store 风格 export const useUserStore = defineStore('user', () => { const token = ref<string | null>(null); const user = ref<User | null>(null); return { token, user }; }, { persist: true });

⚙️ 自定义配置

指定持久化的字段

export const useUserStore = defineStore('user', { state: () => ({ token: null, user: null, loading: false, // 不需要持久化 error: null // 不需要持久化 }), persist: { // 只持久化 token 和 user paths: ['token', 'user'] } });

自定义存储 key

export const useUserStore = defineStore('user', { state: () => ({ token: null, user: null }), persist: { key: 'my-app-user', // 自定义存储 key paths: ['token', 'user'] } });

自定义存储引擎

export const useUserStore = defineStore('user', { state: () => ({ token: null, user: null }), persist: { storage: { getItem(key) { return localStorage.getItem(key); }, setItem(key, value) { localStorage.setItem(key, value); }, removeItem(key) { localStorage.removeItem(key); } } } }); // 使用 sessionStorage persist: { storage: sessionStorage }

🔐 加密存储

import { encrypt, decrypt } from '@/utils/crypto'; export const useUserStore = defineStore('user', { state: () => ({ token: null, user: null }), persist: { storage: { getItem(key) { const value = localStorage.getItem(key); return value ? decrypt(value) : null; }, setItem(key, value) { localStorage.setItem(key, encrypt(value)); }, removeItem(key) { localStorage.removeItem(key); } } } });

🔄 自定义序列化

export const useUserStore = defineStore('user', { state: () => ({ token: null, user: null }), persist: { // 自定义序列化 serializer: { serialize: JSON.stringify, deserialize: JSON.parse }, // 或者使用自定义格式 serializer: { serialize(state) { return JSON.stringify({ ...state, savedAt: new Date().toISOString() }); }, deserialize(value) { const data = JSON.parse(value); delete data.savedAt; return data; } } } });

📋 条件持久化

export const useUserStore = defineStore('user', { state: () => ({ token: null, user: null, rememberMe: false }), persist: { // 根据条件决定是否持久化 beforeRestore: (context) => { console.log('About to restore', context.store.$id); }, afterRestore: (context) => { if (!context.store.rememberMe) { // 如果用户没有勾选记住我，清除持久化数据 context.store.$reset(); } } } });

🛠️ 手动实现持久化

// 不使用插件，手动实现 export const useUserStore = defineStore('user', () => { const token = ref<string | null>(null); const user = ref<User | null>(null); // 从 localStorage 恢复 const savedToken = localStorage.getItem('token'); const savedUser = localStorage.getItem('user'); if (savedToken) token.value = savedToken; if (savedUser) user.value = JSON.parse(savedUser); // 监听变化并保存 watch([token, user], () => { if (token.value) { localStorage.setItem('token', token.value); } else { localStorage.removeItem('token'); } if (user.value) { localStorage.setItem('user', JSON.stringify(user.value)); } else { localStorage.removeItem('user'); } }, { deep: true }); return { token, user }; });

📝 本节小结

  • 使用 pinia-plugin-persistedstate 实现状态持久化
  • 可以指定需要持久化的字段
  • 支持自定义存储引擎和序列化方式
  • 可以结合加密提高安全性
  • 也可以手动实现持久化逻辑
