80.2 Axios 基础

流行的 HTTP 客户端库

📖 本节概述

Axios 是一个基于 Promise 的 HTTP 客户端，可以用于浏览器和 Node.js 环境。它提供了比 Fetch API 更丰富的功能，包括自动转换 JSON、请求和响应拦截器、取消请求、客户端防护 XSRF 等。

🎯 学习目标

  • 了解 Axios 的特点和优势
  • 掌握 Axios 的安装和基本使用
  • 学会使用各种请求方法
  • 理解 Axios 与 Fetch API 的区别

📦 安装 Axios

# 使用 npm npm install axios # 使用 yarn yarn add axios # 使用 pnpm pnpm add axios

引入方式

// ES Modules import axios from 'axios'; // CommonJS const axios = require('axios'); // CDN 方式（浏览器） <script src="https://cdn.jsdelivr.net/npm/axios/dist/axios.min.js"></script>

🚀 基本使用

GET 请求

// 简单的 GET 请求 axios.get('/api/users') .then(response => { console.log(response.data); }) .catch(error => { console.error(error); }); // 带参数的 GET 请求 axios.get('/api/users', { params: { page: 1, limit: 10, name: 'John' } }); // 使用 async/await async function getUsers() { try { const response = await axios.get('/api/users'); console.log(response.data); } catch (error) { console.error(error); } }

POST 请求

// POST 请求 axios.post('/api/users', { name: 'John Doe', email: 'john@example.com' }) .then(response => { console.log(response.data); }); // 使用 async/await async function createUser(userData: { name: string; email: string }) { const response = await axios.post('/api/users', userData); return response.data; }

🔧 请求方法别名

Axios 为所有支持的请求方法提供了别名：

// axios.request(config) axios.request({ method: 'GET', url: '/api/users' }); // axios.get(url[, config]) axios.get('/api/users', { params: { id: 1 } }); // axios.post(url[, data[, config]]) axios.post('/api/users', { name: 'John' }); // axios.put(url[, data[, config]]) axios.put('/api/users/1', { name: 'John Updated' }); // axios.patch(url[, data[, config]]) axios.patch('/api/users/1', { name: 'John' }); // axios.delete(url[, config]) axios.delete('/api/users/1'); // axios.head(url[, config]) axios.head('/api/users'); // axios.options(url[, config]) axios.options('/api/users');
方法 描述
axios.get() 获取资源
axios.post() 创建资源
axios.put() 完整更新资源
axios.patch() 部分更新资源
axios.delete() 删除资源

📤 响应结构

Axios 的响应对象包含以下属性：

interface AxiosResponseany> { data: T; // 服务器返回的数据 status: number; // HTTP 状态码 statusText: string; // HTTP 状态信息 headers: any; // 响应头 config: AxiosRequestConfig; // 请求配置 request?: any; // 原始请求对象 } // 使用示例 axios.get('/api/users').then(response => { console.log('Data:', response.data); console.log('Status:', response.status); console.log('Headers:', response.headers); });

📊 Axios vs Fetch API

特性 Axios Fetch API
JSON 处理 自动转换 需要手动调用 response.json()
错误处理 HTTP 错误会 reject HTTP 错误不会 reject
拦截器 支持 不支持（需要自己实现）
请求超时 内置支持 需要 AbortController
请求取消 CancelToken（旧）/ AbortController AbortController
XSRF 防护 内置支持 不支持
进度监控 支持上传/下载进度 支持下载进度
浏览器支持 广泛（包括旧浏览器） 现代浏览器
💡
选择建议

对于简单的请求，Fetch API 足够使用；对于复杂的应用，Axios 提供了更完善的功能和更好的开发体验。

🛡️ 错误处理

async function handleRequest() { try { const response = await axios.get('/api/users'); return response.data; } catch (error) { if (axios.isAxiosError(error)) { // Axios 错误 if (error.response) { // 服务器返回了错误状态码 console.error('Status:', error.response.status); console.error('Data:', error.response.data); } else if (error.request) { // 请求已发出但没有收到响应 console.error('No response received'); } else { // 设置请求时出错 console.error('Error:', error.message); } } else { // 非 Axios 错误 console.error('Unknown error:', error); } } }

📝 本节小结

  • Axios 是功能丰富的 HTTP 客户端库
  • 自动转换 JSON 数据，简化开发
  • HTTP 错误状态码会自动 reject，便于错误处理
  • 支持请求和响应拦截器
  • 内置请求超时、取消、进度监控等功能
