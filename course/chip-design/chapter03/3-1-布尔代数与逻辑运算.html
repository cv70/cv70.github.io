什么是布尔代数

布尔代数（Boolean Algebra）是由英国数学家乔治·布尔（George Boole）于1854年创立的一种代数系统，它处理的是只有两个值（真/假、1/0、高/低）的逻辑变量。布尔代数是数字电路设计和分析的数学基础，所有的数字系统都建立在布尔代数之上。

在芯片设计中，布尔代数用于描述和优化逻辑电路，是硬件描述语言（HDL）的理论根基。

📊 布尔代数基本定律

定律名称 公式（与形式） 公式（或形式）
恒等律 A · 1 = A A + 0 = A
零律 A · 0 = 0 A + 1 = 1
重叠律 A · A = A A + A = A
互补律 A · Ā = 0 A + Ā = 1
交换律 A · B = B · A A + B = B + A
结合律 (A · B) · C = A · (B · C) (A + B) + C = A + (B + C)
分配律 A · (B + C) = A·B + A·C A + B·C = (A+B) · (A+C)

对合律 (A')' = A
💡
德摩根定律的重要性

德摩根定律（De Morgan's Law）是布尔代数中最重要的定理之一，它建立了与运算和或运算之间的转换关系。在芯片设计中，德摩根定律常用于：
• 用 NAND 门或 NOR 门实现任意逻辑函数
• 优化电路结构，减少门的数量
• 在不同逻辑实现方式之间转换

🔧 复合逻辑运算

NAND（与非）

A NAND B = (A · B)'

NAND门被称为"通用门"，因为任何布尔函数都可以仅用NAND门实现。

NOR（或非）

A NOR B = (A + B)'

NOR门同样是通用门，可以用来实现任何布尔函数。

XOR（异或）

A XOR B = A'·B + A·B'

当两个输入不同时输出为1，常用于加法器、比较器等电路。

XNOR（同或）

A XNOR B = A·B + A'·B'

当两个输入相同时输出为1，常用于等价比较电路。

📝 布尔表达式化简

常用化简技巧

技巧 示例
吸收律 A + A·B = A   |   A·(A + B) = A
消去律 A + A'·B = A + B   |   A·(A' + B) = A·B
冗余律 A·B + A'·C + B·C = A·B + A'·C
⚠️
化简方法

布尔表达式的化简主要有两种方法：
代数化简法：利用布尔代数定律逐步化简，需要经验和技巧。
卡诺图法（K-Map）：图形化方法，直观且系统性强，适合4变量以下的函数化简。
在实际芯片设计中，通常使用EDA工具（如Synopsys Design Compiler）自动进行逻辑优化。
