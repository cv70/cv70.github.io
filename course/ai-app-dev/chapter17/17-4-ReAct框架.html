17.4 ReAct框架

推理与行动的协同框架

🎯 学习目标

  • 理解ReAct框架的核心概念

  • 学会设计ReAct Prompt

什么是ReAct

ReAct（Reasoning + Acting）是一种将推理和行动相结合的框架。它让模型能够交替进行"思考推理"和"执行动作"，通过外部工具获取信息，从而解决需要实时数据或特定能力的复杂问题。

🔄 ReAct核心循环

Thought (思考) → Action (行动) → Observation (观察) → 循环... /* Thought: 分析当前情况，决定下一步 Action: 执行具体操作（如搜索、查询） Observation: 获取执行结果 ...重复直到得出最终答案 */

🔧 ReAct实战示例

示例：查询当前天气

/* 问题：北京今天适合户外运动吗？ */ Thought: 我需要查询北京今天的天气情况， 包括温度、降水等信息来判断是否适合户外运动。 Action: search("北京今天天气") Observation: 北京今天晴转多云，气温18-25度， 空气质量良好，无降水，微风2-3级。 Thought: 根据天气信息，今天温度适宜， 无降水，空气质量好，非常适合户外运动。 Action: finish("北京今天非常适合户外运动。 天气晴朗，气温18-25度，无降水，空气质量良好。 建议选择早晨或傍晚时段进行户外活动。")

示例：多步骤信息查询

/* 问题：iPhone 15 Pro的发布日期和首发价格 */ Thought: 我需要查找iPhone 15 Pro的发布信息。 Action: search("iPhone 15 Pro 发布日期 价格") Observation: iPhone 15 Pro于2023年9月12日发布， 9月22日开售。首发价格：128GB版7999元， 256GB版8999元，512GB版10699元，1TB版12499元。 Thought: 我已经获取了完整的发布日期和价格信息。 Action: finish("iPhone 15 Pro于2023年9月12日发布， 9月22日正式开售。首发价格区间为7999-12499元， 具体为：128GB版7999元，256GB版8999元， 512GB版10699元，1TB版12499元。")

⚙️ ReAct Prompt模板

你是一个智能助手，可以使用以下工具： 1. search[query]: 搜索网络获取信息 2. query[database]: 查询数据库 3. calculate[expression]: 执行数学计算 4. finish[answer]: 完成任务，输出最终答案 使用以下格式回答问题： Thought: 分析问题，思考下一步 Action: 工具名称[参数] Observation: 工具返回结果 ... (重复Thought/Action/Observation) Thought: 我现在知道答案了 Action: finish[最终答案] 开始！ 问题：{user_question}

💻 ReAct实现示例

import re from typing import Callable class ReActAgent: def __init__(self, tools: dict[str, Callable]): self.tools = tools self.history = [] def run(self, question: str, max_steps: int = 10): prompt = self._build_prompt(question) for _ in range(max_steps): response = self._call_llm(prompt) # 解析Action action_match = re.search(r"Action: (\w+)\[(.+)\]", response) if not action_match: continue tool_name, tool_input = action_match.groups() # 执行工具 if tool_name == "finish": return tool_input observation = self.tools[tool_name](tool_input) prompt += f"\nObservation: {observation}\nThought:" return "未能完成任务"
💡
ReAct的优势

ReAct框架让模型能够获取实时信息（如新闻、天气）、执行精确计算、查询专业数据库。同时，推理过程的透明性使得错误更容易被发现和纠正。

⚠️
注意事项

ReAct需要模型具备良好的指令遵循能力和工具调用能力。推荐使用GPT-4、Claude 3.5等大模型。工具调用失败时需要设计容错机制，避免陷入死循环。

📝 本节小结

✅
  • • ReAct结合了推理(Reasoning)和行动(Acting)
  • • 核心循环：Thought → Action → Observation
  • • 支持外部工具调用，获取实时信息
  • • 推理过程透明，便于调试和纠错
  • • 是现代AI Agent的核心框架之一
