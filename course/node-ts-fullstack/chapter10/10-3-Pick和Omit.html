10.3 Pick 和 Omit

选择和排除属性

🎯 学习目标

  • 深入理解 Pick 的实现原理
  • 掌握 Omit 的使用场景
  • 学会组合 Pick 和 Omit
  • 了解实际项目中的应用

📚 Pick 深入

// Pick 从类型中选取部分属性 // 内置实现： type MyPick = { [P in K]: T[P]; }; interface User { id: number; name: string; email: string; password: string; role: 'admin' | 'user'; createdAt: Date; } // 只选取公开属性 type PublicUser = Pick; // { id: number; name: string; email: string; } // API 返回用户信息时排除敏感字段 function getUser(): PublicUser { const user: User = { id: 1, name: 'Alice', email: 'alice@example.com', password: 'secret', role: 'admin', createdAt: new Date() }; const { id, name, email } = user; return { id, name, email }; } // 选取特定类型的属性 type PickByType = { [K in keyof T as T[K] extends U ? K : never]: T[K]; }; type StringProps = PickByType; // { name: string; email: string; password: string; }

🔧 Omit 深入

// Omit 从类型中排除部分属性 // 内置实现： type MyOmit = Pick>; // 排除敏感属性 type SafeUser = Omit; // { id: number; name: string; email: string; role: 'admin' | 'user'; createdAt: Date; } // 排除多个属性 type UserPreview = Omit; // { id: number; name: string; email: string; } // 创建更新类型 type UserUpdate = Omit; // { name: string; email: string; password: string; role: 'admin' | 'user'; } // 排除特定类型的属性 type OmitByType = { [K in keyof T as T[K] extends U ? never : K]: T[K]; }; type NonStringProps = OmitByType; // { id: number; role: 'admin' | 'user'; createdAt: Date; }
💡
Pick vs Omit

Pick 选择需要的属性（白名单），Omit 排除不需要的属性（黑名单）。根据具体场景选择更直观的方式。

🔀 组合应用

// 创建表单数据类型 interface Entity { id: number; createdAt: Date; updatedAt: Date; } interface Product extends Entity { name: string; price: number; description: string; inStock: boolean; } // 创建表单（不包含自动生成的字段） type ProductForm = Omit; // { name: string; price: number; description: string; inStock: boolean; } // 更新表单（所有字段可选） type ProductUpdate = Partial>; // { name?: string; price?: number; description?: string; inStock?: boolean; } // 列表项（精简版） type ProductListItem = Pick; // { id: number; name: string; price: number; } // 详情页（排除敏感信息） type ProductDetail = Omit; // 此例无敏感信息 // 组合多个类型 interface Author { authorId: number; authorName: string; } type ProductWithAuthor = Pick & Author; // { id: number; name: string; price: number; authorId: number; authorName: string; }

🎨 实际应用

// API 响应类型 interface ApiResponse { data: T; status: number; message: string; timestamp: Date; } // 只需要数据 type ApiData = Pick, 'data'>; // { data: T } // 分页响应 interface PaginatedResponse { items: T[]; total: number; page: number; pageSize: number; } // 列表视图 type ListView = Pick, 'items' | 'total'>; // { items: T[]; total: number; } // 权限控制 interface AdminUser extends User { permissions: string[]; lastLogin: Date; } type NormalUserView = Omit; // 普通用户看不到权限信息 // 版本控制 interface VersionedEntity { id: number; version: number; createdBy: string; updatedBy: string; } type CreateInput = Omit; type UpdateInput = Partial>;
⚠️
注意事项

Omit 的第二个参数可以接受任何 string，不会检查是否为 T 的键。使用时确保拼写正确。

📝 本节小结

✅
  • • Pick 选择需要的属性
  • • Omit 排除不需要的属性
  • • 可以组合使用实现复杂类型
  • • 常用于创建表单和 API 类型
