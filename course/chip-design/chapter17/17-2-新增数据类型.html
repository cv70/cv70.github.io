17.2 新增数据类型

SystemVerilog 语言精讲

🎯 学习目标

  • 掌握logic类型
  • 理解双状态数据类型
  • 学会使用枚举类型
  • 掌握结构体和联合体

📊 新增数据类型

// logic类型（替代wire和reg）
logic [7:0] data;
logic clk;

// 双状态类型（0和1，无x和z）
bit [7:0] byte_data;
bit ready;

// 枚举类型
typedef enum {IDLE, RUN, DONE} state_t;
state_t state;

// 结构体
struct {
    logic [7:0] addr;
    logic [31:0] data;
    logic valid;
} transaction;

// 联合体
union packed {
    logic [31:0] word;
    logic [3:0][7:0] bytes;
} data_union;

📝 本节小结

✅
  • • logic简化了变量声明
  • • bit用于双状态数据
  • • enum提高代码可读性
  • • struct和union用于复杂数据
