7.1 CMOS反相器原理

CMOS反相器结构，工作原理

🎯 学习目标

  • 理解CMOS反相器的基本结构组成
  • 掌握NMOS和PMOS晶体管的工作原理
  • 理解CMOS反相器的静态工作特性
  • 了解CMOS技术的核心优势

CMOS技术简介

CMOS（Complementary Metal-Oxide-Semiconductor，互补金属氧化物半导体）是现代集成电路的主流制造技术。其核心思想是将NMOS和PMOS两种晶体管互补使用，实现低功耗、高密度的数字电路设计。CMOS反相器是最基本的CMOS电路单元，是理解所有复杂CMOS电路的基础。

🔬 MOS晶体管基础

NMOS晶体管

⚡
  • 衬底：P型半导体
  • 源/漏区：N+掺杂区
  • 导通条件：Vgs > Vth
  • 载流子：电子（多子）
  • 开关特性：高电平导通

当栅极电压高于阈值电压时，P型衬底表面感应出电子沟道，源漏之间导通。

PMOS晶体管

🔋
  • 衬底：N型半导体
  • 源/漏区：P+掺杂区
  • 导通条件：Vgs < Vth（负值）
  • 载流子：空穴（多子）
  • 开关特性：低电平导通

当栅极电压低于阈值电压时，N型衬底表面感应出空穴沟道，源漏之间导通。

🏗️ CMOS反相器结构

📊
组成部分 连接方式 作用
PMOS晶体管 源极接VDD，漏极接输出 上拉开关，输出高电平
NMOS晶体管 源极接VSS(GND)，漏极接输出 下拉开关，输出低电平
栅极 两管栅极相连作为输入 控制开关状态
漏极 两管漏极相连作为输出 输出信号

⚙️ 工作原理详解

输入为高电平（Vin = VDD）

  • NMOS：Vgs = VDD - 0 = VDD > Vth，处于导通状态
  • PMOS：Vgs = VDD - VDD = 0 > Vth(PMOS为负)，处于截止状态
  • 输出：通过NMOS连接到地，输出低电平（Vout ≈ 0）

输入为低电平（Vin = 0）

  • NMOS：Vgs = 0 - 0 = 0 < Vth，处于截止状态
  • PMOS：Vgs = 0 - VDD = -VDD < Vth(PMOS)，处于导通状态
  • 输出：通过PMOS连接到VDD，输出高电平（Vout ≈ VDD）
💡
互补工作的关键

CMOS反相器的核心在于"互补"：在任何稳态下，PMOS和NMOS总是一个导通、一个截止，绝不会同时导通。这就保证了从电源到地之间不存在直流通路，从而实现了极低的静态功耗。

✨ CMOS技术的优势

低静态功耗

⚡

稳态时无直流通路，静态功耗接近零，适合大规模集成。

高噪声容限

🛡️

逻辑电平明确，抗干扰能力强，信号完整性良好。

高集成度

📦

结构简单，易于制造，适合大规模生产。

📈 晶体管尺寸设计

参数 NMOS PMOS 说明
载流子迁移率 μn ≈ 2μp μp 电子迁移率约为空穴的2倍
导通电阻 Ron ∝ 1/μnW Ron ∝ 1/μpW 迁移率影响导通电阻
典型尺寸比 W/L = 1 W/L = 2 PMOS宽度约为NMOS的2倍
设计目的 使PMOS和NMOS具有相同的驱动能力，实现对称的开关特性
⚠️
尺寸设计的权衡

虽然PMOS宽度加倍可以获得对称特性，但会增加面积和输入电容。在实际设计中，需要根据具体应用场景权衡开关速度、功耗和面积。现代工艺中，常采用非对称设计以优化特定性能指标。

📝 本节小结

✅
  • • CMOS反相器由一个PMOS和一个NMOS互补组成
  • • 输入高电平时NMOS导通、PMOS截止，输出低电平
  • • 输入低电平时PMOS导通、NMOS截止，输出高电平
  • • 互补工作确保稳态时无直流通路，实现低功耗
  • • PMOS宽度通常设计为NMOS的2倍以平衡驱动能力
