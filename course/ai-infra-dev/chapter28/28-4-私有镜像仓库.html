私有镜像仓库概述

私有镜像仓库用于存储和管理组织内部的容器镜像，提供安全、可控的镜像分发渠道。 对于AI应用，私有仓库可以保护模型知识产权、控制镜像访问、实施安全策略。

📦 部署Harbor

Docker Compose部署

# 下载Harbor安装包 wget https://github.com/goharbor/harbor/releases/download/v2.8.0/harbor-offline-installer-v2.8.0.tgz tar xvf harbor-offline-installer-v2.8.0.tgz cd harbor # 配置Harbor cp harbor.yml.tmpl harbor.yml vi harbor.yml # 关键配置 hostname: harbor.example.com http: port: 80 https: port: 443 certificate: /data/cert/server.crt private_key: /data/cert/server.key harbor_admin_password: "Harbor12345" data_volume: /data # 安装Harbor ./install.sh # 查看状态 docker-compose ps

Kubernetes部署（Helm）

# 添加Harbor Helm仓库 helm repo add harbor https://helm.goharbor.io helm repo update # 创建命名空间 kubectl create namespace harbor # 安装Harbor helm install harbor harbor/harbor \ --namespace harbor \ --set expose.ingress.hosts.core=harbor.example.com \ --set expose.ingress.enabled=true \ --set expose.tls.enabled=true \ --set expose.tls.certSource=auto \ --set persistence.persistentVolumeClaim.registry.storageClass=nfs-client \ --set persistence.persistentVolumeClaim.registry.size=100Gi \ --set persistence.enabled=true \ --set harborAdminPassword="Harbor12345" # 验证安装 kubectl get pods -n harbor kubectl get svc -n harbor

存储配置

AI镜像通常较大（GB级别），建议使用高性能存储（如SSD、NFS）作为后端存储。

🔧 Harbor配置管理

创建项目

# 通过UI创建项目 # 1. 登录Harbor UI (https://harbor.example.com) # 2. 点击"新建项目" # 3. 设置项目名称和可见性 # 4. 配置访问级别（公开/私有） # 通过API创建项目 curl -X POST "https://harbor.example.com/api/v2.0/projects" \ -H "Authorization: Basic " \ -H "Content-Type: application/json" \ -d '{ "project_name": "ai-models", "public": false, "metadata": { "public": "false" } }'

用户与权限

# 创建用户 curl -X POST "https://harbor.example.com/api/v2.0/users" \ -H "Authorization: Basic " \ -H "Content-Type: application/json" \ -d '{ "username": "ai-developer", "email": "dev@example.com", "password": "SecurePass123", "realname": "AI Developer" }' # 添加成员到项目 curl -X POST "https://harbor.example.com/api/v2.0/projects/1/members" \ -H "Authorization: Basic " \ -H "Content-Type: application/json" \ -d '{ "member_user": { "username": "ai-developer" }, "role_id": 2 }' # 角色说明 # 1: 项目管理员 # 2: 开发者 # 3: 访客 # 4: 维护人员

机器人账户

# 创建机器人账户 curl -X POST "https://harbor.example.com/api/v2.0/projects/1/robots" \ -H "Authorization: Basic " \ -H "Content-Type: application/json" \ -d '{ "name": "ci-cd-bot", "description": "CI/CD automation", "duration": 30, "level": "project", "permissions": [ { "kind": "project", "namespace": "ai-models", "access": [ { "resource": "repository", "action": "push" }, { "resource": "repository", "action": "pull" } ] } ] }'

🔒 安全配置

漏洞扫描

# 启用自动扫描 # 在项目设置中启用"自动扫描" # 手动触发扫描 curl -X POST "https://harbor.example.com/api/v2.0/projects/1/repositories/myrepo/artifacts/latest/scan" \ -H "Authorization: Basic " # 配置扫描策略 # 通过UI：项目 -> 配置 -> 漏洞扫描 # 扫描策略： # - 每次推送到仓库时扫描 # - 按计划扫描（每日/每周） # - 手动触发扫描

镜像签名

# 推送时签名 docker login harbor.example.com docker tag myapp:latest harbor.example.com/ai-models/myapp:latest docker push harbor.example.com/ai-models/myapp:latest # 使用cosign签名 cosign sign --key cosign.key harbor.example.com/ai-models/myapp:latest # 验证签名 cosign verify --key cosign.pub harbor.example.com/ai-models/myapp:latest # Harbor UI查看签名状态 # 项目 -> 仓库 -> myapp -> latest -> 签名

内容信任

# 启用内容信任 docker login harbor.example.com export DOCKER_CONTENT_TRUST=1 export DOCKER_CONTENT_TRUST_SERVER=https://notary.harbor.example.com # 推送时自动签名 docker push harbor.example.com/ai-models/myapp:latest # 拉取时自动验证 docker pull harbor.example.com/ai-models/myapp:latest

🔄 镜像同步

配置镜像仓库

# 添加远程仓库 # 管理 -> 仓库 -> 新建目标仓库 # 示例：同步Docker Hub { "name": "docker-hub", "endpoint": "https://index.docker.io", "type": "docker-hub", "username": "dockerhub-user", "password": "dockerhub-password", "insecure": false } # 示例：同步另一个Harbor { "name": "backup-harbor", "endpoint": "https://backup-harbor.example.com", "type": "harbor", "username": "admin", "password": "password" }

创建同步规则

# 同步规则配置 { "name": "sync-docker-hub", "description": "Sync from Docker Hub", "src_registry_id": 1, "dest_namespace": "docker-hub-mirror", "enabled": true, "override": true, "schedule": { "type": "Manual" }, "trigger": { "kind": "Manual" }, "filters": [ { "type": "name", "value": "pytorch/*" } ] } # 通过API创建同步规则 curl -X POST "https://harbor.example.com/api/v2.0/replication/policies" \ -H "Authorization: Basic " \ -H "Content-Type: application/json" \ -d @sync-policy.json # 手动触发同步 curl -X POST "https://harbor.example.com/api/v2.0/replication/execution" \ -H "Authorization: Basic " \ -H "Content-Type: application/json" \ -d '{ "policy_id": 1 }'

🗑️ 存储管理

垃圾回收

# 通过UI执行垃圾回收 # 管理 -> 垃圾回收 -> 扫描 -> 清理 # 通过API触发垃圾回收 curl -X POST "https://harbor.example.com/api/v2.0/system/gc/schedule" \ -H "Authorization: Basic " \ -H "Content-Type: application/json" \ -d '{ "schedule": { "type": "Daily", "cron": "0 0 * * *" } }' # 手动执行垃圾回收 curl -X POST "https://harbor.example.com/api/v2.0/system/gc" \ -H "Authorization: Basic "

保留策略

# 配置保留策略 # 项目 -> 配置 -> 保留策略 { "scope": { "level": "project", "ref": "ai-models" }, "schedule": { "type": "Daily", "cron": "0 2 * * *" }, "keep_recently_n": 10, "keep_days": 30 } # 保留最近10个镜像 # 保留30天内的镜像
💡
存储优化建议
  • • AI镜像较大，定期执行垃圾回收
  • • 配置合理的保留策略
  • • 使用分层存储，热数据用SSD
  • • 监控存储使用率，及时扩容

🔍 监控与审计

查看使用统计

# 项目统计 curl -X GET "https://harbor.example.com/api/v2.0/statistics" \ -H "Authorization: Basic " # 返回示例 { "total_project_count": 10, "public_project_count": 3, "private_project_count": 7, "total_repo_count": 156, "public_repo_count": 45, "private_repo_count": 111 }

审计日志

# 查询审计日志 curl -X GET "https://harbor.example.com/api/v2.0/audit-logs" \ -H "Authorization: Basic " \ -G \ --data-urlencode "page=1" \ --data-urlencode "page_size=20" \ --data-urlencode "operation=push" # 审计日志包含： # - 用户操作 # - 镜像推送/拉取 # - 权限变更 # - 安全扫描结果

Prometheus集成

# Harbor默认提供Prometheus metrics # 端点：https://harbor.example.com/metrics # Prometheus配置 scrape_configs: - job_name: 'harbor' static_configs: - targets: ['harbor.example.com'] metrics_path: '/metrics' scheme: https tls_config: insecure_skip_verify: true # 关键指标 # harbor_project_repo_count: 项目仓库数量 # harbor_project_blob_count: 项目blob数量 # harbor_project_artifact_count: 项目artifacts数量

⚙️ Kubernetes集成

配置ImagePullSecrets

# 创建Secret kubectl create secret docker-registry harbor-secret \ --docker-server=harbor.example.com \ --docker-username=robot$ci-cd-bot \ --docker-password= \ --docker-email=bot@example.com \ -n default # 在Pod中使用 apiVersion: v1 kind: Pod metadata: name: ai-pod spec: containers: - name: app image: harbor.example.com/ai-models/myapp:latest imagePullSecrets: - name: harbor-secret

配置全局ImagePullSecret

# 为命名空间添加默认ImagePullSecret kubectl patch serviceaccount default \ -p '{"imagePullSecrets": [{"name": "harbor-secret"}]}' \ -n default # 验证 kubectl get sa default -n default -o yaml

镜像拉取策略

apiVersion: apps/v1 kind: Deployment metadata: name: ai-deployment spec: template: spec: containers: - name: app image: harbor.example.com/ai-models/myapp:latest imagePullPolicy: Always # Always | IfNotPresent | Never
