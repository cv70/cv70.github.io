22.3 LoRA技术

低秩自适应高效微调

🎯 学习目标

  • 理解LoRA的核心原理

  • 学会使用LoRA进行微调
  • 了解LoRA的优势

什么是LoRA

LoRA（Low-Rank Adaptation）是一种参数高效的微调方法， 通过训练少量低秩矩阵来实现模型适配，大幅降低显存需求和训练成本。

📊 LoRA原理

原始权重: W (d×d) 微调增量: ΔW = A × B (A: d×r, B: r×d) 其中 r << d (低秩) 只训练A和B，冻结原始W

💻 使用PEFT进行LoRA微调

from peft import LoraConfig, get_peft_model from transformers import AutoModelForCausalLM # 加载基础模型 model = AutoModelForCausalLM.from_pretrained("model_name") # LoRA配置 lora_config = LoraConfig( r=8, # 秩 lora_alpha=32, # 缩放因子 target_modules=["q_proj", "v_proj"], lora_dropout=0.1 ) # 应用LoRA model = get_peft_model(model, lora_config) print(f"可训练参数: {model.print_trainable_parameters()}")
💡
LoRA优势

显存占用降低60-70%，训练速度提升，生成的适配器文件小（几MB到几百MB），方便切换和部署。
