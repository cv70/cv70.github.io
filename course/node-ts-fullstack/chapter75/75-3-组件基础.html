75.3 组件基础

函数组件与类组件

🎯 学习目标

  • 理解 React 组件的概念
  • 掌握函数组件的写法
  • 了解类组件的写法
  • 学会组件的组合与复用

📚 函数组件

// 函数组件（推荐） // - 接收 props 作为参数 // - 返回 React 元素 // 简单函数组件 function Welcome() { return <h1>Hello, React!</h1>; } // 箭头函数写法 const Welcome = () => <h1>Hello, React!</h1>; // 接收 props function Welcome(props) { return <h1>Hello, {props.name}!</h1>; } // 解构 props function Welcome({ name, age }) { return ( <div> <h1>Hello, {name}!</h1> <p>Age: {age}</p> </div> ); } // 使用组件 function App() { return ( <div> <Welcome name="Alice" age={25} /> <Welcome name="Bob" age={30} /> </div> ); }

🔧 类组件（了解）

// 类组件（旧写法，了解即可） import { Component } from 'react'; class Welcome extends Component { render() { return <h1>Hello, {this.props.name}!</h1>; } } // 带状态的类组件 class Counter extends Component { constructor(props) { super(props); this.state = { count: 0 }; } increment = () => { this.setState({ count: this.state.count + 1 }); }; render() { return ( <div> <p>Count: {this.state.count}</p> <button onClick={this.increment}>+1</button> </div> ); } } // 生命周期方法 class LifecycleDemo extends Component { componentDidMount() { console.log('组件已挂载'); } componentDidUpdate(prevProps) { console.log('组件已更新', prevProps, this.props); } componentWillUnmount() { console.log('组件将卸载'); } render() { return <div>Lifecycle Demo</div>; } }

📊 组件组合

// 组件组合：将组件作为子元素传递 // 1. 使用 children prop function Card({ title, children }) { return ( <div className="card"> <div className="card-header">{title}</div> <div className="card-body">{children}</div> </div> ); } // 使用 function App() { return ( <Card title="用户信息"> <p>Name: Alice</p> <p>Email: alice@example.com</p> </Card> ); } // 2. 组件作为 props function Layout({ header, content, footer }) { return ( <div className="layout"> <header>{header}</header> <main>{content}</main> <footer>{footer}</footer> </div> ); } function App() { return ( <Layout header={<Header />} content={<Main />} footer={<Footer />} /> ); }

📝 本节小结

✅
  • • 函数组件是现代 React 的推荐写法
  • • 类组件是旧写法，了解即可
  • • 组件可以接收 props 并返回 JSX
  • • 使用 children 或 props 进行组件组合
