Ollama简介

Ollama是一个轻量级的本地大模型运行工具，支持多种开源模型， 一键下载运行，非常适合本地开发和测试。

💻 基本使用

# 安装后运行模型 ollama run llama2 ollama run mistral ollama run qwen:7b # 查看已安装模型 ollama list # API调用 curl http://localhost:11434/api/generate -d '{ "model": "llama2", "prompt": "你好" }'
💡
推荐模型

Llama 2/3、Mistral、Qwen、DeepSeek等模型都支持，可根据硬件选择合适大小。
