15.3 Multi-Head Attention

什么是多头注意力

多头注意力（Multi-Head Attention）是Transformer的关键创新之一。 它将注意力计算并行地在多个"头"中进行，每个头可以学习关注输入的不同方面， 最后将所有头的输出合并。这种设计让模型能够同时捕捉多种类型的依赖关系。

📐 Multi-Head Attention公式

# Multi-Head Attention核心公式 # 定义 headi = Attention(Q · WiQ, K · WiK, V · WiV) # 拼接所有头的输出 MultiHead(Q, K, V) = Concat(head1, ..., headh) · WO # 其中： # h - 头的数量 # WiQ, WiK, WiV - 第i个头的投影矩阵 # WO - 输出投影矩阵 # 维度设计 # 通常 d_k = d_v = d_model / h # 例如：d_model=512, h=8, 则 d_k = d_v = 64

💻 PyTorch实现Multi-Head Attention

import torch import torch.nn as nn import math class MultiHeadAttention(nn.Module): def __init__(self, d_model, num_heads): super().__init__() assert d_model % num_heads == 0 self.d_model = d_model self.num_heads = num_heads self.d_k = d_model // num_heads # 所有头的Q、K、V投影（合并为一个矩阵） self.W_q = nn.Linear(d_model, d_model) self.W_k = nn.Linear(d_model, d_model) self.W_v = nn.Linear(d_model, d_model) # 输出投影 self.W_o = nn.Linear(d_model, d_model) def scaled_dot_product_attention(self, Q, K, V, mask=None): # Q, K, V: [batch, num_heads, seq_len, d_k] scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(self.d_k) if mask is not None: scores = scores.masked_fill(mask == 0, -1e9) attention = torch.softmax(scores, dim=-1) output = torch.matmul(attention, V) return output, attention def forward(self, x, mask=None): batch_size, seq_len, _ = x.size() # 线性投影 Q = self.W_q(x) # [batch, seq, d_model] K = self.W_k(x) V = self.W_v(x) # 重塑为多头格式 [batch, num_heads, seq_len, d_k] Q = Q.view(batch_size, seq_len, self.num_heads, self.d_k).transpose(1, 2) K = K.view(batch_size, seq_len, self.num_heads, self.d_k).transpose(1, 2) V = V.view(batch_size, seq_len, self.num_heads, self.d_k).transpose(1, 2) # 计算注意力 output, attention = self.scaled_dot_product_attention(Q, K, V, mask) # 合并多头 [batch, seq, d_model] output = output.transpose(1, 2).contiguous().view(batch_size, seq_len, self.d_model) # 输出投影 output = self.W_o(output) return output, attention

🔬 不同头的学习模式

Head 1-2：句法关系

关注主谓宾等语法结构

# "The cat sat on the mat" # Head 1关注：cat → sat # Head 2关注：sat → mat

Head 3-4：语义关系

关注词汇语义相似性

# "The bank of the river" # Head 3关注：bank → river # 帮助消歧义

Head 5-6：位置关系

关注相邻或特定距离的词

# 捕捉局部上下文 # 类似n-gram效果

Head 7-8：特殊模式

学习任务特定的模式

# 如指代消解 # "He looked at her" # Head关注He/She关系
💡
实践建议

研究表明，并非所有头都同样重要。部分头可以进行剪枝而不显著影响性能。 在资源受限场景，可以尝试减少头数量或使用分组查询注意力来优化。
