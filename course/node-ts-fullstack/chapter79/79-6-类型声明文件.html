79.6 类型声明文件

为 JavaScript 模块添加类型

🎯 学习目标

  • 理解类型声明文件的作用
  • 掌握 .d.ts 文件的编写
  • 学会模块声明语法
  • 了解 DefinitelyTyped

📚 类型声明文件概述

// .d.ts 文件：类型声明文件 // - 只包含类型定义，不包含实现 // - 为 JavaScript 代码提供类型信息 // - 用于第三方库或自己的 JS 模块 // 常见类型声明来源 // 1. 库自带类型（如 axios） // npm install axios // 类型在 node_modules/axios/index.d.ts // 2. @types 包（DefinitelyTyped） // npm install @types/lodash // 类型在 node_modules/@types/lodash/index.d.ts // 3. 自定义类型声明 // 在项目中创建 .d.ts 文件 // 查看 tsconfig.json 配置 { "compilerOptions": { // 类型声明文件查找位置 "typeRoots": ["./node_modules/@types", "./src/types"], // 包含的类型 "types": ["node", "jest"], // 自动包含的类型文件 "include": ["src/**/*.d.ts"] } }

🔧 编写类型声明

// src/types/index.d.ts // 声明全局变量 declare const API_URL: string; declare const VERSION: string; // 声明全局函数 declare function log(message: string): void; // 声明全局对象 declare namespace MyLib { interface Options { debug: boolean; timeout: number; } function init(options: Options): void; function destroy(): void; } // 使用 console.log(API_URL); log('Hello'); MyLib.init({ debug: true, timeout: 5000 }); // 声明模块 // 为没有类型的 JavaScript 模块添加类型 declare module 'my-js-library' { export interface Config { apiKey: string; environment?: 'development' | 'production'; } export function initialize(config: Config): void; export function getData(): Promise<unknown[]>; // 默认导出 const MyLibrary: { version: string; init: (config: Config) => void; }; export default MyLibrary; } // 使用 import { initialize, getData } from 'my-js-library'; import MyLibrary from 'my-js-library'; // 声明非 JS 模块 declare module '*.css' { const styles: { [className: string]: string }; export default styles; } declare module '*.svg' { const content: string; export default content; } declare module '*.png' { const src: string; export default src; } // 使用 import styles from './Button.css'; import logo from './logo.svg'; import banner from './banner.png';

📊 React 组件类型声明

// 为第三方 React 组件添加类型 // src/types/react-components.d.ts declare module 'some-ui-library' { import { ComponentType, ReactNode } from 'react'; // Button 组件 export interface ButtonProps { variant?: 'primary' | 'secondary' | 'danger'; size?: 'sm' | 'md' | 'lg'; disabled?: boolean; loading?: boolean; children: ReactNode; onClick?: () => void; } export const Button: ComponentType<ButtonProps>; // Modal 组件 export interface ModalProps { open: boolean; onClose: () => void; title?: string; children: ReactNode; footer?: ReactNode; } export const Modal: ComponentType<ModalProps>; // 默认导出 const UILibrary: { Button: ComponentType<ButtonProps>; Modal: ComponentType<ModalProps>; version: string; }; export default UILibrary; } // 使用 import { Button, Modal } from 'some-ui-library'; import UILibrary from 'some-ui-library'; // 扩展第三方类型 // src/types/react-router.d.ts import 'react-router-dom'; declare module 'react-router-dom' { interface RouteObject { // 添加自定义属性 auth?: boolean; roles?: string[]; } } // 使用 const routes: RouteObject[] = [ { path: '/admin', element: <Admin />, auth: true, roles: ['admin'], }, ];

📝 本节小结

✅
  • • .d.ts 文件只包含类型定义
  • • 使用 declare 关键字声明类型
  • • 可以为 JS 模块添加类型支持
  • • 可以扩展现有库的类型定义
