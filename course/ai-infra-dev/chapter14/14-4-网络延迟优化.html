网络延迟的重要性

网络延迟直接影响AI训练的迭代速度，特别是对于小batch size和 需要频繁同步的模型并行场景。本节将深入分析网络延迟的来源， 并提供系统性的优化方法。

🔍 延迟测量

测量方法

# 详细测量 ping -i 0.001 -s 64 -c 10000 2. iperf测量 # UDP延迟测量 iperf3 -c -u -b 100M -l 1472 -t 60 3. ib_read_lat (IB专用) # 读取延迟 ib_read_lat -d -i 1 -s 1024 -n 10000 4. NCCL延迟测试 # 运行延迟测试 mpirun -np 8 ./all_reduce_perf -b 1K -e 1K -f 2 5. 自定义测试 # 使用RDMA直接测量 rdma_lat -s 64 -n 10000

延迟分析工具

# 跳数延迟 traceroute -n -q 1 2. mtr # 持续监控 mtr -n -r -c 100 3. tcpdump # 抓包分析 tcpdump -i -w capture.pcap 4. wireshark # 详细分析 # 分析pcap文件，查看延迟分布 5. dstat # 实时统计 dstat --tcp --net
