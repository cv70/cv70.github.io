25.6 综合优化策略

提升综合结果的优化方法和技巧

🎯 学习目标

  • 掌握时序优化的常用策略
  • 了解面积优化的方法
  • 学会功耗优化技巧
  • 理解优化策略的权衡关系

⏱️ 时序优化策略

1. 路径平衡

平衡数据路径和时钟路径的延迟：

# 启用路径平衡 set_balance_registers true # 设置时钟门控 set_clock_gating_style -sequential_cell latch \ -control_point before \ -positive_edge_logic {NAND} \ -negative_edge_logic {NOR}

2. 单元尺寸调整

根据时序需求选择合适的单元尺寸：

# 允许单元尺寸调整 set_auto_wire_load_selection true # 设置最大扇出 set_max_fanout 16 [current_design] # 设置最大转换时间 set_max_transition 0.5 [current_design]

3. 层次结构优化

# 保持层次结构进行优化 set_ungroup_ok false # 或允许特定模块解层次 set_ungroup_ok true [get_cells sub_module*] # 设置边界优化 compile_ultra -no_autoungroup

4. 约束驱动优化

# 设置关键路径权重 set_weight 10 [get_paths -from [get_ports data_in*]] # 设置多路径约束 set_multicycle_path -setup 2 \ -from [get_cells slow_path*] \ -to [get_cells dest_ff*] # 设置虚假路径 set_false_path -from [get_ports async_rst*]

📐 面积优化策略

1. 资源共享

让综合工具共享相同的逻辑资源：

# 启用资源共享 set_resource_sharing true # 设置共享级别 set_sharing_resource_effort high

2. 逻辑简化

# 设置优化级别 set_compile_effort high # 启用常量传播 remove_constant_ports # 移除未使用的逻辑 remove_unconnected_ports -blast_buses

3. 单元选择

# 优先使用小尺寸单元 set_min_library saed90nm_min.db # 使用面积优先的综合策略 compile -map_effort high -area_effort high

⚡ 功耗优化策略

1. 时钟门控

# 插入时钟门控 insert_clock_gating # 设置时钟门控风格 set_clock_gating_style -minimum_bitwidth 4 \ -max_fanout 20 \ -control_point before

2. 多阈值电压设计

# 设置HVT单元用于非关键路径 set_leakage_optimization true # 混合使用不同Vt单元 set_target_library [list \ saed90nm_hvt.db \ saed90nm_rvt.db \ saed90nm_lvt.db \ ]

3. 数据路径优化

# 降低开关活动率 set_switching_activity -activity 0.1 [get_nets quiet*] # 使能功耗优化 compile_ultra -power_effort high

🔄 增量综合策略

增量编译

# 保存当前设计 write -format ddc -hierarchy design_stage1.ddc # 读入保存的设计 read_ddc design_stage1.ddc # 只修改约束后增量编译 compile_ultra -incremental

局部优化

# 只优化特定模块 current_design sub_module_critical compile_ultra # 回到顶层 current_design top_module
💡
优化策略选择

优化策略需要根据设计目标进行权衡。时序优化可能增加面积， 面积优化可能影响时序，功耗优化可能增加设计复杂度。 需要根据项目优先级选择合适的策略组合。

📊 优化效果评估

优化目标 关键指标 评估方法
时序优化 WNS, TNS report_timing
面积优化 Total area report_area
功耗优化 Total power report_power
综合质量 QoR 综合后对比
