佣金费用

佣金费用是量化交易开发中的重要内容。本节将深入探讨佣金费用的相关知识和实践方法。

💻 Backtrader佣金设置

佣金费用配置示例

import backtrader as bt

cerebro = bt.Cerebro()

# 按比例设置佣金
comminfo = bt.commissions.CommInfo(
    commission=0.0005,  # 万分之五
    mult=1.0,
    margin=None
)
cerebro.broker.addcommissioninfo(comminfo)

# 固定佣金模式
cerebro.broker.setcommission(commission=5.0)

🏗️ 核心内容

💰

固定佣金

按交易笔数收取固定费用

📊

按比例佣金

按交易金额的一定比例收取

🔄

阶梯佣金

根据交易量实行阶梯费率

🔧 不同市场佣金对比

市场类型 佣金模式 典型费率
A股按成交额万分之2.5左右
美股按笔数每笔$5-10
期货按合约数每手数元至数十元
加密货币按成交额千分之1-5
