34.3 状态码设置

理解并正确使用 HTTP 状态码

🎯 学习目标

  • 理解 HTTP 状态码的分类
  • 掌握常用状态码的使用场景
  • 学会正确设置状态码
  • 理解状态码与 RESTful API 的关系

📊 HTTP 状态码分类

类别 范围 说明
1xx 100-199 信息响应 - 请求处理中
2xx 200-299 成功 - 请求成功处理
3xx 300-399 重定向 - 需要进一步操作
4xx 400-499 客户端错误 - 请求有问题
5xx 500-599 服务器错误 - 服务器出错

✅ 2xx 成功状态码

// 200 OK - 成功 app.get('/users', (req, res) => { res.status(200).json({ users: [] }); }); // 201 Created - 资源创建成功 app.post('/users', (req, res) => { const user = createUser(req.body); res.status(201).json(user); }); // 204 No Content - 成功但无返回内容 app.delete('/users/:id', (req, res) => { deleteUser(req.params.id); res.status(204).send(); }); // 202 Accepted - 已接受处理 app.post('/import', (req, res) => { // 异步处理 processImport(req.body); res.status(202).json({ message: 'Import started' }); });

❌ 4xx 客户端错误

// 400 Bad Request - 请求参数错误 app.post('/users', (req, res) => { if (!req.body.email) { return res.status(400).json({ error: 'Email required' }); } // ... }); // 401 Unauthorized - 未认证 app.get('/profile', (req, res) => { if (!req.user) { return res.status(401).json({ error: 'Please login' }); } // ... }); // 403 Forbidden - 无权限 app.delete('/users/:id', (req, res) => { if (req.user.role !== 'admin') { return res.status(403).json({ error: 'Admin only' }); } // ... }); // 404 Not Found - 资源不存在 app.get('/users/:id', (req, res) => { const user = findUser(req.params.id); if (!user) { return res.status(404).json({ error: 'User not found' }); } // ... }); // 409 Conflict - 资源冲突 app.post('/users', (req, res) => { if (await emailExists(req.body.email)) { return res.status(409).json({ error: 'Email already exists' }); } // ... }); // 422 Unprocessable Entity - 语义错误 app.post('/users', (req, res) => { const errors = validateUser(req.body); if (errors.length > 0) { return res.status(422).json({ errors }); } // ... }); // 429 Too Many Requests - 请求过于频繁 app.get('/api', rateLimitMiddleware, (req, res) => { if (rateLimited) { return res.status(429).json({ error: 'Too many requests' }); } // ... });

🔥 5xx 服务器错误

// 500 Internal Server Error - 服务器内部错误 app.get('/error', (req, res) => { try { // 可能出错的代码 } catch (error) { res.status(500).json({ error: 'Internal server error' }); } }); // 502 Bad Gateway - 上游服务错误 app.get('/proxy', async (req, res) => { try { const response = await fetch(upstreamUrl); } catch (error) { res.status(502).json({ error: 'Upstream service error' }); } }); // 503 Service Unavailable - 服务不可用 app.get('/health', (req, res) => { if (!serviceReady) { return res.status(503).json({ error: 'Service unavailable' }); } res.json({ status: 'ok' }); });

📋 RESTful API 状态码最佳实践

// 用户 CRUD 示例 // GET /users - 列表 app.get('/users', async (req, res) => { const users = await User.findAll(); res.status(200).json({ data: users }); // 200 }); // GET /users/:id - 详情 app.get('/users/:id', async (req, res) => { const user = await User.findById(req.params.id); if (!user) { return res.status(404).json({ error: 'Not found' }); // 404 } res.status(200).json(user); // 200 }); // POST /users - 创建 app.post('/users', async (req, res) => { const user = await User.create(req.body); res.status(201).json(user); // 201 }); // PUT /users/:id - 完整更新 app.put('/users/:id', async (req, res) => { const user = await User.update(req.params.id, req.body); res.status(200).json(user); // 200 }); // PATCH /users/:id - 部分更新 app.patch('/users/:id', async (req, res) => { const user = await User.patch(req.params.id, req.body); res.status(200).json(user); // 200 }); // DELETE /users/:id - 删除 app.delete('/users/:id', async (req, res) => { await User.delete(req.params.id); res.status(204).send(); // 204 });

✅ 小结

📌
本节要点
  • 2xx 表示成功，4xx 表示客户端错误，5xx 表示服务器错误
  • 201 创建成功，204 删除成功（无内容）
  • 400 参数错误，401 未认证，403 无权限，404 未找到
  • 正确使用状态码是良好 API 设计的基础
