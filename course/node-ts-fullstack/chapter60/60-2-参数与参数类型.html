60.2 参数与参数类型

GraphQL 参数定义与使用

📖 参数概述

GraphQL 参数用于向字段传递数据。参数可以出现在 Query、Mutation、字段等位置，支持多种类型和默认值。

💡
参数的作用
  • 过滤查询结果
  • 分页控制
  • 排序和搜索
  • Mutation 的输入数据

📝 基本参数

// 字段参数 type Query { // 简单参数 user(id: ID!): User // 多个参数 users(limit: Int, offset: Int): [User!]! // 参数默认值 posts(limit: Int = 10, sort: SortOrder = DESC): [Post!]! // 必填参数 search(query: String!): [SearchResult!]! // 可选参数 userByEmail(email: String): User }

参数类型

类型 说明 示例
ID 唯一标识符 id: ID!
String 字符串 name: String
Int 整数 limit: Int = 10
Float 浮点数 price: Float
Boolean 布尔值 active: Boolean
Enum 枚举 status: PostStatus
Input 输入对象 input: CreateUserInput!

⚙️ 默认值

type Query { // 基本类型默认值 users(limit: Int = 10): [User!]! posts(page: Int = 1, pageSize: Int = 20): PostConnection! // 枚举默认值 users(sort: SortOrder = DESC): [User!]! posts(status: PostStatus = PUBLISHED): [Post!]! // 列表默认值 users(ids: [ID!] = []): [User!]! // 输入对象默认值（需要特殊处理） search(filter: SearchFilter = {}): [SearchResult!]! } // 查询时使用默认值 query { users { // limit 默认为 10 name } } // 覆盖默认值 query { users(limit: 50) { name } }

📦 输入对象参数

// 定义输入对象 input UserFilter { name: String email: String role: UserRole isActive: Boolean createdAtRange: DateRangeInput } input DateRangeInput { start: DateTime end: DateTime } input PaginationInput { page: Int = 1 pageSize: Int = 10 } input SortInput { field: String! order: SortOrder = ASC } // 组合使用 type Query { users( filter: UserFilter pagination: PaginationInput sort: SortInput ): UserConnection! } // 查询示例 query GetUsers { users( filter: { role: ADMIN isActive: true createdAtRange: { start: "2024-01-01T00:00:00Z" end: "2024-12-31T23:59:59Z" } } pagination: { page: 2, pageSize: 20 } sort: { field: "createdAt", order: DESC } ) { data { id name email } total } }

🔄 字段参数

type User { id: ID! name: String! // 带参数的字段 posts(limit: Int = 10, status: PostStatus): [Post!]! comments(first: Int = 5): [Comment!]! followers(limit: Int, offset: Int): [User!]! } type Post { id: ID! title: String! comments(limit: Int = 20, sort: SortOrder = DESC): [Comment!]! } // 查询示例 query { user(id: "123") { name posts(limit: 5, status: PUBLISHED) { title comments(limit: 3) { content } } } } // Resolver 实现 const resolvers = { User: { posts: async (user, { limit, status }, context) => { return context.dataSources.postApi.getByUserId(user.id, { limit, status, }); }, }, };

📄 分页参数模式

Offset 分页

input OffsetPaginationInput { offset: Int = 0 limit: Int = 10 } type Query { users(pagination: OffsetPaginationInput): UserConnection! } // 查询 query { users(pagination: { offset: 20, limit: 10 }) { data { id name } total } }

Cursor 分页（Relay 规范）

input CursorPaginationInput { first: Int // 从开始获取 N 条 after: String // 从该 cursor 之后开始 last: Int // 从末尾获取 N 条 before: String // 从该 cursor 之前开始 } type UserConnection { edges: [UserEdge!]! pageInfo: PageInfo! totalCount: Int! } type UserEdge { node: User! cursor: String! } type PageInfo { hasNextPage: Boolean! hasPreviousPage: Boolean! startCursor: String endCursor: String } // 查询 query { users(first: 10, after: "base64-cursor") { edges { cursor node { id name } } pageInfo { hasNextPage endCursor } totalCount } }

🔍 搜索与过滤参数

input SearchInput { query: String! fields: [String!] fuzzy: Boolean = true } input FilterInput { // 等于 eq: String // 不等于 ne: String // 包含 in: [String!] // 不包含 nin: [String!] // 大于 gt: Float // 大于等于 gte: Float // 小于 lt: Float // 小于等于 lte: Float // 包含（字符串） contains: String // 开头 startsWith: String // 结尾 endsWith: String } input UserFilterInput { name: StringFilterInput email: StringFilterInput age: NumberFilterInput role: [UserRole!] createdAt: DateRangeInput } type Query { search(input: SearchInput!): [SearchResult!]! users(filter: UserFilterInput): [User!]! } // 查询示例 query { users(filter: { name: { contains: "张" } age: { gte: 18, lte: 60 } role: [ADMIN, MODERATOR] }) { id name age } }

💻 TypeScript 类型安全

// 从 Schema 生成 TypeScript 类型 interface UserFilter { name?: string; email?: string; role?: UserRole[]; isActive?: boolean; } interface GetUsersVariables { filter?: UserFilter; pagination?: PaginationInput; sort?: SortInput; } // 使用类型安全的查询 const GET_USERS = gql` query GetUsers($filter: UserFilter, $pagination: PaginationInput) { users(filter: $filter, pagination: $pagination) { data { id name email } total } } `; function useUsers(variables: GetUsersVariables) { return useQuery(GET_USERS, { variables }); } // 调用时有完整类型提示 useUsers({ filter: { role: [UserRole.ADMIN], isActive: true, }, pagination: { page: 1, pageSize: 10, }, });

📝 小结

  • 参数用于向字段传递数据
  • 支持基本类型、枚举、输入对象
  • 默认值简化常见查询场景
  • 输入对象组织复杂参数结构
  • 字段参数实现关联数据过滤
  • 分页参数支持 Offset 和 Cursor 模式
