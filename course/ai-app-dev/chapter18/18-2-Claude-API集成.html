18.2 Claude API集成

使用Anthropic Claude API构建应用

🎯 学习目标

  • 掌握Claude API的基本使用方法
  • 理解Claude独特的消息格式
  • 学会使用Claude的高级特性
  • 了解Claude与OpenAI API的差异

Claude API简介

Claude是Anthropic公司开发的大语言模型，以安全性高、上下文长、推理能力强著称。Claude API提供与OpenAI类似的接口风格，但在消息格式和功能设计上有所不同。

📊 Claude模型系列

模型 上下文长度 特点 适用场景
Claude 3.5 Sonnet 200K 性能与速度最佳平衡 日常任务、代码生成
Claude 3.5 Haiku 200K 响应最快、成本最低 简单任务、高频调用
Claude 3 Opus 200K 最强推理能力 复杂分析、研究任务
图：Claude API提供强大的语言理解和生成能力

🔧 环境配置与基本调用

# 安装SDK pip install anthropic # 基本调用示例 import anthropic client = anthropic.Anthropic( api_key="your-api-key" ) message = client.messages.create( model="claude-3-5-sonnet-20241022", max_tokens=1024, messages=[ {"role": "user", "content": "你好，请介绍一下自己"} ] ) print(message.content[0].text)

💬 Claude消息格式

System Prompt

Claude使用独立的system参数设定系统提示。

message = client.messages.create( model="claude-3-5-sonnet-20241022", max_tokens=1024, system="你是一个专业的Python编程助手", messages=[ {"role": "user", "content": "如何读取CSV文件？"} ] )

多轮对话

保持完整的对话历史以实现上下文连贯。

messages = [ {"role": "user", "content": "什么是递归？"}, {"role": "assistant", "content": "递归是..."}, {"role": "user", "content": "能举个例子吗？"} ]

🖼️ 多模态能力（视觉）

Claude支持图像输入，可以分析图片内容。

import base64 # 读取图片并编码 with open("image.png", "rb") as f: image_data = base64.standard_b64encode(f.read()).decode("utf-8") message = client.messages.create( model="claude-3-5-sonnet-20241022", max_tokens=1024, messages=[ { "role": "user", "content": [ { "type": "image", "source": { "type": "base64", "media_type": "image/png", "data": image_data, }, }, { "type": "text", "text": "请描述这张图片的内容" } ] } ] )

🛠️ Tool Use（工具调用）

Claude支持通过Tool Use调用外部函数。

# 定义工具 tools = [ { "name": "get_weather", "description": "获取指定城市的天气信息", "input_schema": { "type": "object", "properties": { "city": { "type": "string", "description": "城市名称" } }, "required": ["city"] } } ] # 调用API response = client.messages.create( model="claude-3-5-sonnet-20241022", max_tokens=1024, tools=tools, messages=[{"role": "user", "content": "北京今天天气怎么样？"}] )
💡
Claude API特色

Claude特别擅长长文档处理（200K上下文）、代码生成和分析、复杂推理任务。其独特的System Prompt设计让角色设定更加清晰稳定。

⚠️
注意事项

Claude API不返回概率信息，不支持temperature=0的精确控制。另外，Claude有内容安全过滤，某些敏感话题可能被拒绝，这是Anthropic对AI安全的特殊设计。
