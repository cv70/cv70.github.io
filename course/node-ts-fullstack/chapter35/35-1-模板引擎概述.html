35.1 模板引擎概述

了解模板引擎的概念和常见选择

🎯 学习目标

  • 理解模板引擎的作用和原理
  • 了解常见的 Node.js 模板引擎
  • 学会根据项目需求选择模板引擎
  • 理解服务端渲染与客户端渲染的区别

📖 什么是模板引擎

模板引擎是一种将模板和数据结合生成最终 HTML 文档的工具。它允许开发者编写带有占位符的模板，运行时用实际数据替换这些占位符。

模板引擎的工作流程

1
编写模板
2
准备数据
3
渲染输出
4
返回 HTML
// 模板示例 (EJS) <h1>Hello, <%= name %>!</h1> // 数据 const data = { name: 'Alice' }; // 渲染结果 <h1>Hello, Alice!</h1>

📊 常见模板引擎对比

模板引擎 语法风格 特点 学习曲线
EJS 类 HTML 简单直观，HTML 中嵌入 JS 低
Pug 缩进式 简洁，不写标签闭合 中
Handlebars {{ }} 插值 逻辑分离，无运行时代码 低
Nunjucks {% %} 标签 功能强大，类似 Jinja2 中
Mustache {{ }} 插值 无逻辑模板，多语言支持 低

⚖️ 选择模板引擎的考量

项目需求

简单的展示页面选择简单的引擎；复杂的业务逻辑选择功能强大的引擎。

团队熟悉度

选择团队熟悉的语法风格，降低学习成本。

性能要求

高并发场景需要考虑渲染性能和缓存能力。

社区生态

活跃的社区意味着更好的文档和问题解决。

💡
推荐

初学者推荐 EJS，语法接近 HTML，学习成本低。大型项目可以考虑 Nunjucks 或 Pug。

🔄 服务端渲染 vs 客户端渲染

特性 服务端渲染 (SSR) 客户端渲染 (CSR)
首屏速度 快 较慢
SEO 友好 不友好
服务器负载 高 低
交互体验 页面刷新 无刷新
适用场景 内容网站、SEO 需求 单页应用、管理系统
