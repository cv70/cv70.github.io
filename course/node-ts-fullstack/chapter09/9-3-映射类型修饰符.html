9.3 映射类型修饰符

添加和移除属性修饰符

🎯 学习目标

  • 理解属性修饰符的概念
  • 掌握 + 和 - 修饰符操作
  • 学会移除只读和可选修饰符
  • 了解修饰符的实际应用

📚 修饰符语法

// TypeScript 支持两种属性修饰符： // - readonly：只读修饰符 // - ?：可选修饰符 // 使用 + 添加修饰符（默认行为） type AddModifiers = { +readonly [K in keyof T]+?: T[K]; }; // 使用 - 移除修饰符 type RemoveModifiers = { -readonly [K in keyof T]-?: T[K]; }; interface OptionalReadonly { readonly name?: string; readonly age?: number; } type RequiredMutable = RemoveModifiers; // { name: string; age: number; } // 现在可以修改 const obj: RequiredMutable = { name: 'Alice', age: 30 }; obj.name = 'Bob'; // OK，不再是只读
💡
修饰符规则

+ 添加修饰符（可以省略），- 移除修饰符。+? 添加可选，-? 移除可选。+readonly 添加只读，-readonly 移除只读。

🔧 实用工具类型

// 移除只读修饰符 type Mutable = { -readonly [K in keyof T]: T[K]; }; interface ReadonlyConfig { readonly apiUrl: string; readonly timeout: number; } type EditableConfig = Mutable; // { apiUrl: string; timeout: number; } // 移除可选修饰符 type Required = { [K in keyof T]-?: T[K]; }; interface OptionalConfig { apiUrl?: string; timeout?: number; } type CompleteConfig = Required; // { apiUrl: string; timeout: number; } // 同时操作两种修饰符 type FullyMutable = { -readonly [K in keyof T]-?: T[K]; }; interface StrictConfig { readonly apiUrl?: string; readonly timeout?: number; } type FlexibleConfig = FullyMutable; // { apiUrl: string; timeout: number; }

🔀 条件性修饰符

// 根据条件添加修饰符 type ConditionalReadonly = Omit & { readonly [P in K]: T[P]; }; interface User { id: number; name: string; email: string; role: string; } // 只让 id 和 role 只读 type ProtectedUser = ConditionalReadonly; // { name: string; email: string; readonly id: number; readonly role: string; } // 根据条件移除修饰符 type IfMutable = T extends { mutable: true } ? { -readonly [K in keyof U]: U[K] } : U; // 只对特定属性添加可选 type OptionalKeys = Omit & { [P in K]?: T[P]; }; type UserUpdate = OptionalKeys; // { id: number; role: string; name?: string; email?: string; }

📝 本节小结

✅
  • • + 添加修饰符，- 移除修饰符
  • • readonly 和 ? 都可以被操作
  • • Mutable 移除只读修饰符
  • • Required 移除可选修饰符
