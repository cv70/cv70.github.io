什么是异步FIFO

异步FIFO（First In First Out）是一种先进先出的存储结构，读写操作使用不同的时钟。它主要用于跨时钟域的数据传输，是解决CDC问题的有效方法。

💻 格雷码转换代码

// 二进制转格雷码
function [ADDR_WIDTH-1:0] bin2gray;
    input [ADDR_WIDTH-1:0] binary;
    begin
        bin2gray = binary ^ (binary >> 1);
    end
endfunction

// 格雷码转二进制
function [ADDR_WIDTH-1:0] gray2bin;
    input [ADDR_WIDTH-1:0] gray;
    integer i;
    begin
        gray2bin[ADDR_WIDTH-1] = gray[ADDR_WIDTH-1];
        for (i = ADDR_WIDTH-2; i >= 0; i = i-1) begin
            gray2bin[i] = gray2bin[i+1] ^ gray[i];
        end
    end
endfunction

📊 满空判断逻辑

FIFO空判断

当读指针追上写指针时，FIFO为空

empty = (rd_ptr_gray == rd_ptr_gray_sync)

FIFO满判断

当写指针即将追上读指针时，FIFO为满

full = (wr_ptr_gray_next == {~rd_ptr_gray_sync[ADDR_WIDTH:ADDR_WIDTH-1], rd_ptr_gray_sync[ADDR_WIDTH-2:0]})
💡
设计技巧

使用格雷码的额外MSB（最高位）作为翻转位，可以区分FIFO是空还是满。当读写指针相等且最高位相同时为空，相等但最高位不同时为满。
