13.5 定时器函数

定时任务与延迟执行

🎯 学习目标

  • 掌握 setTimeout 和 setInterval
  • 理解 setImmediate 的作用
  • 了解 process.nextTick 的执行时机
  • 学会取消定时器

📚 setTimeout

// 延迟执行（毫秒） const timeoutId = setTimeout(() => { console.log('1 秒后执行'); }, 1000); // 传递参数 setTimeout((name, age) => { console.log(`${name} is ${age} years old`); }, 1000, 'Alice', 25); // 立即执行（最小延迟 1ms） setTimeout(() => { console.log('立即执行'); }, 0); // 取消定时器 clearTimeout(timeoutId); // 检查定时器是否存在 // Node.js 返回 Timeout 对象 console.log(timeoutId); // Timeout { ... }

🔄 setInterval

// 重复执行 let count = 0; const intervalId = setInterval(() => { count++; console.log(`执行第 ${count} 次`); if (count >= 5) { clearInterval(intervalId); // 执行 5 次后停止 console.log('定时器已停止'); } }, 1000); // 带参数 setInterval((message) => { console.log(message); }, 2000, '每 2 秒打印一次'); // 实现倒计时 function countdown(seconds) { const timer = setInterval(() => { console.log(`剩余 ${seconds} 秒`); seconds--; if (seconds < 0) { clearInterval(timer); console.log('倒计时结束！'); } }, 1000); } countdown(5);

⚡ setImmediate

// 在 I/O 事件回调之后执行 setImmediate(() => { console.log('setImmediate 执行'); }); // 对比 setTimeout setTimeout(() => { console.log('setTimeout 0ms 执行'); }, 0); // 在 I/O 回调中的执行顺序 const fs = require('fs'); fs.readFile(__filename, () => { console.log('I/O 回调'); setTimeout(() => { console.log('I/O 回调中的 setTimeout'); }, 0); setImmediate(() => { console.log('I/O 回调中的 setImmediate'); }); }); // 在 I/O 回调中，setImmediate 一定先于 setTimeout 执行 // 输出顺序： // I/O 回调 // I/O 回调中的 setImmediate // I/O 回调中的 setTimeout
💡
setImmediate vs setTimeout

在 I/O 回调中，setImmediate 总是先执行。在主模块中，执行顺序不确定。

🚀 process.nextTick

// 在当前操作完成后立即执行（微任务） process.nextTick(() => { console.log('nextTick'); }); // 执行顺序对比 console.log('同步代码 1'); setTimeout(() => { console.log('setTimeout'); }, 0); setImmediate(() => { console.log('setImmediate'); }); process.nextTick(() => { console.log('nextTick'); }); Promise.resolve().then(() => { console.log('Promise'); }); console.log('同步代码 2'); // 输出顺序： // 同步代码 1 // 同步代码 2 // nextTick // Promise // setTimeout 或 setImmediate // setTimeout 或 setImmediate // nextTick 优先级最高，在所有异步操作之前执行

⚠️ 定时器注意事项

// 1. 定时器时间不精确 const start = Date.now(); setTimeout(() => { const elapsed = Date.now() - start; console.log(`实际经过: ${elapsed}ms`); // 可能 > 100ms }, 100); // 2. 阻塞会影响定时器 setTimeout(() => { console.log('我会被阻塞'); }, 100); // 阻塞事件循环 const start = Date.now(); while (Date.now() - start < 1000) { // 同步阻塞 1 秒 } // 3. 定时器在 Node.js 中返回 Timeout 对象 const timer = setTimeout(() => {}, 1000); console.log(typeof timer); // 'object' // 4. hasRef 检查是否保持事件循环 console.log(timer.hasRef()); // true // 取消引用（不阻止程序退出） timer.unref(); // 恢复引用 timer.ref();
⚠️
注意事项

定时器时间只是最小延迟，事件循环阻塞时会被推迟。不要依赖定时器做精确计时。

📝 本节小结

✅
  • • setTimeout 延迟执行，setInterval 重复执行
  • • setImmediate 在 I/O 回调后执行
  • • process.nextTick 是微任务，优先级最高
  • • 定时器时间不精确，不要依赖精确计时
