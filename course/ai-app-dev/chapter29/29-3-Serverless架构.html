29.3 Serverless架构

无服务器架构在AI应用中的应用

🎯 学习目标

  • 理解Serverless架构的核心概念
  • 掌握主流Serverless平台的使用
  • 学会部署AI推理函数
  • 了解Serverless的优缺点和适用场景

什么是Serverless？

Serverless（无服务器）是一种云计算执行模型，云提供商动态分配机器资源，用户只需为代码执行的实际用量付费。Serverless让开发者专注于业务逻辑，无需管理服务器基础设施。

🔄 传统架构 vs Serverless

特性 传统架构 Serverless架构
服务器管理 需要自行管理 完全由云平台管理
资源付费 按配置付费（持续） 按执行量付费（按需）
扩展方式 手动或自动扩容 自动弹性扩展
冷启动 无冷启动 可能有冷启动延迟
部署速度 较慢（分钟级） 快速（秒级）
运维复杂度 高 低

🤖 AI推理函数示例

# AWS Lambda AI推理函数
import json
import boto3
import base64
from PIL import Image
import io

# 初始化客户端（在handler外部初始化，利用容器复用）
sagemaker_runtime = boto3.client('runtime.sagemaker')
s3_client = boto3.client('s3')

def lambda_handler(event, context):
    """处理图像推理请求"""

    # 获取输入图像
    if 'body' in event:
        image_data = base64.b64decode(event['body'])
    else:
        return {'statusCode': 400, 'body': 'No image data'}

    # 调用SageMaker端点
    response = sagemaker_runtime.invoke_endpoint(
        EndpointName='my-inference-endpoint',
        ContentType='image/jpeg',
        Body=image_data
    )

    # 解析结果
    result = json.loads(response['Body'].read().decode())

    return {
        'statusCode': 200,
        'headers': {'Content-Type': 'application/json'},
        'body': json.dumps(result)
    }

# 预处理函数（减少冷启动影响）
def preprocess_image(image_bytes):
    image = Image.open(io.BytesIO(image_bytes))
    image = image.resize((224, 224))
    return image

📦 Lambda容器镜像支持

# Dockerfile for Lambda Container Image
FROM public.ecr.aws/lambda/python:3.10

# 安装依赖
COPY requirements.txt .
RUN pip install -r requirements.txt

# 复制模型和代码
COPY model/ /opt/ml/model/
COPY app/ /var/task/

# 设置处理函数
CMD ["handler.lambda_handler"]

# 部署命令
aws lambda create-function \
    --function-name ai-inference \
    --package-type Image \
    --code ImageUri=123456789.dkr.ecr.us-east-1.amazonaws.com/ai-lambda:v1 \
    --role arn:aws:iam::123456789:role/lambda-execution-role \
    --timeout 30 \
    --memory-size 4096

⚡ 冷启动优化策略

优化方法

  • 使用Provisioned Concurrency预热
  • 减少依赖包大小
  • 使用容器镜像部署
  • 保持函数简单轻量

适用场景

  • API后端服务
  • 事件驱动处理
  • 定时任务
  • 轻量级推理
💡
Serverless AI最佳实践

对于低延迟要求的AI推理，建议使用Provisioned Concurrency或专用推理端点。对于批量处理场景，Serverless可以显著降低成本。

📝 本节小结

✅
