Node.js 性能指标

Node.js 应用性能监控需要关注事件循环延迟、内存使用、CPU 使用、 句柄数量等核心指标，及时发现性能瓶颈和潜在问题。

📊 关键性能指标

指标 说明 健康阈值
Event Loop Lag 事件循环延迟 < 100ms
Heap Used 堆内存使用 < 75%
CPU Usage CPU 使用率 < 80%
Active Handles 活跃句柄数 无持续增长
GC Pause GC 暂停时间 < 100ms

🔧 内置监控代码

// src/utils/performance.ts import { monitorEventLoopDelay, performance } from 'perf_hooks'; import { freemem, totalmem, cpus } from 'os'; // 事件循环延迟监控 const histogram = monitorEventLoopDelay({ resolution: 10 }); histogram.enable(); export const getPerformanceMetrics = () => { const memUsage = process.memoryUsage(); const cpuUsage = process.cpuUsage(); return { // 内存指标 memory: { heapUsed: memUsage.heapUsed, heapTotal: memUsage.heapTotal, external: memUsage.external, rss: memUsage.rss, heapUsagePercent: (memUsage.heapUsed / memUsage.heapTotal * 100).toFixed(2) }, // CPU 指标 cpu: { user: cpuUsage.user, system: cpuUsage.system, percent: ((cpuUsage.user + cpuUsage.system) / 1000000).toFixed(2) }, // 事件循环延迟 eventLoop: { min: histogram.min, max: histogram.max, mean: histogram.mean, p99: histogram.percentile(99), p95: histogram.percentile(95) }, // 系统资源 system: { freeMemory: freemem(), totalMemory: totalmem(), cpuCount: cpus().length }, // Node.js 资源 node: { activeHandles: (process as any)._getActiveHandles().length, activeRequests: (process as any)._getActiveRequests().length, uptime: process.uptime() } }; }; // 定期记录性能指标 setInterval(() => { const metrics = getPerformanceMetrics(); logger.info('Performance metrics', { metrics }); }, 60000);

💾 内存泄漏检测

// src/utils/heapMonitor.ts import { writeHeapSnapshot } from 'v8'; import { writeFileSync } from 'fs'; let lastHeapSize = 0; let growthCount = 0; export const checkMemoryLeak = () => { const currentHeap = process.memoryUsage().heapUsed; if (currentHeap > lastHeapSize * 1.1) { growthCount++; if (growthCount >= 3) { // 生成堆快照用于分析 const filename = `heapdump-${Date.now()}.heapsnapshot`; writeHeapSnapshot(filename); logger.warn('Potential memory leak detected', { heapGrowth: currentHeap - lastHeapSize, filename }); } } else { growthCount = 0; } lastHeapSize = currentHeap; }; # 分析堆快照 # 使用 Chrome DevTools > Memory > Load # 或使用 heapdump 模块 npm install heapdump
