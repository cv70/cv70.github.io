83.2 Store 定义

两种定义 Store 的方式

📖 本节概述

Pinia 提供了两种定义 Store 的方式：Options API 风格和 Composition API 风格（Setup Store）。两种风格功能相同，可以根据个人偏好选择。

🎯 学习目标

  • 掌握 Options Store 的定义方式
  • 掌握 Setup Store 的定义方式
  • 理解两种风格的区别和选择
  • 学会在不同场景下使用合适的风格

📋 Options Store

Options Store 类似于 Vue 的 Options API，通过 state、getters、actions 三个选项来定义 Store。

// stores/user.ts import { defineStore } from 'pinia'; interface User { id: number; name: string; email: string; role: 'admin' | 'user'; } interface UserState { user: User | null; token: string | null; loading: boolean; } export const useUserStore = defineStore('user', { // State - 必须是返回初始状态的函数 state: (): UserState => ({ user: null, token: null, loading: false }), // Getters - 类似计算属性 getters: { // 简单 getter isLoggedIn(state): boolean { return !!state.token; }, // 使用 this 访问其他 getter isAdmin(): boolean { return this.isLoggedIn && this.user?.role === 'admin'; }, // 带参数的 getter（返回函数） hasPermission: (state) => { return (permission: string) => { return state.user?.role === 'admin'; }; } }, // Actions - 类似方法，可以是异步的 actions: { // 同步 action setUser(user: User) { this.user = user; }, setToken(token: string) { this.token = token; }, logout() { this.user = null; this.token = null; }, // 异步 action async login(credentials: { email: string; password: string }) { this.loading = true; try { const response = await api.login(credentials); this.setUser(response.user); this.setToken(response.token); } finally { this.loading = false; } } } });

⚡ Setup Store

Setup Store 类似于 Vue 的 Composition API，使用 ref、reactive、computed 和普通函数来定义。

// stores/user.ts import { defineStore } from 'pinia'; import { ref, computed } from 'vue'; export const useUserStore = defineStore('user', () => { // State - 使用 ref 或 reactive const user = ref<User | null>(null); const token = ref<string | null>(null); const loading = ref(false); // Getters - 使用 computed const isLoggedIn = computed(() => !!token.value); const isAdmin = computed(() => { return isLoggedIn.value && user.value?.role === 'admin'; }); // 带参数的 getter（普通函数） function hasPermission(permission: string): boolean { return user.value?.role === 'admin'; } // Actions - 普通函数 function setUser(newUser: User) { user.value = newUser; } function setToken(newToken: string) { token.value = newToken; } function logout() { user.value = null; token.value = null; } async function login(credentials: { email: string; password: string }) { loading.value = true; try { const response = await api.login(credentials); setUser(response.user); setToken(response.token); } finally { loading.value = false; } } // 必须返回所有需要暴露的内容 return { // State user, token, loading, // Getters isLoggedIn, isAdmin, hasPermission, // Actions setUser, setToken, logout, login }; });

📊 两种风格对比

特性 Options Store Setup Store
State 定义 state() 函数返回对象 ref() / reactive()
Getters 定义 getters 对象 computed()
Actions 定义 actions 对象 普通函数
类型推断 需要显式类型 自动推断
this 指向 store 实例 不使用 this
适用场景 熟悉 Options API 熟悉 Composition API
💡
推荐选择

推荐使用 Setup Store 风格，它与 Vue 3 的 Composition API 风格一致，类型推断更好，灵活性更高。

🔄 使用其他 Store

// stores/cart.ts import { defineStore } from 'pinia'; import { useUserStore } from './user'; import { useProductsStore } from './products'; export const useCartStore = defineStore('cart', () => { const items = ref<CartItem[]>([]); // 使用其他 store const userStore = useUserStore(); const productsStore = useProductsStore(); const total = computed(() => { return items.value.reduce((sum, item) => { const product = productsStore.getProduct(item.productId); return sum + product.price * item.quantity; }, 0); }); async function checkout() { if (!userStore.isLoggedIn) { throw new Error('Please login first'); } const response = await api.checkout({ items: items.value, userId: userStore.user!.id }); items.value = []; return response; } return { items, total, checkout }; });

🏷️ Store 命名约定

// 推荐：useXxxStore 命名 export const useUserStore = defineStore('user', () => { /* ... */ }); export const useCartStore = defineStore('cart', () => { /* ... */ }); export const useProductsStore = defineStore('products', () => { /* ... */ }); // Store ID 通常是模块名 // stores/user.ts -> store id: 'user' // stores/cart.ts -> store id: 'cart'

📝 本节小结

  • Options Store 使用 state/getters/actions 定义
  • Setup Store 使用 ref/computed/函数定义
  • Setup Store 类型推断更好，更灵活
  • 两种风格可以混用，但不推荐在同一个项目中混用
  • Store 可以引用其他 Store
