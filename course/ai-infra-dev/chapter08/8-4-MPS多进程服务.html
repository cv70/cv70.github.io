什么是MPS

MPS（Multi-Process Service）是NVIDIA提供的GPU多进程服务， 允许多个CUDA进程共享单个GPU，提高GPU利用率，适合推理和轻量训练场景。

⚙️ MPS配置

启动MPS

MPS启动配置：

# 设置GPU可见性
export CUDA_VISIBLE_DEVICES=0

# 启动MPS守护进程
nvidia-cuda-mps-control -d

# 设置MPS最大客户端
export CUDA_MPS_PIPE_DIRECTORY=/tmp/nvidia-mps
export CUDA_MPS_LOG_DIRECTORY=/var/log/nvidia-mps

# 查看MPS状态
nvidia-cuda-mps-control -s

# 停止MPS
nvidia-cuda-mps-control -t

# 配置MPS
nvidia-smi -i 0 -c EXCLUSIVE_PROCESS
export CUDA_MPS_PIPE_DIRECTORY=/tmp/nvidia-mps
export CUDA_MPS_LOG_DIRECTORY=/var/log/nvidia-mps
nvidia-cuda-mps-control -d

应用使用MPS

应用配置：

# Python应用
import os
os.environ['CUDA_MPS_PIPE_DIRECTORY'] = '/tmp/nvidia-mps'
os.environ['CUDA_MPS_LOG_DIRECTORY'] = '/var/log/nvidia-mps'

# 运行MPS作业
nvidia-cuda-mps-control -d
python train.py &
python inference.py &

# Docker配置
docker run --gpus all \
    -e CUDA_MPS_PIPE_DIRECTORY=/tmp/nvidia-mps \
    -v /tmp/nvidia-mps:/tmp/nvidia-mps \
    your-image:latest

# Kubernetes配置
apiVersion: v1
kind: Pod
metadata:
  name: mps-pod
spec:
  containers:
  - name: mps
    image: nvidia/cuda:11.8.0-base-ubuntu22.04
    command: ["nvidia-cuda-mps-control", "-d"]
    volumeMounts:
    - name: mps
      mountPath: /tmp/nvidia-mps
  volumes:
  - name: mps
    emptyDir: {}

🔧 MPS优化

性能调优

MPS优化策略：

1. 显存管理
   # 设置MPS显存限制
   export CUDA_MPS_MAX_CLIENTS=16

   # 预分配显存
   os.environ['CUDA_CACHE_DISABLE'] = '1'

2. 批处理优化
   # 调整批大小适应MPS
   batch_size = original_batch_size // num_processes

   # 动态批处理
   batch_size = adaptive_batch_size(num_processes)

3. 优先级调度
   # 设置进程优先级
   import psutil
   p = psutil.Process()
   p.nice(psutil.HIGH_PRIORITY_CLASS)

4. 错误恢复
   # MPS崩溃检测
   def check_mps_health():
       try:
           subprocess.run(['nvidia-cuda-mps-control', '-s'],
                        check=True)
           return True
       except:
           return False

   # 自动重启MPS
   if not check_mps_health():
       subprocess.run(['nvidia-cuda-mps-control', '-t'])
       subprocess.run(['nvidia-cuda-mps-control', '-d'])

💼 MPS应用场景

推理场景

多模型推理：

适用场景：
• 多个模型并行推理
• 小批量推理
• 在线服务

优势：
• 提高GPU利用率
• 降低成本
• 简化部署

示例：
Model A + Model B + Model C
共享一个GPU推理

训练场景

小模型训练：

适用场景：
• 小模型实验
• 参数扫描
• 超参优化

优势：
• 并行训练
• 加速迭代
• 资源高效

注意：
• 不适合大模型
• 显存可能不足
• 性能有所下降
⚠️
MPS注意事项

显存限制：所有进程共享GPU显存，注意显存分配

兼容性：不是所有CUDA应用都支持MPS

故障影响：MPS崩溃会影响所有客户端

调试困难：错误处理比直通更复杂
