generate 语句概述

generate 语句允许在编译时根据参数条件生成不同的硬件结构。这是 Verilog 中实现参数化设计的重要手段，广泛用于生成重复结构、条件实例化等场景。

💡 generate-for 循环生成

module register_array #( parameter WIDTH = 8, parameter DEPTH = 4 )( input wire clk, rst_n, input wire [WIDTH-1:0] din [0:DEPTH-1], output reg [WIDTH-1:0] dout [0:DEPTH-1] ); genvar i; generate for (i = 0; i < DEPTH; i = i + 1) begin : gen_reg always @(posedge clk or negedge rst_n) begin if (!rst_n) dout[i] <= 0; else dout[i] <= din[i]; end end endgenerate endmodule

⚙️ generate-if 条件生成

module mult_wrapper #( parameter USE_DSP = 1 )( input wire [15:0] a, b, output wire [31:0] p ); generate if (USE_DSP) begin : gen_dsp DSP_MULT u_dsp (.a(a), .b(b), .p(p)); end else begin : gen_logic assign p = a * b; end endgenerate endmodule
💡
注意事项

genvar 声明的变量只在编译时存在，仿真时不可见。每个生成块必须命名，便于调试和层次引用。

📝 本节小结

✅
  • • generate-for 用于批量生成重复结构
  • • generate-if 用于条件选择实例化
  • • 必须使用 genvar 声明循环变量
  • • 每个生成块必须有唯一名称
