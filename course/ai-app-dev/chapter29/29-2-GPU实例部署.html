29.2 GPU实例部署

云端GPU计算资源的配置与管理

🎯 学习目标

  • 了解GPU实例的类型和选择
  • 掌握主流云平台的GPU实例创建
  • 学会配置GPU运行环境
  • 了解Spot实例降低成本的方法

GPU实例概述

GPU实例是配备GPU加速器的云计算虚拟机，适用于深度学习训练、推理、科学计算等场景。选择合适的GPU实例需要考虑显存大小、计算性能、网络带宽和成本等因素。

🎮 GPU类型对比

GPU型号 显存 适用场景 性价比
T4 16GB 推理、轻量训练 高
V100 16/32GB 中等规模训练 中
A10 24GB 推理、工作站 高
A100 40/80GB 大规模训练、大模型 中
H100 80GB 超大模型训练 低(高性能)

☁️ AWS GPU实例创建

# AWS CLI创建GPU实例
aws ec2 run-instances \
    --image-id ami-0c55b159cbfafe1f0 \
    --instance-type g4dn.xlarge \
    --key-name my-key-pair \
    --security-group-ids sg-12345678 \
    --block-device-mappings '[{
        "DeviceName": "/dev/sda1",
        "Ebs": {
            "VolumeSize": 100,
            "VolumeType": "gp3"
        }
    }]' \
    --user-data '#!/bin/bash
        sudo yum install -y docker
        sudo service docker start
        sudo usermod -a -G docker ec2-user
    '

# GPU实例类型
# g4dn.xlarge  - 1x T4 GPU, 4 vCPU, 16GB RAM
# g4dn.2xlarge - 1x T4 GPU, 8 vCPU, 32GB RAM
# p3.2xlarge   - 1x V100 GPU, 8 vCPU, 61GB RAM
# p4d.24xlarge - 8x A100 GPU, 96 vCPU, 1152GB RAM

🔵 GCP GPU实例创建

# GCP创建GPU实例
gcloud compute instances create gpu-instance \
    --zone=us-central1-a \
    --machine-type=n1-standard-8 \
    --accelerator="type=nvidia-tesla-v100,count=1" \
    --image-family="ubuntu-2204-lts" \
    --image-project="ubuntu-os-cloud" \
    --boot-disk-size=200GB \
    --maintenance-policy=TERMINATE \
    --restart-on-failure

# 安装NVIDIA驱动
gcloud compute ssh gpu-instance --zone=us-central1-a
sudo apt-get update
sudo apt-get install -y cuda-drivers
sudo reboot

💰 Spot实例省钱策略

AWS Spot实例

# 创建Spot实例
aws ec2 run-instances \
    --instance-type p3.2xlarge \
    --instance-market-options '{
        "MarketType": "spot",
        "SpotOptions": {
            "MaxPrice": "1.5",
            "SpotInstanceType": "one-time"
        }
    }'

# 节省高达70%成本

GCP Preemptible实例

# 创建Preemptible实例
gcloud compute instances create gpu-spot \
    --preemptible \
    --accelerator="type=nvidia-tesla-v100,count=1"

# 节省高达60%成本
# 最长运行24小时
⚠️
Spot实例注意事项

Spot实例可能被随时回收，适合有状态检查点的训练任务。建议实现定期保存检查点和自动恢复机制，确保任务可以从中断处继续。

📝 本节小结

✅
  • • GPU实例类型包括T4、V100、A100、H100等，根据显存和性能需求选择
