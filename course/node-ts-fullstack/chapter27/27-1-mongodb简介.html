文档型 NoSQL 数据库入门

📚 MongoDB 特点

MongoDB 是一个基于文档的 NoSQL 数据库，以 JSON 格式存储数据，具有高性能、高可用性和易扩展的特点。

MongoDB 核心特点： 1. 文档存储 ├── 使用 BSON（二进制 JSON）格式 ├── 支持嵌套文档和数组 ├── Schema 灵活，字段可变 └── 天然适合 JavaScript 应用 2. 高性能 ├── 内存映射文件 ├── 索引支持丰富 ├── 内置分片 └── 高效的读写操作 3. 高可用 ├── 副本集自动故障转移 ├── 自动恢复 └── 数据冗余 4. 易扩展 ├── 水平扩展简单 ├── 自动数据分片 └── 透明扩展 与传统关系型数据库对比： ┌─────────────┬──────────────┬───────────────┐ │ 概念 │ MySQL │ MongoDB │ ├─────────────┼──────────────┼───────────────┤ │ 数据库 │ Database │ Database │ │ 表/集合 │ Table │ Collection │ │ 行/文档 │ Row │ Document │ │ 列/字段 │ Column │ Field │ │ 主键 │ Primary Key │ _id │ │ 外键 │ Foreign Key │ Reference │ │ 索引 │ Index │ Index │ └─────────────┴──────────────┴───────────────┘

📊 基本概念

// 数据库（Database） // 一个 MongoDB 实例可以包含多个数据库 // 集合（Collection） // 类似于关系数据库的表，存储一组文档 db.createCollection("users") // 文档（Document） // 类似于关系数据库的行，以 BSON 格式存储 { "_id": ObjectId("507f1f77bcf86cd799439011"), "name": "Alice", "email": "alice@mail.com", "age": 25, "address": { "city": "Beijing", "zip": "100000" }, "tags": ["developer", "nodejs"], "createdAt": ISODate("2024-01-15T12:00:00Z") } // 字段（Field） // 类似于关系数据库的列 // 文档可以有不同字段（Schema-less） // _id 字段 // 每个文档必须有唯一的 _id // 默认为 ObjectId 类型 // 可以自定义 // 数据类型 String - 字符串 Number - 数字（32位整数或64位浮点） Boolean - 布尔值 Date - 日期时间 Array - 数组 Object - 嵌套文档 ObjectId - 文档ID Null - 空值 Binary - 二进制数据 Regex - 正则表达式 Decimal128 - 高精度小数

⚙️ 适用场景

适合 MongoDB 的场景： 1. 内容管理系统（CMS） ├── 文章结构多变 ├── 需要灵活 Schema └── 嵌套评论、标签等 2. 日志分析 ├── 高写入吞吐量 ├── 数据结构可能变化 └── 易于水平扩展 3. 用户画像 ├── 属性字段多变 ├── 不同用户不同字段 └── 嵌套结构自然表达 4. 物联网数据 ├── 海量时序数据 ├── 设备属性各异 └── 分片扩展需求 5. 社交应用 ├── 动态 Feed ├── 嵌套评论 └── 灵活的关系存储 不适合的场景： ├── 复杂事务（ACID 要求高） ├── 多表关联查询多 ├── 数据结构固定且简单 └── 需要严格约束的业务

📝 本节小结

✅
  • • MongoDB 是文档型 NoSQL 数据库
  • • 使用 BSON 格式存储，支持嵌套结构
  • • Schema 灵活，适合数据结构多变的场景
  • • 推荐使用 Docker 或 MongoDB Atlas 部署
