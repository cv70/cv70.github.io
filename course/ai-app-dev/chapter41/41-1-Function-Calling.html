什么是Function Calling

Function Calling是大模型的一项核心能力，允许模型在对话过程中调用预定义的外部函数。模型会根据用户输入生成结构化的函数调用参数，应用程序执行函数后，将结果返回给模型继续处理。

💻 OpenAI Function Calling示例

from openai import OpenAI client = OpenAI() # 定义可用函数 tools = [ { "type": "function", "function": { "name": "get_weather", "description": "获取指定城市的天气信息", "parameters": { "type": "object", "properties": { "city": { "type": "string", "description": "城市名称，如'北京'" }, "unit": { "type": "string", "enum": ["celsius", "fahrenheit"], "description": "温度单位" } }, "required": ["city"] } } } ] # 发送请求 response = client.chat.completions.create( model="gpt-4-turbo-preview", messages=[ {"role": "user", "content": "北京今天天气怎么样？"} ], tools=tools, tool_choice="auto" ) # 检查是否需要调用函数 if response.choices[0].message.tool_calls: tool_call = response.choices[0].message.tool_calls[0] function_name = tool_call.function.name arguments = json.loads(tool_call.function.arguments) # 执行函数 if function_name == "get_weather": result = get_weather(arguments["city"])
💡
设计原则

函数描述应该清晰准确，让模型能正确理解函数用途。参数的description字段非常重要，帮助模型正确填充参数值。

🔧 完整调用流程

函数执行与返回

def handle_function_call(response, messages): """处理函数调用并返回结果""" message = response.choices[0].message messages.append(message) # 执行所有工具调用 for tool_call in message.tool_calls: function_name = tool_call.function.name arguments = json.loads( tool_call.function.arguments ) # 执行对应函数 result = execute_function( function_name, arguments ) # 添加函数结果到消息 messages.append({ "tool_call_id": tool_call.id, "role": "tool", "name": function_name, "content": json.dumps(result) }) # 继续对话 return client.chat.completions.create( model="gpt-4-turbo-preview", messages=messages, tools=tools )

多函数并行调用

# 定义多个工具 tools = [ { "type": "function", "function": { "name": "search_web", "description": "搜索网络信息" } }, { "type": "function", "function": { "name": "get_weather", "description": "获取天气信息" } }, { "type": "function", "function": { "name": "send_email", "description": "发送邮件" } } ] # 模型可以并行调用多个函数 # 例如：同时查询天气和搜索相关信息

import anthropic client = anthropic.Anthropic() response = client.messages.create( model="claude-3-opus-20240229", max_tokens=1024, tools=[ { "name": "get_weather", "description": "获取指定城市的当前天气", "input_schema": { "type": "object", "properties": { "city": { "type": "string", "description": "城市名称" } }, "required": ["city"] } } ], messages=[ {"role": "user", "content": "上海和北京哪个城市现在更热？"} ] ) # 处理工具使用 for block in response.content: if block.type == "tool_use": print(f"Tool: {block.name}") print(f"Input: {block.input}")
