59.4 Query 查询

GraphQL 数据查询详解

📖 Query 基础

Query 是 GraphQL 中用于读取数据的操作类型。客户端通过 Query 精确指定需要的数据字段。

基本语法

// 基本查询结构 query { fieldName { subField1 subField2 } } // 示例：查询用户 query { user(id: "123") { id name email } } // 响应 { "data": { "user": { "id": "123", "name": "张三", "email": "zhangsan@example.com" } } }

🏷️ 操作名称

为 Query 添加名称可以提高可读性，便于调试和日志追踪。

// 匿名查询 query { user(id: "123") { name } } // 命名查询（推荐） query GetUser { user(id: "123") { id name email } } // 多个查询 query GetUserData { user(id: "123") { name } posts { title } }

📦 变量（Variables）

变量使查询更加动态和可复用，避免硬编码参数值。

// 定义变量 query GetUser($id: ID!, $withPosts: Boolean!) { user(id: $id) { id name email posts @include(if: $withPosts) { title } } } // 变量值（JSON 格式） { "id": "123", "withPosts": true } // 变量默认值 query GetUsers($limit: Int = 10, $offset: Int = 0) { users(limit: $limit, offset: $offset) { id name } }

变量类型

类型 说明 示例
$id: ID! 必填 ID 类型 "123"
$limit: Int 可选整数 10, null
$ids: [ID!]! 必填 ID 数组 ["1", "2"]
$filter: UserFilter 输入对象类型 {"name": "张"}

📄 字段别名

别名允许为字段指定不同的名称，解决字段冲突或提高可读性。

// 使用别名查询多个用户 query { user1: user(id: "1") { name } user2: user(id: "2") { name } } // 响应 { "data": { "user1": { "name": "张三" }, "user2": { "name": "李四" } } } // 复杂场景 query { activeUsers: users(status: ACTIVE) { name } inactiveUsers: users(status: INACTIVE) { name } }

📝 片段（Fragments）

片段是可复用的字段集合，减少重复代码。

// 定义片段 fragment UserFields on User { id name email createdAt } // 使用片段 query { user(id: "123") { ...UserFields posts { title } } users { ...UserFields } } // 响应同： query { user(id: "123") { id name email createdAt posts { title } } users { id name email createdAt } }

片段的高级用法

// 嵌套片段 fragment PostFields on Post { id title createdAt } fragment UserWithPosts on User { ...UserFields posts { ...PostFields } } // 带变量的片段 fragment UserPosts on User { posts(limit: $postLimit) { title } } query GetUser($id: ID!, $postLimit: Int!) { user(id: $id) { ...UserFields ...UserPosts } }

🔀 内联片段

内联片段用于处理接口和联合类型。

// 搜索返回联合类型 query Search { search(query: "test") { ... on User { id name email } ... on Post { id title content } ... on Comment { id content } } } // 响应 { "data": { "search": [ { "id": "1", "name": "张三", "email": "..." }, { "id": "2", "title": "文章标题", "content": "..." }, { "id": "3", "content": "评论内容" } ] } } // 接口类型查询 query { node(id: "123") { id ... on User { name email } ... on Post { title author { name } } } }

⚙️ 指令（Directives）

指令用于动态控制查询的行为。

内置指令

指令 作用 示例
@include(if: Boolean) 条件为真时包含字段 @include(if: $showEmail)
@skip(if: Boolean) 条件为真时跳过字段 @skip(if: $hidePosts)
@deprecated 标记字段已废弃 @deprecated(reason: "使用 newUser")
// @include 指令 query GetUser($id: ID!, $withPosts: Boolean!) { user(id: $id) { name email posts @include(if: $withPosts) { title } } } // 变量 { "id": "123", "withPosts": true } // @skip 指令 query GetUsers($hideInactive: Boolean!) { users { name isActive lastLogin @skip(if: $hideInactive) } }

🔗 多层嵌套查询

GraphQL 的强大之处在于可以在一个请求中查询多层关联数据。

// 多层嵌套查询 query { user(id: "123") { id name email posts(limit: 5) { id title content comments(limit: 3) { id content author { id name avatar { url } } } tags { name } } followers { id name } } } // 一次请求获取完整数据

📊 分页查询

Offset 分页

query GetUsers($limit: Int!, $offset: Int!) { users(limit: $limit, offset: $offset) { id name email } userCount } // 变量 { "limit": 10, "offset": 20 }

Cursor 分页（Relay 规范）

query GetUsers($first: Int, $after: String, $last: Int, $before: String) { users(first: $first, after: $after, last: $last, before: $before) { edges { cursor node { id name email } } pageInfo { hasNextPage hasPreviousPage startCursor endCursor } totalCount } } // 变量 { "first": 10, "after": "YXJyYXljb25uZWN0aW9uOjE5" } // 响应 { "data": { "users": { "edges": [ { "cursor": "YXJyYXljb25uZWN0aW9uOjIw", "node": { "id": "20", "name": "用户20" } } ], "pageInfo": { "hasNextPage": true, "hasPreviousPage": true }, "totalCount": 100 } } }

📝 小结

  • Query 是 GraphQL 中读取数据的操作
  • 操作名称提高可读性和调试效率
  • 变量使查询更加动态和可复用
  • 别名解决字段冲突问题
  • 片段实现字段集合的复用
  • 指令动态控制查询行为
  • 支持多层嵌套查询和分页
