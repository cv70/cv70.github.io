37.3 Context 对象

Koa 的核心上下文对象

🎯 学习目标

  • 理解 Context 对象的作用和重要性
  • 掌握 Context 的常用属性和方法
  • 学会通过 Context 操作请求和响应
  • 了解 Context 的状态管理

📚 Context 概述

Context（上下文）对象是 Koa 的核心概念，它将 Node.js 的 request 和 response 对象封装到一个对象中，提供了许多有用的方法。

💡
核心作用

Context 对象是每个请求的上下文，包含了请求的所有信息，也是设置响应的唯一入口。

// Context 对象通常简写为 ctx app.use(async ctx => { // ctx 包含了 request 和 response console.log(ctx.request); // 请求对象 console.log(ctx.response); // 响应对象 console.log(ctx.state); // 状态对象 });

📊 Context 结构

ctx ├── request # Koa Request 对象 ├── response # Koa Response 对象 ├── state # 跨中间件共享状态 ├── app # Koa 应用实例引用 ├── req # Node.js 原生 request 对象 └── res # Node.js 原生 response 对象
⚠️
注意区分

ctx.request 是 Koa 封装的请求对象，ctx.req 是 Node.js 原生请求对象。推荐使用 Koa 封装的版本。

⚙️ Request 常用属性

属性 说明 示例
ctx.url 请求 URL /api/users?page=1
ctx.path 请求路径 /api/users
ctx.method 请求方法 GET / POST
ctx.header / ctx.headers 请求头对象 { 'content-type': '...' }
ctx.query 查询参数对象 { page: '1' }
ctx.querystring 查询字符串 page=1&limit=10
ctx.host 主机名 localhost:3000
ctx.ip 客户端 IP 127.0.0.1

📤 Response 常用属性

属性 说明 用法
ctx.body 响应体内容 ctx.body = { data: [] }
ctx.status 响应状态码 ctx.status = 201
ctx.type 响应类型 ctx.type = 'application/json'
ctx.set() 设置响应头 ctx.set('X-Custom', 'value')
ctx.redirect() 重定向 ctx.redirect('/login')
ctx.attachment() 设置下载文件 ctx.attachment('file.pdf')

💾 State 状态管理

ctx.state 是推荐的命名空间，用于在中间件之间传递信息。

// 认证中间件 - 设置用户信息 app.use(async (ctx, next) => { const token = ctx.header.authorization; if (token) { ctx.state.user = verifyToken(token); } await next(); }); // 后续中间件 - 获取用户信息 app.use(async ctx => { const user = ctx.state.user; ctx.body = { user }; });
✅
最佳实践

使用 ctx.state 在中间件间传递数据，避免全局变量污染。

💻 实战示例

// 综合使用 Context 对象 app.use(async ctx => { // 获取请求信息 const method = ctx.method; const path = ctx.path; const query = ctx.query; const ip = ctx.ip; // 日志输出 console.log(`${method} ${path} from ${ip}`); // 设置响应 ctx.status = 200; ctx.type = 'application/json'; ctx.set('X-Response-Time', Date.now().toString()); // 返回响应体 ctx.body = { success: true, data: { message: 'Hello Koa!', path, query }, timestamp: new Date().toISOString() }; });
