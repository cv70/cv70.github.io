36.2 类型定义安装

学习如何为 JavaScript 库安装类型定义

🎯 学习目标

  • 理解 DefinitelyTyped 项目
  • 学会安装和使用 @types 包
  • 掌握查找类型定义的方法
  • 学会处理无类型定义的库

📖 类型定义概述

TypeScript 类型定义通常来自两个来源：

内置类型

库自带类型定义，如 TypeScript、express 5.x

@types 包

DefinitelyTyped 项目维护的类型定义

💡
DefinitelyTyped

DefinitelyTyped 是 GitHub 上最大的类型定义仓库，包含数千个流行库的类型定义。

📦 安装常用类型定义

# Node.js 核心 npm install -D @types/node # Express npm install -D @types/express # 常用中间件 npm install -D @types/cors npm install -D @types/morgan npm install -D @types/compression npm install -D @types/cookie-parser npm install -D @types/express-session # 测试工具 npm install -D @types/jest npm install -D @types/supertest # 数据库 npm install -D @types/mongoose npm install -D @types/redis # 工具库 npm install -D @types/lodash npm install -D @types/uuid npm install -D @types/bcrypt

🔍 查找类型定义

# 使用 npm 搜索 npm search @types/package-name # 使用 TypeSearch 网站 # https://www.typescriptlang.org/dt/search # 检查包是否自带类型 # 查看 package.json 中的 "types" 或 "typings" 字段

检查库是否自带类型

// 有些库自带类型定义，无需安装 @types // 检查 node_modules/package-name/package.json { "name": "some-package", "main": "index.js", "types": "index.d.ts" // 有这个字段表示自带类型 }

⚠️ 处理无类型定义的库

1. 创建本地类型声明

// src/types/unknown-package.d.ts declare module 'unknown-package' { // 定义需要的类型 export function someFunction(param: string): number; export interface SomeOptions { debug?: boolean; } const _default: { init(options: SomeOptions): void; }; export default _default; }

2. 使用 any 类型（临时方案）

// src/types/declarations.d.ts declare module 'package-without-types' { const value: any; export default value; } // 或在使用的文件中 // @ts-ignore import somePackage from 'package-without-types';

3. 创建详细类型定义

// src/types/custom-library.d.ts declare module 'custom-library' { export interface Config { apiUrl: string; timeout?: number; retries?: number; } export interface Client { get(url: string): Promise; post(url: string, data: unknown): Promise; } export function createClient(config: Config): Client; }

✅ 小结

📌
本节要点
  • 大多数库的类型定义在 @types/xxx 包中
  • 部分库自带类型定义，无需额外安装
  • 无类型定义的库可以创建本地声明文件
  • 使用 @ts-ignore 作为临时解决方案
