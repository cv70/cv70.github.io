57.4 状态码选择

正确使用 HTTP 状态码传递 API 响应信息

📖 HTTP 状态码分类

HTTP 状态码是三位数字，分为五大类，帮助客户端理解请求的处理结果。

类别 范围 含义 示例
1xx 100-199 信息响应 - 请求已接收，继续处理 100 Continue
2xx 200-299 成功 - 请求已成功接收、理解、接受 200 OK, 201 Created
3xx 300-399 重定向 - 需要进一步操作 301 Moved, 304 Not Modified
4xx 400-499 客户端错误 - 请求包含语法错误或无法完成 400 Bad Request, 404 Not Found
5xx 500-599 服务器错误 - 服务器无法完成有效请求 500 Internal Error, 503 Unavailable

✅ 2xx 成功状态码

常用成功状态码

状态码 名称 使用场景
200 OK 请求成功，响应中包含数据
201 Created 资源创建成功，应返回 Location 头
202 Accepted 请求已接受，但处理尚未完成（异步操作）
204 No Content 请求成功，但响应体为空（DELETE 操作）
206 Partial Content 范围请求成功，返回部分内容
// 200 OK - 获取资源成功 GET /users/123 HTTP/1.1 200 OK { "id": 123, "name": "张三" } // 201 Created - 创建资源成功 POST /users HTTP/1.1 201 Created Location: /users/124 { "id": 124, "name": "新用户" } // 204 No Content - 删除成功 DELETE /users/123 HTTP/1.1 204 No Content

🔀 3xx 重定向状态码

状态码 名称 使用场景
301 Moved Permanently 资源已永久移动到新 URL
302 Found 资源临时移动到新 URL
304 Not Modified 资源未修改，使用缓存
307 Temporary Redirect 临时重定向，保持请求方法
// 301 永久重定向 GET /old-api/users HTTP/1.1 301 Moved Permanently Location: /api/v2/users // 304 未修改 - 配合缓存 GET /users/123 If-None-Match: "abc123" HTTP/1.1 304 Not Modified ETag: "abc123"

❌ 4xx 客户端错误状态码

状态码 名称 使用场景
400 Bad Request 请求语法错误、参数验证失败
401 Unauthorized 未认证，需要登录
403 Forbidden 已认证但无权限访问
404 Not Found 资源不存在
405 Method Not Allowed 请求方法不被支持
409 Conflict 请求与当前资源状态冲突
422 Unprocessable Entity 语义正确但业务验证失败
429 Too Many Requests 请求频率超限
// 400 Bad Request - 参数错误 POST /users { "name": "" } HTTP/1.1 400 Bad Request { "error": "Validation Error", "message": [ { "field": "name", "message": "姓名不能为空" } ] } // 401 Unauthorized - 未认证 GET /users/profile HTTP/1.1 401 Unauthorized WWW-Authenticate: Bearer // 403 Forbidden - 无权限 DELETE /users/123 HTTP/1.1 403 Forbidden { "error": "您没有权限删除此用户" } // 404 Not Found - 资源不存在 GET /users/999 HTTP/1.1 404 Not Found { "error": "用户不存在" }

🔥 5xx 服务器错误状态码

状态码 名称 使用场景
500 Internal Server Error 服务器内部错误
502 Bad Gateway 网关或代理收到无效响应
503 Service Unavailable 服务暂时不可用（维护/过载）
504 Gateway Timeout 网关超时
⚠️
生产环境建议

生产环境中，5xx 错误不应暴露具体的错误堆栈信息，应记录日志并返回友好的错误信息给客户端。

💻 NestJS 状态码处理

import { Controller, Get, Post, Delete, Param, Body, HttpCode, HttpStatus, NotFoundException, ForbiddenException, BadRequestException, } from '@nestjs/common'; @Controller('users') export class UserController { // 200 OK - 默认 @Get(':id') async findOne(@Param('id') id: string) { const user = await this.userService.findOne(+id); if (!user) { throw new NotFoundException('用户不存在'); // 404 } return user; // 200 } // 201 Created @Post() @HttpCode(HttpStatus.CREATED) async create(@Body() createUserDto: CreateUserDto) { return this.userService.create(createUserDto); } // 204 No Content @Delete(':id') @HttpCode(HttpStatus.NO_CONTENT) async remove(@Param('id') id: string) { await this.userService.remove(+id); } } // 自定义异常过滤器 @Catch() export class HttpExceptionFilter implements ExceptionFilter { catch(exception: unknown, host: ArgumentsHost) { const ctx = host.switchToHttp(); const response = ctx.getResponse(); const status = exception instanceof HttpException ? exception.getStatus() : HttpStatus.INTERNAL_SERVER_ERROR; response.status(status).json({ statusCode: status, timestamp: new Date().toISOString(), message: exception.message || 'Internal server error', }); } }

📊 常见场景状态码选择

场景 推荐状态码 说明
GET 成功 200 返回资源数据
POST 创建成功 201 返回 Location 头和新资源
PUT/PATCH 成功 200 返回更新后的资源
DELETE 成功 204 无响应体
参数验证失败 400 返回详细错误信息
未登录 401 提示需要认证
无权限 403 已登录但权限不足
资源不存在 404 请求的资源不存在
唯一键冲突 409 如邮箱已被注册
业务验证失败 422 语义正确但业务规则不满足

📝 小结

  • 2xx 表示成功：200 OK、201 Created、204 No Content
  • 4xx 表示客户端错误：400、401、403、404、422
  • 5xx 表示服务器错误：500、502、503、504
  • 选择正确的状态码帮助客户端理解响应含义
  • NestJS 提供了丰富的异常类和装饰器处理状态码
