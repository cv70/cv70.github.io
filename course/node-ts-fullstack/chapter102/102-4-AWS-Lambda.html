102.4 AWS Lambda

使用 AWS Lambda 构建企业级 Serverless 应用

AWS Lambda 简介

AWS Lambda 是 Amazon 提供的函数即服务 (FaaS) 平台，是市场上最成熟、功能最全的 Serverless 服务。 支持 Node.js、Python、Java、Go、.NET 等多种运行时，与 AWS 生态系统深度集成。

📊 Lambda 限制与配置

配置项 限制 说明
内存 128MB - 10GB 内存越大，CPU 越强
超时时间 1秒 - 15分钟 默认 3 秒
部署包大小 50MB (直传) / 250MB (S3) 解压后最大 250MB
环境变量 4KB 所有变量总和
并发执行 1000 (默认) 可申请提高配额

📁 Lambda 函数示例

// src/handlers/api.ts import { APIGatewayProxyEvent, APIGatewayProxyResult } from 'aws-lambda'; import { DynamoDB } from 'aws-sdk'; const dynamoDb = new DynamoDB.DocumentClient(); const TABLE_NAME = process.env.TABLE_NAME!; export const handler = async ( event: APIGatewayProxyEvent ): Promise => { const httpMethod = event.httpMethod; const pathParameters = event.pathParameters; try { switch (httpMethod) { case 'GET': if (pathParameters?.id) { return await getItem(pathParameters.id); } return await listItems(); case 'POST': return await createItem(JSON.parse(event.body || '{}')); case 'PUT': return await updateItem( pathParameters!.id, JSON.parse(event.body || '{}') ); case 'DELETE': return await deleteItem(pathParameters!.id); default: return { statusCode: 405, body: JSON.stringify({ message: 'Method not allowed' }) }; } } catch (error) { console.error('Error:', error); return { statusCode: 500, body: JSON.stringify({ message: 'Internal server error' }) }; } }; async function getItem(id: string): Promise { const result = await dynamoDb .get({ TableName: TABLE_NAME, Key: { id } }) .promise(); if (!result.Item) { return { statusCode: 404, body: JSON.stringify({ message: 'Not found' }) }; } return { statusCode: 200, body: JSON.stringify(result.Item) }; } async function listItems(): Promise { const result = await dynamoDb.scan({ TableName: TABLE_NAME }).promise(); return { statusCode: 200, body: JSON.stringify(result.Items) }; }

🚀 部署与管理

# 安装 Serverless Framework npm install -g serverless # 本地开发 serverless offline # 部署到 AWS serverless deploy serverless deploy --stage prod # 部署单个函数 serverless deploy function -f api # 查看部署信息 serverless info # 查看日志 serverless logs -f api -t # 移除服务 serverless remove

🔗 AWS 服务集成

触发器集成

  • API Gateway - HTTP API / REST API
  • S3 - 文件上传触发
  • SNS/SQS - 消息触发
  • DynamoDB Streams - 数据变更触发
  • EventBridge - 定时任务
  • CloudFront - Edge Functions

常用服务

  • DynamoDB - NoSQL 数据库
  • S3 - 对象存储
  • RDS - 关系数据库
  • ElastiCache - Redis 缓存
  • Secrets Manager - 密钥管理
  • CloudWatch - 监控日志
