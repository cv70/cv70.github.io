42.3 模块导入导出

实现模块间的依赖共享

🎯 学习目标

  • 理解模块导入导出机制
  • 掌握服务共享方式
  • 学会创建共享模块
  • 理解模块单例模式

📚 模块导出

通过 exports 属性导出服务，使其可以被其他模块使用：

// users.module.ts @Module({ controllers: [UsersController], // 控制器不需要导出 providers: [UsersService], // 声明服务 exports: [UsersService], // 导出服务供其他模块使用 }) export class UsersModule {} // 导出多个服务 @Module({ providers: [UsersService, RolesService, PermissionsService], exports: [UsersService, RolesService], }) export class UsersModule {}
💡
导出规则

控制器不需要导出，它只处理当前模块的路由。服务通过 exports 导出后，其他模块可以注入使用。

🔄 模块导入

// auth.module.ts import { Module } from '@nestjs/common'; import { UsersModule } from '../users/users.module'; @Module({ imports: [UsersModule], // 导入 UsersModule，可以使用其导出的服务 controllers: [AuthController], providers: [AuthService], }) export class AuthModule {} // auth.service.ts - 使用导入模块的服务 @Injectable() export class AuthService { constructor( private usersService: UsersService, // 可以注入 UsersService ) {} async validateUser(username: string, password: string) { const user = await this.usersService.findByUsername(username); // ... } }

📦 创建共享模块

// common/common.module.ts import { Module, Global } from '@nestjs/common'; import { LoggerService } from './logger.service'; import { ConfigService } from './config.service'; @Global() // 全局模块，所有模块都可以使用 @Module({ providers: [LoggerService, ConfigService], exports: [LoggerService, ConfigService], }) export class CommonModule {} // 其他模块不需要显式导入 CommonModule @Injectable() export class UsersService { constructor( private logger: LoggerService, // 直接注入，无需导入模块 private config: ConfigService, ) {} }
⚠️
全局模块注意

使用 @Global() 装饰器声明全局模块后，其导出的服务在任何地方都可以直接注入。但要谨慎使用，避免滥用导致依赖关系不清晰。

🔄 模块单例

NestJS 默认情况下，每个服务在整个应用中是单例的：

// 无论是哪个模块注入 UsersService，都是同一个实例 @Module({ imports: [UsersModule], // UsersModule 的服务是单例 }) export class ModuleA {} @Module({ imports: [UsersModule], // 共享同一个 UsersService 实例 }) export class ModuleB {} // 如果需要重新创建实例 @Module({ imports: [UsersModule], providers: [ { provide: UsersService, useClass: UsersService, // 创建新的实例 }, ], }) export class ModuleC {}

📝 本节小结

✅
  • • exports 导出服务供其他模块使用
  • • imports 导入其他模块，使用其导出的服务
  • • @Global() 创建全局模块
  • • 默认服务是单例的
