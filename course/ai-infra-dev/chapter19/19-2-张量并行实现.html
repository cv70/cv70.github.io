Megatron-LM的张量并行

Megatron-LM的张量并行是一种高效的层内并行策略，将Transformer层的 矩阵运算按维度切分到多个GPU上。相比普通张量并行，Megatron-LM采用了 Column-Parallel和Row-Parallel交替的策略，减少了通信次数，提高了效率。

📊 自注意力层的并行化

Column-Parallel和Row-Parallel

Transformer自注意力层： 输入：X ∈ ℝ^(B×S×H) 其中：B=batch, S=sequence, H=hidden size 标准自注意力计算： Q = X × W_Q K = X × W_K V = X × W_V Attention(Q, K, V) = softmax(QK^T / √d) × V Megatron张量并行切分： 假设TP（tensor parallel）= 4 1. QKV投影（Column-Parallel） ┌─────────────────────────────────────┐ │ W_Q ∈ ℝ^(H×H) │ ├─────────────────────────────────────┤ │ W_Q₁ | W_Q₂ | W_Q₃ | W_Q₄ │ │ H/4 H/4 H/4 H/4 │ │ GPU0 GPU1 GPU2 GPU3 │ └─────────────────────────────────────┘ 每个GPU： Q_i = X × W_Q_i (B×S×H/4) K_i = X × W_K_i (B×S×H/4) V_i = X × W_V_i (B×S×H/4) 2. 注意力计算 每个GPU独立计算： • Q_i × K_i^T • softmax • × V_i 得到：Attention_i ∈ ℝ^(B×S×H/4) 3. 输出投影（Row-Parallel） ┌─────────────────────────────────────┐ │ W_O ∈ ℝ^(H×H) │ ├─────────────────────────────────────┤ │ W_O₁ │ GPU0 ├─────────────────────────────────────┤ │ W_O₂ │ GPU1 ├─────────────────────────────────────┤ │ W_O₃ │ GPU2 ├─────────────────────────────────────┤ │ W_O₄ │ GPU3 └─────────────────────────────────────┤ 每个GPU： Partial_O_i = Attention_i × W_O_i AllReduce求和： O = Σ Partial_O_i (B×S×H) 关键优化： • Column-Parallel：无需通信 • Row-Parallel：一次AllReduce • 总通信：1次AllReduce（而非2次）

📊 MLP层的并行化

GeLU层的并行化

Transformer MLP层： 标准计算： 1. 线性变换：H1 = X × W₁ + b₁ 2. 激活函数：A = GeLU(H1) 3. 线性变换：O = A × W₂ + b₂ Megatron张量并行： 假设TP = 4 1. 第一个线性层（Column-Parallel） ┌─────────────────────────────────────┐ │ W₁ ∈ ℝ^(H×4H) │ ├─────────────────────────────────────┤ │ W₁₁ | W₁₂ | W₁₃ | W₁₄ │ │ 4H 4H 4H 4H │ │ GPU0 GPU1 GPU2 GPU3 │ └─────────────────────────────────────┘ 每个GPU： H1_i = X × W₁_i (B×S×4H) 偏置b₁也切分： b₁_i ∈ ℝ^(4H) 2. 激活函数 每个GPU独立计算： A_i = GeLU(H1_i) (B×S×4H) 3. 第二个线性层（Row-Parallel） ┌─────────────────────────────────────┐ │ W₂ ∈ ℝ^(4H×H) │ ├─────────────────────────────────────┤ │ W₂₁ │ GPU0 ├─────────────────────────────────────┤ │ W₂₂ │ GPU1 ├─────────────────────────────────────┤ │ W₂₃ │ GPU2 ├─────────────────────────────────────┤ │ W₂₄ │ GPU3 └─────────────────────────────────────┘ 每个GPU： Partial_O_i = A_i × W₂_i (B×S×H) AllReduce求和： O = Σ Partial_O_i (B×S×H) 偏置b₂： • 只在GPU0上有完整副本 • 广播到其他GPU（或直接加到结果） 通信总结： • Column-Parallel：无需通信 • Row-Parallel：1次AllReduce • 总通信：2次AllReduce（Attention + MLP）

Column-Parallel：无需通信 output = torch.nn.functional.linear(x, self.weight, self.bias) return output Row-Parallel Linear： class RowParallelLinear(torch.nn.Module): def __init__(self, in_features, out_features): super().__init__() self.in_features = in_features self.out_features = out_features # 获取TP配置 self.tensor_model_parallel_size = mpu.get_tensor_model_parallel_world_size() self.tensor_model_parallel_rank = mpu.get_tensor_model_parallel_rank() # 切分输入维度 self.input_size_per_partition = in_features // self.tensor_model_parallel_size # 权重初始化 self.weight = torch.nn.Parameter( torch.empty(out_features, self.input_size_per_partition) ) self.bias = torch.nn.Parameter(torch.empty(out_features)) # 初始化权重 torch.nn.init.xavier_uniform_(self.weight) torch.nn.init.zeros_(self.bias) def forward(self, x): # Row-Parallel需要AllReduce input_parallel = x # 矩阵乘法 output_parallel = torch.nn.functional.linear( input_parallel, self.weight ) # AllReduce聚合 output = mpu.reduce_from_tensor_model_parallel_region(output_parallel) # 加上偏置 output = output + self.bias return output 完整Transformer Block： class TransformerBlock(torch.nn.Module): def __init__(self, hidden_size, num_attention_heads): super().__init__() # 自注意力层 self.attention = SelfAttention( hidden_size, num_attention_heads ) # MLP层 self.mlp = MLP(hidden_size) def forward(self, x): # 自注意力 + 残差 + LayerNorm attn_output = self.attention(x) x = x + attn_output x = layer_norm(x) # MLP + 残差 + LayerNorm mlp_output = self.mlp(x) x = x + mlp_output x = layer_norm(x) return x

⚡ 通信优化

计算通信重叠

  • 异步通信：非阻塞AllReduce
  • 流水线：通信与计算重叠
  • 预取：提前启动通信

  • 混合精度：FP16通信
  • 梯度累积：减少同步频率
  • 通信融合：合并多次通信

    • 📊 性能分析

    张量并行的性能特性

    指标 说明 优化策略
    通信次数 每层2次AllReduce 通信计算重叠
    通信量 与隐藏维度成正比 混合精度
    计算量 与TP无关 不适用
    扩展性 通信随TP增加 限制TP≤8
    💡

    张量并行适合小规模并行（≤8），因为通信开销随TP线性增长。大规模并行应该使用流水线并行。

    ⚠️
    注意事项
    • TP限制：TP通常≤8，通信开销大
    • 隐藏维度：必须能被TP整除
    • 偏置处理：需要正确广播偏置
    • 初始化：需要跨GPU一致初始化
    • 调试困难：分布式系统调试复杂

    📝 本节小结

    ✅
    • • Megatron-LM采用Column-Parallel和Row-Parallel交替策略
    • • 自注意力和MLP层都可以高效并行化
    • • 每层只需1次AllReduce，减少通信
    • • 适合小规模并行（TP≤8）
    • • 单机多卡（NVLink）效果最佳
