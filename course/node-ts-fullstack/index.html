🎯 课程结构

第一部分：TypeScript 基础篇 (第1-10章)

  • TypeScript 简介与环境搭建
  • 基础类型
  • 接口与类型别名
  • 函数与类
  • 泛型与高级类型

第二部分：Node.js 基础篇 (第11-20章)

  • Node.js 简介与环境搭建
  • 模块系统
  • File System 文件系统
  • HTTP 模块
  • Crypto 加密模块

第三部分：数据库篇 (第21-29章)

  • MySQL 基础
  • TypeORM 基础与关系映射
  • Prisma ORM
  • MongoDB 基础
  • Redis 缓存

第四部分：Web 框架篇 (第30-50章)

  • Express 基础与进阶
  • Koa 框架
  • NestJS 核心
  • 中间件与管道
  • 数据库集成

第五部分：认证与API (第51-67章)

  • JWT 认证
  • Passport.js
  • RESTful API
  • GraphQL
  • WebSocket

第六部分：工程化与部署 (第68-118章)

  • 测试 (Jest)
  • 前端集成 (React/Vue)
  • Docker 容器化
  • CI/CD 与云部署
  • 微服务架构
