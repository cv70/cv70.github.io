52.3 Session 存储

选择合适的 Session 存储方案

🎯 学习目标

  • 了解不同存储方案的特点
  • 掌握 Redis 存储的配置
  • 学会数据库存储的实现
  • 理解存储选择的权衡

📊 存储方案对比

/* +------------+------------+----------------+------------------+ | 存储类型 | 性能 | 持久化 | 适用场景 | +------------+------------+----------------+------------------+ | 内存 | 极快 | 否 | 开发/测试 | | 文件 | 一般 | 是 | 小型应用 | | Redis | 快 | 是 | 生产环境 | | 数据库 | 一般 | 是 | 需要查询 | | MongoDB | 较快 | 是 | MongoDB项目 | +------------+------------+----------------+------------------+ */ // 默认内存存储的问题 // 1. 服务器重启，所有 Session 丢失 // 2. 无法支持多实例部署 // 3. 内存占用不可控 // 4. 不适合生产环境

🔴 Redis 存储

// 安装依赖 // npm install connect-redis redis import session from 'express-session'; import RedisStore from 'connect-redis'; import { createClient } from 'redis'; // 创建 Redis 客户端 const redisClient = createClient({ url: process.env.REDIS_URL || 'redis://localhost:6379', password: process.env.REDIS_PASSWORD }); redisClient.connect().catch(console.error); redisClient.on('error', (err) => { console.error('Redis 连接错误:', err); }); redisClient.on('connect', () => { console.log('Redis 连接成功'); }); // 配置 Session 存储 app.use(session({ store: new RedisStore({ client: redisClient, prefix: 'sess:', // Key 前缀 ttl: 86400, // 过期时间（秒） disableTouch: false, // 是否禁用触摸（延长过期时间） }), secret: process.env.SESSION_SECRET!, resave: false, saveUninitialized: false, cookie: { secure: process.env.NODE_ENV === 'production', httpOnly: true, maxAge: 1000 * 60 * 60 * 24 // 24小时 } })); // Redis 中的 Session Key 格式 // sess:sessionId -> JSON.stringify(sessionData) // 高级 Redis 配置 const advancedRedisStore = new RedisStore({ client: redisClient, prefix: 'myapp:sess:', // 自定义序列化（如果存储复杂对象） serializer: { parse: (str) => JSON.parse(str), stringify: (obj) => JSON.stringify(obj) }, // 不自动移除过期 Session（让 Redis TTL 处理） disableTTL: true }); // 手动管理 Session（可选） async function manageSessions() { // 获取所有 Session Keys const keys = await redisClient.keys('sess:*'); // 获取特定 Session const sessionData = await redisClient.get('sess:abc123'); // 删除 Session await redisClient.del('sess:abc123'); // 设置过期时间 await redisClient.expire('sess:abc123', 3600); // 获取 Session 数量 const count = await redisClient.dbSize(); }
💡
Redis 优势

Redis是生产环境首选的Session存储方案：快速、支持过期时间、支持分布式部署、持久化可选。使用Redis Sentinel或Cluster可以进一步提高可用性。

🍃 MongoDB 存储

// 安装依赖 // npm install connect-mongo import MongoStore from 'connect-mongo'; // MongoDB Session 存储 app.use(session({ store: MongoStore.create({ mongoUrl: process.env.MONGODB_URI!, dbName: 'myapp', collectionName: 'sessions', // 自动删除过期 Session autoRemove: 'native', // 使用 MongoDB TTL 索引 autoRemoveInterval: 10, // 检查间隔（分钟） // 可选：加密 Session 数据 // crypto: { // secret: process.env.SESSION_CRYPTO_SECRET! // } }), secret: process.env.SESSION_SECRET!, resave: false, saveUninitialized: false, cookie: { maxAge: 1000 * 60 * 60 * 24 } })); // MongoDB Session 文档结构 interface SessionDocument { _id: string; // Session ID expires: Date; // 过期时间 session: { userId: string; username: string; // ... 其他 Session 数据 }; } // 查询活跃用户 async function getActiveUsers(): Promise<string[]> { const sessions = await db.collection('sessions') .find({ expires: { $gt: new Date() } }) .toArray(); return sessions.map(s => s.session.userId); } // 获取用户所有活跃 Session async function getUserSessions(userId: string) { const sessions = await db.collection('sessions') .find({ 'session.userId': userId, expires: { $gt: new Date() } }) .toArray(); return sessions; }

🗄️ 数据库存储（TypeORM）

// 自定义 Session 存储 import { Entity, PrimaryColumn, Column } from 'typeorm'; @Entity() class Session { @PrimaryColumn() id: string; @Column({ type: 'json' }) data: Record<string, any>; @Column({ type: 'timestamp' }) expiresAt: Date; @Column({ type: 'timestamp' }) createdAt: Date; @Column({ type: 'varchar', nullable: true }) userId?: string; } // 实现 Session Store import { Store } from 'express-session'; class TypeORMStore extends Store { private sessionRepository; constructor(sessionRepository: any) { super(); this.sessionRepository = sessionRepository; } async get( sid: string, callback: (err: any, session?: any) => void ) { try { const session = await this.sessionRepository.findOne({ where: { id: sid } }); if (!session || session.expiresAt < new Date()) { return callback(null, null); } callback(null, session.data); } catch (err) { callback(err); } } async set( sid: string, session: any, callback: (err?: any) => void ) { try { const expiresAt = new Date( Date.now() + (session.cookie?.maxAge || 86400000) ); await this.sessionRepository.save({ id: sid, data: session, expiresAt, createdAt: new Date(), userId: session.userId }); callback(); } catch (err) { callback(err); } } async destroy(sid: string, callback: (err?: any) => void) { try { await this.sessionRepository.delete({ id: sid }); callback(); } catch (err) { callback(err); } } async touch( sid: string, session: any, callback: (err?: any) => void ) { try { const expiresAt = new Date( Date.now() + (session.cookie?.maxAge || 86400000) ); await this.sessionRepository.update( { id: sid }, { expiresAt } ); callback(); } catch (err) { callback(err); } } // 清理过期 Session async cleanup() { await this.sessionRepository .createQueryBuilder() .delete() .where('expiresAt < :now', { now: new Date() }) .execute(); } } // 使用 const sessionStore = new TypeORMStore( dataSource.getRepository(Session) ); // 定期清理 setInterval(() => sessionStore.cleanup(), 3600000); app.use(session({ store: sessionStore, secret: process.env.SESSION_SECRET!, resave: false, saveUninitialized: false }));

📝 本节小结

✅
  • • 内存存储不适合生产环境
  • • Redis是生产环境首选方案
  • • MongoDB适合已有MongoDB的项目
  • • 数据库存储便于查询和分析
  • • 需要定期清理过期Session
