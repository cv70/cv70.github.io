53.4 单级放大器

构建模拟电路的基本放大单元

🎯 学习目标

  • 掌握四种基本单级放大器结构
  • 理解各种放大器的增益特性
  • 学会分析输入输出阻抗
  • 了解频率响应特性

🔧 四种基本放大器结构

放大器分类

类型 输入 输出 阻抗特性
共源极（CS） 栅极 漏极 高入、高出
共栅极（CG） 源极 漏极 低入、高出
共漏极（CD）/源极跟随器 栅极 源极 高入、低出
共源共栅（Cascode） 栅极 漏极 高入、更高出

📊 共源极放大器（Common Source）

最常用的增益级

电压增益：Av = -gm·RL' 输入阻抗：Rin ≈ ∞ 输出阻抗：Rout = ro || RL'
  • 优点：高电压增益、高输入阻抗
  • 缺点：米勒效应影响带宽、输出阻抗中等
  • 应用：主放大级、增益级

🔄 共栅极放大器（Common Gate）

电流缓冲器

电压增益：Av = gm·RL' 输入阻抗：Rin = 1/(gm + gmb) 输出阻抗：Rout = ro || RL'
  • 优点：宽带宽、无米勒效应、低输入阻抗
  • 缺点：电压增益有限、输入阻抗低
  • 应用：电流缓冲、高频放大、跨阻放大

👤 共漏极放大器（Common Drain）

源极跟随器/电压缓冲器

电压增益：Av ≈ gm·Rs/(gm·Rs + 1) < 1 输入阻抗：Rin ≈ ∞ 输出阻抗：Rout = 1/(gm + gmb) || Rs
  • 优点：低输出阻抗、高输入阻抗、宽带宽
  • 缺点：电压增益小于1
  • 应用：输出缓冲、驱动重负载
💡
米勒效应（Miller Effect）

共源极放大器中，栅漏电容Cgd被放大(1+|Av|)倍，严重影响高频性能。这是限制CS放大器带宽的主要因素。

Cin,Miller = Cgs + (1 + |Av|)·Cgd

🏗️ 共源共栅放大器（Cascode）

高增益、高输出阻抗结构

电压增益：Av ≈ -gm1·(gm2·ro1·ro2) 输出阻抗：Rout ≈ (gm2 + gmb2)·ro2·ro1
  • 优点：极高的输出阻抗、高增益、减小米勒效应
  • 缺点：输出摆幅减小、需要更高的电源电压
  • 应用：高增益放大级、电流镜、OTA

📈 有源负载放大器

使用电流源作为负载

Av = -gm1·(ro1 || ro2)

使用PMOS电流源作为NMOS输入管的负载，获得较高的交流阻抗而不消耗太多电压余度。

  • 相比电阻负载，有源负载具有更高的交流阻抗
  • 直流压降小，节省电压余度
  • 是CMOS运放的基本构成单元

⚡ 频率响应分析

主极点位置

结构 主极点 带宽
共源极 输出节点 受米勒效应限制
共栅极 输入/输出节点 较宽
共漏极 输出节点 很宽
Cascode 输出节点 改善的CS带宽

📝 本节小结

✅
  • • 共源极是最常用的增益级，但受米勒效应影响
  • • 共栅极是电流缓冲器，适合高频应用
  • • 共漏极是电压缓冲器，用于驱动负载
  • • Cascode结构提供高输出阻抗和高增益
  • • 有源负载是CMOS模拟设计的基本技术
  • • 选择合适的结构需要权衡增益、带宽和阻抗
