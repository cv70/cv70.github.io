特征存储概述

特征存储（Feature Store）是集中存储、管理和提供机器学习特征的系统。 它解决了特征复用、数据漂移、训练-服务一致性等挑战，是MLOps的关键组件。

🏗️ 特征存储架构

图：Feast特征存储架构

离线存储

存储历史特征数据。

  • 大数据量
  • 时间旅行
  • 批量查询
  • 训练数据生成

在线存储

提供实时特征服务。

  • 低延迟
  • 高可用
  • 实时更新
  • 推理服务

特征服务

统一特征访问接口。

  • API服务
  • 缓存机制
  • 多数据源
  • 版本管理

🔧 定义特征

数据源定义

from datetime import timedelta from feast import ( FeatureStore, FeatureView, Field, DataSource ) from feast.types import Float32, Int64, String from feast.data_source import FileSource # 定义数据源 user_source = FileSource( path="data/user_features.parquet", event_timestamp_column="created_at", created_timestamp_column="created_at", description="User features data" )

特征视图定义

# 定义用户特征视图 user_features = FeatureView( name="user_features", sources=[user_source], schema=[ Field(name="user_id", dtype=Int64), Field(name="age", dtype=Int64), Field(name="gender", dtype=String), Field(name="income", dtype=Float32), Field(name="purchase_count", dtype=Int64), Field(name="avg_purchase_amount", dtype=Float32), ], ttl=timedelta(days=30), # 特征有效期 description="User demographic and purchase features" ) # 定义交易特征视图 transaction_source = FileSource( path="data/transactions.parquet", event_timestamp_column="event_time", created_timestamp_column="event_time" ) transaction_features = FeatureView( name="transaction_features", sources=[transaction_source], schema=[ Field(name="transaction_id", dtype=String), Field(name="user_id", dtype=Int64), Field(name="amount", dtype=Float32), Field(name="category", dtype=String), ], ttl=timedelta(days=7), description="Transaction features" )

特征注册

from feast import FeatureStore # 创建特征存储 store = FeatureStore(repo_path=".") # 注册特征视图 store.apply([ user_features, transaction_features ]) # 验证注册 registered_views = store.list_feature_views() print("Registered feature views:") for view in registered_views: print(f" - {view.name}")

📊 离线特征获取

生成训练数据

import pandas as pd from datetime import datetime, timedelta # 定义实体DataFrame entity_df = pd.DataFrame({ "user_id": [1, 2, 3, 4, 5], "event_timestamp": [ datetime.now(), datetime.now() - timedelta(days=1), datetime.now() - timedelta(days=2), datetime.now() - timedelta(days=3), datetime.now() - timedelta(days=4), ] }) # 获取离线特征 training_data = store.get_historical_features( entity_df=entity_df, features=[ "user_features:age", "user_features:gender", "user_features:income", "user_features:purchase_count", "user_features:avg_purchase_amount", ] ).to_df() print(training_data.head())

时间旅行

# 获取历史某个时间点的特征 historical_data = store.get_historical_features( entity_df=entity_df, features=[ "user_features:age", "user_features:purchase_count", ], full_dataset=True # 获取完整历史 ) # 时间旅行到特定日期 past_date = datetime(2024, 1, 1) historical_features = store.get_historical_features( entity_df=entity_df, features=["user_features:*"], full_dataset=False, force_update_cache=True )

批量特征计算

# 定义特征变换 from feast import on_demand_feature_view @on_demand_feature_view( sources=[user_features], schema=[ Field(name="user_score", dtype=Float32), ] ) def user_score_transform(user_features): """ 计算用户评分 """ # 基于多个特征计算新特征 score = ( user_features["purchase_count"] * 0.3 + user_features["avg_purchase_amount"] * 0.5 + (user_features["age"] / 100) * 0.2 ) return pd.DataFrame({"user_score": score})

🚀 在线特征服务

加载在线特征

# 将特征加载到在线存储 store.materialize_incremental( end_date=datetime.now() ) # 或加载特定时间范围 store.materialize( start_date=datetime.now() - timedelta(days=7), end_date=datetime.now() )

获取在线特征

# 单个实体获取 online_features = store.get_online_features( features=[ "user_features:age", "user_features:gender", "user_features:income", ], entity_rows=[ {"user_id": 1} ] ) print(online_features.to_dict()) # 批量获取 batch_features = store.get_online_features( features=[ "user_features:age", "user_features:purchase_count", ], entity_rows=[ {"user_id": 1}, {"user_id": 2}, {"user_id": 3}, ] ) print(batch_features.to_df())

实时特征更新

from feast import PushSource # 定义流式数据源 transaction_push_source = PushSource( name="transaction_push_source", batch_source=transaction_source ) # 实时推送特征 store.push( source_name="transaction_push_source", df=pd.DataFrame({ "transaction_id": ["tx123"], "user_id": [1], "amount": [100.0], "category": ["electronics"], "event_time": [datetime.now()] }) ) # 特征立即在线可用 online_features = store.get_online_features( features=["transaction_features:amount"], entity_rows=[{"user_id": 1}] )
