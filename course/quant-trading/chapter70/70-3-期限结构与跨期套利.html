期限结构与跨期套利

期货期限结构是指同一商品不同到期月份合约的价格关系，反映了市场对未来价格的预期和供需状况。跨期套利利用不同月份合约之间的价差变化获取收益，是期货市场最经典且风险相对可控的策略之一。

📊 期限结构类型

升水（Contango）

  • 远月价格 > 近月价格
  • 期货曲线向上倾斜
  • 通常表示供过于求或充足库存
  • 持有成本模型：远月 = 近月 + 仓储费 + 利息
  • 多头移仓会产生负收益
  • 常见于：铜、黄金、农产品丰收季

贴水（Backwardation）

  • 近月价格 > 远月价格
  • 期货曲线向下倾斜
  • 通常表示供不应求或库存紧张
  • 便利收益高于持有成本
  • 多头移仓会产生正收益
  • 常见于：原油短缺、农产品歉收

🔄 跨期套利策略

策略类型 操作 盈利条件 风险等级
牛市跨期套利 买入近月，卖出远月 近月涨幅 > 远月涨幅 中
熊市跨期套利 卖出近月，买入远月 近月跌幅 > 远月跌幅 中
蝶式跨期 买入近月+远月，卖出中月 价差回归均值 中低
展期套利 持有近月，到期移仓至远月 获得展期收益 低

📐 影响期限结构的因素

库存水平

库存低 → 贴水，库存高 → 升水。库存是判断期限结构最重要的指标之一。

季节性因素

农产品在收获季节常升水，在消费旺季常贴水。周期性行业影响明显。

利率水平

利率高 → 持有成本高 → 升水概率大。利率变化影响资金成本和仓储成本。

供需预期

未来预期供不应求 → 贴水，预期供过于求 → 升水。市场预期驱动价格结构。

持有成本

包括仓储费、保险费、利息等。持有成本高 → 升水概率大。

便利收益

持有实物带来的便利性。便利收益高 → 贴水概率大，如原油。

💻 Python实现示例

# 期限结构与跨期套利策略
import pandas as pd
import numpy as np
from datetime import datetime

class TermStructureAnalyzer:
    """期限结构分析器"""

    def __init__(self):
        self.contracts = {}

    def calculate_term_structure(self, futures_prices):
        """计算期限结构"""
        # futures_prices: {'M1': price, 'M2': price, ...}
        contracts = sorted(futures_prices.keys())
        prices = [futures_prices[c] for c in contracts]

        # 计算各月价差
        spreads = {}
        for i in range(len(contracts)-1):
            spread = prices[i+1] - prices[i]
            spreads[f"{contracts[i]}-{contracts[i+1]}"] = spread

        # 判断结构
        avg_spread = np.mean(list(spreads.values()))
        if avg_spread > 0:
            structure = "Contango"  # 升水
        elif avg_spread < 0:
            structure = "Backwardation"  # 贴水
        else:
            structure = "Flat"

        return {
            'structure': structure,
            'spreads': spreads,
            'avg_spread': avg_spread,
            'steepness': (prices[-1] - prices[0]) / prices[0] * 100
        }

    def calculate_roll_yield(self, near_price, far_price, days_to_expiry):
        """计算展期收益"""
        roll_yield = (far_price - near_price) / near_price / days_to_expiry * 365
        return roll_yield

    def calendar_spread_signal(self, near_price, far_price, historical_spread):
        """生成跨期套利信号"""
        current_spread = far_price - near_price
        spread_zscore = (current_spread - historical_spread.mean()) / historical_spread.std()

        if spread_zscore > 2:
            return {
                'signal': 'short_spread',
                'action': '卖出近月，买入远月',
                'reason': '价差过大，预期回归'
            }
        elif spread_zscore < -2:
            return {
                'signal': 'long_spread',
                'action': '买入近月，卖出远月',
                'reason': '价差过小，预期扩大'
            }
        else:
            return {
                'signal': 'hold',
                'action': '持有',
                'reason': '价差在正常范围'
            }

    def butterfly_spread(self, prices):
        """蝶式跨期"""
        # prices = [M1, M2, M3, M4, M5, M6]
        wings = prices[::2]  # M1, M3, M5
        body = prices[1::2]  # M2, M4, M6

        # 计算蝶式价差
        butterfly = wings[2] - 2*body[1] + wings[1]

        return {
            'butterfly_value': butterfly,
            'trade': f"买入M1+M5，卖出2*M3" if butterfly > 0 else f"卖出M1+M5，买入2*M3"
        }

class CalendarSpreadStrategy:
    """跨期套利策略"""

    def __init__(self, symbol, near_contract, far_contract):
        self.symbol = symbol
        self.near_contract = near_contract
        self.far_contract = far_contract
        self.position = None
        self.entry_spread = None

    def on_bar(self, near_price, far_price):
        """每根K线回调"""
        spread = far_price - near_price

        if self.position is None:
            # 开仓逻辑
            if spread > self.entry_threshold:
                self.open_position('short_spread', near_price, far_price, spread)
            elif spread < -self.entry_threshold:
                self.open_position('long_spread', near_price, far_price, spread)
        else:
            # 平仓逻辑
            current_spread = far_price - near_price
            pnl = self.calculate_pnl(current_spread)

            if abs(pnl) > self.tp_threshold or pnl < -self.sl_threshold:
                self.close_position(current_spread)

    def open_position(self, direction, near_price, far_price, spread):
        """开仓"""
        self.position = direction
        self.entry_near = near_price
        self.entry_far = far_price
        self.entry_spread = spread
        print(f"Open {direction}: Near={near_price}, Far={far_price}, Spread={spread}")

    def close_position(self, current_spread):
        """平仓"""
        pnl = self.calculate_pnl(current_spread)
        print(f"Close {self.position}: Entry={self.entry_spread}, Exit={current_spread}, PnL={pnl}")
        self.position = None
        return pnl

    def calculate_pnl(self, current_spread):
        """计算盈亏"""
        if self.position == 'long_spread':
            return current_spread - self.entry_spread
        elif self.position == 'short_spread':
            return self.entry_spread - current_spread
        return 0

# 使用示例
if __name__ == '__main__':
    analyzer = TermStructureAnalyzer()

    # 模拟期货价格
    futures_prices = {
        'M1': 5000,
        'M2': 5050,
        'M3': 5100,
        'M4': 5150,
        'M5': 5200
    }

    # 分析期限结构
    ts = analyzer.calculate_term_structure(futures_prices)
    print("Term Structure:", ts)

    # 计算展期收益
    roll_yield = analyzer.calculate_roll_yield(5000, 5050, 30)
    print(f"Roll Yield: {roll_yield:.2%}")

    # 跨期套利策略
    strategy = CalendarSpreadStrategy('RB', 'M1', 'M2')
    strategy.entry_threshold = 100
    strategy.tp_threshold = 80
    strategy.sl_threshold = -120

    # 模拟价格变动
    for i in range(10):
        near = 5000 + i * 5
        far = 5150 - i * 8
        strategy.on_bar(near, far)

📈 展期收益管理

📋
展期收益策略

在升水市场，持有近月多头到期后移仓到远月会产生亏损（展期收益为负）；在贴水市场，移仓会产生收益（展期收益为正）。长期投资者应选择展期收益为正的品种进行多头配置，或做空展期收益为负的品种。

⚠️
风险提示

跨期套利风险：1）价差可能持续扩大，产生亏损；2）临近交割时流动性下降，滑点增大；3）极端行情下价差可能反向变动；4）移仓成本可能侵蚀收益；5）期货合约可能存在流动性风险。建议严格控制仓位，设置止损，避免临近交割时仍持有头寸。

✨
最佳实践

跨期套利成功的关键：1）深入研究品种的期限结构特征；2）建立价差的历史统计区间；3）关注库存和供需基本面变化；4）做好移仓计划，避免临近交割；5）多品种多期限分散风险；6）使用程序化交易提高执行效率；7）严格风险管理，设置止损止盈。
