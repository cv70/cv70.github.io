6.7 体效应与亚阈值特性

体效应，亚阈值导电

🎯 学习目标

  • 理解体效应的物理机制与影响
  • 掌握体效应对阈值电压的调制
  • 理解亚阈值导电的原理
  • 认识亚阈值特性在低功耗设计中的应用

为什么研究体效应和亚阈值特性

体效应和亚阈值特性是 MOSFET 的两个重要非理想特性。体效应影响阈值电压，在电路设计中必须考虑；亚阈值导电是漏电流的主要来源之一，对低功耗设计至关重要。同时，亚阈值区也是超低功耗电路的工作区域。

💡 体效应（Body Effect）

什么是体效应

体效应（Body Effect）又称衬底偏置效应，是指当 MOSFET 的源极与衬底之间存在电位差时，阈值电压发生改变的现象。

在集成电路中，通常所有 NMOS 共享同一个 P 型衬底，所有 PMOS 共享同一个 N 阱。当源极电位与衬底电位不同时，就会产生体效应。

物理机制

源-衬底反偏（NMOS）：

  1. 源极电位高于衬底电位（VSB > 0）
  2. 源-衬底 PN 结反偏
  3. 沟道下方的耗尽区宽度增加
  4. 耗尽层中固定电荷增加
  5. 需要更大的栅压来达到强反型
  6. → 阈值电压增大

阈值电压的体效应公式

📐

Vth = Vth0 + γ(√|2φF + VSB| - √|2φF|)

其中：

  • Vth0：VSB = 0 时的阈值电压
  • γ（gamma）：体效应系数
  • φF：费米电势
  • VSB：源-衬底电压差

体效应系数 γ

γ = √(2qεsNA) / Cox

体效应系数取决于：

  • 衬底掺杂浓度 NA：掺杂越高，γ 越大
  • 栅氧化层电容 Cox：氧化层越薄，γ 越小

典型值：γ ≈ 0.3-0.8 V^½

体效应的影响

对数字电路
  • 传输门中源极电位变化导致 Vth 变化
  • 影响开关阈值和噪声容限
  • 可能导致逻辑错误
对模拟电路
  • 电流镜源极电位不同导致失配
  • 差分对共模范围受限
  • 可能引起增益变化

体效应的应用

动态阈值电压调整：

  • 通过调整衬底偏置动态改变 Vth
  • VTCMOS：可变阈值 CMOS 技术
  • 低功耗设计中降低静态功耗

避免体效应的方法：

  • 源极与衬底短接（在分离阱工艺中）
  • 使用三阱工艺隔离器件
  • 电路设计时考虑体效应影响

📊 亚阈值特性（Subthreshold Characteristics）

什么是亚阈值区

亚阈值区（Subthreshold Region）是指 VGS < Vth 时，MOSFET 并非完全截止，而是存在微小电流的工作状态。这个区域也称为弱反型区（Weak Inversion Region）。

亚阈值电流的来源

在亚阈值区，导电机制与强反型区不同：

  • 表面尚未形成强反型沟道
  • 但存在弱反型层（电子浓度略高于空穴）
  • 电流由扩散机制主导（而非漂移）
  • 类似 NPN 双极型晶体管的工作方式

亚阈值电流方程

📐

ID = I0 · exp[(VGS - Vth) / (nVT)] · [1 - exp(-VDS/VT)]

当 VDS > 3VT（约 75mV@室温）时：

ID ≈ I0 · exp[(VGS - Vth) / (nVT)]

其中：

  • I0：特征电流（与工艺相关）
  • n：亚阈值斜率因子（通常 1.0-1.5）
  • VT = kT/q：热电压（室温约 26mV）

亚阈值斜率（Subthreshold Swing）

📐

亚阈值斜率 S定义为漏极电流变化一个数量级所需的栅压变化：

S = dVGS / d(logID) = nVT · ln(10)

理想情况下 n = 1，室温下：

Smin = 26mV × ln(10) ≈ 60 mV/decade

实际器件 S 通常为 70-100 mV/decade

🔧 亚阈值特性的工程意义

漏电流问题

亚阈值导电是静态功耗的主要来源：

  • VGS = 0 时，ID 并不完全为零
  • 漏电流随温度指数增加
  • 短沟道器件漏电更严重
  • 在低功耗设计中必须控制

典型值：现代工艺漏电流约 1-100 nA/μm

亚阈值电路设计

利用亚阈值区的指数特性进行超低功耗设计：

优势
  • 电源电压可降至 0.3-0.5V
  • 功耗极低（pW-nW 级）
  • 指数特性适合模拟计算
  • 适合生物医疗、IoT 应用
挑战
  • 速度慢（电流小）
  • 对工艺偏差敏感
  • 噪声影响大
  • 温度稳定性差

DIBL 效应

漏致势垒降低（Drain-Induced Barrier Lowering, DIBL）：

  • 漏极电压影响源端势垒高度
  • 导致亚阈值斜率随 VDS 变化
  • 短沟道效应的表现之一
  • 增加漏电流，恶化开关特性

📊 体效应与亚阈值特性参数对比

⚠️
温度对亚阈值特性的影响

亚阈值电流对温度极为敏感：

  • VT = kT/q，温度升高，VT 增大
  • 漏电流随温度指数增加
  • 温度每升高 10°C，漏电流约增加 2 倍
  • 高温下的静态功耗问题更加突出

📝 本节小结

✅
  • • 体效应：源-衬底电压差改变阈值电压，Vth 随 VSB 增大而增大
  • • 体效应系数 γ 取决于衬底掺杂和氧化层厚度
  • • 亚阈值区：VGS < Vth 时存在扩散电流，呈指数特性
  • • 亚阈值斜率 S 决定开关特性，理想值约 60mV/decade
  • • 亚阈值漏电是静态功耗主要来源，也可用于超低功耗设计
