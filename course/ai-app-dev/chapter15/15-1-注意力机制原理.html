15.1 注意力机制原理

什么是注意力机制

注意力机制（Attention Mechanism）源于人类视觉系统的启发。人类在观察图像时， 不会同时处理所有信息，而是聚焦于关键区域。同样，注意力机制让神经网络能够"关注"输入的重要部分， 这极大地提升了模型处理长序列的能力和可解释性。

📐 注意力机制的核心公式

# 注意力机制计算过程 # 1. 计算注意力分数（Query与Keys的相似度） scorei = similarity(Query, Keyi) # 2. Softmax归一化得到注意力权重 αi = softmax(scorei) = exp(scorei) / Σj exp(scorej) # 3. 加权求和得到上下文向量 Context = Σi αi * Valuei # 其中： # Query (Q) - 查询向量，表示当前关注点 # Key (K) - 键向量，用于与Query计算相关性 # Value (V) - 值向量，实际需要提取的信息

📊 常见的注意力计算方式

类型 计算方式 特点
点积注意力 score(Q, K) = Q · KT 计算高效，需要缩放
缩放点积注意力 score(Q, K) = Q · KT / √dk 防止梯度消失，Transformer使用
加性注意力 score(Q, K) = vTtanh(WqQ + WkK) 灵活但计算量大
余弦相似度 score(Q, K) = Q · K / (|Q||K|) 归一化，受向量长度影响小

💻 PyTorch实现加性注意力

import torch import torch.nn as nn import torch.nn.functional as F class AdditiveAttention(nn.Module): def __init__(self, hidden_dim): super().__init__() self.W_q = nn.Linear(hidden_dim, hidden_dim) self.W_k = nn.Linear(hidden_dim, hidden_dim) self.v = nn.Linear(hidden_dim, 1) def forward(self, query, keys, values, mask=None): # query: [batch_size, hidden_dim] # keys: [batch_size, seq_len, hidden_dim] # values: [batch_size, seq_len, hidden_dim] # 扩展query维度以便广播 query = self.W_q(query).unsqueeze(1) # [batch, 1, hidden] keys = self.W_k(keys) # [batch, seq_len, hidden] # 计算注意力分数 scores = self.v(torch.tanh(query + keys)).squeeze(-1) # [batch, seq_len] # 应用mask（可选） if mask is not None: scores = scores.masked_fill(mask == 0, -1e9) # 计算注意力权重 attention_weights = F.softmax(scores, dim=-1) # 加权求和 context = torch.bmm(attention_weights.unsqueeze(1), values) context = context.squeeze(1) # [batch, hidden_dim] return context, attention_weights

🎬 编码器-解码器中的注意力

传统Seq2Seq问题

# 传统方法：将整个序列压缩为固定向量 encoder_output = encoder(source_sequence) # 问题：长序列信息丢失 decoder_output = decoder(encoder_output)
  • 固定长度瓶颈
  • 长序列性能下降

注意力解决方案

# 注意力：动态获取相关信息 encoder_outputs = encoder(source_sequence) # 每步动态关注源序列不同位置 context = attention(query, encoder_outputs) decoder_output = decoder(context)
  • 保留完整序列信息
  • 长序列效果好
💡
关键理解

注意力机制的核心是让模型学会"看向哪里"。通过Query-Key-Value三个向量， 模型可以动态地、灵活地从输入序列中提取最相关的信息，这解决了传统Seq2Seq模型的瓶颈问题。
