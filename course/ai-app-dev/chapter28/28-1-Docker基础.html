28.1 Docker基础

容器化技术的核心概念与实践

🎯 学习目标

  • 理解容器与虚拟机的区别
  • 掌握Docker核心概念：镜像、容器、仓库
  • 学会基本Docker命令操作
  • 了解Docker在AI开发中的应用场景

什么是Docker？

Docker是一个开源的应用容器引擎，让开发者可以打包应用及其依赖包到一个可移植的容器中，然后发布到任何流行的Linux或Windows操作系统上。容器完全使用沙箱机制，相互之间不会有任何接口。

🔄 容器 vs 虚拟机

特性 虚拟机(VM) 容器(Docker)
启动时间 分钟级 秒级/毫秒级
资源占用 需要完整操作系统(GB级) 共享宿主机内核(MB级)
隔离级别 硬件级隔离 进程级隔离
性能损耗 较高(需Hypervisor) 接近原生性能
可移植性 依赖虚拟化平台 高度可移植

🏗️ Docker核心概念

📦

镜像(Image)

只读模板，包含创建容器所需的所有内容：代码、运行时、库、环境变量和配置文件

🐳

容器(Container)

镜像的运行实例，可以被启动、停止、删除，容器之间相互隔离

🏛️

仓库(Registry)

存储和分发镜像的地方，Docker Hub是最大的公共仓库

💻 Docker常用命令

# 查看Docker版本
docker --version

# 拉取镜像
docker pull python:3.10

# 查看本地镜像
docker images

# 运行容器
docker run -it python:3.10 /bin/bash

# 查看运行中的容器
docker ps

# 查看所有容器（包括停止的）
docker ps -a

# 停止容器
docker stop <container_id>

# 删除容器
docker rm <container_id>

# 删除镜像
docker rmi <image_id>

# 构建镜像
docker build -t myapp:v1.0 .

# 进入运行中的容器
docker exec -it <container_id> /bin/bash

🤖 Docker在AI开发中的应用

环境一致性

确保开发、测试、生产环境完全一致，避免"在我机器上能跑"的问题

# AI开发环境示例 FROM python:3.10 RUN pip install torch tensorflow RUN pip install jupyter pandas numpy

依赖隔离

不同项目可以使用不同版本的深度学习框架，互不干扰

# 项目A使用PyTorch 2.0 # 项目B使用TensorFlow 2.x # 各自独立运行在容器中
💡
最佳实践提示

在生产环境中，建议使用多阶段构建来减小镜像体积，同时注意不要在镜像中包含敏感信息（如API密钥）。

📝 本节小结

✅
  • • Docker是轻量级容器化技术，相比虚拟机启动更快、资源占用更少
  • • 核心概念：镜像（模板）、容器（实例）、仓库（存储）
  • • 掌握docker pull/run/build/exec等基本命令
  • • Docker为AI开发提供环境一致性和依赖隔离能力
