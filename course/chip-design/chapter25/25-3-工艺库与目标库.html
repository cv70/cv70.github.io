25.3 工艺库与目标库

综合所需的库文件配置与使用

🎯 学习目标

  • 理解工艺库的基本概念和组成
  • 掌握目标库、链接库的配置方法
  • 了解工艺角和条件设置
  • 学会选择合适的工艺库进行综合

什么是工艺库

工艺库（Technology Library）是Foundry提供的标准单元库， 包含了特定工艺节点下所有可用逻辑单元的物理、时序和功耗信息。 综合工具通过读取工艺库来选择合适的单元实现设计。

📚 工艺库的组成

组成部分 说明 文件格式
单元库 逻辑单元的功能描述 .db, .lib
时序库 单元的时序参数 .lib, .db
功耗库 单元的功耗参数 .lib, .db
物理库 单元的物理信息 .lef, .gds
符号库 单元的图形符号 .sdb

⚙️ 库文件配置

目标库（Target Library）

用于映射和优化的目标单元库：

# 单个工艺角 set target_library [list saed90nm_typ.db] # 多工艺角 set target_library [list \ saed90nm_ss.db \ saed90nm_tt.db \ saed90nm_ff.db \ ] # 多阈值电压 set target_library [list \ saed90nm_hvt.db \ saed90nm_lvt.db \ saed90nm_rvt.db \ ]

链接库（Link Library）

用于解析模块实例化的库：

# 包含目标库和通配符 set link_library "* $target_library" # 添加额外的IP库 set link_library "* $target_library memory_block.db"

符号库（Symbol Library）

set symbol_library saed90nm.sdb

搜索路径（Search Path）

set search_path [list \ ./rtl \ ./lib \ ./scripts \ /foundry/libraries/saed90nm/ \ ]

🌡️ 工艺角（Process Corner）

工艺角描述了制造过程中的工艺变异，综合时需要考虑不同工艺角：

SS (Slow-Slow)

最差时序，用于setup分析

温度：125°C | 电压：0.9V

FF (Fast-Fast)

最佳时序，用于hold分析

温度：-40°C | 电压：1.1V

TT (Typical-Typical)

典型条件，用于功能验证

温度：25°C | 电压：1.0V

SF/FS

混合角，考虑跨角变异

用于OCV分析

🔧 工艺条件设置

# 设置操作条件 set_operating_conditions -min BCCOM -max WCCOM # 或使用自定义条件 set_operating_conditions -analysis_type on_chip_variation \ -min Pacific_min -max Pacific_max # 设置线负载模型 set_wire_load_model -name TSMC12_WLM set_wire_load_mode top
💡
选择建议

对于综合，通常使用TT（典型）工艺角进行初始综合， 然后在后续的STA中使用SS和FF角进行时序验证。这样可以平衡综合速度和结果准确性。

📝 本节小结

✅
