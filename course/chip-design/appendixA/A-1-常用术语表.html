A-B 字母术语

术语全称中文释义说明
ADCAnalog-to-Digital Converter模数转换器将模拟信号转换为数字信号的电路
ALUArithmetic Logic Unit算术逻辑单元处理器中执行算术和逻辑运算的部件
APBAdvanced Peripheral Bus高级外设总线AMBA协议家族中的外设总线
ASICApplication-Specific Integrated Circuit专用集成电路为特定应用定制的集成电路
AXIAdvanced eXtensible Interface高级可扩展接口ARM定义的高性能总线协议
BISTBuild-In Self Test内建自测试DFT技术，芯片内部的自测试电路

C-D 字母术语

术语全称中文释义说明
CDCClock Domain Crossing跨时钟域信号在不同时钟域之间传递的设计问题
CMOSComplementary Metal-Oxide-Semiconductor互补金属氧化物半导体主流集成电路制造工艺
CPUCentral Processing Unit中央处理器计算机的核心处理单元
CTSClock Tree Synthesis时钟树综合物理设计中构建时钟树的过程
DACDigital-to-Analog Converter数模转换器将数字信号转换为模拟信号的电路
DCDesign Compiler设计编译器Synopsys的逻辑综合工具
DDRDouble Data Rate双倍数据速率每个时钟周期传输两次数据的存储器接口
DFTDesign For Test可测性设计在设计中添加测试功能的设计方法
DRCDesign Rule Check设计规则检查检查版图是否符合工艺设计规则
DSPDigital Signal Processor数字信号处理器专门用于数字信号处理的处理器

E-H 字母术语

术语全称中文释义说明
ECEquivalence Checking等价性检查形式验证方法，验证两个设计功能等价
EDAElectronic Design Automation电子设计自动化芯片设计使用的软件工具集合
EMElectromigration电迁移电流导致金属导线原子迁移的可靠性问题
FIFOFirst In First Out先进先出常用数据缓冲结构
FPGAField Programmable Gate Array现场可编程门阵列可现场编程的集成电路
FSMFinite State Machine有限状态机数字电路中的控制逻辑设计方法
GDSGDSII Stream FormatGDSII流格式版图数据交换的标准文件格式
GPIOGeneral Purpose Input/Output通用输入输出可配置的通用IO端口

I-M 字母术语

术语全称中文释义说明
ICIntegrated Circuit集成电路将电子元器件集成在芯片上的微型电路
IPIntellectual Property知识产权核可复用的设计模块
IR DropCurrent × Resistance Drop电压降电源网络中因电阻导致的电压下降
JTAGJoint Test Action GroupJTAG接口标准测试接口，用于调试和边界扫描
LVSLayout Versus Schematic版图与原理图比对验证版图与电路图一致性的检查
MOSFETMetal-Oxide-Semiconductor Field-Effect TransistorMOS场效应晶体管集成电路的核心器件
MUXMultiplexer多路选择器从多个输入中选择一个输出的电路

P-R 字母术语

术语全称中文释义说明
PDKProcess Design Kit工艺设计套件代工厂提供的设计支持文件包
PLLPhase-Locked Loop锁相环时钟产生和频率合成的关键模块
PnRPlace and Route布局布线物理设计的核心步骤
RAMRandom Access Memory随机存取存储器可随机读写的存储器
RISCReduced Instruction Set Computer精简指令集计算机使用精简指令集的处理器架构
ROMRead-Only Memory只读存储器只能读取不能写入的存储器
RTLRegister Transfer Level寄存器传输级硬件描述语言的主要设计抽象层次

术语全称中文释义说明

SRAMStatic Random Access Memory静态随机存取存储器速度快但密度低的存储器
SSOSimultaneous Switching Output同步切换输出多个输出同时切换导致的噪声问题
STAStatic Timing Analysis静态时序分析分析电路时序的方法
SVSystemVerilogSystemVerilog语言Verilog的扩展，用于设计和验证

UVMUniversal Verification Methodology通用验证方法论基于SystemVerilog的验证框架
VLSIVery Large Scale Integration超大规模集成电路集成度极高的集成电路
