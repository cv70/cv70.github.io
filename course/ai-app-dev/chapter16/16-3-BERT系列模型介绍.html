BERT：双向编码器表示

BERT（Bidirectional Encoder Representations from Transformers）是Google于2018年提出的预训练语言模型。与GPT的单向生成不同，BERT采用双向Transformer编码器，能够同时理解上下文，在自然语言理解任务上表现卓越。

🔄 BERT vs GPT架构对比

特性 BERT GPT
架构 Transformer编码器 Transformer解码器
注意力方向 双向 单向（从左到右）
预训练任务 MLM + NSP 语言模型
主要应用 理解任务（分类、NER等） 生成任务
输入表示 [CLS] + tokens + [SEP] 纯token序列

🧠 BERT的核心技术

掩码语言模型(MLM)

随机遮蔽15%的token，让模型预测被遮蔽的内容。

# MLM示例 原句: 我 喜欢 学习 人工智能 遮蔽: 我 [MASK] 学习 人工智能 预测: 喜欢

下一句预测(NSP)

判断两个句子是否连续，学习句子间关系。

# NSP示例 输入: [CLS]今天天气很好[SEP] 我们去公园散步[SEP] 标签: IsNext (连续)
图：BERT通过双向注意力机制理解完整上下文

📊 BERT系列模型演进

BERT原始版本

  • BERT-Base: 12层, 768维, 1.1亿参数
  • BERT-Large: 24层, 1024维, 3.4亿参数

改进版本

  • RoBERTa: 更大数据、更长训练
  • ALBERT: 参数共享、轻量化
  • DistilBERT: 蒸馏压缩、更快推理
  • ELECTRA: 更高效的预训练

⚡ BERT系列详细对比

模型 参数量 主要改进 适用场景
BERT 110M/340M 开创性双向预训练 通用NLU任务
RoBERTa 125M/355M 去除NSP、更大batch 需要更高精度
ALBERT 12M-235M 因式分解、层间共享 资源受限环境
DistilBERT 66M 知识蒸馏压缩 快速推理场景
DeBERTa 139M-1.5B 解耦注意力机制 需要最强性能
SpanBERT 340M 跨度预测预训练 信息抽取任务

💻 BERT使用示例

from transformers import BertTokenizer, BertModel # 加载预训练模型 tokenizer = BertTokenizer.from_pretrained('bert-base-chinese') model = BertModel.from_pretrained('bert-base-chinese') # 文本编码 text = "人工智能正在改变世界" inputs = tokenizer(text, return_tensors='pt') # 获取BERT表示 outputs = model(**inputs) last_hidden_states = outputs.last_hidden_state pooler_output = outputs.pooler_output print(f"隐藏状态维度: {last_hidden_states.shape}") # 输出: torch.Size([1, 11, 768])

选型建议

对于中文任务，推荐使用BERT-base-chinese或RoBERTa-wwm-ext；对于英文任务，DeBERTa通常效果最好；对于资源受限场景，可选择DistilBERT或ALBERT。
