Kubeflow Pipelines简介

Kubeflow Pipelines（KFP）是Kubernetes原生的机器学习流水线平台。 它提供端到端的ML流水线编排、实验追踪、模型部署等功能，是云原生AI的标准选择。

📦 安装Kubeflow Pipelines

使用Helm安装

# 添加Kubeflow仓库 helm repo add kubeflow https://kubeflow.github.io/pipelines/ helm repo update # 创建命名空间 kubectl create namespace kubeflow # 安装KFP helm install kubeflow-pipelines kubeflow/pipelines \ --namespace kubeflow \ --set pipeline.apiService.serviceType=LoadBalancer # 查看安装状态 kubectl get pods -n kubeflow kubectl get svc -n kubeflow # 获取访问URL kubectl get svc ml-pipeline-ui -n kubeflow

使用kustomize安装

# 克隆Kubeflow仓库 git clone https://github.com/kubeflow/pipelines.git cd pipelines # 部署到Kubernetes kubectl apply -k manifests/kustomize/standalone # 等待Pod就绪 kubectl wait --for=condition=ready pod -l app=ml-pipeline -n kubeflow # 端口转发 kubectl port-forward \ svc/ml-pipeline-ui \ 8080:80 \ -n kubeflow

验证安装

# 访问KFP UI # http://localhost:8080 # 安装Python SDK pip install kfp # 验证连接 kfp list_experiments(host="http://localhost:8080")

🔧 定义流水线

基础流水线示例

from kfp import dsl from kfp.dsl import component, pipeline, OutputPath # 定义组件 @component(base_image="python:3.9") def load_data( output_path: OutputPath() ): import pandas as pd df = pd.read_csv("data.csv") df.to_csv(output_path, index=False) @component(base_image="python:3.9") def train_model( data_path: str, model_path: OutputPath() ): import pandas as pd from sklearn.linear_model import LogisticRegression import joblib df = pd.read_csv(data_path) X = df.drop("target", axis=1) y = df["target"] model = LogisticRegression() model.fit(X, y) joblib.dump(model, model_path) # 定义流水线 @pipeline( name="training-pipeline", description="Training pipeline" ) def training_pipeline(): load_task = load_data() train_task = train_model( data_path=load_task.output )

上传并运行流水线

from kfp import Client # 连接到KFP client = Client(host="http://localhost:8080") # 编译流水线 compiler.Compiler().compile( pipeline_func=training_pipeline, package_path="pipeline.yaml" ) # 上传流水线 pipeline = client.upload_pipeline( pipeline_package_path="pipeline.yaml", pipeline_name="training-pipeline", description="Training pipeline" ) # 创建实验 experiment = client.create_experiment( name="training-experiment" ) # 运行流水线 run = client.run_pipeline( experiment_id=experiment.experiment_id, job_name="training-run-1", pipeline_id=pipeline.id )
✅
KFP组件类型
  • • Lightweight：Python函数，简单快速
  • • Containerized：自定义容器，功能强大
  • • Reusable：可复用组件，共享代码

💾 数据传递

输出和输入

from kfp.dsl import InputPath, OutputPath @component def step1(output_path: OutputPath(str)): # 输出文件 with open(output_path, 'w') as f: f.write("Hello, KFP!") @component def step2(input_path: InputPath()): # 输入文件 with open(input_path, 'r') as f: content = f.read() print(content) @pipeline def data_pipeline(): task1 = step1() task2 = step2(input_path=task1.output)

参数传递

@component def step1() -> str: return "result_value" @component def step2(input_value: str): print(f"Received: {input_value}") @pipeline def parameter_pipeline(): task1 = step1() task2 = step2(input_value=task1.output)
