ReAct框架

ReAct（Reasoning + Acting）将推理和行动结合，让Agent先思考再执行， 通过多轮迭代解决复杂问题。

🔄 ReAct循环

💭

Thought

思考下一步行动

🎬

Action

执行工具调用

👁️

Observation

观察执行结果

✅

Answer

给出最终答案

💡
ReAct优势

通过显式推理过程提高决策透明度和可解释性，减少错误，支持复杂多步任务。
