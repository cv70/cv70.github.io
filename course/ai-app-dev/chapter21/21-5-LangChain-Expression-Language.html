LCEL简介

LangChain Expression Language (LCEL)是一种声明式语言，用于轻松组合LangChain组件。 使用管道符|串联组件，支持流式、异步、批处理等特性。

💻 LCEL基本语法

from langchain_core.prompts import ChatPromptTemplate from langchain_openai import ChatOpenAI from langchain_core.output_parsers import StrOutputParser # 使用|串联组件 chain = ( ChatPromptTemplate.from_template("翻译成英文: {text}") | ChatOpenAI() | StrOutputParser() ) # 调用 result = chain.invoke({"text": "你好世界"}) # 流式输出 for chunk in chain.stream({"text": "你好世界"}): print(chunk, end="", flush=True)
💡
Runnable接口

所有LCEL组件都实现Runnable接口，支持invoke、stream、batch、ainvoke等方法。
