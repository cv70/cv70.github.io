30.1 日志系统设计

构建完善的AI应用日志体系

🎯 学习目标

  • 理解日志系统的重要性和设计原则
  • 掌握日志级别和格式规范
  • 学会使用ELK/EFK日志栈
  • 了解AI应用的日志最佳实践

为什么需要日志系统？

日志系统是AI应用运维的基石。通过完善的日志，可以追踪问题根因、监控系统健康、分析用户行为、满足合规要求。对于AI应用，日志还能帮助追踪模型预测结果、数据变更和训练过程。

📊 日志级别规范

级别 用途 示例场景
DEBUG 调试信息 模型参数、中间结果
INFO 常规信息 请求处理、模型加载
WARNING 警告信息 资源不足、性能下降
ERROR 错误信息 推理失败、连接超时
CRITICAL 严重错误 系统崩溃、数据丢失

🤖 AI应用日志设计

import logging
import json
from datetime import datetime

# 结构化日志配置
class AIStructuredLogger:
    def __init__(self, service_name):
        self.logger = logging.getLogger(service_name)
        self.logger.setLevel(logging.INFO)

        # JSON格式Handler
        handler = logging.StreamHandler()
        handler.setFormatter(JSONFormatter())
        self.logger.addHandler(handler)

    def log_inference(self, request_id, model_name,
                      input_shape, latency_ms, status):
        """记录推理日志"""
        self.logger.info("inference", extra={
            "request_id": request_id,
            "model_name": model_name,
            "input_shape": input_shape,
            "latency_ms": latency_ms,
            "status": status,
            "timestamp": datetime.utcnow().isoformat()
        })

    def log_training(self, run_id, epoch, metrics):
        """记录训练日志"""
        self.logger.info("training", extra={
            "run_id": run_id,
            "epoch": epoch,
            "metrics": metrics,
            "timestamp": datetime.utcnow().isoformat()
        })

# 使用示例
logger = AIStructuredLogger("inference-service")
logger.log_inference(
    request_id="req-12345",
    model_name="gpt-model",
    input_shape=[1, 512],
    latency_ms=150.5,
    status="success"
)

⚙️ Fluentd配置示例

# fluent.conf
<source>
  @type tail
  path /var/log/containers/*.log
  pos_file /var/log/fluentd-containers.log.pos
  tag kubernetes.*
  format json
  time_key timestamp
  time_format %Y-%m-%dT%H:%M:%S.%NZ
</source>

# 过滤和解析AI日志
<filter kubernetes.**>
  @type parser
  key_name log
  reserve_data true
  <parse>
    @type json
    time_key timestamp
    time_format %Y-%m-%dT%H:%M:%S.%NZ
  </parse>
</filter>

# 输出到Elasticsearch
<match kubernetes.**>
  @type elasticsearch
  host elasticsearch
  port 9200
  logstash_format true
  logstash_prefix ai-logs
  include_tag_key true
</match>

📈 日志最佳实践

日志内容规范

  • 包含请求ID便于追踪
  • 记录时间戳和耗时
  • 包含模型版本信息
  • 避免记录敏感数据

性能优化

  • 使用异步日志写入
  • 设置日志轮转策略
  • 控制日志量（采样）
  • 压缩存储历史日志
💡
AI日志特殊考虑

对于AI应用，建议额外记录：模型版本、输入数据摘要、预测结果、置信度分数。这些信息对于模型效果分析和问题排查非常重要。
