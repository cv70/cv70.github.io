10.1 Partial 和 Required

控制属性的可选性

🎯 学习目标

  • 深入理解 Partial 的实现原理
  • 掌握 Required 的使用场景
  • 学会组合使用这两种工具类型
  • 了解实际项目中的应用

📚 Partial 深入

// Partial 将所有属性变为可选 // 内置实现： type MyPartial = { [P in keyof T]?: T[P]; }; interface User { id: number; name: string; email: string; age: number; } // 使用 Partial type PartialUser = Partial; // { id?: number; name?: string; email?: string; age?: number; } // 部分属性更新 const updates: Partial = { name: 'Alice' }; function updateUser(user: User, updates: Partial): User { return { ...user, ...updates }; } const user: User = { id: 1, name: 'Bob', email: 'bob@example.com', age: 25 }; const updated = updateUser(user, { name: 'Alice', age: 26 }); // { id: 1, name: 'Alice', email: 'bob@example.com', age: 26 }

✏️ Required 深入

// Required 将所有属性变为必需 // 内置实现： type MyRequired = { [P in keyof T]-?: T[P]; }; interface FormUser { id?: number; name?: string; email?: string; role?: 'admin' | 'user'; } // 使用 Required type CompleteUser = Required; // { id: number; name: string; email: string; role: 'admin' | 'user'; } // 验证后使用 function validateForm(data: FormUser): Required | null { if (!data.name || !data.email) { return null; } return { id: data.id ?? Date.now(), name: data.name, email: data.email, role: data.role ?? 'user' }; } // API 请求体验证 interface ApiInput { username?: string; password?: string; rememberMe?: boolean; } type ApiInputRequired = Required> & Partial>; // { username: string; password: string; rememberMe?: boolean; }

🔀 组合应用

// 部分必需、部分可选 interface Config { apiUrl: string; timeout: number; retries: number; debug: boolean; logLevel: 'info' | 'warn' | 'error'; } // 创建配置：必需核心属性，可选其他 type CreateConfig = Required> & Partial>; // { apiUrl: string; timeout?: number; retries?: number; ... } const config: CreateConfig = { apiUrl: 'https://api.example.com', timeout: 5000 }; // 合并默认配置 const defaultConfig: Required = { apiUrl: '', timeout: 3000, retries: 3, debug: false, logLevel: 'info' }; function createConfig(input: Partial): Required { return { ...defaultConfig, ...input }; } // 表单状态管理 interface FormState { values: Record; errors: Record; touched: Record; isSubmitting: boolean; } type FormUpdate = Partial; function updateForm(state: FormState, update: FormUpdate): FormState { return { ...state, ...update }; }
💡
最佳实践

Partial 常用于更新操作，Required 常用于验证后的完整对象。结合 Pick 和 Omit 可以精确控制哪些属性需要修改。

📝 本节小结

✅
  • • Partial 使所有属性变为可选
  • • Required 使所有属性变为必需
  • • -? 移除可选修饰符
  • • 常用于表单处理和配置合并
