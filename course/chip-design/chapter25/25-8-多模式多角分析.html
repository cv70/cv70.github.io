25.8 多模式多角分析

MCMM综合方法与实践

🎯 学习目标

  • 理解多模式多角（MCMM）的概念
  • 掌握MCMM综合的配置方法
  • 学会分析多角下的时序结果
  • 了解MCMM在先进工艺中的重要性

什么是MCMM

多模式多角（Multi-Corner Multi-Mode，MCMM）是指在综合时同时考虑 多种工作模式和多个工艺角的设计方法。随着工艺节点的推进，工艺变异和操作条件的 影响越来越大，MCMM成为确保设计可靠性的必要手段。

🌡️ 工艺角（Corner）

工艺角 工艺 电压 温度 应用场景
SS Slow 0.9V 125°C 最差时序（setup）
TT Typical 1.0V 25°C 典型条件
FF Fast 1.1V -40°C 最佳时序（hold）
SF Slow/Fast - - 跨角分析

⚙️ MCMM配置

定义工艺角

# 定义慢角 create_corner ss_corner read_lib -corner ss_corner \ /foundry/libraries/saed90nm/ss.db # 定义快角 create_corner ff_corner read_lib -corner ff_corner \ /foundry/libraries/saed90nm/ff.db # 定义典型角 create_corner tt_corner read_lib -corner tt_corner \ /foundry/libraries/saed90nm/tt.db # 设置操作条件 set_operating_conditions -corner ss_corner ss_0.9V_125C set_operating_conditions -corner ff_corner ff_1.1V_-40C set_operating_conditions -corner tt_corner tt_1.0V_25C

定义工作模式

# 创建功能模式 create_mode func_mode # 创建测试模式 create_mode test_mode # 设置活动模式 current_mode func_mode

为不同模式设置约束

# 功能模式约束 current_mode func_mode create_clock -name CLK -period 10.0 [get_ports clk] set_clock_uncertainty -setup 0.3 [get_clocks CLK] # 测试模式约束（时钟较慢） current_mode test_mode create_clock -name CLK -period 15.0 [get_ports clk] set_clock_uncertainty -setup 0.5 [get_clocks CLK] # 设置测试模式特定约束 set_disable_timing [get_cells scan_enable*]

🔄 MCMM综合流程

#!/bin/tcl # ============================================================================ # MCMM综合脚本 # ============================================================================ # 1. 定义所有工艺角 # ============================================ puts "定义工艺角..." # SS角 create_corner ss_corner read_lib -corner ss_corner lib/saed90nm_ss.db set_operating_conditions -corner ss_corner WCCOM # FF角 create_corner ff_corner read_lib -corner ff_corner lib/saed90nm_ff.db set_operating_conditions -corner ff_corner BCCOM # TT角 create_corner tt_corner read_lib -corner tt_corner lib/saed90nm_tt.db set_operating_conditions -corner tt_corner NOM # 2. 定义工作模式 # ============================================ puts "定义工作模式..." # 功能模式 create_mode func_mode current_mode func_mode # 测试模式 create_mode test_mode # 3. 为每个模式设置约束 # ============================================ puts "设置模式约束..." # 功能模式约束 current_mode func_mode create_clock -name CLK -period 10.0 [get_ports clk] set_clock_uncertainty -setup 0.3 [get_clocks CLK] set_clock_uncertainty -hold 0.1 [get_clocks CLK] set_input_delay -max 2.0 -clock CLK [all_inputs] set_output_delay -max 2.0 -clock CLK [all_outputs] # 测试模式约束 current_mode test_mode create_clock -name CLK -period 15.0 [get_ports clk] set_clock_uncertainty -setup 0.5 [get_clocks CLK] set_clock_uncertainty -hold 0.2 [get_clocks CLK] # 禁用测试模式下的某些路径 set_false_path -from [get_ports scan_enable*] # 4. 读入设计 # ============================================ puts "读入设计..." read_verilog {top.v sub1.v sub2.v} current_design top link # 5. MCMM综合 # ============================================ puts "执行MCMM综合..." # 设置综合考虑所有角落 set_timing_derate -cell_delay -early 1.1 -corner ff_corner set_timing_derate -cell_delay -late 1.15 -corner ss_corner # 执行综合 compile_ultra -retime # 6. 分析所有角的结果 # ============================================ puts "生成多角报告..." # 为每个角生成时序报告 foreach corner [list ss_corner ff_corner tt_corner] { puts "分析工艺角: $corner" report_timing -corner $corner -max_paths 10 \ > "reports/timing_${corner}.rpt" } # 为每个模式生成报告 foreach mode [list func_mode test_mode] { puts "分析模式: $mode" report_timing -mode $mode -max_paths 10 \ > "reports/timing_${mode}.rpt" } # 7. 输出结果 # ============================================ puts "输出结果..." write -format verilog -hierarchy -output outputs/top_mcmm.v write_sdc -nosplit outputs/top_mcmm.sdc puts "MCMM综合完成！"

💡
MCMM注意事项

MCMM综合会显著增加运行时间和内存使用。 对于大型设计，建议先在典型条件下进行初始综合，然后在MCMM环境下进行优化。 同时，要合理选择需要分析的角落和模式，避免过度配置。
