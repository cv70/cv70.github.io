48.2 创建拦截器

实现自定义拦截器

🎯 学习目标

  • 掌握拦截器的创建方式
  • 学会使用 RxJS 操作符
  • 了解拦截器的作用范围
  • 掌握带参数的拦截器

📚 基本拦截器

import { Injectable, NestInterceptor, ExecutionContext, CallHandler } from '@nestjs/common'; import { Observable } from 'rxjs'; import { tap } from 'rxjs/operators'; @Injectable() export class LoggingInterceptor implements NestInterceptor { intercept(context: ExecutionContext, next: CallHandler): Observable { const request = context.switchToHttp().getRequest(); const method = request.method; const url = request.url; const now = Date.now(); console.log(`[${new Date().toISOString()}] ${method} ${url} - Started`); return next.handle().pipe( tap({ next: () => console.log(`[${method} ${url}] - ${Date.now() - now}ms`), error: (error) => console.error(`[${method} ${url}] - Error: ${error.message}`), }), ); } } // 使用 @Controller('users') @UseInterceptors(LoggingInterceptor) export class UsersController { @Get() findAll() { return [{ id: 1, name: 'John' }]; } }
💡
tap 操作符

tap 操作符用于观察流中的值而不修改它们，适合日志记录等副作用操作。

🔧 修改响应数据

import { Injectable, NestInterceptor, ExecutionContext, CallHandler } from '@nestjs/common'; import { Observable } from 'rxjs'; import { map } from 'rxjs/operators'; export interface Response { code: number; message: string; data: T; timestamp: string; } @Injectable() export class TransformInterceptor implements NestInterceptor> { intercept(context: ExecutionContext, next: CallHandler): Observable> { return next.handle().pipe( map((data) => ({ code: 200, message: 'Success', data, timestamp: new Date().toISOString(), })), ); } } // 原始响应: { id: 1, name: 'John' } // 转换后: // { // code: 200, // message: 'Success', // data: { id: 1, name: 'John' }, // timestamp: '2024-01-01T00:00:00.000Z' // }

⚙️ 带参数的拦截器

import { Injectable, NestInterceptor, ExecutionContext, CallHandler } from '@nestjs/common'; import { Observable } from 'rxjs'; import { timeout, TimeoutError, catchError } from 'rxjs/operators'; import { RequestTimeoutException } from '@nestjs/common'; @Injectable() export class TimeoutInterceptor implements NestInterceptor { constructor(private readonly timeoutMs: number = 5000) {} intercept(context: ExecutionContext, next: CallHandler): Observable { return next.handle().pipe( timeout(this.timeoutMs), catchError((err) => { if (err instanceof TimeoutError) { throw new RequestTimeoutException('Request timeout'); } throw err; }), ); } } // 使用 @Controller('api') @UseInterceptors(new TimeoutInterceptor(3000)) // 3秒超时 export class ApiController { @Get('slow') async slowOperation() { await new Promise(resolve => setTimeout(resolve, 5000)); // 会超时 return { message: 'Done' }; } }

📍 拦截器作用范围

// 1. 方法级 @Controller('users') export class UsersController { @UseInterceptors(LoggingInterceptor) @Get() findAll() {} } // 2. 控制器级 @Controller('users') @UseInterceptors(TransformInterceptor) export class UsersController { @Get() findAll() {} // 应用拦截器 @Post() create() {} // 应用拦截器 } // 3. 全局级 async function bootstrap() { const app = await NestFactory.create(AppModule); app.useGlobalInterceptors(new TransformInterceptor()); await app.listen(3000); } // 4. 模块级 @Module({ providers: [ { provide: APP_INTERCEPTOR, useClass: TransformInterceptor, }, ], }) export class AppModule {}
⚠️
拦截器顺序

多个拦截器按注册顺序执行：全局 -> 控制器 -> 方法。响应阶段按相反顺序处理。
