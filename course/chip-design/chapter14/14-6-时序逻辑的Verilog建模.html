14.6 时序逻辑的 Verilog 建模

Verilog HDL 进阶

学习目标

  • 理解时序逻辑的建模方法
  • 掌握同步复位与异步复位的区别
  • 学会使用非阻塞赋值
  • 能够设计可靠的时序电路

时序逻辑概述

时序逻辑电路的输出不仅取决于当前输入，还与电路的历史状态有关。时序逻辑需要时钟信号和存储元件（触发器）。

同步时序逻辑模板

// 同步复位 always @(posedge clk) begin if (rst) q <= 0; else q <= d; end // 异步复位 always @(posedge clk or posedge rst) begin if (rst) q <= 0; else q <= d; end
💡
关键原则

时序逻辑必须使用非阻塞赋值 <= ；复位策略要统一；避免产生锁存器
