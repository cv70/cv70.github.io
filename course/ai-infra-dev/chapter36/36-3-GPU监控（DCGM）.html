NVIDIA DCGM

DCGM (Data Center GPU Manager)是NVIDIA提供的一套GPU监控和管理工具套件，提供深入的GPU性能洞察。

🏗️ DCGM架构

DCGM核心组件

  • DCGM Daemon - 后台守护进程
  • DCGM Libraries - C/Python API
  • DCGM Exporter - Prometheus指标暴露
  • dcgmi CLI - 命令行工具

监控能力

  • 计算单元利用率
  • 内存使用情况
  • 温度与功耗
  • PCIe带宽
  • NVLink带宽
  • XID错误

📊 GPU监控关键指标

指标类别 Prometheus指标 含义 告警阈值
计算利用率 DCGM_FI_DEV_SM_CLOCK SM时钟频率 -
DCGM_FI_DEV_GPU_UTIL GPU利用率 <90%
DCGM_FI_DEV_ENC_UTIL 编码器利用率 -
内存 DCGM_FI_DEV_FB_USED 显存使用量 <95%
DCGM_FI_DEV_MEM_COPY_UTIL 内存复制利用率 -
DCGM_FI_PROF_GR_ECC_SBE_AGG_TOTAL 单比特错误计数 >0
温度功耗 DCGM_FI_DEV_GPU_TEMP GPU温度 <85°C
DCGM_FI_DEV_POWER_USAGE 功耗 接近TDP
PCIe DCGM_FI_DEV_PCIE_REPLAY_COUNTER PCIe重传计数 持续增长
DCGM_FI_DEV_PCIE_RX_THROUGHPUT PCIe接收吞吐 -
NVLink DCGM_FI_DEV_NVLINK_THROUGHPUT NVLink吞吐量 -
错误 DCGM_FI_DEV_XID_ERRORS XID错误代码 非0值

⚙️ 自定义DCGM采集

💡
采集级别

DCGM Exporter提供不同的采集级别：

级别 指标数量 使用场景 性能开销
1 ~50 基础监控 极低
2 ~150 常规监控 低
3 ~500 深度分析 中等
# 使用采集级别 docker run -d \ nvidia/dcgm-exporter:latest \ -f /etc/dcgm-exporter/dcp-metrics-included.csv \ -c 2000ms # 或使用自定义指标列表 # dcp-metrics-included.csv DCGM_FI_DEV_GPU_UTIL DCGM_FI_DEV_FB_USED DCGM_FI_DEV_FB_FREE DCGM_FI_DEV_FB_TOTAL DCGM_FI_DEV_GPU_TEMP DCGM_FI_DEV_POWER_USAGE DCGM_FI_DEV_PCIE_REPLAY_COUNTER

🔍 GPU监控查询示例

# GPU利用率 DCGM_FI_DEV_GPU_UTIL{gpu="0"} # 集群平均GPU利用率 avg(DCGM_FI_DEV_GPU_UTIL) # 按节点聚合GPU利用率 avg by (hostname) (DCGM_FI_DEV_GPU_UTIL) # GPU显存使用率 DCGM_FI_DEV_FB_USED / DCGM_FI_DEV_FB_TOTAL * 100 # 查找空闲GPU DCGM_FI_DEV_GPU_UTIL < 10 # GPU温度异常 DCGM_FI_DEV_GPU_TEMP > 85 # PCIe错误检测 rate(DCGM_FI_DEV_PCIE_REPLAY_COUNTER[5m]) > 100 # 计算集群GPU总数 count(DCGM_FI_DEV_GPU_UTIL)

⚠️ GPU告警规则

# gpu_alerts.yml groups: - name: dcgm_alerts interval: 30s rules: # GPU利用率告警 - alert: HighGPUUtilization expr: DCGM_FI_DEV_GPU_UTIL > 95 for: 10m labels: severity: warning component: gpu annotations: summary: "GPU {{ $labels.gpu }} 在节点 {{ $labels.hostname }} 利用率持续过高" # GPU温度告警 - alert: HighGPUTemperature expr: DCGM_FI_DEV_GPU_TEMP > 85 for: 5m labels: severity: critical component: gpu annotations: summary: "GPU温度过高: {{ $value }}°C" # 显存使用告警 - alert: HighGPUMemoryUsage expr: DCGM_FI_DEV_FB_USED / DCGM_FI_DEV_FB_TOTAL * 100 > 95 for: 5m labels: severity: warning component: gpu annotations: summary: "GPU显存使用率过高" # ECC错误告警 - alert: ECCErrorsDetected expr: DCGM_FI_PROF_GR_ECC_SBE_AGG_TOTAL > 0 labels: severity: warning component: gpu annotations: summary: "检测到ECC单比特错误" # PCIe错误告警 - alert: PCIeErrorsDetected expr: rate(DCGM_FI_DEV_PCIE_REPLAY_COUNTER[5m]) > 100 labels: severity: critical component: gpu annotations: summary: "PCIe重传率异常" # XID错误告警 - alert: XIDErrorDetected expr: DCGM_FI_DEV_XID_ERRORS > 0 labels: severity: critical component: gpu annotations: summary: "GPU检测到XID错误: {{ $value }}"

📈 GPU性能分析

GPU利用率低的原因

  • CPU瓶颈 - 数据预处理或通信占用CPU
  • I/O瓶颈 - 数据加载速度跟不上训练速度
  • 内存瓶颈 - 显存不足导致频繁交换
  • 通信瓶颈 - 分布式训练通信延迟
  • Batch Size - 批大小设置不合理

⚠️
DCGM使用注意事项
  • • 确保NVIDIA驱动版本与DCGM版本兼容
  • • 高频采集会影响GPU性能，生产环境建议2秒以上
  • • 注意XID错误的含义，不同错误代码需要不同处理
  • • 结合Nsight进行更深入的性能分析
