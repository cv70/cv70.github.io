84.3 Props 类型

深入理解 Vue Props 的类型系统

📖 本节概述

本节深入介绍 Vue 3 组件 Props 的类型定义，包括基本类型、复杂类型、可选与必需、默认值设置以及 Props 的验证。

🎯 学习目标

  • 掌握各种类型的 Props 定义
  • 学会设置 Props 默认值
  • 理解 Props 验证机制
  • 掌握 Props 的最佳实践

📋 基本类型 Props

<script setup lang="ts"> interface Props { // 基本类型 title: string; count: number; isActive: boolean; // 可选属性 description?: string; maxCount?: number; // 联合类型 size: 'small' | 'medium' | 'large'; variant: 'primary' | 'secondary' | 'danger'; // 字面量类型 direction: 'horizontal' | 'vertical'; } const props = defineProps<Props>(); </script>

📦 复杂类型 Props

<script setup lang="ts"> interface User { id: number; name: string; email: string; } interface Props { // 数组类型 items: string[]; users: User[]; // 对象类型 user: User; config: { theme: 'light' | 'dark'; locale: string; }; // 函数类型 onClick: (event: MouseEvent) => void; onChange: (value: string) => void; validator: (value: any) => boolean; // 可空类型 nullableString: string | null; optionalUser: User | undefined; } const props = defineProps<Props>(); </script>

⚙️ 默认值设置

使用 withDefaults

<script setup lang="ts"> interface Props { title: string; count?: number; items?: string[]; config?: { theme: 'light' | 'dark'; locale: string; }; onClick?: () => void; } const props = withDefaults(defineProps<Props>(), { count: 0, items: () => [], // 数组需要工厂函数 config: () => ({ // 对象需要工厂函数 theme: 'light', locale: 'zh-CN' }), onClick: () => {} // 函数也需要工厂函数 }); </script>

运行时声明方式

// 不推荐，TypeScript 支持较差 const props = defineProps({ title: { type: String, required: true }, count: { type: Number, default: 0 }, items: { type: Array as PropType<string[]>, default: () => [] } });

✅ Props 验证

<script setup lang="ts"> interface Props { age: number; email: string; password: string; } const props = defineProps<Props>(); // 运行时验证 const props = defineProps({ age: { type: Number, required: true, validator: (value: number) => value >= 0 && value <= 150 }, email: { type: String, required: true, validator: (value: string) => /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(value) }, password: { type: String, required: true, validator: (value: string) => value.length >= 8 } }); </script>

🔄 Props 响应式处理

<script setup lang="ts"> import { computed, toRef, toRefs } from 'vue'; interface Props { modelValue: string; items: string[]; } const props = defineProps<Props>(); const emit = defineEmits<{ (e: 'update:modelValue', value: string): void; }>(); // 使用 computed 创建响应式副本 const localValue = computed({ get: () => props.modelValue, set: (value) => emit('update:modelValue', value) }); // 使用 toRef 创建单个响应式引用 const itemsRef = toRef(props, 'items'); // 使用 toRefs 解构 const { modelValue, items } = toRefs(props); // 监听 Props 变化 watch(() => props.modelValue, (newValue) => { console.log('Value changed:', newValue); }); </script>

💡 Props 最佳实践

// 1. 明确的类型定义 interface UserCardProps { user: User; // 使用接口，不使用 any showAvatar?: boolean; avatarSize?: number; } // 2. 合理的默认值 const props = withDefaults(defineProps<UserCardProps>(), { showAvatar: true, avatarSize: 48 }); // 3. 避免直接修改 Props // 错误：props.count++ // 不要这样做！ // 正确：使用本地副本或 emit 事件 const localCount = ref(props.count); function updateCount(newCount: number) { emit('update:count', newCount); } // 4. 使用 TypeScript 工具类型 type ButtonSize = 'small' | 'medium' | 'large'; type ButtonVariant = 'primary' | 'secondary' | 'danger'; interface ButtonProps { size?: ButtonSize; variant?: ButtonVariant; } // 5. 复杂对象使用 PropType interface TableColumn { key: string; title: string; width?: number; } interface TableProps { columns: TableColumn[]; }

📝 本节小结

  • 使用 TypeScript 接口定义 Props 类型
  • 可选属性使用 ? 标记
  • 对象和数组默认值使用工厂函数
  • 不要直接修改 Props，使用本地副本或 emit 事件
  • 使用 TypeScript 工具类型提高代码可维护性
