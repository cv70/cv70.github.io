波动率计算

波动率是衡量价格变动幅度的核心指标，是市场风险管理的基础。 准确计算和预测波动率对于VaR计算、期权定价、风险管理都至关重要。

📊 波动率的类型

历史波动率

  • 基于历史价格数据计算
  • 反映过去的波动情况
  • 方法简单、易于理解
  • 假设历史代表未来

隐含波动率

  • 从期权价格反推得出
  • 反映市场对未来波动的预期
  • 包含市场情绪信息
  • 需要期权市场数据

📐 历史波动率计算方法

方法 公式 特点 适用场景
简单标准差 σ = √[Σ(r-r̄)²/(n-1)] 所有数据等权重 平稳波动环境
指数加权(EWMA) σ²t = λσ²t-1 + (1-λ)r²t 近期数据权重更高 波动率变化明显
GARCH模型 σ²t = ω + αε²t-1 + βσ²t-1 波动率聚集效应 金融时间序列
已实现波动率 RV = Σ(高频收益)² 使用高频数据 日内风险管理

💻 波动率Python实现

Python代码示例

import numpy as np
import pandas as pd

# 1. 简单标准差法
def historical_volatility(prices, annualization=252):
    """计算历史波动率"""
    returns = np.log(prices / prices.shift(1)).dropna()
    volatility = returns.std() * np.sqrt(annualization)
    return volatility

# 2. 指数加权移动平均(EWMA)
def ewma_volatility(returns, lambda_param=0.94):
    """EWMA波动率"""
    var = returns.var()
    for r in returns:
        var = lambda_param * var + (1 - lambda_param) * r**2
    return np.sqrt(var)

# 3. GARCH模型
from arch import arch_model
def garch_volatility(returns):
    """GARCH(1,1)波动率"""
    model = arch_model(returns, vol='Garch', p=1, q=1)
    res = model.fit(disp='off')
    forecast = res.forecast(horizon=1)
    return np.sqrt(forecast.variance.iloc[-1, 0])

# 4. 已实现波动率
def realized_volatility(high_prices, low_prices):
    """基于高低价的已实现波动率"""
    returns = np.log(high_prices / low_prices)
    return returns.mean() * np.sqrt(252)

📈 GARCH模型详解

📚
GARCH(1,1)模型

条件方差方程：σ²t = ω + αε²t-1 + βσ²t-1

其中：ω是长期平均方差，α是ARCH项系数（新信息的影响），β是GARCH项系数（过去波动的影响）

波动率聚集：GARCH模型捕捉了金融时间序列中"大波动后跟大波动，小波动后跟小波动"的现象

模型选择：通常GARCH(1,1)已经足够，复杂模型可能过拟合

📊 隐含波动率计算

隐含波动率求解方法

  1. Black-Scholes模型 - 使用期权定价公式反推波动率
  2. 数值求解 - 通过Newton-Raphson等迭代方法求解
  3. 二分法 - 简单稳定的数值方法
  4. 插值法 - 从已知隐含波动率插值得到目标值

🔧 波动率在风险管理中的应用

应用领域 具体用途 关键点
VaR计算 作为VaR公式的核心输入 波动率准确性直接影响VaR
期权定价 作为期权定价模型的关键参数 隐含波动率用于定价，历史波动率用于验证
风险限额 基于波动率设定动态限额 波动率升高时收紧限额
仓位管理 根据波动率调整仓位大小 高波动时降低仓位
策略调整 识别波动率交易机会 隐含波动率vs历史波动率差异

⚠️ 波动率计算的注意事项

⚠️
常见问题

年化因子：不同频率数据需要使用不同年化因子（日度252，周度52，月度12）

数据长度：数据太短不稳定，太长反映不了近期变化

异常值：极端事件会显著影响波动率估计

跳空处理：隔夜跳空如何处理需要明确

日历效应：某些日期波动率特征不同（如财报日）

✨
最佳实践

使用多种方法计算波动率并对比。根据市场条件选择合适的模型（平静期用简单方法，动荡期用GARCH）。定期回测波动率预测的准确性。结合隐含波动率和历史波动率综合判断。
