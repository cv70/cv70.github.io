19.2 嵌入模型选择

将文本转换为向量表示

🎯 学习目标

  • 理解文本嵌入的概念
  • 掌握主流嵌入模型特点
  • 学会选择合适的嵌入模型
  • 了解多语言嵌入模型

什么是文本嵌入

文本嵌入（Text Embedding）将文本转换为固定维度的向量表示， 语义相似的文本在向量空间中距离更近。

📊 主流嵌入模型

模型 维度 特点
OpenAI text-embedding-3 1536/3072 效果好，API调用
BGE 768/1024 中文优秀，开源
M3E 768 多语言，开源免费
Sentence-BERT 768 经典模型，可微调
E5 768/1024 微软出品，效果优秀

💻 使用OpenAI Embedding

from openai import OpenAI client = OpenAI() response = client.embeddings.create( model="text-embedding-3-small", input="这是一个测试文本" ) embedding = response.data[0].embedding print(f"向量维度: {len(embedding)}")
💡
选择建议

中文场景推荐BGE/M3E；多语言选M3E或OpenAI；需要私有化选开源模型本地部署。
