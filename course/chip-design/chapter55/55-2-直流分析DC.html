55.2 直流分析DC

电路静态工作点分析

🎯 学习目标

  • 理解直流分析的目的
  • 掌握.op和.dc命令
  • 学会分析静态工作点

📊 工作点分析（.op）

计算静态工作点

.op分析计算电路在直流条件下的稳态解，包括所有节点电压、支路电流和器件功耗。

.op * 输出： * - 所有节点电压 * - 电压源电流 * - 器件工作参数（Vgs, Vds, Id等） * - 小信号参数（gm, gds, Cgs等）

📈 直流扫描（.dc）

参数扫描分析

* 基本语法 .dc source start stop step * 示例1：扫描电压源 .dc V1 0 5 0.1 * 将V1从0V扫描到5V，步长0.1V * 示例2：扫描温度 .dc temp -40 125 5 * 扫描温度从-40°C到125°C * 示例3：双参数扫描 .dc V1 0 3.3 0.1 V2 0 1.8 0.05 * 同时扫描V1和V2

🎯 典型应用

直流分析的用途

  • 偏置点验证：检查电路是否工作在期望区域
  • 传输特性：分析输入输出关系
  • 电源抑制：分析电源变化对输出的影响
  • 温度特性：分析温度漂移
  • 器件匹配：分析失配对电路的影响
