46.1 管道概念

理解 NestJS 管道的作用和原理

🎯 学习目标

  • 理解管道的概念和作用
  • 掌握管道的执行时机
  • 了解管道的两种类型
  • 理解管道与其他组件的区别

📚 什么是管道？

管道是用 @Injectable() 装饰器注解的类，实现 PipeTransform 接口。管道在路由参数被路由处理程序处理之前运行，用于数据验证和转换。

请求处理流程： 客户端请求 ↓ ┌─────────────────┐ │ 中间件 │ └─────────────────┘ ↓ ┌─────────────────┐ │ 守卫 │ └─────────────────┘ ↓ ┌─────────────────┐ │ 拦截器(前) │ └─────────────────┘ ↓ ┌─────────────────┐ │ 管道 │ ← 在这里验证和转换参数 └─────────────────┘ ↓ ┌─────────────────┐ │ 路由处理器 │ └─────────────────┘
💡
管道特点

管道接收输入数据，可以返回修改后的数据或抛出异常。如果验证失败，管道抛出异常，请求不会到达路由处理器。

🔧 管道的两种用途

类型 说明 示例
验证 评估输入数据，有效则放行，无效则抛出异常 ValidationPipe, ParseIntPipe
转换 将输入数据转换为期望的格式 ParseIntPipe, ParseBoolPipe
// 管道可以同时做验证和转换 @Get(':id') findOne(@Param('id', ParseIntPipe) id: number) { // ParseIntPipe: // 1. 验证：确保 id 是有效整数 // 2. 转换：将字符串转换为数字 return this.usersService.findOne(id); }

🌐 管道接口

import { PipeTransform, Injectable, ArgumentMetadata } from '@nestjs/common'; @Injectable() export class CustomPipe implements PipeTransform { // value: 输入值 // metadata: 参数元数据 transform(value: any, metadata: ArgumentMetadata) { console.log('Metadata:', metadata); // { // type: 'param' | 'query' | 'body' | 'custom', // metatype: 类型构造函数, // data: 参数名称 // } // 返回转换后的值 return value; // 或抛出异常表示验证失败 // throw new BadRequestException('Validation failed'); } }

📍 管道的作用范围

// 1. 参数级 - 只作用于特定参数 @Get(':id') findOne(@Param('id', ParseIntPipe) id: number) {} // 2. 方法级 - 作用于整个方法 @Post() @UsePipes(ValidationPipe) create(@Body() createUserDto: CreateUserDto) {} // 3. 控制器级 - 作用于控制器所有方法 @Controller('users') @UsePipes(ValidationPipe) export class UsersController {} // 4. 全局级 - 作用于所有路由 async function bootstrap() { const app = await NestFactory.create(AppModule); app.useGlobalPipes(new ValidationPipe()); await app.listen(3000); }
⚠️
管道执行顺序

管道按照参数顺序执行。全局管道 -> 控制器管道 -> 方法管道 -> 参数管道。如果某个管道抛出异常，后续管道不会执行。
