61.3 分页实现

GraphQL 分页策略详解

📖 分页方式概述

GraphQL 支持多种分页方式，每种方式有不同的适用场景和优缺点。

分页方式 优点 缺点 适用场景
Offset 分页 简单直观，支持跳页 大数据量性能差，数据变化时可能重复/遗漏 后台管理、小型数据
Cursor 分页 性能稳定，数据一致 不支持跳页，实现复杂 无限滚动、实时数据

📄 Offset 分页

// Schema input PaginationInput { page: Int = 1 pageSize: Int = 10 } type UserConnection { data: [User!]! total: Int! page: Int! pageSize: Int! totalPages: Int! } type Query { users(pagination: PaginationInput): UserConnection! } // Resolver const resolvers = { Query: { users: async (_, { pagination }, context) => { const { page = 1, pageSize = 10 } = pagination || {}; const skip = (page - 1) * pageSize; const [data, total] = await Promise.all([ context.prisma.user.findMany({ skip, take: pageSize, orderBy: { createdAt: 'desc' }, }), context.prisma.user.count(), ]); return { data, total, page, pageSize, totalPages: Math.ceil(total / pageSize), }; }, }, }; // 查询示例 query GetUsers { users(pagination: { page: 2, pageSize: 10 }) { data { id name email } total page pageSize totalPages } } // 响应 { "data": { "users": { "data": [...], "total": 100, "page": 2, "pageSize": 10, "totalPages": 10 } } }

🔗 Cursor 分页（Relay 规范）

// Schema - Relay 风格 type PageInfo { hasNextPage: Boolean! hasPreviousPage: Boolean! startCursor: String endCursor: String } type UserEdge { node: User! cursor: String! } type UserConnection { edges: [UserEdge!]! pageInfo: PageInfo! totalCount: Int! } type Query { users( first: Int // 从开始获取 N 条 after: String // 在此 cursor 之后 last: Int // 从末尾获取 N 条 before: String // 在此 cursor 之前 ): UserConnection! } // Resolver const resolvers = { Query: { users: async (_, { first, after, last, before }, context) => { const limit = first || last || 10; // 解析 cursor（通常是 base64 编码的 ID） let cursor = null; if (after) { cursor = Buffer.from(after, 'base64').toString('utf-8'); } // 查询数据 const users = await context.prisma.user.findMany({ take: limit + 1, // 多取一条判断是否有下一页 skip: cursor ? 1 : 0, cursor: cursor ? { id: parseInt(cursor) } : undefined, orderBy: { id: 'asc' }, }); const hasNextPage = users.length > limit; if (hasNextPage) users.pop(); const edges = users.map(user => ({ node: user, cursor: Buffer.from(String(user.id)).toString('base64'), })); const totalCount = await context.prisma.user.count(); return { edges, pageInfo: { hasNextPage, hasPreviousPage: !!cursor, startCursor: edges[0]?.cursor, endCursor: edges[edges.length - 1]?.cursor, }, totalCount, }; }, }, }; // 查询示例 query GetUsers { users(first: 10) { edges { cursor node { id name email } } pageInfo { hasNextPage endCursor } totalCount } } // 下一页 query GetNextPage { users(first: 10, after: "MTA=") { edges { cursor node { id name } } pageInfo { hasNextPage endCursor } } }

⚡ Prisma 分页实现

import { Prisma } from '@prisma/client'; interface PaginationParams { page?: number; pageSize?: number; cursor?: string; orderBy?: string; orderDir?: 'asc' | 'desc'; } async function paginate( model: any, params: PaginationParams, where?: any ) { const { page = 1, pageSize = 10, cursor, orderBy = 'createdAt', orderDir = 'desc', } = params; const order: Prisma.OrderByArg = { [orderBy]: orderDir }; // Cursor 分页 if (cursor) { const items = await model.findMany({ where, take: pageSize + 1, skip: 1, cursor: { id: cursor }, orderBy: order, }); const hasNext = items.length > pageSize; if (hasNext) items.pop(); return { data: items, pagination: { hasNext, endCursor: items[items.length - 1]?.id, }, }; } // Offset 分页 const [data, total] = await Promise.all([ model.findMany({ where, skip: (page - 1) * pageSize, take: pageSize, orderBy: order, }), model.count({ where }), ]); return { data, pagination: { total, page, pageSize, totalPages: Math.ceil(total / pageSize), }, }; } // 使用 const resolvers = { Query: { posts: async (_, { page, pageSize, cursor }, context) => { return paginate(context.prisma.post, { page, pageSize, cursor }); }, }, };

📝 小结

  • Offset 分页简单直观，适合管理后台
  • Cursor 分页性能稳定，适合无限滚动
  • Relay 规范提供了标准的分页接口
  • 使用 totalCount 获取总数
  • Prisma 提供了灵活的分页 API
  • 根据场景选择合适的分页方式
