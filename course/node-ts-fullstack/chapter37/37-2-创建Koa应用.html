37.2 创建 Koa 应用

从零开始构建 Koa 项目

🎯 学习目标

  • 掌握 Koa 项目的初始化方法
  • 理解 Koa 应用的基本结构
  • 学会配置和启动 Koa 服务器
  • 了解开发环境的热重载配置

📦 项目初始化

# 创建项目目录 mkdir my-koa-app cd my-koa-app # 初始化 package.json npm init -y # 安装 Koa npm install koa
💡
安装建议

建议使用 Node.js LTS 版本，确保对 async/await 的完整支持。

💻 最简 Koa 应用

// index.js const Koa = require('koa'); // 创建 Koa 应用实例 const app = new Koa(); // 注册中间件 app.use(async (ctx, next) => { // 设置响应体 ctx.body = 'Hello Koa!'; }); // 监听端口 const PORT = process.env.PORT || 3000; app.listen(PORT, () => { console.log(`Server is running at http://localhost:${PORT}`); });

📁 项目目录结构

my-koa-app/ ├── node_modules/ ├── src/ │ ├── index.js # 入口文件 │ ├── routes/ # 路由目录 │ │ └── index.js │ ├── controllers/ # 控制器目录 │ ├── middlewares/ # 中间件目录 │ └── config/ # 配置目录 ├── package.json └── .env # 环境变量
✅
目录说明

这是推荐的 Koa 项目结构，便于团队协作和代码维护。

🔧 配置 package.json

{ "name": "my-koa-app", "version": "1.0.0", "description": "A Koa application", "main": "src/index.js", "scripts": { "start": "node src/index.js", "dev": "nodemon src/index.js" }, "keywords": ["koa", "nodejs"], "author": "", "license": "MIT", "dependencies": { "koa": "^2.14.0" }, "devDependencies": { "nodemon": "^3.0.0" } }

⚡ 热重载开发环境

# 安装 nodemon npm install -D nodemon # 使用 nodemon 启动 npm run dev

nodemon 会监听文件变化，自动重启服务器，大大提高开发效率。

开发环境 (nodemon)

  • 自动监听文件变化
  • 自动重启服务
  • 适合开发调试

生产环境 (node)

  • 稳定运行
  • 不会自动重启
  • 性能更好

🔌 环境变量配置

# .env 文件 PORT=3000 NODE_ENV=development DB_HOST=localhost DB_PORT=5432
// 安装 dotenv npm install dotenv
// index.js - 使用环境变量 require('dotenv').config(); const Koa = require('koa'); const app = new Koa(); const PORT = process.env.PORT || 3000; app.listen(PORT, () => { console.log(`Server running in ${process.env.NODE_ENV} mode on port ${PORT}`); });

🚀 启动与测试

# 启动开发服务器 npm run dev # 启动生产服务器 npm start # 测试接口 curl http://localhost:3000
💡
测试工具

推荐使用 Postman、Insomnia 或 curl 进行 API 测试。
