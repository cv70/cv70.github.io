阿里云函数计算简介

阿里云函数计算 (Function Compute) 是阿里云提供的 Serverless 计算服务。 国内网络访问更快，与阿里云生态深度集成，支持微信小程序、移动应用等场景，是国内开发者的首选。

🚀

国内节点，访问延迟低

💰

免费额度

生态集成

🚀 使用 Serverless Devs 部署

# 安装 Serverless Devs npm install -g @serverless-devs/s # 配置阿里云密钥 s config add # 本地调试 s local start # 部署函数 s deploy # 部署单个函数 s deploy function # 查看函数信息 s info # 查看日志 s logs # 删除资源 s remove

🔗 触发器类型

常用触发器

  • HTTP 触发器 - Web API
  • 定时触发器 - 定时任务
  • OSS 触发器 - 文件处理
  • 表格存储触发器 - 数据变更
  • 日志服务触发器 - 日志处理
  • MNS 触发器 - 消息队列

云服务集成

  • RDS MySQL - 关系数据库
  • PolarDB - 云原生数据库
  • 表格存储 - NoSQL
  • OSS - 对象存储
  • Redis - 缓存服务
  • SLS - 日志服务

# s.yaml 添加层配置 layers: common: component: fc-layer props: region: ${vars.region} name: common-layer codeUri: ./layer compatibleRuntimes: - nodejs16 - nodejs18 # 函数引用层 function: name: ${vars.functionName} layers: - acs:fc:${vars.region}:official:layers/Nodejs16/versions/1 - ${layers.common.output.layerArn}
