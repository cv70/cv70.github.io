102.1 Serverless 概念

理解无服务器架构的核心思想

🎯 学习目标

  • 理解 Serverless 的核心概念与优势
  • 了解 FaaS 和 BaaS 的区别
  • 掌握 Serverless 适用场景
  • 了解主流 Serverless 平台

什么是 Serverless

Serverless（无服务器）是一种云计算执行模型，云提供商动态分配机器资源， 用户无需管理服务器基础设施，只需为实际使用的计算资源付费。 "无服务器"并非真的没有服务器，而是用户不需要关心服务器的存在。

🏗️ Serverless 架构组成

FaaS (Function as a Service)

函数即服务，将业务逻辑封装成函数，由云平台自动触发和扩展。

  • AWS Lambda
  • Azure Functions
  • Google Cloud Functions
  • 阿里云函数计算
  • 腾讯云 SCF

BaaS (Backend as a Service)

后端即服务，使用云服务商提供的后端服务替代自建服务。

  • 数据库：Firebase、DynamoDB
  • 存储：OSS、S3
  • 认证：Auth0、Cognito
  • 消息队列：SQS、EventBridge

⚖️ 传统架构 vs Serverless

特性 传统架构 Serverless
服务器管理 需要自行管理 云服务商管理
扩展方式 手动扩展 自动扩展
计费方式 按时间/配置 按调用次数/执行时间
启动时间 持续运行 冷启动（毫秒级）
运维成本 高 低
适用场景 稳定高负载 突发/间歇性流量

✅ Serverless 优势

💰

降低成本

只为实际使用的资源付费，无请求时不产生费用

⚡

弹性扩展

自动根据请求量扩展，无需手动配置

🚀

快速开发

专注业务逻辑，无需管理基础设施

🔧

简化运维

无需管理服务器、补丁、安全更新

🌍

全球化部署

轻松部署到全球多个区域

📊

高可用

云服务商提供内置容错和可用性

⚠️ Serverless 挑战

技术挑战

  • 冷启动延迟
  • 执行时间限制
  • 本地调试复杂
  • 状态管理困难

业务挑战

  • 厂商锁定风险
  • 成本预测困难
  • 监控调试复杂
  • 安全边界模糊

🎯 适用场景

最佳实践场景

  • API 后端服务
  • 数据处理管道
  • 定时任务调度
  • 文件处理触发器
  • 聊天机器人
  • IoT 数据处理

不推荐场景

  • 长时间运行任务
  • 高频率小请求
  • 对延迟极其敏感
  • 复杂状态管理
  • 需要 GPU 计算

☁️ 主流 Serverless 平台

平台 特点 适用场景
Vercel 前端优先，Next.js 集成 前端应用、静态站点
Netlify JAMstack 生态完善 静态站点、表单处理
AWS Lambda 功能最全，生态最成熟 企业级应用
阿里云函数计算 国内网络友好 国内业务
腾讯云 SCF 微信生态集成 小程序后端
💡
Serverless 选择建议
  • 前端/全栈应用：Vercel 或 Netlify
  • 企业级复杂应用：AWS Lambda
  • 国内用户：阿里云函数计算或腾讯云 SCF
  • 小程序后端：腾讯云 SCF
  • 多云部署：使用 Serverless Framework

📝 本节小结

✅
  • • Serverless = FaaS + BaaS
  • • 按需计费、自动扩展、无需管理服务器
  • • 适合 API、数据处理、定时任务等场景
  • • 需注意冷启动、执行时间限制等问题
