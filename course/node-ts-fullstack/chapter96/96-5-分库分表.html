📚 分库分表概述

# 为什么需要分库分表 ## 单表瓶颈 - 数据量过大，查询变慢 - 单机存储容量限制 - 写入性能下降 - 备份恢复时间长 ## 解决方案 ### 垂直分表 将大表按列拆分 用户表 → 用户基础信息表 + 用户扩展信息表 ### 水平分表 将数据按行拆分到多个表 用户表 → 用户表1 + 用户表2 + 用户表3 ### 垂直分库 按业务拆分数据库 单库 → 用户库 + 订单库 + 商品库 ### 水平分库 将数据分散到多个数据库实例 用户库 → 用户库1 + 用户库2 + 用户库3 # 架构示例 应用层 │ ▼ ┌──────────────┐ │ 分片中间件 │ │ ShardingSphere│ └──────┬───────┘ │ ┌─────────────┼─────────────┐ │ │ │ ▼ ▼ ▼ ┌───────┐ ┌───────┐ ┌───────┐ │ DB1 │ │ DB2 │ │ DB3 │ │Table0 │ │Table0 │ │Table0 │ │Table1 │ │Table1 │ │Table1 │ └───────┘ └───────┘ └───────┘

🔧 分片策略

# 分片键选择 ## 好的分片键 - 数据分布均匀 - 查询命中率高 - 业务关联性强 ## 常见分片键 - 用户 ID - 订单 ID - 时间（按月/年） - 地区 # 分片算法 ## 1. Hash 分片 // 根据 ID hash 取模 function getTable(userId: number): string { const tableCount = 16; const index = userId % tableCount; return `users_${index}`; } ## 2. 范围分片 // 按范围分表 function getTable(userId: number): string { if (userId < 1000000) return 'users_1'; if (userId < 2000000) return 'users_2'; if (userId < 3000000) return 'users_3'; return 'users_4'; } ## 3. 时间分片 // 按月份分表 function getTable(date: Date): string { const year = date.getFullYear(); const month = date.getMonth() + 1; return `orders_${year}_${month.toString().padStart(2, '0')}`; } ## 4. 一致性 Hash import { ConsistentHash } from 'consistent-hash'; const ring = new ConsistentHash(); ring.add('db1'); ring.add('db2'); ring.add('db3'); const targetDb = ring.get(userId.toString());
💡
分片键选择

选择分片键时要考虑查询模式。如果大部分查询都带分片键，效率最高。避免跨分片查询。

⚙️ 分片中间件

# Prisma 多数据库配置 // schema.prisma datasource db1 { provider = "mysql" url = env("DATABASE_URL_1") } datasource db2 { provider = "mysql" url = env("DATABASE_URL_2") } # 自定义分片路由 class ShardingRouter { private shards: Map<string, PrismaClient>; constructor() { this.shards = new Map(); // 初始化多个数据库连接 this.shards.set('shard1', new PrismaClient({ datasources: { db: { url: process.env.DB_URL_1 } } })); this.shards.set('shard2', new PrismaClient({ datasources: { db: { url: process.env.DB_URL_2 } } })); } getShard(userId: string): PrismaClient { const index = parseInt(userId) % 2; return this.shards.get(`shard${index + 1}`)!; } async getUser(userId: string) { const shard = this.getShard(userId); return shard.user.findUnique({ where: { id: userId } }); } async createUser(data: any) { const shard = this.getShard(data.id); return shard.user.create({ data }); } } # 使用 ShardingSphere-JDBC // application.yml spring: shardingsphere: datasource: names: ds0,ds1 ds0: type: com.zaxxer.hikari.HikariDataSource driver-class-name: com.mysql.cj.jdbc.Driver jdbc-url: jdbc:mysql://localhost:3306/db0 ds1: type: com.zaxxer.hikari.HikariDataSource driver-class-name: com.mysql.cj.jdbc.Driver jdbc-url: jdbc:mysql://localhost:3306/db1 rules: sharding: tables: t_order: actual-data-nodes: ds$->{0..1}.t_order_$->{0..1} table-strategy: standard: sharding-column: order_id sharding-algorithm-name: t-order-inline key-generate-strategy: column: order_id key-generator-name: snowflake

🚀 分布式事务

# 跨分片事务处理 ## 1. 两阶段提交 (2PC) async function transfer(fromId: string, toId: string, amount: number) { const fromShard = router.getShard(fromId); const toShard = router.getShard(toId); // 阶段1：准备 await fromShard.$executeRaw`PREPARE TRANSACTION 'tx1'`; await toShard.$executeRaw`PREPARE TRANSACTION 'tx2'`; try { // 阶段2：提交 await fromShard.$executeRaw`COMMIT PREPARED 'tx1'`; await toShard.$executeRaw`COMMIT PREPARED 'tx2'`; } catch (error) { // 回滚 await fromShard.$executeRaw`ROLLBACK PREPARED 'tx1'`; await toShard.$executeRaw`ROLLBACK PREPARED 'tx2'`; throw error; } } ## 2. 最终一致性（Saga 模式） async function createOrder(orderData: any) { // 1. 创建订单（订单库） const order = await orderShard.order.create({ data: orderData }); // 2. 发送消息到库存服务 await messageQueue.publish('inventory.deduct', { orderId: order.id, items: orderData.items, }); // 库存服务消费消息，扣减库存 // 如果失败，发送补偿消息回滚订单 } ## 3. 本地消息表 async function transferWithLocalMessage(fromId: string, toId: string, amount: number) { const fromShard = router.getShard(fromId); // 在同一个事务中写入业务数据和消息 await fromShard.$transaction(async (tx) => { // 扣减余额 await tx.account.update({ where: { id: fromId }, data: { balance: { decrement: amount } }, }); // 写入本地消息表 await tx.outbox.create({ data: { eventType: 'TRANSFER', payload: { toId, amount }, status: 'PENDING', }, }); }); } // 后台任务轮询发送消息
