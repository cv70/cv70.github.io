国产大模型API生态

国内大模型发展迅速，阿里通义千问、百度文心一言、智谱ChatGLM、深度求索DeepSeek等都提供了完善的API服务。这些模型在中文理解、本土化服务、合规性方面具有独特优势。

🔥 通义千问API（阿里云）

# 安装SDK pip install dashscope # 基本调用 import dashscope from dashscope import Generation dashscope.api_key = "your-api-key" response = Generation.call( model="qwen-turbo", messages=[ {"role": "user", "content": "你好，请介绍一下自己"} ] ) print(response.output.choices[0].message.content) # OpenAI兼容方式 from openai import OpenAI client = OpenAI( api_key="your-api-key", base_url="https://dashscope.aliyuncs.com/compatible-mode/v1" ) response = client.chat.completions.create( model="qwen-turbo", messages=[{"role": "user", "content": "你好"}] )

🔄 统一API适配方案

通过OpenAI兼容接口，可以用统一代码调用多个国产模型。

class LLMClient: """统一的大模型客户端""" PROVIDERS = { "qwen": { "base_url": "https://dashscope.aliyuncs.com/compatible-mode/v1", "default_model": "qwen-turbo" }, "deepseek": { "base_url": "https://api.deepseek.com", "default_model": "deepseek-chat" }, "glm": { "base_url": "https://open.bigmodel.cn/api/paas/v4/", "default_model": "glm-4" } } def __init__(self, provider: str, api_key: str): config = self.PROVIDERS[provider] self.client = OpenAI( api_key=api_key, base_url=config["base_url"] ) self.model = config["default_model"] def chat(self, message: str): return self.client.chat.completions.create( model=self.model, messages=[{"role": "user", "content": message}] )

选型建议

性价比首选：DeepSeek（代码任务）、Qwen-Turbo（通用任务）；中文场景：Qwen-Max、GLM-4；企业合规：百度文心（完善的企业服务）；免费体验：智谱GLM提供较多免费额度。

⚠️
注意事项

国产API需要实名认证和备案，部分模型有内容审核限制。价格可能随时调整，请以官方最新公告为准。建议使用OpenAI兼容接口以便于切换模型。
