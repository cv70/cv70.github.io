18.1 可综合编码规范

HDL 编码最佳实践

🎯 学习目标

  • 掌握可综合编码的基本原则
  • 理解综合工具的限制
  • 学会避免不可综合的代码
  • 能够编写高质量的综合代码

✅ 可综合编码原则

原则说明
同步设计使用单一时钟域
明确复位所有寄存器都应有复位
完整casecase语句包含default
避免锁存器确保所有分支都赋值
参数化设计使用parameter提高复用性

❌ 不可综合的代码

// ❌ 不可综合：延迟
#10 a = b;

// ❌ 不可综合：非阻塞赋值在组合逻辑
always @(*) begin
    a <= b;  // 错误
end

// ❌ 不可综合：循环次数不确定
for (i = 0; i < n; i = i + 1)
    // n必须是常量

// ✅ 可综合：阻塞赋值在组合逻辑
always @(*) begin
    a = b;  // 正确
end
