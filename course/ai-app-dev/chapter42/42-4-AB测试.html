AI产品的A/B测试

A/B测试通过随机对照实验比较不同方案的效果差异。在AI产品中，A/B测试常用于比较不同模型、不同提示词、不同参数设置的效果，是数据驱动迭代的核心方法。

📊 A/B测试核心概念

🎲

随机分流

用户随机分配到实验组和对照组

📏

统计显著性

判断差异是否具有统计学意义

📈

效果指标

定义清晰的衡量标准

⚖️ AI测试场景

测试对象 变量 指标
模型版本 GPT-3.5 vs GPT-4 准确率、满意度、成本
提示词 不同prompt模板 输出质量、一致性
温度参数 temperature 0.0-1.0 多样性、相关性
检索策略 不同检索算法 命中率、答案质量
UI交互 不同展示方式 点击率、使用时长

💻 实验设计实现

import hashlib import numpy as np from scipy import stats class ABTestFramework: """A/B测试框架""" def __init__(self, experiment_name, variants): self.experiment_name = experiment_name self.variants = variants # {"control": 0.5, "treatment": 0.5} def get_variant(self, user_id): """根据用户ID确定分组""" hash_input = f"{self.experiment_name}:{user_id}" hash_value = int(hashlib.md5(hash_input.encode()).hexdigest(), 16) bucket = (hash_value % 100) / 100 cumulative = 0 for variant, ratio in self.variants.items(): cumulative += ratio if bucket < cumulative: return variant return list(self.variants.keys())[-1] def analyze_results(self, control_data, treatment_data): """分析实验结果""" control_mean = np.mean(control_data) treatment_mean = np.mean(treatment_data) # t检验 t_stat, p_value = stats.ttest_ind(control_data, treatment_data) # 效应量 (Cohen's d) pooled_std = np.sqrt( (np.var(control_data) + np.var(treatment_data)) / 2 ) effect_size = (treatment_mean - control_mean) / pooled_std return { "control_mean": control_mean, "treatment_mean": treatment_mean, "lift": (treatment_mean - control_mean) / control_mean, "p_value": p_value, "significant": p_value < 0.05, "effect_size": effect_size }

样本量计算

样本量取决于期望检测的最小效果、显著性水平和统计功效。效果越微小需要越大样本量。可使用在线计算器提前估算所需样本。

🔧 多臂老虎机测试

Epsilon-Greedy策略

import random class EpsilonGreedy: """探索与利用的平衡""" def __init__(self, arms, epsilon=0.1): self.arms = arms self.epsilon = epsilon self.counts = {arm: 0 for arm in arms} self.values = {arm: 0.0 for arm in arms} def select_arm(self): """选择一个arm""" if random.random() < self.epsilon: # 探索：随机选择 return random.choice(self.arms) else: # 利用：选择最优 return max(self.values, key=self.values.get) def update(self, arm, reward): """更新arm的估计值""" self.counts[arm] += 1 n = self.counts[arm] value = self.values[arm] # 增量更新均值 self.values[arm] = ((n - 1) / n) * value + (1 / n) * reward

Thompson Sampling

import numpy as np from scipy.stats import beta class ThompsonSampling: """贝叶斯老虎机算法""" def __init__(self, arms): self.arms = arms # Beta分布参数 self.alpha = {arm: 1 for arm in arms} self.beta_param = {arm: 1 for arm in arms} def select_arm(self): """从后验分布采样选择""" samples = {} for arm in self.arms: samples[arm] = beta.rvs( self.alpha[arm], self.beta_param[arm] ) return max(samples, key=samples.get) def update(self, arm, reward): """更新后验分布""" if reward == 1: # 成功 self.alpha[arm] += 1 else: # 失败 self.beta_param[arm] += 1
