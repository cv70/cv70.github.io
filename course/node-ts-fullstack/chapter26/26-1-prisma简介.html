📚 Prisma 概述

Prisma 是一个现代化的数据库工具集，提供类型安全的数据库访问。它由三个核心组件构成，为开发者提供完整的数据库开发体验。

Prisma 核心组件： 1. Prisma Schema（模式定义） ├── 使用 PSDL（Prisma Schema Definition Language） ├── 声明式定义数据模型 └── 支持多种数据库 2. Prisma Client（客户端） ├── 自动生成的类型安全查询 API ├── 直观的链式调用 └── 完整的 TypeScript 类型推断 3. Prisma Migrate（迁移工具） ├── 自动生成数据库迁移 ├── 版本控制数据库结构 └── 支持生产环境部署 支持的数据库： ├── PostgreSQL ├── MySQL ├── SQLite ├── SQL Server ├── MongoDB └── CockroachDB

🔧 Prisma vs TypeORM

对比维度： 1. 定义方式 TypeORM: 使用 TypeScript 装饰器 @Entity() export class User { @PrimaryGeneratedColumn() id: number; } Prisma: 使用独立的 Schema 文件 model User { id Int @id @default(autoincrement()) } 2. 类型安全 TypeORM: 运行时装饰器 + 编译时检查 Prisma: 代码生成，完整的编译时类型 3. 查询方式 TypeORM: QueryBuilder 或 Repository Prisma: 直观的 API，无需学习 SQL 4. 迁移管理 TypeORM: 手动编写或自动生成 Prisma: 完全自动化的迁移系统 5. 开发体验 TypeORM: 更接近传统 ORM Prisma: 现代化工具链，更好的 DX 选择建议： ├── 已有 TypeORM 项目：继续使用 ├── 新项目：推荐 Prisma ├── 需要复杂 SQL：两者都可以 └── 追求类型安全：Prisma 更优
💡
Prisma 优势

Prisma 的核心优势是类型安全。通过代码生成，Prisma Client 提供完整的 TypeScript 类型推断，减少运行时错误，提升开发效率。

📦 安装初始化

# 安装 Prisma CLI npm install prisma --save-dev # 安装 Prisma Client npm install @prisma/client # 初始化 Prisma npx prisma init # 初始化时指定数据库 npx prisma init --datasource-provider mysql npx prisma init --datasource-provider postgresql npx prisma init --datasource-provider sqlite npx prisma init --datasource-provider mongodb # 生成的文件结构 my-project/ ├── prisma/ │ └── schema.prisma # Prisma Schema 文件 ├── node_modules/ ├── .env # 环境变量（包含数据库连接） └── package.json # .env 文件内容 DATABASE_URL="mysql://user:password@localhost:3306/myapp" # schema.prisma 初始内容 generator client { provider = "prisma-client-js" } datasource db { provider = "mysql" url = env("DATABASE_URL") } // 在此处添加数据模型

⚙️ 基本使用流程

// 1. 定义数据模型（schema.prisma） model User { id Int @id @default(autoincrement()) email String @unique name String? posts Post[] createdAt DateTime @default(now()) updatedAt DateTime @updatedAt } model Post { id Int @id @default(autoincrement()) title String content String? published Boolean @default(false) author User @relation(fields: [authorId], references: [id]) authorId Int } // 2. 生成 Prisma Client npx prisma generate // 3. 同步数据库 npx prisma db push // 开发环境快速同步 // 或创建迁移 npx prisma migrate dev --name init // 创建迁移并应用 // 4. 使用 Prisma Client import { PrismaClient } from '@prisma/client'; const prisma = new PrismaClient(); async function main() { // 创建用户 const user = await prisma.user.create({ data: { email: 'alice@mail.com', name: 'Alice', }, }); // 查询用户 const users = await prisma.user.findMany(); } main() .catch(console.error) .finally(() => prisma.$disconnect());
