29.4 分布式锁

保证分布式系统的并发安全

🎯 学习目标

  • 理解分布式锁的作用
  • 掌握 Redis 实现分布式锁
  • 学会 Redlock 算法
  • 了解锁续期和可重入锁

📚 分布式锁概述

分布式锁用于在分布式系统中协调多个节点的并发访问，确保同一时刻只有一个节点能够执行关键操作。

分布式锁的应用场景： 1. 防止重复操作 ├── 定时任务执行 ├── 订单支付超时取消 └── 消息队列消费 2. 资源竞争 ├── 库存扣减 ├── 秒杀抢购 └── 优惠券领取 3. 数据一致性 ├── 缓存更新 ├── 配置同步 └── 状态机转换 分布式锁的要求： ├── 互斥性：任意时刻只有一个客户端持有锁 ├── 防死锁：锁必须有超时时间 ├── 安全性：只有持有锁的客户端才能释放锁 └── 高可用：锁服务要高可用

🔧 基础实现

import Redis from 'ioredis'; import { v4 as uuidv4 } from 'uuid'; const redis = new Redis(); // 基础分布式锁实现 class DistributedLock { constructor(private redis: Redis) {} // 获取锁 async acquire(key: string, ttl: number = 30): Promise { const token = uuidv4(); // 唯一标识 // SET key value NX EX ttl // NX: key 不存在时设置 // EX: 设置过期时间（秒） const result = await this.redis.set( `lock:${key}`, token, 'NX', 'EX', ttl ); return result === 'OK' ? token : null; } // 释放锁（使用 Lua 脚本保证原子性） async release(key: string, token: string): Promise { const script = ` if redis.call('get', KEYS[1]) == ARGV[1] then return redis.call('del', KEYS[1]) else return 0 end `; const result = await this.redis.eval( script, 1, `lock:${key}`, token ); return result === 1; } } // 使用示例 const lock = new DistributedLock(redis); async function doTask() { const token = await lock.acquire('my-task', 30); if (!token) { console.log('获取锁失败，其他节点正在执行'); return; } try { // 执行关键操作 await performTask(); } finally { await lock.release('my-task', token); } }
⚠️
锁释放安全

必须使用 Lua 脚本释放锁，先判断 token 再删除。直接 del 可能删除其他客户端的锁。

📊 锁续期实现

// 锁续期：自动延长锁的过期时间 class RenewingLock { private renewalTimer: NodeJS.Timeout | null = null; constructor(private redis: Redis) {} async acquire(key: string, ttl: number = 30): Promise { const token = uuidv4(); const result = await this.redis.set( `lock:${key}`, token, 'NX', 'EX', ttl ); if (result === 'OK') { this.startRenewal(key, token, ttl); return token; } return null; } private startRenewal(key: string, token: string, ttl: number) { // 每过 ttl/3 时间续期一次 const interval = (ttl / 3) * 1000; this.renewalTimer = setInterval(async () => { const script = ` if redis.call('get', KEYS[1]) == ARGV[1] then return redis.call('expire', KEYS[1], ARGV[2]) else return 0 end `; await this.redis.eval(script, 1, `lock:${key}`, token, ttl); }, interval); } async release(key: string, token: string): Promise { // 停止续期 if (this.renewalTimer) { clearInterval(this.renewalTimer); this.renewalTimer = null; } const script = ` if redis.call('get', KEYS[1]) == ARGV[1] then return redis.call('del', KEYS[1]) else return 0 end `; const result = await this.redis.eval(script, 1, `lock:${key}`, token); return result === 1; } }

⚙️ 完整实现示例

// 库存扣减示例 async function deductStock(productId: string, quantity: number) { const lockKey = `stock:${productId}`; const token = await lock.acquire(lockKey, 10); if (!token) { throw new Error('系统繁忙，请稍后重试'); } try { // 检查库存 const stock = await Product.findById(productId); if (!stock || stock.count < quantity) { throw new Error('库存不足'); } // 扣减库存 stock.count -= quantity; await stock.save(); // 创建订单 const order = await Order.create({ productId, quantity, userId: getCurrentUserId(), }); return order; } finally { await lock.release(lockKey, token); } } // 使用 redlock 库（多 Redis 实例） import Redlock from 'redlock'; const redlock = new Redlock( [new Redis(), new Redis(), new Redis()], { driftFactor: 0.01, retryCount: 3, retryDelay: 200, retryJitter: 200, } ); async function withLock(resource: string, ttl: number, fn: () => Promise) { const lock = await redlock.acquire([resource], ttl); try { return await fn(); } finally { await lock.release(); } } // 使用 await withLock('locks:order:123', 5000, async () => { // 执行关键操作 await processOrder('123'); }); // 注意事项 // 1. 锁的粒度要合适，避免锁住太多操作 // 2. TTL 要大于操作预期时间 // 3. 使用 try-finally 确保锁释放 // 4. 考虑锁获取失败的降级策略
