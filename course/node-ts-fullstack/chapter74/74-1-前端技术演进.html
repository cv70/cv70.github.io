从静态页面到现代前端架构

🎯 学习目标

  • 了解前端技术的发展历程
  • 理解各阶段技术的特点
  • 掌握现代前端的核心概念
  • 认识前端技术演进的动力

📚 前端技术发展阶段

// 前端技术演进历程 // 第一阶段：静态网页时代（1990s） // - 纯 HTML 文档 // - 简单的 CSS 样式 // - 无交互或极少交互 // - 服务器返回完整页面 // 第二阶段：JavaScript 诞生（1995-2005） // - Netscape 发明 JavaScript // - 表单验证、简单动画 // - DOM 操作萌芽 // - 浏览器兼容性问题严重 // 第三阶段：jQuery 时代（2006-2010） // - jQuery 统一浏览器 API // - 链式调用、选择器 // - AJAX 广泛应用 // - 插件生态繁荣 // 第四阶段：前端 MVC 框架（2010-2013） // - Backbone.js、Knockout.js // - MVC/MVP/MVVM 模式引入 // - 数据驱动的视图更新 // - 前端架构意识觉醒 // 第五阶段：三大框架时代（2013-至今） // - React、Vue、Angular 三足鼎立 // - 组件化开发成为主流 // - 虚拟 DOM、响应式系统 // - 完整的前端工程化体系

🔧 jQuery vs 现代框架

// jQuery 方式：命令式编程 $('#submit-btn').on('click', function() { var name = $('#name-input').val(); if (name) { $.ajax({ url: '/api/users', method: 'POST', data: { name: name }, success: function(response) { $('#user-list').append('<li>' + response.name + '</li>'); $('#name-input').val(''); } }); } }); // React 方式：声明式编程 function UserList() { const [users, setUsers] = useState([]); const [name, setName] = useState(''); const handleSubmit = async () => { if (name) { const response = await fetch('/api/users', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ name }) }); const user = await response.json(); setUsers([...users, user]); setName(''); } }; return ( <div> <input value={name} onChange={e => setName(e.target.value)} /> <button onClick={handleSubmit}>添加</button> <ul> {users.map(user => <li key={user.id}>{user.name}</li>)} </ul> </div> ); }

📊 演进驱动力

💡
前端技术演进的核心驱动力

1. Web 应用复杂度提升：从文档到应用
2. 用户体验要求提高：更流畅、更即时
3. 开发效率需求：可维护性、可复用性
4. 工程化需求：模块化、自动化、规范化

📝 本节小结

✅
  • • 前端技术从静态页面发展到复杂应用
  • • jQuery 统一了浏览器 API，降低了开发门槛
  • • 现代框架采用声明式、组件化开发模式
  • • 技术演进由应用复杂度和用户体验驱动
