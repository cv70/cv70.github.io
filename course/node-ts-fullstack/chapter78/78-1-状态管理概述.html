📊 何时需要状态管理

💡
需要状态管理的场景

1. 多个组件需要访问同一状态
2. 状态需要在不同页面间保持
3. 复杂的状态更新逻辑
4. 需要时间旅行调试
5. 需要状态持久化

不需要状态管理的场景：
1. 状态只在单个组件使用
2. 父子组件简单的 props 传递
3. 临时 UI 状态（开关、输入）

📝 本节小结

✅
  • • 状态分为本地状态、全局状态、服务端状态
  • • 选择合适的状态管理方案很重要
  • • 不要过度设计，按需选择
  • • 服务端状态推荐使用 TanStack Query
