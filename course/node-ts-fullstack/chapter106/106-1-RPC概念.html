106.1 RPC 概念

远程过程调用的核心原理

🎯 学习目标

  • 理解RPC的定义和作用
  • 掌握RPC的工作原理
  • 了解RPC与REST的区别
  • 认识常见的RPC框架

📚 什么是RPC？

// RPC（Remote Procedure Call）远程过程调用 // 允许程序调用另一台计算机上的函数，就像调用本地函数一样 // 本地调用 const result = add(1, 2); // 本地函数调用 // RPC调用（看起来像本地调用，实际在远程执行） const result = await rpcClient.add(1, 2); // 远程函数调用 // RPC核心概念 const concepts = { client: '调用方，发起RPC请求', server: '服务方，处理RPC请求', stub: '桩代码，客户端和服务端的代理', serialization: '序列化，将对象转换为字节流', deserialization: '反序列化，将字节流还原为对象', transport: '传输层，负责网络通信' }; // RPC调用流程 const rpcFlow = ` Client Server | | |--调用本地桩代码-------->| | | |--序列化参数------------>| | | |--网络传输-------------->| | | | 反序列化<-| | 调用函数<-| | 序列化结果| | | |<--网络传输--------------| | | |<--反序列化结果----------| | | |<--返回调用结果----------| `;
💡
RPC核心目标

让远程调用像本地调用一样简单，隐藏网络通信的复杂性。

🔧 RPC vs REST

// RPC风格 // 基于动作，直接表达意图 // JSON-RPC示例 const rpcRequest = { jsonrpc: '2.0', method: 'createUser', params: { name: 'Alice', email: 'alice@example.com' }, id: 1 }; // gRPC示例（Protocol Buffers） service UserService { rpc CreateUser(CreateUserRequest) returns (User); rpc GetUser(GetUserRequest) returns (User); rpc ListUsers(ListUsersRequest) returns (stream User); } // REST风格 // 基于资源，使用HTTP动词 // RESTful API POST /users // 创建用户 GET /users/123 // 获取用户 PUT /users/123 // 更新用户 DELETE /users/123 // 删除用户 GET /users // 列出用户 // 对比 const comparison = { RPC: { 优点: ['性能高', '类型安全', '适合内部服务', '支持双向流'], 缺点: ['耦合度高', '调试不方便', '需要IDL'], 场景: ['微服务内部调用', '高性能场景', '实时通信'] }, REST: { 优点: ['简单通用', '跨语言', '调试方便', '无状态'], 缺点: ['性能较低', '类型不安全', 'over-fetching'], 场景: ['对外API', 'Web应用', '移动端'] } };

🔀 常见RPC框架

// 主流RPC框架 const rpcFrameworks = { gRPC: { language: '多语言支持（Go, Java, Python, Node.js等）', protocol: 'HTTP/2 + Protocol Buffers', features: ['高性能', '双向流', '强类型', '代码生成'], company: 'Google' }, Dubbo: { language: 'Java', protocol: 'TCP/Dubbo协议', features: ['服务治理', '负载均衡', '集群容错'], company: '阿里巴巴' }, Thrift: { language: '多语言支持', protocol: 'TCP/HTTP', features: ['跨语言', '高性能', '可扩展'], company: 'Facebook/Apache' }, JSON-RPC: { language: '语言无关', protocol: 'HTTP/JSON', features: ['简单', '轻量', '易调试'], company: '社区标准' } }; // 简单RPC实现示例 class SimpleRPCServer { private methods: Map = new Map(); // 注册方法 register(name: string, handler: Function) { this.methods.set(name, handler); } // 处理请求 async handle(request: any): Promise { const { method, params, id } = request; const handler = this.methods.get(method); if (!handler) { return { jsonrpc: '2.0', error: { code: -32601, message: 'Method not found' }, id }; } try { const result = await handler(...params); return { jsonrpc: '2.0', result, id }; } catch (error) { return { jsonrpc: '2.0', error: { code: -32603, message: error.message }, id }; } } } // 服务端使用 const server = new SimpleRPCServer(); server.register('add', (a: number, b: number) => a + b); server.register('multiply', (a: number, b: number) => a * b); // 客户端代理 class SimpleRPCClient { private transport: Transport; async call(method: string, ...params: any[]) { const request = { jsonrpc: '2.0', method, params, id: Date.now() }; const response = await this.transport.send(request); return response.result; } }

📝 本节小结

✅
  • • RPC让远程调用像本地调用一样简单
  • • 核心包含序列化、传输、反序列化
  • • RPC适合内部服务，REST适合对外API
  • • gRPC是目前最流行的RPC框架之一
