商品CTA策略

商品CTA策略（Commodity Trading Advisor）是专门针对商品期货市场的趋势跟踪策略。通过捕捉价格趋势，实现多空双向交易，是量化交易中最成熟的策略类型之一。商品CTA策略通常在趋势明显的市场中表现优异。

📈 CTA策略特点

策略优势

  • 多空双向交易，牛熊市都可盈利
  • 趋势跟踪，捕捉大行情
  • 多品种分散，降低单一风险
  • 系统化交易，避免情绪干扰
  • 流动性好，易于大规模执行

策略挑战

  • 震荡市中连续亏损
  • 趋势识别存在滞后
  • 交易成本较高
  • 过度拟合风险
  • 容量限制明显

🔄 经典CTA策略

策略类型 原理 参数 适用市场
双均线策略 快线上穿慢线买入，下穿卖出 短期均线、长期均线 趋势市场
布林带策略 突破上轨买入，跌破下轨卖出 周期、标准差倍数 突破市场
海龟交易法则 突破20日最高点买入 突破周期、止损距离 强趋势市场
唐奇安通道 突破N日最高最低点 通道周期 趋势市场
动量策略 过去N期涨幅大的买入 回看周期 惯性市场

class DualMovingAverageCTA(CTAStrategy):
    """双均线CTA策略"""

    def __init__(self, fast_period: int = 20, slow_period: int = 60):
        super().__init__("DualMovingAverage")
        self.fast_period = fast_period
        self.slow_period = slow_period

    def generate_signals(self, data: pd.DataFrame) -> Dict:
        """生成双均线信号"""
        df = data.copy()

        # 计算均线
        df['fast_ma'] = df['close'].rolling(window=self.fast_period).mean()
        df['slow_ma'] = df['close'].rolling(window=self.slow_period).mean()

        # 计算交叉
        df['cross'] = df['fast_ma'] > df['slow_ma']
        df['signal'] = df['cross'].diff()

        # 生成信号
        latest = df.iloc[-1]
        if latest['signal'] > 0:
            return {'symbol': df['symbol'].iloc[0], 'signal': 'long', 'price': latest['close']}
        elif latest['signal'] < 0:
            return {'symbol': df['symbol'].iloc[0], 'signal': 'short', 'price': latest['close']}
        else:
            return {'symbol': df['symbol'].iloc[0], 'signal': 'hold', 'price': latest['close']}

class BollingerBandCTA(CTAStrategy):
    """布林带CTA策略"""

    def __init__(self, period: int = 20, std_dev: float = 2.0):
        super().__init__("BollingerBand")
        self.period = period
        self.std_dev = std_dev

    def generate_signals(self, data: pd.DataFrame) -> Dict:
        """生成布林带信号"""
        df = data.copy()

        # 计算布林带
        df['middle_band'] = df['close'].rolling(window=self.period).mean()
        df['std'] = df['close'].rolling(window=self.period).std()
        df['upper_band'] = df['middle_band'] + self.std_dev * df['std']
        df['lower_band'] = df['middle_band'] - self.std_dev * df['std']

        # 计算突破
        df['upper_breakout'] = df['close'] > df['upper_band']
        df['lower_breakout'] = df['close'] < df['lower_band']

        latest = df.iloc[-1]

        if latest['upper_breakout']:
            return {
                'symbol': df['symbol'].iloc[0],
                'signal': 'long',
                'price': latest['close'],
                'stop_loss': latest['middle_band']
            }
        elif latest['lower_breakout']:
            return {
                'symbol': df['symbol'].iloc[0],
                'signal': 'short',
                'price': latest['close'],
                'stop_loss': latest['middle_band']
            }
        else:
            return {
                'symbol': df['symbol'].iloc[0],
                'signal': 'hold',
                'price': latest['close']
            }

class TurtleCTA(CTAStrategy):
    """海龟交易法则"""

    def __init__(self, entry_period: int = 20, exit_period: int = 10, atr_period: int = 20):
        super().__init__("Turtle")
        self.entry_period = entry_period
        self.exit_period = exit_period
        self.atr_period = atr_period

    def calculate_atr(self, data: pd.DataFrame) -> float:
        """计算ATR"""
        high = data['high']
        low = data['low']
        close = data['close']

        tr1 = high - low
        tr2 = abs(high - close.shift(1))
        tr3 = abs(low - close.shift(1))

        tr = pd.concat([tr1, tr2, tr3], axis=1).max(axis=1)
        atr = tr.rolling(window=self.atr_period).mean()

        return atr.iloc[-1]

    def generate_signals(self, data: pd.DataFrame) -> Dict:
        """生成海龟信号"""
        df = data.copy()

        # 计算通道
        df['entry_high'] = df['high'].rolling(window=self.entry_period).max()
        df['entry_low'] = df['low'].rolling(window=self.entry_period).min()
        df['exit_high'] = df['high'].rolling(window=self.exit_period).max()
        df['exit_low'] = df['low'].rolling(window=self.exit_period).min()

        # 计算ATR
        atr = self.calculate_atr(df)

        latest = df.iloc[-1]

        if latest['close'] > latest['entry_high']:
            return {
                'symbol': df['symbol'].iloc[0],
                'signal': 'long',
                'price': latest['close'],
                'stop_loss': latest['close'] - 2 * atr,
                'target': latest['close'] + 2 * atr
            }
        elif latest['close'] < latest['entry_low']:
            return {
                'symbol': df['symbol'].iloc[0],
                'signal': 'short',
                'price': latest['close'],
                'stop_loss': latest['close'] + 2 * atr,
                'target': latest['close'] - 2 * atr
            }
        else:
            return {
                'symbol': df['symbol'].iloc[0],
                'signal': 'hold',
                'price': latest['close']
            }

class CommodityCTAPortfolio:
    """商品CTA组合管理"""

    def __init__(self, strategies: List[CTAStrategy]):
        self.strategies = strategies
        self.portfolio = {}

    def generate_portfolio_signals(self, market_data: Dict[str, pd.DataFrame]) -> Dict:
        """生成组合信号"""
        signals = {}

        for symbol, data in market_data.items():
            data['symbol'] = symbol

            for strategy in self.strategies:
                signal = strategy.generate_signals(data)
                signals[f"{symbol}_{strategy.name}"] = signal

        return signals

    def select_best_signals(self, signals: Dict, max_positions: int = 5) -> List:
        """选择最佳信号"""
        # 这里可以添加信号评分和选择逻辑
        # 例如：根据信号强度、相关性等
        selected = []

        for signal_key, signal in signals.items():
            if signal['signal'] != 'hold':
                selected.append(signal_key)

        return selected[:max_positions]

📊 CTA策略评估

📋
CTA绩效指标
  • 夏普比率: 风险调整后收益，优秀策略>1.5
  • 最大回撤: 历史最大亏损，通常控制在20-30%
  • 胜率: 盈利交易占比，通常35-45%即可
  • 盈亏比: 盈利交易平均收益/亏损交易平均亏损
  • 卡玛比率: 年化收益/最大回撤，优秀>1.0
  • 月度胜率: 月度盈利占比，衡量策略稳定性
⚠️
风险提示

CTA策略风险：1）震荡市中持续亏损；2）趋势识别滞后，错过最佳入场点；3）过度拟合导致实盘表现差；4）交易成本侵蚀收益；5）市场容量限制，大资金难以执行；6）相关性风险，极端行情下多品种同向亏损。建议做好风控，持续监控策略表现。

✨
最佳实践

商品CTA策略成功的关键：1）多品种分散降低风险；2）多周期组合提高稳定性；3）动态调整参数适应市场变化；4）严格止损，控制单笔亏损；5）做好资金管理，控制总仓位；6）定期评估策略有效性；7）保持耐心，长期坚持。
