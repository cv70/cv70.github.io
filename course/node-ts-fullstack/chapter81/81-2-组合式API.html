81.2 组合式 API

Vue 3 的核心编程范式

📖 本节概述

组合式 API（Composition API）是 Vue 3 最重要的新特性之一。它提供了一种更灵活的方式来组织和复用组件逻辑，解决了选项式 API 在大型组件中代码组织困难的问题。

🎯 学习目标

  • 理解组合式 API 的设计理念
  • 掌握 setup 函数和 script setup 语法
  • 学会使用 ref 和 reactive 创建响应式数据
  • 掌握 computed、watch 等响应式 API

🔧 setup 函数

基本用法

import { ref, reactive, computed, onMounted } from 'vue'; export default { // setup 在组件创建之前执行 setup(props, context) { // 响应式数据 const count = ref(0); const state = reactive({ name: 'Vue' }); // 计算属性 const doubleCount = computed(() => count.value * 2); // 方法 function increment() { count.value++; } // 生命周期 onMounted(() => { console.log('组件已挂载'); }); // 返回模板需要使用的数据和方法 return { count, state, doubleCount, increment }; } }

setup 参数

export default { props: { title: String }, setup(props, context) { // props - 响应式的 props 对象 console.log(props.title); // context - 上下文对象 // context.attrs - 非 prop 的 attribute // context.slots - 插槽 // context.emit - 触发事件 // context.expose - 暴露给父组件 function handleSubmit() { context.emit('submit', { value: 'data' }); } return { handleSubmit }; } }

⚡ script setup 语法

<script setup> 是 Vue 3.2+ 的编译时语法糖，简化了组合式 API 的使用。

<script setup lang="ts"> import { ref, computed, onMounted } from 'vue'; // 定义 props const props = defineProps<{ title: string; count?: number; }>(); // 定义 emits const emit = defineEmits<{ (e: 'update', value: number): void; (e: 'submit'): void; }>(); // 响应式数据 - 自动暴露到模板 const count = ref(props.count ?? 0); const doubleCount = computed(() => count.value * 2); // 方法 - 自动暴露到模板 function increment() { count.value++; emit('update', count.value); } // 生命周期 onMounted(() => { console.log('Mounted'); }); </script> <template> <div> <h2>{{ props.title }}</h2> <p>Count: {{ count }}</p> <p>Double: {{ doubleCount }}</p> <button @click="increment">+1</button> </div> </template>

📦 ref 和 reactive

ref - 基本类型响应式

import { ref } from 'vue'; // 创建 ref const count = ref(0); const name = ref('Vue'); const isActive = ref(true); // 访问和修改需要 .value console.log(count.value); // 0 count.value++; // 在模板中自动解包，不需要 .value // <div>{{ count }}</div> // ref 也可以存储对象 const user = ref({ name: 'John', age: 20 }); user.value.name = 'Jane'; // 需要通过 .value 访问

reactive - 对象响应式

import { reactive } from 'vue'; // 创建 reactive 对象 const state = reactive({ count: 0, user: { name: 'John', profile: { email: 'john@example.com' } } }); // 直接访问，不需要 .value console.log(state.count); // 0 console.log(state.user.name); // 'John' // 修改 state.count++; state.user.name = 'Jane'; // 注意：解构会失去响应性 const { count } = state; // count 不是响应式的！ // 使用 toRefs 保持响应性 import { toRefs } from 'vue'; const { count } = toRefs(state); // count 是响应式的 ref

ref vs reactive

特性 ref reactive
适用类型 基本类型、对象 对象、数组
访问方式 .value 直接访问
重新赋值 可以 不可以（会丢失响应性）
解构 支持 需要 toRefs

🔄 computed 和 watch

computed - 计算属性

import { ref, computed } from 'vue'; const firstName = ref('John'); const lastName = ref('Doe'); // 只读计算属性 const fullName = computed(() => { return `${firstName.value} ${lastName.value}`; }); // 可写计算属性 const fullNameWritable = computed({ get() { return `${firstName.value} ${lastName.value}`; }, set(value: string) { [firstName.value, lastName.value] = value.split(' '); } }); fullNameWritable.value = 'Jane Smith'; console.log(firstName.value); // 'Jane'

watch - 侦听器

import { ref, watch, watchEffect } from 'vue'; const count = ref(0); const name = ref('Vue'); // 侦听单个 ref watch(count, (newVal, oldVal) => { console.log(`count: ${oldVal} -> ${newVal}`); }); // 侦听多个源 watch([count, name], ([newCount, newName], [oldCount, oldName]) => { console.log(`count: ${newCount}, name: ${newName}`); }); // 侦听 reactive 对象的属性 const state = reactive({ user: { name: '' } }); watch( () => state.user.name, (newName) => console.log(newName) ); // 深度侦听 watch( () => state.user, (newUser) => console.log('user changed'), { deep: true } ); // 立即执行 watch(count, handler => { /* ... */ }, { immediate: true }); // watchEffect - 自动追踪依赖 watchEffect(() => { console.log(`count is ${count.value}`); });

🔌 生命周期钩子

import { onBeforeMount, onMounted, onBeforeUpdate, onUpdated, onBeforeUnmount, onUnmounted, onErrorCaptured } from 'vue'; export default { setup() { // 组件挂载前 onBeforeMount(() => { console.log('beforeMount'); }); // 组件挂载后 onMounted(() => { console.log('mounted'); }); // 组件更新前 onBeforeUpdate(() => { console.log('beforeUpdate'); }); // 组件更新后 onUpdated(() => { console.log('updated'); }); // 组件卸载前 onBeforeUnmount(() => { console.log('beforeUnmount'); }); // 组件卸载后 onUnmounted(() => { console.log('unmounted'); }); } }

📝 本节小结

  • 组合式 API 提供更灵活的代码组织方式
  • setup 是组合式 API 的入口函数
  • script setup 是推荐的语法糖，简化代码
  • ref 用于基本类型，reactive 用于对象
  • watch 用于显式侦听，watchEffect 自动追踪依赖
