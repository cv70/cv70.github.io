17.3 Chain-of-Thought

思维链推理：让模型学会"一步步思考"

🎯 学习目标

  • 理解Chain-of-Thought的核心原理
  • 掌握CoT的基本用法和变体
  • 学会在复杂推理任务中应用CoT
  • 了解CoT的适用场景和局限性

什么是Chain-of-Thought

Chain-of-Thought（CoT，思维链）是一种Prompt技术，通过引导模型展示中间推理步骤，提升复杂问题的解决能力。核心思想是：让模型"大声思考"，把复杂问题分解为可管理的子步骤。

💡 CoT的核心价值

为什么有效？

  • 分解复杂问题：将难题拆解为简单子问题
  • 显式推理过程：避免跳跃式错误
  • 可验证性：便于检查推理逻辑
  • 涌现能力：激发大模型的推理潜力

适用场景

  • 数学问题求解
  • 逻辑推理任务
  • 复杂决策分析
  • 多步骤编程任务
  • 问题诊断排查
图：思维链让模型像人类一样逐步解决问题

🔄 标准CoT vs 无CoT对比

无CoT（直接回答）

问题：小明有15个苹果，给了小红3个， 又买了8个，现在有多少个？ 回答：20个

问题：可能直接给出错误答案，无法验证

有CoT（逐步推理）

问题：小明有15个苹果，给了小红3个， 又买了8个，现在有多少个？ 让我们一步步思考： 1. 小明最初有15个苹果 2. 给了小红3个后：15 - 3 = 12个 3. 又买了8个后：12 + 8 = 20个 4. 所以现在有20个苹果 答案：20个

优点：推理过程清晰，便于验证

🔧 CoT实战示例

示例1：数学应用题

问题：一个商店进购了100件商品，每件成本50元。 如果以每件70元的价格卖出，卖出了80件后打8折， 最终全部卖出。问总利润是多少？ 请一步步思考：
/* 模型输出 */ 让我们一步步计算： 1. 总成本：100件 × 50元 = 5000元 2. 前80件的收入：80件 × 70元 = 5600元 3. 剩余20件的售价：70元 × 0.8 = 56元/件 4. 后20件的收入：20件 × 56元 = 1120元 5. 总收入：5600 + 1120 = 6720元 6. 总利润：6720 - 5000 = 1720元 答案：总利润是1720元

示例2：逻辑推理

问题：如果所有的A都是B，所有的B都是C， 那么有些A是C吗？请一步步推理。
/* 模型输出 */ 让我们一步步推理： 1. 前提1：所有A都是B - 这意味着A是B的子集 2. 前提2：所有B都是C - 这意味着B是C的子集 3. 推导：如果A ⊆ B，且B ⊆ C - 根据集合传递性：A ⊆ C 4. 结论：既然所有A都是C - 那么"有些A是C"这个命题是正确的 - 实际上更强：所有A都是C 答案：是的，命题成立，且实际上所有A都是C

📊 CoT变体技术

技术名称 描述 特点
Zero-shot CoT 只添加"让我们一步步思考" 简单高效，无需示例
Few-shot CoT 提供带推理步骤的示例 效果更好，需要示例
Self-Consistency 多次推理取共识 提高准确性，成本更高
Tree of Thoughts 多分支探索最优路径 适合决策类问题
Least-to-Most 由简到繁分解问题 适合复杂嵌套问题

🚀 Zero-shot CoT用法

只需在问题后添加一句简单的提示语，即可激活CoT推理。

// 标准Zero-shot CoT提示语 "让我们一步步思考" "请一步步分析" "Let's think step by step" // 使用示例 prompt = """ 问题是：一个长方形的长是宽的2倍，周长是36厘米， 求长方形的面积。 让我们一步步思考。 """

🎯 Self-Consistency（自一致性）

通过多次采样取共识，提高CoT的可靠性。

def self_consistency(question, n_samples=5): answers = [] for _ in range(n_samples): # 设置temperature > 0获取多样性 response = model.generate( question + "\n让我们一步步思考。", temperature=0.7 ) answers.append(extract_answer(response)) # 返回最常见的答案 return most_common(answers)
💡
最佳实践

对于数学计算和逻辑推理任务，CoT效果显著提升。但对于简单任务，CoT可能增加不必要的token消耗。建议根据任务复杂度选择是否使用CoT。

⚠️
局限性

CoT主要适用于大模型（通常70B+参数），小模型可能无法有效利用思维链。此外，CoT会增加输出长度，提高API调用成本和响应延迟。

📝 本节小结

✅
  • • CoT通过展示中间推理步骤提升复杂问题解决能力
  • • Zero-shot CoT只需添加"让我们一步步思考"
  • • 适用于数学、逻辑推理等需要多步骤思考的任务
  • • Self-Consistency通过多次采样提高可靠性
  • • 主要适用于大模型，会增加输出成本
