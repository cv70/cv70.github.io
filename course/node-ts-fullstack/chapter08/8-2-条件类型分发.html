8.2 条件类型分发

联合类型的分布式条件类型

🎯 学习目标

  • 理解条件类型的分发机制
  • 掌握联合类型的分发规则
  • 学会控制分发的开启和关闭
  • 了解分发的实际应用

📚 什么是分发？

// 当条件类型作用于联合类型时，会自动分发 // 即对联合类型的每个成员分别应用条件类型 type ToArray = T extends any ? T[] : never; // 分发过程： // string | number 分发为： // (string extends any ? string[] : never) | // (number extends any ? number[] : never) // 结果：string[] | number[] type Result = ToArray; // string[] | number[] // 另一个示例 type NonNullable = T extends null | undefined ? never : T; type R1 = NonNullable; // string type R2 = NonNullable; // number type R3 = NonNullable; // never // 分发过程： // string | null | undefined 分发为： // (string extends null | undefined ? never : string) | -> string // (null extends null | undefined ? never : null) | -> never // (undefined extends null | undefined ? never : undefined) -> never // 结果：string | never | never = string
💡
分发规则

当 T 是联合类型时，条件类型会自动将 T 拆分为每个成员，分别判断后再组合。这是 TypeScript 的内置行为。

🔒 禁止分发

// 有时我们不希望分发，可以使用元组包装 type ToArrayNoDistribute = [T] extends [any] ? T[] : never; type WithDistribute = ToArray; // string[] | number[] type NoDistribute = ToArrayNoDistribute; // (string | number)[] // 对比： // 分发： (string | number)[] => 可以是 string[] 或 number[] // 不分发：(string | number)[] => 必须同时包含 string 和 number // 实际应用：检查是否为联合类型 type IsUnion = T extends any ? [U] extends [T] ? false : true : never; type A = IsUnion; // false type B = IsUnion; // true type C = IsUnion; // false

🔧 实用示例

// 获取函数返回值类型的联合 type GetReturnTypes = T extends (...args: any[]) => infer R ? R : never; type Funcs = (() => string) | ((n: number) => number) | ((b: boolean) => void); type Returns = GetReturnTypes; // string | number | void // 提取联合类型中的特定类型 type ExtractString = T extends string ? T : never; type Mixed = string | number | boolean | 'hello'; type OnlyString = ExtractString; // string | 'hello' // 过滤联合类型 type Filter = T extends U ? T : never; type Values = 'a' | 'b' | 1 | 2 | true; type Letters = Filter; // 'a' | 'b' type Numbers = Filter; // 1 | 2 // 排除类型（Exclude 的实现） type MyExclude = T extends U ? never : T; type E = MyExclude<'a' | 'b' | 'c', 'a'>; // 'b' | 'c'

📝 本节小结

✅
  • • 联合类型自动触发分发
  • • 分发对每个成员单独判断
  • • [T] 包装可禁止分发
  • • 分发是 Filter/Exclude 等工具类型的基础
