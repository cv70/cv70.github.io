布局布线规范

布局布线规范是"设计规范速查"附录中的第3节内容。 合理的布局布线是保证电路性能和可制造性的关键。 本节将系统介绍PCB布局布线的各项规范要求和最佳实践。

📋 布局基本原则

原则 要求 说明
功能分区 按功能模块划分 电源、数字、模拟分区布局
信号流向 符合信号传输路径 输入→处理→输出顺序
就近原则 相关器件靠近 减少走线长度
散热考虑 热源分散布局 功率器件周围留空间
可调性 预留调试空间 关键器件便于更换

🏗️ 核心器件布局

MCU/CPU布局

  • 居中放置，周边围绕外设
  • 电源去耦电容紧贴引脚
  • 晶振靠近时钟输入引脚
  • 高速接口短路径布线
  • 复位电路靠近复位引脚

电源模块布局

  • 输入端靠近连接器
  • 电感、开关节点铺铜散热
  • 反馈网络远离干扰源
  • 输入输出电容就近放置
  • 散热器件预留散热空间

🔗 布线规范

信号布线

信号类型 布线要求 注意事项
高速信号 短、直、差分 阻抗控制，等长匹配
时钟信号 最短路径 包地处理，避免过孔
模拟信号 远离数字 专用层，屏蔽处理
电源线 加宽线宽 根据电流计算线宽
地线 完整平面 多过孔连接

差分线布线

  • 等长、等距、同层
  • 严格控制阻抗（100Ω/90Ω）
  • 避免过孔和换层
  • 保持平行，尽量减少弯曲
  • 弯曲处采用圆弧或45度

⚡ 电源地布局

电源设计

  • 电源平面完整
  • 多电源分区域
  • 电源走线加宽
  • 去耦电容就近
  • 大电流回路短

地线设计

  • 完整地平面
  • 单点接地/多点接地
  • 模拟地数字地分离
  • 多过孔连接
  • 避免地分割

🛡️ EMC设计要点

项目 设计要求
滤波 电源输入端、接口处添加滤波电容
屏蔽 敏感电路加屏蔽罩
去耦 IC电源端就近去耦
接口 接口处ESD防护
接地 良好接地设计
布局 强电弱电分区

🌡️ 散热布局

  • 热源器件分散布局
  • 大功率器件周围留散热通道
  • 热器件避免叠放
  • 利用内层铜箔散热
  • 添加散热过孔阵列
  • 考虑风道和自然对流
✨
最佳实践

1）先布局核心器件，再外设器件； 2）布局完成后检查布线通道； 3）高速信号优先布线； 4）定期运行DRC检查； 5）预留测试点便于调试。
