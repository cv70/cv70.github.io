115.5 函数组合

将简单函数组合成复杂函数

🎯 学习目标

  • 理解函数组合的概念
  • 掌握compose和pipe实现
  • 学会Point-Free风格
  • 了解组合的实际应用

📚 组合概念

// 函数组合：将多个函数合并成一个新函数 // 数学定义 // (f ◦ g)(x) = f(g(x)) // 手动组合 const add1 = (x: number) => x + 1; const double = (x: number) => x * 2; const subtract10 = (x: number) => x - 10; // 不使用组合 const result = subtract10(double(add1(5))); // 5 -> 6 -> 12 -> 2 // 使用组合 const composed = (x: number) => subtract10(double(add1(x))); composed(5); // 2 // 组合的优势 const advantages = { 可读性: '清晰表达数据处理流程', 复用性: '小组合可参与更大组合', 测试性: '每个小函数独立测试', 推理能力: '从右向左或从左向右推理' };
💡
组合原则

组合是从右向左执行，管道是从左向右执行。

🔧 compose与pipe

// compose: 从右向左执行 function compose(...fns: Array<(arg: T) => T>): (arg: T) => T { return (arg: T) => fns.reduceRight((acc, fn) => fn(acc), arg); } // pipe: 从左向右执行 function pipe(...fns: Array<(arg: T) => T>): (arg: T) => T { return (arg: T) => fns.reduce((acc, fn) => fn(acc), arg); } // 使用示例 const add1 = (x: number) => x + 1; const double = (x: number) => x * 2; const subtract10 = (x: number) => x - 10; // compose: 从右向左 const composed = compose(subtract10, double, add1); composed(5); // 执行顺序: add1 -> double -> subtract10 // 5 -> 6 -> 12 -> 2 // pipe: 从左向右 const piped = pipe(add1, double, subtract10); piped(5); // 执行顺序: add1 -> double -> subtract10 // 5 -> 6 -> 12 -> 2 // 实际应用：数据处理管道 interface User { id: number; name: string; email: string; age: number; } const users: User[] = [ { id: 1, name: 'Alice', email: 'alice@example.com', age: 25 }, { id: 2, name: 'Bob', email: 'bob@example.com', age: 30 }, { id: 3, name: 'Charlie', email: 'charlie@example.com', age: 25 } ]; // 过滤成年用户 -> 排序 -> 提取名字 const getAdultNames = pipe( (users: User[]) => users.filter(u => u.age >= 18), (users: User[]) => users.sort((a, b) => a.name.localeCompare(b.name)), (users: User[]) => users.map(u => u.name) ); getAdultNames(users); // ['Alice', 'Bob', 'Charlie'] // Point-Free 风格 // 不使用Point-Free const getNames = (users: User[]) => users.map(u => u.name); // Point-Free: 不显式提及参数 const prop = (key: K) => (obj: T): T[K] => obj[key]; const map = (fn: (x: T) => R) => (arr: T[]): R[] => arr.map(fn); const getNamesPointFree = map(prop('name')); getNamesPointFree(users); // ['Alice', 'Bob', 'Charlie'] // 更复杂的Point-Free示例 const filter = (pred: (x: T) => boolean) => (arr: T[]): T[] => arr.filter(pred); const sort = (compare: (a: T, b: T) => number) => (arr: T[]): T[] => [...arr].sort(compare); const getAdultNamesPointFree = pipe( filter((u: User) => u.age >= 18), sort((a, b) => a.name.localeCompare(b.name)), map(prop('name')) ); // 组合异步函数 const pipeAsync = (...fns: Array<(arg: T) => Promise>) => { return async (arg: T): Promise => { let result = arg; for (const fn of fns) { result = await fn(result); } return result; }; }; const fetchUser = async (id: number) => { const res = await fetch(`/api/users/${id}`); return res.json(); }; const getUserDisplayName = pipeAsync( fetchUser, async (user: User) => ({ ...user, displayName: user.name.toUpperCase() }) );

📝 本节小结

✅
  • • 组合将多个函数合并为一个
  • • compose从右向左，pipe从左向右
  • • Point-Free风格更简洁
  • • 组合是函数式编程核心
