4.1 开发机环境配置

搭建高效的AI开发环境

🎯 学习目标

  • 了解AI开发机的硬件要求
  • 掌握操作系统配置要点
  • 学会安装必要的开发工具
  • 理解环境优化策略

开发机环境概述

开发机是AI工程师的日常工作平台，需要配置合适的硬件、操作系统和开发工具。一个良好的开发环境可以显著提升开发效率，减少环境问题带来的困扰。

💻 硬件配置建议

硬件规格

组件 最低配置 推荐配置 高端配置
CPU 8核16线程 16核32线程 32核64线程
内存 32GB 64GB 128GB+
存储 512GB SSD 1TB NVMe 2TB NVMe
GPU 无 RTX 4090 RTX 4090/A6000
网络 千兆 千兆 万兆
💡
配置建议

根据实际工作需求选择配置。数据预处理需要更多内存和存储，模型训练需要更强的GPU，代码开发需要更快的CPU和SSD。

🐧 操作系统配置

Linux环境

Linux是AI开发的首选系统，Ubuntu是主流发行版：

推荐系统

  • Ubuntu 22.04 LTS
  • Ubuntu 20.04 LTS
  • CentOS Stream 9
  • Rocky Linux 9

系统优化

  • 禁用swap
  • 调整文件描述符限制
  • 配置内核参数
  • 设置时区和编码
系统初始化脚本： # 更新系统 sudo apt update && sudo apt upgrade -y # 安装基础工具 sudo apt install -y \ curl wget git vim htop tmux \ build-essential python3-pip \ zsh net-tools software-properties-common # 配置时区 sudo timedatectl set-timezone Asia/Shanghai # 配置环境变量 echo 'export LANG=en_US.UTF-8' >> ~/.bashrc echo 'export LC_ALL=en_US.UTF-8' >> ~/.bashrc echo 'export EDITOR=vim' >> ~/.bashrc # 安装Oh My Zsh sh -c "$(curl -fsSL https://raw.github.com/ohmyzsh/ohmyzsh/master/tools/install.sh)" # 配置limits echo "* soft nofile 65536" | sudo tee -a /etc/security/limits.conf echo "* hard nofile 65536" | sudo tee -a /etc/security/limits.conf

工具安装命令： # VS Code wget -qO- https://packages.microsoft.com/keys/microsoft.asc | gpg --dearmor > packages.microsoft.gpg sudo install -o root -g root -m 644 packages.microsoft.gpg /etc/apt/trusted.gpg.d/ sudo sh -c 'echo "deb [arch=amd64,arm64,armhf signed-by=/etc/apt/trusted.gpg.d/packages.microsoft.gpg] https://packages.microsoft.com/repos/code stable main" > /etc/apt/sources.list.d/vscode.list' sudo apt install -y code # GitHub CLI curl -fsSL https://cli.github.com/packages/githubcli-archive-keyring.gpg | sudo dd of=/usr/share/keyrings/githubcli-archive-keyring.gpg sudo chmod go+r /usr/share/keyrings/githubcli-archive-keyring.gpg echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/githubcli-archive-keyring.gpg] https://cli.github.com/packages stable main" | sudo tee /etc/apt/sources.list.d/github-cli.list > /dev/null sudo apt install -y gh # tmux配置 echo 'set -g mouse on' >> ~/.tmux.conf echo 'set -g default-terminal "screen-256color"' >> ~/.tmux.conf

⚙️ Python环境

Python版本管理

使用pyenv管理多个Python版本，使用conda或venv管理项目依赖：

Python环境配置： # 安装pyenv curl https://pyenv.run | bash # 配置环境变量 echo 'export PYENV_ROOT="$HOME/.pyenv"' >> ~/.bashrc echo 'export PATH="$PYENV_ROOT/bin:$PATH"' >> ~/.bashrc echo 'eval "$(pyenv init -)"' >> ~/.bashrc source ~/.bashrc # 安装Python 3.10 pyenv install 3.10.13 # 设置全局Python pyenv global 3.10.13 # 安装Miniconda wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh bash Miniconda3-latest-Linux-x86_64.sh # 创建虚拟环境 conda create -n ai-env python=3.10 conda activate ai-env # 安装常用包 pip install jupyterlab ipython pip install numpy pandas matplotlib pip install scikit-learn

🔧 系统优化

性能调优

内核优化

  • 调整TCP参数
  • 优化文件系统
  • 配置NUMA
  • 启用大页内存

存储优化

  • 使用SSD
  • 配置文件系统
  • 设置挂载选项
  • 定期清理
内核参数优化： # 编辑sysctl配置 sudo vim /etc/sysctl.conf # 添加以下参数 net.core.rmem_max = 134217728 net.core.wmem_max = 134217728 net.ipv4.tcp_rmem = 4096 87380 134217728 net.ipv4.tcp_wmem = 4096 65536 134217728 net.ipv4.tcp_congestion_control = bbr vm.max_map_count = 262144 # 应用配置 sudo sysctl -p
