模型评估方法

模型评估是机器学习中至关重要的一环，准确的评估能够判断模型的泛化能力， 指导模型选择和优化。在量化交易中，正确的模型评估更是策略成功的关键。

💡 评估方法全景

📊

分类评估

准确率、精确率、召回率等

📈

回归评估

MSE、MAE、R²等

🔄

验证方法

交叉验证、时间序列验证

🔬 分类模型评估指标

1. 混淆矩阵

展示预测结果与真实标签的对应关系。

预测正类 预测负类
实际正类 真正例 (TP) 假负例 (FN)
实际负类 假正例 (FP) 真负例 (TN)

2. 准确率 (Accuracy)

预测正确的样本占总样本的比例。

Accuracy = (TP + TN) / (TP + TN + FP + FN)

3. 精确率 (Precision)

预测为正类的样本中，真正为正类的比例。

Precision = TP / (TP + FP)

4. 召回率 (Recall)

实际为正类的样本中，被正确预测为正类的比例。

Recall = TP / (TP + FN)

5. F1分数

精确率和召回率的调和平均数。

F1 = 2 * (Precision * Recall) / (Precision + Recall)

6. ROC曲线与AUC

ROC曲线展示不同阈值下的TPR和FPR关系，AUC是曲线下的面积。

  • AUC = 0.5：随机预测
  • AUC = 1.0：完美预测
  • 适用于不平衡数据集

7. PR曲线

精确率-召回率曲线，适用于类别不平衡的情况。

📊 回归模型评估指标

1. 均方误差 (MSE)

MSE = (1/n) * Σ(y_i - ŷ_i)²

对误差敏感，惩罚大误差。

2. 均方根误差 (RMSE)

RMSE = √(MSE)

与原始数据同量纲，易于解释。

3. 平均绝对误差 (MAE)

MAE = (1/n) * Σ|y_i - ŷ_i|

对异常值不敏感。

4. 决定系数 (R²)

R² = 1 - Σ(y_i - ŷ_i)² / Σ(y_i - ȳ)²

模型解释的方差比例，范围[-∞, 1]。

5. 平均绝对百分比误差 (MAPE)

MAPE = (100%/n) * Σ|(y_i - ŷ_i)/y_i|

相对误差度量，适用于不同量纲比较。

🔄 验证方法

1. 留出法 (Hold-out)

将数据划分为训练集、验证集和测试集。

  • 优点：简单快速
  • 缺点：数据利用率低，结果不稳定
  • 适用于：大数据集

2. K折交叉验证

将数据分成K份，轮流使用其中一份作为验证集。

  • 优点：充分利用数据，评估稳定
  • 缺点：计算成本高
  • 适用于：中等规模数据集

3. 时间序列交叉验证

尊重时间顺序，避免未来信息泄漏。

  • 滑动窗口：固定窗口大小向前滑动
  • 扩展窗口：每次增加新的训练数据
  • 适用于：时间序列数据

4. 分层抽样

保持各类别的比例一致。

  • 适用于：类别不平衡数据

💻 代码示例

import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split, cross_val_score, TimeSeriesSplit
from sklearn.metrics import (
    accuracy_score, precision_score, recall_score, f1_score,
    roc_auc_score, roc_curve, confusion_matrix,
    mean_squared_error, mean_absolute_error, r2_score
)
from sklearn.ensemble import RandomForestClassifier, RandomForestRegressor
import matplotlib.pyplot as plt

# 1. 分类模型评估
def evaluate_classification_model(model, X_train, y_train, X_test, y_test):
    """评估分类模型"""
    # 训练模型
    model.fit(X_train, y_train)

    # 预测
    y_pred = model.predict(X_test)
    y_pred_proba = model.predict_proba(X_test)[:, 1]

    # 计算各项指标
    metrics = {
        'accuracy': accuracy_score(y_test, y_pred),
        'precision': precision_score(y_test, y_pred),
        'recall': recall_score(y_test, y_pred),
        'f1': f1_score(y_test, y_pred),
        'auc': roc_auc_score(y_test, y_pred_proba)
    }

    # 混淆矩阵
    cm = confusion_matrix(y_test, y_pred)

    # ROC曲线
    fpr, tpr, thresholds = roc_curve(y_test, y_pred_proba)

    return model, metrics, cm, (fpr, tpr, thresholds)

# 2. 回归模型评估
def evaluate_regression_model(model, X_train, y_train, X_test, y_test):
    """评估回归模型"""
    # 训练模型
    model.fit(X_train, y_train)

    # 预测
    y_pred = model.predict(X_test)

    # 计算各项指标
    metrics = {
        'mse': mean_squared_error(y_test, y_pred),
        'rmse': np.sqrt(mean_squared_error(y_test, y_pred)),
        'mae': mean_absolute_error(y_test, y_pred),
        'r2': r2_score(y_test, y_pred),
        'mape': np.mean(np.abs((y_test - y_pred) / y_test)) * 100
    }

    return model, metrics, y_pred

# 3. K折交叉验证
def k_fold_cross_validation(model, X, y, cv=5):
    """K折交叉验证"""
    scores = cross_val_score(model, X, y, cv=cv, scoring='accuracy')
    return {
        'scores': scores,
        'mean': scores.mean(),
        'std': scores.std()
    }

# 4. 时间序列交叉验证
def time_series_cv(model, X, y, n_splits=5):
    """时间序列交叉验证"""
    tscv = TimeSeriesSplit(n_splits=n_splits)

    cv_scores = []
    for train_idx, test_idx in tscv.split(X):
        X_train, X_test = X.iloc[train_idx], X.iloc[test_idx]
        y_train, y_test = y.iloc[train_idx], y.iloc[test_idx]

        model.fit(X_train, y_train)
        score = model.score(X_test, y_test)
        cv_scores.append(score)

    return {
        'scores': cv_scores,
        'mean': np.mean(cv_scores),
        'std': np.std(cv_scores)
    }

# 5. 信息系数 (IC) - 量化专用
def calculate_ic(y_true, y_pred):
    """计算信息系数"""
    ic = y_true.corr(y_pred)
    rank_ic = y_true.rank().corr(y_pred.rank())
    return ic, rank_ic

# 6. 信号质量评估
def evaluate_signal_quality(predictions, returns):
    """评估信号质量"""
    # IC分析
    ic, rank_ic = calculate_ic(returns, predictions)

    # IC均值、标准差、IR
    ic_mean = ic.mean()
    ic_std = ic.std()
    ic_ir = ic_mean / ic_std if ic_std > 0 else 0

    # 分组回测
    n_groups = 5
    predictions_groups = pd.qcut(predictions, n_groups, labels=False)
    group_returns = returns.groupby(predictions_groups).mean()

    # 多空收益
    long_short_return = group_returns.iloc[-1] - group_returns.iloc[0]

    return {
        'ic_mean': ic_mean,
        'ic_std': ic_std,
        'ic_ir': ic_ir,
        'rank_ic': rank_ic.mean(),
        'long_short_return': long_short_return,
        'group_returns': group_returns
    }

# 7. 模型稳定性测试
def test_model_stability(model, X, y, test_size=0.2, n_tests=10):
    """测试模型稳定性"""
    results = []

    for i in range(n_tests):
        X_train, X_test, y_train, y_test = train_test_split(
            X, y, test_size=test_size, random_state=i
        )

        model_copy = model.__class__(**model.get_params())
        model_copy.fit(X_train, y_train)
        score = model_copy.score(X_test, y_test)
        results.append(score)

    return {
        'scores': results,
        'mean': np.mean(results),
        'std': np.std(results),
        'min': np.min(results),
        'max': np.max(results)
    }

# 8. 模型对比分析
def compare_models(models, X, y, cv=5):
    """对比多个模型"""
    comparison = {}

    for name, model in models.items():
        scores = cross_val_score(model, X, y, cv=cv)
        comparison[name] = {
            'mean': scores.mean(),
            'std': scores.std()
        }

    # 转换为DataFrame
    comparison_df = pd.DataFrame(comparison).T
    comparison_df.columns = ['mean_score', 'std_score']

    return comparison_df.sort_values('mean_score', ascending=False)

📚 量化交易评估要点

1. 信息比率 (IR)

衡量信号预测能力，是量化交易的核心指标。

IR = IC_mean / IC_std

2. 分组回测

将预测值分组，检验各组收益差异。

  • 单调性：预测值高的组收益应高于预测值低的组
  • 显著性：多空收益应具有统计显著性

3. 样本外测试

严格的时间序列验证，确保模型泛化能力。

  • 训练集、验证集、测试集严格按时序划分
  • 避免前视偏差

4. 交易成本考量

评估时需考虑交易成本对实际收益的影响。

⚠️
注意事项

1. 时间序列数据必须使用时序验证方法
2. 不要使用未来信息评估过去
3. 区分统计显著性和经济显著性
4. 注意样本量不足导致的过拟合

✨
最佳实践

在量化交易中，推荐使用IC和IR作为主要评估指标。同时结合分组回测验证信号质量。 始终保留一段完全未使用的样本外数据进行最终验证。
