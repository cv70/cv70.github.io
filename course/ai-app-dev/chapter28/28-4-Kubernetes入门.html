28.4 Kubernetes入门

容器编排平台的核心概念与实践

🎯 学习目标

  • 理解Kubernetes的架构和核心概念
  • 掌握Pod、Service、Deployment等基本对象
  • 学会部署AI应用到Kubernetes
  • 了解GPU调度和资源管理

什么是Kubernetes？

Kubernetes（K8s）是Google开源的容器编排平台，用于自动化部署、扩展和管理容器化应用。它提供了服务发现、负载均衡、存储编排、自动滚动更新和回滚等企业级特性。

🏗️ Kubernetes架构

控制平面 (Control Plane)

  • API Server - 集群统一入口
  • etcd - 键值存储数据库
  • Scheduler - 调度Pod到节点
  • Controller Manager - 控制器管理

工作节点 (Worker Node)

  • kubelet - 节点代理
  • kube-proxy - 网络代理
  • Container Runtime - 容器运行时
  • Pod - 最小部署单元

📦 核心概念

概念 说明 类比
Pod 最小部署单元，一个或多个容器 应用实例
Deployment 管理Pod副本和更新策略 应用管理器
Service 提供稳定的访问入口 负载均衡器
ConfigMap 配置数据存储 配置文件
Secret 敏感数据存储 密码管理器
PersistentVolume 持久化存储 硬盘
Namespace 资源隔离 文件夹

🤖 AI应用部署示例

apiVersion: apps/v1
kind: Deployment
metadata:
  name: ai-inference
  namespace: ai-system
spec:
  replicas: 3
  selector:
    matchLabels:
      app: ai-inference
  template:
    metadata:
      labels:
        app: ai-inference
    spec:
      containers:
      - name: inference
        image: myregistry/ai-inference:v1.0
        ports:
        - containerPort: 8000
        resources:
          limits:
            nvidia.com/gpu: 1
            memory: "8Gi"
            cpu: "4"
          requests:
            memory: "4Gi"
            cpu: "2"
        env:
        - name: MODEL_PATH
          value: "/models"
        volumeMounts:
        - name: model-storage
          mountPath: /models
        livenessProbe:
          httpGet:
            path: /health
            port: 8000
          initialDelaySeconds: 30
          periodSeconds: 10
      volumes:
      - name: model-storage
        persistentVolumeClaim:
          claimName: model-pvc

🖥️ Service配置

apiVersion: v1
kind: Service
metadata:
  name: ai-inference-service
  namespace: ai-system
spec:
  selector:
    app: ai-inference
  ports:
  - port: 80
    targetPort: 8000
  type: LoadBalancer
---
apiVersion: autoscaling/v2
kind: HorizontalPodAutoscaler
metadata:
  name: ai-inference-hpa
spec:
  scaleTargetRef:
    apiVersion: apps/v1
    kind: Deployment
    name: ai-inference
  minReplicas: 2
  maxReplicas: 10
  metrics:
  - type: Resource
    resource:
      name: cpu
      target:
        type: Utilization
        averageUtilization: 70

GPU调度

Kubernetes通过设备插件(Device Plugin)机制支持GPU调度。需要安装NVIDIA设备插件：kubectl apply -f https://raw.githubusercontent.com/NVIDIA/k8s-device-plugin/main/nvidia-device-plugin.yml
