52.3 I2C接口设计

常用外设接口设计

🎯 学习目标

  • 掌握I2C通信协议的基本原理
  • 理解I2C的时序和数据格式
  • 学会I2C主从设备的硬件设计
  • 了解I2C多主仲裁机制

📚 I2C概述

I2C（Inter-Integrated Circuit）是一种两线式串行总线，由Philips公司开发。它使用两根信号线（SDA和SCL）实现多主机、多从设备的通信，具有硬件简单、占用IO少的特点。

💡
I2C特点

• 两线制：只需SDA和SCL两根线
• 多主机多从机：支持多个主设备和从设备
• 地址寻址：7位或10位设备地址
• 开漏输出：需要上拉电阻

🔌 I2C信号接口

信号方向描述特性
SDA双向串行数据线开漏输出，需上拉
SCL双向串行时钟线开漏输出，需上拉

上拉电阻选择

I2C总线需要上拉电阻，典型值：

• 标准模式（100kHz）：4.7kΩ

• 快速模式（400kHz）：2.2kΩ

• 高速模式（3.4MHz）：1kΩ

⚠️
注意事项

• SDA和SCL都是开漏输出，必须接上拉电阻
• 总线电容不宜超过400pF（标准模式）
• 不同速率模式的总线电容限值不同

⏱️ I2C时序

基本时序信号

起始信号（Start Condition）：SCL为高电平时，SDA从高到低跳变。

停止信号（Stop Condition）：SCL为高电平时，SDA从低到高跳变。

数据传输：SCL为低电平时SDA可变化，SCL为高电平时SDA必须稳定。

应答信号（ACK）：接收方在第九个时钟周期拉低SDA表示应答。

📦 I2C数据格式

完整传输序列

| 起始 | 从机地址 | R/W | ACK | 数据 | ACK | ... | 停止 |

| S | 7位 | 1位 | 1位 | 8位 | 1位 | | P |

从机地址格式

| 7位地址 | R/W |

| A6-A0 | 0=写, 1=读 |

首字节：[A6:A0:R/W]

读写操作

写操作：R/W=0，主机向从机写数据

读操作：R/W=1，主机从从机读数据

复合读写：写地址后重启，再读数据

⚙️ I2C主机模块设计

// I2C主机模块
module i2c_master #(
    parameter CLK_FREQ = 50_000_000,
    parameter I2C_FREQ = 100_000  // I2C时钟频率
) (
    input  wire       clk,
    input  wire       rst_n,
    input  wire       start,          // 启动传输
    input  wire       stop,           // 停止传输
    input  wire       read_write,     // 0=写, 1=读
    input  wire [6:0] slave_addr,     // 从机地址
    input  wire [7:0] tx_data,        // 发送数据
    output wire [7:0] rx_data,        // 接收数据
    inout  wire       sda,            // I2C数据线
    inout  wire       scl,            // I2C时钟线
    output reg        busy,           // 忙标志
    output reg        ack             // 应答信号
);

    // 时钟分频
    localparam CLK_DIV = CLK_FREQ / (I2C_FREQ * 4);  // 4倍SCL频率
    reg [15:0] clk_cnt;
    wire sclk_en = (clk_cnt == 0);

    // 状态机
    localparam IDLE = 0, START = 1, ADDR = 2, DATA = 3, ACK_WAIT = 4, STOP_STATE = 5;
    reg [2:0] state;
    reg [2:0] bit_cnt;
    reg [7:0] shift_reg;
    reg sda_out;
    reg scl_out;

    // SDA方向控制
    reg sda_oe;  // 输出使能

    // 三态缓冲
    assign sda = sda_oe ? sda_out : 1'bz;
    assign scl = scl_out;

    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            state <= IDLE;
            sda_oe <= 0;
            sda_out <= 1;
            scl_out <= 1;
            busy <= 0;
            ack <= 0;
            clk_cnt <= 0;
        end else begin
            // 时钟分频
            if (sclk_en) clk_cnt <= CLK_DIV - 1;
            else clk_cnt <= clk_cnt - 1;

            ack <= 0;

            case (state)
                IDLE: begin
                    sda_oe <= 0;
                    scl_out <= 1;
                    busy <= 0;
                    if (start) begin
                        state <= START;
                        busy <= 1;
                        shift_reg <= {slave_addr, read_write};
                        bit_cnt <= 7;
                    end
                end

                START: begin
                    if (sclk_en) begin
                        scl_out <= 1;
                        sda_oe <= 1;
                        sda_out <= 0;  // SDA下降沿
                        state <= ADDR;
                    end
                end

                ADDR: begin
                    if (sclk_en) begin
                        scl_out <= 0;
                        sda_out <= shift_reg[bit_cnt];
                        if (bit_cnt == 0) begin
                            state <= ACK_WAIT;
                        end else begin
                            bit_cnt <= bit_cnt - 1;
                        end
                    end
                end

                DATA: begin
                    if (sclk_en) begin
                        scl_out <= 0;
                        if (read_write) begin
                            // 读模式，释放SDA
                            sda_oe <= 0;
                        end else begin
                            // 写模式，驱动SDA
                            sda_oe <= 1;
                            sda_out <= shift_reg[bit_cnt];
                        end
                        if (bit_cnt == 0) begin
                            state <= ACK_WAIT;
                        end else begin
                            bit_cnt <= bit_cnt - 1;
                        end
                    end
                end

                ACK_WAIT: begin
                    if (sclk_en) begin
                        scl_out <= 0;
                        sda_oe <= 0;  // 释放SDA读取ACK
                        if (sda == 0) ack <= 1;  // 收到ACK
                        // 可以根据需要继续发送或停止
                        if (stop) begin
                            state <= STOP_STATE;
                        end else begin
                            state <= DATA;
                            shift_reg <= tx_data;
                            bit_cnt <= 7;
                        end
                    end
                end

                STOP_STATE: begin
                    if (sclk_en) begin
                        sda_oe <= 1;
                        sda_out <= 0;
                        scl_out <= 1;
                        sda_out <= 1;  // SDA上升沿
                        state <= IDLE;
                        busy <= 0;
                    end
                end
            endcase
        end
    end

    // 输出接收数据（读模式）
    assign rx_data = shift_reg;

endmodule

🔌 I2C从机模块设计

// I2C从机模块
module i2c_slave #(
    parameter SLAVE_ADDR = 7'h50  // 从机地址
) (
    input  wire       clk,
    input  wire       rst_n,
    inout  wire       sda,
    inout  wire       scl,
    output reg [7:0]  rx_data,     // 接收数据
    output reg        rx_valid,    // 接收有效
    input  wire [7:0] tx_data,     // 发送数据
    output reg        tx_ack,      // 发送应答
    output reg        addr_match   // 地址匹配
);

    // 信号同步和边沿检测
    reg sda_prev, sda_sync1, sda_sync2;
    reg scl_prev, scl_sync1, scl_sync2;
    wire sda_rising = ~sda_prev & sda_sync2;
    wire sda_falling = sda_prev & ~sda_sync2;
    wire scl_rising = ~scl_prev & scl_sync2;
    wire scl_falling = scl_prev & ~scl_sync2;

    // 同步异步输入
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            sda_sync1 <= 1; sda_sync2 <= 1; sda_prev <= 1;
            scl_sync1 <= 1; scl_sync2 <= 1; scl_prev <= 1;
        end else begin
            sda_sync1 <= sda; sda_sync2 <= sda_sync1;
            scl_sync1 <= scl; scl_sync2 <= scl_sync1;
            if (scl_sync2 == scl_sync1) begin
                sda_prev <= sda_sync2;
                scl_prev <= scl_sync2;
            end
        end
    end

    // 起始和停止检测
    reg start_cond, stop_cond;
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            start_cond <= 0;
            stop_cond <= 0;
        end else begin
            start_cond <= sda_falling && scl_sync2;
            stop_cond <= sda_rising && scl_sync2;
        end
    end

    // 状态机
    localparam IDLE = 0, ADDR = 1, ACK_ADDR = 2, DATA = 3, ACK_DATA = 4;
    reg [2:0] state;
    reg [7:0] shift_reg;
    reg [2:0] bit_cnt;
    reg read_write;
    reg sda_oe;  // SDA输出使能
    reg sda_out;

    // 三态缓冲
    assign sda = sda_oe ? sda_out : 1'bz;

    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            state <= IDLE;
            sda_oe <= 0;
            rx_valid <= 0;
            tx_ack <= 0;
            addr_match <= 0;
            bit_cnt <= 0;
        end else begin
            rx_valid <= 0;
            tx_ack <= 0;

            case (state)
                IDLE: begin
                    sda_oe <= 0;
                    if (start_cond) begin
                        state <= ADDR;
                        bit_cnt <= 7;
                        shift_reg <= 0;
                    end
                end

                ADDR: begin
                    if (scl_falling) begin
                        shift_reg <= {shift_reg[6:0], sda_sync2};
                        if (bit_cnt == 0) begin
                            state <= ACK_ADDR;
                            if (shift_reg[7:1] == SLAVE_ADDR) begin
                                addr_match <= 1;
                                read_write <= shift_reg[0];
                            end else begin
                                addr_match <= 0;
                            end
                        end else begin
                            bit_cnt <= bit_cnt - 1;
                        end
                    end
                end

                ACK_ADDR: begin
                    if (scl_falling) begin
                        if (addr_match) begin
                            sda_oe <= 1;
                            sda_out <= 0;  // 发送ACK
                            tx_ack <= 1;
                            if (read_write) begin
                                shift_reg <= tx_data;
                            end
                            state <= DATA;
                            bit_cnt <= 7;
                        end else begin
                            sda_oe <= 0;
                            state <= IDLE;
                        end
                    end
                end

                DATA: begin
                    if (scl_falling) begin
                        if (read_write) begin
                            // 读操作，输出数据
                            sda_oe <= 1;
                            sda_out <= shift_reg[bit_cnt];
                        end else begin
                            // 写操作，采样数据
                            shift_reg <= {shift_reg[6:0], sda_sync2};
                        end
                        if (bit_cnt == 0) begin
                            state <= ACK_DATA;
                            if (!read_write) begin
                                rx_data <= shift_reg;
                                rx_valid <= 1;
                            end
                        end else begin
                            bit_cnt <= bit_cnt - 1;
                        end
                    end
                end

                ACK_DATA: begin
                    if (scl_falling) begin
                        if (read_write) begin
                            // 读操作，检查ACK
                            if (sda_sync2 == 0) begin
                                shift_reg <= tx_data;
                                state <= DATA;
                                bit_cnt <= 7;
                            end else begin
                                state <= IDLE;
                            end
                        end else begin
                            // 写操作，发送ACK
                            sda_oe <= 1;
                            sda_out <= 0;
                            tx_ack <= 1;
                            state <= DATA;
                            bit_cnt <= 7;
                        end
                    end
                end
            endcase

            if (stop_cond) begin
                state <= IDLE;
                sda_oe <= 0;
                addr_match <= 0;
            end
        end
    end

endmodule

⚔️ 多主仲裁机制

仲裁原理

I2C支持多主机，当多个主机同时发起传输时，通过SDA线上的电平竞争进行仲裁：

1. 所有主机同时发送起始信号

2. 每个主机在SCL为高时检测SDA

3. 如果发送0但检测到1，则失去仲裁权

4. 最后保留仲裁权的主机继续通信

💡
仲裁特点

• 仲裁不会破坏数据
• 输出0的主机优先级高于输出1的主机
• 地址和数据阶段都可能发生仲裁

📊 I2C速率模式

模式时钟频率总线电容应用场景
标准模式100kHz≤400pF低速传感器、EEPROM
快速模式400kHz≤400pF通用外设、显示驱动
快速模式+1MHz≤400pF高速外设
高速模式3.4MHz≤100pF高速数据传输

🐛 常见问题与调试

⚠️
常见问题

1. 总线卡死
症状：SDA或SCL被拉低无法释放
解决：检查上拉电阻，避免长时间占线

2. 通信失败
症状：无应答或数据错误
解决：确认从机地址正确，检查时序

3. 多设备冲突
症状：多个设备响应
解决：确保每个设备有唯一地址

4. 速率不匹配
症状：高速模式下通信不稳定
解决：降低频率或更换高速模式设备
