什么是SDC

SDC（Synopsys Design Constraints）是业界标准的时序约束格式， 用于描述设计的时序、面积、功耗等约束条件。SDC文件贯穿整个数字设计流程， 从综合到布局布线再到静态时序分析，都使用SDC来传递设计约束。

📋 SDC基本结构

SDC文件结构

# ============================================================================ # SDC约束文件示例 # ============================================================================ # 1. 时钟定义 # ============================================ create_clock -name CLK -period 10.0 \ -waveform {0.0 5.0} [get_ports clk] # 2. 时钟属性 # ============================================ set_clock_uncertainty -setup 0.3 [get_clocks CLK] set_clock_uncertainty -hold 0.1 [get_clocks CLK] set_clock_latency -max 1.5 [get_clocks CLK] set_clock_transition -max 0.3 [get_clocks CLK] # 3. IO约束 # ============================================ set_input_delay -max 2.0 -clock CLK [all_inputs] set_input_delay -min 0.5 -clock CLK [all_inputs] set_output_delay -max 2.0 -clock CLK [all_outputs] set_output_delay -min 0.5 -clock CLK [all_outputs] # 4. 驱动和负载 # ============================================ set_driving_cell -lib_cell INVX1 [get_ports clk] set_load 0.1 [all_outputs] # 5. 时序例外 # ============================================ set_false_path -from [get_ports reset] set_multicycle_path -setup 2 -from [get_cells slow_path*] # 6. 设计规则 # ============================================ set_max_fanout 16 [current_design] set_max_transition 0.5 [current_design] set_max_capacitance 0.5 [current_design] # 7. 面积约束 # ============================================ set_max_area 0

⚙️ 常用SDC命令

命令类别 命令 功能说明
时钟定义 create_clock 创建时钟对象
create_generated_clock 创建生成时钟
时钟属性 set_clock_uncertainty 设置时钟不确定性
set_clock_latency 设置时钟延迟
set_clock_transition 设置时钟转换时间
IO约束 set_input_delay 设置输入延迟
set_output_delay 设置输出延迟
驱动/负载 set_driving_cell 设置驱动单元
set_load 设置负载
时序例外 set_false_path 设置虚假路径
set_multicycle_path 设置多周期路径
设计规则 set_max_fanout 设置最大扇出
set_max_transition 设置最大转换时间

🎯 对象选择

get_*命令族

# 获取端口 get_ports clk get_ports -filter "direction == in" [all_inputs] # 获取引脚 get_pins -hierarchical "*reg*/D" get_pins -filter "is_hierarchical == false" [all_pins] # 获取单元 get_cells -hierarchical "*cpu*" get_cells -filter "ref_name =~ DFF*" [all_cells] # 获取时钟 get_clocks CLK get_clocks -filter "period >= 10" [all_clocks] # 获取网络 get_nets -hierarchical "*data*" # 获取设计 get_designs top_module

🔗 约束分组

时序组（Timing Group）

# 创建时序组 set_timing_derate -cell_delay -early 1.1 set_timing_derate -cell_delay -late 1.15 # 创建路径组 group_path -name CRITICAL -weight 10 \ -critical_range 0.5 # 设置路径组优先级 set_path_group -priority 1 CRITICAL

📝 SDC编写规范

  • 注释清晰：为每个约束添加说明注释
  • 结构化：按功能分组组织约束
  • 可维护：使用变量和参数化配置
  • 完整性：确保所有关键路径都有约束
  • 一致性：在流程中保持SDC一致性
💡
SDC最佳实践

1）使用单独的SDC文件而非嵌入在脚本中；2）将SDC纳入版本控制； 3）定期审查和更新约束；4）使用约束检查工具验证SDC质量； 5）确保约束与设计意图一致。
