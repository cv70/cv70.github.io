21.1 LangChain核心概念

LLM应用开发的框架基础

  • 理解LangChain的设计理念

💡 什么是LangChain

LangChain是一个用于开发LLM应用的框架，提供了构建上下文感知、推理能力应用的组件和集成。

核心价值

  • 统一不同LLM的接口
  • 提供可组合的组件
  • 内置常用模式实现
  • 丰富的集成生态

应用场景

  • RAG问答系统
  • 对话机器人
  • 文档分析
  • AI Agent

🧩 核心组件

Models

LLM和嵌入模型的统一接口

from langchain_openai import ChatOpenAI llm = ChatOpenAI( model="gpt-4-turbo", temperature=0.7 ) response = llm.invoke("你好")

Prompts

提示词模板管理

from langchain.prompts import ChatPromptTemplate prompt = ChatPromptTemplate.from_messages([ ("system", "你是{role}"), ("user", "{input}") ]) chain = prompt | llm

Chains

组件串联执行

from langchain.schema.output_parser import StrOutputParser chain = prompt | llm | StrOutputParser() result = chain.invoke({ "role": "AI助手", "input": "什么是机器学习?" })

Retrievers

文档检索接口

from langchain.retrievers import VectorStoreRetriever retriever = vectorstore.as_retriever( search_kwargs={"k": 3} ) docs = retriever.invoke("问题")

🔗 LCEL - LangChain表达式语言

使用管道符组合组件

from langchain_openai import ChatOpenAI from langchain.prompts import ChatPromptTemplate from langchain.schema.output_parser import StrOutputParser # 定义组件 llm = ChatOpenAI(model="gpt-4-turbo") prompt = ChatPromptTemplate.from_template("用一句话解释{topic}") output_parser = StrOutputParser() # 使用LCEL组合 chain = prompt | llm | output_parser # 执行 result = chain.invoke({"topic": "机器学习"}) print(result)
💡
LCEL优势
  • 支持流式输出
  • 支持异步调用
  • 支持批处理
  • 自动追踪和调试
