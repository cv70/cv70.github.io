31.6 路由最佳实践

掌握 Express 路由设计的最佳实践和设计模式

🎯 学习目标

  • 掌握 RESTful API 设计原则
  • 学会合理的路由组织方式
  • 理解路由安全注意事项
  • 掌握路由性能优化技巧

📐 RESTful API 设计原则

1. 使用名词而非动词

// ❌ 错误：使用动词 app.get('/getUsers', ...); app.post('/createUser', ...); app.delete('/deleteUser/:id', ...); // ✅ 正确：使用名词 app.get('/users', ...); app.post('/users', ...); app.delete('/users/:id', ...);

2. 使用复数名词

// ❌ 不推荐 app.get('/user', ...); app.get('/user/:id', ...); // ✅ 推荐：复数形式 app.get('/users', ...); app.get('/users/:id', ...);

3. 表达资源层级关系

// 获取某用户的所有文章 GET /users/:userId/posts // 获取某用户的某篇文章 GET /users/:userId/posts/:postId // 创建某用户的文章 POST /users/:userId/posts // 但避免过深的嵌套（建议不超过 2 层） // ❌ 不推荐 GET /users/:userId/posts/:postId/comments/:commentId/author

4. 使用正确的 HTTP 方法

操作 HTTP 方法 示例
获取列表 GET GET /users
获取单个 GET GET /users/:id
创建 POST POST /users
完整更新 PUT PUT /users/:id
部分更新 PATCH PATCH /users/:id
删除 DELETE DELETE /users/:id

5. 使用查询参数进行过滤、排序、分页

// 过滤 GET /products?category=electronics&brand=apple // 排序 GET /products?sort=price&order=asc // 分页 GET /products?page=1&limit=20 // 搜索 GET /products?search=iphone // 字段选择 GET /products?fields=id,name,price

📁 路由组织最佳实践

1. 分离路由定义和处理逻辑

// ❌ 不推荐：路由和处理逻辑混在一起 router.get('/users/:id', async (req, res) => { try { const user = await User.findById(req.params.id); if (!user) { return res.status(404).json({ message: 'Not found' }); } res.json(user); } catch (error) { res.status(500).json({ message: error.message }); } }); // ✅ 推荐：控制器分离 // controllers/userController.js exports.show = async (req, res, next) => { const user = await User.findById(req.params.id); if (!user) { return res.status(404).json({ message: 'Not found' }); } res.json(user); }; // routes/users.js router.get('/users/:id', userController.show);

2. 使用路由中间件进行验证

// middleware/validate.js const validate = (schema) => { return (req, res, next) => { const { error } = schema.validate(req.body); if (error) { return res.status(400).json({ success: false, errors: error.details.map(d => d.message) }); } next(); }; }; // routes/users.js const userSchema = Joi.object({ name: Joi.string().required(), email: Joi.string().email().required() }); router.post('/users', validate(userSchema), userController.create);

3. 统一错误处理

// 包装异步路由处理函数 const asyncHandler = fn => (req, res, next) => { Promise.resolve(fn(req, res, next)).catch(next); }; // 使用 router.get('/users/:id', asyncHandler(async (req, res) => { const user = await User.findById(req.params.id); res.json(user); })); // 全局错误处理 app.use((err, req, res, next) => { console.error(err); if (err.name === 'ValidationError') { return res.status(400).json({ message: err.message }); } if (err.name === 'NotFoundError') { return res.status(404).json({ message: err.message }); } res.status(500).json({ message: 'Internal Server Error' }); });

4. 版本控制

// 方式一：URL 路径版本 app.use('/api/v1', v1Routes); app.use('/api/v2', v2Routes); // 方式二：请求头版本 app.use('/api', (req, res, next) => { const version = req.headers['accept-version'] || 'v1'; req.apiVersion = version; next(); }); // 方式三：查询参数版本 // GET /api/users?version=2

🛡️ 路由安全最佳实践

1. 输入验证

// 验证路由参数 router.get('/users/:id(\\d+)', getUser); // 只匹配数字 // 验证请求体 const createUserSchema = Joi.object({ name: Joi.string().trim().max(100).required(), email: Joi.string().email().required(), role: Joi.string().valid('user', 'admin').default('user') }); router.post('/users', validate(createUserSchema), createUser);

2. 防止 SQL/NoSQL 注入

// ❌ 危险：直接使用用户输入 const query = `SELECT * FROM users WHERE id = ${req.params.id}`; // ✅ 安全：使用参数化查询 const user = await db.query('SELECT * FROM users WHERE id = ?', [req.params.id]); // ✅ 安全：使用 ORM const user = await User.findById(req.params.id);

3. 权限控制

// RBAC 中间件 const checkPermission = (resource, action) => { return async (req, res, next) => { const user = req.user; const hasPermission = await PermissionService.check(user.role, resource, action); if (!hasPermission) { return res.status(403).json({ message: 'Forbidden' }); } next(); }; }; // 使用 router.delete('/users/:id', authMiddleware, checkPermission('users', 'delete'), userController.destroy );

4. 速率限制

const rateLimit = require('express-rate-limit'); // API 速率限制 const apiLimiter = rateLimit({ windowMs: 15 * 60 * 1000, // 15 分钟 max: 100, // 最多 100 次请求 message: 'Too many requests' }); // 登录速率限制（更严格） const loginLimiter = rateLimit({ windowMs: 60 * 60 * 1000, // 1 小时 max: 5, // 最多 5 次尝试 message: 'Too many login attempts' }); app.use('/api', apiLimiter); app.use('/auth/login', loginLimiter);

⚡ 路由性能优化

1. 路由顺序优化

// 高频路由放前面 router.get('/users/popular', getPopularUsers); // 高频 router.get('/users/recent', getRecentUsers); // 高频 router.get('/users/:id', getUserById); // 参数化路由放后面 // 静态路由放前面 router.get('/about', aboutPage); router.get('/contact', contactPage); router.get('/:page', dynamicPage); // 参数化路由放最后

2. 缓存策略

// 对不常变化的数据设置缓存 const cacheMiddleware = (duration) => { return (req, res, next) => { res.set('Cache-Control', `public, max-age=${duration}`); next(); }; }; // 使用 router.get('/categories', cacheMiddleware(3600), // 缓存 1 小时 categoryController.list ); router.get('/static-data', cacheMiddleware(86400), // 缓存 1 天 staticDataController.get );

3. 延迟加载

// 懒加载大型路由模块 let adminRoutes = null; app.use('/admin', (req, res, next) => { if (!adminRoutes) { adminRoutes = require('./routes/admin'); } adminRoutes(req, res, next); });

📋 路由清单

设计 API 路由时的检查清单：

URL 设计

  • 使用名词而非动词
  • 使用复数形式
  • 层级不超过 2 层
  • 使用小写和连字符
  • 版本号放在 URL 或 Header

HTTP 方法

  • GET 获取资源（幂等）
  • POST 创建资源
  • PUT 完整更新（幂等）
  • PATCH 部分更新
  • DELETE 删除（幂等）

状态码

  • 200 成功
  • 201 创建成功
  • 400 请求错误
  • 401 未认证
  • 403 无权限
  • 404 未找到
  • 500 服务器错误

安全考虑

  • 输入验证
  • 权限控制
  • 速率限制
  • HTTPS
  • 错误信息脱敏

✅ 小结

📌
本节要点
  • 遵循 RESTful 设计原则：使用名词、复数、正确的 HTTP 方法
  • 分离路由定义和处理逻辑，使用控制器模式
  • 统一错误处理，使用异步包装器
  • 实施安全措施：输入验证、权限控制、速率限制
  • 优化性能：合理的路由顺序、缓存、延迟加载
