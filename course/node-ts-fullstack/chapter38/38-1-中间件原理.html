38.1 中间件原理

理解 Koa 中间件的核心机制

🎯 学习目标

  • 理解中间件的概念和作用
  • 掌握中间件的执行流程
  • 学会编写基本中间件
  • 理解 next() 函数的作用

📚 什么是中间件

中间件是处理请求和响应的函数，介于请求和响应之间。每个中间件可以访问请求对象（ctx）、响应对象（ctx）和下一个中间件（next）。

💡
核心概念

中间件是一个 async 函数，接收 ctx 和 next 两个参数，通过 await next() 将控制权传递给下一个中间件。

// 基本中间件结构 async function middleware(ctx, next) { // 前置处理 - 请求进入时执行 console.log('Request:', ctx.path); // 调用下一个中间件 await next(); // 后置处理 - 响应返回时执行 console.log('Response:', ctx.status); }

⚡ 中间件执行流程

app.use(async (ctx, next) => { console.log('1. 第一个中间件 - 开始'); await next(); console.log('4. 第一个中间件 - 结束'); }); app.use(async (ctx, next) => { console.log('2. 第二个中间件 - 开始'); await next(); console.log('3. 第二个中间件 - 结束'); }); app.use(async ctx => { console.log('核心处理'); ctx.body = 'Hello'; }); // 执行顺序: 1 -> 2 -> 核心 -> 3 -> 4
✅
执行顺序

中间件按照 app.use() 注册顺序执行，形成"先进后出"的栈结构。

🔄 next() 函数

next() 函数是连接各个中间件的桥梁，它返回一个 Promise。

app.use(async (ctx, next) => { const start = Date.now(); // 等待下游中间件执行完成 await next(); const ms = Date.now() - start; console.log(`${ctx.method} ${ctx.url} - ${ms}ms`); });

调用 next()

  • 继续执行下一个中间件
  • 等待下游处理完成
  • 然后执行后续代码

不调用 next()

  • 终止中间件链
  • 直接返回响应
  • 用于认证拦截等场景

💻 手写中间件核心实现

// 简化版 Koa 中间件实现 class SimpleKoa { constructor() { this.middlewares = []; } use(middleware) { this.middlewares.push(middleware); } // 组合所有中间件 compose(middlewares) { return function (ctx) { let index = -1; function dispatch(i) { if (i <= index) { return Promise.reject(new Error('next() called multiple times')); } index = i; const middleware = middlewares[i]; if (!middleware) return Promise.resolve(); try { return Promise.resolve(middleware(ctx, () => dispatch(i + 1))); } catch (err) { return Promise.reject(err); } } return dispatch(0); }; } listen(port, callback) { const http = require('http'); const server = http.createServer((req, res) => { const ctx = { req, res, body: null }; const fn = this.compose(this.middlewares); fn(ctx).then(() => { res.end(ctx.body || 'Not Found'); }); }); server.listen(port, callback); } }

💡 实战示例

// 日志中间件 app.use(async (ctx, next) => { const start = Date.now(); console.log(`--> ${ctx.method} ${ctx.url}`); await next(); const ms = Date.now() - start; console.log(`<-- ${ctx.method} ${ctx.url} ${ctx.status} ${ms}ms`); }); // 认证中间件 app.use(async (ctx, next) => { const token = ctx.headers.authorization; if (!token) { ctx.status = 401; ctx.body = { error: 'No token provided' }; return; // 不调用 next()，终止请求 } ctx.state.user = verifyToken(token); await next(); }); // 业务处理 app.use(async ctx => { ctx.body = { message: 'Success', user: ctx.state.user }; });
