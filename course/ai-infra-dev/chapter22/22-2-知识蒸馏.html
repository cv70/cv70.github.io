什么是知识蒸馏

知识蒸馏（Knowledge Distillation）是一种模型压缩技术，通过让小模型（学生模型）学习大模型（教师模型）的输出， 从而在不损失太多精度的情况下大幅减少模型大小。

👨‍🏫 核心概念

教师模型（Teacher）

  • 特点：大而复杂，精度高
  • 作用：提供软标签和暗知识
  • 来源：预训练或训练好的大模型
  • 状态：参数固定，不更新

学生模型（Student）

  • 特点：小而简洁，速度快
  • 作用：学习教师的知识
  • 设计：根据部署需求定制
  • 状态：参数可更新，训练中

💡 软标签 vs 硬标签

硬标签（Hard Labels）

  • 定义：one-hot编码
  • 示例：[0, 0, 1, 0]
  • 信息：仅包含正确答案
  • 使用：传统训练

软标签（Soft Labels）

  • 定义：概率分布
  • 示例：[0.1, 0.2, 0.6, 0.1]
  • 信息：包含所有类别概率
  • 使用：知识蒸馏

🌡️ 温度系数（Temperature）

温度系数T用于控制软标签的平滑程度，是知识蒸馏的关键超参数。

温度系数的影响

T = 1 (原始)
保持原始分布，接近硬标签
T > 1 (平滑)
使分布更平滑，暴露暗知识
T >> 1 (超平滑)
分布几乎均匀，信息量减少

📊 蒸馏损失函数

# 知识蒸馏损失函数
import torch
import torch.nn.functional as F

def distillation_loss(student_output, teacher_output, labels,
                      T=5.0, alpha=0.7):
    """
    计算蒸馏损失

    Args:
        student_output: 学生模型的输出
        teacher_output: 教师模型的输出
        labels: 真实标签
        T: 温度系数
        alpha: 蒸馏损失权重
    """
    # 软标签损失（蒸馏损失）
    # 使用温度系数平滑概率分布
    soft_teacher = F.softmax(teacher_output / T, dim=-1)
    soft_student = F.log_softmax(student_output / T, dim=-1)
    soft_loss = F.kl_div(soft_student, soft_teacher,
                         reduction='batchmean') * (T ** 2)

    # 硬标签损失（交叉熵）
    hard_loss = F.cross_entropy(student_output, labels)

    # 组合损失
    total_loss = alpha * soft_loss + (1 - alpha) * hard_loss

    return total_loss

# 训练循环示例
def train_student(student, teacher, train_loader, optimizer,
                 T=5.0, alpha=0.7, epochs=10):
    teacher.eval()  # 教师模型不更新参数

    for epoch in range(epochs):
        for batch in train_loader:
            inputs, labels = batch

            # 前向传播
            student_output = student(inputs)
            with torch.no_grad():
                teacher_output = teacher(inputs)

            # 计算蒸馏损失
            loss = distillation_loss(
                student_output, teacher_output, labels,
                T=T, alpha=alpha
            )

            # 反向传播和优化
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()

    return student

🎭 蒸馏策略

策略 描述 适用场景 优势
Response-based 基于输出层蒸馏 分类任务 简单直接
Feature-based 基于中间特征蒸馏 特征学习任务 保留更多信息
Relation-based 基于样本关系蒸馏 相似度计算 保持数据关系
Self-Distillation 自蒸馏 模型优化 无需外部教师

⚠️
蒸馏注意事项
  • 教师模型应比学生模型有显著的性能优势
  • 温度系数需要根据任务调整，通常在2-10之间
  • 学生模型架构需要合理设计，不能太小
  • 蒸馏过程可能需要多轮迭代

📝 本节小结

✅

  • • 软标签包含更多信息，温度系数控制平滑程度
  • • 蒸馏损失结合了软标签和硬标签
  • • LLM蒸馏需要特殊的技术和策略
