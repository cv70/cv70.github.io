28.3 Docker Compose

多容器应用的高效编排工具

什么是Docker Compose？

Docker Compose是一个用于定义和运行多容器Docker应用的工具。通过一个YAML文件配置应用的服务、网络和数据卷，然后使用单个命令创建和启动所有服务。

🔄 Docker vs Docker Compose

特性 Docker Docker Compose
管理对象 单个容器 多容器应用
配置方式 命令行参数 YAML配置文件
服务编排 手动管理依赖 自动处理服务依赖
网络配置 需手动创建网络 自动创建网络
适用场景 简单应用 微服务架构

🤖 AI服务编排示例

version: '3.8'

services:
  # AI推理服务
  ai-inference:
    build:
      context: ./inference
      dockerfile: Dockerfile
    container_name: ai-inference
    ports:
      - "8000:8000"
    environment:
      - MODEL_PATH=/models
      - CUDA_VISIBLE_DEVICES=0
    volumes:
      - ./models:/models
      - ./config:/app/config
    depends_on:
      - redis
      - postgres
    networks:
      - ai-network
    deploy:
      resources:
        reservations:
          devices:
            - driver: nvidia
              count: 1
              capabilities: [gpu]

  # Web前端服务
  web-app:
    build:
      context: ./web
      dockerfile: Dockerfile
    container_name: web-app
    ports:
      - "3000:3000"
    environment:
      - API_URL=http://ai-inference:8000
    depends_on:
      - ai-inference
    networks:
      - ai-network

  # Redis缓存
  redis:
    image: redis:7-alpine
    container_name: redis
    ports:
      - "6379:6379"
    volumes:
      - redis-data:/data
    networks:
      - ai-network

  # PostgreSQL数据库
  postgres:
    image: postgres:15
    container_name: postgres
    environment:
      POSTGRES_DB: aidb
      POSTGRES_USER: aiuser
      POSTGRES_PASSWORD: aipassword
    volumes:
      - postgres-data:/var/lib/postgresql/data
    networks:
      - ai-network

networks:
  ai-network:
    driver: bridge

volumes:
  redis-data:
  postgres-data:

🏗️ 核心配置项

🔧

build

指定构建配置，包括上下文路径和Dockerfile位置

🔌

ports

端口映射，格式为"主机端口:容器端口"

📁

volumes

数据卷挂载，实现数据持久化和共享

💻 常用命令

# 启动所有服务
docker-compose up -d

# 查看服务状态
docker-compose ps

# 查看服务日志
docker-compose logs -f

# 停止所有服务
docker-compose down

# 停止并删除数据卷
docker-compose down -v

# 重新构建服务
docker-compose build

# 扩展服务实例
docker-compose up -d --scale ai-inference=3

# 进入服务容器
docker-compose exec ai-inference bash
💡
生产环境建议

在生产环境中，建议使用docker-compose.prod.yml单独配置，通过docker-compose -f docker-compose.yml -f docker-compose.prod.yml up覆盖开发配置。
