📚 什么是 React

// React 是什么？ // - 由 Facebook（Meta）开发的开源 JavaScript 库 // - 用于构建用户界面，尤其是单页应用 // - 采用声明式编程范式 // - 基于组件化的开发模式 // React 的核心理念 // 1. 声明式：描述 UI 应该是什么样子，而非如何实现 // 2. 组件化：将 UI 拆分为独立、可复用的组件 // 3. 单向数据流：数据从父组件流向子组件 // 4. 虚拟 DOM：高效更新界面 // React 发展历程 const timeline = { '2013': 'React 开源发布', '2015': 'React Native 发布', '2016': 'React 15.0，引入 Fiber 架构计划', '2018': 'React 16.8，引入 Hooks', '2020': 'React 17.0，优化事件系统', '2022': 'React 18.0，并发特性、Suspense', };

🔧 创建 React 应用

// 方式一：使用 Vite（推荐） npm create vite@latest my-app -- --template react-ts cd my-app npm install npm run dev // 方式二：使用 Create React App npx create-react-app my-app --template typescript cd my-app npm start // 项目结构 my-app/ ├── node_modules/ ├── public/ │ └── vite.svg ├── src/ │ ├── App.tsx # 根组件 │ ├── App.css │ ├── main.tsx # 入口文件 │ └── index.css ├── index.html ├── package.json ├── tsconfig.json └── vite.config.ts // 入口文件 src/main.tsx import React from 'react'; import ReactDOM from 'react-dom/client'; import App from './App'; import './index.css'; ReactDOM.createRoot(document.getElementById('root')!).render( <React.StrictMode> <App /> </React.StrictMode> );

📊 React 核心特点

💡
React 的核心优势

1. 声明式开发：代码更直观，易于调试
2. 组件化：高内聚、低耦合、可复用
3. 一次学习，随处编写：Web、移动端、桌面端
4. 强大的生态系统：路由、状态管理、UI 库
