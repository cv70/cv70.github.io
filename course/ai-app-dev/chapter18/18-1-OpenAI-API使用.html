18.1 OpenAI API使用

接入GPT的完整指南

🎯 学习目标

  • 掌握OpenAI API的基本使用
  • 学会构建对话应用
  • 理解Token和计费机制
  • 了解错误处理和最佳实践

🔧 环境准备

# 安装OpenAI SDK pip install openai # 设置API Key # 方式1: 环境变量 export OPENAI_API_KEY='your-api-key' # 方式2: 代码中设置 from openai import OpenAI client = OpenAI(api_key='your-api-key')

💬 基础对话

from openai import OpenAI client = OpenAI() # 基础聊天补全 response = client.chat.completions.create( model="gpt-4-turbo-preview", messages=[ {"role": "system", "content": "你是一个有帮助的助手。"}, {"role": "user", "content": "什么是机器学习？"} ] ) print(response.choices[0].message.content)

📊 模型选择

模型 上下文 特点 适用场景
gpt-4-turbo 128K 性价比最高 大多数应用
gpt-4 8K 最强推理 复杂任务
gpt-3.5-turbo 16K 速度快、便宜 简单任务

🌊 流式输出

# 流式响应 stream = client.chat.completions.create( model="gpt-4-turbo-preview", messages=[{"role": "user", "content": "写一首诗"}], stream=True ) for chunk in stream: if chunk.choices[0].delta.content: print(chunk.choices[0].delta.content, end="")

💰 Token计算

import tiktoken # 初始化编码器 enc = tiktoken.encoding_for_model("gpt-4") # 计算Token数 text = "Hello, how are you?" tokens = enc.encode(text) print(f"Token数: {len(tokens)}") # 估算费用 # GPT-4-Turbo: 输入$0.01/1K tokens, 输出$0.03/1K tokens
⚠️

中文Token消耗比英文多，一个汉字通常需要多个Token。使用tiktoken库预估成本。

📝 本节小结
