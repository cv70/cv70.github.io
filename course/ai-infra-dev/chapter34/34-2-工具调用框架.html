工具调用概述

工具调用（Function Calling）是Agent与外部世界交互的核心机制。通过定义和调用工具，Agent能够执行具体操作、访问外部数据、完成复杂任务。完善的工具调用框架是构建实用Agent的基础。

⚙️ LangChain工具开发

自定义工具实现

from langchain.tools import Tool
from typing import Optional
import requests

# 定义工具函数
def search_web(
    query: str,
    num_results: int = 5,
    engine: str = "google"
) -> str:
    """
    搜索网络信息

    Args:
        query: 搜索关键词
        num_results: 返回结果数
        engine: 搜索引擎

    Returns:
        搜索结果JSON字符串
    """
    try:
        # 调用搜索API
        response = requests.get(
            f"https://api.search.com/search",
            params={
                "q": query,
                "n": num_results,
                "engine": engine
            }
        )
        results = response.json()
        return str(results)

    except Exception as e:
        return f"搜索失败: {str(e)}"

# 创建工具
web_search_tool = Tool(
    name="web_search",
    func=search_web,
    description="""
    搜索网络信息，适用于获取最新资讯和外部信息。
    输入：搜索关键词
    输出：搜索结果列表
    """,
    args_schema={
        "query": "搜索关键词",
        "num_results": "返回结果数（默认5）",
        "engine": "搜索引擎（默认google）"
    },
    return_direct=False,
    verbose=True
)

# 工具注册
tools = [web_search_tool]

🔐 工具安全控制

权限与安全机制

工具安全框架：

1. 权限管理
   ├── 角色定义：Admin/User/Guest
   ├── 工具权限：可调用/禁止
   ├── 参数限制：范围/格式校验
   └── 资源配额：调用次数限制

2. 访问控制
   ├── API密钥验证
   ├── IP白名单
   ├── 时间窗口限制
   └── 率限控制

3. 安全校验
   ├── 参数验证
   ├── 恶意检测
   ├── 注入防护
   └── XSS防护

4. 审计日志
   ├── 调用记录
   ├── 参数记录
   ├── 结果记录
   └── 异常记录

实现示例：
class SecureToolWrapper:
    def __init__(self, tool, config):
        self.tool = tool
        self.config = config

    async def __call__(self, **kwargs):
        # 权限检查
        if not self._check_permission(kwargs):
            raise PermissionError("无权限")

        # 参数验证
        validated = self._validate_params(kwargs)

        # 调用工具
        result = await self.tool(**validated)

        # 记录日志
        self._log_call(kwargs, result)

        return result

    def _check_permission(self, params):
        # 实现权限检查
        return True

🔄 工具链

工具组合与链式调用

工具链设计：

1. 串行链
   Tool A → Tool B → Tool C
   前一个工具的输出作为后一个的输入

2. 并行链
   Tool A
   Tool B → 合并结果 → Tool C
   Tool D
   多个工具并行执行

3. 条件链
   IF condition THEN Tool A ELSE Tool B
   根据条件选择执行路径

4. 循环链
   WHILE condition DO Tool A
   重复执行直到条件满足

LangChain链示例：
from langchain.chains import SequentialChain, ParallelChain

# 串行链
chain = SequentialChain(
    chains=[tool1_chain, tool2_chain],
    input_variables=["input"],
    output_variables=["final_output"]
)

# 并行链
parallel = ParallelChain(
    chains=[tool1_chain, tool2_chain],
    input_variables=["input"],
    output_variables=["output1", "output2"]
)

# 条件链
from langchain.schema import BaseOutputParser

class ConditionalParser(BaseOutputParser):
    def parse(self, text):
        # 解析条件，选择执行路径
        if "error" in text:
            return "error_path"
        else:
            return "success_path"
⚠️
工具调用注意事项

工具调用要考虑幂等性（重复调用安全）、超时控制（避免长时间等待）、降级策略（工具失败时的备选方案）。

🔧 OpenAI Function Calling

OpenAI原生支持

import openai
from openai import OpenAI

client = OpenAI()

# 定义工具
tools = [
    {
        "type": "function",
        "function": {
            "name": "web_search",
            "description": "搜索网络信息",
            "parameters": {
                "type": "object",
                "properties": {
                    "query": {
                        "type": "string",
                        "description": "搜索关键词"
                    }
                },
                "required": ["query"]
            }
        }
    }
]

# 调用Chat Completions
response = client.chat.completions.create(
    model="gpt-4",
    messages=[
        {"role": "user", "content": "搜索AI Agent"}
    ],
    tools=tools,
    tool_choice="auto"
)

# 处理工具调用
tool_calls = response.choices[0].message.tool_calls

if tool_calls:
    for tool_call in tool_calls:
        function_name = tool_call.function.name
        function_args = json.loads(tool_call.function.arguments)

        # 执行工具
        result = web_search(**function_args)

        # 将结果返回给模型
        completion = client.chat.completions.create(
            model="gpt-4",
            messages=[
                {"role": "user", "content": "搜索AI Agent"},
                response.choices[0].message,
                {
                    "role": "tool",
                    "tool_call_id": tool_call.id,
                    "content": str(result)
                }
            ]
        )

OpenAI提供原生Function Calling支持，自动识别需要调用工具并生成工具调用，简化了Agent的开发。
