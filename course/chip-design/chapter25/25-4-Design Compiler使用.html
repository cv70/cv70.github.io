Design Compiler简介

Design Compiler（DC）是Synopsys公司开发的业界标准逻辑综合工具。 它提供了强大的综合优化能力，支持从RTL到门级网表的完整转换流程， 是数字芯片设计流程中最常用的综合工具之一。

🚀 DC启动方式

命令行模式（dc_shell）

# 启动DC Shell dc_shell -topographical_mode # 或使用图形界面 dc_shell -gui # 执行脚本文件 dc_shell -f compile.tcl

图形界面模式（Design Vision）

# 启动Design Vision design_vision # 加载脚本 design_vision -f compile.tcl

📜 完整综合脚本示例

#!/bin/tcl # =========================================== # Design Compiler 综合脚本 # =========================================== # 1. 环境设置 # =========================================== # 设置库名称 set LIB_NAME "saed90nm" # 设置库路径 set LIB_PATH "/foundry/libraries/${LIB_NAME}" # 设置目标库 set target_library [list ${LIB_PATH}/stdcell_rvt/db_${LIB_NAME}/saed90nm_typ.db] # 设置链接库 set link_library "* $target_library" # 设置符号库 set symbol_library ${LIB_PATH}/stdcell_rvt/db_${LIB_NAME}/saed90nm.sdb # 设置搜索路径 set search_path [list \ ./rtl \ ./scripts \ ./netlist \ ${LIB_PATH}/stdcell_rvt/db_${LIB_NAME} \ ] # 2. 读入设计 # =========================================== # 读入RTL文件 read_verilog { \ rtl/top.v \ rtl/sub_module1.v \ rtl/sub_module2.v \ } # 设置当前设计 current_design top_module # 链接设计 link # 检查设计 check_design > reports/check_design.rpt # 3. 设置约束 # =========================================== # 创建时钟 create_clock -name CLK -period 10 [get_ports clk] # 设置时钟不确定性 set_clock_uncertainty 0.5 [get_clocks CLK] # 设置时钟转换时间 set_clock_transition 0.2 [get_clocks CLK] # 设置输入延迟 set_input_delay 2.0 -clock CLK [remove_from_collection [all_inputs] [get_ports clk]] # 设置输出延迟 set_output_delay 2.0 -clock CLK [all_outputs] # 设置驱动强度 set_driving_cell -lib_cell INVX1 [get_ports clk] # 设置负载 set_load 0.1 [all_outputs] # 设置面积约束 set_max_area 0 # 4. 编译优化 # =========================================== # 设置编译策略 set_compile_ultra_ungroup [get_designs *] # 执行编译 compile_ultra # 或使用常规编译 # compile # 5. 报告生成 # =========================================== # 创建报告目录 file mkdir reports # 生成时序报告 report_timing -max_paths 20 -delay_type max \ > reports/timing_setup.rpt report_timing -max_paths 20 -delay_type min \ > reports/timing_hold.rpt # 生成面积报告 report_area -hierarchy > reports/area.rpt # 生成功耗报告 report_power -hierarchy > reports/power.rpt # 生成单元报告 report_cell > reports/cell.rpt # 生成约束报告 report_constraint -all_violators > reports/violations.rpt # 6. 输出结果 # =========================================== # 创建输出目录 file mkdir outputs # 输出网表 write -format verilog -hierarchy \ -outputs outputs/top_synth.v # 输出SDC约束 write_sdc -nosplit outputs/top_synth.sdc # 输出SDF文件 write_sdf -version 2.1 outputs/top_synth.sdf # 输出DDC文件（DC内部格式） write -format ddc -hierarchy \ -output outputs/top_synth.ddc # 7. 清理退出 # =========================================== # 保存会话 save_session output/session # 退出DC exit

⚡ DC常用命令

命令类别 常用命令 功能说明
设计管理 read_verilog, read_vhdl 读入RTL文件
current_design 设置当前设计
link 链接设计
约束设置 create_clock 创建时钟
set_input_delay 设置输入延迟
set_output_delay 设置输出延迟
综合编译 compile 常规编译
compile_ultra 高级编译
报告生成 report_timing 时序报告
report_area 面积报告
文件输出 write 输出网表
write_sdc 输出约束
💡
使用技巧

建议使用脚本化的方式进行综合，而不是在GUI中手动操作。 脚本可以重复执行、版本控制，并且更容易进行回归测试和流程自动化。
