55.1 RBAC 模型

基于角色的访问控制

🎯 学习目标

  • 理解 RBAC 的核心概念

  • 学会设计权限数据模型
  • 理解 RBAC 的优缺点

📚 RBAC 概述

/* RBAC (Role-Based Access Control) 基于角色的访问控制 核心概念： 1. 用户 (User)：系统的使用者 2. 角色 (Role)：权限的集合，如管理员、编辑、用户 3. 权限 (Permission)：对资源的操作能力 4. 资源 (Resource)：被保护的对象，如文章、用户 关系： 用户 -> 角色 -> 权限 -> 资源 RBAC 模型层级： RBAC0：基本模型（用户-角色-权限） RBAC1：角色继承（角色可以有父子关系） RBAC2：角色约束（互斥、基数约束） RBAC3：RBAC1 + RBAC2 */ // RBAC 模型示意 /* ┌─────────────────────────────────────────────────────────────┐ │ RBAC 模型 │ ├─────────────────────────────────────────────────────────────┤ │ │ │ ┌──────┐ ┌──────┐ ┌──────────┐ │ │ │ User │ ──────> │ Role │ ──────> │Permission│ │ │ └──────┘ └──────┘ └──────────┘ │ │ │ │ │ │ │ │ │ ↓ │ │ │ │ ┌───────────┐ │ │ │ │ │ Resource │ │ │ │ │ │ + Action │ │ │ │ │ └───────────┘ │ │ │ │ │ │ ↓ ↓ │ │ 张三 ──────> admin ──────> [user:create, │ │ user:delete, │ │ article:*] │ │ │ │ 李四 ──────> editor ─────> [article:create, │ │ article:edit, │ │ article:publish] │ │ │ │ 王五 ──────> user ──────> [article:read, │ │ comment:create] │ │ │ └─────────────────────────────────────────────────────────────┘ */
💡
RBAC 优势

RBAC将权限授予角色而非直接授予用户，简化权限管理。用户只需分配角色即可获得相应权限，便于维护和扩展。

🔧 数据模型设计

// src/models/user.model.ts import mongoose, { Document, Schema } from 'mongoose'; interface IUser extends Document { username: string; email: string; password: string; roles: mongoose.Types.ObjectId[]; // 用户拥有的角色 isActive: boolean; } const UserSchema = new Schema({ username: { type: String, required: true, unique: true }, email: { type: String, required: true, unique: true }, password: { type: String, required: true, select: false }, roles: [{ type: Schema.Types.ObjectId, ref: 'Role' }], isActive: { type: Boolean, default: true }, }, { timestamps: true }); export const User = mongoose.model('User', UserSchema); // src/models/role.model.ts interface IRole extends Document { name: string; // 角色名称：admin, editor, user description: string; // 角色描述 permissions: mongoose.Types.ObjectId[]; // 角色拥有的权限 inherits?: mongoose.Types.ObjectId[]; // 继承的角色 isSystem: boolean; // 是否系统角色（不可删除） } const RoleSchema = new Schema({ name: { type: String, required: true, unique: true }, description: { type: String }, permissions: [{ type: Schema.Types.ObjectId, ref: 'Permission' }], inherits: [{ type: Schema.Types.ObjectId, ref: 'Role' }], isSystem: { type: Boolean, default: false }, }); export const Role = mongoose.model('Role', RoleSchema); // src/models/permission.model.ts interface IPermission extends Document { name: string; // 权限名称：user:create, article:edit resource: string; // 资源：user, article, comment action: string; // 操作：create, read, update, delete description: string; } const PermissionSchema = new Schema({ name: { type: String, required: true, unique: true }, resource: { type: String, required: true }, action: { type: String, required: true }, description: { type: String }, }); // 复合索引 PermissionSchema.index({ resource: 1, action: 1 }, { unique: true }); export const Permission = mongoose.model('Permission', PermissionSchema);

📊 初始化权限数据

// src/scripts/init-rbac.ts import { Permission, Role, User } from '../models'; // 定义权限 const permissions = [ // 用户管理 { name: 'user:create', resource: 'user', action: 'create', description: '创建用户' }, { name: 'user:read', resource: 'user', action: 'read', description: '查看用户' }, { name: 'user:update', resource: 'user', action: 'update', description: '更新用户' }, { name: 'user:delete', resource: 'user', action: 'delete', description: '删除用户' }, // 文章管理 { name: 'article:create', resource: 'article', action: 'create', description: '创建文章' }, { name: 'article:read', resource: 'article', action: 'read', description: '查看文章' }, { name: 'article:update', resource: 'article', action: 'update', description: '更新文章' }, { name: 'article:delete', resource: 'article', action: 'delete', description: '删除文章' }, { name: 'article:publish', resource: 'article', action: 'publish', description: '发布文章' }, // 评论管理 { name: 'comment:create', resource: 'comment', action: 'create', description: '创建评论' }, { name: 'comment:delete', resource: 'comment', action: 'delete', description: '删除评论' }, ]; // 定义角色及其权限 const roles = [ { name: 'admin', description: '系统管理员', permissions: ['user:*', 'article:*', 'comment:*'], // 所有权限 isSystem: true, }, { name: 'editor', description: '编辑', permissions: ['article:create', 'article:read', 'article:update', 'article:publish'], isSystem: true, }, { name: 'author', description: '作者', permissions: ['article:create', 'article:read', 'article:update', 'comment:create'], isSystem: true, }, { name: 'user', description: '普通用户', permissions: ['article:read', 'comment:create'], isSystem: true, }, ]; async function initRBAC() { // 创建权限 for (const perm of permissions) { await Permission.findOneAndUpdate( { name: perm.name }, perm, { upsert: true, new: true } ); } // 创建角色 for (const role of roles) { const permissionDocs = await Permission.find({ name: { $in: role.permissions }, }); await Role.findOneAndUpdate( { name: role.name }, { name: role.name, description: role.description, permissions: permissionDocs.map(p => p._id), isSystem: role.isSystem, }, { upsert: true, new: true } ); } console.log('RBAC 初始化完成'); } initRBAC();

🔄 权限检查流程

// src/services/rbac.service.ts import { User, Role, Permission } from '../models'; import { Types } from 'mongoose'; export class RBACService { /** * 检查用户是否有指定权限 */ static async hasPermission( userId: Types.ObjectId, permissionName: string ): Promise { // 获取用户及其角色 const user = await User.findById(userId) .populate({ path: 'roles', populate: { path: 'permissions' }, }); if (!user || !user.isActive) { return false; } // 收集所有权限 const permissions = new Set(); for (const role of user.roles as any[]) { // 检查角色权限 for (const perm of role.permissions as any[]) { permissions.add(perm.name); // 支持通配符匹配 const [resource] = perm.name.split(':'); permissions.add(`${resource}:*`); } } // 检查权限 const [resource, action] = permissionName.split(':'); return ( permissions.has(permissionName) || permissions.has(`${resource}:*`) || permissions.has('*:*') ); } /** * 获取用户所有权限 */ static async getUserPermissions(userId: Types.ObjectId): Promise { const user = await User.findById(userId) .populate({ path: 'roles', populate: { path: 'permissions' }, }); if (!user) return []; const permissions = new Set(); for (const role of user.roles as any[]) { for (const perm of role.permissions as any[]) { permissions.add(perm.name); } } return Array.from(permissions); } /** * 为用户分配角色 */ static async assignRole(userId: Types.ObjectId, roleName: string): Promise { const role = await Role.findOne({ name: roleName }); if (!role) throw new Error('角色不存在'); await User.findByIdAndUpdate(userId, { $addToSet: { roles: role._id }, }); } /** * 移除用户角色 */ static async removeRole(userId: Types.ObjectId, roleName: string): Promise { const role = await Role.findOne({ name: roleName }); if (!role) return; await User.findByIdAndUpdate(userId, { $pull: { roles: role._id }, }); } }

📝 本节小结

✅
  • • RBAC 核心概念：用户-角色-权限
  • • 权限格式：resource:action（如 article:create）
  • • 支持通配符：article:* 表示所有文章权限
  • • 用户通过角色间接获得权限
  • • 系统角色不可删除，保证系统稳定
