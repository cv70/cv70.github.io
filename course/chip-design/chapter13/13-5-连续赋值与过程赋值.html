13.5 连续赋值与过程赋值

Verilog HDL 基础

🎯 学习目标

  • 理解连续赋值与过程赋值的区别
  • 掌握assign语句的使用方法
  • 掌握always块与initial块的使用
  • 理解阻塞赋值与非阻塞赋值的区别

赋值方式概述

Verilog中有两种主要的赋值方式：连续赋值（Continuous Assignment）用于组合逻辑建模，过程赋值（Procedural Assignment）用于时序逻辑和行为建模。理解两者的区别是编写正确Verilog代码的基础。

🔗 连续赋值（assign）

基本语法

// 简单连续赋值
assign y = a & b;

// 条件赋值
assign y = sel ? a : b;

// 多条件赋值
assign y = (state == IDLE)  ? 1'b0 :
           (state == ACTIVE) ? 1'b1 :
           1'bx;

特点

  • 目标必须是wire类型
  • 持续监控右侧信号变化
  • 任何输入变化立即更新输出
  • 描述组合逻辑

综合结果

连续赋值语句综合生成组合逻辑电路，对应硬件中的逻辑门互连结构。

⚙️ 过程赋值块

always块

// 时序逻辑：时钟边沿触发
always @(posedge clk) begin
    q <= d;
end

// 组合逻辑：电平敏感
always @(*) begin
    y = a & b;
end

initial块

// 仅用于仿真，不可综合
initial begin
    clk = 0;
    rst_n = 0;
    #100 rst_n = 1;
end
⚠️
注意事项

• initial块只用于仿真初始化，不可综合
• always块必须包含敏感列表或使用@(*)
• 一个模块中可以有多个always块，它们并行执行

🔄 阻塞赋值 vs 非阻塞赋值

特性阻塞赋值 (=)非阻塞赋值 (<=)
执行方式顺序执行并行执行
赋值时机立即更新时间步结束时更新
适用场景组合逻辑时序逻辑
综合结果组合逻辑触发器/锁存器

示例对比

// 阻塞赋值示例（组合逻辑）
always @(*) begin
    a = b + c;    // 先执行
    d = a + 1;    // 后执行，使用更新后的a
end

// 非阻塞赋值示例（时序逻辑）
always @(posedge clk) begin
    a <= b + c;   // 并行调度
    d <= a + 1;   // 使用旧值a
end
💡
编码准则

组合逻辑用阻塞赋值，时序逻辑用非阻塞赋值
• 组合逻辑always块中：使用 = 赋值
• 时序逻辑always块中：使用 <= 赋值
• 不要在同一个always块中混用两种赋值方式
• 不要在不同always块中对同一变量赋值

📝 本节小结

✅
  • • 连续赋值（assign）：用于组合逻辑，驱动wire
  • • 过程赋值：在always/initial块中使用
  • • 阻塞赋值（=）：用于组合逻辑
  • • 非阻塞赋值（<=）：用于时序逻辑
