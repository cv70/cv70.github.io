28.2 Model 操作

使用 Model 进行数据库操作

🎯 学习目标

  • 掌握 CRUD 操作方法
  • 学会查询和过滤
  • 理解 Model 和 Document 的区别
  • 了解批量操作技巧

📚 创建文档

import User from './models/User'; // 方式一：new + save const user = new User({ name: 'Alice', email: 'alice@mail.com', age: 25, }); await user.save(); // 方式二：create（推荐） const user = await User.create({ name: 'Bob', email: 'bob@mail.com', age: 30, }); // 批量创建 const users = await User.insertMany([ { name: 'User 1', email: 'user1@mail.com' }, { name: 'User 2', email: 'user2@mail.com' }, { name: 'User 3', email: 'user3@mail.com' }, ]); // save vs create // save: 触发验证和中间件，返回 Document // create: 触发验证和中间件，返回 Document // insertMany: 批量插入，默认验证但不触发 save 中间件 // 创建时验证失败会抛出 ValidationError try { await User.create({ name: 'Test' }); // email 必填 } catch (error) { console.error(error.message); // "User validation failed: email: Path `email` is required." }

🔧 查询文档

// 查询所有 const users = await User.find(); // 条件查询 const users = await User.find({ status: 'active' }); const user = await User.findOne({ email: 'alice@mail.com' }); // 按 ID 查询 const user = await User.findById('64a1b2c3d4e5f6...'); // 查询或抛出错误 const user = await User.findOne({ email: 'alice@mail.com' }).orFail( new Error('用户不存在') ); // 选择字段 const users = await User.find().select('name email -_id'); const user = await User.findById(id).select('name email'); // 排序 const users = await User.find().sort({ createdAt: -1 }); const users = await User.find().sort('-createdAt name'); // 分页 const users = await User.find() .skip((page - 1) * limit) .limit(limit); // 分页并获取总数 const [users, total] = await Promise.all([ User.find().skip(0).limit(10), User.countDocuments(), ]); // 计数 const count = await User.countDocuments({ status: 'active' }); // 判断是否存在 const exists = await User.exists({ email: 'alice@mail.com' }); // 去重 const emails = await User.distinct('email'); // 查询链 const users = await User.find() .where('status').equals('active') .where('age').gte(18) .sort('-createdAt') .limit(10) .select('name email');
💡
查询返回类型

find() 返回 Document 数组，findOne() 返回单个 Document 或 null。Document 可以修改后调用 save() 保存。

📊 更新文档

// 方式一：修改 Document + save const user = await User.findById(id); user.name = 'New Name'; user.age = 26; await user.save(); // 方式二：findByIdAndUpdate const user = await User.findByIdAndUpdate( id, { name: 'New Name' }, { new: true } // 返回更新后的文档 ); // 方式三：updateOne / updateMany await User.updateOne( { _id: id }, { $set: { name: 'New Name' } } ); await User.updateMany( { status: 'pending' }, { $set: { status: 'active' } } ); // 方式四：findOneAndUpdate const user = await User.findOneAndUpdate( { email: 'alice@mail.com' }, { $set: { status: 'inactive' } }, { new: true, upsert: true } // 不存在则创建 ); // 更新选项 { new: true, // 返回更新后的文档 upsert: true, // 不存在则创建 runValidators: true, // 运行验证器 setDefaultsOnInsert: true, // 插入时设置默认值 context: 'query', // 验证器上下文 } // 增量更新 await User.findByIdAndUpdate(id, { $inc: { loginCount: 1 } }); // 数组操作 await User.findByIdAndUpdate(id, { $push: { tags: 'new-tag' }, }); await User.findByIdAndUpdate(id, { $pull: { tags: 'old-tag' }, });

🗑️ 删除文档

// 方式一：Document remove const user = await User.findById(id); await user.deleteOne(); // 或 user.remove() // 方式二：findByIdAndDelete const user = await User.findByIdAndDelete(id); // 方式三：deleteOne / deleteMany await User.deleteOne({ _id: id }); await User.deleteMany({ status: 'inactive' }); // 删除并返回 const user = await User.findOneAndDelete({ email: 'old@mail.com' }); // 返回删除数量 const result = await User.deleteMany({ status: 'inactive' }); console.log(result.deletedCount); // 删除的文档数 // 软删除（需要 Schema 支持） const userSchema = new mongoose.Schema({ name: String, deletedAt: { type: Date, default: null }, }); // 软删除方法 userSchema.methods.softDelete = function() { this.deletedAt = new Date(); return this.save(); }; // 查询时过滤已删除 userSchema.query.notDeleted = function() { return this.where({ deletedAt: null }); }; const User = mongoose.model('User', userSchema); // 使用 const user = await User.findById(id); await user.softDelete(); const activeUsers = await User.find().notDeleted();
