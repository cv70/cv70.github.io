35.3 Pug 模板引擎

学习 Pug（原 Jade）模板引擎

🎯 学习目标

  • 掌握 Pug 的缩进语法
  • 学会 Pug 的变量和表达式
  • 理解 Pug 的模板继承
  • 掌握 Pug 的 Mixin 功能

📦 安装和配置

# 安装 Pug npm install pug
// Express 配置 const express = require('express'); const app = express(); app.set('view engine', 'pug'); app.set('views', './views');

📝 Pug 基本语法

//- HTML 标签 doctype html html head title My Page body h1 Hello World p This is a paragraph //- 渲染结果: //- <!DOCTYPE html> //- <html> //- <head><title>My Page</title></head> //- <body> //- <h1>Hello World</h1> //- <p>This is a paragraph</p> //- </body> //- </html>

ID 和 Class

//- ID 和 Class div#main div.container div#main.container.active //- 简写 #main .container #main.container.active //- 渲染结果: //- <div id="main"></div> //- <div class="container"></div> //- <div id="main" class="container active"></div>

属性

//- 属性 a(href='/', title='Home') Home input(type='text', name='username', placeholder='Enter name') //- 多行属性 input( type='text' name='email' placeholder='Enter email' ) //- 布尔属性 input(type='checkbox', checked) //- 数据属性 div(data-id='123', data-name='test')

📄 变量和表达式

//- 变量输出 h1= title p Welcome, #{user.name} //- 属性中的变量 a(href=user.profileUrl) View Profile img(src=user.avatar, alt=user.name) //- 表达式 p= 'Hello ' + name p= user.age > 18 ? 'Adult' : 'Minor' //- 转义和非转义 p= content // 转义 HTML p!= content // 不转义 //- 字符串插值 p Hello #{name}, you have #{notifications.length} notifications //- 标签内文本 h1 Welcome to #[strong My Site] //- 管道文本 p | This is a long paragraph | that spans multiple lines | in the template.

🔀 条件和循环

//- 条件判断 if user p Hello, #{user.name} else p Please login //- else if if user.role === 'admin' p Admin Panel else if user.role === 'editor' p Editor Panel else p User Dashboard //- unless（if 的反义） unless user.banned p You can access this content //- case case user.role when 'admin' p Admin privileges when 'editor' p Editor privileges default p Standard user //- 循环 ul each user in users li= user.name //- 带索引 ul each user, index in users li(class=(index % 2 ? 'odd' : 'even'))= user.name //- 对象遍历 ul each value, key in user li #{key}: #{value} //- while - var n = 0 ul while n < 5 li= n++

🔧 Mixin（混合）

//- 定义 Mixin mixin card(title, content) .card .card-header h3= title .card-body p= content //- 使用 Mixin +card('Card Title', 'Card content here') //- 带块的 Mixin mixin article(title) article h2= title if block block else p No content +article('Article 1') p This is the content //- 带参数的块 mixin list(items) ul each item in items li= item if block block +list(['Item 1', 'Item 2']) li Extra item

📁 模板继承
