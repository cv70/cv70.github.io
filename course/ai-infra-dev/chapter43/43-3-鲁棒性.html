AI鲁棒性概述

鲁棒性（Robustness）是指AI系统在面对输入扰动、分布变化、 对抗攻击等异常情况时，仍能保持稳定性能的能力。鲁棒性是AI系统安全、 可靠运行的关键保障，尤其在医疗、自动驾驶、金融等高风险应用中尤为重要。

⚔️ 对抗攻击类型

攻击类型 原理 特点 防御难度
白盒攻击 了解模型参数 精确、高效 高
黑盒攻击 不了解模型 实用、通用 中
目标攻击 使模型输出特定结果 针对性 高
非目标攻击 使模型输出错误 容易实施 中

🎓 对抗训练

# FGSM对抗训练示例
import torch
import torch.nn.functional as F

# FGSM攻击生成
def fgsm_attack(model, x, y, epsilon):
    x.requires_grad = True
    output = model(x)
    loss = F.cross_entropy(output, y)
    loss.backward()

    # 生成对抗样本
    perturbation = epsilon * x.grad.data.sign()
    adversarial_x = x + perturbation

    return torch.clamp(adversarial_x, 0, 1)

# 对抗训练循环
for epoch in range(epochs):
    for x, y in train_loader:
        # 生成对抗样本
        x_adv = fgsm_attack(model, x, y, epsilon=0.1)

        # 混合原始样本和对抗样本
        x_mixed = torch.cat([x, x_adv], dim=0)
        y_mixed = torch.cat([y, y], dim=0)

        # 训练
        optimizer.zero_grad()
        output = model(x_mixed)
        loss = F.cross_entropy(output, y_mixed)
        loss.backward()
        optimizer.step()

# 图像数据增强
from torchvision import transforms

# 定义增强变换
transform = transforms.Compose([
    transforms.RandomHorizontalFlip(),
    transforms.RandomRotation(10),
    transforms.ColorJitter(brightness=0.2, contrast=0.2),
    transforms.RandomAffine(0, translate=(0.1, 0.1)),
    transforms.ToTensor(),
])

# 应用增强
augmented_data = transform(original_image)

# 文本数据增强
import nlpaug.augmenter.word as naw

# 同义词替换
aug = naw.SynonymAug(aug_src='wordnet')
augmented_text = aug.augment(original_text)

# 回译增强
aug = naw.BackTranslationAug(
    from_model_name='facebook/wmt19-en-de',
    to_model_name='facebook/wmt19-de-en'
)
augmented_text = aug.augment(original_text)

🔍 鲁棒性评估

  • 对抗准确率: 在对抗样本上的准确率
  • 扰动敏感度: 小扰动下的性能变化
  • 域适应能力: 在新分布上的性能
  • 噪声鲁棒性: 对输入噪声的抵抗力
💡
鲁棒性权衡

提高鲁棒性通常会降低标准准确率。 在实践中需要根据应用场景在鲁棒性和准确性之间权衡。

📈 鲁棒性指标

指标 定义 目标
对抗准确率 对抗样本上的准确率 > 80%
扰动敏感度 性能随扰动变化的斜率 < 0.1
最坏情况性能 最小性能 > 70%
性能稳定性 性能方差 < 0.05
⚠️
鲁棒性挑战
  • 攻击复杂: 攻击方法多样且不断演进
  • 成本高昂: 鲁棒性训练需要大量资源
  • 评估困难: 缺乏统一的鲁棒性标准
  • 权衡复杂: 准确性、鲁棒性、效率权衡
