58.5 API 文档自动生成

从代码到文档的自动化工作流

📖 自动生成的优势

API 文档自动生成能够保持代码与文档的同步，减少维护成本，提高开发效率。

代码即文档

  • 文档与代码同源
  • 自动同步更新
  • 减少人工维护
  • 降低遗漏风险

开发效率提升

  • 无需单独编写文档
  • 专注业务开发
  • 减少沟通成本
  • 快速迭代

⚙️ NestJS Swagger 自动生成

基于装饰器自动推断

NestJS Swagger 能够自动从 TypeScript 类型推断出 OpenAPI Schema。

// user.dto.ts export class UserDto { // 自动推断类型 @ApiProperty() id: number; // 自动识别为 integer @ApiProperty() name: string; // 自动识别为 string @ApiProperty() email: string; // 自动识别为 string @ApiProperty() isActive: boolean; // 自动识别为 boolean @ApiProperty({ type: [String] }) roles: string[]; // 数组类型需要指定 @ApiProperty() createdAt: Date; // 自动识别为 date-time } // 生成的 OpenAPI Schema { "UserDto": { "type": "object", "properties": { "id": { "type": "number" }, "name": { "type": "string" }, "email": { "type": "string" }, "isActive": { "type": "boolean" }, "roles": { "type": "array", "items": { "type": "string" } }, "createdAt": { "type": "string", "format": "date-time" } } } }

class-validator 集成

import { IsString, IsEmail, IsOptional, MinLength, MaxLength } from 'class-validator'; import { ApiProperty } from '@nestjs/swagger'; export class CreateUserDto { @ApiProperty({ description: '用户名', minLength: 2, maxLength: 50, example: '张三', }) @IsString() @MinLength(2) @MaxLength(50) name: string; @ApiProperty({ description: '邮箱', format: 'email', example: 'zhangsan@example.com', }) @IsEmail() email: string; @ApiPropertyOptional({ description: '用户简介', maxLength: 500, }) @IsOptional() @IsString() @MaxLength(500) bio?: string; }

📄 导出 OpenAPI 文档

运行时导出

// 方式 1：访问 JSON 端点 GET http://localhost:3000/api-json // 方式 2：访问 YAML 端点 GET http://localhost:3000/api-yaml // 方式 3：程序化导出 import { writeFileSync } from 'fs'; import { SwaggerModule, DocumentBuilder } from '@nestjs/swagger'; async function generateSwaggerDocument(app: INestApplication) { const config = new DocumentBuilder() .setTitle('API 文档') .setVersion('1.0') .build(); const document = SwaggerModule.createDocument(app, config); // 写入 JSON 文件 writeFileSync('swagger.json', JSON.stringify(document, null, 2)); return document; }

构建时生成

// swagger-cli.ts import { NestFactory } from '@nestjs/core'; import { SwaggerModule, DocumentBuilder } from '@nestjs/swagger'; import { AppModule } from './app.module'; import { writeFileSync } from 'fs'; async function generate() { const app = await NestFactory.create(AppModule, { logger: false, // 禁用日志 }); const config = new DocumentBuilder() .setTitle('API 文档') .setVersion('1.0') .build(); const document = SwaggerModule.createDocument(app, config); writeFileSync('openapi.json', JSON.stringify(document, null, 2)); console.log('OpenAPI 文档已生成: openapi.json'); await app.close(); } generate(); // package.json { "scripts": { "generate:swagger": "ts-node swagger-cli.ts", "build": "npm run generate:swagger && nest build" } }

🔄 自动化工作流

// .github/workflows/api-docs.yml name: Generate API Docs on: push: branches: [main] jobs: generate-docs: runs-on: ubuntu-latest steps: - uses: actions/checkout@v3 - name: Setup Node.js uses: actions/setup-node@v3 with: node-version: '20' - name: Install dependencies run: npm ci - name: Generate OpenAPI spec run: npm run generate:swagger - name: Commit changes run: | git config --local user.email "github-actions[bot]" git config --local user.name "github-actions[bot]" git add openapi.json git diff --quiet && git diff --staged --quiet || git commit -m "docs: update OpenAPI spec" git push

🛠️ 代码生成工具

从 OpenAPI 生成客户端 SDK

# 安装 openapi-generator-cli npm install @openapitools/openapi-generator-cli -D # 生成 TypeScript Axios 客户端 openapi-generator-cli generate \ -i openapi.json \ -g typescript-axios \ -o ./src/api-client # 生成前端 SDK openapi-generator-cli generate \ -i openapi.json \ -g typescript-fetch \ -o ./src/api # package.json { "scripts": { "generate:client": "openapi-generator-cli generate -i openapi.json -g typescript-axios -o ./src/api-client" } }

生成的客户端使用

import { UsersApi, Configuration } from './api-client'; const api = new UsersApi(new Configuration({ basePath: 'https://api.example.com', accessToken: 'your-token', })); // 自动生成的类型安全方法 const users = await api.usersControllerFindAll(); const user = await api.usersControllerFindOne(123);

📊 类型生成工具对比

工具 特点 适用场景

openapi-typescript 专注 TypeScript 类型 前端项目
swagger-codegen 官方工具，成熟稳定 传统项目
orval 支持 React Query 集成 React 项目
# openapi-typescript 使用 npm install openapi-typescript -D # 生成类型定义 npx openapi-typescript openapi.json -o src/types/api.d.ts // 使用生成的类型 import type { paths, components } from './types/api'; type User = components['schemas']['UserDto']; type GetUsersResponse = paths['/users']['get']['responses']['200']['content']['application/json'];

🔗 Mock 服务生成

# 使用 Prism 创建 Mock 服务 npm install @stoplight/prism-cli -D # 启动 Mock 服务器 npx prism mock openapi.json # Mock 服务器运行在 http://localhost:4010 // 前端开发时使用 Mock const apiBaseUrl = process.env.NODE_ENV === 'development' ? 'http://localhost:4010' : 'https://api.example.com';
✅
Mock 服务优势

基于 OpenAPI 文档生成 Mock 服务，让前端开发不必等待后端 API 完成，实现前后端并行开发。

📝 小结

  • NestJS Swagger 自动从代码生成 OpenAPI 文档
  • class-validator 装饰器与 Swagger 装饰器配合使用
  • 支持导出 JSON/YAML 格式的文档
  • 可配置 CI/CD 自动更新文档
  • 使用 openapi-generator 生成多语言客户端 SDK
  • Mock 服务支持前后端并行开发
