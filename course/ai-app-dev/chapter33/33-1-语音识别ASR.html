什么是语音识别

语音识别（Automatic Speech Recognition, ASR）是将人类语音转换为文字的技术。ASR是人机交互的核心技术之一，广泛应用于语音助手、会议转写、智能客服、字幕生成等场景。随着深度学习的发展，ASR准确率已达到实用水平。

💻 代码示例：使用Whisper进行语音识别

import whisper

# 加载Whisper模型（可选tiny/base/small/medium/large）
model = whisper.load_model("medium")

# 识别音频文件
result = model.transcribe("speech.mp3")

# 输出识别结果
print("识别文本:", result["text"])

# 获取时间戳信息
for segment in result["segments"]:
    start = segment["start"]
    end = segment["end"]
    text = segment["text"]
    print(f"[{start:.1f}s - {end:.1f}s] {text}")

# 支持多语言识别（自动检测语言）
result = model.transcribe("chinese_speech.wav", language="zh")
print("中文识别:", result["text"])

🔧 核心技术组件

特征提取

  • MFCC（梅尔频率倒谱系数）
  • Filter Bank特征
  • 波形直接输入（端到端）
  • 数据增强（噪声、速度扰动）

解码策略

  • 贪婪解码（最快）
  • 束搜索（Beam Search）
  • 外挂语言模型重打分
  • 热词/关键词加权
💡
评估指标

词错误率（Word Error Rate, WER）是ASR最常用的评估指标，计算公式为：WER = (替换+删除+插入) / 参考词数 × 100%。中文ASR使用字错误率（CER）。高质量ASR系统的WER通常在5-15%之间。
