9.5 模板字面量类型

字符串类型的模式匹配

🎯 学习目标

  • 理解模板字面量类型的概念
  • 掌握字符串模式匹配
  • 学会内置字符串工具类型
  • 了解实际应用场景

📚 基本语法

// 模板字面量类型类似于 JavaScript 的模板字符串 // 但用于类型层面 type Greeting = `hello ${string}`; const a: Greeting = 'hello world'; // OK const b: Greeting = 'hello there'; // OK // const c: Greeting = 'hi world'; // Error // 联合类型展开 type Color = 'red' | 'blue' | 'green'; type Size = 'small' | 'medium' | 'large'; type ColorSize = `${Color}-${Size}`; // 'red-small' | 'red-medium' | 'red-large' | // 'blue-small' | 'blue-medium' | 'blue-large' | // 'green-small' | 'green-medium' | 'green-large' // 数值类型 type Pixel = `${number}px`; const width: Pixel = '100px'; // OK const height: Pixel = '200px'; // OK // const wrong: Pixel = '100em'; // Error
💡
模板字面量类型

模板字面量类型在 TypeScript 4.1+ 中引入，允许在类型层面操作字符串类型。

🔧 内置字符串工具类型

// Uppercase - 转大写 type Upper = Uppercase<'hello'>; // 'HELLO' // Lowercase - 转小写 type Lower = Lowercase<'HELLO'>; // 'hello' // Capitalize - 首字母大写 type Cap = Capitalize<'hello'>; // 'Hello' // Uncapitalize - 首字母小写 type Uncap = Uncapitalize<'Hello'>; // 'hello' // 实际应用：创建常量 type HttpMethod = 'get' | 'post' | 'put' | 'delete'; type HttpMethodUpper = Uppercase; // 'GET' | 'POST' | 'PUT' | 'DELETE' // 转换方法名 type MethodName = `${Lowercase}Request`; type GetRequest = MethodName<'GET'>; // 'getRequest'

🔀 字符串模式推断

// 使用 infer 在模板字面量中提取部分 type GetPrefix = T extends `${infer Prefix}_${string}` ? Prefix : never; type P1 = GetPrefix<'user_id'>; // 'user' type P2 = GetPrefix<'order_total'>; // 'order' // 提取多个部分 type Split = S extends `${infer Head}${D}${infer Tail}` ? [Head, ...Split] : S extends '' ? [] : [S]; type Parts = Split<'a-b-c', '-'>; // ['a', 'b', 'c'] // 替换字符串 type Replace = S extends `${infer Before}${From}${infer After}` ? `${Before}${To}${After}` : S; type Replaced = Replace<'hello world', ' ', '-'>; // 'hello-world' // 去除前缀 type RemovePrefix = T extends `${P}${infer Rest}` ? Rest : T; type Without = RemovePrefix<'HelloWorld', 'Hello'>; // 'World'

🎨 实际应用

// 类型安全的事件系统 type EventName = 'click' | 'focus' | 'blur' | 'keydown'; type EventHandler = `on${Capitalize}`; type AllHandlers = { [K in EventName as EventHandler]: () => void; }; // { onClick: () => void; onFocus: () => void; ... } // 路由类型 type Route = '/users' | '/posts' | '/comments'; type RouteParam = `${T}/:${string}`; type DynamicRoutes = RouteParam; // '/users/:id' | '/posts/:id' | '/comments/:id' // CSS 类名生成 type ResponsivePrefix = 'sm' | 'md' | 'lg'; type Property = 'hidden' | 'block' | 'flex'; type ResponsiveClass = `${ResponsivePrefix}:${Property}`; // 'sm:hidden' | 'sm:block' | 'sm:flex' | 'md:hidden' | ... // 数据库查询类型 type Operator = 'eq' | 'ne' | 'gt' | 'lt'; type Field = 'id' | 'name' | 'age'; type WhereClause = `${Field}_${Operator}`; // 'id_eq' | 'id_ne' | 'id_gt' | 'id_lt' | 'name_eq' | ...
⚠️
性能注意

模板字面量类型可能导致编译时间增加，特别是当联合类型组合产生大量结果时。合理使用避免过度复杂。

  • • 联合类型会自动展开组合

  • • infer 可用于提取字符串部分
