19.2 时钟域与跨时钟域设计

RTL 设计方法论

🎯 学习目标

  • 理解时钟域的概念和重要性
  • 掌握跨时钟域数据传输的方法
  • 了解亚稳态的产生原因和处理方法
  • 能够设计可靠的跨时钟域电路

时钟域概念

时钟域（Clock Domain）是指由同一个时钟信号或相位相关的时钟信号驱动的所有同步元件（触发器）的集合。在现代SoC设计中，通常存在多个时钟域，不同模块工作在不同时钟频率下。

跨时钟域设计是芯片设计中最具挑战性的问题之一，处理不当会导致系统功能错误甚至芯片失效。

⚠️ 亚稳态问题

什么是亚稳态

当信号在时钟边沿附近变化时，触发器可能进入不稳定状态，输出在0和1之间震荡。这种现象称为亚稳态，是跨时钟域设计必须解决的核心问题。

参数说明
建立时间（Setup Time）数据在时钟沿前必须稳定的时间
保持时间（Hold Time）数据在时钟沿后必须保持稳定的时间
MTBF平均故障间隔时间，衡量亚稳态可靠性

🔧 跨时钟域处理方法

单比特信号

  • 打两拍：使用两级触发器同步
  • 脉冲同步器：用于脉冲信号传递
  • 适用于控制信号、标志位

多比特数据

  • 握手协议：请求/应答机制
  • FIFO：异步FIFO缓冲
  • 格雷码：减少同时变化位数

💻 两级同步器示例

// 两级同步器 - 打两拍
module sync_2stage (
    input  wire clk_dst,    // 目标时钟
    input  wire rst_n,
    input  wire sig_src,    // 源域信号
    output reg  sig_dst     // 同步后的信号
);
    reg sig_mid;            // 中间级

    always @(posedge clk_dst or negedge rst_n) begin
        if (!rst_n) begin
            sig_mid <= 1'b0;
            sig_dst <= 1'b0;
        end else begin
            sig_mid <= sig_src;
            sig_dst <= sig_mid;
        end
    end
endmodule
⚠️
设计注意要点

1. 跨时钟域信号必须经过同步处理
2. 多比特数据不能直接打两拍
3. 使用CDC检查工具验证设计
4. 在规格书中明确时钟域边界

📝 本节小结

✅
  • • 时钟域是由同一时钟驱动的所有触发器集合
  • • 亚稳态是跨时钟域设计的核心问题
  • • 单比特信号使用打两拍方式同步
  • • 多比特数据使用握手或FIFO方式传输
