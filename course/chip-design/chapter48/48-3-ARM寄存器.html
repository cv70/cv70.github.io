48.3 ARM寄存器

理解ARM处理器的寄存器组织

  • 掌握ARM通用寄存器的组织结构
  • 理解特殊功能寄存器的作用

寄存器概述

寄存器是处理器内部最快的存储单元，ARM架构提供丰富的寄存器资源， 支持高效的指令执行和快速的数据访问。合理使用寄存器是优化程序性能的关键。

📋 ARM64通用寄存器

寄存器 特殊用途 调用约定
X0 - X7 参数/返回值 临时寄存器（调用者保存）
X8 间接结果位置 临时寄存器（调用者保存）
X9 - X15 临时 临时寄存器（调用者保存）
X16 - X17 过程内调用 临时寄存器（调用者保存）
X18 平台寄存器 保留给平台ABI
X19 - X28 临时 被调用者保存
X29 帧指针（FP） 被调用者保存
X30 链接寄存器（LR） 被调用者保存
SP 栈指针 特殊

🔧 特殊功能寄存器

程序状态寄存器

  • N: 负数标志
  • Z: 零标志
  • C: 进位标志
  • V: 溢出标志

系统控制寄存器

  • SCTLR: 系统控制
  • TTBR0/1: 转换表基址
  • TPIDR_EL0: 线程ID
  • CNTVCT: 虚拟计数器

🔢 浮点与SIMD寄存器

V0 - V31

ARM64提供32个128位的向量寄存器，可用于：

🧮

浮点运算（S/D/Q）

📊

NEON SIMD

🚀

SVE向量

💡
寄存器别名

ARM64寄存器支持宽度别名：Xn是64位版本，Wn是低32位版本。例如：W0是X0的低32位。这允许灵活处理不同宽度的数据。

🔄 调用约定示例

// 函数调用示例
func(int a, int b, int c, int d)
{
    // 参数通过X0-X3传递
    // 返回值通过X0返回
    // X19-X28需要被调用者保存
}

// 调用者：
mov x0, #a      // 第一个参数
mov x1, #b      // 第二个参数
mov x2, #c      // 第三个参数
mov x3, #d      // 第四个参数
bl func         // 调用函数
// 结果在x0中

📝 本节小结

✅
  • • ARM64提供31个64位通用寄存器（X0-X30）
  • • X29为帧指针，X30为链接寄存器
  • • V0-V31用于浮点和SIMD运算
  • • 遵循调用约定对代码兼容性至关重要
