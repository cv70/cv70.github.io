40.4 UVM事务与序列

Transaction和Sequence的使用

🎯 学习目标

  • 理解UVM事务（Transaction）的概念
  • 掌握Sequence的定义和使用
  • 学会编写随机约束
  • 了解Sequence的类型和应用

Transaction与Sequence概述

Transaction是UVM中数据交换的基本单元，Sequence是生成和发送Transaction的容器。

📦 Transaction（事务）

Transaction详解

定义：Transaction继承自uvm_sequence_item，是验证环境中的数据单元

  • 包含数据字段和控制字段
  • 支持随机化和约束
  • 支持自动打印和比较
  • 可以通过TLM端口传递

📜 Sequence（序列）

Sequence详解

定义：Sequence继承自uvm_sequence，用于生成和发送Transaction

  • 定义激励序列
  • 支持随机化和约束
  • 可以嵌套和组合
  • 可以并行执行

🎲 随机化与约束

约束随机化

SystemVerilog的随机化是UVM的核心机制

  • rand：声明随机变量
  • randc：声明循环随机变量
  • constraint：定义约束块
  • randomize()：触发随机化
💡
约束示例

constraint addr_range { addr inside {[32'h1000:32'h1FFF]}; }
constraint data_aligned { data[1:0] == 2'b00; }

🔄 Sequence类型

基本Sequence

  • 单个Sequence发送Transaction
  • 最简单的激励形式

虚拟Sequence

  • 协调多个Sequencer
  • 用于复杂场景

嵌套Sequence

  • Sequence调用其他Sequence
  • 实现层次化激励

库Sequence

  • 可复用的Sequence库
  • 标准激励序列

📝 本节小结

✅
  • • Transaction是UVM中的数据单元
  • • Sequence负责生成和发送Transaction
  • • 约束随机化是UVM的核心机制
  • • 支持多种Sequence类型以满足不同需求
