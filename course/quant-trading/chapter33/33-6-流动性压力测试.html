流动性压力测试

流动性压力测试是评估极端市场条件下流动性风险的重要工具。 通过压力测试，可以提前发现流动性薄弱环节，制定应对预案。

📊 压力情景设计

情景类型 假设条件 影响 典型参考
成交量萎缩 成交量下降50%-90% 难以平仓 2015中国股灾
价差扩大 价差扩大3-10倍 交易成本激增 2020疫情初期
全面停牌 多数股票停牌 完全失去流动性 极端政策风险
市场暴跌 单日跌幅>20% 无人接盘 1987黑色星期一
叠加情景 多种风险同时发生 系统性危机 2008金融危机

🔧 压力测试流程

标准流程

  1. 情景设计 - 设计合理的压力情景
  2. 参数设定 - 确定各参数的变化幅度
  3. 执行测试 - 将情景应用到当前组合
  4. 结果评估 - 评估流动性风险暴露
  5. 制定对策 - 根据结果制定应对措施
  6. 定期更新 - 根据市场变化更新情景

💻 流动性压力测试Python实现

Python代码示例

import numpy as np
import pandas as pd

def liquidity_stress_test(positions, stress_scenarios):
    """执行流动性压力测试"""
    results = {}

    for scenario_name, stress_params in stress_scenarios.items():
        # 应用压力情景
        stressed_volume = positions['avg_volume'] * stress_params['volume_factor']
        stressed_spread = positions['avg_spread'] * stress_params['spread_factor']

        # 计算压力下的流动性指标
        tradable_days = positions['position_size'] / (stressed_volume * 0.1)
        impact_cost = (positions['position_size'] / stressed_volume) * 0.5
        total_cost = impact_cost + stressed_spread / 2

        # 评估结果
        results[scenario_name] = {
            'tradable_days': tradable_days,
            'impact_cost': impact_cost,
            'total_cost': total_cost,
            'can_exit': tradable_days < 5 and total_cost < 0.05
        }

    return results

def comprehensive_liquidity_stress(portfolio):
    """综合流动性压力测试"""
    scenarios = {
        'moderate': {'volume_factor': 0.5, 'spread_factor': 2},
        'severe': {'volume_factor': 0.2, 'spread_factor': 5},
        'extreme': {'volume_factor': 0.1, 'spread_factor': 10}
    }

    return liquidity_stress_test(portfolio, scenarios)

评估维度

可变现性：能否在合理时间内变现

变现成本：变现的冲击成本

资金需求：追加保证金的需求

策略调整：需要哪些策略调整

资本充足：资本是否充足应对压力

✨
最佳实践

定期执行流动性压力测试，每季度至少一次。使用历史极端事件作为情景参考。关注测试结果中的薄弱环节，针对性改进。将压力测试纳入风险决策流程。
