47.4 网络配置

优化训练集群的网络性能

🎯 学习目标

  • 理解训练集群的网络需求
  • 掌握InfiniBand配置方法
  • 了解RoCE网络配置
  • 学会网络性能优化

网络的重要性

在分布式训练中，网络性能直接影响训练效率。高效的互联网络可以显著加速梯度同步，提升集群整体性能。

🔄 网络技术对比

技术 带宽 延迟 成本 适用场景
InfiniBand 200-400Gbps <1μs 高 高性能集群
RoCE v2 100-200Gbps 2-5μs 中 企业集群
TCP/IP 10-100Gbps 10-100μs 低 入门集群

🌐 RoCE v2配置

# 加载RDMA模块
modprobe rdma_cm
modprobe ib_core
modprobe ib_uverbs

# 配置PFC（Priority Flow Control）
# /etc/mlx/fw.conf
PCIE_SRIOV_EN=1
SRIOV_NUM_VF=4

# 启用RoCE
echo 1 > /sys/module/rdma_core/parameters/roce_mode

# 配置DCB（Data Center Bridging）
# /etc/sysconfig/network-scripts/ifcfg-eth0
ETHTOOL_OPTS="-C eth0 rx-usecs 100 tx-usecs 100 rx-frames 100 tx-frames 100"

# 验证RoCE
rdma link show

# 测试RDMA性能
rping -s -a 192.168.0.101 -v

🔧 NCCL网络配置

# NCCL环境变量配置
# /etc/profile.d/nccl-env.sh
export NCCL_DEBUG=INFO
export NCCL_IB_DISABLE=0
export NCCL_IB_GID_INDEX=3
export NCCL_NET_PLUGIN=none
export NCCL_SOCKET_IFNAME=eth0
export NCCL_IB_HCA=mlx5_0:1
export NCCL_IB_TIMEOUT=22
export NCCL_IB_RETRY_CNT=7
export NCCL_IB_SL=0

# 启用共享内存
export NCCL_SHM_DISABLE=0

# 启用P2P
export NCCL_P2P_DISABLE=0
export NCCL_P2P_LEVEL=5

# 优化网络缓冲区
export NCCL_NET_BUFFSIZE=8388608

# 测试NCCL性能
nccl-tests/build/all_reduce_perf -b 8 -e 128M -f 2 -g

⚙️ 网络优化技巧

硬件优化

  • 使用高品质线缆
  • 确保光纤长度合适
  • 定期检查接口清洁度
  • 使用冗余链路

软件优化

  • 调整MTU大小（9000）
  • 启用巨帧（Jumbo Frames）
  • 优化中断合并
  • 调整TCP参数
💡
网络故障排查

链路不通：检查光纤连接、交换机端口状态。性能不佳：检查MTU配置、流控设置。丢包严重：检查拥塞控制、QoS配置。NCCL错误：检查IB设备状态、环境变量配置。
