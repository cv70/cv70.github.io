17.5 高级Prompt技巧

进阶技术提升模型输出质量

🎯 学习目标

  • 掌握角色扮演和人格设定技巧
  • 学会使用结构化输出格式
  • 理解自反思和自我优化机制
  • 了解多种高级技巧的组合应用

高级Prompt技巧概览

除了Few-shot和CoT等基础技术外，还有许多高级Prompt技巧可以进一步提升模型表现。这些技巧通过角色设定、结构约束、自反思等机制，让模型输出更加精准、可控、专业。

🎭 角色扮演（Role Playing）

角色设定技巧

通过赋予模型特定角色和专业背景，引导其输出更专业、更符合预期的内容。

// 基础角色设定 你是一个资深的Python开发工程师， 有10年的后端开发经验。 // 增强版角色设定 你是一位在Google工作了15年的资深架构师， 专注于大规模分布式系统设计。 你善于用简洁的语言解释复杂概念， 总是提供具体的代码示例和最佳实践建议。

角色要素

  • 身份背景：职业、经验、专长
  • 思维方式：分析风格、表达习惯
  • 输出风格：正式/随意、简洁/详尽
  • 知识边界：专业领域、能力范围
图：角色设定让模型以特定专业视角回答问题

📐 结构化输出格式

JSON/XML结构化输出

// 要求模型输出结构化JSON 请分析以下文本的情感，并以JSON格式输出： 文本: "这款手机拍照效果很好，但电池续航一般" 输出格式： { "sentiment": "正面/负面/中性", "score": 0-1的数值, "aspects": [ {"aspect": "拍照", "opinion": "正面"}, {"aspect": "电池", "opinion": "负面"} ], "summary": "一句话总结" }

Markdown表格输出

请比较Python和JavaScript的特点，以Markdown表格形式输出： | 特性 | Python | JavaScript | |------|--------|------------| | 类型系统 | 动态类型 | 动态类型 | | 主要用途 | 数据分析、AI | Web前端 | | 学习曲线 | 较平缓 | 中等 |

🔄 自反思（Self-Reflection）

让模型检查自己的输出，发现并修正错误。

// 两阶段Prompt 第一阶段：生成答案 问题：请解释什么是递归，并给出一个例子。 第二阶段：自检 请检查你上面的回答： 1. 定义是否准确？ 2. 例子是否正确？ 3. 是否有逻辑错误？ 如有问题，请修正后重新输出。 --- // 输出示例 检查后发现：例子中缺少递归终止条件， 这会导致无限递归。修正后的代码： def factorial(n): if n <= 1: # 终止条件 return 1 return n * factorial(n - 1)

📊 高级技巧对比

技巧 核心思想 适用场景 效果
角色扮演 设定专家角色 专业咨询、教学 提升专业性
结构化输出 约束输出格式 数据抽取、API集成 便于程序处理
自反思 自我检查修正 高精度任务 提高准确性
思维树(ToT) 多路径探索 决策、创意生成 探索更多可能

渐进式提问 由简到繁引导 教学、复杂问题 降低认知负担

🌳 思维树（Tree of Thoughts）

让模型探索多个推理路径，选择最优解。

// ToT Prompt示例 问题：如何提高用户留存率？ 请生成3个不同的解决方案，评估每个方案的： 1. 可行性（1-10分） 2. 成本（低/中/高） 3. 预期效果（1-10分） 然后选择综合最优的方案，说明理由。 --- 方案1: 改善新手引导流程 - 可行性: 8/10 - 成本: 低 - 预期效果: 7/10 - 综合评分: 15 方案2: 增加会员积分系统 - 可行性: 6/10 - 成本: 高 - 预期效果: 8/10 - 综合评分: 14 方案3: 个性化推荐优化 - 可行性: 7/10 - 成本: 中 - 预期效果: 9/10 - 综合评分: 16 最优方案: 方案3 - 个性化推荐优化 理由: 在可接受成本下效果最好...

🔗 多技巧组合应用

组合示例：代码审查助手

// 组合：角色扮演 + CoT + 结构化输出 + 自反思 【角色设定】 你是一位资深代码审查专家，有15年开发经验。 擅长发现代码中的潜在问题和优化机会。 【任务】 审查以下代码，使用思维链逐步分析， 最后以JSON格式输出审查结果。 【代码】 {code} 【输出格式】 { "issues": [...], "suggestions": [...], "score": 0-100 } 【自检】 输出前请确认： 1. 所有issue都有具体行号 2. 建议可执行且具体 3. 评分合理反映代码质量

⚙️ Prompt优化清单

优化要点

  • 明确任务目标
  • 提供充分上下文
  • 设定清晰边界
  • 指定输出格式
  • 包含错误处理指导

常见陷阱

  • 指令模糊不清
  • 缺少示例参考
  • 上下文过长
  • 格式要求矛盾
  • 忽略边界情况
💡
最佳实践

高级技巧可以组合使用，但要注意平衡效果和成本。建议先用简单Prompt测试基线，再逐步添加优化技巧，对比效果提升。过度复杂的Prompt可能适得其反。
