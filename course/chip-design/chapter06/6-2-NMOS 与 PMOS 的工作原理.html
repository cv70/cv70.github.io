6.2 NMOS 与 PMOS 的工作原理

NMOS/PMOS 导通原理对比

🎯 学习目标

  • 理解 NMOS 的工作原理与导通条件
  • 理解 PMOS 的工作原理与导通条件
  • 掌握两种器件的工作状态差异
  • 理解 CMOS 互补工作的优势

MOSFET 的工作原理概述

MOSFET 是一种电压控制型器件，其核心原理是通过栅极电压控制半导体表面的电场，从而在衬底表面形成或消除导电沟道。当沟道形成时，源极和漏极之间可以导通电流；当沟道消失时，源漏之间截止。

💡 NMOS 工作原理

器件结构回顾

NMOS 在 P 型衬底上制作两个 N+ 区作为源极和漏极，栅极位于两者之间。P 型衬底中多数载流子是空穴，少数载流子是电子。

工作过程详解

①
截止状态（VGS = 0）

当栅源电压 VGS = 0 时：

  • P 型衬底表面的空穴浓度较高
  • 源-衬底和漏-衬底形成两个背靠背的 PN 结
  • 无论 VDS 极性如何，总有一个 PN 结反偏
  • 源漏之间无导电通道，器件处于截止状态
②
耗尽层形成（0 < VGS < Vth）

当施加正栅压但未达阈值时：

  • 栅极的正电压在氧化层中产生垂直电场
  • 衬底中的空穴被排斥远离表面
  • 表面形成耗尽层（留下固定负离子）
  • 尚未形成导电沟道，器件仍截止
③
反型层形成（VGS ≥ Vth）

当栅压达到阈值电压时：

  • 表面电场足够强，吸引少数载流子（电子）到表面
  • 表面电子浓度超过空穴浓度，形成 N 型反型层
  • 反型层连接源区和漏区，形成导电沟道
  • 器件导通，源漏之间可通过电流
④
沟道调制（VDS > 0）

当 VDS 增加时：

  • 漏端沟道电位升高，有效栅压减小
  • 漏端沟道变窄，出现"夹断"现象
  • 进入饱和区，电流基本恒定

💡 PMOS 工作原理

器件结构回顾

PMOS 在 N 型衬底（或 N-Well）上制作两个 P+ 区作为源极和漏极。N 型衬底中多数载流子是电子，少数载流子是空穴。

工作过程详解

①
截止状态（VGS = 0）

当栅源电压 VGS = 0 时：

  • N 型衬底表面的电子浓度较高
  • 源-衬底和漏-衬底形成两个背靠背的 PN 结
  • 源漏之间无导电通道，器件截止
②
耗尽层形成（Vth < VGS < 0）

当施加负栅压但未达阈值时：

  • 栅极的负电压排斥衬底中的电子
  • 表面形成耗尽层（留下固定正离子）
  • 尚未形成导电沟道
③
反型层形成（VGS ≤ Vth）

当负栅压达到阈值电压时：

  • 表面电场吸引少数载流子（空穴）到表面
  • 表面空穴浓度超过电子浓度，形成 P 型反型层
  • 反型层连接源区和漏区，形成导电沟道
  • 器件导通，空穴从源极流向漏极

📊 NMOS 与 PMOS 对比总结

特性 NMOS PMOS
导通载流子 电子 空穴
阈值电压 Vth > 0（正值） Vth < 0（负值）
导通条件 VGS > Vth VGS < Vth（更负）
栅极导通电压 高电平（接近 VDD） 低电平（接近 GND）
电流方向 漏极流入，源极流出 源极流入，漏极流出
迁移率 μn ≈ 2-3 × μp μp 较低
驱动能力 较强（相同尺寸） 较弱，需要更大尺寸
衬底连接 接最低电位（GND） 接最高电位（VDD）
⚠️
为什么 NMOS 比 PMOS 快？

电子的迁移率（μn）约为空穴迁移率（μp）的 2-3 倍。在相同的几何尺寸下，NMOS 的驱动电流更大，开关速度更快。这就是为什么在 CMOS 设计中，PMOS 通常需要更大的宽长比（约为 NMOS 的 2-3 倍）才能实现与 NMOS 相同的驱动能力，使上升和下降时间对称。

🔧 CMOS 互补优势

CMOS 反相器的工作原理

CMOS（Complementary MOS）利用 NMOS 和 PMOS 的互补特性，将两者串联构成反相器：

输入高电平（VIN = VDD）
  • NMOS：VGS > Vth，导通
  • PMOS：VGS = 0 > Vth，截止
  • 输出通过 NMOS 下拉到 GND
  • 输出低电平
输入低电平（VIN = 0）
  • NMOS：VGS = 0 < Vth，截止
  • PMOS：VGS < Vth，导通
  • 输出通过 PMOS 上拉到 VDD
  • 输出高电平

CMOS 的核心优势

静态功耗极低

稳态时，NMOS 和 PMOS 总有一个截止，无直流通路。静态功耗仅来自漏电流，几乎为零。

噪声容限大

输出电平接近电源轨（VDD 和 GND），具有很大的噪声容限，抗干扰能力强。

📝 本节小结

✅
  • • MOSFET 通过栅压控制表面电场，形成或消除导电沟道
  • • NMOS：P 衬底，N+ 源漏，VGS > Vth 时形成 N 型沟道导通
  • • PMOS：N 衬底，P+ 源漏，VGS < Vth 时形成 P 型沟道导通
  • • 电子迁移率高于空穴，NMOS 比 PMOS 更快
  • • CMOS 利用互补特性实现低功耗、高性能
