79.1 组件类型定义

TypeScript 与 React 组件

🎯 学习目标

  • 掌握函数组件的类型定义
  • 理解 FC 类型与直接定义的区别
  • 学会组件返回值类型
  • 了解组件类型最佳实践

📚 函数组件类型定义

import { FC, ReactNode, ReactElement } from 'react'; // 方式1：直接定义（推荐） interface ButtonProps { children: ReactNode; onClick?: () => void; disabled?: boolean; } function Button({ children, onClick, disabled }: ButtonProps) { return ( <button onClick={onClick} disabled={disabled}> {children} </button> ); } // 方式2：使用 FC 类型 const Button: FC<ButtonProps> = ({ children, onClick, disabled }) => { return ( <button onClick={onClick} disabled={disabled}> {children} </button> ); }; // FC 包含 children 属性 const Button: FC<{ variant?: 'primary' | 'secondary' }> = ({ variant = 'primary', children, // FC 自动包含 children }) => { return <button className={`btn-${variant}`}>{children}</button>; }; // 方式3：VFC（无 children） import { VFC } from 'react'; const Icon: VFC<{ name: string }> = ({ name }) => { return <i className={`icon-${name}`} />; }; // 注意：FC 在 React 18 中不再推荐使用 // 推荐直接定义函数类型 // 为什么推荐直接定义？ // 1. 更明确的类型定义 // 2. 更好的类型推断 // 3. 更灵活的返回类型 // 4. 不依赖 React 特定类型

🔧 组件返回类型

import { ReactNode, ReactElement, JSX } from 'react'; // JSX.Element：返回 JSX 元素 function Header(): JSX.Element { return <header>Header</header>; } // ReactElement：React 元素 function Footer(): ReactElement { return <footer>Footer</footer>; } // ReactNode：更宽泛，包含 string、null 等 function MaybeComponent(): ReactNode { const show = useShow(); if (!show) { return null; // ReactNode 允许返回 null } return <div>Content</div>; } // 区别 // JSX.Element = ReactElement = 返回 JSX 元素 // ReactNode = ReactElement | string | number | boolean | null | undefined // 条件渲染组件 interface ConditionalProps { condition: boolean; children: ReactNode; fallback?: ReactNode; } function Conditional({ condition, children, fallback }: ConditionalProps) { return condition ? children : fallback ?? null; } // 使用 function App() { return ( <Conditional condition={isLoggedIn} fallback={<LoginPrompt />}> <Dashboard /> </Conditional> ); } // 组件类型别名 type ComponentType<P = {}> = (props: P) => ReactNode; type ButtonComponent = ComponentType<ButtonProps>; // 用于高阶组件 function withLoading<P extends object>( Component: ComponentType<P> ): ComponentType<P & { loading?: boolean }> { return ({ loading, ...props }) => { if (loading) return <Spinner />; return <Component {...props as P} />; }; }

📊 组件类型最佳实践

// 1. 使用 interface 定义 Props interface CardProps { title: string; children: ReactNode; className?: string; onHeaderClick?: () => void; } function Card({ title, children, className, onHeaderClick }: CardProps) { return ( <div className={`card ${className ?? ''}`}> <header onClick={onHeaderClick}>{title}</header> <div className="card-body">{children}</div> </div> ); } // 2. 使用类型推断，不必显式标注返回类型 // 推荐 function Button({ children }: ButtonProps) { return <button>{children}</button>; } // 不必 function Button({ children }: ButtonProps): JSX.Element { return <button>{children}</button>; } // 3. 导出 Props 类型供其他组件使用 export interface ButtonProps { variant?: 'primary' | 'secondary'; size?: 'sm' | 'md' | 'lg'; children: ReactNode; } export function Button({ variant = 'primary', size = 'md', children }: ButtonProps) { return ( <button className={`btn-${variant} btn-${size}`}> {children} </button> ); } // 其他文件导入 import Button, { ButtonProps } from './Button'; // 4. 使用联合类型实现变体 type ButtonVariant = 'primary' | 'secondary' | 'danger'; interface ButtonProps { variant?: ButtonVariant; } // 或使用 const assertion const VARIANTS = ['primary', 'secondary', 'danger'] as const; type ButtonVariant = typeof VARIANTS[number];

📝 本节小结

✅
  • • 推荐直接定义函数类型而非使用 FC
  • • 使用 interface 定义 Props
  • • ReactNode 允许返回 null/undefined
  • • 导出 Props 类型供其他组件复用
