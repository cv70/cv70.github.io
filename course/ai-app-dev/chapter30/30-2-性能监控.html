什么是性能监控？

性能监控是实时收集、分析和展示应用性能指标的过程。对于AI应用，除了常规的系统指标外，还需要监控GPU利用率、模型推理延迟、预测准确率等AI特有指标。

📊 关键监控指标

类别 指标 说明
系统资源 CPU/内存使用率 基础资源消耗
GPU资源 GPU利用率/显存 GPU计算和存储使用
服务性能 QPS/延迟/P99 请求处理能力
模型性能 推理时间/准确率 模型效果和效率
业务指标 预测分布/错误率 业务层面表现

# 使用DCGM Exporter监控GPU

  -p 9400:9400 \
  nvcr.io/nvidia/k8s/dcgm-exporter:3.1.7-3.1.4-ubuntu20.04

# 关键GPU指标
# DCGM_FI_DEV_GPU_UTIL        - GPU利用率
# DCGM_FI_DEV_MEM_COPY_UTIL   - 内存带宽利用率
# DCGM_FI_DEV_FB_FREE         - 空闲显存
# DCGM_FI_DEV_FB_USED         - 已用显存
# DCGM_FI_DEV_GPU_TEMP        - GPU温度
# DCGM_FI_DEV_POWER_USAGE     - 功耗

# Python中获取GPU指标
import pynvml

def get_gpu_metrics():
    pynvml.nvmlInit()
    handle = pynvml.nvmlDeviceGetHandleByIndex(0)

    return {
        'utilization': pynvml.nvmlDeviceGetUtilizationRates(handle).gpu,
        'memory_used': pynvml.nvmlDeviceGetMemoryInfo(handle).used,
        'temperature': pynvml.nvmlDeviceGetTemperature(handle, 0),
        'power': pynvml.nvmlDeviceGetPowerUsage(handle) / 1000
    }

🔍 分布式追踪

# 使用OpenTelemetry进行分布式追踪
from opentelemetry import trace
from opentelemetry.sdk.trace import TracerProvider
from opentelemetry.exporter.jaeger import JaegerExporter

# 配置追踪
trace.set_tracer_provider(TracerProvider())
tracer = trace.get_tracer(__name__)

jaeger_exporter = JaegerExporter(
    agent_host_name="jaeger",
    agent_port=6831,
)
trace.get_tracer_provider().add_span_processor(
    BatchSpanProcessor(jaeger_exporter)
)

# AI推理追踪
def inference_with_tracing(input_data):
    with tracer.start_as_current_span("inference") as span:
        span.set_attribute("model.name", "gpt-model")
        span.set_attribute("input.shape", str(input_data.shape))

        with tracer.start_as_current_span("preprocessing"):
            processed = preprocess(input_data)

        with tracer.start_as_current_span("model_forward"):
            output = model(processed)

        span.set_attribute("output.confidence", output.confidence)
        return output

监控最佳实践

建立RED指标（Rate请求率、Errors错误率、Duration延迟）作为服务健康的核心指标。对于AI服务，建议增加模型性能指标（准确率、漂移检测）。
