52.7 看门狗设计

常用外设接口设计

🎯 学习目标

  • 掌握看门狗的基本原理与作用
  • 理解独立看门狗和窗口看门狗的区别
  • 学会看门狗模块的硬件设计
  • 了解看门狗的应用场景与配置

📚 看门狗概述

看门狗（Watchdog Timer, WDT）是一种用于监控系统运行状态的定时器。当系统正常运行时，软件会定期"喂狗"（重置看门狗）；如果系统出现故障（如死锁、程序跑飞），软件无法及时喂狗，看门狗将超时并触发系统复位，从而恢复系统正常运行。

💡
看门狗特点

• 独立运行：通常使用独立时钟源
• 可配置超时时间：适应不同应用需求
• 多种触发方式：复位、中断、NMI等
• 安全可靠：提高系统鲁棒性

📊 看门狗分类

类型特点时钟源应用场景
独立看门狗（IWDG）独立于主时钟，可配置超时时间内部低速RC振荡器防止主程序死锁
窗口看门狗（WWDG）必须在窗口期内喂狗APB总线时钟检测程序执行速度异常
外部看门狗独立芯片，硬件级别监控外部晶振高可靠性系统
软件看门狗纯软件实现系统时钟辅助监控

🔄 看门狗工作原理

基本工作流程

1. 初始化：配置看门狗超时时间、使能看门狗

2. 倒计时：看门狗开始递减计数

3. 喂狗：软件在超时前重置计数器

4. 正常情况：定期喂狗，系统正常运行

5. 异常情况：未能及时喂狗，触发复位

⚙️ 独立看门狗模块设计

// 独立看门狗模块
module iwdg #(
    parameter COUNTER_WIDTH = 12,    // 计数器位宽
    parameter PRESCALER_WIDTH = 3,   // 预分频位宽
    parameter LSI_FREQ = 32000       // LSI时钟频率(Hz)
) (
    input  wire                          clk,
    input  wire                          rst_n,

    // 控制接口
    input  wire                          write_enable,   // 写使能
    input  wire [4:0]                    reg_addr,       // 寄存器地址
    input  wire [31:0]                   reg_wdata,      // 写数据
    output wire [31:0]                   reg_rdata,      // 读数据

    // 信号输出
    output wire                          reset_out,      // 复位输出
    output wire                          interrupt_out,  // 中断输出
    output wire                          counter_value   // 计数器值（用于调试）
);

    // 寄存器定义
    reg [PRESCALER_WIDTH-1:0] prescaler;   // 预分频器
    reg [COUNTER_WIDTH-1:0] reload_reg;    // 重装载值
    reg [COUNTER_WIDTH-1:0] counter;       // 计数器
    reg iwdg_enable;          // 看门狗使能
    reg reset_enable;         // 复位使能
    reg interrupt_enable;     // 中断使能
    reg [1:0] window_config;  // 窗口配置

    // 状态标志
    reg timeout_flag;         // 超时标志
    reg prescaler_update;     // 预分频更新标志
    reg reload_update;        // 重装载更新标志

    // 预分频计数器
    reg [15:0] prescaler_cnt;
    localparam PRESCALER_DIV = 1 << prescaler;
    wire prescaler_tick = (prescaler_cnt == 0);

    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            prescaler_cnt <= 0;
            prescaler <= 0;
            reload_reg <= 12'hFFF;
            counter <= 0;
            iwdg_enable <= 0;
            reset_enable <= 1;
            interrupt_enable <= 0;
            timeout_flag <= 0;
            prescaler_update <= 0;
            reload_update <= 0;
        end else begin
            prescaler_update <= 0;
            reload_update <= 0;

            // 寄存器写操作
            if (write_enable) begin
                case (reg_addr)
                    5'h0: begin  // 控制寄存器
                        if (reg_wdata[0] && !iwdg_enable) begin
                            iwdg_enable <= 1;
                            counter <= reload_reg;
                        end
                        if (reg_wdata[1]) reset_enable <= reg_wdata[1];
                        if (reg_wdata[2]) interrupt_enable <= reg_wdata[2];
                    end
                    5'h1: begin  // 预分频寄存器
                        if (!iwdg_enable) begin
                            prescaler <= reg_wdata[PRESCALER_WIDTH-1:0];
                            prescaler_update <= 1;
                        end
                    end
                    5'h2: begin  // 重装载寄存器
                        if (!iwdg_enable) begin
                            reload_reg <= reg_wdata[COUNTER_WIDTH-1:0];
                            reload_update <= 1;
                        end
                    end
                    5'h3: begin  // 喂狗寄存器（键值）
                        if (reg_wdata == 32'hAAAA && iwdg_enable) begin
                            counter <= reload_reg;  // 喂狗
                            timeout_flag <= 0;
                        end
                    end
                endcase
            end

            // 预分频器
            if (prescaler_tick) begin
                prescaler_cnt <= PRESCALER_DIV - 1;
            end else begin
                prescaler_cnt <= prescaler_cnt - 1;
            end

            // 计数器
            if (iwdg_enable && prescaler_tick) begin
                if (counter > 0) begin
                    counter <= counter - 1;
                end else begin
                    counter <= reload_reg;
                    timeout_flag <= 1;  // 超时
                end
            end
        end
    end

    // 输出
    assign reset_out = reset_enable && timeout_flag;
    assign interrupt_out = interrupt_enable && timeout_flag;
    assign counter_value = counter;

    // 寄存器读操作
    reg [31:0] rdata;
    always @(*) begin
        rdata = 32'h0;
        case (reg_addr)
            5'h0: rdata = {28'h0, interrupt_enable, reset_enable, iwdg_enable};
            5'h1: rdata = {{32-PRESCALER_WIDTH{1'b0}}, prescaler};
            5'h2: rdata = {{32-COUNTER_WIDTH{1'b0}}, reload_reg};
            5'h3: rdata = 32'h0;  // 喂狗寄存器写保护
            5'h4: rdata = {{32-COUNTER_WIDTH{1'b0}}, counter};
            5'h5: rdata = {31'h0, timeout_flag};
            5'h6: rdata = {31'h0, prescaler_update};
            5'h7: rdata = {31'h0, reload_update};
            default: rdata = 32'h0;
        endcase
    end

    assign reg_rdata = rdata;

endmodule

🪟 窗口看门狗设计

窗口看门狗原理

窗口看门狗要求喂狗操作必须在指定的时间窗口内进行：

• 下窗口：计数器值必须大于下窗口值才能喂狗

• 上窗口：计数器值必须小于上窗口值才能喂狗

• 作用：防止程序运行过快或过慢，检测程序执行异常

🔧 窗口看门狗模块设计

// 窗口看门狗模块
module wwdg #(
    parameter COUNTER_WIDTH = 7,     // 计数器位宽
    parameter WINDOW_WIDTH = 7,      // 窗口值位宽
    parameter PCLK_FREQ = 50_000_000 // APB时钟频率
) (
    input  wire                          clk,
    input  wire                          rst_n,

    // 控制接口
    input  wire                          write_enable,   // 写使能
    input  wire [4:0]                    reg_addr,       // 寄存器地址
    input  wire [31:0]                   reg_wdata,      // 写数据
    output wire [31:0]                   reg_rdata,      // 读数据

    // 信号输出
    output wire                          reset_out,      // 复位输出
    output wire                          early_wakeup    // 早期唤醒中断
);

    // 寄存器定义
    reg [COUNTER_WIDTH-1:0] counter;       // 计数器
    reg [WINDOW_WIDTH-1:0] window_reg;     // 窗口值
    reg wwdg_enable;          // 看门狗使能
    reg [3:0] prescaler;       // 预分频器

    // 状态标志
    reg timeout_flag;
    reg window_violation;

    // 预分频器
    reg [15:0] prescaler_cnt;
    localparam PRESCALER_DIV = 1 << prescaler;
    wire prescaler_tick = (prescaler_cnt == 0);

    // 计数器递减
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            counter <= 0;
            window_reg <= 7'h7F;
            wwdg_enable <= 0;
            prescaler <= 0;
            timeout_flag <= 0;
            window_violation <= 0;
            prescaler_cnt <= 0;
        end else begin
            // 寄存器写操作
            if (write_enable) begin
                case (reg_addr)
                    5'h0: begin  // 控制寄存器
                        wwdg_enable <= reg_wdata[7];
                        prescaler <= reg_wdata[3:0];
                    end
                    5'h1: begin  // 配置寄存器
                        window_reg <= reg_wdata[WINDOW_WIDTH-1:0];
                    end
                    5'h2: begin  // 喂狗寄存器
                        if (reg_wdata == 32'h55) begin  // 解锁
                            // 允许配置
                        end
                    end
                    5'h3: begin  // 刷新寄存器（喂狗）
                        if (reg_wdata == 32'hAA && wwdg_enable) begin
                            // 检查窗口
                            if (counter >= window_reg && counter < {1'b1, {COUNTER_WIDTH-1{1'b1}}}) begin
                                // 在窗口内，喂狗成功
                                counter <= {1'b1, {COUNTER_WIDTH-1{1'b1}}};
                                timeout_flag <= 0;
                                window_violation <= 0;
                            end else begin
                                // 窗口违规
                                window_violation <= 1;
                            end
                        end
                    end
                endcase
            end

            // 预分频器
            if (prescaler_tick) begin
                prescaler_cnt <= PRESCALER_DIV - 1;
            end else begin
                prescaler_cnt <= prescaler_cnt - 1;
            end

            // 计数器
            if (wwdg_enable && prescaler_tick) begin
                if (counter > 0) begin
                    counter <= counter - 1;
                end else begin
                    counter <= {1'b1, {COUNTER_WIDTH-1{1'b1}}};
                    timeout_flag <= 1;  // 超时
                end
            end
        end
    end

    // 输出
    assign reset_out = wwdg_enable && (timeout_flag || window_violation);
    assign early_wakeup = wwdg_enable && (counter == window_reg);

    // 寄存器读操作
    reg [31:0] rdata;
    always @(*) begin
        rdata = 32'h0;
        case (reg_addr)
            5'h0: rdata = {24'h0, prescaler, 3'h0, wwdg_enable};
            5'h1: rdata = {{32-WINDOW_WIDTH{1'b0}}, window_reg};
            5'h2: rdata = 32'h0;
            5'h3: rdata = 32'h0;
            5'h4: rdata = {{32-COUNTER_WIDTH{1'b0}}, counter};
            5'h5: rdata = {30'h0, window_violation, timeout_flag};
            default: rdata = 32'h0;
        endcase
    end

    assign reg_rdata = rdata;

endmodule

🛡️ 看门狗安全特性

写保护

防止意外关闭或修改看门狗：

• 需要特定序列解锁才能写寄存器
• 防止程序错误导致看门狗失效
• 提高系统安全性

独立时钟

使用独立时钟源提高可靠性：

• 不受主时钟故障影响
• 即使主时钟停止仍能工作
• LSI振荡器通常为32kHz

硬件复位

超时后触发硬件复位：

• 直接复位CPU和外设
• 不依赖软件响应
• 确保系统能够恢复

调试保护

调试模式下仍能工作：

• 可配置调试时是否暂停
• 确保调试时系统安全
• 防止调试掩盖问题

📊 超时时间计算

独立看门狗超时时间

Timeout = (Reload + 1) × Prescaler × (1 / LSI_FREQ)

例如：LSI=32kHz, Prescaler=256, Reload=4095

Timeout = (4095+1) × 256 × (1/32000) = 32.768秒

窗口看门狗超时时间

Timeout = (2^COUNTER_WIDTH) × Prescaler × (1 / PCLK_FREQ)

例如：PCLK=50MHz, Prescaler=8, COUNTER_WIDTH=7

Timeout = 128 × 8 × (1/50000000) = 20.48μs

🐛 常见问题与调试

⚠️
常见问题

1. 频繁复位
症状：系统不断复位
解决：增加超时时间，优化喂狗策略

2. 无法喂狗
症状：喂狗操作无效
解决：检查解锁序列，确认寄存器写入正确

3. 窗口违规
症状：窗口看门狗误触发
解决：调整窗口值，优化喂狗时机

4. 调试时复位
症状：断点调试时系统复位
解决：配置调试模式下暂停看门狗
