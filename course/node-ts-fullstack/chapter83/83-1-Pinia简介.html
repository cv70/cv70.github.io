83.1 Pinia 简介

Vue 3 官方推荐的状态管理库

📖 本节概述

Pinia 是 Vue 3 的官方状态管理库，它提供了更简洁的 API、更好的 TypeScript 支持和更小的打包体积。相比 Vuex，Pinia 更加灵活、易用，是 Vue 3 应用的首选状态管理方案。

🎯 学习目标

  • 了解 Pinia 的特点和优势
  • 理解 Pinia 与 Vuex 的区别
  • 掌握 Pinia 的安装和配置
  • 了解 Pinia 的核心概念

🌟 Pinia 特点

主要优势

// Pinia 的主要特点： // 1. 更简洁的 API // - 没有 mutations // - 直接修改 state 或通过 actions // 2. 原生 TypeScript 支持 // - 完整的类型推断 // - 无需额外类型定义 // 3. 模块化设计 // - 每个 store 都是独立的 // - 无需嵌套模块 // 4. 支持多个 Store // - 可以创建任意数量的 store // - 每个 store 独立管理自己的状态 // 5. 更小的体积 // - 约 1KB gzipped // 6. 支持 Vue 2 和 Vue 3 // - 统一的 API // 7. 支持开发工具 // - Vue DevTools 集成 // - 时间旅行调试 // 8. 支持插件扩展 // - 持久化 // - 状态快照

📊 Pinia vs Vuex

特性 Pinia Vuex
Mutations 无 必需
模块化 独立 Store 嵌套模块
TypeScript 原生支持 需要额外配置
体积 约 1KB 约 3KB
DevTools 支持 支持
状态修改 直接修改或 Actions 必须通过 Mutations
Composition API 原生支持 需要 useStore

📦 安装 Pinia

# 使用 npm npm install pinia # 使用 yarn yarn add pinia # 使用 pnpm pnpm add pinia

配置 Pinia

// main.ts import { createApp } from 'vue'; import { createPinia } from 'pinia'; import App from './App.vue'; const app = createApp(App); // 创建 Pinia 实例 const pinia = createPinia(); // 使用 Pinia app.use(pinia); app.mount('#app'); // 如果使用 Vue Router，确保在挂载应用前安装 Pinia import router from './router'; app.use(router);

🏗️ 核心概念

Store

Store 是保存状态和业务逻辑的实体，类似于组件但独立于组件存在。

// stores/counter.ts import { defineStore } from 'pinia'; // 定义 Store（使用 composition API 风格） export const useCounterStore = defineStore('counter', () => { // State const count = ref(0); // Getter const doubleCount = computed(() => count.value * 2); // Action function increment() { count.value++; } return { count, doubleCount, increment }; }); // 定义 Store（使用 options API 风格） export const useCounterStore = defineStore('counter', { // State state: () => ({ count: 0 }), // Getters getters: { doubleCount: (state) => state.count * 2 }, // Actions actions: { increment() { this.count++; } } });

三个核心部分

概念 说明 类比组件
State 存储数据 data
Getters 计算属性 computed
Actions 方法（可异步） methods

🔧 使用 Store

import { useCounterStore } from '@/stores/counter'; // 在组件中使用 const counterStore = useCounterStore(); // 访问 state console.log(counterStore.count); // 访问 getter console.log(counterStore.doubleCount); // 调用 action counterStore.increment(); // 直接修改 state counterStore.count++; // 批量修改 state counterStore.$patch({ count: 10 }); // 使用函数批量修改 counterStore.$patch((state) => { state.count = 10; });

📂 Store 组织方式

src/ ├── stores/ │ ├── index.ts // 导出所有 store │ ├── counter.ts // counter store │ ├── user.ts // user store │ └── products.ts // products store └── main.ts // stores/index.ts export { useCounterStore } from './counter'; export { useUserStore } from './user'; export { useProductsStore } from './products'; // 使用时 import { useCounterStore, useUserStore } from '@/stores';

📝 本节小结

  • Pinia 是 Vue 3 官方推荐的状态管理库
  • 比 Vuex 更简洁、更轻量、更好的 TypeScript 支持
  • 没有 mutations，直接修改 state 或通过 actions
  • 每个 Store 独立管理自己的状态
  • 支持 Composition API 和 Options API 两种风格
