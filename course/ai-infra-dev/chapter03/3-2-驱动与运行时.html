CUDA概述

CUDA（Compute Unified Device Architecture）是NVIDIA开发的并行计算平台和编程模型，允许开发者利用NVIDIA GPU进行通用计算（GPGPU）。CUDA是深度学习框架的基础，所有主流AI框架都通过CUDA调用GPU计算能力。

🏗️ CUDA编程模型

线程层次结构

CUDA采用层次化的线程组织结构，从单个线程到整个网格：

CUDA线程层次： Grid (线程网格) └─ Block (线程块) └─ Thread (线程) 实际配置示例： • Grid: (2, 1, 1) - 2个Block • Block: (256, 1, 1) - 每个Block 256个线程 • Total: 2 × 256 = 512个线程 内存层次： • Thread Local - 线程私有 • Shared Memory - Block内共享 • Global Memory - 所有线程共享 • Constant/Texture Memory - 只读

⚙️ CUDA运行时API

核心API

CUDA运行时提供丰富的API用于内存管理、kernel启动和设备控制：

类别 API函数 功能
设备管理 cudaGetDeviceCount() 获取GPU数量
内存分配 cudaMalloc() 分配GPU内存
内存传输 cudaMemcpy() 主机与设备间数据传输
Kernel启动 <<<BLOCK, THREAD>>> 启动GPU kernel
同步 cudaDeviceSynchronize() 等待GPU完成
错误检查 cudaGetErrorString() 获取错误信息
CUDA编程示例： #include __global__ void vectorAdd(float *A, float *B, float *C, int n) { int idx = blockIdx.x * blockDim.x + threadIdx.x; if (idx < n) { C[idx] = A[idx] + B[idx]; } } int main() { int n = 1024 * 1024; float *d_A, *d_B, *d_C; // 分配GPU内存 cudaMalloc(&d_A, n * sizeof(float)); cudaMalloc(&d_B, n * sizeof(float)); cudaMalloc(&d_C, n * sizeof(float)); // 启动kernel int blockSize = 256; int numBlocks = (n + blockSize - 1) / blockSize; vectorAdd<<>>(d_A, d_B, d_C, n); // 同步并检查错误 cudaDeviceSynchronize(); cudaError_t error = cudaGetLastError(); // ... 处理错误 }

🔧 CUDA驱动安装

安装步骤

Ubuntu安装CUDA： # 1. 禁用nouveau驱动 sudo bash -c "echo blacklist nouveau > /etc/modprobe.d/blacklist-nvidia-nouveau.conf" sudo bash -c "echo options nouveau modeset=0 >> /etc/modprobe.d/blacklist-nvidia-nouveau.conf" sudo update-initramfs -u sudo reboot # 2. 安装NVIDIA驱动 sudo apt update sudo apt install nvidia-driver-535 # 3. 下载并安装CUDA Toolkit wget https://developer.download.nvidia.com/compute/cuda/12.1.0/local_installers/cuda_12.1.0_530.30.02_linux.run sudo sh cuda_12.1.0_530.30.02_linux.run # 4. 配置环境变量 echo 'export PATH=/usr/local/cuda-12.1/bin:$PATH' >> ~/.bashrc echo 'export LD_LIBRARY_PATH=/usr/local/cuda-12.1/lib64:$LD_LIBRARY_PATH' >> ~/.bashrc source ~/.bashrc # 5. 验证安装 nvidia-smi nvcc --version Docker环境安装： # 使用官方CUDA镜像 docker pull nvidia/cuda:12.1.0-runtime-ubuntu22.04 docker run --gpus all nvidia/cuda:12.1.0-runtime-ubuntu22.04 nvidia-smi

🌊 ROCm平台

AMD开源计算平台

ROCm（Radeon Open Compute）是AMD开发的开放GPU计算平台，类似于CUDA，支持AMD GPU进行通用计算：

ROCm特性

  • 开源软件栈
  • 类似CUDA的编程模型
  • HIP移植层兼容CUDA
  • 支持主流深度学习框架

与CUDA的对比

  • CUDA生态更成熟
  • ROCm更开放
  • CUDA性能更好
  • ROCm成本更低
HIP编程示例（类似CUDA）： __global__ void vectorAdd(float *A, float *B, float *C, int n) { int idx = blockIdx.x * blockDim.x + threadIdx.x; if (idx < n) { C[idx] = A[idx] + B[idx]; } } // 启动kernel int blockSize = 256; int numBlocks = (n + blockSize - 1) / blockSize; hipLaunchKernelGGL(vectorAdd, numBlocks, blockSize, 0, 0, d_A, d_B, d_C, n);
