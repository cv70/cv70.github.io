Argo Workflows简介

Argo Workflows是Kubernetes原生的容器工作流引擎。 它通过Kubernetes CRD定义工作流，提供强大的编排能力，是运行批处理和ML任务的理想选择。

🏗️ 核心概念

Workflow

工作流定义。

  • DAG结构
  • 步骤定义
  • 参数传递
  • 生命周期管理

Template

可复用模板。

  • 容器定义
  • 脚本模板
  • 资源模板
  • 参数化

Step

工作流步骤。

  • 串行执行
  • 并行执行
  • 依赖关系
  • 输出捕获

📦 安装Argo Workflows

使用Helm安装

# 添加Argo仓库 helm repo add argo https://argoproj.github.io/argo-helm helm repo update # 创建命名空间 kubectl create namespace argo # 安装Argo Workflows helm install argo-workflows argo/argo-workflows \ --namespace argo \ --version 0.21.1 \ --set server.serviceType=LoadBalancer \ --set workflow.serviceAccount.create=true \ --set controller.workflowNamespaces=argo,default # 验证安装 kubectl get pods -n argo kubectl get svc -n argo # 获取访问URL kubectl get svc argo-workflows-server -n argo

使用CLI安装

# 安装Argo CLI curl -sLO https://github.com/argoproj/argo-workflows/releases/download/v3.4.8/argo-linux-amd64 chmod +x argo-linux-amd64 sudo mv ./argo-linux-amd64 /usr/local/bin/argo # 安装Argo到Kubernetes kubectl create namespace argo kubectl apply -n argo -f https://github.com/argoproj/argo-workflows/releases/download/v3.4.8/quick-start-static.yaml # 验证安装 argo version

配置CLI

# 配置Argo CLI访问 argo server # 或设置上下文 argo cluster set argo-server \ --server https://localhost:2746 # 列出工作流 argo list
💡
安装选项
  • • Standalone：单命名空间安装
  • • Multi-namespace：跨命名空间管理
  • • Helm：灵活配置，生产推荐

🔧 编写Workflow

基础Workflow

apiVersion: argoproj.io/v1alpha1 kind: Workflow metadata: generateName: training-workflow- namespace: argo spec: entrypoint: training-pipeline templates: - name: training-pipeline steps: - - name: load-data template: load-data - name: train-model template: train-model - name: load-data container: image: python:3.9 command: ["python"] args: ["-c", "print('Loading data...')"] - name: train-model container: image: pytorch/pytorch:2.0.0-cuda11.7-cudnn8-runtime command: ["python"] args: ["-c", "print('Training model...')"] resources: limits: nvidia.com/gpu: 1

参数化Workflow

apiVersion: argoproj.io/v1alpha1 kind: Workflow metadata: generateName: param-workflow- spec: entrypoint: training-pipeline arguments: parameters: - name: learning-rate value: "0.001" - name: batch-size value: "32" - name: epochs value: "100" templates: - name: training-pipeline inputs: parameters: - name: learning-rate - name: batch-size - name: epochs steps: - - name: train template: train arguments: parameters: - name: learning-rate value: "{{inputs.parameters.learning-rate}}" - name: batch-size value: "{{inputs.parameters.batch-size}}" - name: epochs value: "{{inputs.parameters.epochs}}" - name: train inputs: parameters: - name: learning-rate - name: batch-size - name: epochs container: image: pytorch/pytorch:2.0.0-cuda11.7-cudnn8-runtime command: ["python", "train.py"] args: [ "--learning-rate", "{{inputs.parameters.learning-rate}}", "--batch-size", "{{inputs.parameters.batch-size}}", "--epochs", "{{inputs.parameters.epochs}}" ]

提交Workflow

# 提交Workflow kubectl create -f workflow.yaml # 或使用Argo CLI argo submit workflow.yaml # 查看运行状态 argo list # 查看Workflow详情 argo get # 查看日志 argo logs argo logs -f # 跟踪日志

🔄 高级特性

DAG工作流

apiVersion: argoproj.io/v1alpha1 kind: Workflow metadata: generateName: dag-workflow- spec: entrypoint: dag-diamond templates: - name: dag-diamond dag: tasks: - name: A template: task-template - name: B depends: A template: task-template - name: C depends: A template: task-template - name: D depends: B and C template: task-template - name: task-template container: image: alpine:3.17 command: ["echo"] args: ["{{inputs.parameters.message}}"]

条件执行

apiVersion: argoproj.io/v1alpha1 kind: Workflow metadata: generateName: conditional-workflow- spec: entrypoint: conditional-pipeline templates: - name: conditional-pipeline steps: - - name: evaluate template: evaluate - - name: deploy template: deploy when: "{{steps.evaluate.outputs.result}} == 0.95" - name: retrain template: retrain when: "{{steps.evaluate.outputs.result}} < 0.95" - name: evaluate container: image: python:3.9 command: ["python"] args: ["-c", "print(0.95)"] - name: deploy container: image: python:3.9 command: ["python"] args: ["-c", "print('Deploying...')"] - name: retrain container: image: python:3.9 command: ["python"] args: ["-c", "print('Retraining...')"]

循环执行

apiVersion: argoproj.io/v1alpha1 kind: Workflow metadata: generateName: loop-workflow- spec: entrypoint: loop-pipeline templates: - name: loop-pipeline steps: - - name: train-folds template: train-fold arguments: parameters: - name: fold value: "{{item}}" withItems: - 0 - 1 - 2 - 3 - 4 - - name: aggregate template: aggregate arguments: parameters: - name: models value: "{{steps.train-folds.outputs.result}}" - name: train-fold inputs: parameters: - name: fold container: image: python:3.9 command: ["python"] args: ["train.py", "--fold", "{{inputs.parameters.fold}}"]

💾 Artifact管理

输入输出Artifact

apiVersion: argoproj.io/v1alpha1 kind: Workflow metadata: generateName: artifact-workflow- spec: entrypoint: artifact-pipeline templates: - name: artifact-pipeline steps: - - name: generate-data template: generate-data - - name: train-model template: train-model arguments: artifacts: - name: input-data from: "{{steps.generate-data.outputs.artifacts.output-data}}" - name: generate-data outputs: artifacts: - name: output-data path: /tmp/data.csv container: image: python:3.9 command: ["python"] args: ["-c", "import pandas as pd; pd.DataFrame({'a': [1,2,3]}).to_csv('/tmp/data.csv')"] - name: train-model inputs: artifacts: - name: input-data path: /tmp/data.csv container: image: python:3.9 command: ["python"] args: ["-c", "print('Training with data...')"]

Artifact存储

# 使用S3作为Artifact存储 apiVersion: argoproj.io/v1alpha1 kind: ConfigMap metadata: name: workflow-controller-configmap data: artifactRepository: | s3: bucket: argo-artifacts endpoint: s3.amazonaws.com insecure: false accessKeySecret: name: s3-credentials key: accessKey secretKeySecret: name: s3-credentials key: secretKey

🔍 监控与调试

查看运行状态

# 列出所有Workflow argo list # 查看特定Workflow argo get # 查看Workflow YAML argo get -o yaml # 查看Workflow图 argo get --graph

查看日志

# 查看所有日志 argo logs # 查看特定步骤日志 argo logs -c step-name # 跟踪日志 argo logs -f # 查看最近的日志 argo logs --tail=100

调试选项

# 保留失败的Pod用于调试 spec: podGC: strategy: OnPodCompletion # options: OnPodCompletion, OnPodSuccess, OnWorkflowCompletion, OnWorkflowSuccess # 设置重试策略 spec: retryStrategy: limit: 3 retryPolicy: OnError # Always, OnError, OnFailure # 设置超时 spec: activeDeadlineSeconds: 3600 # 1小时
