💻 税费计算

交易税费示例

# A股交易税费计算

def calculate_china_stock_tax(trade_amount, buy=True):
    """计算A股交易税费"""
    # 印花税（仅卖出时收取）
    stamp_duty = 0.0005 if not buy else 0
    
    # 佣金（双向收取）
    commission = trade_amount * 0.0003
    commission = max(commission, 5)  # 最低5元
    
    # 过户费（双向收取）
    transfer_fee = trade_amount * 0.00001
    
    total_tax = stamp_duty + commission + transfer_fee
    return total_tax

# 示例
trade_amount = 100000  # 交易金额
buy_tax = calculate_china_stock_tax(trade_amount, buy=True)
sell_tax = calculate_china_stock_tax(trade_amount, buy=False)
print(f"买入税费: ¥{buy_tax:.2f}")
print(f"卖出税费: ¥{sell_tax:.2f}")

实践建议

不同市场税收政策差异很大，务必了解目标市场的税收规则。A股持有股票超过1年股息红利免征个人所得税。合理利用税收优惠政策可以降低交易成本。
