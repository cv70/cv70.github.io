12.5 npm 包管理

掌握 npm 包管理器的使用

🎯 学习目标

  • 掌握 npm 常用命令
  • 学会安装和管理依赖
  • 了解 package-lock.json 的作用
  • 掌握发布 npm 包的流程

📚 初始化与安装

# 初始化项目 npm init # 交互式创建 package.json npm init -y # 使用默认值快速创建 # 安装依赖 npm install # 安装所有依赖 npm install express # 安装到 dependencies npm install --save-dev nodemon # 安装到 devDependencies npm install -D typescript # 简写 -D # 全局安装 npm install -g nodemon npm install -g pm2 # 安装特定版本 npm install express@4.18.2 npm install express@latest npm install express@next # 下一版本 # 更新依赖 npm update # 更新所有依赖 npm update express # 更新指定依赖 npm outdated # 查看过时依赖

🔧 常用命令

# 查看信息 npm list # 查看已安装依赖 npm list --depth=0 # 只显示顶层依赖 npm list -g --depth=0 # 全局安装的包 npm view express # 查看包信息 npm view express versions # 查看所有版本 npm view express dependencies # 查看依赖 # 卸载依赖 npm uninstall express npm uninstall -D nodemon npm uninstall -g pm2 # 清理缓存 npm cache clean --force # 审计安全漏洞 npm audit # 检查漏洞 npm audit fix # 自动修复 # 检查依赖树 npm ls express npm dedupe # 减少重复依赖

📦 package-lock.json

// package-lock.json 的作用： // 1. 锁定依赖版本树 // 2. 保证团队开发依赖一致 // 3. 加快 npm install 速度 // package.json { "dependencies": { "express": "^4.18.0" // 范围版本 } } // package-lock.json 锁定具体版本 { "name": "my-project", "lockfileVersion": 3, "requires": true, "packages": { "node_modules/express": { "version": "4.18.2", // 锁定的精确版本 "resolved": "https://registry.npmjs.org/express/-/express-4.18.2.tgz", "integrity": "sha512-..." } } } // 重要：package-lock.json 必须提交到版本控制
⚠️
注意

package-lock.json 确保所有环境安装完全相同版本的依赖，必须提交到 Git。

🚀 发布 npm 包

# 1. 注册 npm 账号 # https://www.npmjs.com/ # 2. 登录 npm login # Username: your-username # Password: your-password # Email: your-email # 3. 检查包名是否可用 npm search my-package-name # 4. 发布 npm publish # 发布到指定作用域 npm publish --access public # 5. 版本更新 npm version patch # 1.0.0 -> 1.0.1 npm version minor # 1.0.0 -> 1.1.0 npm version major # 1.0.0 -> 2.0.0 # 6. 发布新版本 npm publish # 7. 取消发布（慎用） npm unpublish my-package@1.0.0 npm unpublish my-package --force # 8. 废弃版本 npm deprecate my-package@1.0.0 "此版本有严重 bug"

🔄 npm vs yarn vs pnpm

💡
操作 npm yarn pnpm
安装依赖 npm install yarn pnpm install
添加依赖 npm i pkg yarn add pkg pnpm add pkg
运行脚本 npm run dev yarn dev pnpm dev

📝 本节小结

✅
  • • npm install 安装依赖，-D 安装开发依赖
  • • package-lock.json 锁定版本，必须提交
  • • npm publish 发布包，npm version 更新版本
  • • yarn 和 pnpm 是 npm 的替代方案
