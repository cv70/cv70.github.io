103.2 ELK Stack

使用 ELK Stack 构建企业级日志平台

🎯 学习目标

  • 理解 ELK Stack 的组件与架构
  • 掌握 Elasticsearch 数据存储
  • 学会使用 Logstash 收集日志
  • 掌握 Kibana 可视化分析

什么是 ELK Stack

ELK Stack 是三个开源项目的首字母缩写：Elasticsearch、Logstash 和 Kibana。 它是业界最流行的日志分析平台，用于收集、存储、分析和可视化日志数据。

🏗️ ELK 架构组成

🔍

Elasticsearch

分布式搜索引擎，负责日志存储和检索

📊

Logstash

数据处理管道，负责日志收集和转换

📈

Kibana

可视化平台，负责日志展示和分析

🔄 数据流转架构

🐳 Docker Compose 部署

# docker-compose.yml version: '3.8' services: elasticsearch: image: docker.elastic.co/elasticsearch/elasticsearch:8.11.0 container_name: elasticsearch environment: - discovery.type=single-node - xpack.security.enabled=false - "ES_JAVA_OPTS=-Xms512m -Xmx512m" ports: - "9200:9200" volumes: - es_data:/usr/share/elasticsearch/data networks: - elk logstash: image: docker.elastic.co/logstash/logstash:8.11.0 container_name: logstash volumes: - ./logstash/pipeline:/usr/share/logstash/pipeline - ./logstash/config:/usr/share/logstash/config ports: - "5044:5044" depends_on: - elasticsearch networks: - elk kibana: image: docker.elastic.co/kibana/kibana:8.11.0 container_name: kibana environment: - ELASTICSEARCH_HOSTS=http://elasticsearch:9200 ports: - "5601:5601" depends_on: - elasticsearch networks: - elk filebeat: image: docker.elastic.co/beats/filebeat:8.11.0 container_name: filebeat user: root volumes: - ./filebeat/filebeat.yml:/usr/share/filebeat/filebeat.yml:ro - /var/lib/docker/containers:/var/lib/docker/containers:ro - /var/run/docker.sock:/var/run/docker.sock:ro depends_on: - logstash networks: - elk volumes: es_data: networks: elk: driver: bridge

📁 Logstash 配置

# logstash/pipeline/logstash.conf input { beats { port => 5044 } } filter { # 解析 JSON 日志 if [message] =~ /^\{/ { json { source => "message" target => "parsed" } } # 提取时间戳 date { match => ["timestamp", "YYYY-MM-DD HH:mm:ss", "ISO8601"] target => "@timestamp" } # 添加字段 mutate { add_field => { "log_type" => "application" "environment" => "${ENV:production}" } remove_field => ["message"] if [parsed] } # 错误日志处理 if [level] == "ERROR" or [level] == "FATAL" { mutate { add_tags => ["error", "alert"] } } } output { elasticsearch { hosts => ["elasticsearch:9200"] index => "myapp-logs-%{+YYYY.MM.dd}" } # 错误日志同时输出到文件 if "error" in [tags] { file { path => "/var/log/logstash/errors-%{+YYYY-MM-dd}.log" } } }

📄 Filebeat 配置

# filebeat/filebeat.yml filebeat.inputs: - type: log enabled: true paths: - /var/log/myapp/*.log json.keys_under_root: true json.add_error_key: true fields: app: myapp env: production - type: container enabled: true paths: - /var/lib/docker/containers/*/*.log processors: - add_docker_metadata: host: "unix:///var/run/docker.sock" processors: - add_host_metadata: when.not.contains.tags: forwarded - add_cloud_metadata: ~ output.logstash: hosts: ["logstash:5044"] logging.level: info

💡
ELK Stack 最佳实践
  • 使用 ILM (索引生命周期管理) 自动清理旧数据
  • 配置合理的分片数量，避免过度分片
  • 使用 Filebeat 代替 Logstash 直接收集
  • 为常用查询字段创建索引模板
  • 监控系统资源，Elasticsearch 内存占用较大

📝 本节小结

✅
  • • ELK = Elasticsearch + Logstash + Kibana
  • • Elasticsearch 负责存储和检索
  • • Logstash 负责数据收集和处理
  • • Kibana 提供可视化分析界面
