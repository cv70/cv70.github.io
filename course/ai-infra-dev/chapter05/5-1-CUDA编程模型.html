CUDA编程模型概述

CUDA（Compute Unified Device Architecture）是NVIDIA的并行计算平台和编程模型。它允许开发者使用C/C++等语言编写在GPU上运行的程序，利用GPU的大规模并行能力加速计算。

🧵 线程层次结构

层次化线程组织

CUDA线程层次： Grid (线程网格) └─ Block (线程块) └─ Thread (线程) 示例配置： Grid: (2, 1, 1) // 2个Block Block: (256, 1, 1) // 每个Block 256个线程 Total: 2 × 256 = 512 // 总共512个线程 线程索引计算： int idx = blockIdx.x * blockDim.x + threadIdx.x; int idy = blockIdx.y * blockDim.y + threadIdx.y; int idz = blockIdx.z * blockDim.z + threadIdx.z;
💡
关键概念

Thread是最小执行单元，Block是一组可以协作的线程，Grid是执行同一Kernel的所有Block的集合。

⚙️ Kernel编程

GPU函数

Kernel是在GPU上执行的函数，使用__global__修饰符声明：

基础Kernel示例： #include #include // Kernel函数 __global__ void hello_kernel() { int idx = blockIdx.x * blockDim.x + threadIdx.x; printf("Hello from thread %d, block %d\n", threadIdx.x, blockIdx.x); } // Kernel：向量加法 __global__ void vector_add(float *a, float *b, float *c, int n) { int idx = blockIdx.x * blockDim.x + threadIdx.x; if (idx < n) { c[idx] = a[idx] + b[idx]; } } int main() { int n = 1024; float *d_a, *d_b, *d_c; // 分配GPU内存 cudaMalloc(&d_a, n * sizeof(float)); cudaMalloc(&d_b, n * sizeof(float)); cudaMalloc(&d_c, n * sizeof(float)); // 启动Kernel int blockSize = 256; int numBlocks = (n + blockSize - 1) / blockSize; vector_add<<>>(d_a, d_b, d_c, n); // 同步 cudaDeviceSynchronize(); // 释放内存 cudaFree(d_a); cudaFree(d_b); cudaFree(d_c); return 0; }

💾 内存层次

存储层次结构

CUDA内存层次： 寄存器（Register） └─ 线程私有 └─ 最快访问 └─ 有限数量 共享内存（Shared Memory） └─ Block内共享 └─ 读写速度快 └─ 需要同步 全局内存（Global Memory） └─ 所有线程共享 └─ 容量大但慢 └─ 缓存在L1/L2 常量内存（Constant Memory） └─ 只读内存 └─ 所有线程共享 └─ 缓存优化 纹理内存（Texture Memory） └─ 只读内存 └─ 空间局部性优化
内存类型 访问速度 作用域 大小
寄存器 极快 线程私有 有限
共享内存 快 Block内 48KB (H100)
全局内存 慢 全局 80GB (H100)
常量内存 快 全局 64KB

🔄 Warp执行

SIMT执行模型

CUDA以Warp为单位执行，每个Warp包含32个线程，同时执行相同的指令：

Warp特点

  • 32个线程一组
  • 相同指令并行执行
  • 分支导致分化
  • 隐藏内存延迟

性能影响

  • 分支 divergence
  • 内存合并
  • 同步开销
  • 资源竞争
Warp相关代码： // 获取Warp ID int warp_id = (blockIdx.x * blockDim.x + threadIdx.x) / 32; // 获取Lane ID int lane_id = threadIdx.x & (warpSize - 1); // Warp内归约 __shared__ float shared_data[256]; int idx = threadIdx.x; shared_data[idx] = data[idx]; __syncthreads(); for (int offset = warpSize/2; offset > 0; offset /= 2) { if (lane_id < offset) { shared_data[idx] += shared_data[idx + offset]; } } // 使用warp级本征函数（更快） int value; float warp_sum = __shfl_down_sync(0xffffffff, value, 1);

⚡ 内存管理

CUDA内存API

内存操作API： // 分配内存 cudaMalloc(void **devPtr, size_t size) cudaMallocManaged(void **devPtr, size_t size) // 统一内存 // 释放内存 cudaFree(void *devPtr) // 内存传输（主机到设备） cudaMemcpy(void *dst, void *src, size_t size, enum cudaMemcpyKind kind) enum cudaMemcpyKind { cudaMemcpyHostToDevice, cudaMemcpyDeviceToHost, cudaMemcpyDeviceToDevice, cudaMemcpyHostToHost } // 内存填充 cudaMemset(void *devPtr, int value, size_t count) // 内存拷贝异步 cudaMemcpyAsync(void *dst, void *src, size_t size, enum cudaMemcpyKind kind, cudaStream_t stream) // 统一内存（简化编程） float *data; cudaMallocManaged(&data, N * sizeof(float)); // 在主机和GPU上都可以访问 data[i] = value; // 主机访问 kernel<<>>(data); // GPU访问
