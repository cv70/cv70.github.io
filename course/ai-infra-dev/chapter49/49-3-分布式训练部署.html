⚙️ 环境配置

# 训练环境配置

# 1. Docker镜像构建
FROM pytorch/pytorch:2.0.1-cuda11.7-cudnn8-runtime

# 安装依赖
RUN pip install --no-cache-dir \
    transformers \
    deepspeed \
    wandb \
    tensorboard

# 设置工作目录
WORKDIR /workspace

# 复制训练代码
COPY train.py /workspace/
COPY model.py /workspace/
COPY data_loader.py /workspace/

# 设置环境变量
ENV PYTHONUNBUFFERED=1
ENV NCCL_DEBUG=INFO
ENV NCCL_IB_DISABLE=0

# 构建镜像
# docker build -t ai-training:latest .

# 2. 启动训练容器
docker run --gpus all \
  --network host \
  -v /data:/data \
  -v /workspace:/workspace \
  -e MASTER_ADDR=login-01 \
  -e MASTER_PORT=29500 \
  -e WORLD_SIZE=8 \
  -e RANK=$RANK \
  ai-training:latest \
  python -m torch.distributed.launch \
    --nproc_per_node=4 \
    --nnodes=2 \
    --node_rank=$NODE_RANK \
    --master_addr=$MASTER_ADDR \
    --master_port=$MASTER_PORT \
    train.py

📊 训练监控

# 训练监控代码
import torch
import wandb
from torch.utils.tensorboard import SummaryWriter

# 初始化监控
wandb.init(project="llm-training", name="experiment-001")
writer = SummaryWriter(log_dir="./logs")

# 训练循环
for step, batch in enumerate(dataloader):
    # 前向传播
    outputs = model(batch)
    loss = criterion(outputs, targets)

    # 反向传播
    loss.backward()
    optimizer.step()
    optimizer.zero_grad()

    # 记录指标
    if step % 100 == 0:
        # WandB记录
        wandb.log({
            "train/loss": loss.item(),
            "train/learning_rate": optimizer.param_groups[0]['lr'],
            "train/step": step,
            "train/gpu_memory": torch.cuda.memory_allocated() / 1e9
        })

        # TensorBoard记录
        writer.add_scalar("Loss/train", loss.item(), step)
        writer.add_scalar("LR", optimizer.param_groups[0]['lr'], step)
        writer.add_scalar("GPU_Memory",
                         torch.cuda.memory_allocated() / 1e9, step)

    # 定期保存checkpoint
    if step % 1000 == 0:
        save_checkpoint(model, optimizer, step)

# 完成训练
wandb.finish()
writer.close()

🔍 调试技巧

常见问题

  • NCCL错误：检查网络配置、IB状态
  • OOM错误：减小batch size，启用梯度累积
  • 训练发散：检查学习率、数据质量
  • 速度慢：检查数据加载、GPU利用率

调试工具

  • nvidia-smi - 监控GPU状态
  • nsight sys - 性能分析
  • py-spy - Python性能分析
  • torch.profiler - PyTorch性能分析
⚠️
部署注意事项

环境一致性：所有节点使用相同的软件版本。网络配置：确保节点间网络畅通。存储挂载：正确配置数据存储访问。监控告警：设置合理的监控告警规则。
