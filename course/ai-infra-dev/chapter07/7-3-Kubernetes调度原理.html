Kubernetes调度简介

Kubernetes调度器负责将Pod调度到合适的节点上运行。 在AI场景中，需要特别关注GPU资源调度、拓扑感知、亲和性等特性， 以满足深度学习训练和推理的特殊需求。

⚙️ 调度流程

详细调度步骤

调度周期：

1. 监听Pod变化 (Informer)
   └─ Watch未调度的Pod
   └─ 更新队列

2. 过滤阶段 (Filter)
   └─ PodFitsResources: 资源足够
   └─ PodFitsHostPorts: 端口可用
   └─ PodMatchNodeSelector: 标签匹配
   └─ NoDiskConflict: 磁盘冲突
   └─ MaxEBSVolumeCount: 卷数量限制
   └─ GeneralPredicates: 通用条件
   └─ 输出: 可行节点列表

3. 打分阶段 (Score)
   └─ NodeResourcesFit: 资源余量
   └─ NodeAffinity: 亲和性
   └─ TaintToleration: 污点容忍
   └─ NodeAffinityPriority: 节点亲和
   └─ ImageLocality: 镜像本地
   └─ 输出: 每个节点得分

4. 选择阶段 (Select)
   └─ 选择得分最高的节点
   └─ 处理平分情况

5. 绑定阶段 (Bind)
   └─ 将Pod绑定到节点
   └─ 更新API Server
   └─ Kubelet拉取Pod

🔌 调度器插件

调度框架插件

调度插件架构：

Extension Points (扩展点):

QueueSort:
  └─ 队列排序优先级
  └─ 插件: PrioritySort

PreFilter:
  └─ 过滤前预处理
  └─ 插件: InterPodAffinity, NodeResourcesFit

Filter:
  └─ 节点过滤
  └─ 插件: NodeUnschedulable, NodeName, NodePorts

PostFilter:
  └─ 过滤后处理
  └─ 插件: DefaultPreemption

PreScore:
  └─ 打分前预处理
  └─ 插件: InterPodAffinity

Score:
  └─ 节点打分
  └─ 插件: NodeResourcesBalancedAllocation, NodeAffinity

NormalizeScore:
  └─ 分数归一化
  └─ 插件: 默认归一化

Reserve:
  └─ 保留节点资源
  └─ 插件: VolumeBinding

PreBind:
  └─ 绑定前处理
  └─ 插件: VolumeBinding

Bind:
  └─ 绑定Pod到节点
  └─ 插件: DefaultBinder

PostBind:
  └─ 绑定后处理
  └─ 插件: 无默认插件

Unreserve:
  └─ 释放保留资源
  └─ 插件: VolumeBinding

GPU调度示例

GPU Pod配置：

apiVersion: v1
kind: Pod
metadata:
  name: gpu-pod
spec:
  containers:
  - name: ai-container
    image: nvidia/pytorch:22.04
    resources:
      limits:
        nvidia.com/gpu: 4  # 请求4个GPU
      requests:
        nvidia.com/gpu: 4
    command: ["python", "train.py"]
    args:
      - "--gpus=4"
      - "--batch-size=128"
  nodeSelector:
    gpu: "true"

# MIG GPU调度
apiVersion: v1
kind: Pod
spec:
  containers:
  - resources:
      limits:
        nvidia.com/mig-1g.5gb: 2
💡
GPU调度注意事项

独占性：GPU默认是独占资源，不支持共享

精度：requests和limits必须相等

亲和性：使用节点亲和性确保GPU节点

拓扑：考虑NUMA和GPU拓扑

🎯 亲和性与反亲和性

调度策略配置

节点亲和性 (NodeAffinity)：

apiVersion: v1
kind: Pod
spec:
  affinity:
    nodeAffinity:
      requiredDuringSchedulingIgnoredDuringExecution:
        nodeSelectorTerms:
        - matchExpressions:
          - key: gpu
            operator: In
            values:
            - "true"
          - key: nvidia.com/gpu.count
            operator: Gt
            values:
            - "4"
      preferredDuringSchedulingIgnoredDuringExecution:
      - weight: 100
        preference:
          matchExpressions:
          - key: topology.kubernetes.io/zone
            operator: In
            values:
            - zone-a

Pod亲和性 (PodAffinity)：

affinity:
  podAffinity:
    requiredDuringSchedulingIgnoredDuringExecution:
    - labelSelector:
        matchExpressions:
        - key: app
          operator: In
          values:
          - training-job
      topologyKey: "kubernetes.io/hostname"

Pod反亲和性 (PodAntiAffinity)：

affinity:
  podAntiAffinity:
    requiredDuringSchedulingIgnoredDuringExecution:
    - labelSelector:
        matchExpressions:
        - key: app
          operator: In
          values:
          - inference-server
      topologyKey: "kubernetes.io/hostname"

🚨 污点与容忍

污点配置

节点污点：

# 设置污点
kubectl taint nodes node01 dedicated=gpu:NoSchedule
kubectl taint nodes node01 nvidia.com/gpu=true:NoExecute

# 查看污点
kubectl describe node node01 | grep Taint

# 删除污点
kubectl taint nodes node01 dedicated:NoSchedule-

# 污点效果
• NoSchedule: 不调度
• PreferNoSchedule: 尽量不调度
• NoExecute: 不调度并驱逐Pod

容忍配置

Pod容忍：

spec:
  tolerations:
  - key: dedicated
    operator: Equal
    value: gpu
    effect: NoSchedule
  - key: nvidia.com/gpu
    operator: Exists
    effect: NoExecute
    tolerationSeconds: 3600

# 专用GPU节点Pod
spec:
  tolerations:
  - key: "nvidia.com/gpu"
    operator: "Equal"
    value: "true"
    effect: "NoSchedule"

# 临时容忍
spec:
  tolerations:
  - key: "maintenance"
    operator: "Equal"
    value: "true"
    effect: "NoExecute"
    tolerationSeconds: 300  # 5分钟后驱逐

🔧 自定义调度器

自定义调度器开发

自定义调度器框架：

package main

import (
    "fmt"
    "k8s.io/klog/v2"
    "k8s.io/kubernetes/pkg/scheduler/framework"
    "k8s.io/kubernetes/pkg/scheduler/framework/runtime"
)

// AIScheduler 自定义AI调度器
type AIScheduler struct {
    handle framework.Handle
}

func (s *AIScheduler) Name() string {
    return "AI-Scheduler"
}

// Filter 过滤阶段
func (s *AIScheduler) Filter(
    ctx context.Context,
    state *framework.CycleState,
    pod *v1.Pod,
    nodeInfo *framework.NodeInfo,
) *framework.Status {
    // GPU拓扑检查
    if !checkGPUTopology(pod, nodeInfo) {
        return framework.NewStatus(
            framework.Unschedulable,
            "GPU topology mismatch",
        )
    }
    return nil
}

// Score 打分阶段
func (s *AIScheduler) Score(
    ctx context.Context,
    state *framework.CycleState,
    pod *v1.Pod,
    nodeName string,
) (int64, *framework.Status) {
    // 计算节点得分
    score := calculateScore(pod, nodeName)
    return score, nil
}

// New 创建调度器实例
func New(cfg, h framework.Handle) (framework.Plugin, error) {
    return &AIScheduler{handle: h}, nil
}

// 注册插件
func main() {
    scheme := runtime.NewScheme()
    config := runtime.NewClientConfig(
        kubeconfig,
        "",
        &rest.Config{},
    )

    command := app.NewSchedulerCommand(
        app.WithPlugin(Name, New),
    )

    if err := command.Execute(); err != nil {
        klog.Fatalf("Unable to run scheduler: %v", err)
    }
}
