59.3 Schema 定义

GraphQL 类型系统的核心

📖 什么是 Schema

Schema 是 GraphQL API 的类型定义，描述了 API 能提供什么数据以及如何交互。它是客户端和服务端的契约。

💡
Schema 的作用
  • 定义 API 的能力范围
  • 提供类型安全
  • 自动生成文档
  • 支持开发工具（自动补全、验证）

📝 基本类型

标量类型（Scalar）

标量类型是 GraphQL 最基本的数据类型，表示单个值。

类型 说明 示例
Int 有符号 32 位整数 1, -5, 100
Float 有符号双精度浮点数 3.14, -0.5
String UTF-8 字符序列 "Hello", "张三"
Boolean true 或 false true, false
ID 唯一标识符，序列化为 String "123", "abc"

自定义标量

// 自定义标量类型 scalar DateTime scalar JSON scalar Upload scalar Email // 使用自定义标量 type User { id: ID! name: String! email: Email! createdAt: DateTime! metadata: JSON }

📦 对象类型

定义对象类型

// 定义 User 类型 type User { id: ID! name: String! email: String! age: Int isActive: Boolean! createdAt: DateTime! posts: [Post!]! } // 定义 Post 类型 type Post { id: ID! title: String! content: String author: User! comments: [Comment!]! createdAt: DateTime! } // 定义 Comment 类型 type Comment { id: ID! content: String! author: User! post: Post! createdAt: DateTime! }

字段说明

type Example { // 基本字段 name: String // 可为 null name: String! // 非空字段（必填） // 列表字段 tags: [String] // 可为 null 的列表，元素可为 null tags: [String!] // 可为 null 的列表，元素非空 tags: [String]! // 非空列表，元素可为 null tags: [String!]! // 非空列表，元素非空（推荐） // 带参数的字段 posts(limit: Int = 10): [Post!]! friends(first: Int, after: ID): [User!]! }

🔍 查询类型（Query）

Query 类型定义了所有可用的查询操作，是 API 的入口点。

type Query { // 获取单个资源 user(id: ID!): User userByEmail(email: String!): User // 获取列表 users(limit: Int, offset: Int): [User!]! usersPaginated(first: Int, after: ID): UserConnection! // 搜索 searchUsers(query: String!): [User!]! searchPosts(query: String!, limit: Int = 10): [Post!]! // 当前用户 me: User // 聚合查询 userStats: UserStats! } // 查询示例 query { user(id: "123") { name email } users(limit: 10) { id name } me { id name posts { title } } }

✏️ 变更类型（Mutation）

Mutation 类型定义了所有可用的数据修改操作。

type Mutation { // 创建用户 createUser(input: CreateUserInput!): User! // 更新用户 updateUser(id: ID!, input: UpdateUserInput!): User // 删除用户 deleteUser(id: ID!): DeleteResult! // 登录 login(email: String!, password: String!): AuthPayload! // 批量操作 createUsers(inputs: [CreateUserInput!]!): [User!]! } // 返回类型定义 type DeleteResult { success: Boolean! message: String } type AuthPayload { token: String! user: User! expiresIn: Int! } // Mutation 示例 mutation { createUser(input: { name: "张三" email: "zhangsan@example.com" }) { id name email } }

📡 订阅类型（Subscription）

Subscription 类型定义了实时数据订阅操作。

type Subscription { // 用户创建事件 userCreated: User! // 用户更新事件（带参数过滤） userUpdated(userId: ID): User! // 消息事件 messageReceived(roomId: ID!): Message! // 计数器更新 counterUpdated: Counter! } // 订阅示例 subscription { userCreated { id name email } } subscription { messageReceived(roomId: "room-123") { id content sender { name } } }

📥 输入类型（Input）

Input 类型用于 Mutation 参数，类似对象类型，但只能用于输入。

// 创建用户输入 input CreateUserInput { name: String! email: String! password: String! age: Int role: UserRole = USER } // 更新用户输入 input UpdateUserInput { name: String email: String age: Int } // 枚举类型 enum UserRole { USER ADMIN MODERATOR } // 过滤条件输入 input UserFilter { name: String email: String role: UserRole isActive: Boolean } // 排序输入 input UserSort { field: UserSortField! order: SortOrder = ASC } enum UserSortField { NAME EMAIL CREATED_AT } enum SortOrder { ASC DESC } // 使用 Input 类型 type Query { users(filter: UserFilter, sort: UserSort, limit: Int): [User!]! } type Mutation { createUser(input: CreateUserInput!): User! updateUser(id: ID!, input: UpdateUserInput!): User }

🔗 接口类型（Interface）

接口定义了一组通用字段，其他类型可以实现这些接口。

// 定义接口 interface Node { id: ID! createdAt: DateTime! } interface Media { id: ID! url: String! type: MediaType! } // 实现接口 type User implements Node { id: ID! createdAt: DateTime! name: String! email: String! } type Post implements Node { id: ID! createdAt: DateTime! title: String! content: String } type Image implements Node & Media { id: ID! createdAt: DateTime! url: String! type: MediaType! width: Int! height: Int! } // 查询返回接口类型 type Query { node(id: ID!): Node searchMedia(query: String!): [Media!]! }

🔀 联合类型（Union）

联合类型表示可以是多种类型之一。

// 定义联合类型 union SearchResult = User | Post | Comment union MediaContent = Image | Video | Audio // 使用联合类型 type Query { search(query: String!): [SearchResult!]! } // 查询时使用内联片段 query { search(query: "test") { ... on User { id name email } ... on Post { id title content } ... on Comment { id content } } }

📝 完整 Schema 示例

# 标量类型 scalar DateTime # 枚举类型 enum UserRole { USER ADMIN } # 输入类型 input CreateUserInput { name: String! email: String! password: String! } input UpdateUserInput { name: String email: String } # 对象类型 type User { id: ID! name: String! email: String! role: UserRole! posts: [Post!]! createdAt: DateTime! } type Post { id: ID! title: String! content: String author: User! comments: [Comment!]! createdAt: DateTime! } type Comment { id: ID! content: String! author: User! post: Post! createdAt: DateTime! } # 查询类型 type Query { me: User user(id: ID!): User users: [User!]! post(id: ID!): Post posts(limit: Int = 10): [Post!]! } # 变更类型 type Mutation { createUser(input: CreateUserInput!): User! updateUser(id: ID!, input: UpdateUserInput!): User deleteUser(id: ID!): Boolean! createPost(title: String!, content: String): Post! } # 订阅类型 type Subscription { userCreated: User! postCreated: Post! }

📝 小结

  • Schema 是 GraphQL API 的类型定义
  • 标量类型是最基本的数据类型
  • 对象类型定义复杂的业务实体
  • Query/Mutation/Subscription 是三个根类型
  • Input 类型用于 Mutation 参数
  • 接口和联合类型提供类型抽象能力
