59.6 Apollo Server 基础

构建生产级 GraphQL 服务器

📖 Apollo Server 简介

Apollo Server 是一个开源的、符合规范的 GraphQL 服务器，支持多种 Node.js 框架。它提供了丰富的功能，包括 TypeScript 支持、Apollo Studio 集成、订阅支持等。

基本服务器

import { ApolloServer } from '@apollo/server'; import { startStandaloneServer } from '@apollo/server/standalone'; // 定义 Schema const typeDefs = `#graphql type User { id: ID! name: String! email: String! } type Query { users: [User!]! user(id: ID!): User } type Mutation { createUser(name: String!, email: String!): User! } `; // 模拟数据 const users: any[] = [ { id: '1', name: '张三', email: 'zhangsan@example.com' }, { id: '2', name: '李四', email: 'lisi@example.com' }, ]; // 定义 Resolvers const resolvers = { Query: { users: () => users, user: (_: any, { id }: { id: string }) => users.find(u => u.id === id), }, Mutation: { createUser: (_: any, { name, email }: { name: string; email: string }) => { const user = { id: String(users.length + 1), name, email }; users.push(user); return user; }, }, }; // 创建服务器 const server = new ApolloServer({ typeDefs, resolvers, }); // 启动服务器 const { url } = await startStandaloneServer(server, { listen: { port: 4000 }, }); console.log(`Server ready at: ${url}`);

📝 Schema 定义方式

1. 字符串定义

const typeDefs = `#graphql type User { id: ID! name: String! } type Query { users: [User!]! } `;

2. 使用 gql 标签

import { gql } from 'graphql-tag'; const typeDefs = gql` type User { id: ID! name: String! } type Query { users: [User!]! } `;

3. 模块化 Schema

// user.schema.ts export const userTypeDefs = `#graphql type User { id: ID! name: String! email: String! } extend type Query { users: [User!]! user(id: ID!): User } extend type Mutation { createUser(name: String!, email: String!): User! } `; // post.schema.ts export const postTypeDefs = `#graphql type Post { id: ID! title: String! content: String! author: User! } extend type Query { posts: [Post!]! } `; // 合并 Schema const server = new ApolloServer({ typeDefs: [userTypeDefs, postTypeDefs], resolvers, });

🔄 Resolvers

Resolver 是处理每个字段的函数，返回对应的数据。

// Resolver 结构 const resolvers = { Query: { // fieldName: (parent, args, context, info) => result users: async (_parent, _args, context) => { return context.dataSources.userApi.getAll(); }, user: async (_parent, { id }, context) => { return context.dataSources.userApi.getById(id); }, }, Mutation: { createUser: async (_parent, { name, email }, context) => { return context.dataSources.userApi.create({ name, email }); }, }, User: { // 关联字段 resolver posts: async (user, _args, context) => { return context.dataSources.postApi.getByUserId(user.id); }, }, };

Resolver 参数

参数 说明
parent 父级字段的返回值
args 查询参数
context 所有 resolver 共享的上下文
info 查询的执行状态信息

🔧 Context 配置

import { startStandaloneServer } from '@apollo/server/standalone'; interface Context { user?: { id: string; role: string }; dataSources: { userApi: UserAPI; postApi: PostAPI; }; } const server = new ApolloServer({ typeDefs, resolvers }); const { url } = await startStandaloneServer(server, { context: async ({ req }) => { // 获取认证信息 const token = req.headers.authorization || ''; const user = await getUserFromToken(token); // 返回 context return { user, dataSources: { userApi: new UserAPI(), postApi: new PostAPI(), }, }; }, listen: { port: 4000 }, });

🔌 与 Express 集成

import express from 'express'; import { ApolloServer } from '@apollo/server'; import { expressMiddleware } from '@apollo/server/express4'; import cors from 'cors'; import bodyParser from 'body-parser'; const app = express(); const server = new ApolloServer({ typeDefs, resolvers, }); await server.start(); app.use( '/graphql', cors(), bodyParser.json(), expressMiddleware(server, { context: async ({ req }) => ({ token: req.headers.authorization, }), }) ); app.listen(4000, () => { console.log('Server running on http://localhost:4000/graphql'); });

📊 Data Sources

Data Sources 是 Apollo Server 提供的数据获取抽象层，可以封装 REST API、数据库等数据源。

import { RESTDataSource } from '@apollo/datasource-rest'; class UserAPI extends RESTDataSource { constructor() { super(); this.baseURL = 'https://api.example.com/users/'; } async getAllUsers() { return this.get(''); } async getUser(id: string) { return this.get(`/${id}`); } async createUser(user: any) { return this.post('', { body: user }); } } // 在 Context 中使用 const server = new ApolloServer({ typeDefs, resolvers, }); await startStandaloneServer(server, { context: async () => ({ dataSources: { userApi: new UserAPI(), }, }), });

📡 订阅支持

import { ApolloServer } from '@apollo/server'; import { makeExecutableSchema } from '@graphql-tools/schema'; import { WebSocketServer } from 'ws'; import { useServer } from 'graphql-ws/lib/use/server'; import { PubSub } from 'graphql-subscriptions'; const pubsub = new PubSub(); const typeDefs = `#graphql type Subscription { userCreated: User! messageReceived(roomId: ID!): Message! } `; const resolvers = { Subscription: { userCreated: { subscribe: () => pubsub.asyncIterator(['USER_CREATED']), }, }, Mutation: { createUser: async (_parent, { name, email }) => { const user = { id: '1', name, email }; pubsub.publish('USER_CREATED', { userCreated: user }); return user; }, }, }; // 创建 WebSocket 服务器 const wsServer = new WebSocketServer({ port: 4001, }); const schema = makeExecutableSchema({ typeDefs, resolvers }); useServer({ schema }, wsServer);

📋 Apollo Studio 集成

const server = new ApolloServer({ typeDefs, resolvers, // 启用 Apollo Studio introspection: true, // 生产环境可关闭 }); // 环境变量配置 // APOLLO_KEY=your-apollo-key // APOLLO_GRAPH_REF=your-graph@current

📝 小结

  • Apollo Server 是功能完善的 GraphQL 服务器
  • 支持字符串、gql 标签定义 Schema
  • Resolver 处理每个字段的请求
  • Context 提供共享上下文和认证
  • Data Sources 封装数据源获取
  • Subscription 支持 WebSocket 实时通信
