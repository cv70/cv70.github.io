8.3 infer 关键字

在条件类型中推断类型

🎯 学习目标

  • 理解 infer 关键字的作用
  • 掌握在条件类型中推断类型
  • 学会提取函数参数和返回值类型
  • 了解 infer 的高级应用

📚 infer 基础

// infer 用于在条件类型的 extends 子句中声明类型变量 // 只能在条件类型的 true 分支中使用 // 提取函数返回值类型 type GetReturnType = T extends (...args: any[]) => infer R ? R : never; type A = GetReturnType<() => string>; // string type B = GetReturnType<(x: number) => void>; // void type C = GetReturnType; // number type D = GetReturnType; // boolean // 提取函数参数类型 type GetParameters = T extends (...args: infer P) => any ? P : never; type Params = GetParameters<(a: string, b: number) => void>; // [a: string, b: number] // 提取第一个参数类型 type GetFirstParam = T extends (first: infer F, ...rest: any[]) => any ? F : never; type First = GetFirstParam<(name: string, age: number) => void>; // string
💡
infer 规则

infer 声明的类型变量只能在条件类型的 true 分支中使用。它会在类型匹配时自动推断类型。

🔧 提取数组元素类型

// 提取数组元素类型 type ElementType = T extends (infer E)[] ? E : never; type A1 = ElementType; // string type A2 = ElementType; // number type A3 = ElementType<(string | number)[]>; // string | number // 提取 Promise 返回类型 type UnwrapPromise = T extends Promise ? U : T; type P1 = UnwrapPromise>; // string type P2 = UnwrapPromise>; // number type P3 = UnwrapPromise; // string (非 Promise 直接返回) // 嵌套 Promise 展开 type UnwrapPromiseDeep = T extends Promise ? UnwrapPromiseDeep : T; type Deep = UnwrapPromiseDeep>>; // string

🔀 多个 infer

// 同时推断多个类型 type GetTupleTypes = T extends [infer First, ...infer Rest] ? { first: First; rest: Rest } : never; type Tuple = GetTupleTypes<[string, number, boolean]>; // { first: string; rest: [number, boolean] } // 提取对象属性类型 type GetPropertyType = T extends { [P in K]: infer V } ? V : never; interface User { name: string; age: number; } type NameType = GetPropertyType; // string // 提取构造函数实例类型 type InstanceType any> = T extends new (...args: any[]) => infer R ? R : any; class MyClass { constructor(public x: number) {} } type MyInstance = InstanceType; // MyClass

📝 本节小结

✅
  • • infer 在 extends 子句中声明类型变量
  • • 自动推断匹配位置的类型
  • • 常用于提取函数、数组、Promise 的类型
  • • 支持多个 infer 同时推断
