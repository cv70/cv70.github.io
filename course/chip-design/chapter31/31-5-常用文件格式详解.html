31.5 常用文件格式详解

掌握物理设计中常用的文件格式

🎯 学习目标

  • 掌握物理设计常用文件格式的用途
  • 理解各文件格式的内容结构
  • 了解文件之间的转换关系
  • 学会选择合适的文件格式进行数据交换

文件格式概述

物理设计涉及多种文件格式，用于描述电路网表、时序约束、物理版图、寄生参数等信息。理解这些文件格式的用途和内容，是物理设计工程师的基本功。

📊 主要文件格式分类

类别 格式 用途 特点
网表格式 Verilog / VHDL 电路结构与连接关系 可读性好，广泛支持
约束格式 SDC 时序约束定义 Synopsys标准格式
物理库 LEF 标准单元物理信息 抽象层信息
物理数据 DEF 版图位置与连接 详细物理描述
版图格式 GDSII / OASIS 制造用的版图数据 二进制格式，文件大
寄生参数 SPEF 寄生RC参数 标准寄生交换格式
时序库 Liberty (.lib) 单元时序特征 查表模型

💡 核心格式详解

LEF (Library Exchange Format)

描述标准单元和宏模块的物理信息：

  • 单元尺寸与边界
  • 引脚位置与层信息
  • 布线阻塞区域
  • 工艺设计规则

DEF (Design Exchange Format)

描述设计的物理实现状态：

  • 芯片面积与形状
  • 标准单元位置
  • 布线信息
  • 网络连接关系

SDC (Synopsys Design Constraints)

定义设计的时序约束：

  • 时钟定义（周期、波形）
  • 输入/输出延时
  • 多周期路径
  • 虚假路径

GDSII / OASIS

最终版图输出格式：

  • GDSII：传统二进制格式
  • OASIS：压缩效率更高
  • 包含所有层的几何图形
  • 直接用于掩模制造
💡
SPEF文件示例结构

*D_NET *1 0.5 - 定义网络，电容值
*CONN - 连接信息（驱动端、负载端）
*CAP - 电容信息（节点、电容值）
*RES - 电阻信息（节点对、电阻值）
SPEF文件用于传递寄生参数，进行时序分析

📈 文件流程关系

📊
  • 输入阶段：Verilog网表 + SDC约束 + LEF库 → 物理设计工具
  • 设计过程：生成DEF文件记录物理状态
  • 寄生提取：DEF + GDSII → StarRC → SPEF
  • 时序分析：网表 + SPEF + .lib → PrimeTime
  • 最终输出：GDSII/OASIS → 代工厂制造
⚠️
文件使用注意事项

1. 版本一致性：确保工具版本支持的文件格式版本
2. 单位统一：不同文件可能使用不同单位（um, nm）
3. 路径问题：文件路径中避免特殊字符和空格
4. 备份习惯：重要文件定期备份，避免数据丢失

📝 本节小结

✅
  • • LEF描述库单元物理信息，DEF描述设计物理状态
  • • SDC是标准的时序约束格式
  • • GDSII/OASIS是最终版图输出格式
  • • SPEF用于传递寄生参数信息
  • • Liberty (.lib) 描述单元时序特征
  • • 理解文件格式有助于数据交换和问题定位
