Docker概述

Docker是容器化技术的标准实现，允许将应用及其依赖打包成轻量级容器。对于AI开发，Docker解决了环境一致性问题，使开发、测试和部署环境保持一致，大大提升了开发效率。

📥 Docker安装

安装步骤

Ubuntu安装Docker： # 1. 卸载旧版本 sudo apt-get remove docker docker-engine docker.io containerd runc # 2. 更新包索引 sudo apt-get update # 3. 安装依赖 sudo apt-get install -y \ ca-certificates \ curl \ gnupg \ lsb-release # 4. 添加Docker官方GPG密钥 sudo mkdir -p /etc/apt/keyrings curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg # 5. 设置仓库 echo \ "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu \ $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null # 6. 安装Docker Engine sudo apt-get update sudo apt-get install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin # 7. 验证安装 sudo docker run hello-world # 8. 配置用户权限（免sudo） sudo usermod -aG docker $USER newgrp docker

🐳 Docker基础操作

常用命令

Docker常用命令： # 镜像操作 docker pull ubuntu:22.04 # 拉取镜像 docker images # 列出镜像 docker rmi # 删除镜像 docker search pytorch # 搜索镜像 # 容器操作 docker run -it ubuntu:22.04 /bin/bash # 运行容器 docker ps # 列出运行中容器 docker ps -a # 列出所有容器 docker stop # 停止容器 docker start # 启动容器 docker rm # 删除容器 docker exec -it /bin/bash # 进入容器 # 数据卷操作 docker volume create my-volume # 创建卷 docker volume ls # 列出卷 docker volume rm my-volume # 删除卷 # 网络操作 docker network create my-network # 创建网络 docker network ls # 列出网络 docker network inspect my-network # 查看网络详情

📝 编写Dockerfile

构建AI环境

PyTorch开发环境Dockerfile： FROM nvidia/cuda:12.1.0-runtime-ubuntu22.04 # 元数据 LABEL maintainer="your-email@example.com" LABEL description="PyTorch Development Environment" # 环境变量 ENV DEBIAN_FRONTEND=noninteractive ENV PYTHONUNBUFFERED=1 ENV TORCH_CUDA_ARCH_LIST="6.0 6.1 7.0 7.5 8.0 8.6+PTX" ENV TORCH_NVCC_FLAGS="-Xfatbin -compress-all" ENV CMAKE_PREFIX_PATH="$(dirname $(which conda))/../" # 安装系统依赖 RUN apt-get update && apt-get install -y \ python3.10 \ python3-pip \ python3-venv \ git \ wget \ vim \ htop \ tmux \ && rm -rf /var/lib/apt/lists/* # 升级pip RUN pip3 install --upgrade pip # 安装PyTorch RUN pip3 install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121 # 安装其他依赖 COPY requirements.txt /tmp/ RUN pip3 install --no-cache-dir -r /tmp/requirements.txt # 安装Jupyter RUN pip3 install jupyterlab # 创建工作目录 WORKDIR /workspace # 暴露端口 EXPOSE 8888 # 启动命令 CMD ["jupyter", "lab", "--ip=0.0.0.0", "--port=8888", "--no-browser", "--allow-root"]

🎮 NVIDIA Docker

GPU容器支持

NVIDIA Docker允许容器访问GPU，是AI应用容器化的关键技术：

安装NVIDIA Container Toolkit： # 添加NVIDIA包仓库 distribution=$(. /etc/os-release;echo $ID$VERSION_ID) curl -s -L https://nvidia.github.io/nvidia-docker/gpgkey | sudo apt-key add - curl -s -L https://nvidia.github.io/nvidia-docker/$distribution/nvidia-docker.list | sudo tee /etc/apt/sources.list.d/nvidia-docker.list # 安装nvidia-container-toolkit sudo apt-get update sudo apt-get install -y nvidia-container-toolkit # 重启Docker sudo systemctl restart docker # 验证GPU访问 docker run --rm --gpus all nvidia/cuda:12.1.0-base-ubuntu22.04 nvidia-smi 运行GPU容器： # 使用所有GPU docker run --gpus all -it pytorch-env # 使用特定GPU docker run --gpus '"device=0,1"' -it pytorch-env # 限制GPU内存 docker run --gpus '"device=0,1"' --shm-size=16g -it pytorch-env

📦 Docker Compose

多容器编排

Docker Compose简化了多容器应用的管理：

docker-compose.yml示例： version: '3.8' services: jupyter: build: . image: pytorch-env container_name: ai-jupyter ports: - "8888:8888" volumes: - ./workspace:/workspace - ./data:/data deploy: resources: reservations: devices: - driver: nvidia count: 1 capabilities: [gpu] restart: unless-stopped tensorboard: image: tensorflow/tensorflow:latest container_name: ai-tensorboard ports: - "6006:6006" volumes: - ./logs:/logs command: tensorboard --logdir=/logs --host=0.0.0.0 redis: image: redis:7-alpine container_name: ai-redis ports: - "6379:6379" volumes: - redis_data:/data restart: unless-stopped volumes: redis_data: # 使用docker-compose docker-compose up -d docker-compose down docker-compose logs -f

⚡ 镜像优化

减小镜像大小

优化策略： # 1. 使用精简基础镜像 FROM python:3.10-slim # 而不是 python:3.10 # 2. 多阶段构建 FROM nvidia/cuda:12.1.0-devel-ubuntu22.04 AS builder RUN apt-get update && apt-get install -y build-essential COPY . /src RUN cd /src && python setup.py build FROM nvidia/cuda:12.1.0-runtime-ubuntu22.04 COPY --from=builder /src/build /app WORKDIR /app # 3. 清理缓存 RUN apt-get clean && rm -rf /var/lib/apt/lists/* # 4. 合并RUN指令 RUN apt-get update && apt-get install -y git vim && \ pip install --no-cache-dir numpy pandas matplotlib && \ rm -rf /root/.cache # 5. 使用.dockerignore echo ".git" > .dockerignore echo "*.pyc" >> .dockerignore echo "__pycache__" >> .dockerignore echo ".DS_Store" >> .dockerignore # 构建时使用构建缓存 docker build --build-arg CACHEBUST=$(date +%s) -t my-image .
