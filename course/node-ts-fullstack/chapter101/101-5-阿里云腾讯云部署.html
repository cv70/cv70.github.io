101.5 阿里云/腾讯云部署

在主流云平台部署 Node.js 应用

🎯 学习目标

  • 了解阿里云和腾讯云的核心产品
  • 掌握云服务器购买与配置流程
  • 学会配置安全组和网络规则
  • 了解域名备案流程

国内云平台概述

阿里云和腾讯云是国内最大的两家云服务提供商，提供完整的云计算产品线。 对于国内用户，选择这些平台可以获得更低的延迟和更好的网络连接质量。

☁️ 云平台产品对比

服务类型 阿里云 腾讯云
云服务器 ECS (Elastic Compute Service) CVM (Cloud Virtual Machine)
负载均衡 SLB (Server Load Balancer) CLB (Cloud Load Balancer)
对象存储 OSS (Object Storage Service) COS (Cloud Object Storage)
关系数据库 RDS (Relational Database Service) TencentDB
容器服务 ACK (Alibaba Container Service) TKE (Tencent Kubernetes Engine)
CDN 阿里云 CDN 腾讯云 CDN

🖥️ 购买云服务器

阿里云 ECS

/* 购买步骤 */ 1. 登录阿里云控制台 2. 进入 ECS 产品页面 3. 选择地域（建议选择离用户最近的地域） 4. 选择实例规格： - 入门级：1核2G（测试用） - 标准级：2核4G（小型应用） - 进阶级：4核8G（中型应用） 5. 选择镜像：Ubuntu 22.04 或 CentOS 8 6. 选择存储：SSD 云盘 40GB 起 7. 选择网络和安全组 8. 设置登录凭证（密钥对推荐） 9. 确认订单并支付

腾讯云 CVM

/* 购买步骤类似 */ 1. 登录腾讯云控制台 2. 进入 CVM 产品页面 3. 选择地域和可用区 4. 选择机型配置 5. 选择镜像：Ubuntu 22.04 LTS 6. 选择存储和网络 7. 设置安全组和登录方式 8. 确认配置并购买

🔐 安全组配置

安全组是云平台的虚拟防火墙，控制入站和出站流量。

/* 常用端口规则 */ 入站规则： ┌──────────┬────────────┬─────────────────┐ │ 端口 │ 协议 │ 用途 │ ├──────────┼────────────┼─────────────────┤ │ 22 │ TCP │ SSH │ │ 80 │ TCP │ HTTP │ │ 443 │ TCP │ HTTPS │ │ 3000 │ TCP │ Node.js(可选) │ │ 3306 │ TCP │ MySQL(内网) │ │ 6379 │ TCP │ Redis(内网) │ └──────────┴────────────┴─────────────────┘ /* 安全建议 */ - 数据库端口只对内网开放 - SSH 端口限制 IP 访问 - 使用安全组而非服务器防火墙（更安全）

📝 域名备案

备案要求

  • 域名需要实名认证
  • 服务器需在国内地域
  • 首次备案约 10-20 天
  • 网站内容需合规

备案流程

  • 1. 域名实名认证
  • 2. 提交备案申请
  • 3. 上传证件材料
  • 4. 等待审核
  • 5. 备案完成

🔧 完整部署流程

# 1. SSH 连接服务器 ssh root@your-server-ip # 2. 系统更新 apt update && apt upgrade -y # 3. 安装基础环境 # Node.js curl -fsSL https://deb.nodesource.com/setup_20.x | bash - apt install -y nodejs # Docker curl -fsSL https://get.docker.com | sh # Nginx apt install -y nginx # PM2 npm install -g pm2 # 4. 配置安全组开放端口 # 在云控制台配置: 80, 443, 22 # 5. 上传应用代码 git clone https://github.com/your-repo/myapp.git /var/www/myapp # 或使用 rsync/scp # 6. 安装依赖并构建 cd /var/www/myapp npm ci npm run build # 7. 配置 PM2 pm2 start ecosystem.config.js --env production pm2 save pm2 startup # 8. 配置 Nginx vim /etc/nginx/sites-available/myapp # 配置反向代理 ln -s /etc/nginx/sites-available/myapp /etc/nginx/sites-enabled/ nginx -t && nginx -s reload # 9. 申请 SSL 证书 apt install certbot python3-certbot-nginx certbot --nginx -d example.com # 10. 配置防火墙 ufw allow 22 ufw allow 80 ufw allow 443 ufw enable

💰 成本优化建议

开发/测试环境

  • 选择按量付费模式
  • 使用抢占式实例
  • 设置自动释放时间
  • 利用免费额度

生产环境

  • 购买包年包月更优惠
  • 使用预留实例券
  • 合理选择规格避免浪费
  • 使用 CDN 减轻源站压力
💡
云平台特有服务
  • OSS/COS: 存储静态文件、图片、视频
  • CDN: 加速静态资源访问
  • SLB/CLB: 负载均衡，分发流量
  • RDS: 托管数据库，自动备份
  • Redis: 托管缓存服务
