⚡ SoC功耗构成

💡
功耗分类

动态功耗（Dynamic Power）：由电路翻转产生的功耗，与频率和电容成正比。P_dynamic = α·C·V²·f

静态功耗（Static Power）：由漏电流产生的功耗，与温度和电压有关。P_static = I_leak·V

短路功耗（Short-circuit Power）：由PMOS和NMOS同时导通产生的功耗，通常较小。

功耗占比分析

模块类型 动态功耗占比 静态功耗占比 特点
CPU/GPU 高（40-60%） 中（20-30%） 高频、高翻转
存储器 中（20-30%） 高（30-40%） 容量大、漏电流高
高速接口 中（10-20%） 低（5-10%） 高I/O活动
低速外设 低（5-10%） 低（5-10%） 低频、低活动

🔧 电源管理技术

时钟门控（Clock Gating）

  • 关闭空闲模块的时钟
  • 消除不必要的翻转
  • 节省动态功耗
  • 实现简单、效果显著

功耗节省：20-40%

电源门控（Power Gating）

  • 关闭空闲模块的电源
  • 消除漏电流
  • 节省静态功耗
  • 需要状态保存/恢复

功耗节省：50-90%（被关断区域）

动态电压频率调节（DVFS）

  • 根据负载调整电压和频率
  • 降低平均功耗
  • 需要软件支持
  • 调节过程平滑

功耗节省：30-60%

多电压设计（Multi-Vdd）

  • 不同模块使用不同电压
  • 性能模块用高电压
  • 非关键模块用低电压
  • 需要电平转换器

功耗节省：20-40%

阈值电压调整（Vt Scaling）

  • 使用多阈值晶体管
  • 关键路径用低Vt
  • 非关键路径用高Vt
  • 降低漏电流

功耗节省：10-30%

自适应电压调节（AVS）

  • 实时监测电路性能
  • 动态调整工作电压
  • 最大化功耗效率
  • 需要传感器支持

功耗节省：10-20%

🗺️ 电源域划分

电源域划分是电源管理的基础。根据功能、性能、使用频率等因素，将SoC划分为多个独立的电源域。

典型电源域划分

Always-On域（AON）

  • 始终上电，永不关闭
  • 包含RTC、PMU、唤醒逻辑
  • 使用低漏电工艺
  • 极低功耗设计

高性能域（HP）

  • CPU、GPU等核心处理单元
  • 最高电压和频率
  • 支持DVFS
  • 可独立关断

外设域（PERI）

  • 各种外设控制器
  • 中等电压
  • 支持时钟/电源门控
  • 按需上电

存储器域（MEM）

  • SRAM、TCM等片上存储
  • 低电压，深度睡眠
  • 支持保留模式
  • 数据保持能力

电源开关设计

// 电源开关单元（Power Switch Cell）
module power_switch (
    input  enable,      // 开关使能
    input  vdd_in,      // 输入电源
    output vdd_out      // 输出电源
);

// 头开关（Header Switch）
// PMOS晶体管作为电源开关
// 当enable=1时，vdd_out ≈ vdd_in
// 当enable=0时，vdd_out ≈ 0V（实际为Vdd - Vth）

// 实际实现使用综合库中的电源开关单元
// 包含：
// - 主开关晶体管
// - 隔离单元（Isolation Cells）
// - 保持寄存器（Retention Registers）
// - 状态检测逻辑

endmodule

// 隔离单元示例
module isolation_cell (
    input  data_in,     // 来自关断域的信号
    input  iso_enable,  // 隔离使能
    output data_out     // 隔离后的信号
);

assign data_out = iso_enable ? ISO_VALUE : data_in;
// ISO_VALUE通常是0或1，防止悬空信号

endmodule

📊 DVFS（动态电压频率调节）

DVFS根据系统负载动态调整处理器的电压和频率，在性能和功耗之间取得平衡。

DVFS操作点（OPP）

OPP等级 频率（MHz） 电压（V） 功耗（W） 应用场景
OPP0 2400 1.05 5.2 高性能计算
OPP1 2000 0.95 3.4 游戏、视频
OPP2 1600 0.85 2.0 日常使用
OPP3 1200 0.75 1.1 后台任务
OPP4 800 0.65 0.5 待机

DVFS转换流程

检测负载变化
↓
决策新的OPP
↓
降低频率
↓
调节电压
↓
提升频率到目标值
↓
确认稳定

注意：升频时先升压后升频，降频时先降频后降压，避免时序违例。

😴 低功耗状态管理

典型低功耗状态

Active（活动态）

  • 所有模块正常工作
  • 最高性能
  • 最大功耗

唤醒时间：0ms

Idle（空闲态）

  • CPU停止执行
  • 时钟门控生效
  • 等待中断唤醒

唤醒时间：<10μs

Standby（待机态）

  • 部分电源域关断
  • 关键状态保留
  • 极少功耗

唤醒时间：<1ms

Deep Sleep（深睡态）

  • 大部分电路关断
  • 仅AON域工作
  • 超低功耗

唤醒时间：<10ms

状态转换控制

// 低功耗状态机（简化）
module power_state_machine (
    input  clk,
    input  rst_n,
    input  [2:0] power_request,  // 0:Active, 1:Idle, 2:Standby, 3:DeepSleep
    input  wake_up_event,
    output reg [2:0] current_state,
    output reg power_switch_hp,   // 高性能域电源开关
    output reg power_switch_peri, // 外设域电源开关
    output reg clock_gate_cpu     // CPU时钟门控
);

// 状态定义
localparam ACTIVE     = 3'd0;
localparam IDLE       = 3'd1;
localparam STANDBY    = 3'd2;
localparam DEEP_SLEEP = 3'd3;

always @(posedge clk or negedge rst_n) begin
    if (!rst_n) begin
        current_state     <= ACTIVE;
        power_switch_hp   <= 1;
        power_switch_peri <= 1;
        clock_gate_cpu    <= 0;
    end else begin
        case (current_state)
            ACTIVE:
                if (power_request != ACTIVE)
                    current_state <= power_request;

            IDLE:
                if (wake_up_event)
                    current_state <= ACTIVE;
                else if (power_request != IDLE)
                    current_state <= power_request;

            STANDBY:
                if (wake_up_event)
                    current_state <= ACTIVE;
                else if (power_request != STANDBY)
                    current_state <= power_request;

            DEEP_SLEEP:
                if (wake_up_event)
                    current_state <= ACTIVE;

            default:
                current_state <= ACTIVE;
        endcase
    end
end

// 输出控制逻辑
always @(*) begin
    case (current_state)
        ACTIVE: begin
            power_switch_hp   = 1;
            power_switch_peri = 1;
            clock_gate_cpu    = 0;
        end
        IDLE: begin
            power_switch_hp   = 1;
            power_switch_peri = 1;
            clock_gate_cpu    = 1;
        end
        STANDBY: begin
            power_switch_hp   = 0;
            power_switch_peri = 0;
            clock_gate_cpu    = 1;
        end
        DEEP_SLEEP: begin
            power_switch_hp   = 0;
            power_switch_peri = 0;
            clock_gate_cpu    = 1;
        end
    endcase
end

endmodule
