81.3 响应式系统

Vue 3 响应式原理与 API

📖 本节概述

Vue 3 使用 Proxy 重写了响应式系统，相比 Vue 2 的 Object.defineProperty，Proxy 提供了更强大的拦截能力，支持更多数据类型，并解决了 Vue 2 中的一些限制。

🎯 学习目标

  • 理解 Vue 3 响应式系统的工作原理
  • 掌握 Proxy 与 Object.defineProperty 的区别
  • 学会使用响应式工具函数
  • 了解响应式系统的限制和最佳实践

🔧 响应式原理

Vue 2: Object.defineProperty

// Vue 2 响应式实现（简化版） function defineReactive(obj, key, val) { Object.defineProperty(obj, key, { get() { console.log(`获取 ${key}`); return val; }, set(newVal) { console.log(`设置 ${key} = ${newVal}`); val = newVal; } }); } // 局限性： // 1. 无法检测对象属性的添加/删除 // 2. 无法检测数组索引和 length 变化 // 3. 需要递归遍历对象的所有属性

Vue 3: Proxy

// Vue 3 响应式实现（简化版） function reactive(target) { return new Proxy(target, { get(target, key, receiver) { console.log(`获取 ${String(key)}`); track(target, key); // 收集依赖 return Reflect.get(target, key, receiver); }, set(target, key, value, receiver) { console.log(`设置 ${String(key)} = ${value}`); const result = Reflect.set(target, key, value, receiver); trigger(target, key); // 触发更新 return result; }, deleteProperty(target, key) { console.log(`删除 ${String(key)}`); const result = Reflect.deleteProperty(target, key); trigger(target, key); return result; } }); } // Proxy 优势： // 1. 可以检测属性的添加/删除 // 2. 可以检测数组索引和 length 变化 // 3. 惰性响应式，只有访问时才代理 // 4. 支持 Map、Set、WeakMap、WeakSet

📦 响应式 API

ref

import { ref, shallowRef, triggerRef } from 'vue'; // 创建响应式 ref const count = ref(0); // ref 内部实现 class RefImpl { private _value; private _rawValue; constructor(value) { this._rawValue = value; this._value = reactive(value); // 如果是对象则转为 reactive } get value() { track(this, 'value'); return this._value; } set value(newVal) { this._value = newVal; trigger(this, 'value'); } } // shallowRef - 浅层响应式 const shallow = shallowRef({ a: { b: 1 } }); shallow.value.a.b = 2; // 不会触发更新 shallow.value = { a: { b: 2 } }; // 会触发更新 // 手动触发更新 triggerRef(shallow);

reactive

import { reactive, shallowReactive, readonly, shallowReadonly } from 'vue'; // 创建响应式对象 const state = reactive({ count: 0, nested: { value: 1 } }); // shallowReactive - 浅层响应式 const shallow = shallowReactive({ count: 0, nested: { value: 1 } }); shallow.count++; // 触发更新 shallow.nested.value++; // 不触发更新 // readonly - 只读代理 const readonlyState = readonly(state); // readonlyState.count = 1; // 警告并失败 // shallowReadonly - 浅层只读 const shallowReadonlyState = shallowReadonly(state); shallowReadonlyState.count = 1; // 警告 shallowReadonlyState.nested.value = 2; // 允许修改

🔧 响应式工具函数

toRef 和 toRefs

import { reactive, toRef, toRefs } from 'vue'; const state = reactive({ name: 'Vue', version: 3 }); // toRef - 为单个属性创建 ref const nameRef = toRef(state, 'name'); nameRef.value = 'Vue 3'; console.log(state.name); // 'Vue 3' // toRefs - 为所有属性创建 ref const { name, version } = toRefs(state); name.value = 'Vue 4'; console.log(state.name); // 'Vue 4' // 在组合函数中返回响应式对象 function useFeature() { const state = reactive({ count: 0, name: '' }); return toRefs(state); // 保持响应性 }

isRef, isReactive, isProxy, isReadonly

import { ref, reactive, readonly, isRef, isReactive, isProxy, isReadonly } from 'vue'; const count = ref(0); const state = reactive({ name: '' }); const readonlyState = readonly(state); console.log(isRef(count)); // true console.log(isReactive(state)); // true console.log(isProxy(state)); // true console.log(isReadonly(readonlyState)); // true

unref

import { ref, unref } from 'vue'; const count = ref(10); // 如果是 ref 则返回 .value，否则返回本身 console.log(unref(count)); // 10 console.log(unref(20)); // 20 // 等价于 const val = isRef(count) ? count.value : count;

📊 响应式转换

响应式丢失问题

import { reactive } from 'vue'; const state = reactive({ count: 0 }); // 解构会丢失响应性 let { count } = state; count++; // 不会触发更新，count 只是普通数字 // 正确方式：使用 toRefs import { toRefs } from 'vue'; const { count } = toRefs(state); count.value++; // 正确触发更新 // 赋值会断开连接 state = reactive({ count: 0 }); // 错误！ // 正确方式：使用 ref 或 Object.assign const stateRef = ref({ count: 0 }); stateRef.value = { count: 1 }; // 正确 // 或者 Object.assign(state, { count: 1, newProp: 'value' });

⚠️ 响应式限制

reactive 的限制

import { reactive, ref } from 'vue'; // 1. 只能用于对象类型 const num = reactive(0); // 错误！ const str = reactive('hello'); // 错误！ // 2. 不能替换整个对象 let state = reactive({ count: 0 }); state = reactive({ count: 1 }); // 断开响应性 // 3. 解构会丢失响应性 const { count } = state; // 不是响应式的 // 正确做法 const countRef = ref(0); // 基本类型用 ref const stateRef = ref({ count: 0 }); // 需要替换时用 ref const { count } = toRefs(reactive({ count: 0 })); // 解构时用 toRefs

不可代理的值

import { reactive, markRaw, shallowReactive } from 'vue'; // 这些值不会被代理 // 1. 基本类型（number, string, boolean, null, undefined） // 2. symbol // 3. 使用 markRaw 标记的对象 const obj = markRaw({ a: 1 }); const state = reactive({ obj }); // state.obj 不会被代理 // 避免 markRaw 的场景 // - 不应该被代理的第三方库对象 // - 不需要响应式的复杂对象

📝 本节小结

  • Vue 3 使用 Proxy 实现响应式，功能更强大
  • ref 用于基本类型，reactive 用于对象
  • toRefs 解决 reactive 解构丢失响应性的问题
  • shallowRef/shallowReactive 提供浅层响应式
  • 了解响应式限制，避免常见陷阱
