网络性能优化

网络性能是分布式AI训练的关键因素，直接影响训练效率。

📊 网络性能指标

指标 定义 目标值
带宽 数据传输速率 接近线路容量
延迟 数据传输时间 <1ms（内部）
丢包率 丢失数据包比例 <0.01%
抖动 延迟变化幅度 <0.1ms
吞吐量 实际传输速率 80%+ 带宽

🔍 网络性能测试工具

# 1. iperf3 - 带宽测试 # 服务器端 iperf3 -s -p 5001 # 客户端 iperf3 -c server_ip -p 5001 -t 30 -P 4 # -t: 测试时长（秒） # -P: 并发连接数 # 双向测试 iperf3 -c server_ip -p 5001 -t 30 --bidir # 2. ping - 延迟测试 ping -c 100 target_host # 精确时间戳 ping -i 0.001 -c 1000 target_host # 3. traceroute - 路由追踪 traceroute target_host # 4. netstat - 连接统计 netstat -an | grep ESTABLISHED | wc -l # 查看端口连接 netstat -an | grep :5000 # 5. ss - 更快的socket统计 ss -s # 查看特定端口 ss -tnlp | grep :5000 # 6. ethtool - 网卡状态 ethtool eth0 # 查看网卡统计 ethtool -S eth0 # 7. sar - 网络统计 sar -n DEV 1 10 # 8. iftop - 实时流量监控 iftop -i eth0 # 9. nload - 流量监控 nload -u M eth0

🔧 网络优化策略

硬件优化

  • 使用高速网络（InfiniBand/RoCE）
  • 启用网卡多队列
  • 配置巨型帧（MTU 9000）
  • 使用RDMA加速通信
  • NUMA亲和性配置

软件优化

  • 优化TCP参数
  • 使用高性能协议
  • 通信计算重叠
  • 梯度压缩
  • 异步通信

优化建议

  • 选择合适协议 - 根据网络类型选择IB/RoCE/Ethernet
  • 优化通信频率 - 减少不必要的通信
  • 利用硬件加速 - 使用RDMA和GPU Direct
  • 平衡计算通信 - 计算通信重叠
  • 监控网络状态 - 实时监控网络性能
  • 定期性能测试 - 验证网络配置效果
