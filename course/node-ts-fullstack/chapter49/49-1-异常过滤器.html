49.1 异常过滤器

理解 NestJS 异常处理机制

🎯 学习目标

  • 理解异常过滤器的作用
  • 掌握异常过滤器的接口
  • 了解异常传播机制
  • 理解过滤器的应用场景

📚 什么是异常过滤器？

异常过滤器是处理应用中未捕获异常的组件。当异常抛出时，NestJS 会查找匹配的异常过滤器来处理该异常。

异常处理流程： 路由处理器抛出异常 ↓ 检查是否有匹配的过滤器 ├─ 有 → 执行过滤器的 catch 方法 │ ↓ │ 返回自定义响应 │ └─ 无 → 使用内置异常处理器 ↓ 返回标准错误响应
💡
异常过滤器特点

异常过滤器可以捕获特定类型的异常，返回自定义的响应格式，记录日志，或执行其他错误处理逻辑。

🔧 异常过滤器接口

import { ExceptionFilter, Catch, ArgumentsHost } from '@nestjs/common'; import { Request, Response } from 'express'; @Catch() // 捕获所有异常 export class AllExceptionsFilter implements ExceptionFilter { catch(exception: unknown, host: ArgumentsHost) { const ctx = host.switchToHttp(); const response = ctx.getResponse(); const request = ctx.getRequest(); const status = exception instanceof HttpException ? exception.getStatus() : HttpStatus.INTERNAL_SERVER_ERROR; const message = exception instanceof HttpException ? exception.getResponse() : 'Internal server error'; response.status(status).json({ code: status, message, timestamp: new Date().toISOString(), path: request.url, }); } } // ArgumentsHost 提供访问请求上下文的能力 interface ArgumentsHost { switchToHttp(): HttpArgumentsHost; switchToRpc(): RpcArgumentsHost; switchToWs(): WsArgumentsHost; }

🌐 异常过滤器作用范围

// 1. 方法级 @Controller('users') export class UsersController { @UseFilters(HttpExceptionFilter) @Get() findAll() {} } // 2. 控制器级 @Controller('users') @UseFilters(HttpExceptionFilter) export class UsersController {} // 3. 全局级 async function bootstrap() { const app = await NestFactory.create(AppModule); app.useGlobalFilters(new HttpExceptionFilter()); await app.listen(3000); } // 4. 模块级 @Module({ providers: [ { provide: APP_FILTER, useClass: HttpExceptionFilter, }, ], }) export class AppModule {}

🔄 异常过滤器与其他组件

组件 处理时机 主要用途
管道 参数验证时 验证失败抛出异常
守卫 权限验证时 权限拒绝抛出异常
拦截器 方法执行后 可捕获方法异常
过滤器 异常抛出后 统一处理异常响应
⚠️
过滤器执行

当异常被抛出时，NestJS 会从最近的作用域开始查找匹配的过滤器。找到匹配的过滤器后，异常不会再继续传播。
