30.2 Express 应用生成器

使用 express-generator 快速创建项目脚手架

🎯 学习目标

  • 掌握 express-generator 的安装和使用
  • 了解生成器创建的项目结构
  • 学会自定义项目生成选项
  • 理解生成项目的配置文件

🔧 什么是 Express 应用生成器

Express 应用生成器（express-generator）是一个官方提供的脚手架工具，可以快速创建一个完整的 Express 项目骨架。它自动生成项目目录结构、配置文件、示例路由等，大大提高开发效率。

💡
何时使用生成器

对于初学者，建议先手动创建项目理解每个文件的作用。熟练后可以使用生成器快速搭建项目。

📥 安装 express-generator

使用 npm 全局安装 express-generator：

# 使用 npm 安装 npm install -g express-generator # 或使用 npx 直接运行（无需全局安装） npx express-generator myapp # 查看帮助信息 express --help

常用命令选项

选项 说明 示例
-v, --view <engine> 指定模板引擎 express -v ejs myapp
-c, --css <engine> 指定 CSS 预处理器 express -c sass myapp
--git 添加 .gitignore 文件 express --git myapp
-f, --force 强制覆盖已存在的目录 express -f myapp
--no-view 不使用模板引擎（API项目） express --no-view myapp

📁 项目结构解析

生成器创建的项目结构如下：

my-express-app/ ├── bin/ │ └── www # 启动脚本，创建 HTTP 服务器 ├── public/ # 静态资源目录 │ ├── images/ # 图片资源 │ ├── javascripts/ # JavaScript 文件 │ └── stylesheets/ # CSS 样式文件 ├── routes/ # 路由目录 │ ├── index.js # 首页路由 │ └── users.js # 用户路由 ├── views/ # 模板文件目录 │ ├── error.ejs # 错误页面 │ └── index.ejs # 首页模板 ├── app.js # 应用主入口文件 └── package.json # 项目配置文件

各目录/文件说明

文件/目录 作用
bin/www 应用启动入口，创建 HTTP 服务器并监听端口
public/ 存放静态文件（CSS、JS、图片等），直接对外提供访问
routes/ 存放路由处理逻辑，按功能模块划分
views/ 存放模板文件，用于渲染动态页面
app.js 应用配置中心，配置中间件、路由等

⚙️ 核心文件详解

app.js - 应用主入口

// app.js 核心配置 var createError = require('http-errors'); var express = require('express'); var path = require('path'); var cookieParser = require('cookie-parser'); var logger = require('morgan'); // 引入路由 var indexRouter = require('./routes/index'); var usersRouter = require('./routes/users'); var app = express(); // 1. 视图引擎设置 app.set('views', path.join(__dirname, 'views')); app.set('view engine', 'ejs'); // 2. 使用中间件 app.use(logger('dev')); // 日志记录 app.use(express.json()); // 解析 JSON 请求体 app.use(express.urlencoded({ extended: false })); // 解析 URL 编码 app.use(cookieParser()); // Cookie 解析 app.use(express.static(path.join(__dirname, 'public'))); // 静态文件 // 3. 注册路由 app.use('/', indexRouter); app.use('/users', usersRouter); // 4. 404 错误处理 app.use(function(req, res, next) { next(createError(404)); }); // 5. 全局错误处理 app.use(function(err, req, res, next) { res.locals.message = err.message; res.locals.error = req.app.get('env') === 'development' ? err : {}; res.status(err.status || 500); res.render('error'); }); module.exports = app;

bin/www - 启动脚本

#!/usr/bin/env node // 引入 app var app = require('../app'); var debug = require('debug')('my-express-app:server'); var http = require('http'); // 获取端口 var port = normalizePort(process.env.PORT || '3000'); app.set('port', port); // 创建 HTTP 服务器 var server = http.createServer(app); // 监听端口 server.listen(port); server.on('error', onError); server.on('listening', onListening); // 端口标准化函数 function normalizePort(val) { var port = parseInt(val, 10); if (isNaN(port)) return val; if (port >= 0) return port; return false; } // 错误处理 function onError(error) { if (error.syscall !== 'listen') throw error; // ... 错误处理逻辑 } // 监听回调 function onListening() { var addr = server.address(); debug('Listening on ' + addr.port); }

🎨 不同模板引擎的项目

生成器支持多种模板引擎，不同引擎生成的文件略有不同：

# EJS 模板引擎（推荐初学者） express -v ejs my-ejs-app # Pug 模板引擎（原 Jade） express -v pug my-pug-app # Handlebars 模板引擎 express -v hbs my-hbs-app # 不使用模板（适合纯 API 项目） express --no-view my-api-app
⚠️
模板引擎选择

EJS 语法接近 HTML，学习成本低；Pug 语法简洁但需要适应；对于纯 API 项目，可以不使用模板引擎。

📝 package.json 配置

{ "name": "my-express-app", "version": "0.0.0", "private": true, "scripts": { "start": "node ./bin/www", "dev": "nodemon ./bin/www" // 手动添加开发脚本 }, "dependencies": { "cookie-parser": "~1.4.4", "debug": "~2.6.9", "ejs": "~2.6.1", "express": "~4.16.1", "http-errors": "~1.6.3", "morgan": "~1.9.1" }, "devDependencies": { "nodemon": "^2.0.0" // 手动添加 } }

✅ 小结

📌
本节要点
  • express-generator 是官方脚手架工具，可快速生成项目骨架
  • 支持自定义模板引擎、CSS 预处理器等选项
  • 生成的项目结构清晰，包含路由、视图、静态文件等目录
  • app.js 是核心配置文件，bin/www 是启动脚本
  • 对于 API 项目可使用 --no-view 选项
