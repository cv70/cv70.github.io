23.2 实体定义

使用装饰器定义数据库实体

🎯 学习目标

  • 掌握 @Entity 装饰器的使用
  • 学会定义各种列类型
  • 理解主键和自动生成策略
  • 了解列选项配置

📚 基础实体定义

import { Entity, PrimaryGeneratedColumn, Column, CreateDateColumn, UpdateDateColumn, } from 'typeorm'; @Entity('users') // 指定表名 export class User { @PrimaryGeneratedColumn('increment') // 自增主键 id: number; @Column({ type: 'varchar', length: 50, unique: true }) username: string; @Column({ type: 'varchar', length: 100 }) email: string; @Column({ type: 'varchar', length: 255, select: false }) // 默认不查询 password: string; @Column({ type: 'int', default: 0 }) age: number; @Column({ type: 'enum', enum: ['active', 'inactive'], default: 'active' }) status: string; @Column({ type: 'text', nullable: true }) bio: string | null; @CreateDateColumn({ type: 'timestamp' }) createdAt: Date; @UpdateDateColumn({ type: 'timestamp' }) updatedAt: Date; } // 对应的 SQL CREATE TABLE `users` ( `id` int NOT NULL AUTO_INCREMENT, `username` varchar(50) NOT NULL, `email` varchar(100) NOT NULL, `password` varchar(255) NOT NULL, `age` int DEFAULT 0, `status` enum('active','inactive') DEFAULT 'active', `bio` text, `createdAt` timestamp DEFAULT CURRENT_TIMESTAMP, `updatedAt` timestamp DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP, PRIMARY KEY (`id`), UNIQUE KEY `username` (`username`) );

🔧 主键策略

// 1. 自增主键 @PrimaryGeneratedColumn('increment') id: number; // 2. UUID 主键 @PrimaryGeneratedColumn('uuid') id: string; // 3. 自定义主键 @PrimaryColumn({ type: 'varchar', length: 36 }) id: string; // 4. 复合主键 @Entity() export class OrderItem { @PrimaryColumn() orderId: number; @PrimaryColumn() productId: number; @Column() quantity: number; } // 5. 使用 uuid 库生成主键 import { v4 as uuidv4 } from 'uuid'; @Entity() export class User { @PrimaryColumn({ type: 'uuid' }) id: string = uuidv4(); }
💡
选择主键策略

自增主键性能好，适合单机；UUID 适合分布式系统，但索引性能略差。实际项目中可根据需求选择。

📊 列类型映射

// 字符串类型 @Column({ type: 'varchar', length: 100 }) name: string; @Column({ type: 'text' }) content: string; @Column({ type: 'char', length: 2 }) countryCode: string; // 数字类型 @Column({ type: 'int' }) age: number; @Column({ type: 'bigint' }) views: number; @Column({ type: 'decimal', precision: 10, scale: 2 }) price: number; @Column({ type: 'float' }) rating: number; // 布尔类型 @Column({ type: 'boolean', default: false }) isActive: boolean; // 日期类型 @Column({ type: 'date' }) birthDate: Date; @Column({ type: 'datetime' }) lastLoginAt: Date; @Column({ type: 'timestamp' }) createdAt: Date; // JSON 类型 @Column({ type: 'json' }) metadata: Record; @Column({ type: 'simple-json' }) // 自动序列化/反序列化 preferences: { theme: string; language: string }; // 枚举类型 export enum UserRole { ADMIN = 'admin', USER = 'user', GUEST = 'guest', } @Column({ type: 'enum', enum: UserRole, default: UserRole.USER }) role: UserRole; // 二进制类型 @Column({ type: 'blob' }) avatar: Buffer;

⚙️ 列选项配置

@Column({ // 列名（默认使用属性名） name: 'user_name', // 数据类型 type: 'varchar', // 长度 length: 100, // 是否可空 nullable: true, // 默认值 default: 'guest', // 唯一约束 unique: true, // 注释 comment: '用户名，唯一标识用户', // 排序 order: 1, // 是否包含在 SELECT 中 select: false, // 插入时的默认值 insert: true, // 更新时是否包含 update: true, // 索引 index: true, // 非空约束 readonly: false, }) username: string; // 使用 Transformer 转换数据 @Column({ type: 'varchar', transformer: { to(value: string[]): string { return value.join(','); // 存储时转为字符串 }, from(value: string): string[] { return value.split(','); // 读取时转为数组 }, }, }) tags: string[];

📝 本节小结

✅
  • • @Entity 装饰器标记类为数据库实体
  • • @PrimaryGeneratedColumn 定义自增主键
  • • @Column 定义普通列，支持多种类型和选项
  • • Transformer 可自定义数据转换逻辑
