组件的数据管理

📚 Props：组件的输入

// Props 是父组件传递给子组件的数据 // Props 是只读的，子组件不能修改 // 基本用法 function Greeting({ name, age, isActive }) { return ( <div> <h1>Hello, {name}!</h1> <p>Age: {age}</p> <p>Status: {isActive ? 'Active' : 'Inactive'}</p> </div> ); } // 使用组件 <Greeting name="Alice" age={25} isActive={true} /> // 默认值 function Greeting({ name = 'Guest', age = 0 }) { return <h1>Hello, {name}! Age: {age}</h1>; } // Props 类型检查（TypeScript） interface GreetingProps { name: string; age: number; isActive?: boolean; // 可选 } function Greeting({ name, age, isActive = false }: GreetingProps) { // ... } // 传递所有 props function Wrapper(props) { return <div {...props} />; } // 传递部分 props function Button({ variant, ...rest }) { return <button className={`btn-${variant}`} {...rest} />; }

🔧 State：组件的内部状态

// State 是组件内部的可变数据 // 使用 useState Hook 管理 import { useState } from 'react'; function Counter() { // const [状态值, 设置函数] = useState(初始值); const [count, setCount] = useState(0); return ( <div> <p>Count: {count}</p> <button onClick={() => setCount(count + 1)}>+1</button> <button onClick={() => setCount(count - 1)}>-1</button> <button onClick={() => setCount(0)}>Reset</button> </div> ); } // 对象状态 function UserForm() { const [user, setUser] = useState({ name: '', email: '', age: 0, }); const updateName = (e) => { // 使用展开运算符保留其他属性 setUser({ ...user, name: e.target.value }); }; // 或使用函数式更新 const updateEmail = (e) => { setUser(prev => ({ ...prev, email: e.target.value })); }; return ( <form> <input value={user.name} onChange={updateName} /> <input value={user.email} onChange={updateEmail} /> </form> ); } // 数组状态 function TodoList() { const [todos, setTodos] = useState([]); const addTodo = (text) => { setTodos([...todos, { id: Date.now(), text, done: false }]); }; const toggleTodo = (id) => { setTodos(todos.map(todo => todo.id === id ? { ...todo, done: !todo.done } : todo )); }; const removeTodo = (id) => { setTodos(todos.filter(todo => todo.id !== id)); }; return ( <ul> {todos.map(todo => ( <li key={todo.id}> <input type="checkbox" checked={todo.done} onChange={() => toggleTodo(todo.id)} /> {todo.text} </li> ))} </ul> ); }

📊 Props vs State

💡
Props 与 State 对比

Props：
- 由父组件传递
- 只读，不可修改
- 用于组件间通信

State：
- 组件内部管理
- 可通过 setState 修改
- 用于存储组件状态

📝 本节小结

✅
  • • Props 是父组件传递的数据，只读
  • • State 是组件内部状态，可修改
  • • 使用 useState Hook 管理状态
  • • 更新对象/数组时使用展开运算符
