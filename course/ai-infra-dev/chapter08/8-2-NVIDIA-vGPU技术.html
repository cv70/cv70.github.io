NVIDIA vGPU简介

NVIDIA vGPU是NVIDIA提供的GPU虚拟化解决方案，通过在Hypervisor层实现GPU资源切分， 为每个虚拟机提供专用的GPU资源，在性能、隔离性和成本之间达到最佳平衡。

⚙️ vGPU配置文件

vGPU Profile配置

vGPU Profile定义：

A100配置:
• A100-80GB: 80GB HBM2e, 1.55 TB/s
• A100-40GB: 40GB HBM2e, 1.55 TB/s

vGPU切分选项 (A100 80GB):
• MIG 1g.5gb: 1/16 GPU, 5GB显存
• MIG 2g.10gb: 1/8 GPU, 10GB显存
• MIG 3g.20gb: 1/4 GPU, 20GB显存
• MIG 4g.20gb: 1/4 GPU, 20GB显存
• MIG 7g.40gb: 1/2 GPU, 40GB显存

vGPU类型:
• C系列: Compute优化 (训练)
• Q系列: Quadro优化 (图形)
• B系列: Business优化 (推理)

示例:
• A100D-80C: 80GB, Compute, 全GPU
• A100-8C: 1/10 GPU, 8GB显存

💻 vGPU部署

宿主机配置

VMware ESXi配置：

# 1. 安装vGPU驱动
sudo rpm -ivh NVIDIA-vGPU-guest-vmware-driver.x86_64.rpm

# 2. 启用vGPU
vim /etc/vmware/config
NVIDIA.vgpu.enabled = "TRUE"

# 3. 重启ESXi
reboot

# 4. 验证vGPU状态
nvidia-smi vgpu

# 查看vGPU信息
nvidia-smi -L
GPU 0: A100-SXM4-80GB (UUID: GPU-xxx)
GPU 1: A100-SXM4-80GB (UUID: GPU-yyy)

虚拟机配置

VM配置：

# 1. 分配vGPU
VM Settings > Add Hardware > PCI Device
选择: NVIDIA A100 vGPU Profile: A100-4C

# 2. 配置虚拟机
CPU: 16 vCPU
Memory: 64GB
GPU: vGPU A100-4C (8GB)

# 3. 启动虚拟机并安装驱动
wget https://developer.nvidia.com/
    compute/virtualization/
    linux/repo/ubuntu2004/x86_64/
    NVIDIA-vGPU-guest-ubuntu20.04.deb

sudo dpkg -i NVIDIA-vGPU-guest-*.deb

# 4. 验证
nvidia-smi

📊 vGPU性能优化

性能调优建议

vGPU性能优化：

1. 调整vGPU配置
   • 增加显存: 减少OOM
   • 增加vCPU: 提升CPU性能
   • 调整Profile: 匹配工作负载

2. 优化虚拟机配置
   • CPU亲和性: 固定vCPU
   • 内存预留: 防止swap
   • NUMA优化: 本地内存访问

3. 网络优化
   • SR-IOV: 网络直通
   • DPDK: 绕过内核
   • RDMA: 低延迟

4. 存储优化
   • 使用SSD: 减少IO延迟
   • 直通存储: 绕过虚拟化
   • 数据本地化: 减少网络传输
