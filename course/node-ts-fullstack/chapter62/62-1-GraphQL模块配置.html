62.1 GraphQL 模块配置

NestJS GraphQL 模块配置详解

📖 NestJS GraphQL 简介

NestJS 提供了 @nestjs/graphql 包，支持两种开发模式：代码优先（Code First）和 Schema 优先（Schema First）。

代码优先

使用 TypeScript 装饰器定义类型，自动生成 Schema

  • TypeScript 类型同步
  • 开发效率高
  • 减少重复代码

Schema 优先

先定义 GraphQL Schema，再实现 Resolver

  • Schema 即文档
  • 前后端并行开发
  • 更好的 API 设计

⚙️ 安装与配置

安装依赖

# 安装 GraphQL 相关依赖 npm install @nestjs/graphql @nestjs/apollo graphql apollo-server-express

基本配置

import { Module } from '@nestjs/common'; import { GraphQLModule } from '@nestjs/graphql'; import { ApolloDriver, ApolloDriverConfig } from '@nestjs/apollo'; import { join } from 'path'; @Module({ imports: [ GraphQLModule.forRoot({ driver: ApolloDriver, // Schema 文件路径 typePaths: ['./**/*.graphql'], // 或使用代码优先 autoSchemaFile: join(process.cwd(), 'src/schema.gql'), // 开发环境启用 Playground playground: true, // 调试模式 debug: true, // 路径配置 path: '/graphql', // CORS 配置 cors: { origin: true, credentials: true, }, }), ], }) export class AppModule {}

🔧 完整配置选项

GraphQLModule.forRoot({ driver: ApolloDriver, // === Schema 配置 === // Schema 优先模式 typePaths: ['./**/*.graphql'], // 代码优先模式 autoSchemaFile: true, // 自动生成到内存 autoSchemaFile: join(process.cwd(), 'src/schema.gql'), // 生成到文件 // Schema 配置 sortSchema: true, // 排序 Schema // === 调试配置 === debug: process.env.NODE_ENV !== 'production', playground: process.env.NODE_ENV !== 'production', introspection: true, // 允许 Schema 内省 // === 路径配置 === path: '/graphql', // === Context 配置 === context: ({ req, res }) => ({ req, res, user: req.user, }), // === 格式化错误 === formatError: (error) => { const graphQLFormattedError = { message: error.message, code: error.extensions?.code, statusCode: error.extensions?.statusCode, }; return graphQLFormattedError; }, // === 响应格式化 === formatResponse: (response) => { return response; }, // === 插件 === plugins: [], // === 订阅配置 === subscriptions: { 'graphql-ws': true, }, // === 缓存配置 === cache: 'bounded', // === 安全校验 === csrfPrevention: true, persistedQueries: false, // 禁用持久化查询 })

🔐 Context 配置

import { Module } from '@nestjs/common'; import { GraphQLModule } from '@nestjs/graphql'; import { ApolloDriver, ApolloDriverConfig } from '@nestjs/apollo'; @Module({ imports: [ GraphQLModule.forRoot({ driver: ApolloDriver, autoSchemaFile: true, context: ({ req, res }) => { const token = req.headers.authorization?.split(' ')[1]; return { req, res, token, }; }, }), ], }) export class AppModule {} // 异步配置 GraphQLModule.forRootAsync({ driver: ApolloDriver, imports: [ConfigModule], inject: [ConfigService], useFactory: async (configService: ConfigService) => ({ autoSchemaFile: true, playground: configService.get('NODE_ENV') !== 'production', debug: configService.get('NODE_ENV') !== 'production', }), })

📝 小结

  • NestJS 支持代码优先和 Schema 优先两种模式
  • autoSchemaFile 配置代码优先模式
  • typePaths 配置 Schema 优先模式
  • Context 用于传递请求上下文
  • formatError 统一错误格式
  • 生产环境应关闭 playground 和 debug
