30.5 请求与响应对象

深入了解 Express 的 Request 和 Response 对象

🎯 学习目标

  • 掌握 Request 对象的常用属性和方法
  • 掌握 Response 对象的常用属性和方法
  • 理解请求生命周期中对象的传递
  • 学会正确处理请求和发送响应

📥 Request 对象 (req)

Request 对象（通常简写为 req）代表了 HTTP 请求，包含请求查询字符串、参数、体、HTTP 头等信息。

常用属性

属性 说明 示例
req.params 路由参数（命名参数） /users/:id 中的 id
req.query 查询字符串参数 ?page=1&size=10
req.body 请求体数据（需中间件解析） POST/PUT 数据
req.headers 请求头对象 req.headers['content-type']
req.method HTTP 请求方法 GET, POST, PUT...
req.url 请求 URL 路径 /api/users?page=1
req.path 请求路径（不含查询字符串） /api/users
req.hostname 主机名 localhost
req.ip 客户端 IP 地址 ::1 或 127.0.0.1
req.protocol 请求协议 http 或 https
req.cookies Cookies 对象（需 cookie-parser） req.cookies.sessionId

获取请求参数示例

// 路由参数 app.get('/users/:id', (req, res) => { const { id } = req.params; console.log('路由参数:', id); res.json({ userId: id }); }); // 查询字符串 app.get('/search', (req, res) => { const { keyword, page, size } = req.query; console.log('查询参数:', { keyword, page, size }); res.json({ keyword, page, size }); }); // 请求体 app.post('/users', (req, res) => { const { name, email, age } = req.body; console.log('请求体:', req.body); res.json({ name, email, age }); });

🔧 Request 常用方法

req.get(name) - 获取请求头

app.get('/info', (req, res) => { const contentType = req.get('Content-Type'); const userAgent = req.get('User-Agent'); const auth = req.get('Authorization'); res.json({ contentType, userAgent, auth }); });

req.accepts(types) - 检查可接受的类型

app.get('/content', (req, res) => { // 检查客户端接受的内容类型 const accepted = req.accepts(['json', 'html', 'xml']); if (accepted === 'json') { res.json({ message: 'JSON response' }); } else if (accepted === 'html') { res.send('

HTML Response

'); } else { res.status(406).send('Not Acceptable'); } });

req.is(type) - 检查请求体类型

app.post('/upload', (req, res) => { if (req.is('application/json')) { // 处理 JSON res.json({ received: req.body }); } else if (req.is('multipart/form-data')) { // 处理文件上传 res.send('File upload'); } else { res.status(415).send('Unsupported Media Type'); } });

其他实用方法

// 检查是否为 AJAX 请求 app.get('/check', (req, res) => { if (req.xhr) { res.json({ isAjax: true }); } else { res.send('Not an AJAX request'); } }); // 获取原始请求对象 app.get('/raw', (req, res) => { // req 是增强后的对象 // req.req 或 req.raw 是原始的 Node.js IncomingMessage res.json({ httpVersion: req.httpVersion, originalUrl: req.originalUrl }); });

📤 Response 对象 (res)

Response 对象（通常简写为 res）代表了 HTTP 响应，在 Express 应用收到请求时生成。

常用方法

方法 说明 用途
res.send() 发送响应 发送各种类型的响应
res.json() 发送 JSON 响应 API 响应
res.status() 设置状态码 配合其他方法使用
res.redirect() 重定向 页面跳转
res.render() 渲染模板 服务端渲染
res.sendFile() 发送文件 文件下载/展示
res.download() 下载文件 文件下载
res.set() 设置响应头 自定义响应头
res.cookie() 设置 Cookie 会话管理
res.clearCookie() 清除 Cookie 登出等操作

🚀 Response 方法详解

res.send() - 发送响应

// 发送字符串 app.get('/text', (req, res) => { res.send('Hello World'); }); // 发送 HTML app.get('/html', (req, res) => { res.send('

Hello World

'); }); // 发送对象（自动转为 JSON） app.get('/object', (req, res) => { res.send({ message: 'Hello' }); }); // 发送数组 app.get('/array', (req, res) => { res.send([1, 2, 3, 4, 5]); }); // 发送 Buffer app.get('/buffer', (req, res) => { res.send(Buffer.from('Hello')); });
💡
res.send() 自动设置 Content-Type

res.send() 会根据发送内容的类型自动设置 Content-Type 头。发送对象/数组时自动设为 application/json。

res.json() - 发送 JSON

// 明确发送 JSON 响应 app.get('/api/data', (req, res) => { res.json({ success: true, data: { users: [ { id: 1, name: 'Alice' }, { id: 2, name: 'Bob' } ] } }); }); // 设置状态码 app.get('/api/created', (req, res) => { res.status(201).json({ success: true, message: 'Resource created' }); });

res.status() - 设置状态码

// 常见状态码使用 app.get('/success', (req, res) => { res.status(200).json({ message: 'Success' }); }); app.post('/created', (req, res) => { res.status(201).json({ message: 'Created' }); }); app.get('/not-found', (req, res) => { res.status(404).json({ error: 'Not Found' }); }); app.get('/error', (req, res) => { res.status(500).json({ error: 'Internal Server Error' }); }); // 链式调用 app.get('/chain', (req, res) => { res .status(200) .set('X-Custom-Header', 'value') .json({ message: 'Chained response' }); });

res.redirect() - 重定向

// 默认 302 重定向 app.get('/old', (req, res) => { res.redirect('/new'); }); // 301 永久重定向 app.get('/permanent', (req, res) => { res.redirect(301, '/new-location'); }); // 重定向到外部网站 app.get('/external', (req, res) => { res.redirect('https://www.google.com'); }); // 返回上一页 app.get('/back', (req, res) => { res.redirect('back'); });

res.set() / res.setHeader() - 设置响应头

// 设置单个响应头 app.get('/header', (req, res) => { res.set('Content-Type', 'text/plain'); res.send('Plain text'); }); // 设置多个响应头 app.get('/headers', (req, res) => { res.set({ 'Content-Type': 'application/json', 'X-Custom-Header': 'custom-value', 'Cache-Control': 'no-cache' }); res.json({ message: 'Headers set' }); }); // CORS 相关设置 app.get('/cors', (req, res) => { res.set({ 'Access-Control-Allow-Origin': '*', 'Access-Control-Allow-Methods': 'GET, POST, PUT, DELETE' }); res.json({ cors: 'enabled' }); });

res.cookie() / res.clearCookie() - Cookie 操作

// 设置 Cookie app.get('/set-cookie', (req, res) => { res.cookie('sessionId', 'abc123', { maxAge: 900000, // 过期时间（毫秒） httpOnly: true, // 仅服务器可访问 secure: true, // 仅 HTTPS 传输 sameSite: 'strict', // CSRF 防护 domain: 'example.com', path: '/' }); res.send('Cookie set'); }); // 清除 Cookie app.get('/clear-cookie', (req, res) => { res.clearCookie('sessionId'); res.send('Cookie cleared'); });

📊 HTTP 状态码参考

状态码 名称 使用场景
200 OK 请求成功
201 Created 资源创建成功
204 No Content 成功但无返回内容（DELETE）
301 Moved Permanently 永久重定向
302 Found 临时重定向
304 Not Modified 资源未修改（缓存）
400 Bad Request 请求参数错误
401 Unauthorized 未认证
403 Forbidden 无权限
404 Not Found 资源不存在
409 Conflict 资源冲突
422 Unprocessable Entity 语义错误
429 Too Many Requests 请求过于频繁
500 Internal Server Error 服务器错误
502 Bad Gateway 网关错误
503 Service Unavailable 服务不可用

✅ 小结

📌
本节要点
  • Request 对象包含请求的所有信息：params、query、body、headers 等
  • Response 对象用于发送响应：send、json、status、redirect 等
  • res.send() 自动设置 Content-Type，res.json() 明确返回 JSON
  • 使用 res.status() 设置状态码，正确使用 HTTP 状态码很重要
  • 可以链式调用 response 方法，提高代码可读性

  • 创建一个完整的 CRUD API，正确使用状态码
