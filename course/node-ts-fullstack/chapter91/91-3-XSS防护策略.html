91.3 XSS 防护策略

多层次的 XSS 防护方案

🎯 学习目标

  • 掌握 XSS 防护的核心原则
  • 学会输出编码技术
  • 理解 CSP 策略配置
  • 了解安全编码实践

📚 防护原则

# XSS 防护核心原则 ## 1. 永远不要信任用户输入 所有输入都可能是恶意的，必须进行处理 ## 2. 输出编码 根据输出上下文进行编码，是最有效的防护方式 ## 3. 内容安全策略 (CSP) 限制资源加载来源，防止未授权脚本执行 ## 4. Cookie 安全 设置 HttpOnly 和 Secure 属性 ## 5. 纵深防御 多种防护措施组合使用 # 防护层次 输入验证 → 输出编码 → CSP 策略 → Cookie 安全 → 监控审计

🔧 输出编码

# HTML 上下文编码 import escapeHtml from 'escape-html'; // 转义特殊字符 function escapeHtml(str: string): string { return str .replace(/&/g, '&') .replace(//g, '>') .replace(/"/g, '"') .replace(/'/g, '''); } // 使用 res.send(`<div>${escapeHtml(userInput)}</div>`); # HTML 属性编码 function escapeAttr(str: string): string { return str .replace(/&/g, '&') .replace(/"/g, '"'); } // 使用 res.send(`<div title="${escapeAttr(userInput)}"></div>`); # JavaScript 上下文编码 // 使用 JSON.stringify 自动转义 res.send(`<script>var data = ${JSON.stringify(userInput)};</script>`); # URL 编码 const encoded = encodeURIComponent(userInput); res.redirect(`/search?q=${encoded}`); # CSS 上下文编码 // 避免用户输入动态生成 CSS // 如果必须，使用严格白名单 function escapeCss(str: string): string { return str.replace(/[^\w-]/g, ''); } # 使用模板引擎自动编码 // EJS（自动编码） <%= userInput %> // Pug（自动编码） #{userInput} // React（自动编码） <div>{userInput}</div>
💡
编码库推荐

推荐使用成熟的编码库如 escape-html、xss、DOMPurify 等，而不是自己实现编码函数。

⚙️ DOM 安全操作

# 避免 innerHTML，使用安全的 DOM 操作 // 危险 ❌ element.innerHTML = userInput; document.write(userInput); // 安全 ✅ element.textContent = userInput; element.innerText = userInput; // 创建元素 const div = document.createElement('div'); div.textContent = userInput; element.appendChild(div); // 使用 DOMPurify 清理 HTML import DOMPurify from 'dompurify'; // 清理并允许部分标签 const clean = DOMPurify.sanitize(userInput, { ALLOWED_TAGS: ['p', 'b', 'i', 'em', 'strong'], ALLOWED_ATTR: [], }); element.innerHTML = clean; # Vue.js 安全实践 // 模板中自动转义 <div>{{ userInput }}</div> // 安全 // v-html 需要谨慎 <div v-html="userInput"></div> // 危险！需要先清理 // 使用 v-html 前清理 const safeHtml = DOMPurify.sanitize(userInput); # React 安全实践 // JSX 自动转义 <div>{userInput}</div> // 安全 // dangerouslySetInnerHTML 需要谨慎 <div dangerouslySetInnerHTML={{ __html: userInput }} /> // 危险！ // 使用前清理 <div dangerouslySetInnerHTML={{ __html: DOMPurify.sanitize(userInput) }} />

🚀 Cookie 安全设置

# 设置 Cookie 安全属性 // Express 设置安全 Cookie res.cookie('session', token, { httpOnly: true, // 防止 JavaScript 读取 secure: true, // 仅 HTTPS 传输 sameSite: 'strict', // 防止 CSRF maxAge: 3600000, // 过期时间 path: '/', domain: 'example.com', }); // Session 配置 app.use(session({ secret: process.env.SESSION_SECRET, resave: false, saveUninitialized: false, cookie: { httpOnly: true, secure: process.env.NODE_ENV === 'production', sameSite: 'strict', maxAge: 3600000, }, })); # Cookie 属性说明 ## HttpOnly - 防止 JavaScript 通过 document.cookie 读取 - 有效防止 XSS 窃取 Cookie ## Secure - 仅通过 HTTPS 传输 - 防止中间人攻击 ## SameSite - Strict: 完全禁止跨站发送 - Lax: 允许 GET 请求跨站发送 - None: 允许跨站发送（需要 Secure）

📝 本节小结

✅
  • • 输出编码是最有效的 XSS 防护方式
  • • 根据输出上下文选择正确的编码方式
  • • 使用 textContent 代替 innerHTML
  • • Cookie 设置 HttpOnly 防止窃取
