SPI协议概述

SPI（Serial Peripheral Interface）即串行外设接口，是一种高速、 全双工、同步的串行通信总线。SPI由Motorola公司开发，现已广泛应用于各种微控制器和外设芯片， 如Flash存储器、ADC、DAC、显示控制器等。

💡 SPI核心特性

🎓

Why - 为什么选择

SPI速度快、硬件简单、支持全双工，适合高速数据传输

🚀

What - 核心特点

同步通信、全双工、主从模式、高速传输

🏗️

How - 如何工作

主设备产生时钟，控制片选，同步收发数据

⚙️ SPI信号线定义

信号名称 缩写 方向 功能说明
Serial Clock SCLK/CLK 主→从 时钟信号，由主设备产生，控制数据采样时机
Master Output Slave Input MOSI 主→从 主设备数据输出线，从设备数据输入线
Master Input Slave Output MISO 从→主 从设备数据输出线，主设备数据输入线
Chip Select CS/NSS 主→从 片选信号，低电平有效，选择从设备

📊 SPI与其他总线对比

特性 SPI I2C UART
通信方式 同步全双工 同步半双工 异步全双工
信号线数 4根(最少3根) 2根 2根
通信速率 高(可达MHz级) 中(400kHz~1MHz) 低~中(115.2kbps~1Mbps)
设备数量 一主多从 多主多从 点对点
硬件复杂度 简单 中等(需上拉电阻) 最简单
✨
最佳实践

SPI通信特点：(1)主设备控制时钟和片选；(2)数据在时钟边沿同步传输； (3)同时进行发送和接收(全双工)；(4)高位先发(MSB First)；(5)无固定协议，数据格式由设备定义。

⚠️
注意事项

SPI没有应答机制和硬件流控，需软件协议保证数据可靠性。 通信过程中必须保持CS信号稳定，否则会导致数据错乱。 时钟频率不应超过设备的最大规格要求。

📝 本节小结

✅
  • • SPI是同步全双工串行总线，由4根信号线组成：SCLK、MOSI、MISO、CS
  • • 主设备产生时钟信号，控制片选，从设备被动响应
  • • 支持高速传输(可达MHz级别)，适合Flash、传感器等高速设备
  • • 主从架构，通常一个主设备连接多个从设备
