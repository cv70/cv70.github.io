75.2 JSX 语法

JavaScript 的语法扩展

🎯 学习目标

  • 理解 JSX 的本质
  • 掌握 JSX 基本语法
  • 学会在 JSX 中使用表达式
  • 了解 JSX 的编译原理

📚 JSX 基础语法

// JSX 是 JavaScript 的语法扩展，用于描述 UI // JSX 看起来像 HTML，但实际上是 JavaScript // 基本 JSX const element = <h1>Hello, React!</h1>; // JSX 编译后 const element = React.createElement('h1', null, 'Hello, React!'); // JSX 中的表达式 const name = 'Alice'; const element = <h1>Hello, {name}!</h1>; // 使用函数 const formatName = (user) => `${user.firstName} ${user.lastName}`; const user = { firstName: 'Alice', lastName: 'Smith' }; const element = <h1>Hello, {formatName(user)}!</h1>; // JSX 本身也是表达式 function getGreeting(user) { if (user) { return <h1>Hello, {formatName(user)}!</h1>; } return <h1>Hello, Stranger.</h1>; }

🔧 JSX 属性与子元素

// JSX 属性 const element = <div id="root" className="container"></div>; // 使用 className 代替 class const element = <div className="active">Active</div>; // 使用 htmlFor 代替 for const element = <label htmlFor="email">Email</label>; // 行内样式（驼峰命名） const style = { backgroundColor: 'blue', fontSize: '14px', padding: '10px 20px', }; const element = <div style={style}>Styled Div</div>; // JSX 子元素 // 字符串字面量 const element = <div>Hello World</div>; // 嵌套元素 const element = ( <div> <h1>Title</h1> <p>Paragraph</p> </div> ); // JavaScript 表达式作为子元素 const items = ['Apple', 'Banana', 'Orange']; const element = ( <ul> {items.map((item, index) => ( <li key={index}>{item}</li> ))} </ul> ); // 布尔值、null、undefined 会被忽略 const element = ( <div> {false} {null} {undefined} {true} {/* 这些都不会渲染 */} </div> );

📊 JSX 规则

💡
JSX 使用规则

1. 返回单个根元素
2. 标签必须闭合
3. 属性使用驼峰命名
4. JavaScript 表达式用 {} 包裹
5. 条件渲染使用 && 或三元运算符

📝 本节小结

✅
  • • JSX 是 JavaScript 的语法扩展
  • • JSX 会被编译为 React.createElement 调用
  • • 使用 {} 在 JSX 中嵌入 JavaScript 表达式
  • • 遵循 JSX 规则，避免常见错误
