21.2 Chain设计模式

串联多个处理步骤

🎯 学习目标

什么是Chain

Chain是将多个组件串联执行的设计模式。通过Chain可以将LLM调用、提示模板、输出解析等组合成完整的处理流程。

💻 LCEL链式调用

from langchain_core.prompts import ChatPromptTemplate from langchain_openai import ChatOpenAI from langchain_core.output_parsers import StrOutputParser # 创建组件 prompt = ChatPromptTemplate.from_template("告诉我关于{topic}的知识") model = ChatOpenAI() parser = StrOutputParser() # 使用LCEL串联 chain = prompt | model | parser # 执行 result = chain.invoke({"topic": "人工智能"})
💡
LCEL优势

LangChain Expression Language (LCEL)使用管道符|串联组件，简洁直观，支持流式输出和异步调用。
