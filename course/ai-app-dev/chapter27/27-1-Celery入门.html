Celery简介

Celery是Python最流行的分布式任务队列，适合处理耗时的异步任务，如文档处理、模型训练等。

💻 Celery基本使用

from celery import Celery app = Celery('tasks', broker='redis://localhost:6379/0') @app.task def process_document(doc_id): # 耗时处理 return result # 调用任务 process_document.delay(doc_id)
