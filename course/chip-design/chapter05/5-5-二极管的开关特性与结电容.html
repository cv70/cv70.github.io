5.5 二极管的开关特性与结电容

PN结与二极管

🎯 学习目标

  • 理解二极管的动态开关特性
  • 掌握反向恢复时间的物理机理
  • 认识结电容的形成与类型
  • 了解开关特性对高频应用的影响

二极管的动态特性概述

在实际电路中，二极管常作为开关使用。理想的开关应该在导通和截止状态之间瞬间切换，但实际二极管由于电荷存储效应和结电容效应，状态切换需要一定时间。理解二极管的动态特性对于高速数字电路和高频模拟电路设计至关重要。

💡 结电容的形成

势垒电容（Cj）

也称耗尽层电容或结电容，由耗尽区中存储的电荷形成。

  • 来源于耗尽区边界随电压变化
  • 反向偏置时为主要电容
  • 随反向电压增大而减小
  • 类似于平板电容器
Cj = Cj0 / (1 + VR/Vbi)n

其中 n 为梯度系数（突变结 n=0.5，线性缓变结 n=0.33）

扩散电容（Cd）

由正向偏置时中性区中存储的少数载流子形成。

  • 来源于少子存储效应
  • 正向偏置时为主要电容
  • 与正向电流成正比
  • 影响开关速度
Cd = τT × IF / VT

其中 τT 为渡越时间，IF 为正向电流

📊 结电容与偏置电压的关系

工作状态 主要电容 电容大小 影响因素
反向偏置 势垒电容 Cj 较小（pF级） 反向电压增大，电容减小
零偏置 势垒电容 Cj0 中等 取决于结面积和掺杂浓度
正向偏置 扩散电容 Cd 较大（可达nF级） 正向电流越大，电容越大
💡
变容二极管原理

利用势垒电容随反向电压变化的特性，可以制作变容二极管（Varactor）。
特点：反向偏置工作，电容随电压变化可调。
应用：压控振荡器（VCO）、调谐电路、频率调制等。

⚡ 反向恢复过程

📈

反向恢复时间（trr）是二极管从正向导通切换到反向截止所需的时间。

恢复过程：

  1. 存储阶段：正向电流变为反向电流，中性区存储的少子开始被抽取
  2. 下降阶段：存储电荷被耗尽，反向电流开始下降
  3. 恢复阶段：反向电流降至稳态值，二极管完全截止

🔬 开关时间参数

关键时间参数

参数 定义 典型值
ts（存储时间） 从正向电流过零到反向电流开始下降 几ns~几μs
tf（下降时间） 反向电流从峰值下降到规定值（如10%） 几ns~几百ns
trr（反向恢复时间） trr = ts + tf 几ns~几μs
ton（开通时间） 从截止到导通所需时间 通常很小，可忽略

📈 不同类型二极管的开关特性

二极管类型 反向恢复时间 特点 应用场景
普通整流二极管 1μs ~ 10μs 恢复慢，正向电流大 低频整流（50Hz/60Hz）
快恢复二极管（FRD） 100ns ~ 500ns 恢复较快 开关电源、逆变器
超快恢复二极管（UFRD） 20ns ~ 100ns 恢复很快 高频开关电源
肖特基二极管 < 10ns 少子存储效应极小 高频、低压应用
⚠️
开关损耗问题

在高速开关电路中，反向恢复过程会产生显著的开关损耗：

  • 反向恢复电流与反向电压同时存在，产生功率损耗
  • 开关频率越高，损耗越大
  • 高频应用需选择快恢复或肖特基二极管
  • 大功率场合需考虑散热设计

📝 本节小结

✅
  • • 势垒电容由耗尽区电荷存储形成，反向偏置时为主
  • • 扩散电容由少子存储效应形成，正向偏置时为主
  • • 反向恢复时间是限制二极管开关速度的关键因素
  • • 肖特基二极管因无少子存储，开关速度最快
  • • 高频应用需选择快恢复或肖特基二极管降低开关损耗
