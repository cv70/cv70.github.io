92.4 Referer 验证

请求来源验证

🎯 学习目标

  • 理解 Referer 和 Origin 头的作用
  • 掌握来源验证的实现方法
  • 了解验证的局限性
  • 学会与其他防护措施配合

📚 Referer 与 Origin

# HTTP 请求头 ## Referer - 包含完整来源 URL - 表示请求从哪个页面发起 - 示例: https://example.com/page.html ## Origin - 只包含协议、域名、端口 - 用于 CORS 和 CSRF 验证 - 示例: https://example.com # 两者的区别 ┌─────────────┬─────────────────────────────────────┐ │ 对比项 │ 说明 │ ├─────────────┼─────────────────────────────────────┤ │ Referer │ 完整 URL，包含路径和查询参数 │ │ Origin │ 只有 scheme + host + port │ │ POST 请求 │ 都会发送 │ │ GET 请求 │ Referer 发送，Origin 不一定 │ │ 可靠性 │ 都可能被伪造或移除 │ └─────────────┴─────────────────────────────────────┘ # 什么情况下不发送 ## Referer - 用户在地址栏直接输入 URL - 从书签访问 - meta 标签设置 no-referrer - Referrer-Policy 限制 - HTTPS → HTTP（默认不发送） ## Origin - 同站请求（某些浏览器不发送） - 导航请求（GET） # Referrer-Policy Content-Security-Policy: referrer-policy no-referrer // 或 <meta name="referrer" content="no-referrer">

🔧 实现来源验证

# Express 中间件验证 function validateOrigin(req, res, next) { const origin = req.headers.origin; const referer = req.headers.referer; // 允许的域名列表 const allowedOrigins = [ 'https://example.com', 'https://www.example.com', ]; // 优先检查 Origin if (origin) { if (allowedOrigins.includes(origin)) { return next(); } return res.status(403).json({ error: 'Invalid origin' }); } // 其次检查 Referer if (referer) { try { const refererUrl = new URL(referer); const refererOrigin = refererUrl.origin; if (allowedOrigins.includes(refererOrigin)) { return next(); } } catch (e) { // URL 解析失败 } return res.status(403).json({ error: 'Invalid referer' }); } // 都没有，根据策略决定 // 安全起见可以拒绝 return res.status(403).json({ error: 'Origin required' }); } // 应用到敏感路由 app.post('/api/transfer', validateOrigin, (req, res) => { // 处理请求 });
⚠️
局限性

Referer 和 Origin 可以被攻击者伪造，或在某些情况下不发送。来源验证应作为辅助防护，不能单独依赖。

⚙️ 安全配置示例

# 完整的 CSRF 防护中间件 import csrf from 'csurf'; // CSRF Token 验证 const csrfProtection = csrf({ cookie: true }); // Origin 验证 function validateOrigin(allowedOrigins: string[]) { return (req, res, next) => { const origin = req.headers.origin; const referer = req.headers.referer; // 如果有 Origin，验证它 if (origin && !allowedOrigins.includes(origin)) { return res.status(403).json({ error: 'Invalid origin' }); } // 如果有 Referer，验证它 if (referer) { try { const refererOrigin = new URL(referer).origin; if (!allowedOrigins.includes(refererOrigin)) { return res.status(403).json({ error: 'Invalid referer' }); } } catch { return res.status(403).json({ error: 'Invalid referer' }); } } next(); }; } // 组合使用 const allowedOrigins = [ 'https://example.com', 'https://www.example.com', ]; app.post('/api/sensitive', csrfProtection, // CSRF Token validateOrigin(allowedOrigins), // Origin 验证 (req, res) => { // 处理请求 } ); # 配合 SameSite Cookie app.use(session({ cookie: { sameSite: 'strict', // SameSite 保护 secure: true, httpOnly: true, }, }));

🚀 特殊场景处理

# 处理无 Origin/Referer 的情况 function validateOriginStrict(allowedOrigins: string[]) { return (req, res, next) => { const origin = req.headers.origin; const referer = req.headers.referer; // 必须有来源信息 if (!origin && !referer) { return res.status(403).json({ error: 'Origin or Referer header required' }); } // 验证逻辑... next(); }; } // 对于某些场景允许无来源 function validateOriginFlexible(allowedOrigins: string[]) { return (req, res, next) => { const origin = req.headers.origin; const referer = req.headers.referer; // 无来源时依赖 CSRF Token if (!origin && !referer) { return next(); } // 有来源时验证 // ... }; } # API 请求验证 // 检查 Content-Type function validateContentType(req, res, next) { const contentType = req.headers['content-type']; // 强制要求 JSON if (!contentType || !contentType.includes('application/json')) { return res.status(415).json({ error: 'Unsupported Media Type' }); } next(); } // X-Requested-With 检查 function validateAjax(req, res, only allow AJAX requests'); } next(); }
