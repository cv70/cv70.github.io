Function Calling

Function Calling让LLM能够结构化地请求调用外部函数，是构建Agent的核心能力。

💻 OpenAI Function Calling

from openai import OpenAI client = OpenAI() # 定义工具 tools = [{ "type": "function", "function": { "name": "get_weather", "description": "获取城市天气", "parameters": { "type": "object", "properties": { "city": {"type": "string"} } } } }] # 调用 response = client.chat.completions.create( model="gpt-4", messages=[{"role": "user", "content": "北京天气如何"}], tools=tools )
