14.5 组合逻辑的 Verilog 建模

Verilog HDL 进阶

学习目标

  • 理解组合逻辑的建模方法
  • 掌握 assign 和 always 的使用
  • 了解组合逻辑常见陷阱
  • 能够编写可综合的组合逻辑代码

组合逻辑建模概述

组合逻辑电路的输出仅取决于当前输入，与历史状态无关。在 Verilog 中，组合逻辑可以通过 assign 连续赋值语句或 always 块来建模。

assign 连续赋值

// 基本逻辑门 assign y = a &b; // 与门 assign y = a | b; // 或门 assign y = ~a; // 非门 assign y = a ^ b; // 异或门 // 条件赋值 assign y = sel ? a : b; // 2选1 MUX
⚠
常见陷阱

敏感列表不完整 - 使用 @(*) 自动推断；赋值不完整 - 会产生锁存器；组合逻辑应使用 = 阻塞赋值
