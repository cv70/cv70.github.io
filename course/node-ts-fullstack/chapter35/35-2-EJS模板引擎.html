35.2 EJS 模板引擎

深入学习 EJS 模板引擎的使用

🎯 学习目标

  • 掌握 EJS 的基本语法
  • 学会 EJS 的条件判断和循环
  • 理解 EJS 的模板包含和布局
  • 掌握 EJS 的配置选项

📦 安装和配置

# 安装 EJS npm install ejs # 安装 express-ejs-layouts（布局支持） npm install express-ejs-layouts
// Express 配置 const express = require('express'); const expressLayouts = require('express-ejs-layouts'); const app = express(); // 设置模板引擎 app.set('view engine', 'ejs'); app.set('views', './views'); // 布局支持 app.use(expressLayouts); app.set('layout', 'layouts/main'); // EJS 配置选项 app.set('view options', { delimiter: '%', // 分隔符 debug: false });

📝 EJS 基本语法

语法 说明 示例
<%= value %> 输出转义后的值 <%= name %>
<%- value %> 输出原始 HTML <%- content %>
<% code %> 执行 JavaScript <% if (user) { %>
<%# comment %> 注释 <%# 这是注释 %>
<%- include('file') %> 包含其他模板 <%- include('header') %>

🔧 EJS 模板示例

变量输出

<!-- 输出转义值 --> <h1>Hello, <%= user.name %>!</h1> <!-- 输出原始 HTML --> <div><%- article.content %></div> <!-- 输出对象属性 --> <p>Email: <%= user.email %></p> <p>Age: <%= user.age %></p>

条件判断

<% if (user) { %> <div class="user-info"> <span><%= user.name %></span> <a href="/logout">Logout</a> </div> <% } else { %> <a href="/login">Login</a> <% } %> <!-- 三元表达式 --> <p class="<%= isActive ? 'active' : '' %>">Item</p>

循环

<ul> <% users.forEach((user, index) => { %> <li class="<%= index % 2 === 0 ? 'even' : 'odd' %>"> <span><%= user.name %></span> <span><%= user.email %></span> </li> <% }); %> </ul> <!-- for 循环 --> <% for (let i = 0; i < items.length; i++) { %> <div><%= items[i] %></div> <% } %>

📁 模板包含

<!-- views/index.ejs --> <!DOCTYPE html> <html> <head> <title><%= title %></title> </head> <body> <!-- 包含头部 --> <%- include('partials/header') %> <main> <h1><%= title %></h1> <!-- 页面内容 --> </main> <!-- 包含底部 --> <%- include('partials/footer') %> </body> </html> <!-- views/partials/header.ejs --> <header> <nav> <a href="/">Home</a> <a href="/about">About</a> </nav> </header> <!-- 向 include 传递数据 --> <%- include('partials/card', { title: 'Card Title', content: '...' }) %>

🎨 布局模板

<!-- views/layouts/main.ejs --> <!DOCTYPE html> <html lang="zh"> <head> <meta charset="UTF-8"> <title><%= title %> - <%= siteName %></title> <link rel="stylesheet" href="/css/style.css"> </head> <body> <%- include('../partials/header') %> <main class="container"> <%- body %> </main> <%- include('../partials/footer') %> <script src="/js/main.js"></script> </body> </html> <!-- views/home.ejs --> <h1>Welcome</h1> <p>This content will be placed in <%- body %></p>

✅ 小结

📌
本节要点
  • <%= %> 输出转义值，<%- %> 输出原始 HTML
  • <% %> 执行 JavaScript 代码
  • include() 包含其他模板文件
  • 使用 express-ejs-layouts 支持布局模板
