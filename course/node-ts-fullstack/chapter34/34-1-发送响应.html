34.1 发送响应

掌握 Express 各种响应发送方法

🎯 学习目标

  • 掌握 res.send() 的各种用法
  • 学会使用 res.json() 发送 JSON 响应
  • 理解不同响应方法的区别
  • 掌握响应链式调用

📤 res.send() 方法

res.send() 是最常用的响应方法，会根据内容类型自动设置 Content-Type 头。

// 发送字符串 app.get('/text', (req, res) => { res.send('Hello World'); }); // 发送 HTML app.get('/html', (req, res) => { res.send('

Hello World

'); }); // 发送对象（自动转为 JSON） app.get('/object', (req, res) => { res.send({ message: 'Hello', data: [] }); }); // 发送数组 app.get('/array', (req, res) => { res.send([1, 2, 3, 4, 5]); }); // 发送 Buffer app.get('/buffer', (req, res) => { res.send(Buffer.from('Hello Buffer')); });

自动 Content-Type 设置

发送内容 Content-Type
字符串 text/html
对象/数组 application/json
Buffer application/octet-stream

📋 res.json() 方法

// 明确发送 JSON 响应 app.get('/api/users', (req, res) => { res.json({ success: true, data: [ { id: 1, name: 'Alice' }, { id: 2, name: 'Bob' } ] }); }); // 配合状态码使用 app.post('/api/users', (req, res) => { const user = createUser(req.body); res.status(201).json({ success: true, data: user }); }); // JSONP 支持 app.get('/api/jsonp', (req, res) => { res.jsonp({ message: 'JSONP response' }); });
💡
res.json() vs res.send()

res.json() 明确将响应设为 JSON 格式，适合 API 开发。res.send() 会根据内容自动判断类型。

🔢 res.status() 方法

// 设置状态码 app.get('/success', (req, res) => { res.status(200).send('Success'); }); app.get('/created', (req, res) => { res.status(201).json({ message: 'Created' }); }); app.get('/not-found', (req, res) => { res.status(404).json({ error: 'Not Found' }); }); app.get('/error', (req, res) => { res.status(500).json({ error: 'Internal Server Error' }); }); // 链式调用 app.get('/chain', (req, res) => { res .status(200) .set('X-Custom-Header', 'value') .json({ message: 'Success' }); });

HTTP 状态码参考

// 2xx 成功 res.status(200); // OK res.status(201); // Created res.status(204); // No Content // 3xx 重定向 res.status(301); // Moved Permanently res.status(302); // Found res.status(304); // Not Modified // 4xx 客户端错误 res.status(400); // Bad Request res.status(401); // Unauthorized res.status(403); // Forbidden res.status(404); // Not Found res.status(422); // Unprocessable Entity res.status(429); // Too Many Requests // 5xx 服务器错误 res.status(500); // Internal Server Error res.status(502); // Bad Gateway res.status(503); // Service Unavailable

📝 其他响应方法

// res.end() - 结束响应（不发送数据） app.get('/end', (req, res) => { res.status(204).end(); }); // res.write() - 流式写入 app.get('/stream', (req, res) => { res.write('Chunk 1\n'); res.write('Chunk 2\n'); res.write('Chunk 3\n'); res.end(); }); // res.type() - 设置 Content-Type app.get('/type', (req, res) => { res.type('json').send({ message: 'Hello' }); }); // res.sendStatus() - 发送状态码响应 app.get('/ok', (req, res) => { res.sendStatus(200); // 发送 "OK" }); // res.format() - 内容协商 app.get('/format', (req, res) => { res.format({ 'text/plain': () => res.send('Hello'), 'text/html': () => res.send('

Hello

'), 'application/json': () => res.json({ message: 'Hello' }), 'default': () => res.status(406).send('Not Acceptable') }); });

✅ 小结

📌
本节要点
  • res.send() 自动设置 Content-Type
  • res.json() 明确发送 JSON 响应
  • res.status() 设置状态码，支持链式调用
  • 正确使用 HTTP 状态码很重要
