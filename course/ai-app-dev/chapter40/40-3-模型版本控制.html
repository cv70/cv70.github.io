什么是模型版本控制

模型版本控制是对机器学习模型进行系统化管理的过程，包括模型的存储、版本标记、阶段转换和变更追踪。它确保团队可以追溯每个模型的来源、训练过程和部署状态。

⚖️ 模型生命周期阶段

阶段 说明 操作
None/Archive 初始状态或已归档 注册新模型
Staging 预发布阶段，进行验证测试 测试验证、性能评估
Production 生产环境运行中 流量服务、监控告警
Archived 已下线，保留历史记录 回滚、审计追溯

💻 MLflow模型注册中心

from mlflow.tracking import MlflowClient client = MlflowClient() # 注册新模型 model_uri = "runs:/abc123/model" model_version = mlflow.register_model( model_uri=model_uri, name="sentiment_classifier" ) # 添加模型描述 client.update_model_version( name="sentiment_classifier", version=model_version.version, description="基于BERT的情感分类模型，准确率95.2%" ) # 阶段转换 client.transition_model_version_stage( name="sentiment_classifier", version=model_version.version, stage="Staging" ) # 获取生产环境模型 production_versions = client.get_latest_versions( "sentiment_classifier", stages=["Production"] )
💡
模型血缘追溯

每个模型版本应记录完整的血缘信息：训练数据版本、代码commit hash、超参数配置、基础模型等。这些信息对于问题排查和审计至关重要。

🔧 模型元数据标准

必填元数据

{ "model_name": "sentiment_classifier", "version": "5", "stage": "Production", "training_data": "data_v3.2", "metrics": { "accuracy": 0.952, "f1_score": 0.948 }, "created_at": "2024-01-15T10:30:00Z", "created_by": "data_team" }
  • 模型名称和版本号
  • 训练数据引用
  • 核心性能指标

推荐元数据

{ "base_model": "bert-base-chinese", "framework": "pytorch", "code_version": "git:abc123", "hyperparameters": { "learning_rate": 2e-5, "epochs": 3, "batch_size": 32 }, "dependencies": { "torch": "2.0.1", "transformers": "4.35.0" } }
  • 基础模型信息
  • 代码版本关联
  • 依赖环境记录

🔄 模型回滚策略

# 自动化回滚脚本示例 def rollback_model(model_name, target_version, reason): """回滚模型到指定版本""" client = MlflowClient() # 获取当前生产版本 current = client.get_latest_versions( model_name, stages=["Production"] )[0] # 将当前版本归档 client.transition_model_version_stage( name=model_name, version=current.version, stage="Archived" ) # 恢复目标版本到生产 client.transition_model_version_stage( name=model_name, version=target_version, stage="Production" ) # 记录回滚原因 client.update_model_version( name=model_name, version=target_version, description=f"Rollback from v{current.version}. Reason: {reason}" )
