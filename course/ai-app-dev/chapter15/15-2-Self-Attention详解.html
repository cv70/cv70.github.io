15.2 Self-Attention详解

自注意力机制的核心原理

🎯 学习目标

  • 深入理解Self-Attention的工作原理

  • 能够实现Self-Attention层

什么是Self-Attention

自注意力机制（Self-Attention）是注意力机制的一种特殊形式，其中Query、Key和Value都来自同一个输入序列。 这意味着序列中的每个元素都可以与序列中的其他所有元素进行交互，从而捕捉序列内部的依赖关系。 Self-Attention是Transformer架构的核心，也是BERT、GPT等模型的基础。

🔄 Self-Attention工作流程

1
线性投影
2
计算相似度
3
缩放归一化
4
加权聚合

📐 Self-Attention数学公式

# Self-Attention（缩放点积注意力） # 输入：X [batch_size, seq_len, d_model] # 步骤1：线性投影生成Q、K、V Q = X · WQ # [batch, seq_len, d_k] K = X · WK # [batch, seq_len, d_k] V = X · WV # [batch, seq_len, d_v] # 步骤2：计算注意力分数（缩放点积） Scores = Q · KT / √dk # [batch, seq_len, seq_len] # 步骤3：Softmax归一化 Attention = softmax(Scores) # [batch, seq_len, seq_len] # 步骤4：加权求和 Output = Attention · V # [batch, seq_len, d_v] # 为什么需要缩放？ # 当d_k很大时，点积结果会很大，导致softmax梯度趋近于0 # 缩放因子√d_k使梯度更稳定

💻 PyTorch实现Self-Attention

import torch import torch.nn as nn import math class SelfAttention(nn.Module): def __init__(self, d_model, d_k=None, d_v=None): super().__init__() self.d_model = d_model self.d_k = d_k or d_model self.d_v = d_v or d_model # Q、K、V的线性投影 self.W_q = nn.Linear(d_model, self.d_k) self.W_k = nn.Linear(d_model, self.d_k) self.W_v = nn.Linear(d_model, self.d_v) # 输出投影 self.W_o = nn.Linear(self.d_v, d_model) def forward(self, x, mask=None): batch_size, seq_len, _ = x.size() # 计算Q、K、V Q = self.W_q(x) # [batch, seq, d_k] K = self.W_k(x) # [batch, seq, d_k] V = self.W_v(x) # [batch, seq, d_v] # 计算注意力分数（缩放点积） scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(self.d_k) # 应用mask（用于解码器或填充） if mask is not None: scores = scores.masked_fill(mask == 0, -1e9) # Softmax归一化 attention = torch.softmax(scores, dim=-1) # 加权求和 output = torch.matmul(attention, V) # 输出投影 output = self.W_o(output) return output, attention

⚖️ Self-Attention vs 传统注意力

特性 传统注意力 Self-Attention
Query来源 解码器状态 输入序列本身
Key/Value来源 编码器输出 输入序列本身
交互范围 跨序列（源→目标） 序列内部
并行计算 受限于解码顺序 完全可并行
长距离依赖 需要编码器传递 直接一步到达

🔬 Self-Attention的优势

并行计算

所有位置同时计算，不像RNN需要顺序处理

# 所有位置一次性计算 output = self_attention(input) # vs RNN需要逐步处理 for t in range(seq_len): h[t] = rnn(x[t], h[t-1])

全局感受野

每个位置直接与所有其他位置交互

# 序列中任意两个位置的距离都是1 # 无论序列多长，都能直接捕捉依赖 # 解决了RNN的长距离依赖问题
💡
计算复杂度

Self-Attention的时间复杂度为O(n²d)，其中n是序列长度，d是特征维度。对于超长序列， 可以考虑使用稀疏注意力或局部注意力来降低计算量。

  • • 实现了任意位置间的直接交互
