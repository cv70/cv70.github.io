74.4 开发工具链

构建现代化前端开发环境

🎯 学习目标

  • 了解前端构建工具
  • 掌握包管理器使用
  • 理解编译和打包流程
  • 认识开发工具链的作用

📚 包管理器

// npm (Node Package Manager) npm init // 初始化项目 npm install react // 安装依赖 npm install -D typescript // 安装开发依赖 npm run build // 运行构建脚本 // package.json 示例 { "name": "my-app", "version": "1.0.0", "scripts": { "dev": "vite", "build": "tsc && vite build", "preview": "vite preview", "lint": "eslint src --ext .ts,.tsx", "test": "vitest" }, "dependencies": { "react": "^18.2.0", "react-dom": "^18.2.0" }, "devDependencies": { "typescript": "^5.0.0", "vite": "^5.0.0", "@types/react": "^18.2.0" } } // yarn / pnpm（更快的包管理器） pnpm install react // 使用符号链接节省磁盘空间 pnpm add -D typescript // 更快的安装速度 // workspace 支持多包项目 pnpm-workspace.yaml packages: - 'packages/*'

🔧 构建工具

// Vite 配置示例（vite.config.ts） import { defineConfig } from 'vite'; import react from '@vitejs/plugin-react'; import path from 'path'; export default defineConfig({ plugins: [react()], resolve: { alias: { '@': path.resolve(__dirname, './src'), }, }, server: { port: 3000, proxy: { '/api': { target: 'http://localhost:3001', changeOrigin: true, }, }, }, build: { outDir: 'dist', sourcemap: true, }, }); // Webpack 配置示例（webpack.config.js） module.exports = { entry: './src/index.tsx', output: { path: path.resolve(__dirname, 'dist'), filename: 'bundle.[contenthash].js', }, module: { rules: [ { test: /\.tsx?$/, use: 'ts-loader', exclude: /node_modules/, }, { test: /\.css$/, use: ['style-loader', 'css-loader'], }, ], }, resolve: { extensions: ['.tsx', '.ts', '.js'], }, };
