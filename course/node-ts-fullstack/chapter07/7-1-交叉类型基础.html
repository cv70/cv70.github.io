7.1 交叉类型基础

将多个类型合并为一个类型

🎯 学习目标

  • 理解交叉类型的概念和作用
  • 掌握 & 运算符的使用
  • 学会合并对象类型
  • 了解交叉类型与联合类型的区别

📚 什么是交叉类型？

// 交叉类型使用 & 符号将多个类型合并为一个 // 新类型拥有所有类型的特性 interface Name { name: string; } interface Age { age: number; } // Person 同时拥有 name 和 age type Person = Name & Age; const person: Person = { name: 'Alice', age: 30 }; // 合并多个类型 interface Email { email: string; } interface Phone { phone: string; } type Contact = Email & Phone; type User = Person & Contact; const user: User = { name: 'Alice', age: 30, email: 'alice@example.com', phone: '123-456-7890' };
💡
交叉类型 vs 联合类型

交叉类型（&）表示"同时拥有"，联合类型（|）表示"或其中之一"。交叉类型取交集的属性（必须同时满足），联合类型取并集的属性（只需满足其中一个）。

🔧 基本用法

// 合并基本类型 type StringAndNumber = string & number; // never - 没有值能同时是 string 和 number // 合并对象类型（最常用） interface BusinessPartner { name: string; credit: number; } interface Identity { id: number; name: string; } interface Contact { email: string; phone: string; } type Customer = BusinessPartner & Identity & Contact; const customer: Customer = { id: 1, name: 'Acme Corp', credit: 100000, email: 'contact@acme.com', phone: '555-1234' }; // 函数参数使用交叉类型 function printCustomerInfo(customer: BusinessPartner & Identity): void { console.log(`ID: ${customer.id}, Name: ${customer.name}, Credit: ${customer.credit}`); }

📝 本节小结

✅
