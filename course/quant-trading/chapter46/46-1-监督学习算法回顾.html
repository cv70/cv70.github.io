监督学习算法回顾

监督学习算法是机器学习中最核心的一类算法，在量化交易中有着广泛应用。 通过已有标签的数据训练模型，实现对金融市场的预测和决策。本节将系统回顾监督学习的主要算法及其在量化中的应用。

🔬 核心算法详解

1. 线性回归

最基础的回归算法，通过拟合直线来预测连续值。在量化中常用于收益预测、因子权重分配等。

应用场景：

  • 股票收益预测
  • 波动率建模
  • 因子收益归因

2. 逻辑回归

分类算法，使用Sigmoid函数将输出映射到[0,1]区间，用于二分类问题。

应用场景：

  • 涨跌方向预测
  • 违约风险分类
  • 信号生成

3. 支持向量机（SVM）

通过寻找最优超平面进行分类，可使用核函数处理非线性问题。

应用场景：

  • 市场状态识别
  • 异常检测
  • 模式识别

4. 决策树

通过树形结构进行决策，可解释性强，但容易过拟合。

应用场景：

  • 规则提取
  • 特征重要性分析
  • 可解释性要求高的场景

5. 随机森林

集成多个决策树，通过投票或平均提升模型稳定性和准确性。

应用场景：

  • 多因子选股
  • 风险预测
  • 特征重要性排序

6. 梯度提升树（GBDT）

通过迭代训练弱学习器并逐步纠正错误，在表格数据上表现优异。

应用场景：

  • 价格预测
  • 成交量预测
  • 量化因子挖掘

7. XGBoost/LightGBM

优化的梯度提升算法，速度快、效果好，是量化交易中的主流选择。

应用场景：

  • 高频信号生成
  • 实时预测
  • 大规模数据建模

8. 神经网络

多层感知器等基础神经网络，能够学习复杂的非线性关系。

应用场景：

  • 复杂模式识别
  • 非线性关系建模
  • 多模态数据融合

💻 代码示例

import numpy as np
import pandas as pd
from sklearn.linear_model import LinearRegression, LogisticRegression
from sklearn.ensemble import RandomForestClassifier, GradientBoostingClassifier
from sklearn.svm import SVC
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score, mean_squared_error

# 示例数据准备
def prepare_data(df, target_col, test_size=0.2):
    """准备训练测试数据"""
    X = df.drop(columns=[target_col])
    y = df[target_col]
    return train_test_split(X, y, test_size=test_size, random_state=42)

# 1. 线性回归 - 收益预测
def linear_regression_predict(X_train, y_train, X_test):
    """使用线性回归预测收益"""
    model = LinearRegression()
    model.fit(X_train, y_train)
    predictions = model.predict(X_test)
    mse = mean_squared_error(y_test, predictions)
    return model, predictions, mse

# 2. 逻辑回归 - 涨跌分类
def logistic_regression_classify(X_train, y_train, X_test):
    """使用逻辑回归进行涨跌预测"""
    model = LogisticRegression(random_state=42)
    model.fit(X_train, y_train)
    predictions = model.predict(X_test)
    proba = model.predict_proba(X_test)
    accuracy = accuracy_score(y_test, predictions)
    return model, predictions, proba, accuracy

# 3. 随机森林 - 多因子选股
def random_forest_predict(X_train, y_train, X_test):
    """使用随机森林进行预测"""
    model = RandomForestClassifier(
        n_estimators=100,
        max_depth=10,
        random_state=42
    )
    model.fit(X_train, y_train)
    predictions = model.predict(X_test)
    feature_importance = pd.DataFrame({
        'feature': X_train.columns,
        'importance': model.feature_importances_
    }).sort_values('importance', ascending=False)
    return model, predictions, feature_importance

# 4. GBDT - 高频预测
def gradient_boosting_predict(X_train, y_train, X_test):
    """使用梯度提升树进行预测"""
    model = GradientBoostingClassifier(
        n_estimators=100,
        learning_rate=0.1,
        max_depth=5,
        random_state=42
    )
    model.fit(X_train, y_train)
    predictions = model.predict(X_test)
    return model, predictions

# 5. 多算法对比
def compare_models(X_train, y_train, X_test, y_test):
    """对比多种算法性能"""
    models = {
        'Logistic Regression': LogisticRegression(random_state=42),
        'Random Forest': RandomForestClassifier(n_estimators=100, random_state=42),
        'GBDT': GradientBoostingClassifier(n_estimators=100, random_state=42),
        'SVM': SVC(probability=True, random_state=42)
    }

    results = {}
    for name, model in models.items():
        model.fit(X_train, y_train)
        predictions = model.predict(X_test)
        accuracy = accuracy_score(y_test, predictions)
        results[name] = accuracy

    return results

📚 量化交易应用案例

案例1：多因子选股模型

使用XGBoost结合多个因子进行股票收益预测，选择预测值最高的股票组合。

  • 输入：量价因子、财务因子、情绪因子等
  • 输出：未来收益率预测
  • 策略：买入Top-K股票，定期调仓

案例2：高频择时模型

使用LightGBM在分钟级数据上进行短期涨跌预测。

  • 输入：技术指标、订单簿特征、微观结构指标
  • 输出：未来5分钟涨跌概率
  • 策略：概率超过阈值时交易

案例3：违约风险预测

使用随机森林评估企业违约风险。

  • 输入：财务比率、行业特征、宏观指标
  • 输出：违约概率
  • 应用：信用风险管理
⚠️
注意事项

1. 金融数据噪声大，需要特别注意过拟合问题
2. 特征工程比算法选择更重要
3. 样本外验证必不可少
4. 交易成本会影响实际收益

✨
最佳实践

在量化交易中，推荐从简单模型（如逻辑回归、随机森林）开始，建立基线后再尝试复杂模型。 特征质量往往比模型复杂度更重要，建议投入更多时间在特征工程上。
