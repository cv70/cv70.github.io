什么是模型量化

模型量化（Model Quantization）是指将神经网络中的参数从高精度浮点数（如FP32）转换为低精度数（如INT8）的技术。 通过减少每个参数占用的比特数，可以显著降低模型的存储需求和计算成本。

🎭 量化方法

对称量化

  • 范围：[-scale, scale]
  • 零点：始终为0
  • 优点：计算简单
  • 缺点：分布不对称时精度损失大

非对称量化

  • 范围：[zero_point, zero_point + scale]
  • 零点：可调整
  • 优点：适应任意分布
  • 缺点：计算稍复杂

📊 量化公式

量化与反量化

对称量化
Q(x) = round(x / scale)
DQ(q) = q * scale
非对称量化
Q(x) = round(x / scale) + zero_point
DQ(q) = (q - zero_point) * scale

💻 量化实现示例

import torch
import torch.nn as nn

def quantize_tensor(tensor, num_bits=8):
    """
    对张量进行对称量化
    """
    # 计算量化参数
    max_val = tensor.abs().max()
    qmax = 2 ** (num_bits - 1) - 1

    # 计算scale
    scale = max_val / qmax

    # 量化
    quantized = torch.clamp(
        torch.round(tensor / scale),
        -qmax,
        qmax
    ).to(torch.int8)

    return quantized, scale

def dequantize_tensor(quantized, scale):
    """
    反量化
    """
    return quantized.float() * scale

# 使用示例
# 原始FP32张量
fp32_tensor = torch.randn(10, 10)

# 量化到INT8
int8_tensor, scale = quantize_tensor(fp32_tensor, num_bits=8)

# 反量化
reconstructed = dequantize_tensor(int8_tensor, scale)

# 计算量化误差
error = (fp32_tensor - reconstructed).abs().mean()
print(f"量化误差: {error:.6f}")

# PyTorch内置量化
from torch.ao.quantization import quantize_dynamic

# 动态量化（权重）
model = nn.Sequential(
    nn.Linear(768, 768),
    nn.ReLU(),
    nn.Linear(768, 256)
)

quantized_model = quantize_dynamic(
    model,
    {nn.Linear},  # 要量化的层类型
    dtype=torch.qint8
)

# 比较模型大小
def get_model_size(model):
    param_size = 0
    for param in model.parameters():
        param_size += param.nelement() * param.element_size()
    return param_size

print(f"原始模型大小: {get_model_size(model) / 1024:.2f} KB")
print(f"量化后模型大小: {get_model_size(quantized_model) / 1024:.2f} KB")

⚠️
量化注意事项
  • 量化会带来精度损失，需要评估实际影响
  • 低比特量化（INT4）可能需要特殊校准
  • 不同层的敏感性不同，可考虑分层量化
  • 某些硬件不支持低精度计算
