31.2 命名实体识别

从文本中提取结构化信息

🎯 学习目标

  • 理解命名实体识别(NER)的概念与意义
  • 掌握常见实体类型与标注方法
  • 了解主流NER模型架构
  • 学会使用开源工具进行实体识别

什么是命名实体识别

命名实体识别（Named Entity Recognition, NER）是指从非结构化文本中识别并分类预定义类别的实体，如人名、地名、组织名、时间、金额等。NER是信息抽取、知识图谱构建的基础任务。

🏷️ 常见实体类型

👤

人名(PER)

张三、李四、王五

🏢

组织(ORG)

腾讯、阿里巴巴、清华大学

📍

地名(LOC)

北京、上海、长江

📅

时间(TIME)

2024年、明天、下周

⚖️ 标注方法对比

标注方法 说明 示例 特点
BIO B-开始，I-内部，O-其他 B-PER I-PER O 简单常用
BIOES B-开始，I-内部，O-其他，E-结束，S-单字 B-PER I-PER E-PER O 标注更精细
BMEOW B-开始，M-中间，E-结束，O-其他，W-单字 B-PER M-PER E-PER O 中文分词常用

💻 代码示例：使用HuggingFace进行NER

from transformers import AutoTokenizer, AutoModelForTokenClassification
from transformers import pipeline

# 加载中文NER模型
model_name = "bert-base-chinese"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForTokenClassification.from_pretrained(model_name)

# 创建NER管道
nlp = pipeline("ner", model=model, tokenizer=tokenizer)

# 实体识别
text = "张三在北京清华大学学习人工智能"
results = nlp(text)

for entity in results:
    print(f"实体: {entity['word']}")
    print(f"类型: {entity['entity']}")
    print(f"置信度: {entity['score']:.2f}")
    print("---")

🧠 NER模型架构演进

传统方法

  • 基于规则的方法（字典匹配）
  • 隐马尔可夫模型(HMM)
  • 条件随机场(CRF)
  • 需要大量特征工程

深度学习方法

  • BiLSTM-CRF
  • BERT-CRF
  • Biaffine NER
  • 端到端学习，效果更优
⚠️
注意事项

中文NER相比英文更具挑战性，因为中文没有天然的词边界。在实际应用中，需要考虑分词错误传播、嵌套实体识别、低频实体识别等问题。
