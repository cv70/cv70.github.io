19.3 Pinecone使用

云端向量数据库入门

🎯 学习目标

  • 掌握Pinecone基本概念
  • 学会创建和管理索引
  • 掌握向量增删查操作
  • 了解Pinecone的元数据过滤

Pinecone简介

Pinecone是一个托管的向量数据库服务，提供高性能的向量存储和检索能力， 无需管理基础设施，适合快速构建AI应用。

💻 基本使用

from pinecone import Pinecone pc = Pinecone(api_key="your-api-key") # 创建索引 pc.create_index( name="my-index", dimension=1536, metric="cosine", spec=ServerlessSpec(cloud="aws", region="us-east-1") ) # 连接索引 index = pc.Index("my-index") # 插入向量 index.upsert([ ("id1", [0.1, 0.2, ...], {"text": "示例文本"}), ("id2", [0.3, 0.4, ...], {"text": "另一文本"}) ]) # 查询相似向量 results = index.query( vector=[0.1, 0.2, ...], top_k=5, include_metadata=True )

🔍 元数据过滤

results = index.query( vector=embedding, top_k=10, filter={ "category": {"$eq": "tech"}, "year": {$gte": 2023} } )

免费额度
